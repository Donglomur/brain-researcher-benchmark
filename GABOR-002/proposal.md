## GABOR-002

**Proposal Title:** Voxel-wise visual-encoding (Gabor receptive-field) model of a stimulus-response cohort — an execution-hard reconstruction task (recipe divergence + coupled-physics assembly + hidden robustness)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** Computational visual neuroscience / voxel encoding models

**Source paper:** Kay et al. 2008, *Nature* (identifying natural images from human brain activity / Gabor-wavelet voxel encoding, https://doi.org/10.1038/nature06713); Naselaris et al. 2011, *NeuroImage* (encoding and decoding in fMRI). Dataset: a **paper-parameterized** visual-encoding cohort (precomputed Gabor-pyramid features + per-voxel training responses, held-out test stimuli; Kay 2008 encoding-model signal model), generated deterministically at `synth_build/generate_fixtures.py`; the true physiology is held out for grading under `tests/planted_truth.npz` (the noise-free true response `F_te · W_true` + the true signal-voxel mask, built by the generator; never under `environment/data`).

**Status: FULL runnable Harbor task.** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — the instruction names the deliverable (fit each voxel's receptive field and predict held-out test responses) and the difficulty is *execution*, not an un-cued judgement. It follows the shape of the maintainer's `pcasl-cbf-quantifier`: the agent implements the encoding-model pipeline **from scratch** (no fitter bundled), over a **heterogeneous cohort where subjects need fundamentally different computations**, with a **declared robustness** requirement (realization hidden), graded against the **held-out planted physiology** on a **convention-invariant** (correlation-scored) prediction.

### What changed in this revision (addressing the review of the recompute-and-grade design)

1. **Robustness contract made public.** `instruction.md` now states, under *Robustness / data-quality contract*, that (a) a substantial minority of voxels are pure noise and must be excluded, (b) a minority of subjects carry grossly corrupted training samples that must be detected and rejected robustly, and (c) the time-course subjects must be HRF-deconvolved — only the *realization* (which voxels/samples/subjects) is hidden. A correct implementation of the stated model is no longer penalized for failing to guess an undeclared step.
2. **Graded against the true receptive fields, not one fitter.** The verifier no longer recomputes with a private pipeline on the noisy data and demands agreement. It compares each submitted prediction, voxelwise-by-correlation, to the **held-out planted target** = the noise-free true test response `F_te · W_true` (direction only, since grading is correlation-based) and the **true** signal-vs-noise voxel mask (`tests/planted_truth.npz`, emitted by `synth_build/generate_fixtures.py`). That target is the convention-invariant physical truth; **any valid estimator** applied to the noisy data recovers it within tolerance. The hidden reference modules (`gabor_pipeline.py`, `gabor_ref.py`) were removed from `tests/`.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — subjects ship the training responses in *two different representations*, discoverable only from each sidecar: some provide per-stimulus response amplitudes (`resp_train`, ready to regress) while others provide a raw detrended BOLD time-course (`ts_train`) plus stimulus-onset TRs and **no** amplitudes — those must first be recovered by least-squares **HRF deconvolution** against the canonical HRF before any receptive field can be fit. A pipeline that assumes one representation cannot process the other.
2. **Coupled-physics assembly** — the fit is a per-voxel L2-regularised (ridge) regression with the regularisation chosen from the data; on the time-course subjects the deconvolution feeds the regression, and the **direction** of the receptive field (not any absolute scale) is what must generalise to held-out stimuli. An error in the deconvolution, the ridge path, or the reliability score compounds.
3. **Declared robustness, hidden realization** — the instruction now *declares* that a minority of subjects carry a few grossly corrupted training samples (motion spikes) that must be rejected before fitting — including on the time-course subjects, where the spike must be caught in the *deconvolved* amplitudes, so the deconvolution and the robust rejection are coupled — and that a substantial fraction of voxels in every subject carry no stimulus tuning (pure noise) and must be **excluded as NaN columns** rather than predicted, judged per-voxel from cross-validated reliability. Only the *realization* (which subjects/samples/voxels) is hidden — the agent must still find them from the data without dropping the good ones.
4. **Convention-invariant grading** — predictions are scored by *correlation* across the test stimuli against the noise-free true response `F_te · W_true`, so any global gain, offset, or regularisation strength cancels — only the receptive-field direction is graded; the true signal-vs-noise set is separated by a wide bimodal gap (signal voxels ~0.6–0.9 recoverable prediction correlation, noise voxels ~0), so an independently-implemented reliability criterion recovers the same mask. No reporting-convention ambiguity.

### Verifier

`tests/test_outputs.py` grades each submitted prediction **against the held-out planted physiology** (`tests/planted_truth.npz`; never under `/app/data`), one parametrized test per (subject × panel) — **16 panels** in all (8 subjects × {pred, omit}). A `pred` panel passes when ≥90% (`PRED_FRAC`) of the **true signal voxels** have a finite predicted column correlating ≥0.90 (`CORR_MIN`), across the test stimuli, with the planted true response `F_te · W_true`; an `omit` panel passes when the submission's keep/exclude decision matches the **true** signal-vs-noise mask on ≥90% (`OMIT_FRAC`) of voxels. Correlation grading makes the score scale/offset invariant, so any gain or regularisation strength cancels — only the receptive-field direction is graded. Reward is fractional over the 16 panels. The thresholds are unchanged from the original recompute-and-grade verifier; the target changed from a reference fit on noisy data to the noise-free planted truth. All reference modules were removed from `tests/`.

**Validity / discrimination evidence (recomputed for this revision).** The oracle recovers the planted target on **all 16 panels** (per-subject fraction of true-signal voxels meeting `CORR_MIN` 0.95–1.00; keep/exclude agreement 1.00 on every subject) — comfortably inside tolerance, and the reference's data-derived fittable mask equals the true signal mask exactly (wide bimodal gap). Wrong pipelines each fail their own axis, graded through the real verifier / identical grading logic: **skip the corrupted-sample rejection** → 9 panels fail (exactly the corrupted subjects); **never exclude un-fittable voxels** → 8 omit panels fail; **skip the HRF deconvolution (treat the raw time-course as amplitudes)** → 6 panels fail (the three time-course subjects). So a from-scratch correct solver passes and each single-axis shortcut fails, on axes the instruction now *declares*.

### Notes / honesty

- **Reconstruction paradigm.** This task's difficulty is executional (get many coupled quantitative decisions right with no recipe), unlike the recognition-tier "un-cued judgement" tasks in this repo. `instruction.md` names the deliverable, the model conventions, *and* the robustness contract, but never enumerates the *realization* (which subjects use which representation, which samples are corrupted, which voxels are noise) — the agent must discover it from the data.
- **Data.** Paper-parameterized, small, deterministic, and **leakage-clean** (the planted truth lives only in `tests/planted_truth.npz`, never under `/app/data`; verified by regen leaving `environment/data` byte-identical). Regenerable via `synth_build/generate_fixtures.py`.
- **allow_internet=false.** The task is self-contained (dependencies baked in the image; no network at run or verify time).
