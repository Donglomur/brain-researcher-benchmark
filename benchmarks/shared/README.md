These families retain scientific source used by, related to, or not yet assigned to registered tasks. A shared folder does not establish task ownership or a completed benchmark. The authoritative registry records owners, related tasks and scientific scope separately.

- **Assigned source:** explicit registered task owners; the scope note still governs whether source is partial or alternative.
- **Related source only:** a scientific relationship without an assigned implementation, such as ABR background classification versus threshold transfer.
- **Unbound scientific family:** no registered task owner or related-task assignment; preserved source remains available without inventing a benchmark association.
- **Unresolved ownership:** an explicit unresolved status; no task implementation is claimed.

Scientific and submission readiness remain **unknown**. Stable artifact IDs and original paths remain in [catalog metadata](../catalog/catalog.json).
