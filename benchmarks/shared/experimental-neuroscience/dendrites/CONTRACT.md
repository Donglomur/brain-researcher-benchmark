## Prospective improvement, defined before data execution

The improvement question is whether morphology predicts FL/PL in an unseen donor or animal under preprocessing learned only from training groups. The mandatory biological group is source-supported donor/animal identity. A neuron identifier, reconstructed file or recording field is not a substitute. Every eligible group becomes a held-out group exactly once, separately within each species. At least three groups per species are required for the declared nested group tuning. Both outer and every inner training complement must contain both lobes; otherwise the complete design is unresolved rather than dropping that fold. The scorer checks this complete support condition before evaluating predictions.

The frozen protected manifest contains all2,363 human and16,011 mouse source identities, each included or excluded with a source-supported reason. These totals are archive-metadata expectations, not a verified payload census or the final eligible cohort. Include FL/PL pyramidal cells passing the frozen feature rule; account for every other source neuron. Admission must authenticate the complete neuron-to-group map and its digest before the scorer receives the manifest. The scorer checks syntax and completeness, not the truth of that map.

Primary metric: for each species and true lobe, calculate recall in each biological group that contributes that lobe; average those group recalls, then average the two lobes and the two species. This prevents a donor with many reconstructed neurons from dominating. Group/class weighted Brier loss and clipped log loss are diagnostics. The probability decision is fixed: `p_PL > 0.5` selects PL, otherwise FL. Keep species-specific results visible. The numerical primary metric is fully implemented in `score_lobes.py`.

Required frozen comparators are a training-prior constant predictor and an RF using the released feature family with all feature transformation, ranking and hyperparameter selection inside the training groups. Nested group validation selects hyperparameters and feature count; an outer held group never influences either. The RF is a prospective corrected comparator, not asserted equivalent to the notebook's historical predictions. A size-only baseline using the corresponding length, distance and volume features assesses whether a gain requires branching organization. No reference has been fitted by this source phase.

The same held-group predictions must support paired reference deltas. Before an improvement claim, independently verify the complete reference, all folds, label joins and a donor/animal-level uncertainty analysis. Do not bootstrap neurons as independent biological replicates. If the authentic grouping cannot support that analysis, report finite descriptive scores without biological-transfer significance. The present scorer reports a descriptive delta, never a p-value, SOTA claim or qualification flag.
