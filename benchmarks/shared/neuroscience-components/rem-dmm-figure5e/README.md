# Finite REM stimulation outcome evaluator

This adds an executable missing output evaluator for registered `PAPER-SCOPE-20261114-REM-DYNAMICS`, restricted to the complete Figure 5e dmM stimulation cohort. It does not add another benchmark ID. It does not reproduce the six-mouse spontaneous-transition Figure 2h, other interventions, LDA fitting, whole-session PCA or native paper results.

`score.py` scores complete held predictions under an owner-bound 22-PC by ten-repeat realization of the published protocol. It computes confusion matrices, accuracy, sample SEM and one-sided t statistics, leaving unresolved multiple-testing correction explicit. A separate probability profile implements the previously scoped prospective equal-mouse Brier endpoint, clearly distinguished from the original paper statistic. `TASK.md` and `INTERFACE.md` explain exposure, inference and finite support.

`python score.py OWNER.json CANDIDATE.json --baseline BASELINE.json` adds a frozen comparator for `historical_fig5e` only. Both prediction sets must cover every held trial in all 220 cells on the identical declared plan. The report retains all 22 ten-repeat accuracy distributions, the same baseline summaries, paired accuracy differences and discordant correctness counts. Each cell includes all five mice, with null accuracy for absent mice; the 45-trial census preserves zero-use trials. These descriptive comparisons retain pooled-trial accuracy and do not introduce a selected-PC score, cross-protocol scalar, paired significance test or improvement admission. They do not authenticate the declared original cohort, splits, preprocessing or baseline. Omitting `--baseline` retains the single-submission path; supplying it for prospective Brier mode is refused.

`test_score.py` uses only fabricated data, with deliberately unequal mouse trial counts. It exercises complete support, omission/duplication, group weighting, label authority, split separation, analytic t-tail controls, undefined statistics, malformed probabilities and bounded filesystem parsing. Paired controls check exact discordant counts, preserved source statistics, reordered comparator rows, mismatched plans, missing or substituted held trials, absent mice and zero-use trial retention. Running those controls is source validation, not neuroscience analysis or an agent benchmark run.

No authentic numerical dataset, reference predictions, original author code or article text is bundled. `PRIMARY_EVIDENCE.json` records retained source identities and paraphrased endpoint observations. The source provenance is Nature Neuroscience DOI10.1038/s41593-026-02314-z, Zenodo19462601 Ver2 and Npx commitded027368c37f19c837baf02b81802007886ba46.
