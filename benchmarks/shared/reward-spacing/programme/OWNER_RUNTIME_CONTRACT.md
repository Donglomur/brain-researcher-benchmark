# External trusted-owner interface

This component ships a callable generated program/grade path; its run.py and neural CLI deliberately refuse authentic execution. It also preserves existing source-level APIs for a future qualified owner. No adapter here creates Docker containers, downloads data, logs in to providers or invents an environment.

## Exact external inputs

EXTERNAL_INPUTS.json lists retained source identities only. The owner-inputs paths are logical paths relative to an explicit external input root, not paths automatically resolved or downloaded by this package. They are absent from the component. For example, paper/runtime/native.collect_native receives root explicitly and verifies complete source/export descriptors there. A pair's ordinary author-code descriptors must match the available source-role byte lengths and hashes; pipeline.source_roles still recognizes the exact /public/code/ suffix. A descriptive source tree entry is not executable source.

The paper needs a complete original corpus/export, 13-condition biological registry and alias provenance, semantic panel artifacts/contracts, exact source and export recipes, environments and the missing supplements. The source closure retains all missing roles. The neural path additionally needs native clocks, endpoint support, original source/export and biological lineage, training-only model provenance, registered reference families and complete comparison support. Paper/neural export views refer to one physical source family; new paths/digests do not create independent animals.

## Existing owner API, still gated

central.adapters.original_paper_boundary forwards unchanged to paper/runtime/controller.original_run_unit_boundary. Its parameters are:

```text
lib, run, program_sha256, unit_manifest, budget, deadlines,
source_commit, recover_all, private_factory, scorer, admission,
support_precommit=None
```

The trusted lib must supply the existing ten-argument run_unit protocol. The source commitment binds program bytes, full public inputs and scope before release. admission must come from an independently qualified full-programme owner; it is not candidate output. The boundary requires all producer resources absent, an independent three-resource producer/holder/volume absence report, original commit bytes and exact captured output. Only after those checks does it call private_factory and the unchanged scorer. Improvement also binds pre-prediction support. Old 38-mouse slice receipts cannot satisfy a new full-scope identity.

paper/runtime/native.execute_with_original_owner similarly requires a closed source/environment/exporter recipe and an owner implementing assert_execution_authorized, assert_qualified_full_programme and run_sealed_original_recipe. It does not supply that owner or authenticate a caller's assertions independently. Native collection verifies exact original source and output identities, full panel/model support and semantic provenance. Missing recipes cannot be replaced by an invented simulation.

central.adapters.Numerical and the original neural Workflow retain full commit/stage/produce/close/grade/interpret stages. The bundled producer is explicitly engineering-only and never establishes hostile isolation. The central dispatcher still refuses fitting; merely supplying a fitted artifact or editing synthetic/admission flags does not provide an authentic execution route.

## Resource and readiness boundary

The generated controller observes logical I/O, deadlines and retained files, with per-child limits. It does not establish aggregate process-tree memory, physical disk I/O, adversarial isolation, escaped-descendant closure or authentic native runtime qualification. An external owner must qualify those separately and use current storage/compute booking. No paid/model/native campaign is authorized by this source package. All scientific/submission qualification remains false; prior historical receipts are not transferred to relocated bytes.
