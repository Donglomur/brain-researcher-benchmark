# Frozen prospective ABR references

Status: concrete recipes for later implementation and independent review. No authentic fit, prediction or accuracy has been obtained. These choices do not modify the endpoint, labels, nested folds, cutoff or scorer. They are not a claim that a simple classifier establishes scientific adequacy by itself.

## Matched tabular waveform and layout reference pair

Use the identical deterministic fitting procedure in both routes. NumPy 2.2.6, SciPy 1.15.3 and scikit-learn 1.6.1 under Python 3.12.8 are the prospective numerical environment. Float64 feature arithmetic, single-thread limits and random_state=0 are fixed. Fit each outer fold from a new process and empty storage. No fitted object or learned vocabulary crosses folds.

In each inner training split, learn the ordered numeric-level vocabulary independently for each of the nine predeclared stimulus names. Create one bucket for every observed numeric level plus one unknown-level bucket per stimulus. Do not use validation/test layouts to enlarge this vocabulary. Retain every record and repeat. At transform time map unseen levels to that stimulus's unknown bucket. No source/animal/record identity is a feature. The same procedure is refit on the complete outer training set after C is chosen.

Layout features for every bucket are record count; means and population standard deviations of numeric level, sample count and repeat index; plus bucket-present indicator. Empty buckets have zero summaries and absent indicator. Include total records and per-stimulus record counts. Every record contributes exactly once, including repeated levels. Sample indices are used only for sample count, not sample amplitude.

Waveform features start with those exact layout features. For each record with N sample values, partition its integer sample positions into 32 bins by floor(32*j/N), for j=0..N-1. Each sample contributes to exactly one bin. For each bin compute its numerical mean and root-mean-square, with zero and an explicit absent indicator for empty bins. Also compute whole-record mean, population standard deviation, minimum, maximum and RMS. These use raw released numerical values; no physical voltage/time calibration or per-record amplitude normalization is asserted. Within each learned stimulus-level bucket, take means and population standard deviations of every resulting record feature across all records, keeping repeats. Empty bucket features are zero. This is deterministic feature compression, not removal of records from the input packet.

For each feature, learn mean and population standard deviation on the current training animals only. Replace a zero training standard deviation with one. Standardize validation/test animals with those stored values. Any nonfinite transformed feature is a hard reference failure, not silently imputed. Record convergence warnings and fail rather than accepting a nonconverged fit.

Fit LogisticRegression(penalty="l2", solver="liblinear", C=C, class_weight="balanced", fit_intercept=True, intercept_scaling=1.0, tol=1e-6, max_iter=10000, random_state=0). Evaluate C in [0.01, 0.1, 1, 10, 100] on the frozen four inner folds. Pool their validation predictions across every outer-training animal and maximize balanced accuracy using only those training labels and cutoff 0.5. This inner measure has its own observed class denominators, not the final scorer's fixed 50/54 denominators. Break exact ties by smaller C. Do not retune C from outer-fold outcomes. Refit the full preprocessing/classifier on all outer-training animals at the selected C and output predict_proba for class 1 on every outer-test animal. No additional probability calibration is fitted in this recipe.

Both methods get the same runtime, current fold, inner splits, class-weight rule, C grid, training-only transforms and resource limits. A candidate using waveform data may improve on this waveform recipe but must retain the separately frozen layout comparator; the paired final score cannot be obtained from an omitted or easier layout route. A constant empirical outer-training class prior is an additional negative reference, not a substitute for the layout classifier.

## Controls and competence requirements before qualification

The source controls include a full-104 privileged scoring oracle, its inverted predictions, a constant-probability paired baseline, incomplete outputs, duplicate/wrong-fold/bool/nonfinite predictions, private-label and source-ID injection, reused context IDs, altered inputs/methods and uncertain cleanup. The privileged oracle is evaluator-only invented test data; it is not a participant method and has no scientific accuracy interpretation.

Before an authentic reference campaign, implement the above two programs as frozen single-file inputs, independently review their exact feature/tuning boundary, and run invented known-signal/layout-confound examples within the accepted native runtime. The waveform positive control should depend on numerical samples with identical layout across classes. A separate layout-confound positive should depend only on layout. Permuted training labels provide a failure diagnostic with fixed permutation seed and no repeated selection from test feedback; no universal finite-sample chance bound is asserted. Both controlled tasks are validation of the methods, not extra benchmark IDs.

A time-series alternative (for example a separately specified ROCKET-family reference) remains a competence investigation, not an unspecified executed baseline. It must define ragged-record handling, complete animal aggregation, training-only tuning, runtime and independent review before comparison. The tabular pair alone must not be advertised as the best achievable reference. Improvement over a fixed reference is not automatically frontier research.
