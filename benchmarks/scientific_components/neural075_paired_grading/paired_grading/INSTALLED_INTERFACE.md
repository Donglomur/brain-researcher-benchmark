This directory adds source inspection and a trusted-host caller around the exact accepted four-module paired grader. The six accepted files are byte-identical to source commit `8f1c65894fc9a3d699e7376d7474617bac310111`; the original unscored adapter, registration, canonical and qualification flags are unchanged. ## Source-only inspection

The portable command is:

```text
python -I -S -B operator.py inspect --source-bytes <selected manifest size> --source-sha256 <selected manifest SHA256> --read-bytes <positive selected limit> --write-bytes <positive selected limit> --seconds <positive selected duration>
```

Every operand is explicit. The source read minimum is the sum of `(bytes + 1)` for all nine inventory members, including SOURCE_MANIFEST.json. The parent installation map records the exact measured minimum after this package is frozen; the API inspection also returns `minimum_loader_read_bytes`. The CLI additionally requires at least 32,768 write bytes for its single bounded JSON serialization/output. Those are source-transport bounds, not an inferred CPU/RAM/native/scientific profile. No production duration is supplied by this package.

`inspect(source_pin, budget)` returns a Python metadata object without serializing it. Its caller must account for any later serialization; the CLI accounts for its own output in the same budget. Inspection validates the complete nine-file ordinary inventory and its selected manifest. It does not compile the four modules, import NumPy, read any of the 18 external dependency bodies, or open a producer, prepared design, target, programme, receipt, signal or reference. Dependency names/counts come from the unchanged declared source metadata, not fresh data validation. Success says source integrity only.

## Import and namespace boundary

The filename `operator.py` deliberately is an entry script, not an import name. Never import it as stdlib `operator` and never add this directory to `sys.path`. Use an isolated interpreter for the CLI. A trusted Python caller should load the externally authenticated file under a unique module name through its existing source loader, without changing search paths.

Captured modules execute only under the fixed aliases `closed_pair`, `paired_contrasts`, `pinned_scorer` and `_neural075_installed_paired_grade`. Each module is registered before execution so dataclass resolution works. Every prior alias object, including a prior None value or an absent entry, is restored in `finally` after success, partial initialization, authority refusal or downstream failure. No ambient authoring import path is installed and no existing module is reused as the task implementation.

Use a dedicated trusted, serialized operator process with no background grading work. The lock covers loading and the entire synchronous grade call through this one operator instance; it does not synchronize unrelated importers or other instances in the same process. This is trusted-host composition, not a sandbox against arbitrary host Python. Deadline checks are cooperative, not a hard process timer. Source capture is a stable-read sequence rather than an atomic filesystem snapshot.
