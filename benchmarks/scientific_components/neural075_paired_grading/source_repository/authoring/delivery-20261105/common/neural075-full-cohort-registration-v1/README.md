# NEURAL075 complete-pair campaign registration

This is an additive, uninstalled source proposal for the existing NEURAL075
task. Both the default program route and the named `complete_pair` route mean
the entire paired A/B controller: five people, three matched scientific arms,
two phases, 30 original cases per access and 60 isolated invocations. There is
no A-only, B-only, participant subset or cropped-input route. Registration
does not add a task or transfer qualification from another program.

The common campaign `--program` operand is an ordinary, root-selected JSON
**pair descriptor**, not a Python candidate file. Its `programs` map names the
two independently authored program files by absolute path, bytes and SHA256.
Its `commitments` map names the already frozen directories and exact original
`COMMIT.json` pins used by the existing full-cohort controller. Each program
path must be exactly its corresponding directory's `program.py`. The two
directories are distinct; program contents may coincide after independent
authorship. Both commitments must precede any query staging.

The common campaign currently represents one context for a canonical task. It
does not establish independent authorship under two exposure conditions. A
separate root attestation is therefore mandatory. It binds both program and
commitment maps, the exact pair file, controller and adapter sources, and the
existing source-defined material policy. The two arm records must have distinct
context IDs and distinct provenance-content pins. Hashes alone do not prove
access histories: root must independently verify provenance before issuing the
attestation. Provenance bodies are not read by this adapter.

Access A is `task_citation_and_data`. Access B is
`task_citation_data_and_author_code`, adding only the four selected author
files. The existing public specification, data and generic reference source
remain matched. No full article is supplied. Prior model knowledge and public
development exposure are not controlled. Current authoring must have no query
payload before program commitment and no case feedback before global
commitment. Neither generic single-context exposure assessment nor two labels
on one authoring session establishes this paired condition.

`adapter.py` captures its exact source, the complete existing controller
source, root review, selection, paired context attestation, runtime prerequisite
receipts, pair descriptor and original commit metadata. It opens no program
source, data, key, gold or provenance body in this preflight. The trusted
complete controller opens the frozen programs only after all preflight joins
pass. Runtime receipts must describe the exact controller/adapter, fixed image
and NumPy 2.2.6/h5py 3.13.0 requirements; the existing runtime's version guards
remain active. Runtime receipts are root-authority records, not signatures or
substitutes for independently observed native qualification.

The adapter calls the existing complete controller directly. Its captured
`panel.py` receives exactly two source-checked clock changes: initialize the
whole-panel origin from the adapter's entry time, and arm only the time
remaining to that original endpoint. An exact reverse delta restores the
original bytes. All cohort, lifecycle, staging, output, metric and resource
logic is unchanged. The controller source on disk is not modified. Preflight
has a 60-second allowance within the same whole clock, not a new runtime lease.
An independent outer observer must still include interpreter startup and the
final natural-zero process exit.

All 60 positive candidate/resource/host closures precede either final 30-file
collection. The output contains two original-format submission collections and
their exact context indexes. This route is explicitly **unscored**: no private
evaluator is authorized or called. A future independent scoring operation must
authenticate the full completed A/B root and preserve the original grader's
full-30 admission-before-gold behavior. There is no partial-result promotion.

## Proposed common interface

The proposed manifest belongs at
`benchmarks/neuroscience/neural-075/manifest.json`; it remains in this proposal's
`proposed/` tree. Its default `program_execution` and named `complete_pair`
alias point to the same adapter with the existing hardened Python prefix and
whole-token `{program}`, `{output}`, `{review}` and `{other_reserve_bytes}`
substitutions. The existing campaign API can transport a pinned pair file; its
generic single-program LLM authoring workflow cannot create a qualified pair.

`PAIR.template.json`, `SELECTION.template.json`, `REVIEW.template.json`,
`ROOT_PAIR_ATTESTATION.template.json` and `RUNTIME.template.json` describe the
future root-owned operands. Templates are disabled and are not approvals.
The review is passed through the campaign's existing repository-confined
`--review` slot. Root must independently select/pin that review; file hashes
do not identify its author. The source preference and runtime qualification
gates remain separate from this metadata interface.

The exact cached metadata baseline is V10: 200 canonical IDs and 57 runtime
registrations, with no NEURAL075 runtime or preferred interface. Previous V9
capture remains under `history/`, including its read/write charges. Source
tests reuse compact actual metadata rather than rereading all 200 delivery
specifications. Root must rejoin current state before installation or adding
this source interface to a later preference receipt. No installed registry,
WORK, PLAN, source preference, canonical specification or Git state is edited.

The proposed qualification status is `not_run`. Real default and named command
builders must refuse before touching the candidate/pair operand. Tests may
stub qualification only to inspect argument compatibility; such a stub is
never accepted as actual runtime evidence. `QUALIFICATION_SOURCE_FREEZE.json`
lists the exact source closure for a future independent qualification. It
contains no imported success from source controls, prior runtimes or scorers.

## Resources and interpretation

The controller retains its 2 GB host reservation, 20 GiB physical floor plus
other reservations, full 200 MB case allowance, and explicit 200 GB read/32 GB
write phase ceilings. Source-derived nonrefundable reservations remain 126 GB
reads and 17.32 GB writes, not measured traffic or physical IO throttles.
Adapter pre/postflight adds at most 750,000 reserved metadata-read bytes and
no runtime artifact writes; stdout is bounded by the small completion record.
Capturing controller source in preflight is included in this adapter cap.
The controller's own later source reauthentication remains in its original
phase reservation. No candidate tmpfs traffic or peak RSS claim is introduced.

The original scientific endpoint and limitations remain unchanged: same-person
instructed-category transfer from public processed fMRI, equal-person 50-way
imagery trial Top1 with exact tie splitting, five biological participants,
perception diagnostic and matched controls. This is not raw BOLD understanding,
causal cue-free imagery, imagined-photograph truth, new-person generalization,
an exact 2017 paper replay or a SOTA result. Methodological compliance still
requires scientific review. No authentic arrays, private key, targets,
candidate, model, native container or scorer was accessed/run in this build.
