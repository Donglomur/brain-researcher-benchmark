## Ordinary checkout checks

Use Python 3.11. Jaxley's small invented schedule/ranking/schema check requires
NumPy; CI pins NumPy 2.4.6 to make the current arithmetic environment explicit.
From this repository root:

```sh
(cd benchmarks/scientific_components/jaxley_allen_selector && python3 -I -B check_portable.py)
python3 -I -S -B benchmarks/scientific_components/marble_fit_closed/test_portability.py
```

The first command checks four source/helper behaviors without fitting or simulation.
The second runs six standard-library checks, including the real inspect branch and
missing-operand/native-source refusals. It prohibits numerical imports and network or
subprocess use within those checks. Both use ordinary readable checkout permissions.
Neither executes a scientific campaign, reads authentic neural data or grants native
execution authority. Passing CI is source evidence, not a reproduction, improvement,
SOTA or submission-readiness result. The existing [scientific contracts](../scientific_contracts/README.md)
are indexed separately; no task registration or qualified-study count changes here.
