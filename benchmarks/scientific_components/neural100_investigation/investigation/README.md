# NEURAL-100: complete numerical investigation and scientific claims

This is an **inactive source component for the existing NEURAL-100 assignment**. It adds an actual two-artifact candidate interface and a guarded numerical-and-claims grading transition. The existing support-only programme, its authorization flags, installed task registration, central admission and all qualification holds remain unchanged. This source is neither another benchmark nor a completed scientific study.

The historical programme emits one `report.json`, validates support only and leaves numerical grading as a disabled future handoff. This separate condition commits one programme before any public signal view, obtains exactly `report.json` and `claims.json`, closes the candidate resources, captures both stopped outputs, retires its public view and admits the complete pair before constructing the private grade phase. A well-formed but scientifically wrong claim is graded; malformed or incomplete artifacts are refused before private reference access.

## Candidate interface and complete scope

The new candidate entry executes the same frozen programme once:

```
python -I -B /submission/program.py --input /input \
  --output-report /output/report.json --output-claims /output/claims.json
```

`report.json` uses the **unchanged** original strict numerical report contract. `claims.json` uses the fully specified [claims contract](package/CLAIMS_CONTRACT.md). These are separate files, not an unvalidated prose attachment or extra fields silently inserted into the old report. The stopped output directory may contain exactly those two regular, single-link files: report at most 64,000,000 bytes, claims at most 1,000,000 bytes, total at most 65,000,000 bytes. The existing 67,108,864-byte tmpfs output profile is retained. No candidate stdout/log output is accepted as a result.

Preserve the complete released cortical-click cohort: 47 recordings, 41 mice, 39 A1 and eight A2 recordings, and all eight jointly reported conditions. The numerical input/public view remains all 54 public members, including all 47 primitive inputs; no recording or condition is selected for a favorable result. The source roster is an independently pinned operator input, not a population verified by synthetic fixtures. The programme receives the entire declared public analysis input; this investigation is not held-out animal prediction.

The original numeric core is copied exactly and remains unchanged: counts occupy 100 half-open 1-ms bins in [−50,50) ms; primary baseline is [−50,−5), sample SD uses ddof=1, and the first **strictly** greater-than-mean-plus-three-SD run lasting at least 2 ms in [1,50) defines onset. Zero SD, no eligible units and absent crossing remain undefined. Even zero-based trials are evaluation; odd trials alone support development SNR/contact matching. No data-driven tuning or condition selection is introduced.

The eight conditions remain `primary`, `threshold_2_5`, `threshold_3_5`, `bins_2ms`, `boundary_erosion_one_depth`, `baseline_pseudo_onset`, `development_snr_bin_contact_matched` and `first_spike_median_descriptive`. The six population-detector variants have a different interpretation from the pre-stimulus pseudo-onset and conditional first-spike summaries. Claims must preserve that distinction.

Repeats are averaged within mouse/area, then mice equally. An undefined repeat makes that mouse undefined; any undefined mouse withholds the full-area estimate. Observed-only results remain separately identified. The exact source PCG64 seed 100043 and 1,000 shared whole-mouse bootstrap draws are unchanged, including missingness propagation and no redraw to eliminate undefined support. No effect direction, significance threshold or success cutoff is invented.
