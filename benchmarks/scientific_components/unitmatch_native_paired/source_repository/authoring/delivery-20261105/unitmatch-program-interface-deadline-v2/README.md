# UnitMatch five-mouse program interface: public source profile

This is the ordinary source dependency of the paired UnitMatch comparison.
It preserves five complete held-mouse jobs, both access views, program sealing,
complete probability matrices, functional development/withholding, source and
receipt identities, resource declarations, and cleanup/absence barriers.

The strict original producer deadline is unchanged: a successful producer wait
must complete with `time.monotonic() - start < 20` before capture, validation or
commit. Equality and later completion refuse through the existing cleanup path.
The bounded CLI also checks its own deadline after wait and stream closure.
These are contract statements, not new observed control or scientific results.

Public profile `unitmatch_native_paired_public_local_socket_v1` replaces the
legacy engine's personal default with fixed `unix:///var/run/docker.sock` and
removes ambient Docker context/TLS overrides from that default. The actual paired
transport still dispatches through its overriding BoundEngine.run with the trusted
runner's explicit local Unix-socket environment and binary. Candidate programs do
not select those host operands. No Docker call or scientific execution follows
from importing or inspecting source.

`SOURCE_MANIFEST.json` is the live exact source identity. `SOURCE_ORIGIN.json`
describes the historical deadline predecessor and must not be substituted for
this profile's current pins. `CHECKS.json` is a declarative public check scope;
original tool outcomes are excluded. `test_deadlines.py` is retained source,
not a recorded result or a requirement to replay the old campaign.

The [public package guide](../../../../README.md) provides the normal-checkout
source check. A future actual run still requires external authentic complete
packet/cohort, exact executable and source identities, trusted serialized host,
separately qualified runtime and an enclosing natural-exit observer. Source
packaging grants no execution authority or benchmark/readiness promotion.
