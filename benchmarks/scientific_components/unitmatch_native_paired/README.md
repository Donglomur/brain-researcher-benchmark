# UnitMatch: native reference and paired five-mouse source

This package contains the substantive comparison implementation: the fixed caller,
MATLAB producer and complete pair-table capture, both existing five-fold candidate
executors, original scorer and decoder, separate arithmetic reference bank,
target-last grading and full paired report. It supports the existing
`PAPER-paper-method-007` assignment. It adds no benchmark and supplies no measured
scientific result or native runtime qualification.

The selected scope is five mice, two recordings per mouse, 1,264 good units and
complete directed matrices of sizes 534, 109, 96, 59 and 466. There are 526,890
entries per method, including both directions and diagonals, and ten A/B candidate
outputs. Native plus A and B covers 1,580,670 entries. This is a functional-proxy
comparison, not the full sixteen-mouse paper or true neuron-identity accuracy.

The caller and scientific source are under `installed/`; its complete 24-member
ordinary dependency tree is mirrored under `source_repository/` with original
relative locators. Those locators can contain `private` because they identify
ordinary scorer source. No authentic target arrays, cohort, packet map, official
native source corpus, private control outcomes or registration catalogue is
included. External operands remain required and source presence cannot authorize
a run.

## Ordinary checkout commands

Use Python 3.11 from this repository root. Both commands use the standard library
and require no dependency installation:

```sh
python3 -I -S -B benchmarks/scientific_components/unitmatch_native_paired/installed/run_native_paired.py source-check --repository benchmarks/scientific_components/unitmatch_native_paired/source_repository
python3 -I -S -B benchmarks/scientific_components/unitmatch_native_paired/test_portability.py
```

The first command reaches the actual caller and source loader, authenticating and
loading the seven owned source bodies and 24 ordinary dependencies. It opens no
scientific input. The second checks the complete ordinary source inventory and
permissions, real source inspection, bad-pin refusal, required missing packet
refusal, fixed local engine configuration using an inert process leaf, and the
live runner manifest. Numerical/native imports, network and real subprocess use
are prohibited inside those tests. A passing source check is not a scientific
study, improvement result, full native environment or execution grant.

## Public package profile and unchanged science

The explicit profile is `unitmatch_native_paired_public_local_socket_v1`. It is a
successor to the installed source profile, not a claim that every byte still has
the old source identity. The legacy engine default now names fixed
`unix:///var/run/docker.sock` and excludes ambient Docker context/TLS overrides.
That socket is neither opened nor assumed to exist during source inspection.
The actual paired transport continues to override `Engine.run` with
`BoundEngine.run`, using the trusted runner's explicit local Unix-socket
environment and selected binary. Candidate programs do not select host endpoints.

All affected manifest, dependency, caller and API pins identify the actual new
public bodies. The study and installed caller differ only in those source-pin
assignments; every scientific function and numerical body remains unchanged.
Public documentation and provenance omit private construction history, and the
old control-outcome metadata is replaced by a declarative check scope. The private
installed condition and its historical identities are preserved outside this
package. `SOURCE_ORIGIN.json` in the dependency mirror is explicitly historical;
the live `SOURCE_MANIFEST.json` and `SOURCE_BINDING.json` govern this profile.

## Full comparison and external requirements

Both methods and policies freeze before any execution. The source owns native
MATLAB production, all ten candidate outputs, linked method/input/source receipts,
cleanup/absence evidence and complete output admission. The private functional
grade happens only after native and both full arms close. Other-four-mice
functional development support remains an explicit privilege; target-last does
not mean that all development functional information is hidden.

The separate arithmetic bank checks histogram ownership/mass, directed centered
correlations, deterministic matching and finite-class tie-aware AUC. Shared raw
inputs and identity metadata limit that independence: computational agreement
does not prove biological provenance. All five mice must be eligible for a proxy
improvement declaration; decoded yield and finite matched-direction support
cannot fall. B-minus-A is descriptive across five mice, with no neuron-pooled
significance or causal code-access claim. See the full
[scientific contract and limitations](installed/native-paired/README.md) and
[mathematical contract](installed/native-paired/MATH_CONTRACT_V1.md).

Authentic full-scope cohort/packet/assets, original official code, real licensed
MATLAB and applicable toolboxes, genuine Python/Docker/MATLAB executable pins,
complete runtime/transitive-source/resource admission, protected boundaries and
an enclosing natural-exit observer remain external requirements. The selected
official v2.0 snapshot is `6ef0023cb4a7be0a94dabbab24bb79c084b6fb1e`; it is not
automatically equivalent to the paper-era v1 or another historical source pin.
Unfilled policy/limit templates refuse. No fake native provider, supplied baseline
file, target substitute, row truncation or reduced scientific scope is introduced.

The two candidate arms alone declare 80 GB controlled reads, 26 GB writes and
6 GB retained capacity in aggregate, before native staging, grading and headroom.
Those are conservative source declarations, not measured current requirements or
available resources. Source inspection does not demonstrate numerical/native
parity, license entitlement, effective hostile-host isolation or sufficient
whole-study storage. Public-data and prior model exposure remain interpretation
