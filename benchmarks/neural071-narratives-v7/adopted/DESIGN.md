## Questions and interventions

Q1: On held families, how accurately does each agent predict the full 400-parcel response, relative to independently trained Rmean, R0 and R2 references?
Q2: Under the same model/provider, tool catalogue, source material, resource ceilings and case/arm support, what is the paired difference between a frozen program F and interactive investigator I?
Q3: Does supplying real rather than all-zero training responses alter prediction quality? This is an information-use sanity check. It cannot establish neural specificity, causal understanding or native LLM comprehension.
Q4: How do independently trained temporal, acoustic, static lexical and contextual feature configurations compare? These are predictive attribution controls, not a causal or unique-information decomposition.
Q5: Does the documented analysis respect current-fit train-only selection, historical method-prior provenance, timing, dependency and uncertainty limits? Scientific interpretation is reported separately from numerical prediction.

## F/I matched chronology

The old global-source-before-any-view policy is preserved as historical source, but superseded for this proposed experiment only by A01. F's author sees the case's allowed training view and public method/tool contracts; query feature values are unavailable to the author. The author may inspect training data, write arbitrary allowed code, and run train-only validation. Its complete program and analysis declaration are sealed. A new isolated process executes that frozen arbitrary program on the same training and then query features, with no continuing author-model calls. It may contain general query diagnostics or adapt transductive X-only transformations if declared; none may touch query Y.

I receives the same training view plus this case's query features during authoring. It can iterate within the same aggregate allowance, then seals its final program/state/prediction and analysis declaration. The distinction is author access to query features and when adaptation is chosen; F still has full program freedom. Both modes use the same qualified libraries and fixed feature products. Neither can access the private final reference bank or outer-score feedback. Public reference method source may be inspected; candidate-run fits are their own separately charged operations. A service exposing hidden reference target predictions is not selected.

There is no context, file, cache, optimizer state or model-memory reuse across cases, arms, response conditions or modes. A held family's responses can legitimately be another case's training data, so this isolation is essential. Paired execution order is deterministic by opaque context IDs, not by observed accuracy. Each independent provider request needs the original request/response receipt and resource attribution. No unauthenticated model service or paid run is authorized now.

A single preregistered provider/model version and decoding profile must be adopted before execution. Fixed numerical methods here require no random selection. Candidate stochastic operations must declare their source-owned seeds and actual state; no repeated seed search after outer scoring. Provider nondeterminism is reported; one episode is not an estimate of provider variance. Extra replication would require another pre-score amendment, not selective retries.

## Investigation and limits

Before predictions are sealed, each episode must submit a machine-readable declaration: hypotheses; expected direction or explicit uncertainty; chosen training-only analyses; support/split provenance; inspected tool outputs; model-selection rule; feature and timing assumptions; limitations and intended falsifiers. Claims that require query targets must remain conditional. Failed analyses, discarded training configurations and their costs stay in the transcript.

The final operator produces a fixed full-family report with all numerical outcomes, pre-score claims and discrepancies. Scientific interpretation is not graded merely by eloquence or reference similarity. Two independent blinded reviewers and adjudication may annotate factual/methodological validity under the exact rubric in METRICS_REPORT.md; their actual receipts and disagreements are required for an adjudicated interpretation outcome. Prediction can be reported without pretending this human-review outcome is complete. Reviewers receive no agent/provider labels until ratings freeze.

The inference is retrospective within-listener family generalization using already cleaned whole-run BOLD, not prospective online neurophysiology or causal manipulation. A large contextual model may encode timing, lexical frequency, acoustics or memorized text. Fixed controls reduce some alternatives but cannot isolate native LLM neural understanding or guarantee absence of pretraining contamination. No new current-evaluation-response tuning of lag, atlas, parcel mask, layer, pooling rule, hyperparameter grid or success threshold is allowed. The historically response-selected layer-eight prior remains explicit; the current freeze does not erase its earlier Narratives selection.

The layer-eight extractor is a historical Narratives-response-selected feature prior: Caucheteux et al. selected it using brain-prediction comparisons on 101 listeners, seven stories and 237 subject-story pairs from the same public corpus. The exact overlap with the current 171 listeners/486 cases is UNKNOWN. Current outer/inner transforms, coefficients and alpha/gamma selection use their fitting support only; this locality does not establish independence of the earlier global layer choice. Results are exploratory public-corpus evaluation with a disclosed shared-corpus prior, without an untouched-test or globally independent layer-selection claim. METHOD_PRIOR.json supplies the mandatory identity and disclosure.

Every pre-score declaration names METHOD_PRIOR.json and CLOCK_CONVENTIONS.json, distinguishes local estimation from global method design, and acknowledges the exploratory public-corpus scope. ZERO withholds present-case Y but retains the historical prior. No additional independently selected arm, new layer search or untouched cohort is selected.
