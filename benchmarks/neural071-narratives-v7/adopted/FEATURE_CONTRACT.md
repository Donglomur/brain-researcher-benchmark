# Feature, source and clock contract (prospective A02–A04)

## Immutable geometry and trusted preparation

The trusted preparer must join raw release, derivative version, exact bytes, scan/person/family/variant, hemisphere, atlas, source method and clock records. It reads authentic BOLD and creates protected target products, so target-last refers to agent/scorer access, not a fiction that preparation never touched responses. All real preparation reads/costs require future authorization.

Keep 40,962 vertices per hemisphere, exactly 200 nonempty positive atlas labels per hemisphere plus background, and all 400 parcels. Same-open authenticated decoding; no external GIfTI file references, symlink aliases or caller-generated atlas-name-only claims. Parcel response is the prescribed average of all fixed vertices; finite values are required. No target-dependent parcel mask, quality censor, fill, outlier clipping or dimensional drop.

Each scan has a qualified first-sample scanner origin, native TR (including 1.52), audio-at-scanner-zero and exact audio/variant/Gentle clock. BIDS story onset is not added twice. Native sample indices satisfy t−6−TR−16 ≥ story_start and t+12 < story_stop, with t=first_sample+i*TR, and at least 20 rows per segment. Segments never bridge story boundaries. Feature windows for lags 1.5,3,4.5,6 seconds are [t−lag−TR,t−lag), translated once to audio time. Include current words by start_window ≤ word.end < end_window. Missing alignments remain counted, never imputed or used to remove response rows. Future source qualification must establish the complete ordered segment/run/family map before any score.

Primitive features use exact source ordering. Outputs are finite C-order little-endian float32, while extraction/fit arithmetic is float64 except GPT-2 inference's proposed float32. Source identity, dtype, all rounding rules and original producer receipts are bound. Feature products computed once per identical source/clock/recipe may be shared operator-side; their creation costs are recorded once and every consumer joins that same identity. This does not authorize cross-case fitted-state sharing.

## Legacy feature path, preserved

For each lag the existing 8 waveform summaries are followed by word rate, mean normalized-word length and within-story elapsed time (t-story_start)/3600, where t=first_sample_scanner_seconds+i*TR and story_start uses the same qualified scanner clock. Then come 64 current-word signed hashes and 64 prior-16-second unigram/bigram hashes. Hashing, interval boundaries and normalization remain exactly stimulus.py/protocol.py. Training word log-frequency is fitted anew from fitting-support lag-word occurrences, including repeated occurrences across windows; denominator is total+vocabulary_size+1. Validation/query words never enter counts. Four lags produce 48/304/560 features for NUISANCE/LEXICAL/CONTEXT. R0 uses only these legacy features.

## Strong blocks, explicit new feature recipe

For each lag define current words exactly as above. Empty normalized tokens are excluded; normalization is original lowercase/non-[a-z'] removal. Current word rate is count/TR, mean length is sum lengths/max(1,count), and log frequency is the same fit-local occurrence recipe. These three plus within-story elapsed time (t-story_start)/3600, with t=first_sample_scanner_seconds+i*TR on the same qualified scanner clock as story_start, bounded relative story progress (t−story_start)/(story_stop−story_start), and six onset ramps min(max(t−story_start,0)/tau,1) for tau=3,6,12,24,48,96 seconds form T: 11 features/lag, 44 total. Complete segment duration is offline known metadata, not an online information claim. No story ID or response-derived timing feature is included.

A has 72 features/lag, 288 total: the exact eight legacy acoustic summaries plus 64 fixed log-mel summaries. Define mono PCM by the existing stereo mean and full-scale conversion. Native rate must be at least 16 kHz. Frames have N=floor(0.020*rate) samples with start floor(k*0.010*rate), k≥0 in audio-global coordinates. Only frames wholly contained in the lag window contribute. At least one frame per window is required. Use a symmetric Hann h[n]=0.5−0.5cos(2*pi*n/(N−1)); FFT length is smallest power of two ≥N; divide one-sided power by sum(h²), double interior positive-frequency bins, and retain DC/Nyquist once. Sixty-four triangular filters have 66 equally spaced HTK-mel edges from 50 Hz to min(8000,rate/2), mel(f)=2595log10(1+f/700), inverse accordingly. Each filter's weighted spectral power is divided by its sum of discrete nonnegative bin weights; zero weight sum fails. Average each filter power over contained frames, then log1p. No learned normalization, peak alignment, phonemes, F0 estimator or unknown pretrained speech model is hidden in this control. This is a defined prospective acoustic control, not a claim to remove every acoustic/phonological confound.

L has 768 features/lag, 3,072 total. For each current word tokenize the exact string ' '+normalized_word through the pinned slow GPT2 byte-BPE with add_prefix_space=False, no special tokens and no generation. Mean that word's token embedding-table vectors (wte only, without position embeddings or blocks), then average words in the lag window. No words means exact zeros. This historical static lexical representation is a proposed comparator, not an original Narratives implementation.

C also has 768 features/lag, 3,072 total. For each current word at end time e, create a fresh text sequence consisting of previous normalized words whose ends are in [e−16,e), in original stable order, followed by this word; words sharing e precede the current word only when earlier in stable source order, and no later word is included. The complete string is one space before every word, no special tokens. Require 1..1024 BPE tokens; overflow is an explicit unsupported-input failure, never silent truncation or segmentation. Run exact frozen GPT2Model in eval/no-grad, float32, use_cache=False, output_hidden_states=True, eager causal attention, explicit positions 0..n−1. Take hidden_states[8] at the current word's last token. Mean these vectors over the lag's current words; no current words means exact zeros. No future words or other segments enter a context; cut prior history at this story segment's start. Word-end inclusion remains the legacy temporal convention. All static/contextual pooling is mean, not a test-selected mean/sum/last comparison.

The semantic context convention differs from legacy prior-window hashed history, which remains unchanged and is separately named. Layer/context/pooling are frozen before this generation exposes held-case responses. Layer eight nevertheless carries the historical shared-corpus response-selected prior in METHOD_PRIOR.json; this freeze is not global selection independence. No model fine-tuning occurs in this feature extractor. Body pins for tokenizer and weights remain an open qualification gate; metadata pins alone cannot produce an admitted feature bank.

NUISANCE strong support=T+A (332 columns); LEXICAL=T+A+L (3,404); CONTEXT=T+A+L+C (6,476). For each arm F/I receive identical legacy and strong feature products; source-reference R2 gets exactly the same scientific blocks, clocks, rows and train-response support. Rtemp gets T only; Racoustic gets A only. No R2-only information privilege is allowed. Features containing fit-local frequency are computed by a source-owned training transform with an explicit FIT→state→TRANSFORM interface, including inner folds. All other primitive extraction performs no new response-dependent numerical fitting; the inherited response-selected layer prior remains separately disclosed.

## Fitting transforms and leakage controls

Legacy R0 uses training-only weighted centering/scaling and unwhitened 16-PC SVD, exact old rank guard s16>s0*1e−10, no lower-rank rescue. New R2/Rtemp/Racoustic use full group widths after weighted centering/scaling; they do not apply PCA. This explicit choice avoids treating a 16-PC bottleneck as a strong language reference. Dimension-matching does not imply nested information or equal effective capacity.

For every inner/outer fitting support, recompute occurrence counts, X mean, X standard deviation and kernel normalization only from that fitting support. Constant X columns get scale 1. Validation/query X never changes these states in source references. Model states bind ordered rows/weights/groups and all finite parameters. The arbitrary participant may use a declared X-only transductive method within its allowed view, but its outputs are labeled as such and cannot be described as the fixed reference recipe.

A single source clock or full-bank admission failure prevents the complete result; do not silently remove the two scrambled variants, 17 atypical-TR scans, constant feature groups or unfavorable parcels.

The layer-eight extractor is a historical Narratives-response-selected feature prior: Caucheteux et al. selected it using brain-prediction comparisons on 101 listeners, seven stories and 237 subject-story pairs from the same public corpus. The exact overlap with the current 171 listeners/486 cases is UNKNOWN. Current outer/inner transforms, coefficients and alpha/gamma selection use their fitting support only; this locality does not establish independence of the earlier global layer choice. Results are exploratory public-corpus evaluation with a disclosed shared-corpus prior, without an untouched-test or globally independent layer-selection claim. METHOD_PRIOR.json supplies the mandatory identity and disclosure.

CLOCK_CONVENTIONS.json binds both legacy and strong T elapsed time. The same scalar (t-story_start)/3600 is repeated in each lag block, exactly as the legacy source; t is the current sample time, not a lag-window endpoint. Other windows, ramps, origins and units are unchanged. Every feature-bank manifest binds both design identities, direct C consumption where applicable, exact clocks and original receipts.
