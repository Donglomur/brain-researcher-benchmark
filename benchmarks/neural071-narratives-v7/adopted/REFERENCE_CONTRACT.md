## Proposed full-feature group-regularized reference

R2 has groups [T,A], [T,A,L], [T,A,L,C] for the three arms. Rtemp and Racoustic have [T] and [A]. For each fitting support compute positive weights w summing 1, muY, each X group's weighted mean/SD (SD≤1e−12→1), and Z=(X−muX)/SD. Compute t_j=sum_i w_i*sum_d Z_j[i,d]^2. If t_j=0, K_j is exactly zero; otherwise K_j=Z_j Z_j'/t_j. Query cross-kernel uses the fit means/SD, same t_j and exact stored training Z. Do not compute the trace or any selection statistic on validation/query X.

For m>1 the ordered finite gamma list is: uniform; each of m one-hot vertices in group order; each of m vectors with one group weighted 4 and all others 1, normalized to sum 1. For m=1 the deduplicated list is [1]. Every gamma is paired with alpha in [0.0001,0.01,1,100,10000], gamma-major/alpha-minor order. Config counts are 25,35,45 for the three R2 arms, and 5 each for Rtemp/Racoustic: 115 configs per inner fold across all five references. Zero-weight/zero-trace groups remain explicit; no implicit equalization or sample omission.

Construct unweighted K=sum_j gamma_j K_j. Proposed actual source call is pinned Himalaya KernelRidge(kernel='precomputed', alpha=alpha, fit_intercept=False, solver='eigenvalues', solver_params={'method':'svd'}, force_cpu=True), using NumPy float64 backend, fit(K_owned_copy, Y−muY, sample_weight=w). The pinned implementation applies sqrt weights internally and returns the weighted dual; caller must not preweight K or Y again. INFER computes unweighted K_query @ dual_coef + muY. This deterministic finite-grid route is an adaptation of group-regularized regression, not the paper's random-search algorithm.

The exact numerical environment and solver-parameter compatibility require future source review and execution qualification; no module has been imported here. Require finite matrices/states/predictions, symmetric PSD construction, and solve residual ||(sqrt(W)Ksqrt(W)+alpha I)a−sqrt(W)(Y−muY)||_F / max(1,||sqrt(W)(Y−muY)||_F) ≤1e−8, with a reconstructed from stored weighted dual by dividing each row by sqrt(w). All output casts must remain finite. Failure blocks this reference; no undocumented alternate solver, precision relaxation, diagonal jitter or alpha enlargement.

## Train-only inner selection and exact expansion

Let f_c be the number of distinct outer-training families for case c, determined from authorized private metadata before features/responses. If f_c≥2, k_c=min(3,f_c). Sort training families by SHA256 of canonical JSON ['N071-inner-family-v1', case_opaque_id, family_opaque_id], tie-break by family opaque ID, then assign cyclically to k_c buckets. Each family is validation exactly once; complete family/run/segment memberships are indivisible. For each fold, refit occurrence frequencies, scaling, trace and model from the remaining whole families only. No outer-fit transform or outcome-tuned splitting.

For each of 115 configurations per fold compute all validation predictions and retain all 400 per-parcel outcomes. Selection minimizes out-of-fold per-parcel MSE using equal family→run→segment→sample weighting over the complete out-of-fold union. Do not average uneven folds equally. Exact ties choose earlier configuration. This is current-training-only coefficient/transform/alpha/gamma selection. No current test responses choose a new layer, lag, pooling or source; it does not establish historical independence of layer eight.

If f_c=1, select uniform gamma and alpha=1 prospectively with zero inner folds. This branch is based solely on family count. It is not equivalent to validated generalization and must be reported separately. Never switch to this branch after a failed fold. f_c=0 contradicts eligibility and blocks census admission.

After selection, recompute all transforms on complete outer training support and actually fit selected configurations to obtain all 400 columns. Group columns by selected configuration, record every physical solve and its column mapping, and serialize the final complete state. At most 115 distinct selected-configuration solves per case across the five new references, at least five. Logical final state count is five, not necessarily physical solve count. Legacy R0 contributes three solves and Rmean one mean computation per case.

K=sum_c k_c is not known in this phase; 0≤K≤1458. There are exactly 115K nested logical config fits (≤167,670), with all fold-specific state publications and predictions required. Source-owned expansion must join actual f_c and full private mapping before execution. Three inner folds do not authorize an arbitrary subset of families or rows. Query-target scoring never changes any selected configuration. Reference competence is a prospective method claim only: training diagnostics, numerical controls and a different review must establish faithful execution; favorable outer scores are not an admission criterion.
