# Narratives071: public benchmark construction source

This package contains the complete first-party Narratives071 implementation and its scientific/API contracts. It is **construction source, not a scientifically qualified or submission-ready benchmark**. All 32 qualification gates remain open.

The task is retrospective, within-listener prediction for held-out story families. It compares frozen-program and case-investigation access, three feature arms, and REAL/ZERO response settings against nine source-owned references. The full plan retains 345 people and 873 scans, 171 eligible listeners, 572 eligible scans, 486 cases, 400 parcels, 5,832 candidate and 4,374 reference contexts, 57 contrasts and 171 metric rows. These contexts are not separate benchmarks.

`entry.preparation`, `entry.reference`, and `entry.complete` are Python call interfaces for a separately qualified trusted launcher. This package provides no enabled scientific command, installed environment, dataset, model weights, credentials or qualification record. Missing qualified operator inputs must stop execution; there is no local uncontained fallback.

The original design documents retain their exact construction-stage wording, including historical proposal-status fields. Their inclusion records the selected method contracts and their provenance; those fields do not supply current execution authority. Engineering source acceptance does not close any scientific gate.

## Important interpretation limits

Layer eight was selected historically using Narratives brain responses. Exact overlap with the present cohort is unknown. Current fit-local estimation does not make that prior globally independent. REAL-minus-ZERO is an information-access check, not evidence that an LLM understands raw neural signals or that a result uses an untouched test set. GPT-2 is a historical reference, not a claim of current SOTA.

Numerical agreement, authentic input and model identities, source/data rights, complete native isolation and cost observation, resource feasibility, independent reference competence and protected evaluation remain unqualified. The final-path blocking-open boundary also remains unqualified.

The [public manifest](PUBLIC_SOURCE_MANIFEST.json) binds this source snapshot. It is a fresh public identity. Qualification, runtime receipts and results from another source identity do not transfer to it.
