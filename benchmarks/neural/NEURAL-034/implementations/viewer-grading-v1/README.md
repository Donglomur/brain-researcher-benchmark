# Protected grading of a closed combined-view collection

This additive owner connects the original seven-fold viewer collection to the
unchanged protected numerical scorer. It freezes the complete 140 probabilities,
starts a new trusted grading controller with the original process owner, stops
and reaps that controller, and performs the original grader recovery. It never
creates a programme, fold-programme commits, or programme execution history.

The original combined viewer remains unchanged: seven selected, historically
exposed mice; 120 labeled training windows and 20 queries per held mouse;
calcium and behavior visible together. Equal-mouse balanced accuracy and log
loss, all six fixed references, labels, query order and source limitations are
unchanged. This is viewer-mediated interpretation, not a no-tools condition.
The package does not measure neural contribution, provider image delivery or
model performance merely by scoring an already collected prediction file.

## Two explicit collection provenance routes

`retained_20261117` accepts only the exact previously accepted fixed-0.5
collection: public receipt `8a2a848d…`, independent saved review `5304764e…`,
and 9,419-byte submission `c55e9f94…`. Full hashes are in `run.RETAINED`.
The receipt identifies executed source `557488918361fbe19aa24ce7ec7236dc7f8bc9b2`.
This route does not reopen packets, images, wire transcripts or historical
process identifiers. It does not replay `audit_transport` or recheck old PIDs.

`separately_admitted_closed_collection` accepts a future original combined
collection only after a separately pinned root acceptance of its closed
collector, exact submission, transport receipt, independent review,
source/client/condition bindings and execution identity. The new grading root
admission must pin that authority. A caller-written `complete_unscored` JSON
alone is insufficient. The acceptance schema is validated by
`closed_authority`; its shape is not a signature or independent execution proof.
Root and the operator must control admitted metadata and output directories.
Fresh collection acquisition, participant/provider boundaries and independent
acceptance happen outside this grading owner.

Both routes consume the exact captured submission bytes and require all 140
original ordered pairs, finite nonboolean probabilities and ordinary single-link
files. `submission.json` is created with `O_EXCL|O_NOFOLLOW`, explicitly set to
0444 on the owned descriptor and fsynced. The captured pin is revalidated before
grading and again when inspecting results. The original host scorer hashes
private assets when dispatched; private-target decoding remains inside its
protected worker. No claim of zero private-byte reads is made at that point.

## Result and failure boundaries

`controller.py` joins the actual new owner token, child argv, PID and process
group before private grading. It writes a grade intent and one result. The
outer owner waits for the original bootstrap's natural child-completion record,
stops and reaps only that owned group, then calls `recover_grade`. A killed
bootstrap's return code is not confused with the actual controller return code.
Timeouts, malformed output and unresolved cleanup retain failure records.

`check_result.py` checks the submitted snapshot, exact new controller completion,
grader invocation, immutable ID/name cleanup, seven mouse means and original
six-reference arithmetic. It uses the existing pure comparison helper, not the
old programme-history checker. Its result is consistency of trusted saved
records; it is not independent live containment or scientific attestation.
Successful CLI execution additionally requires `checked-result.json`; a
preliminary `outer-result.json` status without that check is insufficient.

Construction tests use generated probabilities, metadata and a tiny local
original-owner fixture. They do not load authentic arrays, render data, call
Docker, decode private targets, score a scientific candidate or test a provider.
The actual standalone viewer-to-protected-grade run remains a separately
reviewed and admitted protocol after this source is accepted.
