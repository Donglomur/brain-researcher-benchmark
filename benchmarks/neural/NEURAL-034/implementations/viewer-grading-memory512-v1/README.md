# Protected grading of a closed NEURAL-034 viewer collection

This entrypoint freezes all 140 ordered probabilities from an independently
accepted, closed seven-fold combined calcium/behavior viewer collection and
grades that snapshot with the unchanged protected scorer and six reference
streams. It creates a new grading owner; it does not invent a programme
lifecycle, rerender the viewer, or probe historical participant processes.

The protected profile uses 512 MiB RAM and RAM+swap ceilings, two CPUs and two
worker threads. The host request is a separate 2 GiB cooperative envelope.
Original offline, read-only mounts, process ownership, cleanup, 7/8.5-second
worker timing and numerical behavior are preserved. The older 4 GiB
container/6 GiB host proposal and HOLD remain historical and unchanged.

## What was exercised

One separately admitted fixed-control operation completed on 2026-11-18 using
the exact six Python files distributed here, with the archived executed
SOURCE.json and README. All 140 probabilities were 0.5: equal-mouse balanced
accuracy was 0.5 and log loss was 0.6931471805599453. The six reference
calculations agreed. This tests collection-to-protected-grader construction,
not an AI participant, neural understanding, improvement or scientific validity.

Kernel cgroup-v2 memory.peak was 23,609,344 bytes through the saved post-grader
read cutoff; it does not cover the entire later container lifetime. OOM
counters/deltas were zero, terminal exit was zero and OOMKilled was false.
Both cleanup receipts and new owner/controller closure were verified from saved
records. Host pressure level was 2 at both observations and Pageouts increased
by 69; these are not healthy-host, stable-pressure or measured-2-GiB-usage claims.
The full 95-second attempt allowance was retained in accounting.

See [the compact receipt](../../docs/memory512-control-20261118/RECEIPT.json).
The public SOURCE.json and this README are a metadata-only portability
successor. Their new hashes were not the executed descriptor hashes; no root
qualification or execution authority transfers. All general qualification
flags remain false. The selected exposed seven-mouse development panel and

authoring/neural034-viewer-grading-memory512-v1/ within it. Source admission
must pin the current package descriptor and every member/dependency, and supply

submission, protected assets, runtime eligibility and a fresh output location.

    python3 -I -B /ABSOLUTE_CONFIGURED_ROOT/authoring/neural034-viewer-grading-memory512-v1/run.py \
      --review /ABSOLUTE_REVIEW.json --review-sha256 EXACT_REVIEW_SHA256

This is the owned grading entrypoint, not an admission command. Root/operator
resource admission and a bounded 90-second watchdog plus 5-second kill grace
must surround the full preparation/owner lifecycle, with preparation <=30 s
and owner <=60 s fitting that remaining deadline. The private machine-specific
preparation driver and root descriptors from the fixed run are not distributed
as a generic deployment tool. Merely editing a review or setting a boolean
cannot qualify an installation.

Both grade and post-owner recovery select the same pinned memory overlay.
Telemetry invokes the unchanged grader and records original stdout plus framed
stderr. Unsupported counters remain unknown; RSS, Docker samples and exit137
