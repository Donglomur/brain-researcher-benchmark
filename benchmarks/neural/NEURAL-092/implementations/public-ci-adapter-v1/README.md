# NEURAL-092 public CI evidence adapter

This adapter executes the existing six inactive public source/import/CLI controls. It does not run a neural model, read authentic neural data, issue a Selection, qualify the native host, or replay numerical primitive controls.

The maintained parallel runner supplies an absent `${ARTIFACT_DIR}` outside the checkout. The adapter exclusively creates that ordinary directory with mode0700, authenticates all69 frozen runtime/check files (429930bytes), then invokes the original checks/test_public_contract.py under the same existing isolated POSIX interpreter with -I -S -B. It omits --runtime-root, retaining installed-parent discovery. The original operator verifies its source descriptors and39-module/50-role graph; exact69 source identities are rechecked after the child returns or fails.

RAW_REPORT.json retains the original dynamic interpreter, python_version, platform, and all six real control statuses. STDOUT.json and STDERR.txt retain the actual child streams. ADAPTER_RECEIPT.json records selected runtime provenance, argv, available exit/error/source-guard evidence, and the raw report hash on success. Partial or missing reports remain failure evidence; absence never becomes a pass. External termination can leave no final adapter receipt, which must not be inferred as completion.

Only after zero child exit, empty stderr, exact stdout/report equality, strict JSON parsing, actual runtime provenance equality, exact ordered six statuses and unchanged scope flags does stdout emit a deterministic projection of that actual report. The existing json-controls runner validates this projection exactly. This is six actual controls, not a synthetic unittest count. The enclosing runner retains the artifact-directory pointer in success and failure records.

Retained child stdout+stderr is bounded to16384bytes combined; raw report and adapter receipt each have8192byte bounds. The original suite writes one59byte shadow-package fixture. The adapter permits120seconds for its child; the public row permits150seconds. The enclosing trusted job owns the inherited process group, timeout and descendant cleanup. The adapter does not establish an OS memory limit or a native/scientific execution boundary. A terminated child may leave partial artifacts. Before/after source checks are trusted-CI stability checks, not protection against adversarial same-user replacement.

Public selector: `${PYTHON} -I -S -B benchmarks/neural/NEURAL-092/implementations/public-ci-adapter-v1/ci_adapter.py --artifact-root ${ARTIFACT_DIR}` from repository root.
