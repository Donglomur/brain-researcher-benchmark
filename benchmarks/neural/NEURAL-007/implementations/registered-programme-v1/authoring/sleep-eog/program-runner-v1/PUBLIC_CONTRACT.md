# Whole-night sleep: submitted program, feature condition

This is the existing NEURAL-007 development task: predict W, N1, N2, N3, R for every full 30-second epoch of each of two people. It is an offline, whole-recording task; temporal smoothing may use the active person's complete recording. It is not a causal/online prediction task. No raw signals or investigator workflow are claimed here.

Submit one ordinary UTF-8 Python file, at most 200,000 bytes. The operator freezes its bytes before releasing any evaluation case. Each invocation is `python -I /program/program.py --input /input --out /output`. Write exactly one ordinary single-link `/output/predictions.npz`, at most 400,000 bytes. The same frozen program runs independently for development-001 (2,780 epochs) and development-002 (2,670 epochs). Each invocation has a fresh process, scratch directory and output volume. There is no cross-case mutable state. Training or calibration may be recomputed from the same public training files inside each invocation; there is no uncharged preprocessing stage or separately supplied fitted artifact in this version.

Both invocations receive the identical six training cases (16,290 full epochs): `/training/features/train-NNN_features.npz`, `/training/labels/train-NNN_labels.npz`, and `/training/model/train-NNN.npz`. They also receive `/training/tools/cache_core.py` and `cache_io.py`. The exact current case manifest is `/input/case.json`; only its features `/input/features.npz` and common-model cache `/input/model.npz` are exposed. The public validation helper `/input/public_validation.py` is optional. No other evaluation person, development label/mask, prior prediction, raw recording, private scorer file, or reserved person is mounted. Public training masks are allowed. All binds are individual readonly files, never parent folders.

Feature NPZ keys: `epoch_id` (canonical case/00000... Unicode IDs), `epoch_start_seconds` (0,30,...), `clock_features` (N,3: elapsed hours, wall-clock sine, wall-clock cosine), `signal_features` (N,3,6), `channels`, `feature_names`, scalar `sample_rate_hz=100`, scalar `epoch_seconds=30`. Channels: EEG Fpz-Cz, EEG Pz-Oz, EOG horizontal. Features: delta/theta/alpha/sigma/beta mean-relative PSD, then log variance in volts squared. Feature values are finite float64; there is no label-derived sleep crop.

Training label keys: `epoch_id`, integer `stage`, boolean `score_mask`. Stage -1 denotes unscored/unknown/movement, otherwise 0..4 in the fixed class order. `score_mask == (stage >= 0)`. Preserve the complete clock and identity when joining labels, features and model caches.

Model cache keys: `epoch_id`, `class_order`, `component_order`, `component_probabilities` (N,4,5 float64). Components are Fpz_EEG, Pz_EEG, Fpz_EEG_EOG, Pz_EEG_EOG. Optional helper views are those four, EEG_ensemble, EEG_EOG_ensemble, and Fpz_EEG_EOG_anchor. These are fixed previously computed YASA outputs. Your final prediction need not be a fixed view, convex mixture, or YASA output.

Each prediction archive must be an uncompressed ZIP_STORED NPZ with exactly three members: `class_order` (Unicode W,N1,N2,N3,R); `<case>__epoch_id` (all canonical IDs in original order); `<case>__probabilities` (N,5 float32 or float64). No object/structured arrays, duplicate/extra entries, encryption or compression. Probabilities must be finite in [0,1], with absolute row-sum error <=1e-6, summed in float64. No clipping/renormalization is performed. Exact argmax ties select the first class. Full-clock predictions are required before the private scoring mask is applied.

The primary continuous metric is the equal-person mean of each person's fixed-five-class macro-F1. A class with zero truth and prediction support contributes zero. Also report confusion matrices, class support/recall, supported-class balanced accuracy, and candidate-minus-YASA and candidate-minus-RF differences. Valid weak/constant/null-improvement predictions remain valid scores. Invalid artifacts have null score; operator errors are separate. There is no binary scientific-success threshold. Two development people cannot support a population-level superiority claim.

Per person: maximum 20 seconds candidate work (additionally bounded by the operator's remaining whole-stage deadline), 3 GiB RAM including swap limit, 1.75 CPU, two numeric threads, 64 PIDs, 64 MiB scratch, 8 MiB output tmpfs, 1 MiB file-size ulimit, no network, nonroot readonly image. Training computation consumes this same allowance on each case. The common holder and trusted grader are charged separately to the same outer allocation. Feedback is returned only after both outputs are frozen and all producers/holders/output volumes have been removed.

This enforces the local execution boundary. It does not establish blind method selection: these development cases and descriptive results have already been used during benchmark development. Agent/model trials, matched investigator access/budgets, raw-condition training delivery, stronger held-out evaluation, and statistical study design remain separate scientific gates.
