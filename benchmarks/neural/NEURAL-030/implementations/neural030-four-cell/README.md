## Source verification and generated controls

Use an ordinary POSIX directory, outside any input/output/data directory, with a trusted Python interpreter. The flat SOURCE_MANIFEST.json closes every28 required authored/source-document member. From this directory:

```sh
python -I -B package.py manifest-pin
python -I -B package.py check --source-bytes N --source-sha256 SHA256
python -I -B package.py inspect --source-bytes N --source-sha256 SHA256
```

Replace N and SHA256 with the independent release/commit's selected SOURCE_MANIFEST.json pin. `manifest-pin` displays the local candidate pin and explicitly does not authenticate its origin. Comparing only against a digest computed from the same untrusted checkout establishes local consistency, not independent authenticity. The packaging mapping/selector supplied to the maintainer carries the exact release pins.
