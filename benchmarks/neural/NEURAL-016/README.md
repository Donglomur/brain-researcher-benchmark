## Current neural-understanding objective

The full-minus-nuisance held-out neural prediction contrast on identical scalar response rows; negative, zero or inconclusive increments are valid empirical outcomes.

**Source delivery:** partial\_delivery. The paired held-out neural-response evaluator is delivered and distinguishes EV from R². It verifies declared prediction/fit IDs, not actual fitting or clinical electrode correspondence; native preparation and a competent fixed nuisance/full reference remain missing.
