# Complete historical forecasting programme

This component restores candidate execution and a portable connection to the
existing NEURAL-018 numerical grader. The accepted task previously shipped an
artifact scorer whose host launcher retained old workspace and Docker paths.
The new route freezes one submitted Python file, exposes exactly the three
historical public operands, captures its output only after producer removal,
and invokes the unchanged numerical worker and core in a separate trusted
container. Source construction and generated controls do not qualify the native
environment or establish a model result. Canonical registration is unchanged.

The complete endpoint is 1,721 training trials and 574 development queries from
one exposed Jenkins session. Queries contain 137 held-in units over
[-250,450) ms and the originally allowed trial condition context. Predictions
cover all 182 units over forty 5 ms bins in [450,650) ms. The source is the
historical preprocessed packet, not the separate `causal-packet-v1` projection.
No raw NWB preparation, new fingerprint, causal preprocessing certification,
online spike-sorting claim, independent animal or new hidden set is introduced.

The public files already provisioned by the operator total 138,824,524 bytes:
`past.npz`, `training_future.npz`, and `public_manifest.json`. Their exact
identities come from the unchanged `../registered-runtime/scoring-v2/assets.json`.
The programme receives all training and query context together and may fit and
select a procedure within the original whole-training-trial policy. Any
unsupervised query adaptation must be declared. Process isolation cannot prove
the method's scientific fitting provenance. No query targets, raw NWB, saved
predictions, reference reports or operator code are participant mounts.

Submit one ordinary Python file, at most 200,000 bytes. It runs as:

```sh
python -I -B /program/program.py --input /input --out /output
```

Write only `/output/predictions.npz`, at most **34 MiB**. The unchanged scorer
requires `expected_counts` (574,40,182), complete `trial_ids`, `forecast_unit_ids`,
`bin_left_edges_ms`, `prediction_units`, and `panel_fingerprint`. Rates must be
finite and strictly positive. All original identity and unit constraints apply.
The 34 MiB limit is deliberate: valid Unicode64 identities can push a complete
float64 archive above 32 MiB. No subset, lower precision or silent ID truncation
is substituted to make transport easier.

The scorer keeps joint forward bits/spike and **all five** signed comparisons:
global rate, condition/time, past activity plus condition, pooled condition and
selected ridge. The last two are outcome-informed development references.
Neither beating a weak reference nor producing a valid archive establishes
SOTA, incremental neural information, scientific success or native understanding.
Negative gains and the zero-target-spike undefined result remain valid outcomes.
