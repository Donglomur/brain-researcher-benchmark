# Complete prospective N061 evaluation design

## Status and decision

The original construction is useful source work but its agent factorial is not a defensible default allocation. The different whole peer retains N061-W01 (P1: unallocated prospective factorial) and N061-W02 (P2: partial-seed competence). This packet proposes a coherent decision; it neither repairs frozen source nor claims W01 is fully closed by smaller integer counts. Actual operation/resource/capacity admission remains unimplemented.

The recommended primary scientific question is unchanged: on the same held-animal target windows, does a selected region improve predictive information relative to an equally sized, probe/rate/QC-matched non-region population, given the same background? The primary replacement effect is loss(BC)−loss(BR). BR and BC each contain2k units and share B; R/C/B triples are disjoint and matched without outcomes. It is a conditional observational predictive contrast, not necessity, causal neural coding or a rank ordering of all regions.

The primary signal estimator stays evaluator-owned reference / signed wheel velocity / k10 / real anatomy / replacement across every earlier Beryl grey-matter region. The primary agent slice uses exactly those head/budget/anatomy/matching axes and BR/BC. It does not claim to reproduce the published TS1 aggregate or execute the full nine-head programme. The full original scientific sensitivity catalogue remains separately registered and reportable.

## Recommended staged selection

**Q0: source/runtime and capacity qualification.** There is no benchmark result at this stage. Implement and independently review the missing same-open input/projection, native launcher, safe state/tool transport, panel leases, provider broker, full operation observers, outside completion and late-target binding. Use separately authorized source/development calibration and genuine resource measurements, not hidden evaluation-target feedback. Source-visible fit counts do not qualify this stage.

**S0: complete primary reference audit.** Run the selected independent reference on signed velocity/k10/real anatomy with all six original arms, all ten seeds, all regions and all evaluation animals. This preserves the original all-arm reference completeness policy and supplies B/R/C/ZERO diagnostic comparisons alongside the primary matched BR/BC effect. Full-eligibility work is1,860R fits (six configurations ×five source folds plus final fit, per arm/seed/region) and1,740R evaluation-session predictions. Source standardization and source-animal model selection remain unchanged. The primary inferential family is still R reference replacement effects, not six timesR new primary claims. This stage can produce a scientific reference study only after all input/native/scientific gates are satisfied.

**A0: minimal full-support agent evaluation, recommended first model tier.** Add one global source-only F author context using T0 and one predeclared repeat. Seal the source before any evaluation query view. Fit/infer that source separately for every primary region/seed/BR-or-BC arm, preserving all29 evaluation sessions and13 animals. Full eligibility gives20R fits and580R session predictions. The global source author context may contain many model calls and many tokens; one context is not a one-call or cheap-work claim. This tier tests frozen programme construction, prediction competence and precommitted scientific claims. It does not test case-local I adaptation or a tool effect.

**A1: paired full-support F/I evaluation.** Add exactly one I panel with the same chosen T0/repeat policy and original inputs, reference availability and whole-panel resource ceiling. An I context is isolated by animal ×region ×matching seed ×arm (plus the fixed head/budget/anatomy/tool/repeat identity). It sees only the current animal's permitted sessions for that exact cell/arm. There are260R I author contexts and fits; with F,280R fits and1,160R session predictions. This is the recommended complete F/I scientific comparison if an actual bounded deployment can support it. It is not automatically affordable and cannot be activated by this design.

A0 versus A1 must be selected before evaluation outcomes or protected-target grading. If A0 is intentionally published as an F-only study, a later I extension must be a new prospectively registered evaluation with prior exposure disclosed. Do not inspect F performance and then decide which regions, seed or I arm to add. Partial executions retain costs and all expected failure/unstarted rows; they are not completed lower-tier studies by default.

**A2: targeted trained-tool comparison, optional.** Add the second tool policy T1 with one repeat only when the question is whether the fixed same-cell/arm trained reference helps. The paired F/I T0+T1 design has two global F contexts,520R I contexts,560R candidate fits and2,320R session predictions. Reference states are already evaluator-produced, but actual tool transport/queries/state lifetimes and repeated reads are additional charged work. This is a selected2×2 mode/tool design, not the original12-panel default.

**A3: stochastic method-authoring replication, optional.** The original T0/T1×three-repeat design on primary scientific axes has six F contexts,1,560R I contexts,1,680R candidate fits and6,960R session predictions. Repeats measure realized programme/agent variability; they do not increase animal n. Repeat/model identifiers, selection, transcript/cost accounting and aggregation require pre-outcome selection. A repeat is not a retry of a failed original context. This tier remains optional even if S0 is complete.

The practical recommendation is Q0→S0→A0, with A1 selected only when a full operation and capacity plan supports it. This preserves the primary support while avoiding a default54-fold head/budget/anatomy expansion, threefold extra-arm expansion and sixfold agent tool/repeat expansion. It does not promise that S0 or A0 fits any particular machine, dollar amount or deadline.

That is540R cells and3,240R arm-specific references; at full eligibility the source makes100,440R fit calls and93,960R evaluation-session prediction groups, in addition to source CV prediction and preparation/capture work.

A full scientific-sensitivity-completion claim requires all selected audit waves and all original required null/QC/competence qualifications. Reducing agent factors does not erase these reference costs or declare the full original programme complete.

All unlike head losses remain separate. Anatomy shuffle remains a diagnostic rather than a calibrated exchangeability test; a genuine temporal-null producer remains missing. Continuous-quality and residual-rate balance assessment stays required. The current two model families share pooled mean/variance features and need authentic competence checks. A stronger independent source-trained set/sequence reference is a prospective optional methodological addition, with exact same allowed units/windows, five source-animal folds and a separately selected cost/identity contract. No donor fitted state, extra query input or arbitrary larger architecture is adopted here.

## Explicit lower-cost alternative that changes the estimand

A one-seed agent pilot could fix one seed before outcomes and matching availability, while retaining allregions and all13 animals. One paired F/I setting would have one F context,26R I contexts,28R fits and116R evaluation-session predictions. This is a contribution estimate conditional on one sampled matched population. It loses ten-seed Monte Carlo averaging and cannot be called the primary ten-seed agent estimator.

If selected, its candidate/reference competence and F/I comparison must use that exact one seed on both sides, with its own complete support and explicitly secondary family. The ten-seed reference science may remain mandatory, but it cannot be presented as ten-seed agent evidence. Choosing a favorable or more available seed, resampling until complete, or pooling ten seed queries to obtain these counts is prohibited. This option is not the recommendation for the full primary agent claim.

## What the agent comparisons mean

F versus I combines frozen programme construction with case-local unlabeled query access/adaptation. It does not isolate abstract reasoning ability. T0 versus T1 concerns task-trained reference access; T0 still permits code, fitting and data analysis. None of these tiers establishes native signal understanding without tools.

The user's literal no-tools question remains a separate explicit design decision. It requires a fixed admissible representation/encoding of each original neural window, full target/support equivalence, context/token feasibility and a source-closed response format. A representation change or shortened window may change the task. This packet does not choose an unspecified encoding or call T0 a no-tools condition. The code-enabled benchmark can proceed through its own design gates while that interface study is designed separately.

A larger positive regional difference is not automatically a better agent score: an agent could inflate it by degrading BC. Report signed BR and BC prediction losses and paired reference competence, the reference-defined regional science, and separately scored precommitted claims. No target-informed narrative rewrite or rewarding a predetermined positive effect is permitted. Free-text reasoning still needs the blinded rubric and cannot be certified by numerical agreement alone.

No tier changes the canonical benchmark count. Readouts, arms, regions, tool settings and repeats remain conditions inside NEURAL-061.
