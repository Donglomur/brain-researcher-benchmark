# Capability and resource contract for the proposed tiers

## Query information boundaries

An I author context owns exactly one (model/policy/tool/repeat,animal,head,region,k,seed,realization,arm) identity. It can receive only the physically projected source training views and the permitted unlabeled query views for that same cell/arm/current animal. The original source permits the current animal's several sessions; this is the declared I context, not cross-animal pooling. Each session/window uses only its selected arm's units. Private labels, raw original biological identifiers, target-derived hashes and other neural views remain inaccessible.

The following shortcuts are invalid:
- pooling ten seed query views into one context, then writing ten methods;
- a single region context that sees BR and BC;
- combining regions whose control/background units differ;
- persisting query-visible conversational memory, hidden files, fitted state or a mutable tool worker into another isolated context;
- passing all-unit spikes plus a mask instruction;
- copying outputs or using a method generated after such a union and labelling them isolated predictions.

The unit union across seeds can exceed2k. A reset of a fit object after shared authorship cannot erase prior query information. No batching API or matching source digest closes this information boundary. Batch submission may transport **independent** contexts under identical original isolation, but it does not reduce their author-context count.

F authorship is global source-only per tool/repeat, before any evaluation view. Its frozen code is fitted separately by scientific cell/arm. Source-only immutable preparation and reference artifacts may be reused only with exact original data/support/assignment/transform/fold/objective/source/environment/state lineage and all repeated reads and storage accounted. Current preparation already reuses identical matching assignments across readout heads; that saving is not a reason to reuse different numerical fits or give I extra query views.

T1 is only the same-cell/same-arm source-trained reference. No pooled cross-arm/region/seed query worker, private target access, precomputed query answer table or pickled host capability is allowed. Safe state transfer/persistent reference lifetime is still missing source work.

## Symbolic accounting, not measured cost

Let R be the full predeclared atlas region count; A=13 evaluation animals; E=29 evaluation sessions; H=9 heads; K=3 unit budgets; S=10 matching seeds; U=2 anatomy realizations; M=6 arms; P=tool-policies×method-repeats. The original code hasP=6 and two modesF/I.

The cell count isC=R·H·K·S·U. For an audit with m selected reference arms, each cell/arm has6 configurations×5 source folds+1 final fit=31 fit calls. Reference final evaluation groups areC·m·E, with30·C·m additional source-fold validation prediction calls. Window/timestamp counts, actual arrays, selected model family, optimizer work, model-state size and captured bytes are not supplied by these expressions.

Candidate F author contexts=P, F fits=P·C·m; I contexts and I fits=P·A·C·m; combined F/I evaluation-session prediction groups=2·P·C·m·E. These count host interface opportunities, not underlying LLM calls, tokens, dollars, optimizer iterations, CPU seconds or scientific tasks. A host.author context can invoke multiple generations/tools. A candidate fit can contain substantial optimization inside its bounded child. A session prediction contains all required windows and target positions. Publication, observation and cleanup are extra required work, not free.

All counts are full-eligibility opportunities. Scientific-unavailable cells may suppress effects while retaining their original dispositions. There is no universally attained minimum cost and no permission to rely on hoped-for missing regions to call the plan affordable. R and actual support remain unknown. No sample R is substituted into a claimed machine or money estimate.

TIERS_AND_COSTS.json provides exact coefficient identities from the current source. The complete original reference audit is already shared across candidate panels; do not divide its cost by agent factors twice or recalculate it as a free artifact. Amortized and unamortized reports must coexist.

## Required capacity decision before effects

A concrete future source-owned OperationPlan must bind:
1. the full earlier source/atlas/region/session/animal/matching roster and selected tier/families;
2. every preparation, reference CV/refit/predict, F/I author/fit/predict, source/tool state lease, capture/serialize/readback, report and independent cleanup/observation operation;
3. actual authenticated maximum input/output/state/temporary extents, copies and retained buffer lifetimes, plus method/model/API invocation bounds;
4. original monotonic clocks, separately allocated preparation/reference/panel/observer/grading owners, actual resource counters and native enforcement;
5. the whole study budget, each F/I panel's equal total ceiling, and a finite pre-effect partition across that panel's contexts, with sufficient independently held cleanup/report tails;
6. provider identity/account/call/token/spending limits, native dependency/model identities, safe primitive state/transport and final outside completion;
7. once-only failed and partial attempts, retained returned-prefix costs, active holds and unknowns. No retry/reset/new owner is an implicit capacity extension.

Equal whole-panel F/I ceilings remain the original fairness policy. Hundreds of I contexts cannot each receive a fresh copy of F's entire allowance. Conversely, an arbitrary tiny per-I slice that cannot execute the selected programme does not establish a fair comparison. The actual per-operation plan and capacity qualification must demonstrate feasibility before admission. This design chooses no fake token/dollar/runtime constant.

Qualification may use later explicitly selected source/development controls for actual measurements. It may not expose evaluation targets, select favorable biological support or adapt the study's claims to observed test performance. A measured bound for one source operation is not proof of whole-campaign fit without the complete inverse. If the chosen plan does not fit, decline that tier before evaluation and explicitly select another prospectively reviewed design; do not silently truncate an in-progress tier.

All authenticated primary/model/header data access, provider spending, scientific execution and native qualification remain separate future selections. This document performs none.
