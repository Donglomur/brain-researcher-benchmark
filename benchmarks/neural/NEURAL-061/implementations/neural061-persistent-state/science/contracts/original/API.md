# Source API and complete producer graph

No function here converts a source digest into live authority. A trusted parent must supply an earlier real bound host session, original resource owner and qualified same-open input captures. This source phase does not implement that parent or claim an executable deployment.

1. `contracts.cohort` validates the closed 452-session role census; `contracts.catalogue` expands every selected region through nine heads, three budgets, ten seeds and two anatomy realizations. The earlier native input producer proves the actual roster and ordered ontology. Metadata validation alone is insufficient.
2. `preparation.prepare(originals, cohort_rows, ontology, owner, opaque)` consumes every original while its captured descriptor is live. `joined_units` checks actual raw session/subject, probe, unit and spike-index joins and computes training-only rate support. `project_windows` constructs every head's actual original sampler windows and full target/mask inverse. Original capture, preprocessed arrays, readbacks and failures remain charged under the same preparation owner. Public and private outputs are separated before publication.
3. Public prepared records have opaque animal/session/query/unit identities, stable source ordinals, source-only folds, exact neural arrays and masks, labeled source windows, and physically selected assignments. Original unit/probe identifiers, target values for evaluation, original trial joins and rate/quality balance stay private. An independent projection observer compares the public bytes with the original source-owned construction. Public identity aliases do not establish ownership.
4. `reference.complete_reference` runs all five source-animal folds and all six configurations for each arm, selects only on source animals, refits, then predicts all evaluation sessions. `models.fit/predict/loss` are actual numerical implementations. They were neither imported nor executed during construction. Each model state and source selection graph must be retained by the trusted native reference owner. A safe primitive serialization or original persistent reference-worker lease must be implemented before T1 deployment; a pickled host object or completed answer callback is prohibited.
5. `production.collect` expands all twelve panels, gives F one global source-only authoring context and I separate animal/cell/arm contexts, and calls actual `host.author`, `host.fit`, and `host.predict` operations. I never sees another arm's query values during authorship. Each operation returns a captured original outcome object. `observe_operation(kind,request,outcome,owner)` independently joins the exact request, complete mounts, method identity, fit state, full return and original terminal/resource evidence. A user-supplied object implementing matching method names is not a bound host session.
6. `worker.load_method` is restricted to `/participant/method.py` inside the previously isolated native child. Candidate `fit({task,source,tool})` returns a safe primitive model state; candidate `infer({task,query,tool},state)` returns one `{query,values}` row for every original query. Child serialization must reject arbitrary objects, pickle, object arrays, callbacks and path-bearing state; this serialization and native bootstrap are unimplemented gates. The trusted host never imports participant source.
7. Whole production publication includes all candidate/reference outputs or prespecified unavailable dispositions, complete source/fit/tool transcripts, actual native child receipts and original owner costs. Natural zero exit, complete stdout/stderr EOF, reap and process/container absence must be established independently. The producer cannot certify the outside completion of its own process. Partial results remain partial, with the original failure and unresolved cleanup status.
8. A later independent selection grants `grading.score` target access only after `late_host.require_closed_production` binds the actual earlier outer completion to the complete immutable output graph. It first checks every expected output key. Only then does `capture_targets` open the exact protected targets. The grading owner is a distinct original scope, not a reset of production. `report.verify_claims` consumes the precommitted candidate report and the recomputed evidence; target-informed revisions are not accepted.

The host entry has no arbitrary Python module/factory selector in public JSON. Root must select a concrete immutable implementation of the launcher, broker, native worker bootstrap, primitive state transport, projection observer and outside completion consumer. These implementation obligations are listed in `NATIVE_CONTRACT.md` and remain open. No central CLI, registration or preference migration is included.

All payload extents, job counts, memory reservations, source captures and aggregate cost ceilings must be fixed for the actual full catalogue before launch. No prefix truncation, reduced region list, shortened neural window or smaller cohort is an implicit fallback. A planned scientific-unavailable cell remains in all expected output and multiplicity rosters. A failed operation does not become such a cell.
