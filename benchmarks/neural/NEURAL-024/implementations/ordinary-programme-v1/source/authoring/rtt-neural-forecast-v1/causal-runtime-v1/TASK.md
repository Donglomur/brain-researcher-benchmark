# Causal next-bin neural count forecasting

Write one UTF-8 Python program (at most 65,536 bytes). It runs as `python -I -B /program/program.py` in one persistent offline process. For each request, return 96 strictly positive finite expected counts for the next 20 ms bin, in the existing channel order. Units are counts per bin, not rates per second. JSON booleans, nonfinite numbers, nonzero literals that underflow to zero, omitted channels and nonpositive means are invalid. Values must remain representable as finite Python float64 numbers; no clipping is applied.

Your five read-only files are `/program/program.py`, `/training/source_counts.npz`, `/training/calibration_counts.npz`, `/public/TASK.md` and `/public/PROTOCOL.json`. Each NPZ has exactly `counts` (little-endian uint32) and `bin_edges_seconds` (little-endian float64). Source counts have 18,700 rows; calibration has 3,000 rows; both have 96 columns. Stored clock edges retain their native absolute times. Request intervals instead use seconds relative to the first calibration edge. The first request starts at approximately 60 seconds; the last ends at approximately 502 seconds. Do not assume every decimal clock endpoint is represented exactly.

Use newline-delimited ASCII JSON on stdin/stdout. Flush each reply. Every input or output line is at most 4,096 bytes including its newline. Diagnostics belong on stderr (32,768 bytes total). Emit `{"status":"ready"}` first. Read the initialize object and acknowledge `{"status":"initialized","protocol":"NEURAL024-causal-v1"}`. Then answer each predict request with exactly `sequence`, `nonce` and `mean_counts`. Copy its integer sequence and nonce; emit the entire 96-number vector. The protocol metadata gives the exact schemas.

There are 22,100 calls: sequences 0–9 are required, unscored warm-up; sequences 10–22,099 comprise all 22,090 scored bins. The first request has `observation:null`. Every later request carries only the previous bin's `{target_bin,counts}` observation. That observation is released only after all 96 forecasts for its bin have been durably committed. The final stop message carries the last observation; acknowledge `{"status":"stopped"}` and exit zero. No shortened or favorable prefix receives a score.

You may maintain state and learn online from the source, calibration and already revealed prefix. The submitted programme and method files are committed before candidate activation and its first request. The existing packet was prepared earlier and is reused; the runtime does not assert that arbitrary in-memory model weights remain frozen. You cannot access current/future neural observations, original MAT files, the assessment NPZ, behavior/velocity arrays, private score artifacts or future-history batches. The local historical data are exposed development material; this is not a protected-test or memorization-proof claim.

The persistent candidate has a full 600-second wall allowance, 1.75 CPU, 3 GiB memory, 32 processes and 16 MiB writable `/tmp`; the root filesystem is read-only and networking is disabled. Numerical thread variables are fixed to one. Preparation and grading are separate trusted processes. The whole granted attempt is 780 seconds including their work and cleanup.

The primary metric is Poisson log-likelihood gain over the previously executed calibration-rate reference, divided by total spikes and ln(2), in bits per spike. Full likelihood includes the log-factorial term. Mean negative log likelihood and signed comparisons with all six fixed references are retained. Ten warm-up vectors do not enter any metric. All 2,120,640 scored cells remain in the denominator. Invalid or unsupported arithmetic yields an explicit failure, not a partial score. Ordinary programs have no accuracy floor. The fixed references keep their already executed parameters; adaptive programs are not described as matched-policy or matched-compute comparisons.

Submit the program with a small method JSON containing exactly `schema_version:1`, `method_id`, `method_description`, `training_policy` and `limitations` (nonempty strings). The operator binds both files, the current output, cumulative budget and review before execution. This source proposal does not grant execution or register a benchmark route.
