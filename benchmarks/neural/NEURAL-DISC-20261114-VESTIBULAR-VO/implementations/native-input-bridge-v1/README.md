# Vestibular native input bridge: construction in progress

This additive implementation begins the missing bridge from the complete
`VO_dataset.mat` to the existing neural velocity-decoding task. The original is
180,725,660 bytes, SHA256
`3db6c47e61f51230ea4a83b5722f1c019337ab09f7ad836b36ce934a0270ca86`,
Borealis `10.5683/SP3/FXFZ2J` version 2.0. Its accepted download is distinct from
authentication of its biological schema. No authentic MAT bytes have been read
or decoded by this construction phase.

The scope remains 49 distinct neurons, 35 genuine simultaneous pair
relationships and three animals: D 11/6, B 34/26, O 4/3 neurons/pairs. All
naturalistic motion, eight registered sinusoidal frequencies and any additional
authentic conditions must be accounted for. Repeated appearances of one neuron
do not create independent neurons. An analysis-specific 41-neuron subset and
nonsimultaneous pseudo-populations cannot replace this scope.

`native_mat.py` provides complete MAT-v5 loading and exact structural path
resolution. It reuses the preserved census parser byte-for-byte, with new owned
file-descriptor authentication and read accounting. It loads all top-level
variables, checks complete coverage, preserves shapes and MATLAB Fortran
cell/struct coordinates, and traverses every nested member. Objects, functions
and opaque MATLAB classes are refused. Numeric signal values are not emitted
in the private census. Text and allowlisted scalar metadata stay private and
are explicitly unverified semantic candidates. No physical role is inferred
from a name.

`census.py` is a separately selectable prospective host census route using
existing Python 3.11, NumPy 2.4.6 and SciPy 1.17.1. It does not run Docker,
inspect SSL targets, modify the old prefix, or claim that the historical Docker
inventory passed. The old four-external-SSL-alias failure and its source and
receipts remain intact. `CENSUS_SOURCE.json` freezes this new route's three
runtime source files; it is not a whole-package runtime inventory.

An actual operation requires a separately accepted bounded protocol and shared
native lease. The wrapper limits wall time, child CPU time, file/output extent,
diagnostic output and managed input reads. It observes the trusted worker's RSS
every 0.25 seconds and stops/reaps its owned process group on violation. This
is sampled memory supervision, not an OS hard RSS quota. Decoded-array byte
accounting occurs after allocation and cannot substitute for supervision.
Incomplete operations preserve private partial output and failure records;
there is no reduced-file success or automatic retry.
Authored refusal reasons are retained through a fixed allowlist. Arbitrary
third-party exception text is not published. If termination prevents a bound
worker receipt, actual original reads remain unknown and the full 550,565,588
byte read ceiling is conservatively charged; absence of a receipt is not zero I/O.
