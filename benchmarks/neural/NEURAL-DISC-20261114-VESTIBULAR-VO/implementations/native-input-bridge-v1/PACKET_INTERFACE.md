# Complete-repeat projection and existing evaluator bridge

These are trusted in-memory source APIs. They do not authenticate the unknown
original MAT fields, export authentic materials, isolate a participant, fit a
prior or evaluate an AI. `CENSUS_SOURCE.json` and its separately admitted census
runtime remain unchanged. No original preparation is implied by generated
fixtures that happen to have the required census size.

`packet_projection.project(prepared, admission,
accepted_admission_sha256=..., id_key=...)` accepts the complete prepared-repeat
schema documented in its source. The separately selected admission hash joins
the exact preparation, census, physical role, split, protocol and review
identities. Those joins are not independent evidence of their scientific truth.
Generated controls use their own explicit admission kind.

The producer requires all 49 distinct neurons, 35 distinct unordered genuine
pair relationships and D/B/O counts 11/6, 34/26 and 4/3. Recording groups retain
session and recording identities; genuine pair relationships may have multiple
recordings. The source-record inventory accounts for every original record,
including exclusions. Conditions include the nine declared stimuli and every
additional condition, with explicit animal-condition-stratum availability.

Every active repeat has exact integer ticks, an explicitly documented rational
seconds-per-tick scale, repeat origin, measured-velocity unit and axis, original
spike events, channel clock/alignment evidence, fixed support and complete target
values. Unknown clocks and units cannot be invented. Each query group-condition
needs separate training repeats. All views of an acquired presentation stay in
one partition; a presentation cannot count as two repeats within a group.
Shared neurons and presentations across different genuine groups retain common
acquisition geometry instead of becoming fabricated independent neurons.

The returned `public` object contains full-repeat spike events, relative exact
ticks/times, physical units and operator-keyed opaque case/group/channel IDs.
Training repeats additionally expose calibration velocity and its fixed mask.
Query targets, query masks, source identities, original clock origins, hidden
presentation metadata, admission evidence and the HMAC key stay outside it.
The distinct `protected` object retains original ticks, source census, identity
crosswalk and target cases. It has no synthesized prior and claims no baseline
qualification.

`tile_query` takes one already projected query and returns every one-coordinate
tile to the operator. It checks the nested public clock whitelist and preserves
the declared half-open event support. A future participant invocation must
receive only one tile in a fresh context/workspace; this function does not
implement that boundary. The full-repeat and tiled-core conditions remain
distinct. The adapted `paired_shift` retains the original common-channel,
past-history seam mask; it does not qualify models that consume future context.

`reference_bridge.assemble` revalidates the exact preparation/projection and
accepts a separately pinned supplied-prior bundle. The prior must bind the
exact public evidence, full-repeat information condition, every query case and
its complete relative integer grid. Declared selection records must be unique
training records; such declarations still do not prove actual training or prior
competence. Missing predictions, changed grids, held-record selections and
candidate-provided masks fail assembly. No prior values are fabricated.

The current `condition-evaluator-v2` declares global target and clock units.
Assembly therefore requires one common documented velocity unit, axis and
exact rational tick scale across the complete preparation. It refuses mixed
units instead of guessing normalization or dropping conditions. Any necessary
source-derived conversion must be separately documented before preparation.
The assembled protected reference uses the unchanged v2 schema and validation;
no scoring equation is added and no candidate evaluation is called.

This assembler binds **full-repeat** priors only. A tiled-condition prior needs
its own matched observation/transport proof and is not admitted by changing a
label. Both prior competence and actual participant execution remain separate
requirements. Whole in-memory resource sizing also awaits the authentic census;
these APIs are not an admitted full-export driver.

Generated controls cover a complete 49-neuron/35-pair panel, 38 recording groups,
10 conditions, 761 source records, 380 held repeats and 1,520 tiles. They test
duplicate acquired-repeat rejection, legitimate shared acquisition views,
complete support, exact large integer clocks, split leakage, unit disagreement,
target-field exclusion and existing v2 reference interoperability. These counts
describe invented software fixtures, not observations recovered from the MAT.
