# NEURAL-058 finite score aggregation repair

This is a bounded replacement candidate for the existing programme's `program/scores.py`. It repairs score arithmetic and validates complete score support. It does not install itself into the authenticated runtime or change the benchmark definition.

The predecessor can produce finite per-animal R² values and then overflow while averaging them across the 13 required animals. For example, the generated control uses two target samples `[0, 2]` per head and predictions `7.8e153`: the per-animal score is finite, while summing 13 such scores inside NumPy's mean overflows. The paired-policy average has the same defect with three finite scores of `-6e307`. These deliberately extreme software counterexamples are not physiological wheel measurements or scientific results. They exercise the declared finite-output boundary.

The replacement uses compensated summation, with an exact rational mean rounded once when the unscaled sum overflows. Dividing summands before summation is insufficient at the largest finite float because each division can round upward; an independent reviewer found this boundary and its regression remains in the controls. The repaired operation applies to the animal mean, the three paired policy effects per animal, and each bootstrap replicate. Percentile interpolation uses weighted endpoints rather than their potentially overflowing difference, preserves identical adjacent endpoints exactly, and falls back to an exact convex sum on overflow. An individually unrepresentable R² is refused at the metric boundary. Malformed policy lengths and nonfinite scores are checked before returning an undefined endpoint, so a constant target cannot hide missing policy support or another nonfinite result.

The scientific estimator remains unchanged: equal timestamps per window, equal windows per session, equal sessions per animal, followed by equal animals. Signed velocity is primary; absolute speed is a separate companion. Negative R² is retained. Exact constant targets remain undefined with support retained. The paired contrast still uses three paired realizations within each animal, 10,000 PCG64 draws, seed 580058, and linear 2.5%/97.5% sample quantiles. Floating-point last bits may differ from NumPy's uncompensated reduction. No scientific tolerance or eligibility rule is relaxed.

`controls/test_scores.py` compares the weighting against an independent rational-arithmetic oracle, reproduces the predecessor overflow, checks the seed and animal-resampling recipe against an independent generated oracle, and exercises constant, missing, duplicate, and nonfinite cases. Run it through the shared generated-test pool. It imports only the predecessor's `core.py` helper and the old/new score modules; it does not load native data, models, historical predictions, or private target files.

Integration requires a new authenticated runtime source manifest and its dependent pins, with this module replacing the old scorer through the existing protected grader. Those shared/runtime integration changes are intentionally deferred to the integration owner; an ad hoc import must not bypass the original source-authentication or target-last gates. Version 1 and its reviews remain intact.

The full 452-object source custody, 423/29 session cohort, physical wheel units/sign, authentic preparation, trained references, participant isolation, and complete scientific execution remain unqualified. This change supplies a score component and generated software controls only. It establishes neither direct neural interpretation nor benchmark performance.
