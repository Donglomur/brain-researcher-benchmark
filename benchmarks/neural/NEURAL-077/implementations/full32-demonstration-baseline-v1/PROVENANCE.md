# Provenance and interpretation

This source implements a deterministic, demonstration-only reference programme for the existing NEURAL-077 full32 condition. Method choices were fixed before generated control execution. No original query, demonstration or answer payload informed this source phase.

The existing `full32-paired-benchmark-v1` bundle, consumer and recipe sources define the participant entrypoint, framed prompt/response protocol and two-channel sample geometry. The named predecessor delivery source establishes that demonstrations are a JSON list. The parser follows those structural contracts without inventing literal prose delimiters. The supplied recipe already performs its reference and first-256-sample baseline correction; this component does not repeat it.

The captured programme source and configuration are the future study operands. A trusted operator must freeze the whole bundle and authoring-exposure declaration before evaluation query access. Four permitted demonstrations supply the method's parameters; the evaluation query supplies only the observation to classify and the opaque identity to echo. The participant split, event-label target, full 6,400-case count, original scorer and paired label-access barrier are unchanged.

The four generated controls test signal discrimination, demonstration-label reversal, demonstration-order invariance and query-identity independence. The original prompt and packet were not exercised, so actual EEG execution compatibility also remains unqualified. They cannot establish ERP decoding accuracy, calibration, physiological P3 inference, benchmark difficulty or a new SOTA. Passing generated source controls also does not establish physical sandbox or provider qualification.

No provider transport is added or relabeled here. The direct arm still needs authentic first-response/configuration custody and the separately stated capability-policy qualification. Instructions asking an agent not to use tools do not enforce that restriction. This programme supplies one concrete comparator while those direct-arm study requirements remain open.

Public source metadata records exact source/control identities and observed results. Private authoring receipts, local data paths, credentials and generated campaign artifacts are excluded from the publication allowlist. The original accepted components and historical evidence are not rewritten by this source phase.
