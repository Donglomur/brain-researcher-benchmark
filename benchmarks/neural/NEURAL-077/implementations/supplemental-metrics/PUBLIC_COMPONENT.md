This directory contains reviewed software source and generated test examples only.
It includes exact copies of the canonical validator/scalar primary scorer so the
supplemental evaluator and its controls do not depend on private study artifacts.
There are no recordings, authentic trial labels, private target/reference-grade
identities, absolute workstation paths or communications in this projection.
Canonical source hashes identify software, not scientific answer artifacts.

Use an admitted NumPy runtime for an actual evaluator operation. The generated
source checks use only Python standard libraries and the bundled source:

```text

```

For actual scoring, pass this component's canonical directory to
`evaluate_submission`, with the existing operator's independently verified public
IDs, private-loader closure, saved reference structure and frozen observed-input
submission. No private input is bundled or created by this component. The outer
isolated grader and producer-absence proof still require their own admission.

The seven evaluator/oracle/test/document bodies are byte-identical to the
private source proposal. The two bundled canonical source bodies have
the exact hashes required by that evaluator. The previously run generated controls
therefore cover the same code bytes; projection custody is not a fresh runtime or
empirical qualification. No canonical primary metric or benchmark ID changes.

This is a proposal for root's publication review, not an assertion that it has
been pushed, merged, run on authentic inputs, or accepted by another benchmark.
