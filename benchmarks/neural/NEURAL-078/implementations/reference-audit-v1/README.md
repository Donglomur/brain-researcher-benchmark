# Independent reconstruction of the fixed matched contrast

This operator tool independently recomputes NEURAL-078's complete eight-person report from the selected public packets and checks it against the current numerical core. It addresses the missing independent numerical cross-check described in the [current source inspection](../../docs/current-source-inspection.md). It never opens historical reference answers. It does not admit a protected reference or change the historical grader, its source binding, the task, or the primary matched-FCz MAE companion.

The source algorithm is pinned to `analysis_core.py` SHA256 `d8780ed20e7c55d9d726fc894a605332856a729323ed51b95d4038e0e007bd7e` in [the existing implementation](../neural078-deferred-grade/scorer/analysis_core.py), as inspected at repository base `c620e64d39fda59e049c40b3bc7d6d328d1534f9`. The original [ERP CORE source](https://github.com/lucklab/ERP_CORE) supplies the source-study context; this fixed-eight-person matched analysis is a benchmark adaptation. This addition makes no new claim about the author pipeline, event codes, sample clock, amplitude calibration, or original paper parity.

The second matching implementation walks a prefix grid. It maximizes pair count, minimizes total absolute RT difference, then maximizes an explicit base-four action word with priority match, skip-correct, skip-error. At a given grid cell, paths with equal pair count have equal action-word length, so integer comparison implements the existing lexicographic tie rule. This differs from the source's suffix count/cost tables and local action selection. Both sort by integer RT then opaque trial identity. Pairs remain within all four response-hand × stimulus-congruency strata; the caliper remains 25 ms (25 integer samples admitted, 26 excluded at 1,024 Hz). No signal value enters matching.

The independent statistics use explicit fixed sample positions and exact accumulation of the binary input values before rounding each mean to float64: 0..102 inclusive for FCz/HEOG/VEOG, and -512..-410 inclusive for pre-response FCz. Error-minus-correct contrasts retain native EEGLAB amplitude units. RT diagnostics use milliseconds. The threshold remains ten pairs per person. All eight people retain equal weight, and any unsupported person forces null complete-cohort aggregate values. Between-person SE is descriptive `SD/sqrt(8)`, not a population confidence interval or a causal result.

The **packet decoder and validator are shared with the pinned source**. This is algorithmically separate matching/statistics, not independently authenticated raw acquisition or preprocessing. The tool checks all 195 original report leaves, requiring exact support/digest/null/status equality and the frozen numerical tolerance `1e-9 + 1e-7*abs(source_value)`. Roundoff differences within that existing tolerance are allowed and their maximum normalized magnitude is recorded. These 195 leaves are report checks, not independent biological observations. The output reference contains the independent computation, not a copied source result.

After a separately frozen and authorized authentic-data protocol, an operator can run:

```sh
python3 audit.py \
  --packet-directory /operator/selected-public-data \
  --packet-pins /operator/independently-selected-packet-pins.json \
  --output-directory /operator/fresh-protected-reference-audit
```

The placeholder pin file is a JSON object mapping exactly `sub-001` through `sub-007` and `sub-010` to `{"bytes": integer, "sha256": "64 lowercase hex characters"}`. These pins must come from independently selected packet provenance; recomputing pins from an arbitrary replacement is not admission. The directory must supply each corresponding `<person>.npz`. Packets are read and checked sequentially, bounded to 15 MB each, decoded without pickle, and never downloaded by this tool. There is no historical-gold argument, hidden answer lookup, or candidate submission interface.

Only after both computations agree for every person and aggregate does the tool create its fresh mode-0700 output directory and write `REFERENCE.json` and `AUDIT.json`. The receipt binds selected input bytes, protocol, current numerical core, audit source, reference bytes, and comparison summary. A failed write can leave an incomplete directory, which must not be used; success requires exit 0 and both complete outputs. This is a local operator tool, not a hostile-filesystem sandbox or an authorization mechanism. The reference and receipt disclose target-derived values and must stay outside public Git and candidate feedback. Shared custody, source timing, empirical source preparation and protected-grading admission require separate review.

The task-local generated suite checks 1,600 exhaustive small matching panels against an unrestricted assignment oracle and the source's exact pair choices; analytic eight-person effects and descriptive SE; both window endpoints; 25/26-sample boundaries; hand/congruency isolation; input-order invariance; unsupported outcomes; mismatch refusal; original RT overflow rejection; source and input pin enforcement; and full CLI publication from generated packets.
