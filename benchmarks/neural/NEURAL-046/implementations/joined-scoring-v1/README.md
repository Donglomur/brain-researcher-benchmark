# Complete paired scoring for NEURAL-046

This callable successor scores the current matched-model fluorescence investigation and its independently tuned joint-model sensitivity on the same complete case set. It preserves the existing shared arithmetic and adds a strict join and sealing boundary. The shared `score_sensitivities` callable uses positional `zip` without its own length, identity, endpoint or closure checks: a shorter target list silently omits animals, and a reordered list can pair predictions with another case's target. Generated controls retain both counterexamples.

The existing `workflow.grade_once` separately authenticates stored artifacts and scores the primary output before this sensitivity. These counterexamples establish a weakness in the standalone scoring callable; they do not establish that the existing workflow's authenticated artifacts were corrupted. No historical results were read or rescored.

`score.py` exposes `score_joined(public, submission, sensitivity_predictions, binding, closure, load_private)`. The public object and primary submission retain the current shared schemas. The sensitivity dictionary retains the existing `MEN_independently_tuned` slot only when the control permits MEN; controls without MEN require an empty dictionary. The implementation imports the existing arithmetic and control registry after checking the eight exact source/specification SHA256 pins in `PINS`. It never calls model fitting.

The operator constructs `binding` at preparation, before predictions, and stores it outside the participant interface. It maps every public query ID to exactly six native metadata fields: `id`, `animal`, `session`, `condition`, `endpoint`, and `domain`. Case IDs must be unique. Public/native animal and session mappings must be consistent and one-to-one, and each biological animal must have one condition/domain. Nonopaque controls require the original ID, animal and session. The opaque control uses the explicit mapping instead of trusting list order. This source does not establish biological alias truth; the original source identity audit remains required.

Before target loading, the operator closes producers and seals primary and sensitivity artifacts plus the binding. `closure` contains the existing three fields (`all_required_producers_closed=true`, `all_required_artifacts_sealed=true`, `private_targets_opened_before_closure=false`) and four canonical SHA256 values: `public_digest`, `submission_digest`, `sensitivity_digest`, `binding_digest`. The current shared `digest` function defines canonical serialization. The scorer snapshots these inputs, validates closure and the complete finite prediction sets, and only then calls the zero-argument `load_private` callback. That callback must authenticate and return the original prepared private query rows. The scorer rejects missing, duplicate or extra cases and changed metadata, aligns accepted rows by native ID, and passes the same aligned list to primary and sensitivity arithmetic.

The report retains primary model MSEs and the signed `Delta`, `G_E`, `G_N` and permitted M0 gains. It adds `mandatory_sensitivity` and a compact `paired_join` receipt. The primary remains an equal-biological-animal average of within-animal MSE. For the current cue AUC, response units are stored fluorescence times seconds; squared loss units are their square. This component does not convert units, recompute fluorescence targets, substitute the historical observed-span mean response, alter exclusions, or create a preferred sign. No interval, biological estimability or direct neural interpretation claim follows from these calculations.

The callback and closure are a trusted operator interface, not a sandbox or proof that targets have never been seen. The caller must protect and authenticate private bytes, preserve model-artifact provenance and establish closure externally. Existing numerical range behavior in the shared arithmetic is unchanged. Complete authentic preparation, endpoint coverage, independent biological IDs, full model fitting, refitting uncertainty, participant transport and direct/viewer delivery remain unqualified. The legacy scoring bridges still have their recorded missing dependency closures. This successor is not wired into the shared dispatcher or canonical registration.
