# Original trial identity in the NEURAL-003 reference

This successor repairs a source-join defect in the partition and matched-ridge components. The retained predecessor joins observations with `(person, session, trial)`: it discards the original block, and the compiled fold does not bind instruction. Consequently, a row with a changed block or a switched valid instruction passes the predecessor's reference admission. Instruction affects the contrast/instruction comparator and the EEG arm, so accepting this change can alter the benchmark comparison without a source-identity failure.

`neural003_identity.partition` now retains each immutable `Trial(person, session, block, trial, instruction)` in the outer and inner rosters. The first four fields define the original trial; instruction is bound metadata. Duplicate original trials, conflicting instruction for the same original trial, and conflicting instructions within an original block fail admission. The reference requires exact equality with that bound record before fitting or prediction. It validates the complete 25-inner-fold partition before the first fit, including a malformed final inner fold. Arbitrarily changed but internally consistent source records still require authentication by the future native source producer.

The two Python modules are a jointly versioned successor. Use their `Trial`, `Fold`, `compile_splits`, `Observation`, `fit_reference`, and `predict_reference` together; predecessor three-field fold keys are not accepted. Input row order may vary: admission restores the compiled order. The split still contains all 26 held-person folds, 25 whole-person inner folds each, and matched EEG and contrast/instruction arms. No source identity field enters the prediction feature vector. The per-person source bound is 20,000 trials, consistent with the existing complete-output schema.

The numerical ridge kernels and feature construction are retained from the predecessor: equal-person training weights, training-only mean and scale, alphas 0.1/1/10, all 25 inner-person validation losses, deterministic alpha tie-breaking, and projection strictly above 0.1 seconds. This revision does not alter the fixed causal window, RT estimand, scorer, target barrier, or paired participant-macro MAE. It does not claim that reference fitting was executed.

## Source basis

The cached official [experiment source at revision 76464a9ca15564897e58256081af4b99d08ae8db](https://github.com/GWeindel/decision-times/blob/76464a9ca15564897e58256081af4b99d08ae8db/experiment_code/experiment.py) writes `condition`, `trial`, and `block` together in both its pause record (lines 269–278) and its normal-response record (lines 340–349). Its source SHA-256 is `51dc947f4ae0c4083a998159922d941e15ee755887a5c569410d749101eaa743` (14,220 bytes). The session-level trial counter is initialized once and is not reset at block boundaries. Accordingly, the generated repeated-trial-name control demonstrates preservation of distinct full identities; it is **not** evidence that this source experiment used block-local numbering.

Paused/interrupted records can require a distinct source resolution. This code does not invent attempt identifiers, infer blocks from row order, deduplicate source records, derive an EEG clock join, or turn a missing response into a target. Exact repeated full identities fail until an authenticated source preparation resolves their meaning.

The predecessor files remain unchanged at `../causal-reaction-time/`. Their SHA-256 values are `aca8a7576c63cd4d4825c15a089cee4f2663aa7475b79a981403f25ef10aae90` for `neural003/partition.py` and `ecb3f5ae31fcbae047e8df9dbc6de496750615a8dc9a0e081874f55ad6c5c5a1` for `neural003/reference.py`. ## Generated controls and limits

`test_identity.py` contains nine standard-library software controls. They reproduce the predecessor accepting altered block/instruction metadata, reject those changes in both successor arms before fitting/query prediction, check complete whole-person support and late malformed inner folds, preserve distinct blocks with repeated trial names, reject conflicting metadata and query labels, check arm boundaries and prediction-feature exclusions, and exercise all 75 inner selection calls plus the final fit with stubs. These stubs verify routing only: no NumPy, model fitting, neural observations, authentic targets, or candidate predictions are used. During the parallel construction wave, run this script through the shared reviewed test pool.

This is an executable repair to downstream components, not an authenticated EEG preparation or a runnable benchmark. Original native EEG, person/session/block/trial and clock joins, complete finite first-response targets, the nonresponse/censoring estimand, isolated fold/arm execution, and measured numerical reference qualification remain open. The existing public processed-epoch release cannot supply causal raw input by cropping. Direct observation, typed viewing, tool-assisted investigation, and frozen-program delivery all remain undelivered. No new scientific performance or neural-understanding result is claimed.
