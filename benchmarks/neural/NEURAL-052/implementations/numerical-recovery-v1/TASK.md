# Object-property organization across independent visual ROIs

NEURAL-052 asks whether continuous human liveliness and real-world-size ratings add predictive information about fMRI responses beyond fixed image descriptors and acquisition-position covariates, and how those increments differ between V1 and inferior temporal (IT) cortex. Produce the complete numerical analysis below and a short `METHODS.md` interpretation. Negative effects, null effects and undefined support are valid answers. This is a prospectively defined analysis of authentic THINGS-fMRI, not a reproduction of the original notebook's in-sample OLS or a claim of improved biological performance.

## Complete source panel

Use all three source participants (01–03), all 12 sessions, and the complete author-designated repeated panel: 100 concepts, one identical image per concept, once per session. There are 1,200 rows per person. Preserve native voxel identity separately for each person. Include every voxel in independently supplied V1 or the official IT union (Glasser TE1p, TE2p, FFC, VVC, VMV2, VMV3, PHA1, PHA2, PHA3). Native union counts are 5,130, 4,962 and 4,218; V1 counts 1,049, 1,104 and 839; IT counts 4,081, 3,858 and 3,379. Do not select voxels, subjects, ROIs or responses using response strength, published noise ceilings or the resulting effects. There is no cross-person voxel correspondence.

The exact input is a transparent row/column projection of the released full native float32 response matrices. The shared source acquisition preserves all 9,840 trials; this task uses its complete repeated-image subset. Released preprocessing was performed upstream; the split here cannot establish that upstream processing was fitted independently of evaluation data. The same image is repeated, so this assesses new-concept and held-out-session prediction, not unseen-exemplar transfer.

`input/features.json` contains independently collected THINGSplus norms: `animacy` is `lives_mean`, a continuous 1–7 liveliness rating; `size` is `meanSize`, an anchor-relative 0–519 rating. Neither is a binary class or a physical length in centimetres. All 100 concepts are present. Fifteen fixed image-only descriptors use the exact source photos: RGB means and population SDs, encoded-Rec709 luma SD, horizontal and vertical gradient energy, five radial Fourier-power fractions and a zero-power flag, after RGB conversion and 256×256 Lanczos resampling. See `FEATURE_PROTOCOL.md`. These encoded-RGB features do not implement ICC/display calibration or exhaustive visual-confound adjustment. No pretrained image model is used.

## Prespecified folds and models

Sort concepts by the SHA256 digest of UTF-8 `52052`, a NUL byte, and the concept ID; break an exact digest tie by concept ID. Assign successive concepts round-robin to five folds. Cross each concept fold with held-out session blocks 1–4, 5–8 and 9–12, giving 15 outer folds. Train on the other 80 concepts in the other eight sessions (640 rows); predict the 20 held-out concepts in the four held-out sessions (80 rows). Exclude both the held-out concepts and the held-out sessions from training. Each of the 1,200 rows is predicted exactly once.

Fit each person and voxel independently using float64 numerical arithmetic. The ordered predictors are numerical session, numerical run, within-run position, the 15 supplied image features in their documented order, then animacy and size. Within-run position is the zero-based chronological rank within each session/run in the complete original 9,840-trial metadata, not the repeated subset. Its source derivation is supplied. Session/run are numerical covariates, not one-hot identifiers. Standardize each predictor using only its training mean and population SD; replace a zero SD by 1. Fit four ridge models with fixed penalty 1, an unpenalized intercept, and no tuning: image+nuisance baseline; baseline+animacy; baseline+size; baseline+both. Center responses by the fold's training mean only; do not standardize or select responses. No test targets, reliability values or evaluation error may determine transforms, hyperparameters or selection.

## Primary and paired controls

For each voxel, sum all its held-out squared errors across folds. Use the common denominator `SST = sum((query response − that fold's training response mean)^2)`. The three increments are `(SSE_size − SSE_both)/SST` (animacy given size), `(SSE_animacy − SSE_both)/SST` (size given animacy), and `(SSE_base − SSE_both)/SST` (joint). The primary for each participant/ROI/endpoint is the equal-voxel mean of these ratios. Preserve negative increments. A zero-SST voxel makes the complete-ROI primary undefined; separately report the defined-voxel mean as a diagnostic, never a replacement. Nonfinite input or unsupported arithmetic is a source/runtime error, not a numerical reward.

Report IT-minus-V1 contrasts separately within each person, then the equally weighted descriptive mean over all three persons. No voxel or trial is an independent population replicate. Undefined participant support propagates to the full descriptive mean.

For a reliability sensitivity analysis, use only each fold's 80 training concepts and eight training sessions. Average each concept's response over the first four versus last four chronologically sorted training sessions, then calculate raw Pearson correlation across concepts for each voxel. This is raw split-half reliability, not a noise ceiling or Spearman–Brown correction. Use fixed bins `[-1,0)`, `[0,.25)`, `[.25,.5)`, `[.5,.75)`, `[.75,1]`; preserve undefined correlations. Within bins present in both ROIs, give each common bin equal total weight and each voxel in that bin equal weight. Other/undefined bins get zero *secondary* weight and remain counted. No common bin in any fold makes the complete weighted control undefined.

The weighted control pools weighted incremental SSE and weighted SST before dividing. Also report an unweighted pooled-error comparator, `sum incremental SSE / sum SST`, using every ROI voxel, and the paired weighted-minus-unweighted difference. These two pooled estimands are comparable. Neither is a reliability-corrected macro primary: changing from mean-of-ratios to ratio-of-sums changes the estimand. Report all fold/bin support counts and zero-weight coverage so selection consequences remain visible.

## Uncertainty and interpretation

Use 1,000 bootstrap draws of the sorted 100 concept IDs, each drawing 100 concepts with replacement, using NumPy `Generator(PCG64(52053))`. Preserve all 12 repetitions and share the draw schedule across all participants/ROIs/endpoints. Recombine the fixed held-out per-concept error/SST contributions; do not refit or relearn reliability weights. Report 2.5th/97.5th percentiles using linear quantiles. These are conditional fixed-prediction concept intervals, not full-training uncertainty or population inference. If a point is undefined or any requested draw is undefined, report a null interval and all defined/undefined counts; do not discard or redraw replicates. The many endpoint/ROI/control intervals are pointwise and exploratory, with no multiple-comparison or confirmatory-significance claim.

Interpret changes between the primary, paired pooled controls and participants in `METHODS.md`. Distinguish predictive association conditional on these controls from causal semantic representation, noise-ceiling equivalence or a population claim. The numerical scorer does not automatically assess the quality of that prose.
