# Scientific and data provenance

- THINGS-data: [Hebart et al., eLife2023, DOI10.7554/eLife.82580](https://elifesciences.org/articles/82580). The source object-property illustration uses in-sample concept-level regression; this task's held-out incremental-error protocol is new.
- Author repository: [ViCCo-Group/THINGS-data, commit5e0eccac51eac78b57045f5b90b4f53814f56c32](https://github.com/ViCCo-Group/THINGS-data/tree/5e0eccac51eac78b57045f5b90b4f53814f56c32). Relevant original sources are `MRI/thingsmri/dataset.py`, `MRI/data/animacy.csv`, `MRI/data/size_fixed.csv` and `MRI/notebooks/animacy_size.ipynb`. An output-stripped source derivative is retained separately from the original notebook.
- Native source: [OpenNeuro ds004192](https://openneuro.org/datasets/ds004192), linked with the author release. Exact direct HDF5 S3 version IDs, ETags, byte geometry and selected-range hashes are bound by the acquisition records. Source filenames and the public dataset label alone do not substitute for these identities.
- Alternate author distribution: [Figshare THINGS-fMRI trial-wise betas article20492835 v2](https://figshare.com/articles/dataset/THINGS-fMRI_trial-wise_betas/20492835/2). No43GB response ZIP was downloaded. Source stimulus/ROI metadata was acquired by exact ZIP-member ranges and CRC checked; the full native V1/IT response selection used the direct immutable HDF5 objects.
- Independent property norms: [THINGSplus, DOI10.3758/s13428-023-02110-8](https://doi.org/10.3758/s13428-023-02110-8). Human noun ratings are independent of these neural measurements but are not exact-photo ratings or causal interventions.
- Exact repeated photos: [THINGS original image release, OSF version1](https://osf.io/download/rdxy2/?version=1). Selected100 members were verified against the complete source central directory, local headers, CRC and local SHA256. The full archive was not locally hashed. Original photographs retain owner copyrights and research/education source terms; they are not included as publicly redistributable benchmark assets. The fixed derived descriptor table has its own construction provenance. Different CC0 THINGSplus exemplars were not substituted.

The same source participants and stimuli underpin NEURAL051. Separate task IDs reflect distinct canonical questions, not independent biological datasets. Cross-task exposure must be recorded in any future model evaluation.
