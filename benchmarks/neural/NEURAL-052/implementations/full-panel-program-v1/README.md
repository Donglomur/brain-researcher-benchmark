# Complete public-panel programme and numerical grade

This addition publishes the original NEURAL-052 participant lifecycle and joins
its captured artifacts to the existing numerical scorer. `producer/` contains
the original 13 source members and their manifest, recovered byte for byte.
The new files provide the outer process observation and a separately selected
numerical phase. Existing preparation, numerical algorithms, task registration
and qualification remain unchanged. No authentic participant, reference fit,
numerical grade or model experiment was run during this construction.

The original complete public view has **14 files, 71,207,593 bytes**. It retains
all three people, 100 repeated concepts, 12 sessions, 1,200 rows per person and
all independently selected V1/IT voxels: 5,130/4,962/4,218 union voxels. The
investigation uses 15 crossed concept/session folds per person, four fixed
models and 1,000 shared concept draws. Neural responses, image covariates and
property norms are intentionally public. Internal cross-validation does not
make this a hidden-outcome evaluation of the analyst.

## Original participant lifecycle

The unchanged source commits one self-contained programme before exposing its
public view. The participant executes:

```sh
python -I -B /submission/program.py --input /input --output /output
```

`/input` is the complete public package root, including its `input/` subfolder
and protocol documents. The candidate must return exactly `result.json`
(at most 4,000,000 bytes) and UTF-8 `METHODS.md` (at most 1,048,576 bytes).
Both files are captured together only after the candidate exits naturally and
its container is removed. The producer, holder and output volume must close;
the full public copy is then retired. The original separate support phase
checks complete report structure, not numerical values or interpretation.

The original external `observe.py` checks commitments, public-view retirement,
both native closure records, CLI group closure, both captured outputs and the
support result. Its `GRADE_HANDOFF.json` remains explicitly ungraded and
unauthorized for numerical execution. The new outer wrapper uses the original
bounded `process.run` once to observe **observe.py itself** exiting naturally
with code zero, reaped process/group and closed streams. It then reuses
`observe.admit`; an external receipt file alone is insufficient.

Original limits are preserved: one candidate CPU, 512 MiB–4 GiB selected RAM,
2–7,200 selected work seconds, one additional 1 GiB/one-CPU holder, a 64 MiB
output volume and 32 MiB candidate scratch. Support has 300 seconds and 2 GiB.
The original whole interval is candidate seconds plus 1,200; original managed
read/write ceilings and 192 MiB retained-artifact allowance remain in force.
The recovered inner 20 GiB free-disk guard is supplemented by the new outer
60 GiB floor, outstanding reservations and both phase artifact holds.

## Separate numerical phase

After actual observer zero and complete original admission, the new code calls
the existing NEURAL-007 concrete provider as an unchanged, source-pinned
dependency. No new transport framework or provider copy is introduced. This
trusted phase has its own explicit selected time and memory, one CPU and one
thread, plus the provider's additional 128 MiB/one-CPU holder. It mounts only
the full original public packet, pinned DESIGN/PACKET_BINDING, unchanged
numerical source, the bridge/worker and the two frozen participant artifacts.
The participant programme is absent. The complete grade is captured after
trusted producer removal and all provider resources close.

`grade_worker.py` requires the original Python 3.12.8 and NumPy 2.2.6. It
executes captured, verified copies of the existing numerical modules. The
original `run.score` and `grade.grade_submission` algorithms remain unchanged.
Their artifact-capture bindings check the **bytes actually returned** against
the stopped result/METHODS commitments. A changed report is refused before
`load_packet` or `analyze`; checking filenames before and after a reference fit
would not provide that boundary. Other original captures remain unchanged.

The original grader validates the complete report before numerical packet
loading and recomputes `analyze(draws=1000, strict=True)`. It retains all 18
person × ROI × incremental-variance primary comparisons, signed negative/null
effects, reliability sensitivities and undefined-support outcomes. METHODS is
required and hashed, but prose quality is not scored. A numerical match does
not establish scientific reasoning, causal understanding, superiority or SOTA.
