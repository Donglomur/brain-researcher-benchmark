# Training-only reference selection

This additive component implements the selection step that `rendered-references-v1`
deliberately leaves external. It reuses that predictor and the existing direction
scorer unchanged. It does not implement native MAT normalization, construct
authentic training episodes, execute a participant, or establish scientific
qualification.

## One outer fold at a time

`select_fold` receives only the authenticated private projection for the other
47 positive records. The outer-held record is represented only by its public
roster identifier. A complete census, all eligibility decisions and the packet
descriptors are validated before any packet callback. The 49-row public roster,
its separate zero record, and all 48 positive outer folds remain unchanged.

For each of the 47 training records, the projection supplies one complete
pseudo-held episode: the earliest eligible trial of each direction is support;
every other eligible trial remains a query in source order. All eight query
classes must be represented. Counts that disagree with the declared roster,
unresolved eligibility, duplicate identities, missing classes or absent packets
refuse the complete selection. Adjudication hashes are assertions to be
authenticated by the owner, not evidence generated by this module.

The new nested-scale policy is explicit in `SCALE_POLICY.json`: each training
episode uses the maximum absolute finite full-field delta from exactly the other
46 outer-training records. Its own support/query maps and the outer-held record
do not contribute. The original outer-held inference uses its separate scale
from all 47 outer-training records. The existing full-field producer does not
yet construct this nested 46-record envelope. A trusted source-linked adapter
and independent input review remain prerequisites; generated envelopes do not
resolve original clocks, trial/row identity, Run99 lineage or native geometry.

Each episode binds a single scale, eight unchanged calibration maps and a fixed
context across all its queries. Every candidate receives the identical immutable
nine-map bytes for a query. Existing native-resolution PNG, mask, geometry and
reference input validation is reused; the selector does not crop, resize, select
voxels, choose time points, or compute scales from quantized pixels.

## Selection rules fixed before data use

The selector retains nine complete training outcomes:

- uniform, as a mandatory separate control;
- squared-distance and cosine templates;
- linear kernel ridge at exactly 0.001, 0.01, 0.1, 1, 10 and 100.

Template and ridge winners are selected **separately**. Uniform cannot replace
either family. The objective is the mean of eight class recalls per session,
then an equal-session mean within each animal, then the equal mean of the two
animals. Confusion/support counts come from the unchanged scorer; selection
compares their rational values exactly. Ties favor squared distance over cosine
and the smaller ridge lambda. The scorer retains its own lowest-angle rule for
equal class probabilities.

Predictor exceptions, missing outputs and malformed predictions retain their
fixed query denominator and receive the existing incorrect/worst-loss treatment.
Unassignable outputs invalidate that candidate's complete episode according to
the existing scorer. Failures are not a reason to fall back to a smaller cohort.
Input loading, packet identity, calibration consistency or decoding failures
abort selection and return no completed freeze. Secondary angular/Brier results
remain the existing scorer's downstream responsibility; only balanced accuracy
selects settings here.

## Interface and freeze boundary

```python
wire = select_fold(
    private_manifest_bytes,
    expected_manifest_sha256=authenticated_projection_sha256,
    load_packet=private_training_loader,  # called only with (training_record, query_id)
    max_manifest_bytes=...,
    max_packet_bytes=...,
    max_total_packet_bytes=...,
    max_map_pixels=...,
)
descriptor = publish_freeze(wire, private_new_path,
                            expected_sha256=sha256(wire).hexdigest())
# Only after successful return may the owner deliver the outer-held packet.
```

The freeze retains the projection digest, every candidate's per-session support,
confusion and invalid counts, exact objective values, exception counts, all
dependency pins and all three required choices. It contains private training
assessment and must remain in protected owner custody. Case-time inference
receives only the selected configuration and its common nine-map packet; it
does not receive these training assessment rows or any fitted training weights.

`publish_freeze` exclusively creates a private 0400 file and fsyncs the file and
parent directory. A publication failure is not a completed freeze, even if a
partial or full file remains. The operator must preserve the failure, keep the
directory protected and withhold held-session inputs. There is no automatic
retry or overwrite. This primitive does not itself isolate processes or prevent
a privileged caller from inspecting other files.

`verify_coverage` validates exactly 48 canonical ordered record/digest
descriptors. Its explicit output flags say it has not authenticated freeze
bodies or established fresh process isolation. It is a complete roster check,
not a claim that 48 authentic selections ran. Separate fresh construction
contexts per fold/access mode and fresh inference contexts per query remain
required by the task.

## Bounds and evidence

The caller supplies positive manifest, per-packet, total-packet and pixel bounds.
The full input manifest and packet descriptor sum are admitted before loading;
packets are loaded once each. The private freeze has a fixed 1 MiB ceiling.
These are explicit application payload bounds, not a hard RAM or physical-I/O
quota. Source dependencies are bounded ordinary files authenticated by exact
extent/SHA256 before their bytes execute in private module namespaces.

The generated controls validate construction logic and faithful reuse only.
They cannot establish authentic data agreement, adequate task difficulty,
full-resolution provider delivery, model competence, or native/scientific
readiness. No canonical task/admission flags are changed by this component.
