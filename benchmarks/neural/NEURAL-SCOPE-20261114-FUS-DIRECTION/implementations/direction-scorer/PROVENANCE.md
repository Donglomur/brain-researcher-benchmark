# Sources and construction boundary

The scientific starting point is Griggs and colleagues' 2025 study,
[Functional ultrasound neuroimaging reveals mesoscopic organization of saccades
in the lateral intraparietal area](https://pmc.ncbi.nlm.nih.gov/articles/PMC12488887/).
Its measurement is cerebral blood-volume change in two male macaques performing
memory-guided saccades. This benchmark's complete eight-shot calibrated assay is
a prospective design, not the paper's selected-session performance statistic.

The factual roster is derived from the complete public
[ProjectRecord_paper.json at the selected release commit](https://github.com/wsgriggs2/PPC_directional_tuning/blob/a5571a3488b1d25e7259bccd8f3fe894b5e852bd/Project%20Records/ProjectRecord_paper.json):
12,552 bytes, SHA-256
`deb726b85aa3c8894cfebe0485ce22ceb99fa55f97c3a52a22f4e4cccabacc8d`.
The retained original was reauthenticated in this phase. `roster.py` contains
only selected factual fields and elapsed days derived from each animal's first
listed date. It is not a raw source capture or an upstream analysis-code copy.
All 49 rows remain, with 27 L/22 P rows, one L zero row, and 48 positive rows.

The selected code release is v0.0.2, commit
`a5571a3488b1d25e7259bccd8f3fe894b5e852bd`, archived at
[Zenodo 16732610](https://zenodo.org/records/16732610).
Author code is GPL-3.0; this component does not reproduce or execute its MATLAB
analysis or bundled third-party toolboxes. Data metadata identifies
[CaltechDATA p5jan-02r60](https://data.caltech.edu/records/p5jan-02r60), v0.0.1,
revision 3, CC0-1.0, one 56,527,114,780-byte archive. No archive or signal body
was acquired/read here. The authentic expanded schema remains unknown.

The current expansion registry accepts the V3 FUS contract. A separate
current-route audit checked that exact entry, contract, root registration
review, linked finite selector and delivery directory. Their remaining scorer
requirement is real; old V2 evidence and stale runtime flags were not used to
declare existing work absent. This is a bounded linked-route conclusion,
not a claim to have searched every unlinked historical file.

Generated fixtures exercise every metadata row and all 20,622 invented source
trial slots. Their cyclic directions, timing, identities, evidence digests,
predictions and exclusions are fictional control inputs. Counts do not become
observed scientific cases. No biological signals/targets, numerical-library
imports, model/API calls, fits, Docker, canonical mutation or Git action is
selected by this construction.
