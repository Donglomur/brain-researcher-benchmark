## Current neural-understanding objective

Protected source-derived matched response values and signed per-mouse FIRST-minus-REPEAT contrasts, together with exact catalogue/support/exclusion counts. The true contrast can be zero, negative, positive or unavailable; a favored novelty narrative is not ground truth.

**Source delivery:** partial\_delivery. The snapshot contains support/matching and reference-composition code, but its native source reader, response/statistical core and execution owners are omitted; operational routes explicitly refuse. The defensible target is held-mouse FIRST-versus-REPEAT response prediction under measured pre-state/history matching, with outcomes as a separate sensitivity. Exact lifetime exposure and causal novelty are not identified by the supplied variables.
