# EEG preparation source archive and generated controls

This package preserves the exact producer, resource guards and ZIP directory guard used for the local full-source DoSEI numerical preparation. The archived Python bytes retain their original hashes and historical local path constants. **The archived native CLI is environment-bound; it is not a portable public data-preparation command.** Running it would require its original private source artifacts, exact operational protocol, root admission and resource controller, which are not distributed here.

The portable part is the repository-relative generated test harness. It loads the archived producer and guards plus the sibling [numerical cores](../source-eeg-numeric-v1/README.md) and [annotation adapter](../source-annotation-events-v1/README.md) by their pinned hashes. The producer fixture uses an in-memory ZIP containing171 generated recordings,513 source rows and342 annotation events. It has no original EEG data, private clinical labels or native source access. Only the ZIP guard's expected archive-size constant is rebound to the generated bytes. The guard controls create small temporary files and generated authority dictionaries; they never construct a native `GuardContext`.

The archived producer authenticates complete member evidence and projects source rows into time, EEG and quality streams, together with private annotation events. It requires complete stream hashes and closed file signatures before member success, and all171 members before cohort success. Cumulative read/write limits, partial artifacts and failure receipts remain explicit. A parseable success file alone cannot establish successful completion: a successful observed exit, settled operation, complete receipts and absence of contradictory failure evidence are also required.

The code retains source row order, sparse measurements, exact clock duplicates and quality flags. It never interpolates, deduplicates, transforms recording IDs into biological persons or exposes these private preparation streams as participant inputs. Meaningful marker-relative packets, artifact policy, biological-person grouping, canonical scoring and AI evaluation require subsequent work.

From the repository root, the full generated controls can be invoked with standard-library Python on a POSIX platform:

```sh
python3 -I -S -B -m unittest discover -s benchmarks/neural/clinical-dosei-responsiveness/implementations/source-eeg-preparation-v1 -p 'test_eeg_*.py' -v
```

The archive uses POSIX file locks and signals; Windows compatibility is not asserted. The native environment and resource controller are intentionally not reconstructed by these generated tests. `PROVENANCE.json` records exact source pins and the limited packaging validation. The controls' original behavioral suites were already reviewed separately; the packaging check exercises repository-relative loading, source bootstrap and one complete generated171-record pipeline without repeating all unchanged groups. No original data or authentic preparation is rerun for packaging.
