# Select the stable-loss scorer in NEURAL-094's complete source

The existing stable-loss-v2 scorer fixes finite cancellation, but the published
complete regional package still selects its predecessor. This additive package
constructs an explicit successor without editing the old package or selecting a
new scientific task. Exactly one executable body changes: the already reviewed
stable-loss scorer, byte for byte. Its nested numerical, runtime, source and
origin manifests change together. The other27 Python bodies remain unchanged.

`RECIPE.json` binds the old closed source manifest, seven before/after bodies,
the reviewed scorer and the resulting closed source manifest. Authenticate this
composer and its frozen recipe independently before use. `compose()` is a pure
source-byte transformation; it refuses missing, stale or altered bodies.
`materialize()` authenticates the entire input set before copying the35 source
files to a fresh, disjoint destination. It reserves the complete output size
before the first write and retains partial failed output for inspection. Input
source is never executed or modified. No arrays or scientific data are read.

The operator supplies absolute predecessor and overlay roots, an empty successor
root, the externally selected `compose.RECIPE_PIN`, and an explicit `Budget`
for source reads, writes and wall time. Existing `operator.py inspect` works on
the new source with its separately selected manifest pin. The unchanged
`regional_runtime.materialize` can later stage the authenticated successor under
separate native admission. The recipe, source identity and inactive flags do not
constitute that admission. There is deliberately no automatic registry switch.

All39 sessions,10 mice,73 literal regions,2628 pairs, five seeds, final-choice
classes, first100ms observations, competent nuisance reference and trial-session-
mouse weighting remain unchanged. Negative, infinite and undefined effects are
retained. Direct/viewer access remains undelivered; current authentic execution,
reference fits, runtime isolation and scientific qualification remain unproved.

`test_successor.py` checks the actual published source composition, the linked
scorer's cancellation behavior, unchanged executable bodies, refusal paths, one
bounded source-only materialization and compatibility with the unchanged source
inspector. It does not repeat the existing full numerical suite or run a model.
Run through the project's existing shared generated-test pool. The test accepts
`NEURAL094_TASK_ROOT` only to locate the read-only task source during private
construction; normal repository use locates the enclosing task automatically.
No current CI enrollment or benchmark readiness is asserted by this package.
