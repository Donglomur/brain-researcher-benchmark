# Release-annotation agreement: operator scope

This separately named condition asks whether the two access procedures predict the numeric annotations stored in the complete fixed Marcotti release. It is one condition of the existing ABR benchmark, not another dataset or benchmark registration. The original calibrated expert-threshold and four-labelled-stack transfer design stays unchanged.

The complete observed target contains 936 animal-by-stimulus cases from 104 animals, 16,226 traces and 1,953 samples per trace. Existing preparation and an independent audit already established the full raw-annotation join and field separation. `EXISTING_PREPARATION.json` pins that evidence. These saved facts do not establish current protected participant access.

## Information and answers

Both access arms use the same complete per-case native observations, recorded level codes, explicit tone/click category, sample indices and raw numerical amplitude values. No resampling, physical voltage conversion, assumed acoustic origin, dropped repeats, zero-trace removal or target-label-dependent preprocessing is part of this condition. The direct viewer and programme receive the same label-free documentation and zero labelled support examples. Programmes are frozen before protected target exposure; per-case contexts and state are isolated according to the frozen execution protocol.

A viewer plot and numerical arrays have different display precision. The common underlying values and complete case coverage must match, and any plotting or serialization limits must be declared. Results from such access bundles do not isolate the causal effect of tool use. Missing original source-laboratory expert labels are not replaced with demo predictions.

Each arm supplies exactly one numeric `predicted_annotation_code` of finite binary64 magnitude for every opaque case. Every original code remains a target, including source 100; numerical 100 and 100.0 are the same answer. There is no clipping, inferred censoring, physiological unit conversion, target-derived allowable alphabet or hidden rounding tolerance. Exact agreement, averaged within each animal and then equally across all 104 animals, is primary. Absolute code distance and within-5/10 code-unit rates are descriptive secondary summaries; they are not dB errors or clinical accuracy. A missing or invalid required answer withholds aggregate scores and leaves the complete denominator visible.

## Custody and genuine completion

First finals are immutable, including invalid answers. Both complete panels must be frozen before the private annotation loader is called; no feedback or answer replacement is permitted. Scoring requires the observed roster and authentic private annotation identities, not counts alone. Public packets exclude biological identities, genotypes, filenames, threshold fields, wave1 tables and label-derived summaries. This operator document and its evidence descriptor are not candidate packets.

The portable code and generated controls can establish these software behaviors. An authentic operator must still reauthenticate the prepared files, materialize the full public projections, verify complete viewer/programme access and capacity, and enforce disjoint target custody, isolated execution and no network lookup. This source selection does not authorize those original-body operations or claim that they ran. A competent same-information baseline and waveform ablations are needed before interpreting a future gain as waveform understanding; no AI result is claimed here.

Public data exposure remains a limitation. Opaque IDs and local target-last grading cannot establish absence from model pretraining. The condition measures agreement with a released annotation encoding, not whether that encoding is a correct physiological threshold.
