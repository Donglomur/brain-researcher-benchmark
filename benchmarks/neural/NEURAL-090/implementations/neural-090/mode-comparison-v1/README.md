# Paired Broad execution-mode comparison

`comparison.compare(complete_report)` provides the missing explicit paired comparison between the existing `frozen_program` and `case_adaptive_equal_inputs_tools_compute` modes. It consumes the original closed report and compares candidate neural log loss in each of the four primary axis/budget strata. Positive `frozen_minus_adaptive` favors the adaptive mode. Negative differences remain valid. The eight original primary losses and their lower-is-better interpretation are unchanged; there is no cross-stratum scalar, new rank or pass threshold.

The consumer runs the unchanged, SHA256-pinned numerical validator over every original section: all 76,800 invocation rows, 1,200 person/seed vectors, 120 ten-seed averages, 61,440 control contrasts and 7,680 candidate/reference contrasts. Missing exposed-person or stimulus-exposed rows still prevent output. It additionally requires identical reported 39-class support for each person/chapter across every mode, track, arm, axis, budget and seed. The authentic CaptureBook already requires identical private query support across these conditions. Class-count agreement here is only a necessary scalar consistency check; it cannot authenticate event identity or replace that capture path.

Each stratum preserves 640 person/chapter/seed pairs, 320 person/seed differences, all ten seed means and all 32 person means. It averages the two fixed chapters equally within person, then people equally, then all ten seeds. Query counts never weight people. Seeds, events and the two chapter blocks are not additional biological people or independent visits. Differences use natural-log nats per prediction under the original probability transformation. The output remains a finite-cohort point report with no confidence interval, p-value or narrative-population inference. Independent reference and control estimates remain in the original full report; they are not repurposed as mode effects.

Both mode names currently use the action-capable controller. This component therefore does not establish a direct/no-tools comparison, a frozen/adaptive policy distinction, equal observations, equal resources, no leakage or authentic execution. Those require independently audited participant sources, input/resource custody and the original native owner. No task/access/readiness status is promoted. No scientific or model run was performed.

Use the operator-only CLI after complete report closure:

```sh
python3 -I -S -B comparison.py --report /operator/point-report.json --output /operator/fresh-mode-comparison.json
```

The CLI rejects duplicate JSON fields and nonfinite constants, validates the entire report before creating output and refuses overwrites. Its output binds the SHA256 and size of the exact bytes captured and parsed in one read; this does not authenticate their origin. Keep authentic reports and outputs private. The CLI loads the full JSON report and its byte snapshot in memory; trusted callers may instead provide single-pass iterable sections to `compare`, whose output explicitly has no exact input-byte hash and requires caller custody. This small generated-control fixture does not establish the memory cost of authentic list-based reports. The component adds no participant access path or private-label loader.

Generated controls, from the repository root:

```sh
python3 -I -S -B benchmarks/neural/NEURAL-090/implementations/neural-090/mode-comparison-v1/test_comparison.py
```

For a staged candidate, `--source-root` may name the existing task's `implementations/neural-090` directory for the pinned validator and existing scalar-fixture module. Set `--scratch-root` to an existing authorized scratch directory when temporary writes must stay inside a task grant; this is passed explicitly to `TemporaryDirectory` and does not depend on launcher environment handling. Controls cover full distributions, heterogeneous paired effects, unequal query counts, retained negative differences, individually valid but mismatched class counts, missing secondary/companion support, JSON ambiguity, source pin failure and non-overwriting output. All values are invented arithmetic fixtures; none demonstrate neural learning or reliable model interpretation. Authentic full-cohort preparation, native/reference qualification, direct observation delivery and scientific reasoning review remain unresolved.
