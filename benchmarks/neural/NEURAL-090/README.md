They still require authentic event/clock/source qualification. The 348-claim consumer checks arithmetic consistency only and cannot establish qualitative investigation quality. The source emits both candidate and reference self-contrasts but no safe scalar ranking rule; this revision designates absolute candidate neural loss for ranking without changing source arithmetic.
