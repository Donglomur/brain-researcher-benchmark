# NEURAL-029 executor boundary backport

This successor retains the complete retrospective registered GrC1s-to-2s
calcium-transfer task: every declared pair, registered cell, query and all
61 times; the original mouse-macro training-scale NRMSE and comparisons.
It changes no scientific module, cohort, score, access condition or task ID.
PREDECESSOR.json pins every member of the accepted original package.

Three inherited executor defects are corrected:

- Request admission used to query the private binding's link metadata before
  producer closure. It now validates the private binding and prepared private
  subtree lexically, with exactly one POSIX root anchor. Binding/tree overlap
  with programme, public tree, method/package, Docker executable/socket/config,
  output, interpreter and supplied CLI-request paths is refused before any
  executor path metadata checks. Physical private-path checks occur only after
  all owned candidate, holder and volume resources are absent.
- mkdir(mode=0755) was reduced to0700 by umask077. The new owned public staging
  directory receives an explicit chmod0755; its immutable files remain0444.
- Rejecting only PID/IPC='host' admitted container:other and unknown modes.
  IPC is explicitly requested as private. The new private PID namespace is
  requested by omitting PID inheritance; effective PidMode must be exactly the
  empty default and effective IpcMode exactly private. Both candidate and
  holder undergo these checks before start; missing modes refuse.

The trusted interpreter/source bootstrap and operator request must be admitted
independently. They are read to learn the request; a rejected declaration does
not retroactively make those already-read authority bytes blind. Lexical
separation does not establish immutable storage against a malicious operator.
No private path is resolved or probed merely to perform the separation check.

The cached-bytecode defense remains: only authenticated captured runtime bytes
are compiled, with no package import path. The original512MiB prospective
reservation,100,000,000-byte submission and128MiB volume are unchanged.

Run focused generated controls using Python -I -S -B boundary_controls.py -v,
and the unchanged cache regression using Python -I -S -B cache_regression.py.
The focused suite reuses the accepted generated inspection fixture, intercepts
private metadata/body access, checks lexical and double-root aliases, verifies
mode0755 under umask077, rejects cross-container namespaces for both roles,
and traces successful/failed cleanup through the actual executor. Native
producer and numerical grader calls are inert leaves in that ordering test;
no candidate model or scientific computation is run. Original scientific
modules and resource reservation are checked against their predecessor pins.

No actual Docker call, authentic data/target read, model/API call, native
qualification, submission readiness or new benchmark is established here.
