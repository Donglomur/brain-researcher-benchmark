# NEURAL-033: Kir and the activity–plasticity relationship

Using the supplied longitudinal spine observations, estimate whether the association between relative activity and later spine-volume change differs between control and Kir cohorts, separately for apical and basal dendrites. Report the treatment contrasts, their compartment difference, and the prescribed mouse-deletion sensitivity. A null, reversed or unidentifiable relationship is a valid outcome.

This is a new, explicitly specified investigation using Wright et al.'s released data. It is not an exact reproduction of their estimator or an estimate of a randomized treatment effect. The observed activity units have not been verified to match across cohorts; use the cohort-relative ranks below. Rank conversion does not establish that the two measurements represent an identical biological construct.

## Inputs and information boundary

`observations.json` contains all 1,936 projected rows: 1,143 control rows and 793 Kir rows, from 27 control and 17 Kir fields of view, representing 20 control and 10 Kir mice. Every row includes its source member/row index, mouse, treatment, compartment, typed baseline/followup flags, two spine volumes, and activity rate. Nonfinite source numerics are encoded as null. No row has been selected using the outcome. `identity.json` fixes row and mouse IDs and the input hash.

All these observations, including later volumes and cohort labels, are visible. This is an analysis task, not held-out outcome prediction. You may use Python and scientific libraries to analyze the public inputs. No external data is needed. The evaluator consumes only an ordinary JSON file and never imports or runs submitted code.

## Required analysis

`CONTRACT.json` is normative. Apply these rules without adjusting them after seeing results:

1. Exclude rows in this priority order: unstable baseline flag, unstable followup flag, baseline Shaft Spine, followup Shaft Spine, then invalid numeric fields in order baseline volume, followup volume, activity rate. A stable flag contains none of `New Spine`, `Eliminated Spine`, `Absent`. Preserve source membership semantics: substring membership for a string, exact element membership for list/tuple. Numeric volumes must be finite and strictly positive; activity must be finite and nonnegative. Record every excluded row and its first reason. This conditions on persistence, not survival/formation.
2. Define outcome as `log2(followup_volume) - log2(baseline_volume)`. In each treatment × compartment group, give every eligible mouse equal total initial weight and divide its weight equally over its rows. Compute weighted empirical mid-CDF ranks separately for activity and baseline volume. A tie receives `(mass_below + mass_equal/2)/total_mass`.
3. Fit the `all` panel: four separate weighted least-squares models, each with intercept, activity rank and baseline-volume rank. Report full support, normalized effective mouse count and coefficients. Require at least three rows, two mice, and three singular values with the smallest greater than `1e-10` times the largest. Otherwise report unavailable; do not regularize or use a rank-deficient pseudoinverse.
4. Fit the `balanced` panel using the same ranks. Form nine joint rank bins from fixed thirds: `[0,1/3)`, `[1/3,2/3)`, `[2/3,1]`. Within each compartment, each bin's target mass is the smaller of the two treatment-specific initial masses. Multiply row weights by target mass divided by their group's bin mass. Drop zero-weight rows and normalize weights within group. Refit without reranking. Report the nine unnormalized target masses. This balances relative distributions, not physical units; effective mouse count can decrease.
5. For both panels report Kir-minus-control activity slopes in each compartment, and apical-minus-basal difference of those contrasts. Use null when a required model is unavailable. Remove each eligible mouse jointly from both compartments, then recompute the whole panel, including ranks and BOTH cohorts' balancing weights. The deletion roster is the original eligible union of mice within each treatment, before balancing. If every required deletion is defined, jackknife variance is the sum across treatments of `(M-1)/M * sum((delete_estimate - mean_delete_estimate_for_treatment)^2)`. Report its square root and minimum/maximum deletion estimates. If any required deletion is undefined, retain the point but return null uncertainty with the appropriate status. This is an approximate diagnostic; no coverage or p-value is claimed.

Retain source row order in eligible/excluded lists and group row support; sort mouse IDs lexicographically. Order the nine matching masses by `3 * activity_bin + baseline_bin`, with each bin numbered 0, 1, 2. In the all panel, `matched_bin_mass` is an empty object. The three contrast keys are listed in `CONTRACT.json`. Undefined fits and uncertainty must follow the schema; unavailable estimates are not zero.

When fewer than three rows or two mice remain, do not compute SVD: report status `unavailable`, reason `insufficient_support`, rank 0, and null effective mouse count and coefficients. With sufficient support but deficient design, report reason `rank_deficient`, the computed rank below 3, finite effective mouse count, and null coefficients. Defined fits have rank 3 and null reason. When a point is unavailable use `point_unavailable`; when the point exists but a required deletion fails use `deletion_unavailable`. In either case all three uncertainty numbers are null. Report every mouse's deletion contrasts even if some are null.

## Submission and evaluation

Write one UTF-8 JSON artifact conforming to `submission.schema.json`, with schema version 1, task ID `NEURAL-033`, SHA256 of the exact `CONTRACT.json` bytes, SHA256 of the exact `observations.json` bytes, and the complete `analysis` object. Maximum size is 2 MiB. Duplicate keys, booleans as numbers, nonfinite numbers and incomplete source-row partitions are rejected. No executable attachment is accepted.

The primary error averages `abs(candidate-reference)/(1+abs(reference))` over defined point contrasts within each panel, then averages the two panel means equally. Both panels need a defined contrast. Missing or extra availability, or any structural discrepancy in support/counts/status, makes the primary null rather than rewarding an omission. Other numerical claims are compared as secondary diagnostics. Lower is better; no binary scientific-success threshold is defined. A perfect reconstruction score says that the prescribed analysis was implemented accurately, not that Kir has an effect or that this establishes frontier scientific understanding.

## Interpretation limits

Mice, not rows or fields of view, are the independent biological units. Some mice span both compartments; treatment IDs do not overlap. Cohort, acquisition and treatment effects can be confounded. Relative-rank slopes compare cohort-relative distributions and cannot quantify total suppression of activity by Kir. Conditioning on persistent spines excludes lost and newly formed spines. The released basal-control mouse roster differs from the published figure count; this task retains the whole release rather than inventing a reason to drop an animal. Control data overlap NEURAL-031, NEURAL-032 and PAPER-FIND-REP-012; they are not independent benchmark datasets. See `LICENSES.md` for source attribution.
