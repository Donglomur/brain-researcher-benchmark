# F01: target-specific joint-moment covariance and percentile resampling

This is an executable source proposal for the fixed 999-replicate competitor. It does not establish calibrated coverage, numerical correctness, speed, or native executability. G14, the dependency/environment gates, every complete-bank denominator and the original calibration rules remain required. The method is an approximate crossed bootstrap for nonlinear moment estimators. In particular, no exact finite-sample confidence theorem is claimed for a participation-ratio estimator, a near-zero denominator, a degenerate U statistic, a heavily weighted sample, or a sparse observed mask.

## Operative path and complete affected bank

`finite_runtime.uncertainty_plan.build` creates fixed provider definitions and exact per-case jobs from all 24 accepted keys. Its membership is the accepted reference/uncertainty catalog, not a new smaller bank. There are 108 mandatory F10 U01–03 variants and 18 F11 variants across the two trial views. U01 and U02 consume the full two-by-two covariance, including the off-diagonal term. U03 consumes all 999 ratio replicates. The already accepted U04 residual estimator and its separate development pool are unchanged.

`References.bundle` checks source, definition, complete point request, original case input, exact protocol and point-fit state before invoking `uncertainty.resample`. That dispatcher now calls `finite_science.design_resampling.resample`. Identical source/input/state/protocol/seed requests are actually executed once per bundle and their original receipt reused across U01–03. Cost belongs to that original producer; a second interval computation is still a separate consumer. There is no participant callback, supplied covariance substitute, or open-ended future algorithm recipe.

## Finite F10 population and resampling law

The original target is the fixed complete matrix with R=512 rows and C=256 columns, sampled independently without replacement along each axis. Every selected P divides R and every selected Q divides C. For the row bootstrap, form a conceptual population containing R/P distinct copies of each observed row; select P distinct copy labels uniformly without replacement from 0,...,R-1, then map label l to floor(l/(R/P)). Columns independently use the same construction with C,Q. Repeated observed values are distinct pseudo-population units. Calling the old iid multinomial sampler with a finite label would be a different method.

This pseudo-population construction is described for simple random sampling in [Statistics Canada's published methods article, section 2.4.1](https://www150.statcan.gc.ca/n1/pub/12-001-x/2018001/article/54926/02-eng.htm). Its purpose is to reproduce the without-replacement sampling structure. The two-axis extension and explicit finite-sample count calibration below are derived here; that article does not prove coverage for this benchmark's quartic moments.

Let n=P, N=R and k=N/n. The count vector D for a without-replacement draw from groups of size k is multivariate hypergeometric. It has E D_i=1, Var(D_i)=(n-1)(N-n)/(n(N-1)), and Cov(D_i,D_j)=-Var(D_i)/(n-1) for distinct i,j because its sum is fixed. Set c_n=sqrt(n(N-1)/(N(n-1))) and L_i=1+c_n(D_i-1). Direct substitution gives Var(L_i)=1-n/N and off-diagonal covariance -(1-n/N)/(n-1). Consequently, for any fixed scalar observed vector h, Var(sum_i L_i h_i/n)=(1-n/N)s_h^2/n, exactly the usual sample-based variance for the finite-population mean. This identity is about the conditional bootstrap count covariance, not equality to the unknown true finite-population variance for every possible sample.

For theta=(A,B), evaluate theta_0 on the original sample, theta_r on resampled rows only, theta_c on resampled columns only and theta_rc on their intersection, each using the same finite target sizes, exact reference variant and full aligned trial vectors. Define each replicate

    theta* = theta_0 + c_R (theta_r-theta_0)
                       + c_C (theta_c-theta_0)
                       + c_R c_C (theta_rc-theta_r-theta_c+theta_0).

For a linear matrix average this is exactly the product of the calibrated count weights. It retains row, column and interaction terms. For nonlinear HT, plug-in and shrinkage moments, it is a specified empirical resampling competitor; the count identity does not imply exact nonlinear variance or percentile coverage. The covariance estimate is the ordinary sample covariance of these 999 paired vectors, divisor 998. Gamma*=A*/B*. No intrinsic/infinite population target is substituted.

When an axis is a census, the implementation uses identity indices for that axis and its difference term is exactly zero. If both axes are censuses all replicas equal the original estimator, up to its own deterministic arithmetic. The six selected cells are non-census; the explicit boundary prevents a future with-replacement variance at complete observation. Nondivisible roster sizes are not silently rounded: this particular algorithm refuses them because they are outside the selected six-cell protocol.

## F11 known density ratios and shared-trial entry masks

The sampling unit is an entire row or column, not a scalar response or a trial. Rows are sampled independently from the shifted distribution, columns from their original distribution, and each observed row carries its fixed known target/source density ratio. The response and its mask are jointly resampled. A row index selects its ratio and all aligned trials; the column index selects every trial and the corresponding mask column. The original per-entry Bernoulli observation indicator is shared across all trials. It is neither re-generated nor imputed, and unobserved values are never consulted.

Each selected array is re-evaluated by REF11_WEIGHT_MASK with the unchanged known mask probability and fixed-tuple-count normalization. The existing optimized moment source counts distinct logical row/column/trial mask units in each product and divides by the specified joint inclusion probability. Importance factors occur once per distinct logical sampling unit in the relevant tuple. Bootstrap slot identities are distinct even when the empirical source index repeats, as in a nonparametric empirical distribution; the original source-index arrays are retained as output ancestry. This preserves the actual missingness and weight operands rather than stripping them and relabeling the complete-data estimator.

Independent row/column resampling of incomplete crossed arrays follows the strategy studied in [Owen, The pigeonhole bootstrap (2007)](https://arxiv.org/abs/0712.1111). Its mean-consistency results concern the assumptions and statistics in that paper, not a general theorem for the present weighted quartic ratio. We use it as a prespecified competitor. Its finite positive observation probability, finite relevant weighted moments and nondegenerate leading row/column projections are substantive asymptotic conditions; high leverage weights, interaction-dominated variance, degeneracy and small cell sizes can cause poor coverage. Such behavior is measured by the unchanged full calibration/evaluation procedure, not erased by a source qualification ID.

For F11 the covariance uses the 999 joint moment pairs from these weighted/masked point evaluations. U03 uses their ratios. No self-normalization, clipped weight, missing-value mean replacement, independent trial resampling, flattened-entry draw, or target change is performed. Mask probability 1 and shift 0 are supported boundary cases of this same explicitly declared family. Informative or unknown masks remain unsupported.

## Seeds, exact dependencies, status and storage

The issuer preselects a 256-bit master seed and commits the complete provider plan before any reference calibration or hidden evaluation. The fixed SHA256 domain, source identity, full point variant, opaque case ID, input identity and replicate ordinal deterministically specify every one of 999 uint64 seeds. Expansion happens at the actual job boundary, avoiding hundreds of millions of duplicated seed integers in the metadata plan. A collision is an explicit failure. Separate NumPy SeedSequence([seed,0]) and ([seed,1]) states feed PCG64 row and column generators; NumPy's exact version must match the source-qualified environment. All seeds, indices, status codes and underlying status names are retained, not just an unverified seed label.

All 999 replicates remain in the output. A nonphysical ratio is NaN in the numeric artifact, accompanied by an explicit status code. If any ratio fails, the bootstrap competitor is nonphysical; it is never estimated on a successful subset. Finite moment pairs may still identify a covariance when ratios fail, but no lost moment is replaced by zero. A missing/nonfinite moment prevents a covariance output. U01/02 can therefore have a defined joint-moment input when an ordinary ratio percentile fails, without claiming that the failed ratio succeeded. Original scientific point failures and every actual point-call status are retained. Unexpected runtime/resource errors remain job failures with original process accounting.

Indices, seeds and status vectors are numeric artifacts, not oversized JSON. The finite path makes at most 2998 point calls (one original and three per replicate); weighted and iid paths make 1000. Array writes and child CPU/RSS remain under the existing independently qualified worker monitor. Those operation counts must be included in future admission reservations and actual costs. This source build executed none of them.

## Required qualification and unchanged gaps

Qualification must compare direct and optimized estimators, check covariance symmetry/PSD and exact linear finite boundary cases, test all selected weights/masks/tuple hierarchies, and run every predeclared calibration cell and scale with the original 40/240-world rules. It must not tune scales, number of draws or seed choice on evaluation. Failed coverage is an observed ineligible competitor, not an incomplete source implementation. Infra/source failures remain an incomplete mandatory reference bank. Original final biological, LLM and figure-producer gaps remain separate and unresolved.
