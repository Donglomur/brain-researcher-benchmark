# Additive source integration

This public component lives separately at `benchmarks/scientific_contracts/cerebellar/`. It includes the exact small original scorer and requirement/notices from the existing NEURAL-030 bundle; README.md pins their provenance. The original benchmark preparer and fixed-reference fitting modules remain in `benchmarks/neuroscience/neural-030/` and are trusted operator dependencies, not candidate inputs. `candidate_views.py` uses only the standard library. `candidate_contract.py` imports that module and the existing sibling `score.py`; the latter retains its existing NumPy dependency. There is no runtime dependency on an authoring directory, new downloaded source, native MAT loader or model service.

The trusted operator's sequence is:

1. Use the existing native-binding and packet interfaces only after their genuine intake holds are resolved. Call `compile_panel(prepared_public)` to obtain all 16 cases and all four condition views.
2. Use `calibration_packet(view)` and `query_packet(view)` at separate enforced execution stages described in the contract. Supply a candidate-specific byte/resource envelope; the pure source does not choose compute defaults or launch code.
3. Compute the unchanged fixed reference privately with `reference.predict_reference(prepared_public, arm="context_handle")`. That legacy feature helper requires the full prepared object even for the context arm; do not send that object to a context-only candidate or fabricate missing neural channels. The candidate receives only the projected condition packet.
4. Collect complete response objects for all 64 case/condition combinations. Evaluate privately with `score_matched_panel(plan, expected_rows, outputs, fixed_reference_predictions=..., mouse_binding=...)`. Outputs map exactly `context_handle`, `grc`, `cf`, `joint` to lists of 16 response objects. Flatten private case `expected` rows only in the trusted evaluator.
5. If its support and execution holds are satisfied, deliver each `mismatch_query_packet(joint_view)` query packet to the same frozen joint predictor after a state-equivalent reset; keep the returned donor list private. Supply the resulting complete joint panel as optional `mismatch_outputs`. Neither re-training nor score feedback is part of that replay.

The existing `task_operator.py inspect`, canonical executor/scorer references, gates and admission flags remain untouched. This is a callable source companion, not a new runnable task or a decorative replacement entry point. This standalone component does not enter or change the existing task freeze. A later installer that exposes it through the authenticated task operator must update that task’s inventories coherently. It must not set a runtime or scientific flag merely because the functions import or invented checks pass. The root owns that separate selection and transaction.

This separate public directory contains only the reviewed original candidate modules/specification, this layout note, the exact small scorer/requirement/notice copies, a provenance README and an invented import/arithmetic smoke. The two candidate module bodies and full scientific specification are unchanged. No private authoring evidence is an execution dependency. The existing frozen task bundle and its admission state are untouched.
