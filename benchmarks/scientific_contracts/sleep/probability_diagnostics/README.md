# Sleep probability diagnostics

This additive source component measures probability quality on the same eligible epochs used by the complete sleep scorer. Its new scorer is an inactive successor; it is not installed in the accepted programme or registry.

For each person, pool all of their nights before averaging epoch losses. The multiclass Brier score is the sum of five squared probability errors, without dividing by five. Log loss is measured in nats with the fixed floor 1e-15 on the true-stage probability; the number of clipped eligible epochs is retained. Prediction rows keep the existing simplex tolerance 1e-6 and are never renormalized. Unknown/movement epochs remain part of the full clock but do not enter these numerical losses.

For each class, calibration in the large is mean predicted probability minus observed class frequency. These five marginal differences do not measure full conditional calibration, discrimination, or clinical usefulness. The panel averages each person's diagnostics with equal person weight. If required eligible support is undefined, the aggregate stays null instead of excluding that person. No confidence interval, p-value, ECE binning, model recalibration, or positive-result threshold is introduced. The standalone panel helper preserves undefined support as null. The integrated scorer preserves the original stronger completeness rule: a person with zero eligible epochs causes the entire grade to be refused before either the original or diagnostic result is returned.

The complete result has schema `neural007_full153_grade_with_probability_diagnostics_v2`. Its `grade` object preserves the original `neural007_full153_grade_v1` result. Its separate `probability_diagnostics` object has schema `neural007_full153_probability_diagnostics_v1`, the same prediction descriptor, class order W/N1/N2/N3/R, 78 people, 153 nights and the same 27 panel keys. Each panel retains per-person full-clock/eligible/masked counts, night accounting, truth counts, means, the clipping count and marginal calibration. The diagnostic truth counts must match the original person's confusion-row sums. These are consistency checks on trusted scorer products, not authentication of a candidate-supplied JSON object.

The included `predecessor/scorer.py` and `predecessor/science.py` are exact source snapshots for the invented parity and source-comparison checks. `PROVENANCE.json` records the component identities and the narrow scorer transformation. It retains the original admission and independent boundary-audit prefix byte for byte except for an inert module import. Only after that barrier does the scorer call the new numerical tail. Probability diagnostics accumulate in the existing pass over admitted probabilities and private targets; they add no label read or prediction-file pass. The original confusion/argmax calculations and six original contrasts are unchanged. Future actual execution still needs the complete programme's existing source, grants, provenance, capacity and scientific review. Added arithmetic cost has not been measured on authentic inputs.

The source-only controls execute the actual predecessor and successor numerical tails with explicitly invented readers and the accepted pure metric functions. They verify identical original grades on the complete 2,106-row/27-panel/78-person/153-night shape for both workflow profiles. They do not replay the outer transport, native input decoding or custody boundary. The unchanged prefix is separately compared exactly. Other controls cover analytic losses, masking, zero probabilities, unequal night counts, missing support, invalid inputs and detached results.
