# Required genuine mapping, not a fabricated NWB schema

`load_population` requires a complete61-file/15-mouse release roster, exact local bytes/SHA256 and a disposition per asset. Source identity is checked on the opened file before decoding; an immutable isolated input mount remains a required deployment producer. The mapper does not discover assets or download data.

Each recording map binds exact source hash and its own canonical JSON digest. `mouse_path` and `session_path` select scalar identities. `trials`, `stimuli`, and each plane's `roi_table` are explicit columns with unique native row IDs. Column descriptors supply literal path/owner_path/owner_object_id,shape,dtype,max_bytes and kind(text,integer,number,time). Time columns also require positive affine clock_scale,clock_offset,output_unit=seconds and clock_evidence. No units or clock transforms are inferred from equal array shapes. Exposure/support intervals must conservatively include clock error; this cannot be established by a user-supplied boolean.

Required trial columns:trial_id,block_id,epoch,start,stop,go,move_onset,contact,direction,previous_direction,previous_reward,history_speed,history_end,regular_reward,onset_method. Onset method must be tracking_tongue_onset. A missing onset-producing tracking path is a real admission gap. Grid metadata supplies exact physical-layout identity,shape and ordered class names. It must demonstrate cross-recording equivalence before labels are joined.

Each plane binds its response series, native ROI DynamicTableRegion and referred table object_id, full ROI row order, explicit(time,roi)axes, source unit/conversion/offset, and canonicaldff units. ROI columns contain roi_id,x/y/z inµm,qc_keep and independently defined atlas_bin. QC provenance must be segmentation-only. Four clock columns exposure_start/end and support_start/end, a source-derived artifact mask and a genuinely observed movement column are required. No guessed frame rate, inferred orientation or default zero movement is permitted. Full ROI row-index bounds and referenced table identity are checked.

Cross-epoch cell_links bind cell_id,behavior_roi,rest_roi,baseline_roi and actual identity evidence; each triple is(epoch,plane,ROIid). Baseline epoch must precede stimulation and contain no stimulation. Target metadata binds target_id,position,cell_id ornull,condition,classification_basis and evidence. A target lacking valid behavioral cell identity cannot acquire invented tuning. Stimulus columns include stim_id,epoch,on/off,target_id,power_mw,condition,block_id,movement,assignment_probability. Conditions distinguish neuron_target,nonresponding_site,true_sham. The actual assignment-probability producer is still absent; the reader never promotes metadata into causal authority.

This is an implemented explicit mapping reader with genuine mapping inputs missing, not a verified NWB→DataJoint adapter. The public scripts do not include the original conversion, table definitions, optical artifact mask, epoch link producer or movement-onset producer. Those omissions remain visible gates.
