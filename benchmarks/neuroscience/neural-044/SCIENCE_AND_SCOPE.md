# Scientific design and source limits

Two existing assignments, NEURAL-043 and NEURAL-044, share one loader and one public release. They are distinct prediction and investigation questions. The two arms, class layouts, mice, sessions, folds, controls, and sensitivity analyses do not increase the task count.

The public peer-review file describes randomized target switching at192ms, and a baseline-rest→stimulation-rest→behavior sequence. Neither description establishes every actual release field or assignment probability. DANDI descriptive metadata covers61 files,15 subjects,44,969,345,792 bytes. ## NEURAL-043

Primary: whole repeated-target blocks held out within a recording, with immediately adjacent blocks embargoed. A separate held-mouse track requires externally established anatomical feature alignment and the entire mouse's sessions held out. Both use tracking-defined onset, a fixed[-0.5,-0.1]s interval and only exposures whose complete preprocessing support lies inside it. The evaluation is retrospective onset-aligned decoding, not an online prediction of future onset. First contact and go cue are never accepted as movement onset. Unknown preprocessing reach or unknown onset lineage refuses admission.

4×4 and5×5 target layouts retain full distinct class spaces; missing training directions and unsupported anatomical bins are explicit non-estimable dispositions. Never silently merge target labels, interpolate unseen neurons, use test-mouse tuning for alignment, select cells by test outcomes, or normalize on evaluation data. Segmentation-only ROI QC is required. Prior-direction/reward and movement history must end before the neural window. Public packets use keyed opaque IDs and contain no current target-coded event, raw source ID, future timestamp or query label.

References: smoothed training class prior, training-only history/time logistic regression, neural logistic regression, neural+history/time regression, and a deterministic whole-block label-rotation diagnostic. C=1 is a fixed prospective reference choice, not the paper's missing decoder or a tuned result. Train scalers only on the training view. F/I views have the same public packet, tools, limits and no evaluator feedback; no test-batch adaptation is enabled. The actual isolated provider is not implemented or admitted by this scientific package.

Grading joins exact IDs/classes, validates complete probability simplices, pools held-out predictions within each mouse before class recall, and reports mouse-macro balanced accuracy/log loss per class-space/claim. Missing test-class coverage remains visible. Approximate t intervals use mouse units; one mouse gets no population interval. Constant valid predictions remain scoreable controls. There is no fabricated chance-adjusted success or reference score.

## NEURAL-044

Primary estimand: conditional tuning–response association; responding/nonresponding-site class comparison is observational, even when target sequence is randomized. Verify the actual full assignment schedule and probabilities before any randomized causal claim. No claim of monosynaptic connection strength or random allocation of response-defined classes is made.

Tuning uses regular-reward behavior trials from named non-test blocks; all directions must be represented. Rest/behavior/baseline cell identity requires an explicit crosswalk. Baseline activity comes from a separately mapped prestimulation-rest epoch, not the mean of the stimulation response. The root-selected prospective tuning window is contact-aligned[0,1)seconds, with full support. It includes postcontact and reward-related activity; it is not pure directional/motor tuning or a causal mediator. The historical DataJoint tuning window remains unknown, and the prospective window is not represented as its reproduction.

Reference response estimation retains the complete stimulus sequence and every target×power×condition stratum, with10 prespecified100ms lag bins through1s, an intercept, drift and genuinely measured movement covariates. Stimulus overlap is modeled jointly; no isolated pre/post pulse approximation is used. Artifact and temporal-support masks are obligatory. Fixed ridge regularization stabilizes an associational model; rank, condition number and whether the unregularized coefficients are identifiable are reported. A rank-deficient model is not evidence of identified individual causal effects. Native feasibility, RAM and solve cost are unmeasured; a declared full-design cap refuses rather than subsamples.

The effect source reports unadjusted and distance/baseline/movement/power-adjusted coefficients per mouse, held-mouse response-model improvement with mouse-unit aggregation, and high/low tuning matched contrasts. For each held mouse, other mice supply equal-mouse-weight empirical quartiles and0.2SD calipers. Boundaries are high>=Q75, low<=Q25, caliper distances<=1; tied quartiles are non-estimable, zero spread demands exact equality. Greedy match ties resolve by source row order, no stochastic draw. Distance strata are[25,50),[50,100),[100,250], and>250µm. All proximal/direct targets, missing identities/tuning/baselines, unsupported strata and unmatched rows remain dispositioned.

Controls include future-stimulus lead association, within-distance tuning rotation, distinct response-selected-site sensitivity, distance strata, and true-sham availability. Deterministic rotations are diagnostics, not randomization p-values. A nonresponding control site never substitutes for an absent true sham. Unknown or absent control data are not converted into zero effects. Separate held-response prediction packets withhold held-mouse response signals; the executable effect-reconstruction channel is not a shortcut into that prediction channel.

No numerical/scientific method has been executed. Reference outcomes, robustness, estimator calibration, null calibration, external replication and publication claims remain open.
