# BaRISTA source distinctions and unresolved branches

Primary manuscript: https://arxiv.org/html/2512.12135v1 (NeurIPS 2025; local SHA256 427c56188d6d0e2ef416a21fff14480fc1da84935118e567fecdeeac15253b07). Canonical task: PAPER-paper-method-replacement-008. This is one paper project, not a collection of extra task IDs.

The paper uses ten clinical participants and 26 Brain Treebank recordings. Table5 divides them into17 pretraining recordings, two downstream validation recordings and seven downstream test recordings. Standard pretraining includes downstream people. Session labels in the paper are ordinal; raw dataset trial numbers are not universally contiguous (subject6 has trial000, trial001 and trial004). The exact source config must resolve that join. Neither PopT's19-pretraining roster nor its clean contact list can be substituted: BaRISTA Table9 has151 contacts for subject4 and134 for subject6, after ventricular exclusions, versus152/135 in PopT.

Main classification compares nine independently pretrained encoding/masking combinations (channel, parcel and lobe on each axis), three spatial random-initialization controls, PopT+BrainBERT, and Brant. Tables1/2 require seven sessions, two tasks and five finetuning seeds per model. Native reported mean/SEM pools35 session-seed AUCs; a seven-person hierarchical summary would be a separately labeled prospective statistic. The native significance claims are not automatically re-established by an AUC scorer.

The main segments are three seconds/6144 samples at2048Hz, nonoverlapping, with80/10/10 random splits after class balancing. Sentence-onset and speech positives are word-centered. Negatives require silence over the whole three seconds, unlike PopT's center-second rule. Whole-segment z-scoring and centered windows are offline operations; they do not establish online causal decoding. Exact label/event clocks, nonoverlap selection, native sample intervals, source split and channel/region joins require authentic input validation.

AppendixK repeats all nine scale combinations and three random-initialization controls plus PopT and Brant on four tasks: sentence onset, speech/nonspeech, volume and optical flow. Five chronological folds allow overlap within partitions but must prevent neural context overlap across train/validation/test. Every model shares the same selected identities. Published summaries pool175 session-fold-seed AUCs; the extra repeats are not175 independent people. Whole-model pretraining exposure, preprocessing support and event clocks remain separate leakage issues. Volume/flow use source quartile labeling, whose exact row-order/tie semantics require executable source.

Brant uses the author's pretrained model and resamples6144 samples to1500. The paper re-pretrained PopT and checked its original task performance; a generic public checkpoint is not automatically that comparator. Training schedules differ across models, so native comparison is not an equal-compute experiment. Exact checkpoint hashes, upstream data exposure, executed seed/fold/configuration identities, comparator schedules and predictions are unavailable here. A candidate-supplied model name or weak comparator does not demonstrate improvement.

Reconstruction is a required separate full-paper endpoint: all seven held-out sessions, every channel masked in turn, one finetuning seed,20epochs, nine encoding/masking models and three spatial random-initialization controls. Predicted masked tokens map to512-sample temporal patches. Observed-token reconstruction is only a training auxiliary. The manuscript does not uniquely freeze channel/session weighting or R² SST/flattening conventions; do not infer R²=1−MSE from rounded table values. Savitzky–Golay smoothing in Figure4 is visualization-only. The exact segment producer must also resolve AppendixA's 'same pretraining segments' wording against held-out reconstruction cases. The separately supplied source-amended reconstruction reference and MSE scorer are documented in ../../reference/PAPER_AND_REFERENCE.md; neither recovers historical H or R².

Other required branches remain distinct: multiple pretraining seeds (AppendixF), held-person-out pretraining, pretraining-data scaling with five subsets per percentage, attention/interpretation, spectral reconstruction analysis and temporal/spatiotemporal architectural ablations. Main classification source implementation does not complete these or reproduce the full paper.

This source construction does not run authentic neural preprocessing, model fitting/inference, reference computation or scientific grading. All missing raw inputs, model assets, native configuration/exposure, numerical references and execution-isolation evidence remain explicit blockers.

Do not execute the unchanged example as a complete or compatible paper configuration.

run_finetune_random_splits.sh fixes default finetuning seeds0…4. Its five logical seed slots are bound to those exact integers here. The now-held chronological launcher confirms the same default0…4 integers; actual historical execution/configuration/fold identities remain unverified. Splitter uses its own fixed seed0 by default; training seed is not automatically a new random source partition.

The chronological notebook builds5% buckets by **metadata row index/count**, not elapsed recording seconds, and uses labels to find validation/test-containing buckets. It returns multiple train/val/test interval arrangements; there is no random replacement with physical80%/90% times. Its builder can reference an uninitialized found_ind if no eligible window is found. The trusted adapter must preserve saved authentic folds and validate every native sample interval. The current strict constructor refuses any cross-partition interval overlap; it does not silently purge or repair source folds. Exact native split compatibility, including behavior at adjacent overlapping word-centered segments, is not established.

Volume/optical-flow labels use np.quantile at .25/.75 on non-NaN feature values, with inclusive bottom/top comparisons; top assignment occurs last when both thresholds coincide. This differs from PopT's rank-sliced quartiles. Raw features undergo dropna before trigger-aligned sample mapping. Authentic source annotations and mapping are missing here, so these rules are not recreated from an arbitrary normalized label array.

Filtering uses six causal lfilter notch operations at60–360Hz and then Laplacian rereferencing against separately filtered neighbors. Whole segments are independently transformed by sklearn StandardScaler across their6144 time samples. This gives centered offline input; it does not establish causal target prediction. Source clean-electrode ordering and original HDF5 column ordering must be reconciled explicitly before claiming normalized input compatibility. The primitive adapter preserves supplied float32/64 segment values; it does not recompute normalization or silently change precision.

The released aggregate_runs.py is a convenience log-table formatter: it accepts incomplete logs, computes population standard deviation within available seeds, rounds cells to three decimals and averages those rounded strings. It does **not** implement the full manuscript's35/175-cell mean±SEM calculation. This benchmark keeps every unrounded cell and uses explicit sample-SD/sqrt(n) SEM on the manuscript's stated pooling unit. Exact historical SEM implementation is unconfirmed; this is a disclosed numerical reporting convention, not recovered hidden analysis code. No p-value, ANOVA or significance replay is claimed.

The completed source closure resolves several implementation facts without running them. train.py uses class1 softmax probabilities, sklearn ROC-AUC, ordinary loss.backward(), AdamW and validation-AUC checkpoint selection. The chronological launcher confirms force_nonoverlap=False and seeds0…4. data.check_no_common_segment checks path sets, not sample-interval support. The collator skips all-zero tensors, so raw-source compatibility must explicitly reconcile support before a query roster is frozen; no such arrays were examined here. Fixed metadata shuffle uses random_state42. Rounded printed AUCs are not a per-query artifact, and no authenticated probability exporter is present. The selected full repository still does not provide executable original pretraining/reconstruction/comparator branches sufficient for full-paper parity; source closure does not fill these by inference.

Native run_epoch converts AUC failures to NaN. finetune_model always saves the first epoch when best_state is None; if that validation AUC is NaN, later finite values do not compare greater than NaN, so the saved state stays at epoch1. The source is preserved unchanged. A faithful reference must disclose this behavior and establish finite validation support/logs before calling its state the best finite-validation checkpoint; silently fixing it is a separate method change. The all-zero collator can also fail on an entirely empty batch; test drop_last=False alone does not establish full support.

The native source config specifies30epochs, AdamW rates1e-4 upstream/1e-3 new head, weight decay.01 and frozen pretrained tokenizer. These are source facts, not measured run properties.
