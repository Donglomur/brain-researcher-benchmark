# BaRISTA source-amended benchmark

This source package retains 85 current ordinary roles for one paper project, PAPER-paper-method-replacement-008. classification/ contains the full main and chronological tasks, fourteen source models, both access arms, full-support scoring and the complete original-source role map. reconstruction/source contains the complete seven-person masked-channel MSE/export contract. reference/ supplies an explicitly source-amended concrete F/G/H training/query/export route: seven people, 945 channels, twelve models, both arms, 168 cells and 22,680 output matrices.

The historical H, original R² and other historical execution claims are not recovered. Pretraining, held-person-out/scaling/interpretation/ablations and authentic execution remain required; the full paper remains incomplete and scientifically unqualified. No registration or qualification delta follows from source publication.

Read SOURCE_ACCESS.md before use. Operator helpers are separate from staged candidate inputs; the classification/private directory contains ordinary protected operator source, not credentials or private participant data. Only a fresh per-context/model/arm view may be exposed to a candidate. Paper/data/weights remain external descriptors.

Authored benchmark code and public metadata are under AUTHORED_LICENSE.txt. Original BaRISTA portions retain their USC educational/research/non-profit terms, with commercial permission separate. Third-party portions retain their own terms in THIRD_PARTY.md and classification/source/notices/. No blanket MIT grant covers upstream code.
