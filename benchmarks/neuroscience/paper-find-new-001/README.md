# Astrocyte sequence reconstruction: local scoring component

This package is a **verified local scoring adapter**. Eight artifact/boundary controls and the actual interrupted-wrapper fixture passed; all five containers and three activated process groups were removed. It accepts one finished directory of 42 numerical artifacts for the already declared 21-record source-recipe reconstruction. It does not execute submitted programs, grade open-ended paper interpretation, compare code-access conditions, evaluate improvement, or reproduce the whole paper.

The associated paper assignment is PAPER-FIND-NEW-001. The scientific component is the source-ordering statistic for Figure 4a–c of the assigned 25 May 2026 preprint, DOI 10.1101/2024.09.06.611660, with later disclosed data/code versions. Eighteen finite and three insufficient-event outcomes are the existing reference; the 21 records cover 14 mice and are not 21 independent benchmarks. Null/cohort tests and their published discrepancies remain outside this scoring component.

`public_contract.json` discloses the exact source-prefix policy, 28-second event window, 420-point interpolation grid, post-event normalization, ordering convention, all output names, structural rules and tolerances. It intentionally defines a prescribed reconstruction control. Other paper-consistent methods need a separate method-neutral scientific evaluator. Matching a headline correlation without the required input-derived intermediates does not pass.

Use the common scoring command:

```sh
python3 tools/neurobench.py score PAPER-FIND-NEW-001 \
  --submission /absolute/finished-output-directory \
  --output /absolute/repository/artifacts-build/new-scoring-run
```

The output path must be a fresh path under the local repository's `artifacts-build` directory. The task currently depends on pinned existing observations and cached wheels in this operator workspace. It is not a portable release bundle. The command uses only an opaque immutable snapshot of the submitted files; no candidate code is imported on the host or in the grader.

The trusted grader reuses the unchanged qualified scientific verifier, event parser and transport reader. It runs offline, nonroot, with a read-only root and exact individual file binds, two CPUs and 3 GiB total memory. The same previously qualified NumPy 1.26.4/SciPy 1.15.3 environment is reconstructed from 13 already cached wheels in an ephemeral overlay; no dependency download or image pull is allowed. The source order/tie convention must not silently change to the base image's NumPy 2.2.6.

All required files are checked against the 26 MB aggregate cap before copying. The full snapshot is parsed and structurally validated before any observation arrays are decoded. Each case is then independently recalculated. The numerical result is 1 only when all 21 required source-recipe dispositions and intermediates verify, and 0 for a structurally admissible but incorrect reconstruction. Invalid submissions and numerical-review cases have no automatic numerical score. Per-case outcomes preserve all cases; insufficient-event outcomes do not become finite correlations.
