# Complete NEURAL-073 source

## Scientific scope

The fixed catalogue contains 9,532 records from 13 people, with 25 declared protocol labels and 300 available person/protocol cells. All records remain required, including 57 sub-08 records with unresolved producer lineage. The 234 contexts are 13 held people × three data conditions × two analysis arms × three repetitions. They are repeated conditions of one task.

The primary metric averages record accuracy within each available person/protocol cell, then across available protocols for that person, then equally across all 13 people. Brier scoring uses the same weights. All declared predictions, failures, original captures, references and full outputs are required. The independent nuisance, neural and joint references include all 353 configurations, 55,068 inner fits and 455 outer fits. Source-only construction has not performed these fits.

F authors and freezes its complete prediction program before query access. I investigates the permitted batch using the same scientific ceilings. Original arrays, spatially scrambled arrays and nuisance descriptors distinguish several explanations for performance. Public data, acquisition structure, memorization and unresolved lineage limit inference; label accuracy alone does not establish native neural understanding, causal validity, frontier improvement or SOTA.

## Inspect the source

Keep the 130 files under `full-catalogue-v1/` byte-for-byte unchanged, with their relative names. [PUBLIC_SOURCE_INDEX.json](PUBLIC_SOURCE_INDEX.json) pins the complete package. Documentation here sits outside the closed package; do not put extra files or generated caches inside it. `SOURCE_FREEZE.json`, `CODE_CLOSURE.json`, `PARENT_CLOSURE.json`, `TASK.json` and `DEPLOYMENT.json` bind its own source graph. The package needs no private planning checkout or shared WORK registry for standalone inspection.

Replace `ABS_PYTHON` and `ABS_CHECKOUT` with explicit absolute paths. This is a source-inspection recipe, not a scientific run:

```text
ABS_PYTHON -I -S -B ABS_CHECKOUT/benchmarks/neuroscience/neural-073/full-catalogue-v1/run.py inspect
  --deployment ABS_CHECKOUT/benchmarks/neuroscience/neural-073/full-catalogue-v1/DEPLOYMENT.json
  --deployment-sha256 652b2d0194e61a74ade38e8e77bd0958b5cd2ddb7ea8954dbadade0f3b150b3f
```

The wrapped command above is one argv sequence. The inspector checks source/deployment identities and reports unconfigured, source-only, unqualified status. It opens no external deployment section, key, array, model or native binary. Retain its actual stdout, stderr and exit when you run it; this release audit inspected the source and has not executed this command. Inspection does not provide an independent trust anchor or an operational qualification.

## What an executable deployment still requires

The initial deployment has seven null external sections and execution disabled. An operator must provide independently authenticated trust-anchor, numerical-runtime, corpus, host/tool, provider, capacity and private-output sections. The actual consumers and [DEPLOYMENT_SCHEMA.json](full-catalogue-v1/static/DEPLOYMENT_SCHEMA.json) define them. External private records, credentials, models and arrays are absent from this source distribution.

Original NIfTI conversion and producer fidelity are an explicit missing input-production dependency. The canonical corpus must contain every frozen record, its actual geometry and exact float64 body identity, full cross-person duplicate screening and provenance. Public catalogue metadata cannot replace a neural array or prove a faithful conversion. The stricter original-producer/FFX provenance profile remains unresolved where independent evidence is absent.

The authentic runtime entry fixes Python 3.11, NumPy 2.4.6 and five API Python-source identities. It requires a separately selected, independently authenticated native-host contract containing the actual extension, METADATA and RECORD pins. That native-host contract and its qualification evidence are not supplied here. Historical engineering bindings separately retain observed Darwin extension identities and two known RECORD alternatives; those engineering bindings do not qualify an authentic deployment. These are source-defined constraints, not an installation recommendation or measured native compatibility. No wheel, environment installation or empirical compatibility result is bundled. The host contracts additionally require the selected namespace/process, privileged OOM witness, custody and output guarantees.

Actual operator admission must prove all ten original-body/producer/rights/identity/geometry/native/OOM/provider/capacity/output gates, then create a fresh source-bound deployment and execution selection. All context ceilings and whole-invocation costs remain cumulative. The 64 GiB RSS and 512 GiB writable per-context ceilings in TASK.json are limits, not measured requirements or evidence that a machine can run the complete study. A consumed invocation cannot be silently retried or adopted.

Read [OPERATOR.md](full-catalogue-v1/static/OPERATOR.md), [OUTPUT_CONTRACT.json](full-catalogue-v1/static/OUTPUT_CONTRACT.json) and the exact callable source before configuring an instance. Complete protected scoring independently joins the full original run; caller-supplied score scalars are insufficient.

## Provenance and reuse

The catalogue is frozen public metadata from [NeuroVault collection 6618](https://neurovault.org/collections/6618/), associated with [Pinho et al. (2020)](https://doi.org/10.1038/s41597-020-00670-4). It pools release sources; the benchmark is explicitly conditional declared-catalogue recovery. No newly fetched map or altered catalogue was used for this release.

The package preserves all 89 accepted parent source bodies, plus the complete portable orchestration, admission, transforms, references, provider transport, evidence and scoring source. Historical source bodies remain marked history and cannot be selected as operative constructors. `SOURCE_PROPOSAL.json` and source-origin path strings are inert source descriptors; they are not permissions to follow private paths.

See [RIGHTS_AND_PROVENANCE.md](RIGHTS_AND_PROVENANCE.md). Source availability, installed registry state, qualified execution and scientific results are separate stages.
