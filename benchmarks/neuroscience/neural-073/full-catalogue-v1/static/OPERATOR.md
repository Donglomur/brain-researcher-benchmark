It does not open external section bodies, private keys, neural arrays, model files, captures or native binaries. SOURCE_PROPOSAL.json is a downstream preferred interface. Relocation strips only F's declared package prefix onto this explicit package directory; there is no dependency on a private planning checkout, WORK file or globally installed task.
