# Operator bridge and exposure specification

The bridge is a qualified *derivative*, not a downloaded dataset or a new gold definition. The operator must produce it from authenticated complete original observations with an exact reviewed transformation program. A hash supplied without its source evidence is not scientific qualification. No such bridge, original arrays, or private reference exists in this package.

`neuroformer_qualified_bridge_v1` contains `closed_operator_exclusive:true`, `source_roster_sha256`, `transformation_program_sha256`, `original_inputs` and `recordings`. Each original identity has `source_id,bytes,sha256`. Each recording has `id,animal,cohort,neurons,ticks,neural_tick_us,behavior_tick_us,event_definition_sha256,class_map_sha256,source_ids,arrays`. All identities and hashes are mandatory. `source_ids` must join the complete original roster; two names or two cerebral regions do not by themselves establish independent mice. All original records needed for the selected panel must be present, including any genuinely new held sessions.

Safe numeric arrays are C-order NPY v1/v2 with exact relative path, bytes, SHA256, dtype and shape. Neural inferred-event counts are little-endian int32 `[T,C]`, withC1,905 medial or2,022 lateral andT divisible by10. Speed is float64 `[T/10,1]`; exact original25-class labels are int32 `[T/10,1]`; video is uint8 `[T/10,H,W]`; lateral gaze is float64 `[T/10,2]`. Medial gaze is not invented. A5ms neural tick and50ms behavior/frame tick are the deliberately explicit derivative ABI, not evidence that the advertised10ms rate file has that resolution. Source-derived events must not be mislabeled as electrophysiological spike ground truth. Unit ordering/correspondence, finite ranges, class mapping, source clock and any physical↔normalized value transformation require retained source qualification. In particular, unknown class edges must not be estimated from the held-out data.

The private query fixes both native cohorts, exact full output shapes, shared support plans, source/preprocessing/reference hashes and the *exact bridge digest*. Each support row binds an opaque window ID to its recording/animal,5ms tick interval and complete receptive-field start, with a train/validation/test designation. Source-split conditions record their historical exposure; their chronology and normalization are not presumed leakage-resistant. Blocked and held-session policies enforce disjoint full receptive fields. The extra session conditions additionally require disjoint recording IDs across the three partitions, with independently authenticated biological/session identities and a defensible unit/feature correspondence. These identities are currently missing; the code does not manufacture them.

All methods within a baseline/ablation family require identical ordered support rows. The1%/10% label sets are nested, matched between pretrained/scratch arms and use the same validation/test rows as the full-speed condition. That is a prospective matched-artifact convention; the original draw/seed/denominator and pretraining exposure must still be recovered. Shared support plans prevent repeated large metadata bodies for every method.

For generation, current neural truth is never an input. Each contiguous test segment gets one true150ms initial neural history only if that interval intersects **none** of the assessed test blocks. Subsequent history is generated by the candidate. Arbitrary gaps cannot be used to reveal prior test targets through a new true-history seed. The case metadata exposes segment offsets, not the original trial/recording IDs. Video and declared behavioral covariates remain distinct from the withheld neural target. Behavior decoding admits the full50ms current neural block, so it is not a claim of streaming causality.

The separate prospective pretraining helper supplies only neural/video rows from the blocked-plan training partition. It exposes no speed/gaze labels and no validation/test observations. It does not reconstruct native author pretraining. Separate isolated execution is required for each case/method; otherwise a program can carry labels from another view. Static projections and operator-only file modes do not establish that isolation.

`prepare.py` authenticates input arrays and exact identity/support joins, then precomputes all serialized metadata sizes. It publishes QUERY/TARGET/output-index only after validation and the COMPLETE marker last. Query SHA is independently selected by the operator; its bridge digest prevents a self-rehashed substitute TARGET from changing source-array identities. `stage.py` plans exact NPY and all document/VIEW bytes before source-array reads and before output creation, then captures bounded whole-view bytes. Budget the corresponding RAM; no full authentic packet has been staged.

Candidate files are fixed-path, full-support non-object NPYs. The scorer captures and validates all files sequentially into a fresh private store before the first target-loader call. Later mutation of candidate originals cannot affect grading. The full private query is not a candidate input: only a label-free output index and one case projection are released. Independent reference metrics come solely from operator-bound artifacts, never from the candidate's claimed baseline. No tolerance, binary reward or complete-paper assertion is derived from these checks.
