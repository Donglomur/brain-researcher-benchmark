# Neuroformer benchmark source (unfinished)

This package preserves all 71 reviewed source roles for one neuroscience paper assignment. It is an unfinished research benchmark source package: 46 case slots, 85 condition cells and all seven wider paper families remain explicit, and none is scientifically qualified or submission-ready. Source files and condition cells are not additional benchmarks.

The full paper + data versus paper + data + official code comparison is retained. The public release contains source and contracts only. The required paper identity is external; no paper body, neural observations, held-out answers, trained weights, numerical results, private build history or source archive is bundled. Data terms, complete cohorts, source/run mapping, native runtime, isolation and independent references remain unresolved.

Start with source/public/TASK.md, source/public/PACKAGE.md and source/operator/RUN_COMPOSITION.md. The operator directory contains source code and empty templates, not private targets or observations. PUBLIC_SCOPE.json is the complete current scope. Original 10 ms source conditions, source-amended protected conditions and prospective 5 ms conditions remain distinct; known historical defects are preserved.

All 26 original official scientific bodies are preserved. 24 files are byte-identical; simulation.py and utils.py only gain licensing comments. The source readers verify the distributed bytes and recover/authenticate the exact original SHA256/Git blobs before original-definition compilation. The code-access staging function carries every additional notice with the official code. No original model module is imported by source verification.

Third-party terms and attribution are in source/public/official_code/THIRD_PARTY_NOTICES.md and adjacent LICENSE-*.txt files; exact primary references are in UPSTREAM_RIGHTS.json. Publicly released upstream machine/conda paths and legacy launch defects remain unchanged original-source evidence, not usable local configuration. Historical nested Drive locators were replaced by the pinned official acquisition entry; no current dataset availability is asserted.

The root repository MIT license applies to original benchmark wrappers; it does not override third-party source, paper, data or weight terms. No environment installation, data fetch, native/model run, scoring study or central registration follows from this source release.
