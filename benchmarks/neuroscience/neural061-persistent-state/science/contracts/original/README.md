# NEURAL-061 — regional predictive contribution

This is a new, inactive source construction for the existing canonical NEURAL-061 assignment. It asks whether a recorded region supplies predictive information beyond equally sized, firing-rate- and quality-matched co-recorded neural populations. It supplies scientific programme and scorer source. No data packet, installed native environment, model result, scientific qualification, central registration, or additional benchmark ID is supplied.

The current candidate requires a different whole-source review. `SCIENTIFIC_CONTRACT.md` fixes the proposed study. `API.md` specifies the real preparation, participant, reference, controller and grading calls. `NATIVE_CONTRACT.md` identifies the missing launcher/capture/isolation/observer implementations and their obligations. These are implementation gaps as well as qualification gates; matching source hashes or supplying a correctly shaped dictionary cannot satisfy them.

The complete scope is 423 source sessions from 126 source animals and 29 evaluation sessions from 13 disjoint animals; all nine declared readouts; every member of a prior, complete Beryl grey-matter ontology roster; three unit budgets; ten matching seeds; real and within-stratum shuffled anatomy; six neural arms; and twelve F/I, T0/T1, repeated candidate panels. A separately fitted reference graph accompanies all cells. Matching seeds, regions, probes and sessions do not create independent animals or additional benchmarks. Exact job and storage counts depend on the still-unacquired original ontology/corpus and must be materialized before execution, not guessed here.

The candidate contains snapshots of the selected ordinary N058, N059 and BrainWide S8 source contexts. They establish source facts and prior limitations; they are not N061 acceptance or runtime authority. Primary upstream source originals are retained outside this repository in `/private/tmp/neural061-primary-source-20261110`; the provenance manifest records their exact identity and public URLs. No embedded data, header, model, credential, cohort, cache, or private runtime aliases were followed.

All scientific algorithms remain unexecuted. Only Python parsing and small structural/control-flow checks are eligible in this construction phase. The package is suitable for independent source review, not for a claim of 200 ready benchmarks.
