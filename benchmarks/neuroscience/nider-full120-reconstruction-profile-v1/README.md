# NIDER full120 reconstruction profile

This package publishes the source and task specification for one scoped, method-assisted neuroscience reproduction profile. An owner must provide authorized assets and private evaluation bindings. It is **not a fully provisioned benchmark or an isolated candidate runner**. No paper, workbook, official R script, authentic answer, private reference, runtime image or owner key is included.

The paper is *Emotion regulation capacity lacks a shared neural signature*, DOI [10.1038/s41586-026-11203-1](https://doi.org/10.1038/s41586-026-11203-1). Task identity: `PAPER-EXP-20261113-003`; profile: `nider-full120-original-with-existing12-procedure-v1`.

The participant writes a program that reproduces three correlation meta-analyses. Both information conditions provide the same paper, data and detailed method specification. B additionally receives the exact official R source and its license. A is method-assisted; privileged compiled-method engineering fixtures are not evidence of an independent or source-free model result. See [participant/TASK.md](participant/TASK.md).

## What is evaluated

| Scope | Defined result |
| --- | --- |
| Original input, 120 fields | 27 source-reporting-precision quantities; 21 exact integer counts; 72 continuous-error diagnostics without a binary threshold |
| Original plus three hypothetical inputs | The same frozen program must emit all120 fields for each case. The existing12-field projection is scored on all four cases. |
| Remaining hypothetical quantities | 108 fields per hypothetical case are validated and retained, but unscored. |

There is **no overall120-field binary scientific pass**. Exact reporting boundaries and undefined values are not automatic agreements. N is the author's sample-size sum, not verified unique participants; source labels do not establish cohort independence. The Fisher-z/native-table scale ambiguity remains explicit in METHODS.md. The four cases are one profile, not four empirical benchmarks.

## Included source

- `comparator/`: a complete standard-library owner-side comparator for an already frozen JSON result and a privately supplied, authenticated reference. Exit0 means the comparison completed, not scientific success.
- `runtime/`: unchanged exact-number validation, original reporting/coarse-procedure scoring, the full120-to12 projection, and a pure inert-image build-plan constructor. The directory does not contain an admitted runtime, container launcher or public owner authority.
- `participant/`: task, method assistance, data/output schemas and source-label conventions. These are specifications of a future provisioned task; paths such as `/input/study.xlsx` do not exist merely because this package is present.
- `templates/OWNER_LOCK.example.json`: deliberately non-runnable placeholders for the standalone comparator's private owner lock. It is not the protected runner's owner configuration.
- `tests/`: invented source/interface controls only. They do not execute R, Docker, statistical fits or an LLM and do not use authentic data or answers. Their status is reported by the executing CI/run, not assumed from source publication.

The unchanged `runtime/full120_output.py` constant `ORIGINAL` is the identity of the public original **input workbook**, not an expected-answer identity. For the original it validates the source-workbook identity; the projected12-field response separately binds the delivered XLSX. Derivatives bind their own delivered workbook. Genuine reference hashes and owner runtime policies remain private.

Read [PROVISIONING.md](PROVISIONING.md) before using the comparator or constructing a benchmark run. The current private inert-image44-control attempt was refused before dispatch by a memory guard; all44 remain unrun. The earlier corrected portable51-control result and accepted local scientific evidence do not establish the new inert-image/runtime provisioning or an external Linux ARM64 run.

The separate whole-paper leave-one-study/cohort contract, frontier improvement experiments and LLM campaign are broader work. They are not claimed here and do not redefine this existing narrower profile. Publishing source changes neither the number of empirical datasets nor submission-ready benchmarks.
