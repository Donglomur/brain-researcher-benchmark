# NEURAL-062 public source — inactive and incomplete

This package exposes the complete installed source-role closure for the prospective Allen Visual Behavior image-identity benchmark. All 23 Python files (22 original modules plus the operator), all 28 original code/contract roles and their SOURCE_LOCK are unchanged. Public provenance and registration metadata are explicit projections, not copies of private construction records. All 21 qualification gates remain open. No fit, prediction, scientific score, container or authentic-data check is claimed by this publication.

The full scope remains 107 mice, 703 sessions and 1,936 experiment planes, with 73 training, 15 protected validation and 19 protected test mice. There are 136 mouse/image-set/context cases, four panels, three owners (participant, fixed logistic, fixed HGB), two F/I modes, 3,264 cells and 6,528 phases. Mouse is the independent statistical unit; unsupported contexts remain null. The primary endpoint is protected test CHANGE/POST mouse-macro balanced accuracy. Log loss, controls and paired mouse differences against both references remain explicit.

Read source/public/PROTOCOL.json and TASK.md for the retained scientific condition, PHASE_API.md and ACCESS_MATRIX.json for its current two-phase F/I extension, and OPERATOR_API.json for the actual trusted operator interface. TASK.md, input.schema.json, input_allowlist.json and reference_program.py retain the legacy combined-view/artifact interface; PHASE_API.md, phase_views.py and reference_phase.py define the full programme's separated FIT/INFER route. These are distinct source interfaces, not a claim that the legacy combined view is delivered in every phase.

The source/private directory contains publicly inspectable evaluator/operator code, not private inputs. Publication of that source does not add it to a participant's allowed runtime view. FIT may see training rows/labels/opaque training-mouse groups; INFER sees only its query features and opaque row IDs. Protected cohort identities, targets, cross-case data, credentials and feedback remain unavailable. All cells must be admitted and all phases retired before protected evaluation. Public release data and known split recipes do not constitute a secret evaluation set; exposure and leakage qualification remain open.

operator.py delegates to the actual full programme. It requires externally admitted source inputs, a genuine independent key/grant, a qualified environment and complete limits. The public manifest therefore has no central program_execution entry, no native activation and no run/score readiness. Library requirements include Python, NumPy, h5py, cryptography, Docker/host support and the exact reference scikit-learn version declared in source; none is installed or qualified by this export. There is no automatic acquisition, issuer, environment, model/provider or capacity supplied here.

See EXTERNAL_INPUTS.md for the exact missing cohort identity and source acquisition prerequisites. In particular, metadata.py intentionally preserves one already-public dataset asset identifier and size override; this publication makes no claim that every asset identifier is absent or that older Git history was erased. No roster, acquisition URL, authentic input/header, prepared array, credential, learned state, private review or tool history is included.

SOURCE_FREEZE.json binds public package contents except itself and manifest.json. manifest.json binds that freeze. CANONICAL_SPEC.json equals the separate public canonical record. INSTALLED_SOURCE_RESOLUTION.json binds the unchanged original roles using public-relative paths; ACCEPTED_SOURCE_MANIFEST.json retains their exact identities and external cohort requirement. These are source provenance checks, not live authority or evidence of a completed benchmark.
