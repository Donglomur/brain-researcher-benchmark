# NEURAL-062 — image identity on held-out mice

Predict which of eight flashed images produced each observation in Allen Visual Behavior optical physiology v1.1.0. This prospective construction condition uses fixed population summaries of the published dF/F, preceding locomotion/pupil summaries and declared recording context. It tests closed-vocabulary decoding on new mice. Image identities are shared between training and held mice within image sets A/B/G/H; it does **not** test classification of globally unseen image classes. Source G/H also share some images. This is one canonical assignment, separate from NEURAL-063 omission-response prediction on the same cohort.

The full published cohort is retained: 1,936 experiments, 703 sessions, 107 mice, all four projects, all active/passive sessions and all experience levels. All recordings, containers and registered cell lineages of a mouse share its split. A fixed hash within Cre line assigns 73 training, 15 validation and 19 test mice. Nothing is fit or selected on validation/test mice. There are 136 held-mouse × image-set × CHANGE/REPEAT cases and four arms per case. Every case and arm is required, including an empty probability list when no common-support observations exist.

The representation deliberately avoids pretending neurons are aligned across mice. For every native-clock 250 ms bin, average each published source-valid ROI over its samples, then take the mean, population SD and 10th/25th/50th/75th/90th percentiles across that fixed ROI set. PRE has bins [−.50,−.25), [−.25,0); POST has [.05,.30), [.30,.55) seconds relative to source image onset. No interpolation, new filtering or new baseline correction is performed. Missing coverage or any invalid value in the fixed ROI set makes that entire window missing; the event remains. The two windows give 14 features each. The release's preprocessing and dF/F estimation are historical; these windows do not establish causal availability or physiological response latency.

CONTEXT has preceding running/pupil means and coverage, missingness, the same PRE/POST availability flags as every arm, and Cre/area/experience/passive/depth/indicator/project covariates. PRE, POST and PRE_POST add their named neural windows, yielding 32/46/46/60 predictors. Controls can expose source acquisition/quality context; missingness can itself carry information. PRE contains carryover from earlier flashes and is an important diagnostic, not a blank neural baseline. No current or previous image names, presentation order/clock, mouse/session/cell identity, lick/reward/response outcomes or future behavior are provided in a candidate view. POST features and their missingness are post-stimulus offline observations.

Use the supplied training rows and labels to output eight probabilities for each query row. A view contains only `VIEW.json`, `train.npy` and `query.npy`. Training matrices append integer class index and positive sample weight to the feature columns; query matrices contain features only. Column names and exact file identities are in the view. The class dictionary is fixed within each image set and represented as indices 0–7. It is not a supplied empirical answer key. NPY inputs are C-order little-endian float32, allow NaN only as missing features, and are pinned. Artifacts must satisfy `submission.schema.json`; the runtime also enforces an eight-way simplex, exact opaque query IDs, case/arm identity and current generation. See `input.schema.json` and `PROTOCOL.json`.

Evaluation matches within experiment × CHANGE/REPEAT × fixed pre-onset running bin. Only strata containing all eight image classes enter metrics. This conditions the endpoint on observed common support; it does not equalize all unmeasured behavior. Unsupported strata/experiments are counted, never substituted. Class means are averaged equally across supported bins, then supported experiments, image sets within mouse, and mice. If any held mouse/image-set case has no support, that context's full aggregate is null. The primary artifact score is test-mouse-macro POST balanced accuracy on CHANGE trials. Log loss and REPEAT metrics are also reported. All 1,936 source experiments remain in the census, including experiments that contribute no matched stratum.

CONTEXT/PRE comparisons and PRE_POST results are descriptive. Candidates control their comparison outputs; captured files cannot prove a fair common fitting budget, and a candidate could degrade a comparator. Their signed gains are therefore not qualified improvement rankings. Different arm dimensions, limited nuisance measurements, repeated images, prior neural activity, experience and passive/active context prevent claims of unique visual information or causal image effects. Negative and zero gains are valid outcomes. Mouse SE is descriptive, conditional on one split and shared training set; it is not a calibrated confidence interval or a measure of all item/session dependence.

The fixed reference program performs training-only median imputation, weighted standardization and multinomial logistic regression. It is supplied source, not a source-author trained decoder or a benchmark score. Its numerical execution has not been qualified. Any tuning must use training mice only; this condition's supplied program does none. A frozen candidate must run in fresh isolated per-case/per-arm invocations with only the allowed view and public contract/code. Other cases, raw NWBs, full metadata, plans/references, cross-case state, network and evaluator feedback are prohibited. The package does not supply or verify such an execution sandbox.

This is **partial construction**: all authentic neural/behavior payloads and prepared views/targets are absent. Metadata and bounded structural headers exist; those do not verify full-payload schema, event support, source timing/units, numerical runtime or scientific accuracy. No empirical fit or score has been run. The original broad optical decoder objective is not declared complete by these source artifacts.
