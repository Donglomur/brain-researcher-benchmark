# One held-source-animal prediction fold

This folder contains one public fold only. `fold.json` gives a training table with response_target and an assessment table without responses. Preserve exact `(asset_id,cue_event_row0)` keys; asset_id is the unchanged source asset UUID (called asset_uuid descriptively elsewhere). Event rows are original zero-based log indices, not contiguous trial numbers. The held source animal appears only in assessment rows. Use no files, prior predictions or learned state from another fold. A future program experiment must freeze source before any labels or feedback and reset each fold's process and writable storage. This packet alone does not establish that isolation.

The target is the previously accepted time-weighted mean of stored dF/F in the physical half-open cue window [cue, cue+0.5s), minus the time-weighted mean in [cue−0.5s,cue). Each mean uses the actual observed first-to-last sample span and trapezoidal weighting. It is not a nominal-span AUC or percent conversion. The eligibility mask was frozen from timestamps before amplitude access; do not change it or drop difficult assessment identities. Stored fluorescence was already processed across its session upstream. This is retrospective prediction, not future-data-free forecasting or native raw-signal understanding.

Features are asset/event identity, source animal, spacing condition (60s/600s), sex (F/M), recorded day and split ordinal, observed released-log cumulative seconds E and delivered count N. E/N do not establish complete lifetime experience. Missing-lick and missed-fiber identities remain unresolved; no lick adjustment, anatomy inference, source-ID exclusion or causal interpretation is authorized. Stable IDs are legitimate inputs but can permit memorized responses because the development data and reference history are exposed. Fresh fold isolation does not erase that exposure or make a new biological cohort.

The declared day/split vocabularies come from all original event features, including timestamp-ineligible rows, and are independent of target amplitudes. Use training responses only for fitting and response normalization. Do not treat supplied assessment features as labels or fit normalization using held targets. A candidate may use any allowed predictor; the existing reference comparisons are five precisely specified procedures, not proofs of conditional information beyond nuisance.

The reference constant is the animal-equal weighted mean of training targets. The fixed ridge procedures use intercept, condition600, sexFemale, day indicators except the first declared level, split indicators except the first, optionally E, N or both. Feature means/RMS scales are unweighted training-only; constant columns use safe scale 1. Target mean/SD use per-row weights 1/(training rows of that animal), normalized by total weights. All nonintercept coefficients, including nuisance indicators, are penalized with lambda 1; intercept is unpenalized. Exact constant training targets take the constant path. Added features can redistribute nuisance shrinkage, so differences are performance contrasts among these regularized predictors, not identified distinct information. No fitting or expected-prediction construction occurs in packet preparation.

`training_control=original` supplies accepted labels. `within_animal_forward_one` is one fixed developer diagnostic: within each training animal sort by asset_id UTF-8 bytes then cue_event_row0, and replace each row's target by the next sorted row's target, wrapping once. Assessment features and private assessment targets are unchanged. This preserves each training animal's target multiset. It tests recomputation only for a declared known algorithm; arbitrary predictors may validly ignore training labels. No alternative shift is selected if separation is inconclusive.

Neither tag contains full-target, reference, prior-score or operator-provenance hashes. These two identities have distinct scopes and must not be substituted for the registered all-panel scorer fingerprint, which remains operator-only.
