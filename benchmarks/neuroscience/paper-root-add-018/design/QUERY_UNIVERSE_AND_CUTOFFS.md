# Target-independent prospective queries

This is a normative design, not an implementation. It repairs OFC-D03 for I_A and I_B and for every qualified comparator. Reproduction remains a separate historical lane. `FAMILY_SCORE_CONTRACTS.json` and `SCORE_AND_DISPOSITION_POLICY.md` define complete-support scores.

## Behavior universe and timing

An operator-signed administrative event ledger fixes session/trial identities, trial order, training stage and recorded start/fixation/wait-start events. It is separate from the private outcome ledger. Eligibility is determined from permitted administrative information and training-prefix evidence. The chronological 60/20/20 original-trial-index split is the prospective design choice; its test interval is fixed before candidate execution. Native expert selection using next-session performance cannot enter this eligibility rule.

For each selected test session, issue exactly one prediction request for **every trial in the fixed test interval that reaches the recorded start of waiting**. The cutoff is side reward-port LED onset after successful fixation, immediately before any delay-period observation. A fixation violation completed before that cutoff has no wait-start event and therefore no query; its disposition is recorded in the administrative universe. No catch, reward delivery, opt-out, timeout, actual wait duration, future violation or later success flag is consulted to select a query. In particular, both rewarded and unrewarded trials generate queries, even though only the predeclared unrewarded scoring subset supplies the waiting endpoint. The same full universe is used for all candidates and references.

Allowed query fields are contract/arm/lane/family IDs; opaque rat/session/trial/query tokens drawn independently of outcomes; mechanical trial ordinal; current offered physical volume and common ordinal mapping; fixed wait-limit policy T=100 s; relative event time at the cutoff; and a canonical chronological stream of permitted events whose observation times are at or before the cutoff. Prior outcomes and elapsed waiting can be included only after they have become observable in a later trial. Do not expose current/future block labels, catch allocation, scheduled reward delay, delivery/omission flag, actual wait duration, opt-out/timeout indicator, scoring mask/weight, or native performance-derived cohort labels. Protected outcome roles must not appear in paths, token prefixes, missing fields, padding, error messages or receipt lengths.

The public `query_universe` manifest has the full administrative key roster, order, version and availability rules only. For behavior, order is fixed session/rat token order followed by original trial ordinal. It contains no outcome-conditioned cardinalities or per-query eligibility-to-score flags. A separately sealed operator `target_roster` binds the same query keys to private future outcomes, target dispositions, scoring masks and fixed weights. Private target identity is retained in the operator ledger; no public hash of low-entropy outcomes is supplied. The target roster and mask are committed before candidate predictions and are joined only after the collector has closed **all required predictions for all compared methods and arms**, including predictions on unscored queries.

The trusted host renders the public query from the administrative ledger and permitted prefix; the candidate cannot supply or alter its cutoff. Before running a query, the host records query identity, public payload identity, permitted-observation watermark, source/build/model/stream identity and attempt policy. After prediction it seals the bounded response and original process status. An outcome cannot change current query scheduling, display timing, quotas or time budget. Offline playback uses host scheduling independent of current outcome rather than real waiting duration. No mask-specific retry is permitted. Failure to return even an unscored query invalidates the behavior family; reward/catch membership therefore cannot be inferred from whether omissions are tolerated. All current-trial outcomes remain private until the required closure; later naturally observable prior events in independent chronological streams are allowed only through the declared watermark.

The required counterfactual source/host control fixes the administrative ledger, permitted history at a query cutoff, candidate source/model and scheduling seed, then changes only unobservable current/future outcome assignments. The visible query presence, order, cardinality, field schema/values, public identity and scheduling/resource/receipt format must remain identical. This is a noninterference requirement conditional on the same permitted past; it does not require hiding legitimately observed prior events from later trials. The control must also inspect the complete exported roster for filtering by catch/timeout, not merely compare one rendered payload. If a task ever intentionally reveals a catch-conditioned role, that would be a separately named task/estimand, not this pre-wait prediction family.

## Neural and decoder universes

The neural primary fixes training-prefix eligible sessions/units and every 50-ms bin in the declared held-time test intervals. Do not choose bins/neurons by test firing, future stability, activity or candidate performance. All required query keys and equal-bin→neuron→session→rat weights are sealed independently of predictions. Target-neuron training observations may fit its loading, but its entire test stream is withheld in its own isolated process. Current peer neurons are permitted; no current/future target observations, future peer bins, centered smoothing or whole-trial future summary is permitted. Shared fitted state is read-only; mutable filtering state cannot cross target-neuron streams. This is conditional reconstruction on held time, not never-trained-neuron generalization or forecasting.

The reward-decoder family uses a **separate neural-only interface**: no current offered volume, tone identity, reward amount, true block or behavior-derived label proxy is passed as a covariate to latent learning or decoder prediction. Fixed relative event timestamps/window definitions may be supplied, but target reward classes are private in test. Train labels are allowed only in the declared supervised probe, after the neural transform is fitted from permitted training activity; validation controls regularization. Test windows and query order are selected from the administrative event ledger, not balanced by privately dropping or resampling classes. Predictions use only neural observations available through each window cutoff. The five-class balance is performed in the private scoring weights, not through a label-revealing test query schedule. Native 10-fold full-session decoding remains a separate historical analysis.

Association/MI products carry every prespecified session/time key and filtered-latent watermark; block labels remain private to the test association grader. They cannot orient signs, select a latent coordinate, choose support or fit an unsupervised test representation. Complete original simulation case IDs are opaque and mechanism-independent in I; all 200 cases are issued. Truth parameters/mechanism and fixed recovery support stay private. Native R products retain full historical labels while never entering the I context.

## Complete protected handoff

The operator manifest joins public universe and private target roster by immutable IDs, contract version and source-compatible input version. Actual submitted source→build→fit→sealed model→query execution→complete collector seal is reverified by the separate grader. The grader alone opens the protected target/reference roles, recomputes dispositions and exact weights, writes family score records and binds the final report. The assembler rejects mixed-source, mixed-model, mixed-universe, mixed-split or mixed-reference products. Separate grading is intentional; no participant process receives targets or a private grading callback.

Missing cutoff semantics, administrative/outcome separation, authentic time-limit binding or complete independently generated targets/reference values remains an open qualification gate. An API document cannot certify those facts. No queries, fixtures, target bodies or predictions were generated in this phase.
