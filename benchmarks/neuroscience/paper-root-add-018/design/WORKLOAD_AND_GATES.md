# Workload, unresolved gates and qualification sequence — S2

These are source-derived workload counts and proposed scheduling boundaries. They are not measured runtimes, downloaded-byte claims or ready-to-run resource requests. No authentic data or native program was executed.

## Full workload

- Behavior has 349 rats in two historical roles (expert and first 15 eligible training sessions), not 698 independent rats. Main expert and supplemental novice sigmoid loops each request six fits per rat ×50 starts: at most 104,700 optimizer starts per role, 209,400 combined before skips. Preserve skipped/failing fits. Source: `plotFigure1_expertBeh.m:120–149`; `plotFigureS9_naiveBehSupp.m:79–110`.
- The S2 source contains 50 explicit rat indices, two model families ×two reward representations ×four transitions ×50 starts: 40,000 requested sigmoid starts. This is the source's fixed subset, not a newly sampled cohort. S2 Methods separately discuss alpha .15/.30/.45; this producer fixes .15. That discrepancy remains a gate, not an invented factor sweep. Reproducing the entire behavioral model family also includes the all-rat simulations and historical-noise outputs before the sigmoid subset.
- Nine paired muscimol animals require complete condition/session products, three alternative-model pairs, history regressions and acute physiology for the separate animal. Their source numerical workloads are small relative to latent fitting, but their scientific mapping cannot be replaced with one aggregate ratio.
- TCA rank selection requires 20 ranks ×10 initializations ×two expert/naive groups =400 fits. A separately repeated final rank-8 fit adds ten per group (=20); seed-exact reuse is permissible only if shown equivalent to the native call path. Missing naive rank-output production and dependencies remain gates. Input tensors retain all eligible neurons, five events and three block levels. Source windows comprise three [-1,1] and two [-1,.8] windows at .05 s; Methods says [-1,1] for all. Exact indexing and tensor geometry are verified later against authentic arrays, never assumed from these symbolic counts.
- Native hLDS/MI roles cite 58 expert and 42 naive sessions, distinct from 96 naive behavioral recording sessions. One fitted session model can support multiple held-neuron queries when its parameters are legitimately shared read-only. Each target-neuron stream remains isolated. Original held-time fold count, restart count and ordinary-LDS dimension are unbound; do not invent a native runtime from 100 sessions alone.
- Native MI nominally requires 100 session estimates ×1,000 label shuffles. This is a paper-derived workload expectation, not proof that every session is eligible for every other neural role. Native block decoding is five-fold; reward SVM decoding is ten-fold with balanced five-class 250-ms features. Both need actual producer closure.
- Simulation recovery requires all 200 original cases (100 additive, 100 divisive), with complete fit/truth/ATI products. Native generator distributions, geometry, seeds and fitted comparison models are missing gates. A small toy generator cannot qualify this obligation.
- Event-response significance includes four alignments ×pre/post ×all declared bins ×1,000 native resamples for each required group; the source has nonstandard sampling semantics recorded separately. d-prime uses 15 bias-shuffle iterations per balanced group. Preserve per-event/session/neuron denominators and stochastic failures.
- Four matched conditions multiply submitted-program investigation costs, not scientific task counts. Do not cross every possible hyperparameter, source condition, split, model and seed into an uncontrolled Cartesian product. Predeclare a finite selection budget, paired seeds and a measured full-cohort resource envelope during future native qualification.

## Resource policy

Stage by immutable role-specific input manifests and stream by session. Keep behavior, expert neural, naive neural, other-area controls, muscimol, TCA and simulations separately addressable. A design estimate for linear latent work scales with observed time×neurons and time×latent-state matrix operations; resident memory depends on time×neurons plus state covariances and native EM storage. Dense MATLAB intermediates and TCA may dominate. These are scaling relationships, not promised GB or minutes. Record actual compressed/uncompressed sizes and peak resident memory in a later authorized input/qualification phase; never infer them from archive file counts. Preserve scientifically complete cohorts when streaming. Partial pilot runs, if separately selected, cannot be called full-paper qualification.

Do not start downloads, native runs, package installs or model execution under this design authorization. Future scheduling should first resolve producer and cohort gates with bounded source-only work. Only after review should authentic resource envelopes and controlled execution be selected. Existing user preference is benchmark building, not uncontrolled benchmark model runs.

G06: Resolve or explicitly preserve each source/Methods discrepancy in `SOURCE_DISCREPANCIES.json`; native reproduction and corrected prospective estimands must remain distinguishable. This includes the corrected signed permutation role/null/mask interpretation and native muscimol distance mutation. No hidden repair or false exact-paper claim.

G07: Independently qualify original and prospective baselines, seeds, tolerances, scientific effect thresholds, multiplicity and full role denominators. Paper p-values are not private targets; frozen independent numerical products are required. Qualify the complete administrative query universe, 100-s restricted-wait clock, all-five-class support, full ATI support, typed failure/censoring rules and fixed weights; unavailable support is required-unscorable, never silently removed.

G08: Implement and independently review arbitrary participant source execution, fit lineage, time/condition isolation, sealed collection, private grading and complete report assembly. This proposal contains interfaces only.

G09: Execute the declared adversarial/positive controls and full authentic cohort products within measured resources; publish all failures/attempts and paired uncertainty. No current fixture or runtime evidence satisfies this gate.

G10: Independent scientific/API peer acceptance of the complete design, then explicit selection of bounded next work. Design acceptance itself does not install code, change the task count or qualify science.

All gates are open in this design; source evidence may partially support a gate without completing it. A missing supplement or native producer is a blocker to a full-paper claim, not grounds to redefine the paper as the old 48 behavior curves.

## S2 workload implications

Behavior execution covers the full pre-wait administrative universe, not only the smaller private catch-scored subset. Every reference executes that same universe, and all responses close before scoring-mask joins. Neural target streams and neural-only decoder windows remain separately isolated. TCA provenance retains pre-assignment matrices and full default-zero masks without changing ranks, cohorts or fit counts. Acute physiology retains each row before/after source mutations and every bin/fit failure. Simulation recovery still requires exactly100+100 original cases. Byte/time/RSS costs of these additional products remain unmeasured; qualification must budget full rosters without shrinking scientific support. All10 gates remain open.
