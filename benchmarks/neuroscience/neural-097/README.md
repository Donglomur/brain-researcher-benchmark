# NEURAL-097: task-irrelevant stimulus-content decoding

This package supplies a canonical registration and direct source adapters for the existing MEG benchmark. The selected public predecessor does not include the central campaign engines; central integration is unavailable until those engines are separately published and reviewed. It preserves all 33 people, 66 person/image folds, five feature arms, A/B access, F/I mode, three fixed seeds, 3,960 candidate attempts, 1,650 reference attempts, and 12 interpretations. There is one canonical benchmark. The four named conditions are partial contributions, never four new benchmarks.

The full-cogitate-meg-v1 directory retains all 41 runtime roles in the existing public namespace. Scientific methods are preserved; provenance, the exact metadata loader and source locks use the explicit public projection. The existing protected-roster adapter remains in place. It remains deployment-disabled. Registration, source hashes and metadata checks do not close the 22 scientific/runtime gates. Unrestricted Python no-query-fit, common-method conformity and dynamic-operation accounting remain unresolved semantic qualifications. Native cohort, source, event, time-axis, preprocessing, numerical reference, exposure and empirical/rubric qualification also remain open.

## Routes

- `run.py --program PROGRAMME_DESCRIPTOR --output FRESH_DIRECTORY --review PROTECTED_REVIEW --other-reserve-bytes N [--condition complete|A-F|A-I|B-F|B-I]` forwards to the original candidate stage. Complete runs and grades all 3,960 attempts after prerequisites. A named condition produces only a NAMED_CONTRIBUTION; all three seeds and five arms remain.
- `score.py --submission PROGRAMME_DESCRIPTOR --output FRESH_DIRECTORY --review PROTECTED_REVIEW --other-reserve-bytes N` forwards to the original assemble stage. The submission operand is the original programme descriptor, not a prediction file. The protected review binds the four contribution artifacts. Their unique full 3,960-attempt union and original process closures must pass before private target access. This route preserves the original report; it creates no substitute scalar reward.
- `operator.py --stage STAGE --program PROGRAMME_DESCRIPTOR --output FRESH_DIRECTORY --review PROTECTED_REVIEW --other-reserve-bytes N` exposes every original stage: prepare, references, candidate, assemble, interpretation and final-report. Only candidate accepts a non-complete condition.

The operational dependency order is preparation and separate reference qualification, candidate completion or all four contributions, protected whole report, aggregate-only interpretations, and blinded final-report collection. None is fabricated automatically. The complete default candidate run needs earlier preparation/reference/exposure/runtime authority. `OPERATOR_ROUTES.json` states the original artifact and caller joins.

Any future central integration still requires their original campaign admission and separate passing runtime/scorer verification. No such receipts are included. The protected review must also satisfy the central 32,768-byte envelope, a tighter central bound than the original entry's 2 MB read cap; full authentic feasibility is unmeasured. Oversize reviews fail rather than being shortened or granted a new cap.

The adapter reads only its exact source lock and 41 source members before invoking the original entry. This is source integrity, not authority or measurement of original IO. Later qualification must account for this 382,150-byte payload read and filesystem/runtime overhead under the actual common launch budget. No scientific library is imported by adapter validation. Package copying does not install dependencies, expose protected capabilities, launch a child, or mutate the accepted source.

Only full-cogitate-meg-v1/public/TASK.md and full-cogitate-meg-v1/public/SUBMISSION.md are participant instructions. Runtime contracts, protected source rosters, original evidence aliases, private target joins, review inputs and operator artifacts are not candidate mounts. PINS.original pins each current portable body; PINS.source_identity separately preserves the immutable pre-projection source digest. Unbundled source identifiers are documentary identities, never filesystem aliases or permission to read an external body. No original data, header, checkpoint, key, private Table25 or N098 source is delivered.

Source and scientific reports remain separate: COMPLETE_REPORT.json retains H01–H05, paired-person operands/support, all seeds, nulls, failures and costs. BLINDED_REPORT_COLLECTION.json preserves the twelve interpretation outcomes and private rubric joins. No combined prediction/interpretation score, significance claim, population inference or scientific result is produced by packaging.

This is a complete public source candidate pending a different whole public-byte/consumer review. It adds one canonical registration for the already existing NEURAL-097 assignment; it is not a new scientific method. Source dependency closure is distinct from protected runtime inputs, native qualification and readiness. See full-cogitate-meg-v1/SOURCE_PROVENANCE.json and PROTECTED_INPUTS.md in that directory.

The direct adapter source is self-contained within this package apart from the standard library and the explicitly declared, uninstalled scientific/native dependencies. Their absence prevents a claim of public central-runner integration; it does not grant a bypass of campaign admission, review bounds or qualification.
