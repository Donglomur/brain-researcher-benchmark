# Three neuroscience construction drafts

Snapshot: **14 November 2026**. The programme registers **208 contracts/drafts: 106 paper and 102 neural**. **Zero are scientifically qualified or submission-ready.** This snapshot updates draft registration, not earlier package or interface counts. It adds three specifications to the [previous expansion registry](../expansion-20261113/registry.json).

| Track | Draft | Intended evaluation |
| --- | --- | --- |
| Paper research | [Cortical consensus](tasks/cortical-consensus.json) | Reproduce held-neuron prediction and assess improvement under a separate protected protocol. |
| Neural data | [Patch-identified neuron localization](tasks/patch-neuron-localization.json) | Localize an identified extracellular spike source under channel degradation. |
| Paper research | [StructuredExperience](tasks/structured-experience.json) | Reproduce MEC within/across-context time-decoding results, then improve held-trial decoding with unseen-mouse policy transfer and within-session calibration. |

StructuredExperience covers the stated 13 sessions from eight mice, with 40 half-second time bins and ten trial-grouped folds. Paper plus data and the same inputs plus official code are information conditions of one task. The prospective improvement score gives each mouse equal weight; it does not treat repeated sessions, cells, folds or overlapping leave-one-mouse-out results as independent biological observations.

The new design retains unresolved paper/source timing conventions, all-unit-zero-event trial support, code rights, authentic data admission, fresh numerical references, protected execution and scorer qualification. The published session-level test and a prospective mouse-level evaluation are separate claims. Inactive instruction text is included for review; it grants no access to owner-only answers or reference caches.

The Consensus and localization specifications retain their exact previously published file identities. They reflect their registration-stage evidence, including outstanding implementation and source questions; this snapshot does not rewrite their contracts or imply those tasks are ready.

All three designs identify their paper, repository revision and data accession. Public availability does not demonstrate absence from model training. Conditions, folds and controls do not add benchmarks. No scientific data, official source code, weights, private answers, model comparison or SOTA result is included.

[Machine-readable registry](registry.json) records counts and specification identities. Reference construction, competent baselines, protected evaluation and independent scientific qualification remain required.
