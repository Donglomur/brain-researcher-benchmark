# Two neuroscience construction drafts

Snapshot: **14 November 2026**. The programme now registers **207 contracts/drafts: 105 paper and 102 neural**. **Zero are scientifically qualified or submission-ready.** This draft-registration snapshot does not refresh earlier package or interface counts. It adds two reviewed specifications to the [previous expansion registry](../expansion-20261113/registry.json); it supplies no runnable tasks, scientific data, fitted weights or answer arrays.

| Track | Draft | Intended evaluation |
| --- | --- | --- |
| Paper research | [Cortical consensus](tasks/cortical-consensus.json) | Reproduce held-neuron prediction in a two-area cortical model, then assess predictive improvement under a separately frozen protocol. |
| Neural data | [Patch-identified neuron localization](tasks/patch-neuron-localization.json) | Localize an identified extracellular spike source and quantify accuracy under channel degradation. |

The paper task compares paper plus data against the same inputs plus official code. Historical model selection used held-out likelihood and an other-trial PSTH; prospective improvement therefore requires separate nested splits, training-only eligibility and baselines, and protected final assessment. Better prediction alone does not establish the paper’s mechanistic interpretation.

The neural task compares case investigation with a frozen prediction program, with official-code access as a separate factor. Its reference locations are approximate, and 11 selected recording pairs are not necessarily 11 independent animals. Missing dependencies and the active callgraph of a truth-conditioned retry helper require resolution before reference qualification. This specification reflects the accepted contract at registration; subsequent investigations need separate reviewed evidence.

Both specifications link exact paper, repository revision and data accessions. They preserve complete-support requirements, information boundaries, grouped uncertainty and unresolved construction gates. Public source availability does not imply clean training-unseen evaluation. Conditions, folds, cells and controls do not add benchmarks.

[Machine-readable registry](registry.json) records the counts and file identities. Data admission, licensed source staging, native references, scorer and runner implementation, and protected evaluation remain required. No model comparison or SOTA result is reported here.
