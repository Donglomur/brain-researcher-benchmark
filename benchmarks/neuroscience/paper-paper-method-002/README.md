# Jaxley full-paper benchmark source

This source package covers the proposed reproduction and improvement benchmark for [Jaxley: differentiable simulation enables large-scale training of detailed biophysical models of neural dynamics](https://www.nature.com/articles/s41592-025-02895-w), Nature Methods (2025). It is one existing paper assignment with 36 complete families and 144 condition-family jobs: paper + data or paper + data + official code, each for reproduction and improvement. Jobs and files are not separate benchmarks.

All 67 scientific source roles are retained byte-for-byte. The source implements the full reference-capture route and preserves the complete scientific population and output contracts. It does not yet implement a complete participant grader. All 21 qualification gates remain open, and generic run/score remain disabled. No scientific benchmark result or improvement claim is established by publication.

From the repository root, inspect ordinary source without reading scientific inputs or running a model:

```sh
python3 -I -B benchmarks/neuroscience/paper-paper-method-002/operator.py --inspect
```

The future protected route is the same script with `--run` and all four exact `--configuration-root`, `--configuration-path`, `--configuration-bytes` and `--configuration-sha256` operands. It invokes the original `full_scientific_operator.main`, complete compiler, original full controller and FullAuthority/native capture path. That route requires authentic inputs and external native authority which this package does not issue. Source inspection is not a scientific run. To use the typed API, load this file by its explicit path under a unique module name; `import operator` normally selects Python's standard-library module.

[CANONICAL_SPEC.json](CANONICAL_SPEC.json) is the public scientific contract snapshot. [FULL_PROGRAMME_INVERSE.json](FULL_PROGRAMME_INVERSE.json) maps every family and output; [FULL_SCIENTIFIC_API.md](FULL_SCIENTIFIC_API.md) and [SOURCE_API.json](SOURCE_API.json) document the actual source. [CURRENT_SCIENTIFIC_LIMITS.json](CURRENT_SCIENTIFIC_LIMITS.json) retains all 21 gates and missing capabilities. In particular, the CPU-only launcher refuses J03's required CPU+A100 programme; independent J36 comparison producers and authentic input/environment/observer evidence remain unavailable.

The DMS no-clipping repair and complete unthinned state, posterior and population contracts are preserved. Bootstrap Python I/O is not a measured native whole-controller cost. Public paper results, source algorithms, parameter literals and public specimen identifiers are exposed material; subsequent model evaluations need an explicit contamination policy.

See [PUBLICATION_SCOPE.md](PUBLICATION_SCOPE.md) for exact metadata projections and excluded inputs, and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for the retained author-code license and source attribution.
