The source recording is the versioned DANDI dandiset `000130`, version `0.241017.1448`, asset `c90cbccc-31a5-4815-88e6-822d8c5ca68c`, archive member `sub-Haydn/sub-Haydn_desc-train_ecephys.nwb`. The unsigned asset endpoint is `https://api.dandiarchive.org/api/assets/c90cbccc-31a5-4815-88e6-822d8c5ca68c/download/`. The recorded source asset identity is 14,119,912 bytes, SHA256 `6212aaee2c978d1cd53fbfb433d11f418ed27cd83017b8b2befa4a1d7add5198`. This document contains no expiring signed object URL.

Downloading that NWB file alone does not provision this benchmark. The exact TRAIN/query split, four strictly pre-Set spike bins, forty held-in units, clock/cue definitions, released target field, matched cue-only/neural packets and fixed comparator grades must reproduce the registered task. This package does not yet distribute a portable converter, packet release or isolated candidate producer. Do not substitute another session, choose a new split, infer a convenient event-difference target or drop cases and call the result this task.

`artifacts.json` records the existing identities of five evaluator operands by logical filename: public identity, private query targets, fixed reference grade, reference production commitment and independent arithmetic audit. It includes only byte counts and hashes, not labels, predictions or private filesystem locations. These files are not included or fetched automatically. A trusted operator must provision the exact files separately before the scorer CLI can run on the original task. Hash identity is a compatibility check, not a data license.

The public identity is suitable for candidate alignment. Query targets and reference prediction payloads must not be exposed to a candidate process. The scorer accepts precomputed reference grades and validates all five comparator identities and their accepted production/arithmetic metadata; it never reruns reference fitting. Raw NWB and internal evaluation artifacts must remain outside any candidate's input mount.

The public component is therefore a task/scoring source release, not a turnkey portable benchmark environment. The independently qualified local construction uses additional protected execution and data provisioning that are not bundled here. Source release, later distribution of a licensed derived data packet, portable producer construction and new candidate scientific evaluation are separate steps.
