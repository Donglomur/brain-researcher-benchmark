# Frozen scientific design

The broader-catalogue obligation retains every source condition, including categories outside Familiar, Novel 1 and Novel >1. A zero is permitted only within an admitted complete population. `unknown_catalogue_membership`, `absent_in_admitted_secondary_panel`, incomplete event projection, unknown required history, and observed no overlap remain distinct. Support rows include all source experiment coverage and event dispositions. Event counts distinguish experiment-event observations from unique behavioral events; imaging planes sharing one session do not add independent presentations or people. Overlap capacity is descriptive one-to-one support, not an effective sample size or causal-identification proof.

The protected support producer computes separate profiles for image+animal, exact lifetime history, session/order, exact lifetime plus pre-state, exact lifetime plus pre-state plus outcomes, relaxed within-session history plus pre-state, and that relaxed profile plus outcomes. Missing required fields are counted and excluded from matching keys. UNKNOWN=UNKNOWN does not create support. Protected quantitative agreement is assessed against the complete source-derived tables, not an author-written answer. Where source membership or projection is unavailable, the quantitative result remains null even if a candidate correctly explains the limitation.

Secondary source selection and mouse assignments must come from the original membership producer; no new random split is constructed. The full declared panel remains mandatory. The new source adapts the inherited primary analysis by moving eight post-stimulus trial flags to a separately named sensitivity, preserving rows with unknown outcomes for pre-state matching. The original source is retained unchanged for review. The matching stratum is mouse/container/image/change, running bin, pupil rank quartile and within-session same-image presentation-count bin. Sensitivity adds all eight native trial flags. Sort each arm by source date, onset order and event identity; pair once across all repeats, without replacement. Repeat sessions are not independent mice.

Running and pupil pre-state windows are [-0.5, 0), requiring at least 80% finite samples and maximum clock gap 0.1 seconds. Running bins use 1, 5 and 10 cm/s. History bins use 10, 50 and 200 prior same-image presentations within the session's change-detection sequence. Pupil uses blink-masked source area and tied midrank quartiles over eligible rows with both valid pre-state signals. This is target-free full-session transduction, not a training-only or online transform and not absolute between-day arousal matching. Source QC/dF/F processing and registered-cell survival can use whole-record information; those limitations persist. Removing outcome-based eligibility changes the rank population relative to the historical outcome-conditioned extraction and is an explicit prospective design change.

Native image novelty in FIRST determines the new-image primary subset, with already-familiar-image controls separate. All FIRST labels for a container/image must agree; unknown labels make the intended denominator incomplete. Every supported matched case requires a prediction, including control/unknown subsets. Any missing expected mouse, incomplete source, unknown new-image denominator or unsupported planned new-image pair prevents a complete primary result. Per-mouse and cell-type null/support dispositions remain visible.

Allowed nuisance inputs are cell type, image set and image identity, area, depth, change, pre-running value/bin, pre-pupil quartile, within-session history count/bin; sensitivity additionally permits outcomes. JOINT alone receives exposure phase. Mouse/experiment/session IDs, date/order, native current-session novelty and source-path fields are join/support fields, not predictive nuisance inputs. Prior image-set exposure and exact lifetime status belong to support evidence, not predictive substitutes for phase. Candidate feature preprocessing and category/missingness learning use FIT only. Unknown categories have fixed unknown buckets; continuous missing values use FIT medians plus missingness indicators. No query-category vocabulary, query refitting or query-driven model choice is permitted.

The hierarchical baseline retains the original weighted categorical hierarchy/fallback family, with outcome removed only for the pre-state primary; it uses a transparent subset of the common permitted covariates. The HGB comparator uses all permitted covariates. Both have the same information permission as the corresponding candidate arm. HGB grid: `max_leaf_nodes` 15 or 31 crossed with `l2_regularization` 0 or 1; learning rate 0.1, 200 iterations, minimum leaf size 20, early stopping disabled, fixed random_state 127. This setting is source design, not RNG execution. Both references train on all supported matched FIT cases, as does the permitted candidate training view; primary validation loss and scale use the new-image subset. HGB receives equal-mouse/container/pair/phase FIT sample weights. Train four settings per arm; choose by whole-mouse validation normalized RMSE, tie by grid order. Publish both hierarchy and selected HGB. Freeze the primary nuisance family using validation loss only, with hierarchy winning ties. No refit on validation. The candidate receives a maximum five FIT training attempts per arm (four tunable trials plus one fixed baseline), with the same allowed validation information; runtime enforcement remains a missing producer. A model family is not empirically competent merely because its recipe is reasonable.

Primary error is equal-mouse normalized RMSE on new-image pairs, using FIT-only weighted response SD. Report gain against the validation-selected evaluator nuisance reference, never a candidate nominated nuisance baseline. Reference and candidate rows must share exactly the same intended query denominator. Report signed FIRST–REPEAT response contrast and absolute contrast error per mouse, then equal-mouse by cell type, without preferring a sign. Already-familiar-image controls and outcome-conditioned results remain separate. Undefined scale, unavailable reference, failed tuning or missing intended support yields null primary gain, not a success on a reduced denominator.

No superiority threshold, confirmatory uncertainty interval or multiplicity plan is selected. A future inferential proposal must resample whole mice (retaining every session/container/cell/pair and both policies), respect cell-type strata and reference selection, and account for multiple cell types, support profiles, policies and comparison modes. Cells, imaging planes, events, matched pairs, folds or sessions must not become independent animals. Descriptive estimates do not authorize a significant or causal conclusion.


V2 event-support completion: each completely projected experiment supplies a source-event partition census (retained plus excluded equals the complete presentation-table observation count) and every excluded identity/reason. The permitted support view carries those metadata fields without neural values; protected tables and assessed comparisons include exclusions, reason counts, per-experiment denominators and population summaries. Experiment-event observations count each imaging plane; unique behavioral IDs separately deduplicate the same session event across planes. A failed or unavailable projection has a null source denominator and an explicit status, not zero. Observed prefixes are separately labeled and cannot establish complete population support. A missing or overlapping retained/excluded identity, mismatched source census or disagreement across planes fails the metadata join. Non-change-detection rows receive their source exclusion before omission validation; undefined omission on a gray/spontaneous row is outside the shown-image field domain.
