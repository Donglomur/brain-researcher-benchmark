# Full NEURAL-047 source programme

This conditional programme retains one canonical task: predict dorsal versus ventral post-reversal turns in entirely held-out verified worms. It is prospective retrospective prediction from processed SAAV calcium, with recent-behavior and combined views. It is not the paper's phase-warped event-level GRU reproduction, an online-causal claim or an independent dataset replication of NEURAL-048.

The exact WT aggregate, all source rows, all maximal observed reversals and every eligible event are required. A separately qualified operator must establish every recording's animal identity, native frame mapping, physical clock, anatomical sign and SAAV support. Neither a filename, nominal frame rate, self-asserted evidence string nor a valid JSON file establishes those facts. At least three independent eligible animals are required; an empty animal or unsupported training fold prevents the complete panel. Only explicit no-SAAV recording and prescribed event exclusions are allowed.

Features use every contiguous native sample in the preceding 4.8 seconds through the first native timestamp at least 2.4 seconds after reversal onset while still reversing. The target uses mean dorsal-positive head curvature at the first two native frames after reversal end. Original source preprocessing may use whole-recording information. Future behavior, reversal end/duration, original identities, odor and cross-fold state are unavailable to candidate workers.

All animals are held out once in each N, B and NB view. F mode supplies one precommitted prediction program to all independent contexts. I mode permits investigation and program creation within one fresh outer-fold/arm context, with the same precommitted agent policy, tools and cumulative resource limits across arms. Both receive the same training and query information; I's permitted tool interactions are measured separately from F's execution. No outcome from another fold/arm or scorer is returned. Only the current fold's permitted training people and labels may support inner leave-one-animal-out development. The program/specification is frozen before any outer context is delivered.

References are fixed logistic C=1 and independently development-selected logistic/gradient-boosted summaries. A single declared family and hyperparameter grid applies to every arm; selection uses only inner whole-animal log loss within that outer training set. For the minimum three-animal case, inner fits can have one training animal and must still contain both classes. Unsupported reference development makes that reference unscorable, not an excuse to use query labels or skip animals. Query probabilities are never tuned on final private targets. References are prospective and unqualified, not inherited published results.

The six per-channel summaries are last value, mean, population standard deviation, minimum, maximum and physical-time least-squares slope. Reference scaling is fit on training rows only. Equal animal, equal within-animal-class weights sum to the training event count. We preserve fixed-logistic provenance and add a prespecified stronger prospective comparison without claiming it is SOTA.

The N arm's animal-macro balanced accuracy at threshold0.5 is primary; equal-animal log loss with probability floor1e-15 is co-primary. Report all N/B/NB animal-level and aggregate values. One single-class animal leaves the entire-panel balanced accuracy undefined; do not omit it or compute a favorable subset. Retain complete-panel log loss. Whole-worm bootstrap intervals are descriptive under overlapping training folds. All predictions for both modes and all reference families must be closed, authenticated and complete before target access; valid abstention is unscored and never invokes private targets.

The deployment remains unconfigured. Original input admission, execution isolation, numerical/backend parity, complete resource feasibility and real evaluation remain explicit external gates. Source and tiny invented controls cannot close them.
