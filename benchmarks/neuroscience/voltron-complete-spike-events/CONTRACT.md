# Complete optical-voltage spike timing: scientific scoring component

This implements the missing event scorer and coverage/clock/fold validator for the existing registered draft `NEURAL-DISC-20261114-VOLTRON-SPIKES`. It is a source-only addition to the accepted complete twelve-cell contract. It does not add a benchmark ID, acquire signals, extract optical traces, detect electrical reference spikes, fit a baseline, run a candidate or establish native isolation.

The primary source is the Janelia collection [10.25378/janelia.c.5325254.v1](https://doi.org/10.25378/janelia.c.5325254.v1), linked to [Cell Reports 2021, 108954](https://doi.org/10.1016/j.celrep.2021.108954). The reviewed dossier records twelve deposited cells, optical rates 400 Hz or 1 kHz, seven paper-reported mice but only six animal tokens in cell titles. The biological map is unresolved. This component requires the reported seven-group scope; it does not manufacture the seventh animal or convert six filename tokens into an authenticated census. A different authenticated census requires an explicit scientific amendment.

## Fixed endpoint and numerical choices

Predict all electrophysiologically verified spike times from a label-independent optical trace. Include every movie of all twelve cells. Each movie's complete half-open duration is partitioned into contiguous nonoverlapping scored cores. Retrospective context halos are allowed upstream, but only core-owned event timestamps may be submitted. Complete movie events are reassembled before matching, so an event near a core boundary is not counted twice or needlessly missed.

The common timebase is an independently authenticated integer clock. `clock_hz` must represent the 400/1000 Hz frame grid exactly. This component does not guess offsets, convert frames to electrical time or validate physical synchronization. A prediction and target match when `abs(prediction_tick - truth_tick) * 200 <= clock_hz`, exactly inclusive five milliseconds without floating-point threshold rounding.

Use chronological earliest-compatible matching on strictly sorted, unique event lists. For one-dimensional points under an equal tolerance this attains maximum cardinality. Each prediction and target can be credited once. Secondary latency follows this deterministic matching; no minimum-total-latency or nearest-event assignment is claimed. Tests compare its cardinality against an independently written exhaustive bipartite assignment oracle for all 1,024 pairs of five-location event sets.

Matching occurs independently inside each contiguous valid optical/electrical intersection. Adjacent intervals are coalesced; no match crosses an actual invalid interval. Private valid intervals must be contained in the public optical-validity mask. Reference spikes outside declared valid support are a reference error. Predictions outside valid support are retained as an excluded count rather than called true or false events. Optical extraction failures remain explicit movies and cells with no valid support. They cannot disappear from the roster.

Counts are aggregated over cores into complete movies, then over all movies of each cell before cell F1. F1 is `2 TP / (2 TP + FP + FN)`. Empty/empty is undefined, never a perfect score; no-spike movies with false events have F1 zero and a real false-events-per-valid-minute burden. Precision and recall retain undefined denominators. Signed/absolute matched latencies, valid and total duration, optical-rate strata, and all failed/partial dispositions accompany the counts.

This additive scorer freezes a previously unspecified weighting detail: the primary is the seven animal-specific vectors of equally weighted cell F1, with no cross-animal headline. If any cell's F1 is undefined, that animal's full equal-cell value is undefined; an explicitly named observed-only mean is separate. Metric support is the declared valid intersection, not a claim of successful full-duration extraction. Partial validity remains visible at movie, cell and animal levels. An animal's number of cells does not make it more independent than another animal.

Four matched input roles must be complete before any private callback: `candidate`, `optical_mad`, `optical_matched_filter`, and `metadata_rate`. The comparator recipes are training-only median/MAD threshold with refractory control, a training-only matched filter/threshold, and an acquisition-metadata/fixed-rate prior. This component scores their frozen event predictions; it does not implement or qualify their producers. Full-video VolPy is a richer-input auxiliary reference, absent from these matched primary roles. The scorer reports candidate-minus-comparator animal F1, retaining negative and undefined differences. No significance or improvement threshold is introduced.

The split is complete leave-one-animal-out: exactly one query fold per resolved animal, every movie of all its cells in that fold, and all other animals' cells in the corresponding outer training roster. The validator rejects query cells in training and shared-animal movies assigned to another fold. Hyperparameter selection must remain within the outer training animals; the scorer's metadata check cannot prove that an upstream program followed this rule.

## Concrete interface

`grade(public, predictions, private_loader)` is a pure Python library operation. No candidate code is executed. The protected caller, not the candidate, supplies the private loader. This library is not a process boundary or authorization service. The caller must freeze source, prepare all provenance, obtain actual run/resource authority and keep private operands unavailable to candidate execution.

`public` has exactly: `schema="voltron-complete-events-public/v1"`, `task_id`, `release_manifest_sha256`, `cells` (twelve unique opaque identifiers), `expected_animals=7`, and `movies`. Each movie has `cell_id`, `fold_id`, `clock_hz`, `optical_rate_hz`, `start_tick`, `end_tick`, `input_disposition` (`ready` or `optical_extraction_failed`), `optical_valid_intervals`, and `tiles`. Intervals are `[start_tick,end_tick)` integer pairs. Tiles have `tile_id`, `start_tick` and `end_tick`; they cover the whole movie, even failed-extraction intervals.

`predictions` has exactly: `schema="voltron-complete-events-predictions/v1"`, `task_id`, `public_sha256`, and `roles`. The public hash is SHA-256 of sorted-key compact finite JSON. Each required role has `program_sha256`, `calibration_sha256`, and `tiles`, a complete mapping from public tile IDs to strictly increasing integer event ticks owned by that core. The source/calibration digests bind identities, not proof of legitimate training or actual computation.

The private callback is invoked exactly once only after all roles and every final tile are admitted and captured into independent immutable tuples. It returns exactly: `schema="voltron-complete-events-reference/v1"`, `task_id`, `public_sha256`, `census_evidence_sha256`, `mapping_evidence_sha256`, `cell_to_animal`, `outer_folds`, and `movies`. Each fold has `query_animal` and the complete `train_cells`. Each movie has `valid_intervals` and strictly sorted unique `spikes` on the same physical clock. Evidence hashes do not authenticate biological facts by themselves.

Malformed candidate panels return `invalid_submission` with zero private callbacks. Invalid public contracts or reference geometry/fold/coverage errors raise typed exceptions and produce no successful primary score. Private-reader failures propagate as operational exceptions, not false zero-read or zero-score claims. Successful results retain all role/movie/cell/animal metrics and set `scientific_qualified=false` and `new_benchmark_ids=0`.

Engineering format ceilings are 4,096 movies, 200,000 cores and 1,000,000 events per full role/reference, with integer ticks below 2^63. These are refusal limits, not permission to truncate the real cohort or a measured authentic memory envelope. The whole real census must fit a separately budgeted operation; otherwise an explicit source amendment is required.
