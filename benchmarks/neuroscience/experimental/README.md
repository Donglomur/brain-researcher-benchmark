# Experimental neuroscience task components

**These three prototypes are not ready benchmarks.** They are independently authored scorer and protocol components for two proposed paper-research tasks and one proposed neural-data task. They do not add registered, qualified or submission-ready tasks. No model performance or scientific improvement has been measured with this export.

| Component | Proposed question | Implemented | Required before authentic evaluation |
|---|---|---|---|
| [Macaque memory](macaque-memory/README.md) | Reproduce historical decoding; improve within-session temporal-block old/new prediction | Prospective weighted scorer and failure checks | Complete trial/feature joins, protected split and references, runtime, rights, isolated runner |
| [Dendritic morphology](dendrites/README.md) | Reproduce FL/PL feature curves; predict lobe in held biological groups | Prospective group-weighted scorer and complete-census checks | Authentic donor/animal mapping, complete features, data terms, references and runner |
| [Calcium state](calcium-state/README.md) | Compare matched workflows on presegmented held-animal state classification | Metadata windows, opaque-ID projection, descriptive scorer | Complete signal/animal/label/context admission, references, uncertainty and runner |

Tests use invented observations and probabilities. Their success checks software behavior, not scientific validity or a candidate's skill. The paper-task scorers implement prospective improvement metrics; they do not score every requested historical reproduction output. No paper, upstream implementation, dataset, authentic target or private source history is included.

Use each family README for commands and its contract for the actual scientific scope. For calcium, the mandatory scope addendum discloses target-conditioned segmentation. Public data can be pretraining-exposed even when a future runner protects labels during execution.
