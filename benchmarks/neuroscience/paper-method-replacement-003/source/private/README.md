## Preserved normalized-index interface


This partial package builds a strict arbitrary-prediction interface and continuous scorer for the full selected central C4 mouse/monkey endpoint. It retains the actual operator code and an exact mandatory external-source descriptor, but no empirical data, predictions, private labels, VAE weights or scientific reference. Nothing has been fitted or scored on original data.

Historical generated-check source is retained; it has not been rerun or asserted compatible with the new external-source exposure interface. New source-distribution checks are separate. Original invocation:

```sh
python -I -S -B private/test_generated.py
```

In the source tree use `tests/test_generated.py`; the exporter maps it to `private/test_generated.py`, preserving `parents[1]`.

Future operator preparation requires an externally authenticated `c4_normalized_index_v1` from all five exact originals. Its schema is implemented by `private/prepare.py:index`: original file name/length/published MD5/locally verified SHA256; complete ordered `units.mouse_loo` and `units.monkey_transfer`; per-unit opaque ID, private original key, class, animal/session/lab and feature path/length/SHA256; full `pretraining_units`; source-key/reason exclusions; exact selection, pretraining and run-configuration SHA256s. Hashes identify external reviewed records; they are not substitutes for their scientific audit. The current package has none of these authentic records. The five original identities alone do not prove completeness of any unit selection.

Normalized feature JSON is exactly `{waveform:[120 finite values], acg_3d:[10 rows of 201 finite values], engineered:{37 exact source-combined named finite scalars}, layer:"unknown"|"GCL"|"PCL"|"ML"}`. This is the pinned classifier's pre-half-lag input geometry; waveform/ACG computation, quality masks, engineered feature derivation and source-specific biological identity mapping remain upstream. Do not reinterpret raw HDF5 as this normalized format. The normalized feature format does not yet carry raw spike indices or multichannel templates needed by the original augmentation options; the printed augmented author command therefore remains a source template requiring those original inputs, not an executable route through this normalized packet alone. Pretraining units are separate from all labelled/query units, preserving the paper's separate-unlabelled-training design; an alternative transductive exposure requires a different declared task protocol.

After these inputs exist, `index(x)` returns the exact public query and private target. Publish query alone. For one bounded lazy case:

```sh
python -I -S -B private/prepare.py --index OPERATOR_INDEX.json --index-sha256 EXACT_SHA --feature-root NORMALIZED_STORE --case OPAQUE_MOUSE_ID --output FOLD.json
# or --case monkey_transfer for all mouse training and full monkey query
python -I -S -B private/stage.py --packet FOLD.json --packet-sha256 EXACT_SHA --arm paper_and_data --article-path REQUIRED_ARTICLE.xml --output fresh_A
python -I -S -B private/stage.py --packet FOLD.json --packet-sha256 EXACT_SHA --arm paper_data_official_code --article-path REQUIRED_ARTICLE.xml --dependency-root VERIFIED_SOURCE_ROOT --output fresh_B
python -I -S -B private/score.py --query QUERY.json --submission CANDIDATE.json --target PRIVATE_TARGET.json --output fresh_metrics.json
```

The grader validates the complete public submission before opening private target content. Its metrics remain operator-private. A static candidate view receives only its selected fold, contract and optional B source. Pretraining features still need an authenticated separately staged source view; only their roster/hash is emitted by this preparer, so this is explicitly not a runnable complete training packet. A future isolation wrapper must forbid private outputs, alternate folds' held labels, source-store labels and unauthorized network access.

`private/reference_recipe.py` prints source CLI templates without execution. Deep entry downloads checkpoints automatically and requires further preprocessing/ACG/source config; do not run it as an oracle under construction-only authorization. The complete original source selection is represented by mandatory exact dependency rows; notebook training code, frozen inference artifacts and historical hyperparameter correspondence are not. A new production roster differing from202 is refused pending explicit scientific reconciliation, not coerced.

No article body, original arrays, weights, scientific tables or private numeric targets belongs in the source-only Git proposal. Exact external source/license descriptors, owned generated-check source and contracts do; upstream bodies remain outside this source tree. No new canonical task, acceptance, runtime, or historical count is claimed.
