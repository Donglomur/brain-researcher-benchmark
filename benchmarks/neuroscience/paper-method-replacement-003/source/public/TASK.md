# C4 cerebellar cell classification and mouse-to-monkey transfer

Task: PAPER-paper-method-replacement-003. This is a partial construction package for the central classification/transfer experiment of Beau et al., Cell (2025), DOI [10.1016/j.cell.2025.01.041](https://doi.org/10.1016/j.cell.2025.01.041). It is not a reproduction or a task covering every auxiliary analysis in the paper.

The scientific question is whether a semi-supervised waveform/discharge/layer classifier improves classification over engineered-feature baselines while retaining useful coverage, and whether a mouse-trained classifier agrees with expert labels on the full selected monkey cohort. Mouse source ground-truth labels and monkey expert references are different kinds of evidence and are never pooled into one accuracy.

Use the fixed output order `GoC, MLI, MFB, PkC_ss, PkC_cs`. Simple and complex spikes are two Purkinje output classes, not two biological cell types. Granule cells and MLI subclusters are not silently added to this central five-output analysis. The pinned monkey loaders remove MLI_B and map MLI_A to MLI for this five-class route; these source exclusions and the 40-to-30 kHz waveform resampling must be reconciled against the published cohort before production. Every excluded original record must have an operator-bound source/QC reason. The published central ground-truth analysis has 202 units; a changed number at the pinned software revision requires reconciliation, not arbitrary subsampling to 202.

Reconstruct the mouse leave-one-unit-out experiment with ten instantiations per held unit, plus the full selected monkey transfer. Submit probabilities for all units and all five declared variants: combined engineered-feature logistic regression, random forest, Gaussian process, the deep classifier, and a separately specified improvement. The baseline feature view is exactly `feat.FEATURES` minus the six `prepare_classification` metadata/channel columns (37 named inputs), not arbitrary user-defined predictors. Waveform-only/temporal-only feature ablations remain outside this central comparison. Each probability row has five finite nonnegative entries summing to one. Each unit has ten rows. For deep monkey transfer, each row is the mean over one instantiation's 202 LOO models (2,020 total); identical averaging weights are required. The query binds each variant's model count. This artifact contract cannot establish that those models were actually trained or independently instantiated.

The scorer averages probabilities before the paper-style confidence ratio (largest/second-largest). It reports full confusion counts, conditional true-class rows, unclassified fractions, accuracy, class support, and coverage at ratios 1, 2, 3, 5, 10. Ratio 2 uses `>=`, matching the pinned prediction API; the source survival plot uses `>` and its boundary is disclosed. It also reports the separate plotting-helper convention of maximum probability strictly above 0, .5, .6, .7, .8, .9 for pooled baseline repeats; deep uses mean predictions for both CV and transfer, with the additional .4 threshold. The improved method uses the same mean/grid only as a prospective convention. Mean-probability threshold diagnostics and per-instantiation macro-F1 mean/population deviation are separately labeled. A class with no retained observations is undefined, never perfect; nulls remain visible. Fixed-five-class macro-F1 remains null when a denominator is absent, while an additional observed-union macro-F1 matches sklearn’s default averaging support. Supplemental Brier score, group-descriptive accuracies, and fractional-tie matched-coverage comparisons are prospective diagnostics, not claimed published numerical outputs. No binary success threshold is registered.

A meaningful improvement must improve accuracy/calibration at matched retained coverage on the same units, with the same input and declared model/data budget. Use training-only selection/calibration; never choose an improvement or threshold from monkey expert labels or held mouse labels. Unit LOO is not leave-animal/session/lab-out generalization. Any animal-held-out experiment needs a separate frozen grouping protocol and is not substituted for the published endpoint here.

Two information arms use identical paper/data and task: A `paper_and_data`, B `paper_data_official_code` additionally receives the pinned official source. Both receive the same dependency policy. Public data/paper exposure means these are not blinded labels or a causal estimate of code benefit. The static view builder does not enforce network/process isolation. Query feature rows contain no source keys, private labels, animal or session names; anatomical layer is an intended feature.
