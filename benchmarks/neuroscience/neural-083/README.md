# NEURAL-083: complete OpenBMI preparation source

This task exposes the reviewed source for preparing the complete 54-person, two-session OpenBMI cohort. It preserves 108 records, 10,800 query trials, four settings, three arms and both candidate/reference panels: 2,592 conditions and 5,184 later native fit/infer phases. These conditions remain part of one registered assignment.

The [preparation guide](preparation/README.md) describes the exact captured-source entry, complete projection/finalization routes and external inputs. This package contains source only. It does not contain original neural data, observed schema bindings, identity keys, protected answers, native environments or independent scientific admission.

From this task directory, select an absolute fresh absent cache prefix in an owned, nonshared parent and run:

```sh
python3 -I -S -B -X pycache_prefix=ABSOLUTE_FRESH_ABSENT_PREFIX \
  preparation/source/prepare_entry.py inspect
```

This command captures and authenticates source bytes without importing the local scientific modules or opening any data operand. The original ten modules remain exact. Public provenance locations and their entry/manifest identity joins are source counterparts, not a new scientific method. No generic public CLI sidecar discovery is claimed.

From the repository root, the source-only checker is:

```sh

```
