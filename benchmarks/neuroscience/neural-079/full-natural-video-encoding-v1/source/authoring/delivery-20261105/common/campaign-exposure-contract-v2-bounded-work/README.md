# Bounded campaign admission, source successor

This version keeps the original declared-exposure decisions and typed relationships. It changes only source admission and metadata capacity. A successful decision remains a compatible development selection, not proof of independent history, input permission, or runtime qualification.

WORK is bounded at 2 MiB. The exposure Reader and preferred-route capture each use a 4 MiB aggregate. Construction must leave 256 KiB of WORK headroom. Every stable body includes its EOF sentinel in its logical read charge; the preferred route reserves cap plus one before capture. The authenticated POLICY, LOCK, validator constants, manifest and gate must agree.

The ordinary CLI still captures real files twice, performs actual assess(), and checks future cache freshness. The trusted source view is an internal prepublication interface only. It has no filesystem fallback, performs source/routing checks, and cannot authorize a run. Its cache check is lexical; actual cache freshness remains unverified.

The capacity planner authenticates the complete local contract source, then uses the existing graph, builder and declaration descriptors without reading their bodies. It derives the full Reader and preferred-route arithmetic, accounts validator bootstrap separately and describes both caller passes. Qualified source scans, parsing, CPU/RSS, actual file system operations and execution require separate provision.

No prior CHECKS receipt is represented as a new test pass. New controls and source provenance live in the separately owned contract-controls directory. The original version remains immutable. All external descriptor identities and the DECLARATIONS body are unchanged.
