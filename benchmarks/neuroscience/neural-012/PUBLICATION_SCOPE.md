# Publication scope

This public source snapshot contains one existing canonical assignment, NEURAL-012. It does not add independent benchmarks for its arms, phases or files. It distributes source code and contracts only: no EEG, EDF/HDF5 headers, event-annotation datasets, participant mappings, fitted models, protected targets, preparation keys or local authoring history.

The 57 inherited source roles retain their complete relative layout. Fifty-five roles are byte-for-byte identical to the installed source. Two metadata roles are projected for publication: SOURCE_BINDINGS.json replaces ten private authoring paths with descriptive prerequisite identifiers and removes a private architecture-selection locator; SOURCE_PROVENANCE.json omits local acquisition history and held-asset locators. Prerequisite hashes, absent-input status, source citations and the full scientific scope remain. These metadata roles are not runtime data inputs.

All inherited scientific Python bodies, the selection bridge and the signal snapshot implementation are unchanged. The central operator changes only the expected source-manifest size/hash and aggregate metadata byte count, so its actual source inspection authenticates the public projection. The accepted-source manifest, outer source freeze and inactive registration manifest are regenerated consistently. Documentation states the public source status. Original private source remains separate and unchanged.

All 12 genuine-input/native/scientific gates stay false, and generic run/score remain null. Public source inspection neither qualifies the scientific environment nor launches a scientific campaign. Acquisition, preparation and campaign modules are executable future workflow source; they are not harmless metadata commands and are not run by this publication.

The `private/` directory names identify trusted-host roles. They contain ordinary source code and metadata, not confidential records. They must not be mounted as candidate input during an evaluation. The public underlying datasets and published task/scoring logic also require an explicit contamination policy for any subsequent model evaluation.

The retained public author clock parser includes its published filename and clock-correction literals. These are algorithm source; the annotation datasets and private evaluator targets are not distributed.
