# Failure, output and assessment contract

Every ordinary controller operation is owned before its fallible final observation. Raw first exceptions are retained separately from diagnostic descriptions; independent close operations add ordered occurrences. A fresh catch reusing an exception object is distinct from propagating an existing owner/index occurrence. Logical reservations are monotone and retain unknown effects; no retry/reset/refund is inferred from failure. Actual file reads verify no-follow type, full extent, stability and hash. Writes handle short writes and final extent, close the acquired leaf and parent independently, and preserve the original body failure.

The reference owns all acquired MNE recordings and closes each once even after failed scientific work. Plot/serialization owners are retired before the final logical budget is closed. Publication is one terminal effect; failure stays on the same owner and there is no recursive publication. Returned clock-free cost snapshots include the publication's reservations, known bytes and unknown prefixes. Input/output roots are owned externally and are not retired by borrowed callees. These are source guarantees; no empirical native ownership claim is made.

Products retain actual time axes and exact participant/condition/pipeline/score identities. The condition-specific random OOF tensors include all five folds. The full product set requires 990 identities. Group outputs preserve all 52 comparison identities. Available inferential maps retain actual subject values, t fields, cluster masks/probabilities/nulls and seeds; unavailable maps retain complete endpoint/dependency reasons. The two random structural controls retain subject differences and complete identity provenance, with no invented t/p/null/BF arrays. The three explicitly named BF10 maps each have an available or unavailable disposition. Outputs also retain the averaged random-condition OOF tensor, six rendered PDF figures and their actual byte captures. Partial theoretical support or undefined/infinite Fisher coefficients retain all independent products and defined group inference plus an explicit unavailable manifest. No subset-person or subset-cell Fisher endpoint is substituted. GroupResult.structural and GroupResult.unavailable are consumed by serialization, all six figures and terminal publication. The structural controls are explicitly labelled as construction identities, not a null scientific finding. The source exposes complete, empirical_and_most_likely, and theoretical collection identities, each requiring all 33 participants and its full fixed product set. A protected operator must select that endpoint before candidate output; arbitrary candidate-chosen subsets are forbidden. The full theoretical comparison still refuses unavailable cells. A serialized input or result dictionary never establishes native execution lineage.

The actual product reader refuses missing/extra/duplicate identities, mismatched axes, nonfinite values, object arrays, unknown ZIP members and over-cap archive expansion. Library/parser allocation peak remains under the separate native qualification hold; this is not a certified adversarial decompressor. A candidate file hash is matched against actual captured bytes; a separate trusted producer/source/run binding remains required upstream.

Numerical agreement is a diagnostic enumerating every product's maximum absolute error against an actual independently admitted reference. Tolerance is a required preselected input, not inferred from candidate output. No qualified reward exists yet, and this packet does not establish scientific correctness merely because two arrays agree. Historical parity, complete retrospective figure agreement, empirical method competence, absence-of-effect sensitivity and a distinct improvement panel remain separate obligations.

There are only the two original access arms. No cross-attempt source or state history is admitted. The source projection is concrete, but full OS enforcement and source freeze/participant execution are unavailable until a genuine native installation and admission owner are selected. No header, behavior table, neural array, model state or output answer was accessed during BUILD.

For empirical reordered recordings, the callee owns a newly acquired raw through event construction, the enclosing operation final observation and returned Recording construction. Failure preserves the original error before one local raw close; success transfers exactly once. Operation event identities propagate unchanged, while an independently caught close failure is a fresh occurrence even when it reuses the first raw exception object.

## V3 operation-owner routing

The actual campaign creates one Operations with its original Budget and campaign
Custody. participant, load_recording, empirical_recording and draw explicitly
derive Operations.scoped(local) before their operation contexts. A scoped view
accepts only the same actual Custody or a descendant of that view's owner. It
shares the original Budget, operation-row list and original Operations object;
it creates no new reservation, operation event or counter. This is internal
source ownership, not a native capability or an external admission mechanism.

The operation's own local Custody propagates its original owner/index occurrence
up through the caller's local Custody, participant and campaign. A caller whose
local owner already holds that occurrence does not catch the same propagation
again. A new close or final-clock failure is still a fresh occurrence, including
when it reuses the first raw exception object. Failed-return raw, FIF buffer and
partial-figure retirement stay independent and once-only. The original shared
operation list retains one monotone sequence across these local views.

These four internal callers now require the real Operations.scoped interface;
an arbitrary context-manager callback is not a compatible replacement. The
scientific leaves receive the same operation interface, inputs, fit/test indices,
trial supports and numerical definitions as V2. All scientific scope, unavailable
endpoint dispositions, historical/prospective distinctions and twenty gates are
unchanged. No successful native or scientific execution is established here.
