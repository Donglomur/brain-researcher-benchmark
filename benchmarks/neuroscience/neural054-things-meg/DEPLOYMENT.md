# NEURAL-054 central source package

This is the complete inactive public source package. It retains all 22 original Python members, all 16 scientific contract roles, five runtime/custody documents and two source adapter modules. Public provenance replaces private filesystem locators without changing scientific methods. The registration is manifest.json. Source publication is separate from installation, execution and scientific qualification.

The default central entry retains the original `plan` operation. It authenticates the package and prints the original complete metadata plan without opening `--program`, a review, source inputs, targets, or output. `selected_campaign` runs the exact externally selected campaign. The 15 `modes_*` names cover every nonempty subset of P/I/D/R and require exact agreement with that same campaign; they never filter conditions, replicates, arms, windows or cases. P/I NUM and NUM_REF, D NONE and R REPORT_ONLY remain original campaign fields. These names add no benchmark IDs or scientific tests.

The central `{program}` operand is an ordinary programme-bundle JSON file. It is not executable participant code. The closed fields and review are in `BUNDLE_AND_REVIEW_SCHEMA.json`. The bundle names the exact original execution selection, campaign and source registry; predictive routes name the admitted feature metadata/root and private issuer-secret path. Source registry entries retain the original four build/train/predict/interpret entrypoints, source-tree identity, and absolute source root. Every selected programme must appear exactly once. Neither the adapter nor central argv construction imports participant code. Original `Controller.register` snapshots and authenticates that source.

Predictive execution dispatches `n054.cli.main` with the original selection hash, original campaign/registry paths and unmodified scientific operands. It preserves all original internal admission checks. R-only passes only the original prior report/provenance route and explicitly refuses feature, target-admission or issuer-key operands. `prepare` is a separately reviewed operator route, exposing original complete extraction only after its original authentic admission; it is not a central programme condition. No source/image/key body has been opened while building this package.

The original `Controller.grade` remains the sole scientific grading caller. It revalidates the complete global seal and current resources before `FeatureIssuer.protected_targets`, and calls the exact original `n054.report.score`. No second scorer is registered under central `entrypoints.score`. There is no selected S4 standalone artifact-to-controller reconstruction authority; a synthetic regrade would bypass original target/resource custody. The protected scorer source, complete output contract and concrete call chain are packaged in full instead. Original REPORT, GLOBAL_SEAL, collections, process Journals, state bindings, costs and final disposition remain original products, not summaries substituted by the wrapper.

`FINAL_DISPOSITION.json` under `output/campaign` is canonical only when original S4 admits its durable final custody. DISPOSITION is provisional. Initial and final terminal holds remain incomplete. Failures, partial outputs, unknown counters and unresolved children are not converted to success. The adapter owns the raw first exception in the same Prefix before terminal diagnostics. LAST_FAILURE_PREFIX and the exception traceback retain that owner independently of optional exception attributes. The single terminal snapshot attempt can fail without replacing the original exception; its raw failure is retained as a secondary, and entry reuses that outcome instead of retrying its clock. Optional context and custody attachments are attempted once per attribute, with attachment failures retained separately. No exception stringification, rendering or terminal write occurs in error enrichment. A bare re-raise is the final fallback, and finder cleanup failures also remain secondary when a primary already exists. This controls source-level diagnostic callbacks; it is not a guarantee against interpreter death or exhausted memory. The adapter performs no original-work retry and writes no replacement campaign result. The independently qualified outer host must retain the real entry exit, earlier host costs and any failure before the original Controller exists. Such deployment custody is not qualified here.

All source bytes are authenticated before importing the package. The new loader imports captured `n054` bytes without reading pyc files. Later original trusted-source copying, preparation legacy imports, participant and numerical execution still require the original immutable deployment and native qualification. The source lock and central qualification source are exact inventories, not signatures or proof of OS isolation. An `ACCEPTED` string inside a future review is only one source check; current central verification is `not_run`, so the package declares central execution unavailable until the separately required campaign engines are published, reviewed and qualified.

The metadata bridge preserves original 16 MiB campaign/registry/admission read ceilings and original 1 MiB execution-selection ceiling. Its separate 64 MiB prefix ceiling covers those possible reads, the fixed source closure and bounded bundle/review. Reservations precede its reads, a one-byte EOF probe is included, and failed reads/once-only-close uncertainty retain pending debt. This is additional logical metadata work. It is not a change to original campaign limits, physical IO measurement, or permission for an unreserved prefix. Future host qualification must reserve and observe the prefix before launch; `other_reserved_bytes` is not a refund or a way for a later plan to pay earlier work.

All 240 folds, 27 labels, four people, 12 sessions/person, 88,992 experimental trials and 108,192 original dispositions remain. The programme retains all 20 stages, 42 obligations, 30,000 full-core and 12,000 summary reference artifacts when applicable, all 29 open gates and 37 unexecuted future scientific controls. P/I and D do not share a ranking composite. Standalone R activates no scientific bank. Null/negative/inconclusive outcomes retain the original interpretation.

`INSTALL_RECIPE.json` specifies the source registration destination and exact existing dependency roles. The install recipe does not invent native library versions, a container digest, input qualification or model access. The original environment requires a content-addressed image and independent Linux/Docker/cgroup qualification. An independently qualified deployment must select this exact public source interface and original execution authority before runtime admission. Installation, execution, qualification, source acceptance and registry counts remain separate.
