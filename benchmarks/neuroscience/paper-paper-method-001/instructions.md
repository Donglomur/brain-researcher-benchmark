# Finite-sample dimensionality: local numerical reconstruction

Reconstruct the source-polynomial participation-ratio estimates for the supplied Stringer recording M170714_MP032, 2017-08-07. This numerical component uses one full panel and 18 fixed nonfull stimulus/neuron subsets, listed in public_design.json. The two repeated full-grid endpoints are represented once. The 76 estimator records are nested outputs of one task and one animal.

Use the published data and the declared historical preprocessing: normalize each neuron by spontaneous mean and standard deviation plus1e-6; remove the first 32 spontaneous principal components; center responses using the complete recording; exclude the maximal blank stimulus ID; form chronological halves of each image's repeated presentations. The existing float64 reference uses a deterministic matrix-free eigensolver, tol=1e-8, maxiter=200, with eigenpair residual at most1e-6. Historical-runtime projector equality and the 32nd/33rd eigengap remain unassessed. Do not treat globally centered responses as independent iid samples.

For the full panel and each supplied subset, compute the author's naive, row-corrected, column-corrected, and both-corrected polynomial moments A, B and the ratio A/B. Use the exact supplied subset identities. This is one draw per nonfull size, not the paper's repeated-sampling uncertainty experiment. Moment-estimation properties do not make the ratio unbiased or the full-data estimate biological ground truth.

Submit one UTF-8 JSON object {"records":[...]} containing exactly 76 unique records, in any order. Each record has exactly point, estimator, A, B, ratio. Point is full, P0..P8, or Q0..Q8; estimator is naive, row, col, or both. All three numerical fields must be finite JSON numbers with absolute value≤1e100. Every combination is required. Boolean/string values, duplicates, missing/extra fields and nonfinite values are invalid.

Primary score is the root-mean-square relative error of the four full-panel ratios; lower is better. Secondary scores separately report relative RMSE for A, B, and ratio across the 18 nonfull panels and A/B moments at full size. Relative error divides by the absolute,nonzero saved reference value. All signed record errors are retained. Imperfect finite outputs receive continuous errors; there is no invented scientific pass threshold. The score checks numeric results, not candidate-program provenance, scientific explanation, open-paper alternatives, paired code access, improvement or publication readiness.

The article is Estimating Dimensionality of Neural Representations from Finite Samples, ICLR 2026.
