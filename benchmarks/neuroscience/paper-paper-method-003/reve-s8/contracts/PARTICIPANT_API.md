# Participant programme and trusted interfaces

This is a normative API design, not an executable harness. The future controller must launch the registered participant source and collect its products. An evaluator-owned hardcoded learner, caller-authored metric JSON, qualified=true flag or generic external-service placeholder cannot satisfy the contract.

## Actors and custody

The operator owns preparation, complete rosters, access manifests and process custody. Each A/B domain-specific development actor owns an arbitrary offline source tree and its declared dependencies. The operator must admit its developer/source-generation context before label release under EXPOSURE_DOMAINS.md; a global actor cannot accumulate all family labels and then author a supposedly clean few-shot descendant. Independent reference actors own fixed comparator source; participants cannot choose or populate their bank. A collector reads completed output objects and expected indexes without targets. A separate grader owns protected labels and metric reduction and never imports participant or author code. The global calibration map, private aliases and reference outputs remain operator-private. Physical isolation is an open engineering gate; hashes and role labels alone do not enforce it.

Requests and responses are ordinary bounded UTF-8 JSON files with exact schema/version, request_id, programme_id, task_id, arm, purpose, scientific_profile, family, condition, role, source/environment identity, upstream receipts, input/output object indexes and resource policy. Binary objects have exact relative paths, sizes, hashes, dtypes, shapes, ordering, units and channel/clock/support bindings. No arbitrary host path, command string, evaluator callable, pickle or serialized executable enters the data ABI. The operator materializes separate readonly input roots. Missing or zero resource limits fail closed; a future selection must set each byte/process/time cap and the complete live, retained and cumulative union before authentic reads or launches.

## Required source-owned lifecycle

A mandatory pre-label boundary inside S02/S04/S05 precedes these calls: resolve all private aliases and role overlaps; seal domain grants and incompatible contexts; admit clean ancestors and physical isolation; only then issue local development labels. This is separate from the later S13 method/state freeze and S19 target barrier. Complete actor/source registries and all attempted information grants are retained.

1. **register_source** accepts the participant source manifest, build recipe, dependencies, external/pretrained asset declarations, seeds and scientific intent. It returns an immutable source identity. A and B have identical common numerical dependencies; A has no author REVE implementation hidden in installed modules. Network access is disabled. Native compilation, asset terms and sandbox admission require separate qualification. Source cannot change after query admission.
2. **build** launches that registered source in a fresh build actor. It returns an executable/environment identity and original exit, stdout, stderr and resource receipts. Failed attempts remain in the ledger. A claimed generic container image is insufficient; the future image and build route must be pinned and qualified.
3. **plan_programme** receives the public paper-derived obligations, output schema and permitted train/validation descriptions. The participant supplies its learner configurations, data-dependency graph, variant graph, search policy and budget allocation. The operator checks complete scope and safe dependencies without choosing a better method. A/B plans and conflicting family/profile development contexts are independent. Each source-generation/search plan carries context_admission_receipt, monotone exposure_receipt and its domain-specific dependency closure. The operator assembles their whole-programme union without returning another domain's learned decisions to a developer. Process/product counts derive from the actual sealed roster, not an inferred convenient job count.
4. **pretrain** launches the participant executable on the selected training corpus, geometry, configuration and seed. It emits learned states, separate masked-loss sums/counts, effective exposure, schedule, parameter/configuration fingerprints and checkpoint inventory. Every required scale and ablation remains mandatory. An evaluator-produced state cannot be inserted as participant output.
5. **adapt** launches participant source with its selected pretraining state and permitted downstream training data. Development may access only its domain's declared validation labels within the sealed total search budget; all generated source, trial feedback and selected states inherit that exposure and stay in that domain. Every trial, invalid configuration, early stop, failure and state-selection decision is retained. Protected query metrics and labels are absent. Native test-exposed replay is quarantined operator evidence and cannot supply protected states.
6. **cross_finetune** actually trains on the five specified XFT sources, with exact class/units/geometry mapping and protected-query overlap exclusions. It produces a distinct PT→XFT state and training receipts. Relabeling a PT checkpoint does not satisfy this call.
7. **make_soup** runs registered source on exact compatible completed member states under a preregistered rule. It emits the averaged state and member weights, tensor/buffer schema and compatibility receipt. Averaging metrics or ensembling predictions is a different method and must be labeled accordingly.
8. **freeze_programme** binds registered source, produced states, all training/validation selection receipts, input/support manifests and output rosters. It closes development across every query-coupled family, dataset and arm before protected input release and verifies the complete earlier developer/source/context exposure closure. The early isolation boundary cannot be replaced by this later freeze. Optimizer states and mutable training caches are absent from inference views. Custody signatures do not establish scientific fidelity.
9. **calibrate_case** creates a fresh actor for each person/shot/draw/PT-or-XFT case. It sees only its own2N labels, permitted calibration inputs and frozen encoder state. It emits a case-specific state. No other draw's state or query result can enter. Any permitted centroid or EA fitting happens here before query input release. Calibration support and transformations must satisfy SCIENTIFIC_METHODS.md.
10. **predict** launches the actual frozen participant executable on one admitted epoch or one declared ISRUC20-epoch sequence. It receives no target, expected metric, reference output or persistent writable cross-query cache. Output contains opaque event IDs, ordered class scores, representation type and admitted diagnostics. Protected inference forbids fitting batch statistics, gradient updates and state/architecture changes on query inputs. A fresh process per query is the conceptual boundary; an immutable worker may replace it only after an independent equivalence audit proves request independence. Reusing a mutable object across cases is insufficient.
11. **collect_closed** accepts original completed-process receipts, the expected output manifest and stable ordinary files. It snapshots files, rejects links and path escapes, verifies shape/class order/finiteness/probability rules and exact case/run/event coverage, and joins source/state/request/resource identities. Missing, duplicate or unexpected products fail admission. It reads no targets. Leftover output from a failed process is not a completed prediction. Candidate and reference banks must each reach an explicit valid terminal state, including failed or abstaining attempts.
12. **grade_protected** starts only after the global barrier below. It opens operator targets once and computes metrics from closed predictions, including independent reference predictions. Caller metrics remain untrusted participant claims. The grader produces all family comparisons, uncertainty and completeness denominators without launching models, fitting transforms or importing participant code.
13. **report_science** joins the participant's frozen methods/hypotheses with the closed evaluator results into source-bound tables, claim assessments and error analyses. Unsupported conclusions remain marked. Explanations after scoring cannot change source, states or predictions. Reproduction and protected improvement remain separate reports.

## Observation and output types

TrainingInput contains exact tensor projections, units, clocks, channels, approved labels and group tokens needed for permitted development. QueryInput contains opaque event IDs and admitted EEG/geometry/clock metadata only. Class ontology/order is public; class-bearing source filenames are not. SequenceInput contains20 consecutive epochs, clock joins and20 ordered event IDs without labels. State is a passive safe tensor/configuration bundle with fitted-data dependencies and trained-parameter masks, not pickled executable code. Model source is registered separately and executes only in its actor.

ProcessReceipt binds original request, source, state and input identities; OS exit/signal; start/end and monotonic wall time; CPU/GPU/device/RAM/VRAM/scratch telemetry or explicitly unavailable measurements; retry parent; output/log manifests; and enforced limits. Missing telemetry is not silently recorded as zero cost.

PredictionOutput is an N×K finite float32/64 matrix with explicit probability or historical raw-logit representation and exact event/class order. Probabilities lie in[0,1] and sum to1 within1e−6; raw logits remain finite and unnormalized. Class-only output is insufficient except the explicit hard one-hot NCM convention. ReconstructionOutput and LossCountTrace include every component's raw absolute-error sums, masked-patch/sample/example/batch counts, width, mask identity, named patch/sample/batch/rank/accumulation reductions, alpha/lambda, backpropagated scalar, train/eval status and original training/context provenance, as specified in LOSS_PROFILES.md. A profile mismatch cannot be hidden by multiplying the reported scalar. Future retained training reconstruction arrays stay private and are not source-publication payloads. RepresentationOutput binds authorized sealed features to exact state/support identities; it does not authorize a global cache of calibration labels. ClaimOutput records source citations, methods, effect direction and limitations, while evaluation uses measured products rather than supplied confidence.

Corpus audits, architecture/state lineage, source-parity and compute reports are mandatory typed products even when they have no prediction matrix. A scalar accuracy cannot satisfy those obligations.

## Global barrier, attempts and reuse

Before opening any protected targets, close the entire coupled programme: both arms, all purpose conditions, every source family/case/run slot, all independent reference banks, every few-shot draw/shot/PT-XFT calibration view and all supplementary mandatory products. Query input release requires programme freeze. No target-derived feedback reaches an active development actor. The operator seals the complete candidate/reference collection and terminal ledger before the grader receives a target mount. Partial banks cannot obtain early scores while other learners are active. Historical test-exposed diagnostics use quarantined historical material and never protected targets.

Before target access, failures return bounded structural reasons only. After access, a retry is an exposed attempt and cannot be presented as a fresh blind evaluation. Invalid, timeout or abstention statuses preserve missing products and denominators; they never fabricate scientific success. A complete terminal ledger is not a complete paper if mandatory scientific products failed. Original failures, retries and costs remain recorded.

States may be reused only with exact identity and permitted exposure proofs across source, environment, corpus, preprocessing, geometry, configuration, seed and selection history. No cross-arm, cross-purpose, conflicting-domain or cross-draw state/source/developer-memory reuse by convenience. A reuse_admission_receipt checks the full producer and source-generation ancestry against the consumer's allowed domain before access, including label-derived configuration/search/preprocessing/log dependencies. Every consumer retains its original producing-process identity and its own dependency/custody record. Trusted immutable feature reuse cannot expose other calibration labels or query-fitted statistics.

## Compatibility with the predecessor

The frozen stager, contract, collector, target bridge, scorer and spectral/NCM helpers remain historical source. Their tests do not implement this lifecycle. A future version must preserve all2144 case IDs and support checks, add the two missing ISRUC source products through a selected migration, extend outputs to corpus/architecture/soup products, bind actual execution receipts, and replace unverified caller-provided reference metrics with independently produced and scored banks. No source or implementation change was made here.

## Participant ownership of scientific preprocessing

The operator's ingest establishes authentic object identity, clocks, physical units, target custody and permitted observation boundaries. It does not silently perform the participant's scientific method. A **prepare_signal** call launches registered participant or independent reference source on the permitted raw/physical training observations to implement filtering, referencing, resampling, windowing, artifact rules and fitted normalization/EA. It emits the transformed views, fitted preprocessing state, exact raw-to-event mapping and process/resource receipts. Its source and learned preprocessing state are bound into freeze_programme. Training-only and case-calibration dependencies are checked before use; inference applies the frozen recipe inside the same isolated predict call to the admitted query observation. No operator-side hidden transform may give a candidate a better method than its submitted source produces.

Common prepared epoch projections can be offered later as an explicitly labeled convenience/input condition, symmetrically in A and B. They do not demonstrate participant reproduction of the raw-to-epoch scientific operators. Full-construction reproduction requires the participant-owned preprocessing products; the reference bank uses its independently fixed converter. The operator may independently compare outputs for source parity but cannot replace a failed participant product with its own. Source profiles that require full-session context remain tagged retrospective/transductive; protected query observations cannot expose such extra context by convenience.

## Required S2 evidence types

ExposureDomainRoster, PrivateAliasOverlapGraph, CompatibilityDecision and PermittedLabelGrant are operator-owned S04 products. ContextAdmissionReceipt binds actual developer/conversation/tool/source ancestry before local labels; ExposureReceipt is append-only; ReuseAdmissionReceipt checks the complete producing closure. Public requests carry opaque domain handles and receipt identities, never private alias/label rows. Every build, source revision, prepare_signal, pretrain, adapt, cross_finetune, soup, calibration, predict and report product carries these joins. Collector admission requires their real actor/input/process enforcement, not participant-authored clean=true fields.

ObjectiveProfile, LossCountTrace and ScheduleProfile/StepExposureTrace are produced by S07/S08 and inherited by every downstream state. S18 checks their component/denominator/profile identity; S20 uses independent formula references for matching products. A/BConfirmatoryManifest fixes the full160contrast union and direct-A/B exploratory classification before relevant outcomes, with no changes to the original80logicalreferencefamilies. These are design contracts; none of these receipts has been materialized or empirically validated.
