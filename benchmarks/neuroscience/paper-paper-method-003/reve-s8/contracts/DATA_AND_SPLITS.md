Each support row binds datasetversion, personalias, recording, session, event, stimulus where applicable, eventstart/end in source clock, epoch clock, orderedchannels/reference/frame, targetontology and sequence/index if applicable. The public row IDs are randomized opaque tokens with an operator-private bijection to biological/source identities. Filename, path, key order, original class suffixes, source split names and sorted labels must not leak targets. Provenance includes original exclusion reasons and counts before any prediction. Empty or incomplete source support is not eligible for a complete score.

A query observation is one complete source epoch, except ISRUC's declared20epochsequence supplies all20inputs together and requires20orderedpredictions. That is retrospective sequence classification, not a causal forecast. Noncausal filters and whole-epoch normalization must be labeled. Source per-session statistics may depend on other query epochs; this is historical transductive exposure. Protected improvement instead derives fitted global normalization/imputation/whitening/EA/artifact thresholds exclusively from training, or from the current disclosed few-shot calibration where explicitly permitted. No cached statistic may depend on future query items, assessment labels or another draw. Pure deterministic filtering within the current declared observation is allowed with fixed coefficients/boundaries and exact same reference inputs; whole-session context beyond the observation is forbidden unless a separately named condition explicitly permits it.

The source folds are not replaced when comparing public table numbers. For strict_person, a new qualified sealed biological split is required across all10datasets, respecting real group sizes/classes and clustering repeat recordings. Use source person splits where truly disjoint and validated; otherwise choose and freeze a new person roster using only source metadata before fitting, with a manifest that fully identifies grouping, stratification and seeds. This changes the scientific condition and cannot produce a direct historical table deviation. Lack of identities or feasible class support blocks that condition; it never licenses an epochwise fallback. Human source metadata can define split strata, but its diagnostic/target fields are absent from learner views except approved training/validation labels.

For strict_person_and_montage, compare actual normalized ordered channel membership and acquisition reference/geometry, not arbitrary montage IDs. Equal channel sets with a new name are not disjoint. A single-montage dataset may have no natural feasible partition. Retain its mandatory cell as unavailable rather than invent a valid held-montage claim. Future intentional sensor-subset transfer would need its own sealed selection/exposure specification, preserved alongside source sparse conditions.

Sparse conditions require identicalevent/run universes acrosscounts. Few-shot requires a fixed288event universe per person acrossallshots/draws/methods,144/session; exactly2Ncalibration labels and288−2Nquerytrials. The global mapping of which events are labeled across1,800cases is private. A fresh actor per case receives its own training/XFTstate and only its2Nlabels; state/query outputs from onecase cannot enter anothercase, even if their query sets overlap. PT/XFT pairing is enforced by exact support/draw identity, not merely equal seed labels. Reused label-free features are permissible only if the frozen feature producer depends on no target person calibration/query statistics and no otherdraw; an operator cache does not expose the global feature table to participants.

Query targets are reserved relative to each domain. A label authorized for principal BCIC training can be a protected few-shot query label in another domain; therefore the cross-domain method/developer/source boundary in EXPOSURE_DOMAINS.md must be established BEFORE its first development release. A fresh final process and a late grader mount do not remove upstream label exposure.

All splits reserve their own query targets for the grader. Pretraining reconstruction targets are the training input patches within authorized training scope; they are not held-out downstream targets. Unsupervised pretraining on a downstream query recording still constitutes exposure and is forbidden in the protected condition. Foundation-model and XFT source data overlap is audited even if labels were absent. Public checkpoint replay cannot be called clean held-person transfer without training-data lineage. Exact unknown baseline pretraining exposure stays an explicit qualification gap.
