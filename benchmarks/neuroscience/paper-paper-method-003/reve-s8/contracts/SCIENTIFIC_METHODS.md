Every operator emits a content-bound recipe, source identity, units/shapes, complete support, upstream state identities, randomness, fitted-data dependency set and resource/terminal receipt. Numeric arrays and checkpoints below are future products; none was generated in this design phase.

## Corpus and input construction

The full corpus operator must reconstruct all92 original sources, not the redistributable subset. Preserve the paper's24,274people/150,833sessions/61,415hours,19TBraw/6TBprocessed and396electrode-name claims with reconciliation of exact source identities, versions, all exclusions and apparent Table7/name-list discrepancies. Count unique biological people separately from source-local aliases, sessions, recordings, windows and channel layouts. A public anonymous alias may group authorized splits without exposing private identities. Do not infer membership from model weights. Exclude all downstream source recordings/people required by the intended pretraining regime and audit overlaps with XFT and source foundation baselines.

Paper pretraining converts to200Hz, bandpass0.5–99.5Hz, float32, session-statistic z-scores clipped to±15SD, and ten-second windows; recordings shorter than10s and downstream datasets are excluded. Exact endpoints, filter type/order/phase, resampling, constant-channel policy, boundary padding, reference and artifact removal are source-qualification requirements. The native loader consumes big-recording, corrected-session and statistic CSVs plus EEG/position/statistic memmaps. Raw-to-corpus conversion is missing. Its filtered session indices, strict length test, exclusive end-window range, channel-count bucketing and c>6 training filter require source parity; a paper metadata total is not actual eligible training support. Window boundaries cannot cross recording/session splits. Logs preserve dropped short sessions/tails/channels, sampler leftovers and effective exposure.

## Tokenization and geometry

An epoch is a C×T real signal at exactly200Hz plus C×3 authenticated electrode coordinates, axis/origin/frame, reference scheme and physical unit provenance. Physical mV is retained as a separate projection for the spectral control. Model normalization and division by source scale factors are explicit transformations; dimensionless z-scores cannot be substituted for mV. Ordered channels, bipolar derivation signs and pair endpoints are bound to every signal row. Pair midpoint coordinates encode a bipolar channel's location, not its polarity; the actual signed voltage difference remains in the signal. Unknown coordinates, casing aliases, legacy T3/T7 naming, reference electrodes and coordinate frame changes require an authenticated mapping, never a zero-filled coordinate guess.

Use 200sample windows with20sample overlap, stride180, complete-patch count floor((T−200)/180)+1 whenT≥200, and a declared tail disposition. This count is the native unfolding behavior, not an assertion that ambiguous paper notation is equivalent. The paper-literal adapter uses centimeters and1-based patch times times an explicit scale; native Fourier source uses supplied spatial coordinates and0-based patch index times0.1. Neither numeric scale is seconds without a declared conversion. Noise0.25cm corresponds to0.0025m only when source units are meters. Immutable coordinate bases must survive training noise. Time/space scaling, margin0.4 and width1.8 in the native Fourier map are recorded separately from paper intentions.

Fourier encoding uses a Cartesian four-dimensional frequency grid, sine/cosine features and a learned4→embedding MLP withGELU/LayerNorm, then sum/LayerNorm. Paper Small/Base use4frequencies and512width; Large uses5frequencies and1250width. Native Large config uses1216width and truncation. This source difference stays gated; the source slice with zero truncation must be checked before any proposed1250 configuration. Small/Base/Large depth/head/dimension variants and no-learnable-position alternatives remain distinct states. Learned finite position/time tables have defined support limits; unsupported unseen geometry cannot be silently clamped to a known electrode.

## Masked reconstruction and architecture

The paper noncausal transformer uses RMSNorm, GEGLU, FFN ratio8/3, FlashAttention2 and the selected bias/initialization rules. The paper Eq.1 primary objective averages vector L1 patch norms; the native source instead averages scalar sample errors. LOSS_PROFILES.md fixes separate R-paper.patch_L1 and R-native.sample_L1 profiles, explicit per-example and pooled counts, batch/rank/accumulation conventions, and the width200 conversion only under identical support and weighting. The global learned-query attention context concatenates the selected encoder layer outputs; the secondary two-layer decoder reconstructs the same masked samples from repeated context plus positions. Total training objective is alpha*(Lprimary+lambda*Lsecondary), with alpha=1 and lambda=0.1 in the stated dual-loss condition, using the same named reduction for both components. Mixed reductions or compensating scale changes are separately named changed objectives, never silent fidelity corrections. Return primary and secondary sums/counts separately, not only an ambiguous combined scalar. Native source includes the input embedding in the layer-output list and computes secondary loss only during training; paper descriptions differ. A validation trace of primary-only loss is not evidence of the total training objective.

Block masks cover spatial radius3cm, temporal radius3 in the qualified paper/native clock,55% ratio and10% spatial channel dropout radius4cm. Native blocks repeat3patches: that is not automatically3physical seconds with0.9s stride. Mask construction indexes flattened patches in a different apparent order from MAE channel-major flattening; original mapping must be resolved before claiming spatial/temporal masking fidelity. Random mask controls retain25/55/75% and all frozen/fullFT branches. Mask counts, union/overlap, nonempty complement, same random seed policy and actual loss denominator are required products. An encoder that never sees a channel is different from masking its reconstruction target; do not conflate dropout, token dropping and zeroing.

Small/Base/Large paper sizes are approximately12/69/408M parameters with depths4/22/22 and heads8/8/19. Exact parameter counts, decoder depth and head dimensions, learned queries, active parameters and checkpoint tensor shapes must be emitted from the future producer. Paper StableAdamW usesβ=(.9,.95),eps1e−9,peakLR2.4e−4,batch4096,initstd.02 and10/80/10warmup/stable/decay with end1%peak and dimension-scaledLR∝D^−.90. Retained defaults differ in betas,LR,batch,epochs and schedule. The paper itself describes a cyclic trapezoidal variant. Native scheduling also cycles from an epoch-iteration argument, but exact integer boundaries, initial/restart LR, optimizer-update versus microbatch clocks, resume state and bucketing/DDP/accumulation exposure need the full ScheduleProfile/StepExposureTrace in SCHEDULE_AND_MULTIPLICITY.md. Cyclicity alone is not a paper discrepancy. Distinct source profiles must be frozen, not mixed into a favorable hybrid.

## Adaptation and variant union

For each requested architecture/corpus/seed state, full pretraining produces an encoder plus complete training state and summaries. LP freezes the backbone, fits the specified head and any explicitly source-permitted learned pooling query; an attention query is a trained parameter even when called linear probing. FT identifies all trainable parameters, LP warm start, optimizer, early stopping and optionalLoRA adapters. Native dt.py does not instantiateLoRA despite a config switch; the legacy train_core path does. NoLoRA label without executed parameter evidence. Baseline and candidate heads consume the same qualified epochs; architecture-specific adapters may differ with declared source justification.

The source native train_stage selects best validation balanced accuracy, evaluates/prints test at each improvement and returns the final in-memory state rather than necessarily reloading model_best. dt_opt maximizes the returned best_test. These paths are historical exposure diagnostics. Prospective adaptation uses training and validation only, freezes one selected state by validation balanced accuracy (first chronological tie) for neural reference models, never prints query metrics and does not refit on train+validation in this initial fixed reference recipe. LP andFT selection are distinct snapshots; FT begins from the selected LP state, not the last worse epoch. Candidate search may choose its own prespecified validation criterion within the same budget; it must retain the complete search and state lineage. No query-driven configuration or repeated evaluator feedback is allowed.

Tables3–4,17–20 instantiate the exact declared grids, not a Cartesian explosion of every ablation. Pretrained, nonpretrained, frozen, pool/no-pool, dual/primaryloss, mask ratios/types, PE/noise/dropout/time and activation/norm configurations receive different training-state fingerprints unless exact recipe identity proves reuse. Negative effects on ISRUC/HMC and dataset-specific activation reversals remain mandatory outputs. Table18 supplies eight-dataset aggregates only; no invented per-dataset historical values. Model scaling is a descriptive controlled-size comparison; no fitted scaling-law or causal architecture attribution without matched budget/corpus exposure.
