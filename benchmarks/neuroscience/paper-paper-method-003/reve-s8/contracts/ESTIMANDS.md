# Metrics, aggregation and uncertainty

## Classification definitions

The grader derives metrics from admitted prediction matrices. Class order is fixed, and argmax ties choose the lowest class index. Source reproduction uses event weights w_i=1. The inherited prospective estimand uses w_i=1/n_person(i), where n_person is that person's complete declared query-event count before any prediction failure. Define C_ab=sum_i w_i·1[y_i=a,pred_i=b]. Missing outputs invalidate complete scoring rather than changing these denominators.

Balanced accuracy is the mean of K class recalls, defined only when all K target classes have positive support. Cohen's kappa is (p_o−p_e)/(1−p_e), where p_o is weighted accuracy and p_e is the dot product of target and predicted class proportions; it is undefined when p_e=1. Weighted F1 averages 2C_cc/(rowtotal_c+coltotal_c) by target class support, using zero for a class with zero denominator. Report the confusion matrix, class support, all-classes-present flag, and event/person/session/recording counts. Multiclass source endpoints are BA, kappa and weighted F1; binary source endpoints are BA, AUROC and AUC-PR.

Binary AUROC integrates tied-score blocks in ROC space. Average precision is sum of Δrecall×precision over complete tied-score blocks; trapezoidal PR area instead averages adjacent precisions, starting at recall0/precision1. They are distinct. When either target class is absent, ranking metrics are undefined. Original AUC-PR identity remains a source gate, so both named diagnostics are retained until resolved. Native eval_core ranks raw positive-class logits, while prospective ranking uses positive-class probabilities. Softmax can change rankings across examples; no silent conversion is allowed. Main native binary=False calls return placeholders, not measured AUROC/AP.

Equal-person-total-weight pooled confusion/ranking metrics are NOT the mean of per-person metrics. The latter can be reported separately with their own undefined cases. Source sleep metrics pool individual epochs;20-epoch sequences are observation groups, not independent people. Prospective weights pool all epochs within a person, retaining sequence and recording dependence. Repeated recordings cannot be counted as new people.

For each non-few-shot case, retain every metric for the complete qualified run roster, then compute an equal-run mean and explicitly named population/sample SD. Original run count, seeds and SD convention are not known merely because n_runs=10 appears in an Optuna configuration. Failed runs remain in the required denominator and prevent a complete-run mean. A conditional observed mean may be displayed separately with completed/required counts; missing values are never replaced by zero.

Few-shot reduction first scores each person×shot×draw×method on all288−2N remaining query events, averages all20 draws within that person, then gives each of the nine people equal weight. PT/XFT comparisons use paired calibration and query supports. Same-session and other-session query results are supplementary diagnostics; primary scoring uses both sessions. Overlapping query events across draws are dependent. Five shot levels are correlated learning-curve points. Soup metrics come from predictions by the actual averaged state, accompanied by every member's result and the validation-selected best single member. Averaging published accuracies is not a soup result. Pretraining products report primary/secondary loss sums and counts, effective exposure, parameter identity and compute. Loss comparisons require matched units, masks and denominators. Architectural contrasts with different corpus exposure or compute are labeled confounded descriptive comparisons.

## Reproduction and improvement

Reproduction reports signed and absolute deviation from an explicitly identified historical or regenerated endpoint, with protocol/source matching status. Public means and unidentified SDs cannot determine an acceptance tolerance. Future numerical parity tolerances must be independently chosen from precision/algorithm considerations before authentic results. Faithful null and negative findings count as faithful reproduction. A close table mean alone does not establish methods fidelity or full-paper coverage.

Improvement reports signed candidate−reference differences for every dataset, condition, endpoint and fixed comparator. Primary performance is balanced accuracy on the inherited equal-person-weight pooled support. AUROC/AP or kappa/F1 remain secondary scientific endpoints; the best-looking metric cannot replace the primary. Probability calibration diagnostics are additionally fixed as mean multiclass Brier score sum_c(p_ic−1[y_i=c])² and negative log likelihood −log(max(p_i,y,1e−12)), using the same event/person weights. Report the count of clipped assigned-class probabilities and retain the unclipped probability objects. These are new prospective diagnostics, not source-table endpoints; hard NCM one-hot output does not become a calibrated model. None has been executed.

This design returns continuous effects and uncertainty, not an unjustified binary reward. A future thresholded success claim needs a preregistered minimum effect and resource rule plus competent comparators. No novelty or current SOTA follows from beating a dated public table number.

## Prospective uncertainty

The biological inference unit is the held-out person. A fixed prospective recipe uses10,000 paired person-cluster bootstrap replicates with a seed committed before query access. Sample people with replacement and carry all their recordings, events, sequences and paired candidate/reference predictions together. For each fitted run, recompute the declared pooled metric with person multiplicities; then average run metrics using the same fixed run roster. Do not average predictions across runs unless an ensemble was the declared method. This interval conditions on the fitted states. Report training-seed SD separately; seed variation does not increase biological N. Joint inference over training randomness would require a separately selected crossed person/run design.

Use percentile2.5/97.5 bounds on valid paired-difference replicates and report every undefined replicate. Never redraw until a class appears. If fewer than95% of replicates are defined, mark the interval unqualified and report the class-support limitation. This is a new fixed prospective recipe, not the original paper's interval. Tiny groups, including two held BCIC people or four arithmetic people, limit population inference; show individual contributions and avoid broad generalization claims.

For few-shot uncertainty, bootstrap the nine people and carry all20 draws, five shot levels and both methods together. Draw variation within a person describes calibration-sampling uncertainty and is reported separately. It does not create180 independent people. Source within-person speech evaluation remains conditional on that training regime; resampling its15 people does not turn it into held-person decoder performance.

The confirmatory primary family is the union of both candidate arms:2×20dataset-condition cells×4references=160 predeclared paired BA contrasts, preserving each arm's80slots. This is a contrast count, not160independentreferencefits. Report ordinary95% intervals and approximate two-sided centered-bootstrap p-values: p=(1+count(|delta_b−delta_observed|≥|delta_observed|))/(B_valid+1). Require the validity threshold above, disclose Monte Carlo resolution, and apply Holm over the full160-slot A/B union. No arm may be chosen after outcomes and presented with only its80-slot correction. Unavailable contrasts receive p=1 only for conservative adjustment bookkeeping while their scientific estimates remain null. Bootstrap testing/coverage must be calibrated before confirmatory use; it has not been validated here. Missing or infeasible cells do not shrink the family after outcomes are seen.

Secondary metric, ablation and family analyses are exploratory unless separately preregistered. Shared people across datasets require an alias-based joint resampling manifest for aggregate uncertainty. Without it, aggregate intervals remain unqualified rather than assuming independent datasets. Mean±SD is not automatically a confidence interval of the mean; the source checklist's68% language does not resolve the underlying run/population estimand.

The20direct A-versus-B primary-endpoint differences are exploratory descriptive effects, not part of the160candidate/reference confirmatory family and not confirmatory superiority claims. Both complete arms are reported; marginal95%intervals are not simultaneous intervals. Details and any prospective new confirmatory selection are governed by SCHEDULE_AND_MULTIPLICITY.md.

Reconstruction estimands use LOSS_PROFILES.md: paper vector-L1 E/M versus native element-mean E/N, exact per-example/pooled counts and matched support. Width200 yields the stated factor only under identical reduction weighting; unequal per-example masks make equal-example and pooled reductions distinct. Primary/secondary terms, alpha/lambda, raw and displayed scalar values, signal units and optimizer-state identity are preserved separately. No loss conversion grants checkpoint equivalence or scientific qualification.
