# Source licenses and boundaries

The existing benchmark license is MIT, copyright 2026 Brain Researcher. It applies to benchmark-owned implementation and documentation, not to third-party or data/model assets. Exact original license text is retained in LICENSE.

Included namespaced REVE code is covered by the retained REVE MIT license (BRAIN – BRoader Artificial INtelligence). The exact CBraMod (Jiquan Wang) and BIOT (Chaoqi Yang) root MIT notices are retained as provenance, but their complete adapted source families remain external pending nested-source notice closure. Original notices remain in each source file. Empty namespace files and prospective adapters are benchmark-owned. The original ARL CC0/Apache license text is retained for the EEGNet reference lineage; the Torch EEGNet implementation is explicitly a benchmark reconstruction, not the original TensorFlow program. The full ARL text includes its jurisdiction and patent notes and is not abbreviated to CC0.

The external Braindecode snapshot is not uniformly BSD. Its exact file headers include BSD, MIT, Apache, noncommercial and unknown upstream terms; a required NOTICE closure is absent from the selected source packet. The whole library remains external, including the EEGConformer/DeepSleepNet/USleep dependency chain. There is no partial library substitution.

StableAdamW records optimi MIT, PyTorch BSD, torchdistX BSD and Composer/timm Apache lineage. Its complete applicable notice set is not resolved here. ST-Transformer cites a modified external EEG-Transformer body; LaBraM cites BEiT-v2/timm/DeiT/DINO bodies. Those three implementation files remain external until their source/notice closure is checked. Their exact adopted source identities and upstream revisions are retained in EXTERNAL_SOURCE_DEPENDENCIES.json.

Code licenses do not grant data, pretrained-weight, montage-bank, participant-identity or paper redistribution rights. None of those bodies is included. Source provenance and declared scientific behavior are retained without publishing private raw history, logs, signed URLs, credentials or primary-paper bodies.

Additional concrete evidence: three BIOT residual-block files retain PyHealth example references; CBraMod criss-cross source retains the PyTorch TransformerEncoder structure and internal API call. A root MIT license alone does not establish the full inherited notice set for those bodies. No legal compatibility is invented; both adapted families remain external.
