# REVE benchmark source proposal

This proposal contains benchmark-owned implementation and contracts for PAPER-paper-method-003, with a selected set of source files covered by retained licenses. It is an inspection and development package. **It is not a runnable complete reference distribution or a scientifically qualified benchmark.** The execution entrypoint refuses before reading any execution authority or input.

The retained design covers 2,144 cases, including 1,800 few-shot cases, ten datasets, 13 scientific families, 54 obligations and 22 stages. The 30 qualification gates, 37 source discrepancies and 50 future scientific controls remain. Cases and versions do not add canonical benchmarks.

Paper reproduction compares participant access to paper + data with paper + data + authenticated author code. Prospective improvements use frozen outputs, common support, independent references, protected target-last grading and complete reporting. Historical native reproduction and prospective methods remain separately named. No result or SOTA claim is made.

Use `python3 -B run.py inspect` for a source-only scope report. It needs only the Python standard library and opens public contract JSON. It does not import neural libraries or open data. `python3 -B public_source_check.py` checks this package's finite source manifest and dependency declarations. Neither operation establishes scientific accuracy.

All benchmark controller, custody, source registration, exposure, support, prediction, grading, reduction and reporting source is included. The accepted reference actor and benchmark-authored preprocessing, corpus, fitting, calibration and state adapters are retained. Missing third-party source is listed individually with original path, byte identity and pinned upstream revision; no substitute algorithm or silently reduced roster is provided. The original 222-member fixed-reference identity has 31 exact members here and 191 external members. It cannot be registered or run from this package alone.

Read API.md, S8_ACTOR_API.md, S8_SCIENTIFIC_SOURCE.md and contracts/PARTICIPANT_API.md for the interfaces. Contracts retain all required scientific products and failure denominators. PUBLIC_STATUS.json states exactly what can be inspected. EXTERNAL_SOURCE_DEPENDENCIES.json and RUNTIME_DEPENDENCIES.json close every declared source/import edge as bundled or explicitly unavailable. DATA_MODEL_DEPENDENCIES.json lists the separate acquisition and qualification requirements.

Benchmark-owned code and documentation use the existing Brain Researcher MIT license. LICENSES_AND_PROVENANCE.md and PUBLIC_FILE_PROVENANCE.json give per-file terms, creators and source identities. Third-party code is not relicensed under the benchmark license. The retained Braindecode snapshot has mixed file licenses, including noncommercial and unknown terms, so its whole exact package remains external. StableAdamW, ST-Transformer and LaBraM nested notice/license closure also remains unresolved. No network or installation is performed by this proposal.

Original dataset-specific heads/checkpoints, historical recipes and run rosters, authentic corpus and exclusions, raw-decoder/native agreement, and REVE-Large secondary reconstruction width limitations remain. Exact private build history and original observations stay private; the aggregate provenance statement does not impersonate their proof. Root and a different reviewer must approve this public subset before publication. No Git commit, push, deployment, authentic execution or benchmark-count promotion accompanies it.

The complete adapted BIOT and CBraMod families are also external pending incorporated-source notice closure. Their root MIT notices remain available as provenance, without relicensing nested source. `run.py execute` is disabled; internal actor functions, vendor examples and low-level source are not a sandbox or authorization to execute. Only the two documented source-inspection commands are selected for this proposal.
