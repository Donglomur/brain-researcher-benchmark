# S7 fixed actor and plan contract

reference_actor.py is a closed independent-reference entrypoint. contracts/FIXED_REFERENCE_SOURCE.json pins every source file needed by its bundle and its actual source ID. The controller requires the exact source manifest, source ID and entrypoint for independent reference jobs. Existing participant source registration remains available to A/B.

The actor consumes the existing reve-actor-request-v1, emits the existing typed reve-process-product-index-v1, uses the existing native /input and /output mounts, and accepts no module/function/command callback. payload.reference has exactly configuration, views, parent_state, members, and qualification. Configuration has the closed recipe, seed/device, immutable scientific cases, initialization and pretraining identity, purpose/condition, ablation, and qualified geometry. The fixed source fixes its recipe rather than accepting a caller-supplied optimizer/grid. Interpreter, dependency environment, rights, passive pretrained assets and native competency still require independent selection.

S05 emits build registration. S06 emits the full method plan. S07 constructs the actual parameter schema. S08 runs the explicit prospective reconstruction producer with one declared loss product for every optimizer update. S09 adapts; S10 uses the exact five-source XFT collection; S11 independently fits soup members; S12 first writes an averaged state, then a separate DAG job summarizes that already closed state. S15 fits calibration-only centroids; S17 predicts one epoch or one ISRUC20 sequence; S21 consumes the closed public grading projection; S22 prepares physical epochs. S01/02/03/04/13/14/16/18/19/20 remain trusted controller/operator roles.

Input arrays are operator-selected immutable .npy objects with allow_pickle=False. A reve-fixed-array-view-v1 declares role, dataset/projection, unit/rate, signal/label object names, exact events and people, geometry object, channel IDs, support and geometry qualification. TRAIN and DEV are disjoint. Query manifests contain no label object and permit exactly one current query view. Pretraining receives a qualified reve-corpus-buckets-v1 manifest that streams bounded shards across REVE-92-source-corpus, retaining all92 source dispositions and per-window geometry. It receives each shard in separately named session-zscore units, with source inventory, normalization and exclusion qualifications; normalized data never substitutes for physical millivolts. XFT uses a closed five-source collection and preserves source/ontology/exclusion qualifications.

Passive pretrained adapters accept safetensors only. An operator-qualified original asset product uses asset. tensor keys; this is distinct from a fitted model. state or pretrain. MAE state. Fixed adapters map known REVE/CBraMod/BIOT/LaBraM tensors. Missing non-head tensors, unexpected keys, or incompatible shapes fail. No unsafe checkpoint decoder, download, guessed channel-token mapping, or remote model code runs in the actor. Pretraining-to-downstream REVE mapping retains the actual encoder and deliberately initializes the permitted head. A query configuration must exactly match the selected state's configuration.

All native fit/predict costs remain inside the existing original process receipt and limits. Output writes reserve byte/file capacity before writing. Trace capacity is checked before training; every required reconstruction update owns passive prediction arrays and an independent target identifier. The protected evaluator obtains its own targets, so the source cannot provide a passing scalar. Partial writes, exceptions, or unclosed processes do not become valid products.

Each original prediction group has a scientific_identity hashing canonical id/family/dataset/method/configuration/metrics. Its dataset and method must equal the original panel. Its prediction spec, selected state scientific_cases, state producer payload and query producer payload bind the same original question. State details repeat those exact scientific cases at collection. These immutable question fields are separate from an A/B participant's chosen algorithm.

Soup rows additionally declare arm and recipe=uniform_equal_weights_v1; the required soup product stores the complete soup_study tuple. The exact required union is programme × arm × each of R-paper/R-native/I-person/I-person-montage × ten datasets × Small/Base/Large × every selected run × five members, plus a separate ten-member Base/TUEV row. The single-run three-programme metadata fixture has372 studies. This is a study-slot count, not a task count. Unsupported mandatory profiles stay unavailable; deleting them or substituting the ten-member study for the five-member study is refused.

For REVE-Base-PT, S15 accepts only an actual pretraining/qualified passive asset state, including its pretrained attention-pooling query. It creates fixed100µV normalization without fitting a target-person statistic, then fits centroids. The PT route refuses S09/S10/S11 supervised fitting. REVE-Base-XFT S15 requires the distinct five-source fitted model and its frozen normalization.
