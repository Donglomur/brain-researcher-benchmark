## Source-owned requests and outputs

Each source process receives a bounded `reve-actor-request-v1` on stdin: programme/job/task/stage/operation, source/domain/context, exact input manifest, actual parent identities, expected products, sealed payload and limits. The original bytes, delivered byte count, argv, actual PID, start/end, stdout/stderr, exit/signal, cleanup observations, outputs and measured or explicitly unavailable telemetry are retained. No method is executed by parsing participant-reported metrics.

`products.json` has schema `reve-process-product-index-v1`, exact job ID and exact expected product census. Every product binds its source, original request hash, context, actual parent states, intended objective, owned objects and kind-specific details. Current kinds are executable, method_plan, corpus, preprocessing, architecture, state, loss_trace, schedule_trace, prediction, representation, soup, claim, resource and scope. The inert_marker kind is refused in production. Any unexpected file, duplicate ID, nonzero/timeout output or incomplete stdin invalidates collection.

An executable product binds the registered interpreted entrypoint, interpreter, environment, dependency manifest and actual build request; it is not a participant-provided shell command. Later scientific source operations consume that actual build. Model state is separately passive. Every actual source and every consumed participant product is automatically included in output exposure ancestry even if a submitted output spec omitted it.

`loss_trace` contains named primary/optional secondary reconstruction components, individual example/target IDs, exact mask indices and owned M×200 arrays, named objective and batch reduction, alpha/lambda, phase, actual reported scalar, mask identity, source request, optimizer/rank/accumulation and support. The protected audit reads independently selected target patches, recomputes E/M/N/B and the scalar, and retains disagreements. It does not infer gradients or checkpoint equivalence from a matching scalar. `R-paper.patch_L1` cannot silently become native element-mean. An absent evaluation secondary term is absent, not measured zero.

Schedule products bind an owned step-trace object and selected profile. The source oracle checks exact per-rank microbatch/optimizer/scheduler continuity, accumulation, skipped updates, resume profile and native cyclic integer boundaries. Cycling itself is permitted. Corpus, preprocessing, architecture and state contracts have separate exact operator-selected oracle facts; passive agreement never substitutes for empirical method validity. Soup audits read actual closed member and averaged tensors, require the selected member count/weights and compatible schemas, compare weighted floating values and enforce the selected nonfloating-buffer policy. No accuracy averaging qualifies as weight averaging.

## Query isolation and whole-case estimates

Prediction products correspond to a single epoch, one qualified ISRUC 20-epoch sequence, or an independently qualified immutable worker. The last route requires explicit prior request-independence evidence; a label alone is insufficient. A predict job has one exact query partition, no extra visible signals, no targets, and a state frozen before query input. Calibration uses a fresh own-case child, its own 2N labels and no sibling/parent feedback. All 1,800 cases remain.

`prediction_groups` assemble passive products into a whole case/run/purpose using exact event/class/support order. Every query product belongs to exactly one complete nonoverlapping group and one frozen state. A case may comprise many isolated processes without turning those queries into independent replicates. `case_profile_roster` explicitly maps all original case IDs to qualified scientific purposes; it does not automatically multiply every original paper case into every prospective condition. Additional protected cells and missing ISRUC products have explicit selected source mappings.

The grader accepts only closed groups, opens exact operator targets after the whole terminal barrier and computes metrics itself. Epoch-weighted source estimands remain separate from equal-person protected estimands. The fixed 160-slot A/B confirmatory union remains present with unavailable slots; direct A/B effects are exploratory. The future kernels implement paired biological-cluster resampling, explicit undefined replicates, Holm adjustment, few-shot draw/person reduction and named paper aggregates. They were not numerically qualified in this phase.
