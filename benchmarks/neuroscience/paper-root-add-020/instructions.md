# Archived IT face-memory curve reconstruction

Reconstruct the six numerical curves defined below from the released neural responses and face features. Submit a UTF-8 JSON object with exactly `schema_version: 1` and `records`. The 300 records must cover every combination of region (`AM`, `PR`, `TP`), condition (`familiar`, `unfamiliar`), and the 50 time values in `public_design.json`. Every record has exactly `region`, `condition`, `time`, `mean`, `sem`, and `defined_cells`. Row order is irrelevant.

This is an exposed, prescribed numerical component for the existing paper, not unrestricted paper reproduction or scientific-improvement grading. The paper is [Temporal multiplexing of perception and memory codes in IT cortex](https://www.nature.com/articles/s41586-024-07349-5); original author code and empirical inputs are in [Zenodo 10460607](https://zenodo.org/records/10460607). Original MATLAB source is not claimed to have executed unchanged.

Use `thousand_monkey_features.mat` for AM/PR and `thousand_monkey2_features.mat` for TP, with the corresponding `*_AM_psth.mat`, `*_PR_psth.mat`, and `*_TP_psth.mat` arrays. The exact local input identities are recorded in `input_assets.json`. These are pooled measured responses, not figure tables. Keep all 134 AM, 72 PR and 197 TP cells. AM/PR responses have eight rows beyond the available 1,036 feature rows; they are unused by this component. Do not infer cell-to-animal identities.

Divide each of the 20 face-feature columns by its full released RMS. Use the source archive's five-bin, 50-unit moving window on the documented 10-ms bins, at centers 4.5 through 494.5 in steps of 10. This preserves the archive clock: the README's time-unit label is inconsistent, and the paper body describes a distinct 100-ms window. Neither conversion to seconds nor the 100-ms variant is part of this numerical component.

For each selected stimulus set, compute the STA as `X.T @ centered_response`. To preserve exact constant-response zero axes, first subtract one observed response and then subtract the mean of those residuals. This is mathematically ordinary subset response centering, an explicitly disclosed finite-arithmetic adaptation. Cosine similarity is over all 20 axis coordinates; zero-norm cosines remain undefined. Do not replace undefined values with zero or apply an epsilon norm threshold.

For AM/PR, the familiar curve compares the axis from zero-based rows 0–999 with the axis from rows 1000–1035. For the unfamiliar curve use one NumPy PCG64 generator initialized with seed 0, generating 100 consecutive `choice(1000,36,replace=False)` subsets; the same saved draw sequence is used for both regions. Each draw compares its 36-row axis with its disjoint 964-row complement axis. Center each subset directly; do not subtract large cross-products to form the complement. These draws are a new fixed realization, not the authors' historical MATLAB RNG sequence.

For TP, the familiar curve compares rows 0–1007 against 1008–1043; the unfamiliar curve compares rows 0–1007 against the fixed matched unfamiliar rows 1044–1079. It has one matched comparison. The manuscript-caption AM/PR 964-vs-36 familiar sensitivity is stored in the reference separately and is not included in this six-curve score.

Average finite draw cosines within each neuron first, then calculate the finite-neuron mean and sample SEM at each time. A single defined neuron has SEM zero. No defined neurons means `mean:null`, `sem:null`, and `defined_cells:0`. Otherwise use finite means in [-1,1], SEM in [0,1], and integer cell counts within the region's total. Candidate/reference zero-support masks must agree for a comparable score. Other cell-count differences receive an explicit error metric; missingness cannot be used to omit difficult times.

The primary score is the arithmetic mean of the six curve RMSEs, one equal weight per region/condition, with equal time weighting inside each curve. Lower is better. Secondary metrics separately report SEM RMSE and cell-count MAE, plus count and undefined-mask mismatches. No binary scientific threshold is defined. These descriptive neuron summaries do not establish independent-animal uncertainty, causal effects, paper onset claims or a biological improvement. Adjacent windows, repeated subsets and regions are correlated.
