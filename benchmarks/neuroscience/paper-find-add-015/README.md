This package implements the **PAPER-FIND-ADD-015 numerical reconstruction control**, using processed optogenetic calcium-imaging traces. See [instructions](instructions.md), [submission schema](submission_schema.json), [exact public inputs](public_assets.json), and [verification](../../../authoring/opto-attenuation-v1/README.md).

The primary open-paper reproduction and improvement objective is preserved separately in [paper_task.md](paper_task.md). It has not been qualified by this exact-numerical control. No candidate program or LLM has been run. The continuous scorer accepts valid imperfect results, assigns zero error to exact reconstruction, and rejects invalid submissions without a scientific score. It requires the pinned local data and Docker runtime; it is not a self-contained hosted release.
