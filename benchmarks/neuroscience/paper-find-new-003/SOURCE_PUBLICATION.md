# BANC complete source publication boundary

This reviewable package preserves the existing `PAPER-FIND-NEW-003` assignment: 96 paper panels, 18 families, 24 legacy entries, seven operator branches and 139 accounting obligations. It adds licence texts, scoped notices and per-file attribution to the exact original 131-file source candidate. It creates no new benchmark or empirical result.

The original command and configuration descriptions remain in [complete-banc-v1/OPERATOR.md](complete-banc-v1/OPERATOR.md). Default and named `complete_banc_programme_v1` routes retain the same `run.py`, stage descriptors and `grade.py`. `DEPLOYMENT.json` remains unconfigured; execution, runtime qualification and scientific qualification are disabled. This notice operation neither runs those commands nor changes their source, configuration or exposure guards.

The selected portable source is complete as an audited package. It is not a claim that every upstream R source, package, PETSc/SLEPc dependency, Python/R environment, dataset, annotation, target, credential or source-of-result receipt has been acquired, installed or qualified. All 16 scientific gates, including G10/G12/G14 and independently signed runtime admission, retain their original meaning. The exact native package sources and benchmark adapters are distinguished in [SOURCE_ATTRIBUTIONS.json](SOURCE_ATTRIBUTIONS.json).

The new `LICENSES/`, `THIRD_PARTY_NOTICES.md`, `SOURCE_ATTRIBUTIONS.json` and this document sit outside `complete-banc-v1/`. The immutable `SOURCE_MANIFEST.json`, `SOURCE_FREEZE.json`, `SOURCE_CATALOG.json`, source-owned member sets, hashes, command paths and operative bodies are unchanged. The original influencer `DESCRIPTION` is restored at its original name using exact approved bytes, and source paths containing spaces remain literal.

Only the complete source allowlist reviewed for this package is eligible for a separately selected publication to `Donglomur/brain-researcher-benchmark` on its separate public history. No publication occurs through this supplement, and private build or agent ancestry is not part of the proposed public files. Historical TLS/cache failures, subsequent actual HTTP observations and the older bancpipeline licence distinction are preserved in the private review evidence and summarised in the scoped notices. The older commit has its own exact GPLv3 LICENSE and README grant evidence; this does not establish the separate, still-unverified Zenodo archive-to-tree equivalence. Complete independent notice review and a separate root publication selection remain prerequisites.
