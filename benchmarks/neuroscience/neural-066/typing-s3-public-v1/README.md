# NEURAL-066: controlled decoding of typed keypresses

This auditable **public source derivative** contains the controller, preparation algorithms, references, scoring, transport and scientific contracts. It supports inspection and operator preparation. It is **not a qualified runnable benchmark or a scientific result**. Different whole-source/content review and final publication audit remain pending.

Run the standard-library-only inspector from this directory:

~~~sh
python3 -B inspect_source.py
python3 -B inspect_source.py --check-ready
~~~

The first command checks declared file hashes and Python syntax. The second intentionally exits 2 and reports missing requirements. Neither imports benchmark modules, opens data, downloads, installs, trains, launches containers or calls a model.

The question is whether an event-assisted, retrospective observed-key decoder improves on timing, ocular, window and training-shuffle controls under matched held-person/template support. This is not corrected intended-text decoding, unassisted continuous typing or a physiological-causality test. Two matched case-local modes differ in when current-query information becomes available.

The complete scope remains one benchmark: 78 cases, six arms, two modes, 936 candidate episodes, 6,474 named reference fits, 1,794 prediction contexts, 164 descriptive contrasts and 24 open gates. MEG and EEG have 19 and20 modality-local identities; overlap is unresolved, so this is not a39-independent-person inference. Full methods and obligations remain in source/design.

All43 original Python roles are present, plus one operator-policy validator. Six original Python modules change only to carry a required private policy. Missing policy cannot select defaults or reduce support. Provenance-only reference-lock paths are made portable. New hashes require fresh independent authority/environment/model receipts.

Read OPERATOR_POLICY.md, DEPENDENCIES.json, PUBLIC_STATUS.json, CHANGELOG.md and LICENSE_AND_PROVENANCE.md. Private policy values, metadata, neural assets, target transcripts, fitted models, credentials, authoring history and tool logs are excluded. Actual execution requires separately qualified inputs, environments, custody, full resources, method admission and every original gate.

Known documentation issue C01 is retained: the reference ABI's generic samples_per_key=25 is too narrow for TIMING; actual feature/preparation/public-ABI semantics specify1 for TIMING and25 for channel-window arms.

Source paper: Non-invasive decoding of typed sentences from human brain activity; DOI10.1038/s41593-026-02303-2. This controlled observed-key endpoint and prospective source-adapted reference do not claim untouched paper reproduction or SOTA.
