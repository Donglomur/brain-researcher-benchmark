# Required private operator policy

No policy instance or placeholder identities are supplied. The operator must recover the exact original policy, compare it with the private accepted source, obtain independent review and select its byte/SHA pin in authority.reviewed_membership_policy. Schema validation alone is not approval.

op.native_inputs.membership_policy is an exact {path, bytes, sha256} descriptor under the selected native metadata root. operation.admit joins its pin to the independent authority and validates it before cohort/log reads. Original cohort/log/loader descriptors must match the policy. The controller rereads it under the original budget and stages the same immutable body only for operator preparation; native transport binds one disjoint individual metadata file.

The JSON has exactly eight fields:

| Field | Meaning |
|---|---|
| schema | neural066_operator_membership_policy_v1 |
| task | NEURAL-066 |
| source_revision | Original data revision fixed by the validator |
| loader_revision | Original author revision fixed by the validator |
| asset_pins | Exactly cohort, logs, loader; each positive bytes and lowercase SHA-256 |
| meg_aliases | Exactly the original four nonempty source-alias mappings |
| exclusions | Exactly the original nonempty-sentence exclusion with modality, alias, session, task, trial |
| drop_empty_keys | Literal true, retaining original25 empty dispositions |

The same authenticated policy is passed through membership, eligibility, loader authentication, projection alignment, joins, views and full shape accounting. Original formulas, windows, census, splits and statistical units remain. Incorrect but well-formed policies are unacceptable; independent selection against the original policy is mandatory.

Absent, mismatched or malformed policy fails. No environment-variable lookup, discovery, fallback mapping, synthetic pin or default exclusion exists. Candidate/reference realms receive no policy. This distribution cannot manufacture the required authority.

Both host policy reads and each operator job's capture/staging are real costs within the original clock and budgets. Future profiles must include them; no extra free allowance or old receipt is inherited. All source licensing, data, native/runtime/science gates remain.
