# License and provenance

The benchmark's own source and packaging follow the repository MIT license, included here. This does not grant rights in external data, original-author software, dependencies or weights.

The retained source lock records the original author source/config as CC BY-NC4.0 and explicitly denies a blanket redistribution grant. Original author bodies, loader, datasets, wheels and weights are not bundled. The lock records scientific parameter values and artifact identities; logical external-source labels are provenance identifiers, not installed paths or downloads.

Separately acquired neuraltrain, neuralset, PyTorch, NumPy, MNE, pandas, scikit-learn and transitive dependencies require their own licenses and immutable environment qualification. The historical dependency-license note is not a new legal review; version strings alone do not establish compatibility.

Exact private selection/audit records bind the source origin and transformations. Those records, private Git history, reviews, local paths, original tool logs, data and exact hidden answers are intentionally excluded. This preparation does not modify the existing public branch or its history.
