NEURAL-081: complete instructed-excerpt EEG prediction, protocol V4

This is the public candidate contract, not a run authorization, an assessment
answer, or a claim of demonstrated model competence. Predict the instructed
excerpt class of exactly one current EEG window. The complete experiment uses
all ten original participants and every admitted condition-4 trial, all twelve
classes, two views EEG and ZERO, and replications r0, r1, r2. Training excludes
the held participant entirely. No authentic result or participant identifier is
provided by this text. Cohort membership can be statistically inferable from

Task and full support
The fixed crop is the full four seconds starting 0.5 seconds after the source
onset: source samples [onset+256,onset+2304) at 512 Hz, resampled to 128 Hz.
For each source sample, preparation subtracts the mean of all 64 channels in
binary64, then averages each nonoverlapping four-sample block and casts once
to finite float32. No outside-window padding, ICA, interpolation, adaptive
filtering, mastoid referencing or whole-session fitting is added. Four-point
averaging is the chosen representation, not ideal antialias filtering. Missing
channels, active projections, nonfinite samples or unrepresentable float32
values refuse complete preparation. Candidates receive these complete windows,
with no trial selection by outcome,
self-report, apparent cleanliness, model success or convenience. Genuine
physical boundary ambiguity or incomplete support fails preparation. Synthetic
feedback pseudo-times are not physical interruption times and do not select
trials. No artifact-based channel/trial removal or authentic self-report label
is a candidate decision. Original bad-channel flags are privately preserved and
their aggregate prevalence is reported only after complete closure.

Each current query is [64,512], float32, in volts, 128 samples per second.

Reference definitions and interpretation
The fixed references stay inductive: fit on permitted training data only, never
the current query. BP_LDA and TM_LDA each select shrinkage from .01,.1,.5,AUTO;
RBF_KRR selects absolute alpha from .01,.1,1,10 and gamma from 1/1280,1/320,4/320.
HISTORICAL_BP_LDA retains its literal historical feature/scaler/AUTO-LDA recipe
on the prospectively role-ordered inputs; no historical numerical parity is
claimed. The complete inner person-held-out grid chooses configurations and
calibration on training folds only. Temperature grid is 1,.25,4,.0625,16,
.015625,64; the historical comparator uses 1. Selection uses actual emitted
binary64 calibrated probabilities, including rounded ties, not a claim that
temperature cannot affect finite-precision argmax. Mathematical definitions,

source-owned and remain unchanged. No reduced grid/subsample/jitter/approximate
kernel is silently substituted for a complete reference.

Reference mathematical conventions
BP: demean each 512-sample channel, multiply by the symmetric Hann weights
(1-cos(2*pi*t/511))/2, use unnormalized forward rFFT and power |a_k|^2/512.
At frequencies k/4 Hz, average power over k=4..15,16..31,32..51,52..79,80..119,
then ln(max(mean_power,1e-24)). The 320 features are channel-major/band-minor.
TM: use the same demeaned channel and sixteen consecutive means of 32 samples,
1,024 features in channel-major/bin-minor order. All learned arithmetic is
finite binary64. No padding, deletion, imputation or new signal filter is added.
Global training scaler uses each row with weight1/n, population mean/variance.
With eps=2^-52 and b=n*eps*v+(n*mu*eps)^2, scale is1 if v<=b, else sqrt(v).
Validation/query rows reuse that saved scaler; ZERO is not a separate shortcut.

LDA uses class means a_k and class-population covariance S_k. Fixed shrinkage is
(1-lambda)*S_k+lambda*trace(S_k)/d*I; the final covariance is the equally weighted
mean across twelve classes, not class-frequency weighting. AUTO independently
population-standardizes each class, applies the specified classwise Ledoit-Wolf
formula, then restores the class feature scales before that uniform mean.
It is not pooled Ledoit-Wolf or OAS. If V is the recentered standardized class,
E=V^T*V/n_k, a_j=sum_i(V_ij^2)/n_k, mu=sum_j(a_j)/d,
D=sum_jl(E_jl^2), B=sum_jli(V_ij^2*V_il^2), then
beta0=(B/n_k-D)/(d*n_k), delta=(D-2*mu*sum_j(a_j)+d*mu^2)/d,
beta=min(beta0,delta), lambda=0 if beta==0 else beta/delta.
L=(1-lambda)*E+lambda*mu*I is restored by the two saved class-scale diagonals.
Nonfinite or out-of-range shrinkage fails; no extra clipping/fallback is added.
Solve W=Sigma^+*A^T with minimum-norm SVD, keeping singular values strictly
greater than eps*s_max (zero threshold if all zero). Scores are
z^T*W_k-.5*a_k^T*W_k+log(1/12). Singular models use this rule, never jitter or
a nearest-centroid substitute. Numerical residual/rank checks can refuse them.

KRR uses BP features and saved scaling, exp(-gamma*sum((z_i-z_j)^2)) with direct
finite squared differences. Center K and one-hot Y using H=I-11^T/n. Solve
(Kc+alpha*I)*B=Yc: alpha is absolute, not multiplied by n; intercept is unpenalized.
For one query k_i=K(z_i,z), scores are mean(Y)+(k-r-mean(k)+grand_mean(K))^T*B,
where r is the training row-kernel mean. No clipping of raw scores. The dense
kernel/full support is exact; no subsampling, random features or approximate
kernel. The selected SPD residual check refuses inaccurate solves without jitter.

Softmax subtracts the largest finite raw score, divides by positive temperature,
exponentiates and normalizes; underflow to zero is allowed. Selection enumerates
all twenty settings on all nine inner held participants (fit the other eight).
Rank each family's configurations by (-mean_person_BA_at_T1,mean_person_NLL_at_T1,
grid_index). Each selected family's temperature minimizes mean-person OOF NLL,
ties first in its declared list. Recompute BA at that temperature. Strongest
family ranks (-calibrated_BA,calibrated_NLL,family_order). Historical is a separate
AUTO BP fit at T=1. No failed setting can be dropped to select surviving recipes.
Uniform is1/12; Laplace prior is (training_class_count+1)/(n_train+12).

For metrics, success/total counts are exact integers, each recall is correct/total;
BA uses math.fsum in class order divided by12 and then math.fsum of participant
scores divided by participant count. NLL uses -log(max(p_true,1e-12)); the floor
applies only inside the log. Row terms and participant terms use math.fsum in
source-owned fixed order. Configuration/temperature/family ties use the exact
computed finite floats, no epsilon tie band. Replication means use r0,r1,r2
math.fsum/3; paired contrasts subtract paired participant scores before macro
reduction. Library transcendentals/linear algebra are not claimed correctly
rounded or bitwise identical across platforms. The historical package contract
is NumPy2.2.6/SciPy1.15.3/scikit-learn1.6.1, with separately qualified exact
interpreter/image/BLAS and one numerical thread.

Prediction and assessment

The primary score is participant-macro balanced accuracy (mean of twelve class
recalls per participant, then equal participant weighting), with paired F/I
and EEG/ZERO contrasts. NLL, complete confusion/recall rows, participant omission
sensitivity and replication range/sample SD are descriptive reports. Trials
