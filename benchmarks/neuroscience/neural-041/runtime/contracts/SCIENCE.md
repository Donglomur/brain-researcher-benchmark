# NEURAL-041: held-patient working-memory load

This is a complete proposed source programme for the existing NEURAL-041 endpoint, with no scientific run, acquired cohort, qualified reference or active execution. The public export remains incomplete pending its external inputs and qualification. It predicts low versus high memory load from equal-duration maintenance LFP/spike windows. The output is one probability of high load per eligible original trial. Patients, including every session of the same patient, are the replication and outer/inner split units.

The fixed documentary source is DANDI 000673 snapshot 0.240118.2135 and SBCAT author revision a25e8cc3f61630a428f190381745257d4506f148. The declared extent is 44 sessions, 36 patients, 140 trials per session and 70 trials per load before eligibility. These are source declarations, not observed counts. Every expected asset and original trial receives a private disposition; no smaller cohort or convenient file is substituted. SOURCE_EVIDENCE.json cites the documentary sources. The roster and all original assets are external dependencies; see ../../EXTERNAL_INPUTS.json.

The public canonical specification is benchmarks/manifests/neural/NEURAL-041.json. Its public source references describe this export; all admission fields remain false. N042 is a distinct PAC reconstruction/perturbation task. Its primitive NWB access and native transport are source donors, while its hippocampus-only, colocated-unit selection, PAC outcomes and event-rich actor views are not N041 policy.

## Source evidence and exact distinctions

The original main MATLAB script counts LFPs and units in Hippo, Amy, preSMA, dACC and vmPFC. condenseAreas.m supplies ten explicit left/right location tokens mapped to those five areas. NWB_SB_extractUnits.m joins subject, session, unit ID and the source electrode row; its comments also retain a January 2025 waveform indexing correction. This task reads spike times, not waveforms, and makes no claim that waveform APIs in a newer snapshot are interchangeable with the selected archive.

NWB_calcSelective_SB.m uses 2.5 seconds after maintenance onset for maintenance plotting. Its category-selective cell tests use stimulus IDs and encoding/probe responses; those tests and optional global firing-rate filtering are not used to select N041 cells. The original main defaults the rate filter to empty. NWB_importFromFolder_SBCAT.m may remove failed imports after a warning; N041 instead fails complete source qualification when an expected asset is unavailable.

NWB_samplePAC_LFP.m is a single-channel example using a saved stratified mask of correct, balanced load trials after artifacts. NWB_samplePAC_SU.m is a selected unit/channel example using correct load-3 trials and a saved artifact mask. Neither example supplies a full-cohort clinical or artifact map. Their masks remain unopened. These selections cannot define a low/high decoder cohort. The examples use inclusive padded windows and original MATLAB sample conventions; N041 has a separately selected half-open maintenance rule, and does not claim PAC numerical parity.

The benchmark specifies [maintenance, maintenance + 2.5 s), with 1000 samples at the documented 400 Hz. The exclusive endpoint may equal probe onset, but every included sample must be strictly before probe. The first sample is ceil((maintenance - recording_start) * 400), preserving fractional alignment privately; no resampling, inclusive-end truncation or guessed clock shift occurs. Relative spike times satisfy 0 <= t < 2.5 s. Exclusive-boundary equality is allowed; every included sample must still precede probe onset.

## Population and exclusions

All five regions and both modalities are retained when prospectively eligible. No hippocampus, colocated-unit, PAC significance, category selectivity, correctness, response-time, load-balancing or firing-rate filter is inherited. The independent clinical review must name every original LFP/unit row, its actual electrode and microwire bundle, exact source region, eligibility/reason and original artifact trial rows. It must join the whole source roster and document source preprocessing. Region spelling is checked against source electrode metadata; unknown anatomical labels are an input-schema hold, not a biological exclusion.

Per-channel/unit artifacts remove that modality element for the affected trial. A trial remains if any prospectively eligible neural modality remains. Global trial exclusions need an explicit clinical or signal-artifact reason blind to load, correctness and order. Every excluded or modality-empty trial remains in private dispositions. This availability policy avoids imposing an unselected common-channel complete-case restriction. It still requires independent scientific acceptance of actual artifact decisions. No authentic decisions were supplied or inferred here.

All source sessions remain attached to their patient. A patient with no eligible trials or without both load classes fails complete-ascertainment qualification; the scorer does not silently remove that patient or redefine balanced accuracy. Repeated trials, channels, units and sessions are not additional independent people. Source-declared mapping reversal after trial 70 is a leakage concern and remains unascertained here; trial order and mapping metadata never enter actor views.

## Neural inputs and leakage

The public epoch contains only LFP volts, exact area indices, relative spike times, ragged unit offsets and unit area indices. Public file names and IDs are keyed study-local opaque tokens; archive filenames, patient/session originals, trial numbers, clock values, PicIDs, load, correctness, probe fields, encoding counts, phase markers and event files remain private. Training views additionally contain training targets and opaque patient groups for nested validation. Prediction views contain neither training labels nor held targets. ZIP member timestamps are fixed. One actor-safe epoch pool is copied in opaque-ID order with normalized file times, replacing source-order private inodes; it is shared across views rather than copied36 times. Full source/private directories are never mounted: the actual Engine mounts individual authenticated public-pool files.

The fixed and adaptive arms use identical prepared observations, tools selected by arm, and the same per-patient CPU/wall/resource envelope. Fixed methods and recipes are bound before the study. The adaptive numeric and agent-plus-decoder slots can call a concrete training-only investigation stage, emit case-specific source/recipe/rationale, then freeze those bytes before fitting and prediction. Decoder-only uses the fixed reference implementation. The fit/investigation capsules have only training patients; the later prediction capsule gets frozen model state and query epochs without training labels or target feedback. This implements training-only adaptive investigation, not online streaming or unrestricted query-driven refitting. Foundation-model identity, actual reasoning competence, call/token measurement and provider deployment remain external qualification gates; a Python strategy hook alone is not evidence of agent reasoning.

Original LFP preprocessing reportedly interpolated spikes from the whole microwire bundle before lowpass175 Hz, downsampling400 Hz and 60/120 Hz notch filtering. This source provenance must be independently verified for every selected asset. LFP and spike modalities therefore are not independent recordings of independent information: combined gain cannot establish a separate biological mechanism. Temporal support/phase response of upstream filtering and interpolation is unresolved; cropping before probe alone does not prove absence of post-probe influence in an already filtered signal. No raw preprocessing reversal or replacement is attempted. This remains a substantive input qualification gate.

## References, metrics and interpretation

Five source-owned reference candidates use the identical folds and observations: a training-patient-weighted prior, availability-only counts, spike-rate-only summaries, LFP-power-only summaries, and their neural combination. Counts are a nuisance diagnostic, not neural evidence. Per-area rate features summarize log1p(unit spikes / 2.5 s); power features summarize log band power in V² from a fixed within-window Welch estimator. Bands, numerical floor and optimization are explicit in reference.py. These are prospective N041 baselines, not original paper PAC analyses, measured SOTA or already competent references.

Training-only median imputation, missingness flags and robust scaling are fit inside each inner fold. Entirely unavailable training features retain a flag and zero imputation, without invented measurements. L2 logistic regularization is chosen by equal-patient inner log loss over a fixed grid, then refit on outer-training patients with equal total patient weights. Nonconvergence or missing class support fails the reference; no fold is dropped. No query-based normalization, calibration or feature selection is applied. Proper reference competence and numerical agreement require later independent scientific work.

Primary reports are the mean of per-patient balanced accuracy at p_high >= 0.5 and the mean of per-patient binary log loss, with probability clipping at 1e-15 for log loss. Each patient's sessions/trials are pooled within that patient; larger patients do not receive more aggregate weight. The full per-patient denominators and both class counts are retained. A separate scalar implementation checks the aggregate arithmetic. It has not run.

The canonical paired-uncertainty requirement is implemented as full paired patient differences and a prospective 10000-resample patient bootstrap against the combined reference, using one precommitted signed-profile seed and the same draw bank across families/metrics. Percentile intervals are conditional on the frozen cross-validated predictions. They omit refitted-training variation, and overlapping outer training sets limit any population-inference interpretation. This is diagnostic uncertainty, not a new primary win, superiority criterion or clinical threshold. No RNG or interval computation occurred during construction.

The canonical resource class remains CPU_workstation_bounded. Participant descriptions must state the target/unit/window, estimand, uncertainty, alternatives and limitations. The evaluator checks structured requirements and actual captured model/source/prediction lineage. Scientific truth or competence of free-text reasoning is not claimed by that check; it remains an independent scientific review requirement.

All 36 declared folds imply 396 prediction cells: six mode/arm cells plus five references per patient. There are 864 planned actor/reference native operations: fixed arms two each, adaptive numeric/agent-plus-decoder three each, adaptive decoder-only two, and references two each. One whole-source preparation capsule precedes them. These are prospective programme slots; eligibility, feasibility, actual operations and counts remain unmeasured. They are not additional benchmarks.
