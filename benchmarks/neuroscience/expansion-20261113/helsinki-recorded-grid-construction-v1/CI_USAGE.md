# Linux engineering ownership

The workflow selects one complete invocation of the unchanged 109-control Helsinki harness. The owned root is /tmp/helsinki-recorded-grid-controls-RUN_ID-RUN_ATTEMPT with umask 022. Preparation refuses an existing root, authenticates the selected ordinary source files and copies them read-only. Shared runner directories are never chmodded.

The interpreter is exact CPython 3.11.18. Preparation, the isolated owner and the trusted collector verify the selected interpreter's canonical libpython3.11.so.1.0 by size/SHA256 and loaded mapping. This runtime binary operand is limited to 64 MiB per observation and three observations; it is not source, a dataset or an external model. Only the selected canonical library directory is supplied, with PATH and LANG, in a cleared environment.

sudo starts GNU timeout and unshare with a new network/PID namespace, private proc mount and kill-child behavior. setpriv selects UID/GID 65534, clears supplementary groups and all capabilities, enables no-new-privileges and sets parent-death SIGKILL after the credential change. The inner owner must observe PID1 and the selected isolation state before starting the fixed harness. It accepts no arbitrary command and runs no submitted agent or prediction programme.

The original absolute attempt deadline is 120 seconds, starting once before namespace entry. An outer 130-second timeout bounds failure cleanup; the whole Actions job is limited to five minutes. Child resources are bounded by 2 GiB address space, 120 CPU seconds, 1 MiB per regular output file and 256 file descriptors. The descriptor limit accommodates the complete 82 simultaneously open invented source files. All 109 checks and the full 79-infant fixture remain present. The harness's existing 120 MiB fixture allowance is unchanged; the owner additionally admits no more than 128 MiB across original source, fixtures, streams, result records and the duplicate upload artifact. An oversized or incomplete packet fails; limits are not extended or retried.

The unchanged harness creates private 0700/0600 invented fixture paths under the dropped UID. After namespace termination, only the exact hash-pinned trusted finish collector runs with host root privilege in a cleared environment so it can read those private files. It never imports or executes fixture content or candidate code, and it never changes fixture ownership or shared permissions. This privilege is confined to a fixed reviewed collector in an ephemeral CI runner; the scientific worker retains its dropped identity. The collector copies regular files with readable artifact modes, records any symlink without dereferencing it and refuses a passing result if the expected Helsinki fixture census contains a symlink or an unlisted file.

The original outer status and deadline are admitted separately from the inner result. Passing requires the exact ordered 109 names; complete invented support and two arms/three controls/five folds; all expected source and output hashes; both complete EOF streams; natural zero; direct-child reap and absent process group; no forced signal, closure error or discarded output. The full original fixture inventory is checked, including the two intentional one-byte mutations and their pre/post identities. Both namespace termination and original failure evidence remain explicit. The kernel rule that terminating namespace PID1 terminates its descendants supports the stated closure observation; a client exit alone is insufficient.

Complete bounded artifacts are uploaded on success and failure. If setup or the collector cannot complete, the workflow retains an explicit incomplete-failure marker and the available fixed diagnostic files; it does not claim a full passing result. A full admitted packet includes all invented fixture files, raw stdout/stderr, source selection, source files, runtime/isolation/ownership records and the result. Raw streams and fixtures belong in the CI artifact, not in Git.

The primary ownership rationale is documented by [unshare](https://man7.org/linux/man-pages/man1/unshare.1.html), [setpriv](https://man7.org/linux/man-pages/man1/setpriv.1.html) and [PID namespaces](https://man7.org/linux/man-pages/man7/pid_namespaces.7.html). This is a fixed trusted-source engineering route. It does not claim a filesystem sandbox for arbitrary candidate code, real-model performance, physical hardware-cost equivalence or scientific qualification.
