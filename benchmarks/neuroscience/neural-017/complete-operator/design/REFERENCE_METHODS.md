The included source supplies the complete reference producers described here; actual scientific construction remains separately authorized and qualified. Every required reference needs complete training/search/state/prediction/collection provenance. Before agent use, G07.development requires training/inner-development source/convergence/domain evidence; fresh assessment competence is G07.assessment after the global barrier, never a prerequisite that reads assessment labels early. ## Required families and exact distinctions

R0, deployable training constant: `nlb/scientific/linear_bank.py::context_train`. For withheld unit u, mu_train[u]=(sum of training counts +0.5)/(Ntrain*140+1); broadcast over each query trial/bin. This is strictly positive, train-only and distinct from the scorer's private evaluation mean. Fit once to all1721 training trials. Context and neural input are unnecessary.

R1, fixed condition/time: the same `context_train` function. At each condition/bin/unit, shrink the summed training counts by one pseudotrial toward mu_train, divide by n_condition+1, and convolve with the normalized 60-bin symmetric Gaussian, sigma10bins=50ms. Divide by convolution of ones to correct trial edges. An unseen condition uses mu_train. The exact source is a full producer, not an imported target-derived PSTH. No historical R1 prediction asset is bundled or substitutes for new fitting provenance.

R2, selected context: `nlb/scientific/_context.py::{ordered_hypotheses,fit_statistics,profiles_for_hypothesis,select_model,refit_selected,predict_profiles}`. Complete13-option search: the original sigma10/kappa1 first; the remaining bandwidth0,5,10,20bins×pseudotrials0.25,1,4 combinations without duplicating the original; training constant last. On the exact old whole-trial1381/340 training split, select by pooled validation Poisson log likelihood. All13 finite rows must complete, strict larger-than wins, exact ties retain earlier order. Refit the selected configuration on all1721 training trials; query conditions affect lookup only. Float64 statistics/likelihood and exact even-kernel edge convention remain. Output no observed-neuron input is necessary. The competitor is not just a fixed weak nuisance model.

R3, fixed source-based smoothing/Poisson GLM: `nlb/scientific/glm.py::{smoothing_features,fixed_train}`, adapted from organizer `run_smoothing.py`. Smooth each observed unit within each trial using Gaussian sigma50ms,60bins, zero outside the trial, **without edge renormalization for neural features**. Transform log(smoothed expected counts+1e-4). Fit one PoissonRegressor per withheld unit, alpha0.01, intercept, no query withheld labels. The existing local version is one fit max500iterations with warning/convergence checks, tol1e-4, lbfgs and clipped output1e-9…1e20. An all-zero training target unit is a declared unavailable reference (no invented finite optimum). All45 unit fits and predictions must finish; no subset-of-units score. Keep this distinct from the official retrying script and full sweep.

R4, organizer smoothing search adapted to this development split: included `nlb/scientific/glm.py::sweep_train`, derived from organizer `smoothing_cv_sweep.py` and `run_smoothing.py`. MC_Maze selector must replace the scripts' unrelated default dataset. Hyperparameter grid sigma30,40,50,60ms × alpha0.001,0.01,0.1,1.0, five folds; each fold takes every fifth training trial in original training order, leaving the rest for fitting. Every candidate uses all5 folds and all140bins/45 target units; average the five fold co-bps as the **native selection convention**, not pooled-fold bps. Tie rule is first CSV row, kernel-major then alpha. This is16 parameter combinations/80 fold configurations/3,600 withheld-unit GLM fits before retries, then45 final unit fits. A future implementation must retain the count of every restart; fitted model caches may share identical fixed inputs but cannot hide work. Refit selected pair on all1721 training trials. The official script combines train+val for its original test phase; our1721-only adaptation is explicit and prevents validation-target leakage.

The official convergence sequence is max_iter500,2500,12500 because its loop tests max_iter<10000 **before** multiplying by5. Do not describe a hard10000 iteration cap. A bounded source-faithful producer records every trial, warning and iteration count. Exhausted nonconvergent attempts make the full reference unavailable; retrying another grid or quietly using a partial prediction is forbidden. The old single500 local R3 remains its own recipe. scipy's removed `signal.gaussian` namespace may require an exact `signal.windows.gaussian` adaptation; pin and numerically qualify that compatibility change before execution. No install is authorized here.

R5, organizer GPFA: included `nlb/scientific/gpfa.py`, derived from organizer `run_gpfa.py` and `gpfa_cv_sweep.py`. `array_to_spiketrains` expands every integer bin count into repeated spikes at t=bin_index*5ms, t_stop=700ms, separately per trial/unit. This deliberately preserves organizer bin-start reconstruction; it is not recovered sub-bin timing. GPFA fits observed training units only using Elephant `GPFA(bin_size=5ms,x_dim=k).fit_transform`, then calls `transform` for query observations. Factors are trial×latent×time and transposed/stacked to rows of bin×latent.

The organizer **does use unlabeled query data**: `fit_rectlin` fits Ridge from factors to observed counts on the vertical concatenation of train AND query observations, then rectifies predictions below1e-10. `fit_poisson` subsequently fits the reconstructed observed-rate features to training withheld-unit counts and applies that model to query features. Thus the final heldout GLM can legitimately be fitted *after* the observed-query calibration, while its only withheld-unit labels remain training labels. A pre-query GPFA state is not the final predictive state. The complete TrainState→QueryAdaptState lineage must bind GPFA fit, train and query factor identities, combined observed readout fit, rectification and the subsequent training-label Poisson fit. For the I arm this full-pool adapted state is frozen before dispatching case contexts. Banning that calibration silently would change the official baseline and the selected task policy.

GPFA search uses k=32,36,40,44,48,52, alpha1 and alpha2 each0,0.0001,0.001,0.01, three interleaved whole-training-trial folds. There are96 parameter combinations×3folds, but only18 GPFA latent fits; each factor fit is reused across16 readout combinations. This gives288 Ridge readout fits and12,960 heldout-unit GLM fits before restarts. Each fold's observed heldout-fold activity may calibrate its observed readout, matching the query adaptation, but its withheld-unit labels are reserved for selection score only. The native selector averages three fold co-bps and chooses the first maximum. The script's final print mistakenly uses loop alpha1/alpha2 rather than best_alpha1/best_alpha2; the producer must bind the selected dataframe row, never parse that print as authority. Refit one selected GPFA on all1721 training trials, transform all574 observed query trials, fit the combined observed readout and45 training-label GLMs, then freeze the complete adapted state. The fixed published MC_Maze defaults are k52/alpha1.01/alpha2.0; this separately labeled recipe cannot stand in for the full search.

Transformation, covariance, EM/stopping, serialization and native behavior still require exact source/environment admission and scientific qualification. R6, existing multiscale ridge: `nlb/scientific/linear_bank.py::{ridge_train,ridge_predict}` and adjacent `_ridge.py`. Two411-feature families (137units×30ms,90ms,whole-trial mean), direct and condition-residual. Per-trial edge-corrected filters,25ms mean pooling for fitting, full5ms-bin inference. Residual profiles leave the current fitting trial out of the condition mean; the small global prior uses all fitting trials, never inner-validation targets. Fit-center/scale features (scale floor1e-5); ridge solves the normalized Gram/cross-product eigensystem with penalties0.003,0.03,0.3. Four blends0.25,0.5,0.75,1.0 for each family/penalty, plus R1:25 alternatives. Training-only1381/340 selection uses strict pooled likelihood gain, then full1721 refit. Model flooring1e-6 is declared producer behavior; the scorer never supplies it. No observed-query calibration is performed by this reference, although the task permits other programs to do it.

R7, existing standardized finite Nyström-feature ridge: `nlb/scientific/linear_bank.py::{ridge_train,ridge_predict}` and adjacent `_nystrom.py`. Retains all24 linear choices plus72 nonlinear choices and R1 (97 alternatives). For each direct/residual family, fit-only centering/scaling;512 fitting-row landmarks with RandomState20261104; median of positive squared landmark distances; RBF gamma multipliers0.25,1,4 divided by that median. Nystroem maps are themselves fit-centered and coordinate-standardized by ridge, so this is not exact unmodified RBF-kernel ridge. Fixed order gives six kernel maps/eight ridge paths/24 coefficient solutions during selection. Refit selected geometry on all training rows; inference blocks4096 cover all rows. Degenerate landmark geometry or fewer512 rows fails explicitly. The donor method also defines a375/125-trial Maze-Large panel; N017's selected programme uses ONLY1721/574,137/45,140. The other panel is not an extra case set or a bundled result here.

R8, existing temporal/shrinkage: `nlb/scientific/linear_bank.py::{temporal_train,temporal_predict}` and adjacent `_temporal.py`. Complete13 context choices;548 neural features comprise30ms/90ms smoothed counts, whole-trial means and0.5×(short[t+6]−short[t−6]) with clamped indices (not divided by seconds, so a finite-difference feature, not a physical derivative). Fit25ms-pooled rows, infer every5ms bin. Three normalized ridge penalties0.03,0.3,3; four global blends; then per-unit blends0,.125,…,1 selected on the same inner validation data with20-nat quadratic penalty toward the chosen global blend. Refit training transforms/coefficients on all1721 trials, retain learned unit weights. This repeated selection carries optimism; it is not fresh calibration evidence. The singleton split rule retains a fitting trial whereas the old ridge puts singleton conditions into validation. Preserve each source's rule and verify the actual split identities before claiming equality. No evaluation-label selection. A separately scoped375/125 source must not replace this standard-panel implementation.

## Modern latent models and published results

The source paper also uses SLDS, NDT and AutoLFADS. Their current availability is separate from the mandatory task reference bank above. NDT source revision98dd85a24885ffb76adfeed0c2a89d3ea3ecf9d1 is external to this package; a separately specified100epoch adaptation does not establish parity with the paper's source schedule or hyperparameter search. SLDS requires the authors' modified ssm plus random search, full refits and documented hand tuning. The author-linked paper states its AutoLFADS co-smoothing modification was internal/unreleased at that time; a public similarly named implementation is not proof of native parity. No checkpoint is acquired or presumed legal/current here.

Appendix A.4 Tables 8–10 report MC_Maze parameter-optimization runtimes of 3.2 hours for smoothing, 35.7 hours for GPFA and 73.2 hours for SLDS on CPU-only setups (GPU count 0). Tables 11–12 report 4.66/4.5 hours on 10 RTX 2080 GPUs for AutoLFADS/NDT. The tables do not identify CPU concurrency or measured aggregate CPU time. These are reported setup-specific runtimes for one baseline run, not aggregate CPU-hours, local-host requirements or three-seed totals; multiplying by an assumed CPU count is not evidence. They show why a20-second entrant contract cannot silently include complete native searches. Published Table1 co-bps values (.211,.187,.219,.329,.346) refer to the original benchmark split/settings and are context, not local leaderboard thresholds. Every modern model requires exact code/config/dependency/fit/exposure and compute gates before it can enter a prospectively selected matched profile. Failure to beat all published numbers does not invalidate a correctly scored local prediction; beating them on this different split does not establish SOTA.
