# Data attribution and dependencies

The MC_Maze recording is the Jenkins macaque session of 25 September 2009, distributed as [DANDI 000128, version 0.220113.0400](https://dandiarchive.org/dandiset/000128/0.220113.0400), under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). This packet is a 5 ms binned, source-aligned derivative with training targets and evaluation observed units; it omits evaluation withheld-neuron counts. Attribute the source dataset, [Churchland et al., Nature 2012](https://doi.org/10.1038/nature11129), and the [Neural Latents Benchmark](https://arxiv.org/abs/2109.04463) when using it. Prior public data exposure remains possible.

The official NLB source is MIT licensed but is not bundled in this primary reference-withheld arm. Its license does not automatically license new interface or candidate code. General installed libraries retain their own licenses: Python (PSF), NumPy/SciPy/scikit-learn/pandas (BSD family), and h5py (BSD). No task-specific pretrained model or paid API is supplied. Runtime package/version availability is declared in the prompt and must be respected without installation or network access.
