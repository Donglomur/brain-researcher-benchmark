# NEURAL-017: complete MC_Maze operator source

This public checkout provides the full inactive MC_Maze operator and scientific source. It is one existing assignment. It preserves all 100 matched groups, 574 query cases per applicable group, 28,844 scientific and broker roles, and all R0–R8 references. The scientific task is retrospective co-smoothing of 45 withheld neurons from 137 observed neurons, using all 1,721 training and 574 validation/development trials in one exposed historical Jenkins macaque session. Each complete trial has 140 five-ms bins, with bin-left edges from -250 to +445 ms around movement onset. Source/exposure limits, whole-study conditions, legal observed-query transduction, protected collection barrier, uncertainty and independent report judgments remain in the full design. Trials, bins and source files do not create independent animals or extra benchmarks.
