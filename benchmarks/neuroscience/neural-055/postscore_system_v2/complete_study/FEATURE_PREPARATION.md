# Fixed image-feature preparation

The actual operator entry is `central_entry.py prepare-features` with the same explicit source-root, manifest, pinned plan, operator-root and fresh output operands as the main entry. It routes to `n055.features.execute` and the concrete `produce` implementation. This command performs model/image computation and is not authorized by the source-only construction phase. The default remains `inspect`.

Its plan schema is `neural055-image-feature-preparation-plan-v1`, with `task_id`, exact `source_manifest`, original `limits`, `trust`, pinned `checkpoint`, `image_metadata`, `image_index`, literal `image_root`, exact `environment`, independent `runtime_qualification`, and `closure_reserve_seconds`. All file descriptors use the existing path/bytes/SHA-256/mode/role shape. The checkpoint is a preexisting exact local state dict, at most 512 MiB; no URL, cache lookup, pretrained download or replacement weights are accepted. The signed `fixed_image_feature_preparation_runtime` subject binds the whole source, checkpoint, image order, fixed recipe, environment and limits before any scientific input is opened.

The exact runtime selects torch 1.10.1, torchvision 0.11.2, CPU float32, and prospectively pinned Python, NumPy and Pillow versions. `environment` also specifies `memory_bytes`, `network_isolated: true`, `maximum_image_bytes` (at most 16 MiB) and `maximum_image_pixels` (at most 20 million). Independent runtime qualification must establish the offline environment. The implementation sets a non-increasing address-space and CPU ceiling in the standalone operator process, one torch thread, deterministic algorithms, eval mode, and an original-deadline alarm. It does not claim those source-level checks alone prove native containment. The cleanup reserve is carved out of the original lifetime, not added to it.

`image_metadata` is validated by the exact retained original metadata validator: 16,540 training images from 1,654 concepts with ten exemplars each and 200 disjoint assessment concepts/images. `image_index` has schema `neural055-ordered-original-image-index-v1`, `image_metadata_sha256`, and `training`/`test` ordered lists. Each list entry is `{image_id, file}`. Image IDs must equal the corresponding original metadata list, in order. Each file descriptor is exact, bounded and local under `image_root`; duplicate paths across partitions are refused. Original acquisition/event-image joins remain a separate all-ten qualification; a plausible filename or shape is not proof of a join.

The selected forward path matches the authenticated author's ReLU7 extraction semantics: Pillow RGB conversion, torchvision 0.11.2 Resize((224,224)), ToTensor, ImageNet mean/std normalization, AlexNet features, adaptive 6×6 pooling, flattening and classifier modules 0 through 5 inclusive. One image is processed per call; no PCA, dataset-fitted transform, EEG or target input is used. `alexnet(pretrained=False, progress=False)` builds the fixed architecture; the fully captured exact local state dict is loaded strictly on CPU before inference. The code never invokes the pretrained downloader. ReLU7 is the 4,096-dimensional second fully connected ReLU, not a concatenation of layers or the final 1,000-way output. This source selection is not a numerical equivalence claim or empirical feature-validation result.

The producer writes safe non-object little-endian float32 NPY matrices in original order, `training_features.npy` with shape 16,540×4,096 and `test_features.npy` with shape 200×4,096. Sequential writes account for actual returned prefixes, first/secondary failures and descriptor closure; every original row retains an attempted/failed/unattempted disposition. `FEATURE_RECIPE.json` identifies the recipe; `FEATURE_OPERATIONS.json`, `ORIGINAL_COSTS.json` and the original terminal preserve operation/closure history. Failed or unknown closure never yields a successful preparation terminal.

`FEATURE_MANIFEST.json` uses the unchanged strict `neural055-image-feature-manifest-v1` fields expected by original `build_case.py` and `build_panel.py`: training/test descriptors, canonical original image-metadata digest, checkpoint and recipe digests, representation name and `fixed_checkpoint_no_dataset_fitted_transform_no_EEG` scope. Pass this manifest to the unchanged original builder's `--feature-manifest` operand with the original staging index and independently qualified all-ten join attestation. The private operator must require the producer's complete original terminal, exact environment and output identities when qualifying that input; mere presence of a manifest is not a completed run. `prepare` and the campaign still consume the resulting independently qualified all-ten packet, preserving original case/candidate permutations and target-last authority.

Official API provenance is recorded separately from runtime inputs. The versioned library source confirms that `pretrained=False` avoids its URL loader and that classifier index 5 is ReLU7. Actual checkpoint bytes, dependency environment, authentic image joins, numerical features and resource adequacy remain unqualified. No scientific or checkpoint operation was performed while writing this source.
