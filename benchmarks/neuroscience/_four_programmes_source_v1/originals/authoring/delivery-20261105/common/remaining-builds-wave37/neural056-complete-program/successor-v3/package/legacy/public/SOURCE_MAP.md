# Primary source and deliberate departures

Gifford et al.(2022), *A large and rich EEG dataset for modeling human visual object recognition*, NeuroImage264:119754, [DOI](https://doi.org/10.1016/j.neuroimage.2022.119754), [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC9771828/). Primary code is [gifale95/eeg_encoding at101997d4f14c41b615bcaf8c0907740106d260c5](https://github.com/gifale95/eeg_encoding/tree/101997d4f14c41b615bcaf8c0907740106d260c5). No article body is bundled. Ten author code/license files were retrieved through immutable Git blobs, byte and Git-blob authenticated, and are held for operator source inspection only.

- `02_eeg_preprocessing/preprocessing_utils.py`: epoching selects O/P coordinates, rejects event99999, baseline-corrects −0.2 to0.8s epochs and resamples; MVNN averages train/test covariance before whitening; saved repeats merge sessions/shuffle and retain only EEG/ch_names/times. This motivates the explicit transductive/no-sequence claim.
- `04_synthesizing_eeg_data/linearizing_encoding_utils.py`: source between-person branch equally averages the other nine participants' four-repeat training means, then fits OLS over image features. We preserve person/repeat support, but the prospective fixed ridge(alpha1) is not that OLS implementation.
- `03_dnn_feature_maps_extraction/extract_feature_maps_alexnet.py`: resize224×224, ImageNet normalization, eval-mode AlexNet layer extraction. Our fixed ReLU7 is one declared layer. The original pipeline's `feature_maps_pca.py` actually uses degree4 polynomial KernelPCA after training-image standardization, not linear PCA. We do not claim to reproduce it: our task fixes raw ReLU7 plus training-only ridge standardization, without KernelPCA.
- `05_synthetic_data_analyses/correlation.py`: Pearson across200 test images per coordinate/time; historical code averages random40-repeat-half targets and a noise-ceiling analysis. The current canonical task uses all80 repetitions for its target and fixed odd/even halves only as separate descriptive reliability. It is a new locked encoding condition on the authentic source, not a copied historical score.
- [OSF EEG nodeanp5v](https://api.osf.io/v2/nodes/anp5v/files/osfstorage/) and [image nodey63gw](https://api.osf.io/v2/nodes/y63gw/files/osfstorage/): exact version1 publisher hashes/bytes are retained for all10 original17-channel ZIPs, training/test image ZIPs and metadata. Alternate63-channel derivatives are not substituted. Only the metadata/license were acquired here; the full EEG/image archives were not.

The original metadata file was authenticated and converted by a symbolic pickle-opcode reader that never imports or invokes serialized globals. It proves16540 training filenames/1654 concept groups and200 disjoint testconcepts. Original THINGS concept identifiers are used for joins; partition-local numeric prefixes are not globalconcept IDs. This establishes stimulus metadata, not all-ten EEG payload/schema/event alignment.

EEG license metadata, author code CC BY-NC4.0 and photograph research-use notice are separate. Local source construction does not grant public redistribution of photographs or derived neural packets. Frozen pretrained image models can have stimulus exposure; no fresh-image-population claim follows from an outer concept split.
