# NEURAL-056: image-to-EEG visual-response encoding

Predict the complete 17-coordinate × 100-time-point response to each of all 200 original test images for each of all ten THINGS-EEG2 participants. The target is the mean of all 80 released test repetitions. The training partition contains all16,540 images from1,654 concepts, with four EEG repetitions per image. The test200 concepts are disjoint. This is one ten-person cross-validation study sharing the same200 test images, not30 independent tasks or a new cohort. NEURAL055 is inverse image identification; NEURAL057 studies semantic/low-level information with sequence-context requirements. Their source exposure overlaps this task.

## Split and information boundary

For each outer person, only the other nine people's original training partition may supply EEG targets. The final reference uses their equally weighted four-repeat means. Neither the outer person's training EEG nor any person's original test EEG is a candidate input. All200 test images and their allowed fixed image features are legitimate query inputs. No query responses, reliability arrays, label-derived channel selection, target-person adaptation, scorer feedback or cross-fold state are permitted. The source collection remains operator-private: other outer contexts can include a person's training EEG, so contexts must never be merged/mounted together or reused to adapt a fixed program.

Programs, checkpoints, preprocessing, hyperparameters and method-tool access are frozen before outer queries. The supplied reference has fixed alpha1 and no tuning. A proposed tuning variant must use only inner whole-person holdouts among the nine training people and the fixed330 development concepts (all ten images per concept held together), fitting all standardization and supervised choices on the complementary eight people/1,324 concepts. The final nine-person aggregate is a refit view, not an inner-validation packet. Such adaptive validation is not supplied or executed by this draft; no arbitrary tuning on the refit view is allowed.

Every arm gets the same complete image IDs and training EEG. IDs expose no semantic names; public metadata groups training images by opaque concept ID. Image-trained models are supplied tools, not evidence of neural understanding. Prior image exposure, checkpoint provenance, and any EEG-trained tool must be declared. The fixed reference representation is AlexNet ReLU7(4096 features), input resized224×224 with ImageNet RGB normalization, eval mode, and an exact future-bound ImageNet1K checkpoint. Its hash is currently absent: no weights have been downloaded. The lower-level comparator is RGB16×16(768 values) with bilinear resize and values divided by255. Preparation never uses EEG to compute image features. Runtime extraction is model inference and remains unrun.

## Mandatory outputs and controls

Three matched arms are required for each person: `representation`, `low_level`, `response_permuted`. Each future reference fits a centered ridge(alpha1) after training-only feature standardization. The response-permuted arm uses the same4096 features but rotates whole training concept response groups by one in sorted opaque-concept order. All1,654 groups have ten images; within-group exemplar order is preserved, all1700 response coordinates move together, no concept maps to itself, and the full fit/standardization is rerun. Query features are unchanged. This tests joint training image–response alignment, not a unique neural mechanism or guaranteed null.

Write exactly `predictions.json` and30 files `<sub-XX>__<arm>.npz`. Each file contains only finite float32/float64 `prediction[200,17,100]` in the exact public query-image/channel/time order. Bind every file's byte count/SHA256 and the complete design hash. All30 blocks are admitted before any private target access. Single-case execution writes three files plus `case_predictions.json`; the operator's opaque collector joins exactly ten cases before grading. Candidate-supplied metrics are ignored. A saved artifact cannot prove model execution, training choices, chronology or isolation; any program-run comparison needs independent external enforcement.

## Score, units and limitations

For each person and each of all1700 coordinate/time cells, compute Pearson correlation across the same200 test images between predictions and the full80-repeat target mean. The primary score is the arithmetic mean of all1700 correlations, then the equal-ten-person mean; higher is better. All cells and people retain full support. A constant prediction receives scoring correlation0 with raw Pearson reported null; a constant private target makes that cell, person aggregate and primary aggregate unavailable, never silently omitted. Report constant counts and the entire correlation matrix. Paired person differences versus both controls are separate. There is no binary threshold or empirical success claim.

Private deterministic odd/even40-repeat means provide descriptive split-half correlation, reported separately, never used to scale/rank the primary score. They are not session replicates, a noise ceiling correction or a physical partition. The author's original correlation script instead averages scores against repeatedly sampled40-repeat halves; our80-repeat endpoint and fixed split-half diagnostic are explicit prospective choices, so published numerical scores are not direct comparators.

The released values are multivariate noise-normalized EEG, not microvolts. MVNN covariance combines training and test partitions within each original session and mixes channel coordinates. Thus this is an explicitly **transductive released-preprocessing** condition, not strict train-only preprocessing. The held person is excluded from supervised fitting but has already contributed to their own released preprocessing. Preserve observed channel labels/times; currently only one source archive's `(16540,4,17,100)` and `(200,80,17,100)` headers were historically inspected. Do not invent all-ten coordinate equality or exact endpoints until full validation.

Rapid presentation is100ms with200ms onset spacing. Prestimulus and late responses can contain neighboring-image activity. Released repeats were shuffled across sessions and lose sequence/session identities. This full waveform prediction task does not isolate late semantic processing, infer electrode-specific physiology after whitening, or restore causal sequence history. Inference across ten exposed people remains conditional on these200 shared images; no population-confidence or independent-replication claim is supplied.
