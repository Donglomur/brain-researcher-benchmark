# Paired research benchmark
This is one existing paper assignment, with reproduction and prospective improvement as distinct evaluations. The full workload contains all76 main/extended panels and all supporting methods. A missing branch is required-unscorable, never removed from the denominator.

Both arms receive the same complete primary PDF, data support/schema, task question, resolved neutral interpretation notes, output contract, compute/storage/time policy and approved dependencies. Condition A receives paper+data; condition B additionally receives the complete authenticated original analysis/simulation/plot code. The current five-file exposed author subset is insufficient for condition B. No native expected arrays, grading implementation, trusted reference artifacts or notebook result outputs enter either arm. Results visible in the paper remain openly known; this is a public reproduction benchmark, not a contamination-proof hidden discovery test.

Start each condition and each prospective fold with fresh agent state, process filesystem and fitted models. Do not let condition B's code or intermediate answers persist into A. Pair immutable input/seed schedules and total resource grants; counterbalance agent-run order. Shared common libraries are the same, and library calls that expose the solution must be declared. Record tool calls, code, intermediate analysis, failed attempts, wall/CPU/GPU/I/O/storage and final artifacts. Tokens, replicas, folds and panels do not create benchmark IDs.

The conflicting paper/code formulas cannot be resolved by demanding secret code quirks from the paper-only arm. A neutral, reviewed clarification visible to both arms defines the primary reproduction estimand. Literal author-code parity is a separately identified result, with every retained bug/repair declared. Until this adjudication, affected metrics are held. A legitimate paper interpretation is not a failed reconstruction merely because an undocumented implementation differs.

The paper's numerical result is not an x% prediction score in every branch. Reproduction seeks the complete claimed numeric objects and evidence; improvement needs its own protected target:
1. Neural prediction: leave out an entire biological group, including every recording assigned to it, and predict its spectra/temporal structure from permitted acquisition/region/sensor information. Use a cohort-mean curve and a noise/finite-sampling-aware model alongside the symmetric near-critical model. All model-selection data stay in nested training groups. Report spectrum-scale, normalized-shape and ACG errors separately, macro-averaged over animals and stratified by sensor/region including CA1. FX43 grouping and unknown full cohort identity remain gates. A new within-recording estimator study is a distinct endpoint, with blocked-time preprocessing and shared raw query access; it must not be relabelled cross-animal prediction.
2. Simulation inference: recover protected generator parameters or covariance/temporal statistics on fresh matrix/noise seeds and prespecified alternative drives (correlated input, heterogeneous rates, partial observation or nonnormal dynamics). Train/select only on development generators. Keep original simulations unchanged for reproduction; new generators are a prospective challenge with explicit out-of-distribution scope. Report parameter non-identifiability, not forced unique answers.
3. Memory capability: compare complete retrieval curves on fresh matrix/input/noise seeds with the original symmetric, nonsymmetric and echo-state systems. At fixed recurrent size, input dimensionality, readout access, training examples, simulation horizon and total compute, a proposed new initialization/readout may improve held-out retrieval. Recurrent-weight training is a different training-resource condition, not a free win against fixed random weights. Report fixed-time and variable-time retrieval for allthree tasks; preselect a useful delay range/AUC and noninferiority constraints only after exact original delay-grid source closure, before evaluations. No tuning on final retrieval outcomes.
4. Spatial interpretation: simulated ground-truth graph recovery admits a quantitative improvement test under matched topology and observation budget. On tissue data, only out-of-sample statistical prediction is testable; no synaptic-connectivity correctness or causal frontier claim follows without independent evidence.

The strongest present design thesis is that complete-paper reproduction plus protected discriminating extensions can measure research assistance beyond shell/tool fluency. The alternative is that public outputs and author code allow answer copying without understanding. Executable regenerated artifacts, hidden fresh procedural inputs, independent numeric banks, provenance and explanation of source conflicts discriminate these alternatives. They do not alone demonstrate native neural-signal understanding or a novel biological discovery.

No prospective hyperparameter/search grid, execution budget or empirical acceptance tolerance has yet been authorized. Those are explicit prerequisites for future qualification, not defaults the implementation may invent.
