# Primary source mapping and limits

Official code revision: `e60764df21ab63d39ffa726a0dd38c2b6f1e3e9a`, [COGITATE MSP1](https://github.com/Cogitate-consortium/cogitate-msp1/tree/e60764df21ab63d39ffa726a0dd38c2b6f1e3e9a). `SOURCE_ORIGINS.json` records exact MIT-licensed byte copies verified against the retained official Git tree's blob IDs. Those copies include the full phase-3 roster, fixed posterior sensor config, ROI loader and temporal-generalization source. No scientific function from those copies is executed during construction.

[P04_extract_events.py](https://raw.githubusercontent.com/Cogitate-consortium/cogitate-msp1/e60764df21ab63d39ffa726a0dd38c2b6f1e3e9a/coglib/meeg/preprocessing/P04_extract_events.py), lines 132–166, defines the V1 metadata, category/image trigger relationship, boolean response and raw-sample response-time calculation. [P07_make_epochs.py](https://raw.githubusercontent.com/Cogitate-consortium/cogitate-msp1/e60764df21ab63d39ffa726a0dd38c2b6f1e3e9a/coglib/meeg/preprocessing/P07_make_epochs.py), lines 95–126 and 173–198, describes concatenated metadata, epoch construction/detrending, annotation rejection and automated amplitude rejection. Their primary text was inspected through the web tool. Terminal TLS retrieval failed, so these two files are not represented as exact cached copies or as byte-verified source. Their expected tree blob IDs are retained for future authentication.

The [official dataset description](https://cogitate-consortium.github.io/cogitate-data/03_cogdataset/) supplies phase/experiment and event-code context. Experiment 1 uses manipulated duration and relevance; experiment 2 is outside this task. The full multimodal collection is not the eligible sample for this declared analysis. The source's ROI loader reads label-aware test pseudotrials and estimates covariance before splits; its source inverse also has a documented regularization-expression ambiguity. This package performs neither operation and makes no parity claim for its prospective sensor-space convention.

The current analysis fixes windows, long-duration transfer training, biological/image splitting, weighting and scoring prospectively. These are benchmark conventions, not claimed author preregistration. Full temporal/RSA theory tests, source-space spatial predictions, experiment-2 visibility and inferential calibration remain outside this package.

Data-use/access questions are recorded in the retained [COGITATE source audit](https://www.arc-cogitate.com/data-bundles); code MIT licensing does not resolve participant/stimulus data access or redistribution. The subject-averaged processed alternative at Zenodo15315238 is not a substitute for the required single trials and is not used.
