# Four-programme source distribution

This is a combined source distribution for the inactive HM and NEURAL-098 benchmark entries and their preserved NEURAL-056/CriticalInit dependencies. The 596 runtime files are retained byte for byte, including all original headers and notices. Source publication does not make these assignments runnable or scientifically qualified: both runtime manifests remain `source_only_inactive`, execution/scoring are null, and all65 qualification holds remain open.
