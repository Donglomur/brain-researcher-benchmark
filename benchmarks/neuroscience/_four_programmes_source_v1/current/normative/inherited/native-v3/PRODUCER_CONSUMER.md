# Complete producer and consumer contract

PRODUCER_GRAPH is the finite stage dependency graph. Its numbering is a stable identifier, not execution order: C08 must precede C06. Every concrete instance consumes the already completed actual parent captures/live owners, not a planned output or a future receipt. Each generated record gets its actual original producer request/operation custody where the base type supplies it; this amendment does not retroactively add self-receipt fields to base records. Publication and packet receipts remain separate later records.

## Full failure census and current source work

Every stage has three distinct conditions: not entered/no effect, entered with original known prefix, entered with unknown effect or failed cleanup. A failed constructor before endpoint return is not 'known closed'. After either endpoint returns it is owned even if the second flag/capture fails. After process return both original pipes remain owned before any fileno/nonblocking/identity check. After a physical short read/write its acknowledged prefix is retained before subsequent parse/clock/accounting. After H publication with lost reply its completed capture remains and W cannot replay. F00 is diagnostic-only and uses exact nullable resource projections for objects actually unavailable; it cannot be used as an alternative successful packet or owner.

Raw local exception identities remain in the exact source producer; wire projections carry only bounded source-owned enum/site/count fields. Unknown/uncaptured child exceptions remain unknown to H. All closes/waits/original terminal captures are attempted independently within original reserves even after a secondary failure; no blocking pipe drain is permitted without known nonblocking admission and original residual capacity. An ambiguous FD close/unlink/signal never restarts. Loss of the proxy channel itself does not erase the original H server/worker/native cleanup responsibilities.

Required source work is explicit: actual source-root bootstrap issuer/qualification; compiled versioned policy/profile and contract source captures; endpoint acquisition/remap/entry; fixed channel framing/credentials/state machine; H original reserve/effect/publication handlers; W proxy/captured-record factory; source-fixed backend native engine; full actual group/socket/artifact/native observations; and final H consumer integration. Existing native syscall fragments are concrete code but not this completed integration. The source-owned fixed agent entry, model/executable qualification, actual platform/private-channel/no-escape proof and all65 original gates remain unqualified.

NativeIOCustody, fixed process/HTTP/artifact/socket/group owners and all callbacks must be concrete source-owned callers using these exact interfaces.
