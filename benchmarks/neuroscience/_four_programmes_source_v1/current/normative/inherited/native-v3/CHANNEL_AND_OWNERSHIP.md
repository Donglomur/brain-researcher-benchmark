# Closed private channel and original cost ownership

## Transport and framing

Use one H-created AF_UNIX SOCK_SEQPACKET socketpair, SOCK_CLOEXEC initially, with both returned objects registered immediately in the original DevelopmentAttemptHandle. Set SO_PASSCRED on the receiver before launch. The H endpoint is nonblocking; a distinct alias of the original child endpoint is acquired as exact FD198 in original parent custody before Popen and explicitly included in pass_fds, and the remap must be explicitly present in the selected policy/profile/source closure. No caller-supplied integer, environment override, extra command flag, network socket, shared workspace file or writable cgroup descriptor creates a channel. W's entry validates AF_UNIX/SOCK_SEQPACKET, connected peer, source-selected descriptor and original bootstrap joins. No SCM_RIGHTS are sent or accepted. Each actual received packet must include exactly the required kernel SCM_CREDENTIALS, no extra ancillary records, no MSG_TRUNC/MSG_CTRUNC and no unexpected FDs; any returned unexpected descriptor must enter a once-only cleanup slot before refusal.

SO_PEERCRED on a socketpair created before fork may identify its creator; it must not be used as evidence that a packet came from W. H checks actual per-packet PID/uid/gid against the retained original RunningProcess and pidfd/start identity; W checks the actual H sender against its earlier independently admitted parent identity. Sender credentials do not substitute for retained original process identity or source/namespace qualification.

Every packet is canonical UTF8 JSON, exact closed PacketV1 fields, with no NUL, duplicate key, trailing bytes, nonfinite numeric value, alternate schema, encoded path alias or unbounded parse. Absolute wire ceiling is 65,536 bytes, also bounded by the selected original profile.maximum_request_bytes and profile.maximum_metadata_bytes. Effective packet_limit=min(65536, original request cap, original metadata cap); if it cannot hold one actual required packet, refuse before send. No capacity is added. Receive buffers, ancillary buffers, parse/hex/copy work and response capacity are reserved by H from the original shares before the corresponding read/child grant. recvmsg requests exactly the admitted finite bound; truncation is a failed original packet, never a retry/continuation.

A successful send must acknowledge the entire SOCK_SEQPACKET packet. A short/zero/unknown send, InterruptedError with uncertain effect, timeout, duplicate or unexpected sequence, response loss, peer death, invalid packet, unexpected credentials, or reply after original deadline permanently poisons the application channel. A known EAGAIN before any packet was accepted may await the same nonblocking readiness only within its original reservation/deadline; it does not create a second logical request. No reconnect, retransmission, deduplication-as-replay, reopened counter, repaired prior receipt or fresh owner follows uncertainty. H's existing terminal/native cleanup remains available under original reserved custody; successful worker application continuation is not.

There is exactly one outstanding request/reply and strictly increasing sequence. Sequence0 is BootstrapHelloV3/WorkerBootstrapGrantV1. Hello carries fixed schema/FDs plus actual prior sealed carrier digest and start-observation Pin; its packet context/source_policy/previous_ack remain null. H compares that later receipt to its actual original carrier/start, then authenticates worker/process/group before grant. W independently imports original H authority/clock/caps through actual FD199 before Hello; kernel credentials are additional checks, never sole authority. Later packets retain same original context/source policy and prior ack. Sequence advances only after exact authenticated reply; overflow, duplicate pending, uncertainty or identity mismatch refuses/poisons without replay.

There is no arbitrary method name, source callback, generic dictionary operation, path choice, read-file operation or generic source/backend admission operation.

The original H CanonicalPublisher remains the actual Store writer and original source/cost owner. W's closed WorkerCanonicalPublisher is a channel-bound facade. It admits one finite logical publication before encoding/copy and sends BeginPublication with fixed record kind, source-owned site and declared canonical extent/digest. A participant-supplied name or record kind is not accepted. Complete SOURCE_SITE_TABLE must be compiled and reviewed; an omitted site refuses, no wildcard path.

The total logical canonical bytes are bounded by the original H publisher maximum, original metadata allowance and pending-retained bound. The finite chunk count is exactly ceil(total_bytes/chunk_size), computed by H before storage; no supplied larger count. Chunks are sequential, contiguous, exact-length except the last, same publication ID/site/kind/digest and cannot overlap/replay. For newly published W records, W constructs WorkerCapturedRecord only through the exact live pending publisher receiving that ack over the retained channel; it keeps the original canonical bytes and same proxy owner. The separate fixed bootstrap/admission delivery factories create the same private handle only from complete authenticated original H captures under their closed table/reply selectors, retaining an explicit origin discriminant and actual pending reception. Arbitrary imported ack/body/Pin cannot construct it. Lost ack after successful H publication retains the H capture and W unknown disposition, forbids replay and prevents a second publication.

The explicit new worker lifecycle branch accepts only the fixed channel-created WorkerCapturedRecord and WorkerContextProxy; the old in-process EarlyResources/CapturedRecord branch remains exact and separate. read_capture validates raw byte identity/type/source/owner/attempt against the same completed local pending publication. ## Failure, teardown and external observation

Every returned socket/FD/process/buffer/iterator is registered immediately before subsequent fallible work. A close/remap/unlink/kill attempt latches and relinquishes its slot before the effect; unknown result never authorizes a second attempt against the integer or path. Preserve actual local first exception and ordered secondary exceptions without repr/str/attribute callbacks. Local W raw error identity stays local; bounded WireFailureProjection says which actual source retained it and what is unknown. H never fabricates a Python exception or claims a W object is retained in H. H transport/native failures are separate actual H raw objects. Diagnostic encode/write/clock failures cannot replace the original failure or erase its consumed prefix.

Pre-exec child failures occur before the W bootstrap protocol. If the child cannot send a source-qualified finite failure packet, H retains unknown child-local details and its actual launch/pipe/process observation; it must not claim an observed child exception object. The source-fixed bootstrap channel transport may preserve a bounded pre-entry failure record only if its actual producer and original caller identity are implemented and qualified. Absence is not zero. Channel shutdown consumes the earlier reserve, closes each endpoint once, and cannot imply server/worker/group closure. The existing original H outside E-bound closure still owns those claims.
