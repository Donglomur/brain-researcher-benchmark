## Prospective coordinates and features

PRE = [-0.1,0) seconds and LATE = [0.2,0.4) seconds, selected from actual source times. A time must agree with integer microseconds within 0.1 microsecond; successive samples must differ by 10,000 microseconds. PRE must contain ten and LATE twenty source samples. Missing or inconsistent coverage refuses the whole programme. These windows were prespecified for this new task; they are not claimed paper-analysis parity. The reported EEG units are released noise-normalized values, not microvolts; whitened axes are not untransformed anatomical sensors.

All four/eighty repetitions for an original image are averaged once. No repeat is an independent test unit. IMAGE is 176 deterministic low-level features: 48 RGB cell means (4×4 spatial cells) and 128 mean Sobel-magnitude orientation bins (4×4×8) from the original RGB image, no neural network, checkpoint, crop, resize or target-fitted representation. Source RGB mode and orientation must be qualified; the code refuses implicit color/orientation conversion. PRE is 17×10 values. BASE concatenates IMAGE and PRE. LATE appends 17×20 late values to exactly BASE. Thus dimensions are 176, 170, 346 and 686. Source images and all rows remain exactly matched across panels. These finite low-level features do not exhaust every possible visual confound.

## Split, estimator and training-only calibration

Each outer fold holds one entire person; only the other nine people's training images are available to FIT. Test concepts are disjoint from all 1,654 training concepts. A target-independent SHA256 order under `NEURAL-057/v1/concept/` divides all training concepts into 994 fit, 330 tune and 330 calibration concepts before unsupported-label filtering. Every image and repetition from a concept stays in its group. The lexicographically first remaining person is the inner held person; the other eight are inner fitting people. Inner fitting uses only fit concepts; tuning uses only tune concepts of the inner held person. The final fit uses fit+tune concepts of all nine training people; calibration uses only calibration concepts of those nine. There is no outer person's labeled calibration and no query-set transform fitting.

F's independent reference is a fixed weighted binary logistic procedure with lambda=1 for every category and a fixed train-only calibration procedure. I's independent reference selects lambda in [0.01,0.1,1] by all-53-category inner log loss (tie: smaller lambda), then refits and calibrates as above. Each panel uses the same groups, grid, optimizer limits, output obligations and resource limits. Training weights give equal person, equal concept within person and equal exemplar within concept. Scaling means/variances are fitted only to the current fitted training rows. Zero-variance scales become one. No source-fitted scaler is updated during query.

The logistic objective is weighted binary log loss plus lambda/2 times squared slope norm; intercept is unpenalized. Full-batch deterministic L-BFGS-B starts at zero, maxiter=2000, ftol=1e-12, gtol=1e-7, maxls=40. Nonconvergence is failure, never a fallback model. If a training category contains one class only, its predictor is the smoothed distinct-concept prevalence (positives+0.5)/(concepts+1). This retains the fixed category even when a class is absent. The 53 independent calibration maps have logit scale in [0,10], shift in [-10,10], a fixed quadratic penalty toward (1,0), maxiter=1000, ftol=1e-12 and gtol=1e-7. A constant training class or single-class calibration subset leaves the training predictor unchanged. No category is dropped based on held data.

## Protected loss and comparisons

Every query outputs 53 independent probabilities; they need not sum to one. Exact finite [0,1] probabilities are required. Truth is exact integer 0/1, not Boolean/float coercion. Log loss uses natural logarithms with no clipping: assigning zero probability to a positive label or one to a negative label yields explicit positive infinity. An undefined paired difference is reported unavailable, not replaced by zero. The native lower-is-better score is LATE loss. Fully reported matched BASE→LATE gains describe each owner's learning procedure; independent reference outcomes and all candidate control panels remain visible.

Within a person, average image loss within concept and then give every supported concept equal weight; average ten person means equally. The source reports every person and concept contribution, all unsupported query IDs and exact denominators. The paired person SEM uses ddof=1 with n=10 and a descriptive t9 interval; separate concept SEM is descriptive. There is no p-value reward, selective window search or test-label category dropping.
