# NEURAL-057 — prospective semantic prediction on THINGS-EEG2

This is a complete source-construction proposal, not a qualified benchmark run. The code contains an original-source preparer, independent reference fitter, participant FIT/INFER interface, complete campaign controller, protected scorer and native lifecycle. No EEG, original taxonomy mapping, image, key or model was opened, and no numerical/scientific/native workload was executed during construction. All future data and runtime prerequisites remain open. The N055 S8 donor's source acceptance is not N057 acceptance.

The task asks whether a fixed late EEG representation improves prediction of published THINGSplus category memberships beyond a matched low-level-image plus prestimulus comparator. The taxonomy has 53 overlapping categories, not an exclusive 53-way class. The original 1,854 concepts retain dispositions: 1,448 assigned, 406 unsupported/unassigned; 664 have multiple memberships. Unsupported concepts are not silently converted to all-negative truth. All 200 original query rows still require predictions; protected scoring selects supported concepts using the independently admitted original mapping and retains excluded identities and denominators.

The sole native task loss is mean Bernoulli log loss over all 53 fixed categories, then equal image within concept, equal concept within person and equal person. Lower LATE loss is better. Participant BASE-minus-LATE gain is reported descriptively, not used alone as a reward: worsening BASE cannot improve the native score. Independent reference IMAGE, PRE, BASE and LATE outputs permit matched comparisons. The complete reference and candidate collections must exist before any protected score is calculated.

The claim is descriptive prediction on this public corpus and its released preprocessing. It is not causal, not isolation of the current image's semantic activity, not raw-data inductive generalization and not a new protected-data claim. Stimuli occur every 200 ms; the proposed late window overlaps later presentations. Original session-wide MVNN mixes information across the released session and train/test partitions. Original sorted epoch dictionaries do not supply event-sequence identity. These facts remain limitations even after successful prediction.

The current source-level programme is 10 outer people × 2 source modes × 4 panels = 80 cells for each of two owners (independent reference and participant), 160 complete cells and 320 native FIT/INFER phases. These are construction scope counts, not benchmark or qualification increases. Every cell is fresh, including cells for the same person. A model may cross only from that exact cell's FIT to its fresh INFER; no sibling state, mutable caches, model service, provider, network or cross-query feedback exists in this profile. A participant commits both mode sources before preparation/exposure. No public or shared repository is mutated by this package.

The original source methods, new proposed science and qualification requirements are separated in SCIENTIFIC_METHODS.md and PROVENANCE.md. Exact current code is normative for closed field validation; API_CONTRACT.json fixes stage ordering and producer ownership. Any implementation discrepancy is a source finding, not permission to reinterpret a field. Independent whole review and root adoption are required before any delivery or execution.

V2 repairs only original terminal construction and complete cost-prefix publication. It preserves all scientific methods, 160 cells, 320 phases and 24 qualification gates.
