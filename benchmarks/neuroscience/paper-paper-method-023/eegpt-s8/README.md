# EEGPT S8: inspection and development source

This package exposes the EEGPT benchmark implementation for source inspection and further development. It is **not an execution-ready benchmark**, a result reproduction, a SOTA result, or a Terminal-Bench submission.

From this directory, use Python 3.11 or later:

```sh
python3 -I -S -B inspect.py inspect
python3 -I -S -B inspect.py verify
```

These commands read the finite, authenticated ordinary source closure and call the actual benchmark scope constructor. They do not load signals, targets, pretrained weights, scientific libraries or model code. They write no files. `python3 -I -S -B inspect.py execute` refuses: no execution authority or qualified intake is supplied. The copied standalone coordinator and reference entries also refuse scientific dispatch. The modules remain readable development source; this is not a sandbox for arbitrary imported code.

The scope is one catalogue assignment, PAPER-paper-method-023, with 11 scientific families, seven downstream datasets, 43 folds, 86 selectors, three downstream repetitions, 15,402 classification coordinates, 200 within-family contrasts and 1,200 metric cells. These are conditions and outputs, **not additional benchmarks**. Historical reconstruction (H), protected reconstruction (P), improvement (I), paper-and-data access (A), and paper-data-and-author-code access (B) remain distinct. All 24 scientific gates and 54 future scientific control groups remain open.

Every one of the original 157 operative roles is listed in PROGRAMME_ROLE_DISPOSITION.json: 69 roles are bundled and 88 remain required external source. All 32 benchmark modules and 20 contracts are included. The full EEGPT author family is external pending nested-source notices; the Temple model family has the same requirement. ARL EEGModels is included with its complete original CC0/Apache license. Licenses and exact upstream revisions are described in LICENSE_MATRIX.json and LICENSES_AND_PROVENANCE.md. Nothing is downloaded automatically and an absent family is never substituted by a smaller or different model.

The unresolved original no-predictor recipe/producer (S01) and historical H Temple recipe, seed/selection and checkpoint ancestry (S02) are scientific source gaps. They are not solved by installing dependencies. Prospective Temple P implementations do not establish historical H parity. C01 remains: uncertainty is conditional on fitted states; a single query person in a LOSO fold does not estimate retraining variability and may leave an interval unavailable. Authentic full-cohort intake, checkpoint ancestry, numerical parity, resource/isolation evidence and independent reference production are also outstanding. SOURCE_STATUS.json is the current publication status; older wording in retained design/specification files is source history, not a readiness claim.

This operator inspection package is **not the A or B participant information view**. Source-derived method diagnostics and grader algorithms are visible for public development. They must not be mounted into the A arm or silently supplied as hints; an eventual evaluation must create and audit its participant views and prior-exposure policy. No protected target values, answers, fitted-state bodies, private keys, primary papers, personal communications, private build history, credentials or signed resource URLs are included. Published method descriptions and public source-derived constants are distinct from protected outcome data.

SOURCE_MANIFEST.json closes the actual public file set. ORIGINAL_PROGRAMME_IDENTITY.json names the prior complete source identity solely as provenance; it does not attest that the external source is present. PORTABLE_CHANGES.json records the exact locator changes and inspection-entry restrictions. No scientific algorithm was replaced. Development changes require a new manifest, source review and authority/intake decisions before any scientific run; adding data or a configuration file to this package does not authorize execution.
