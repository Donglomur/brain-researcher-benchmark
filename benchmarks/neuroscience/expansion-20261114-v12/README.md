# Hybrid behavioral-data benchmark draft

This adds one registered neural-track task: **causal held-session prediction of human information-sampling and stopping decisions**. The [complete definition](tasks/NEURAL-CENTRAL-20261114-HYBRID-BEHAVIOR.json) preserves all 20 participants, 80 sessions, 4,884 trials and 163,135 eligible decisions. The task uses human behavior; it contains no neural measurements and does not reproduce the paper's ANN, symbolic or imaging result.

The [registry](registry.json) extends the unchanged [233-draft predecessor](../expansion-20261114-v11/registry.json) to **234 drafts: 116 paper and 118 neural**. Zero complete registered contracts are qualified and zero tasks are submission-ready. The public checkout gains a scientific definition, not a runnable authentic evaluator.

The source study is [Dambrogio and colleagues, Nature Neuroscience (2026)](https://www.nature.com/articles/s41593-026-02342-9), with [official code/data](https://github.com/simonedambrogio/HybridModellingProject/tree/3d343beb6dc7f1b7c6c7521ebec61f7dcef35b12) and [archived release](https://zenodo.org/records/19685085). The definition pins the code revision and processed data object. Public availability and software licensing do not establish permission to redistribute every data artifact.

A program commits four action probabilities before seeing the next observation. All four held-session folds per participant are required. The primary metric averages decision NLL within session, four sessions within participant, then all 20 participants equally. Candidate improvement is compared with the fixed training-selected reference family; selection uses only inner training sessions. Other reference contrasts are descriptive unless a confirmatory multiplicity policy is fixed beforehand. Participant-level uncertainty, both stopping recalls, failed coverage and public-data contamination must be reported.

Complete authentic trusted-host reference construction is independently accepted. Its trained-family NLL is 0.259685; the reported improvement interval includes zero and both stopping recalls are below 2%. These are neither SOTA nor LLM capability results. Invented isolated episodes validate interface behavior separately; the complete authentic arbitrary-candidate route has not run. General candidate training/export/provenance, matched-history comparisons and public data distribution remain unverified.

This fourth narrow local profile has a different evidence scope from the three earlier protected reconstruction evaluations. The separate whole-paper candidate remains held and unregistered. No accepted reference fits were rerun for registration. Folds, models, modes and trials add no tasks or independent source families.

Private local evidence paths are null; the retained byte/hash references do not include those evidence bodies. Current registry/publication context governs registration where frozen source wording describes an earlier proposal. Scientific values and limitations are unchanged. The receipt-aware private catalog is not distributed. Existing [Hybrid causal controls](../hybrid-causal-controls-v1/README.md) use invented data and do not reproduce these authentic results.
