# MotorMINT benchmark source

This is the complete **source-only** MotorMINT package for one benchmark assignment, `PAPER-paper-method-011`. It covers nine datasets and 17 required analysis modules, including 964 factorial R² cells, 14,800 neuron-loss group R² cells, four maze simulation regimes, a multitask network, seven NLB data sources, and the RTT pseudo-condition accuracy–cost comparison. These are obligations within one task, not separate benchmarks.

The paired conditions compare a paper and its data with the same inputs plus an admitted author implementation. Reproduction and prospective improvement retain separate estimands, reference comparisons, uncertainty and resource costs. The default and `full_motormint_v1` identify the same complete programme.

**Deployment is disabled. All 17 scientific gates remain unresolved.** This release contains no neural-data payloads, protected answers, trained models, qualified native environment, empirical evaluation results or SOTA claim. Published dataset counts and method settings describe the paper; they do not authenticate the underlying data. The tiny invented numerical examples in the source are engineering controls, not neuroscience observations.
