# MotorMINT full-paper source interface

One canonical assignment: PAPER-paper-method-011. The target is the full accepted nine-dataset,17-module paper programme, including964 factorial R² cells,14,800 neuron-loss group R² cells, four maze simulation regimes, the multi-task network, RTT pseudo-condition accuracy/cost, seven NLB data sources and all17 original scientific gates.

The paired conditions compare paper+data against the same resources plus the selected author implementation. Independent reference, candidate A and candidate B run in complete balanced blocks. Reproduction and improvement remain distinct case purposes. Outputs retain their original estimands, matched references, uncertainty and scientific units; they are never averaged into one cross-estimand score.

This package implements the canonical source CLI and complete invocation construction around the accepted MotorMINT runtime. Its bundled deployment is disabled. A source inspection or a successful engineering control does not authorize neural input access, fit models, establish native equivalence or produce a scientific result.

Original data support, authentic preprocessing, unknown historical conventions and missing full-paper method extensions remain required gates. The constructor cannot replace them with a smaller cohort, a callback or a JSON success label.
