# Numerical contracts and independent reference banks

This document defines future numerical work; no reference was implemented, imported or executed in this phase. BankA and BankB must be authored independently under later explicit grants. They share this written contract, admitted immutable observations, units/schema, basic libraries and source pins. They do not share candidate code, the other bank's code, intermediate matches, fitted state, scores or selected outputs. Native author sorters are competent algorithmic comparators only after separate qualification; the numerical banks are not substitute spike sorters.

A compressed archive name or tutorial probe is insufficient. Preserve all mandatory source units and event rows. Admission must establish the source class/ID join, including any source nmax600 convention; arbitrary first600 slicing is forbidden.

Event timestamps are compared in exact rational physical seconds, or an exactly equivalent common integer tick domain. No floating conversion may silently move a boundary. Candidate event times must be finite, in the admitted recording interval and assigned to a declared observed unit. Normalize I unit identity using unique event labels with a stable original-ID map; no-event declarations do not create recovered units. An entirely empty candidate recording is valid abstention, not an exception concealed by a default score. Repeated times are distinct events for I's one-to-one matching. Unsorted valid events are stably sorted by(time, original row ordinal) in I. R_source preserves the called source routine's input-order assumptions instead of applying this repair invisibly.

Literal publication conversion remains a separate R gate.

Every output records case/unit identity, full support, profile/version, match counts, FP/FN denominators, pair score, quality flags and reason codes, aggregate numerators/denominators, and scientific/native/source failures. ## R_source20: literal released-source behavior

The authoritative captured modules are bench.py8,533B/SHA07390fa03e78c46d5fd9f639a6040e03fa18d2345cfc2894dd6dd64e0b8877ef and CCG.py3,566B/SHA3ec752f016d0ca825b9dea7617f5a702effaa8a271f3d18707e844c88dc7d270, from the authenticated v4.0.2 GitHub capture. The complete function, dtype, array-order and library profile must accompany any native run. This prose does not silently replace a source operation.

compare_recordings allocates U×20 result arrays, then match_neuron ranks detected-unit vertical coordinates by NumPy argsort of absolute depth difference. It checks min(20,D) units. The exact NumPy version/tie behavior and the source of depth estimates belong to the pinned runtime; unspecified equal-depth ordering is not assigned a fictitious historical tie rule. Depths come from source waveform/PC processing, including every-tenth-batch sampling in clu_ypos and its strict interior-batch event mask. Missing waveform counts or nonfinite depths are recorded as source problems, not invented channel locations.

nmatch starts i=j=0. For each truth event it advances j while a following detected event is at most truth_time+dt, then tests the current detected event against the tolerance. It can count the same detected event for more than one truth event. It does not implement nearest-event matching or a bijection. Its return n0 is the number of truth iterations counted as matches, while the separate detected Boolean array can have a smaller count. match_neuron uses n0 for both denominators, computes FN=max(0,1−n0/n) and FP=max(0,1−n0/m), and compares1−FN−FP to an initial fmax=0. Strictly greater scores replace the first initialized best_ind; zero/negative alternatives leave the initialized miss/FP values at0. Those misleading zeros are preserved as literal-source outputs, with an explicit status; they are not interpreted as absence of errors.

The helper's default dt=6 is a sample count, not a universal millisecond interval. At30kHz it equals0.2ms. At another clock or a fractional transformed timestamp, the publication equivalence must be checked. n_check=20 is hard-coded by compare_recordings. Empty detected depths trigger access to isort[0]; zero truth events and absent label slots can cause undefined divisions; these are source-specified failure/undefined branches, not observed failures in this phase. Native result handling must preserve them.

The source converter signature mismatch, simulator writer mismatch and all other static pitfalls do not disappear from this profile. A separately specified wrapper can use a supported source entrypoint only after its publication/native relationship is authenticated. An altered helper belongs to a separately pinned reconstruction, with the original source outcome retained.

## I_bijective_full: exact authored matching

For each truth/detected unit pair with n,m events, let k be the maximum number of one-to-one event pairs satisfying |t_truth−t_detected|≤1/5000second. Every event participates in at most one pair for that unit-pair comparison. All U×D pairs belong to the domain. A temporal index may prove zero-coincidence pairs without traversing their full trains; a depth-neighbor cap may not discard possible matches. Empty truth trains have no recovery edge and stay in the complete truth-unit denominator. Empty output has recovered count0, no output quality units, FN=1 for each nonempty truth unit and undefined precision/FP denominators, explicitly typed.

For n,m>0, precision=k/m, recall=k/n, FP=1−k/m, FN=1−k/n and score=k/m+k/n−1. Retain negative pair scores. A recovery edge exists exactly when score>4/5, equivalently5k(n+m)>9nm. Use exact integer arithmetic for that strict boundary. No epsilon, floor or rounded percentage changes edge membership. The independent best-score curve for each truth unit takes the largest score over observed detected units; equal scores use canonical detected-ID ordering solely for its displayed witness. If D=0, score is null with abstention status, and recovery remains0; a zero-filled curve is not fabricated.

Construct a bipartite graph of truth units and detected units with those recovery edges. First maximize the number of injectively assigned edges; then, among maximum-cardinality assignments, maximize the number of assigned detected units classified as good by the fixed quality contract below. These integer objectives make both recovered count and unmatched-good count invariant to residual tied assignments. A bank may return a different valid tied witness. Validate its feasibility and both objective values; do not require identical arbitrary assignment labels. Witness-dependent flags are labeled as such. Per-truth independent best-score and individually-matchable flags remain separate from the injective assignment.

Known-truth duplicates are detected units that have at least one recovery edge but are unassigned after the optimal cardinality assignment. Their count is the number of such detected units minus the recovered count, independent of a tied witness. For hybrids, this is a duplication diagnostic about labeled injected units; all other unmatched natural units remain unclassified. For full synthetic and biophysical data, unmatched-good count is total good detected units minus the optimized number of good assigned units. It is the paper-inspired quality-surrogate endpoint, not proof that every unmatched unit is a biologically nonexistent neuron. Multi-unit/background modeling and finite source support remain relevant limitations.

The exact duplicate aggregation is v_c=duplicate_count_c/U_c and v=(sum_H v_c/3 + sum_D v_c/6 + sum_B v_c/2)/3. U_c is the designated evaluation-truth denominator above, never all1200 synthetic generators or the candidate's detected-unit count. The meaningful-improvement guard is v_candidate≤v_reference using exact rational arithmetic. It is aggregate-only; all per-case duplicate deltas must be reported, but no unstated per-case duplicate guard is applied. The q guard analogously uses (sum_D unmatched_good_c/U_c/6 + sum_B unmatched_good_c/U_c/2)/2.

## Fixed I quality calculation and source-role distinctions

The service computes quality from events, not candidate-provided good/bad labels. The authored I policy follows the captured CCG ratio/probability calculation with Q<0.2 and P<0.2, and requires more than10 spikes and positive time span. Small/degenerate trains receive not-assessable quality and are not called good; they are still present in outputs, matching, diagnostics and resource counts. The source's initialized Q=0 for untested units must never be mistaken for a passed quality test.

Use nbins=500 and tbin=1ms, except the twice-speed biophysical condition uses0.5ms. The window is±nbins*tbin. For target event t and source event s, include t−window<s≤t+window, matching the captured left-open/right-closed CCG loop. Histogram index is round-to-nearest, ties-to-even of(t−s)/tbin, plus500. The autocorrelogram initially includes self-pairs and distinct same-bin pairs. For quality metrics only, set the entire central bin to0 and restore it in any returned display histogram. Do not confuse removal of the whole zero bin with removal of self-pairs alone.

Let H be the1001-bin histogram, N the train length and T=max(time)−min(time). Source index sets are F={1,…,249}∪{750,…,999}, L={450,…,489}, R={510,…,549}. Define Q00=sum(H[F])/(|F|*tbin*N²/T), Q1 and Q2 similarly for L/R, and baseline R00=max(mean(H[F]),mean(H[L]),mean(H[R])). After zeroing the central bin, for i=1,…,10 let c_i=sum(H[500−i:500+i+1]); Q_i=c_i/(2i*tbin*N²/T), n_i=c_i/2 and λ_i=R00*i. Then Q=min_i(Q_i)/(10^−10+max(Q00,Q1,Q2)) and P=min_i{[1+erf((n_i−λ_i)/sqrt(10^−10+2λ_i))]/2}. This names the code's Q12 contamination ratio and R12 probability explicitly, avoiding reversal with the paper's symbols.

For I, rational quantities and Q-threshold comparisons can be computed exactly from integer counts/rational clocks. P is a transcendental function: each independent bank must provide enough numerical precision or certified interval refinement to establish its comparison to1/5. If a boundary cannot be resolved within the admitted finite precision/resource profile, the quality decision and joint improvement claim are unresolved; they are not coerced by a tolerance. R_source instead preserves its pinned floating implementation and separately reports numerical parity failure. Internal sorter ACG/split thresholds and README10% labeling are different roles, not silently replaced by this evaluation policy.

## Two independent bank algorithms and coverage

BankA uses independently authored sorted two-pointer interval matching for each nonzero-coincidence unit pair. An exchange argument establishes that pairing the earliest mutually compatible events yields maximum event cardinality in ordered tolerance intervals. It computes maximum unit cardinality and then maximum good-unit cardinality with independently authored integer min-cost max-flow. BankA independently enumerates CCG windows/histograms and all panel aggregations.

BankB constructs temporal coincidence edges with an independent sorted endpoint/range-index sweep and obtains event cardinalities through an independent sparse bipartite matching algorithm. It computes the two unit objectives with an independently authored padded integer assignment formulation; the dominant cardinality weight must exceed the maximum possible good-count difference. It independently computes quality histograms using range-index bin counts with the identical open/closed and rounding rules. It shares no finished edges/matches with BankA. Neither bank imports bench.py or CCG.py to produce its I answers.

Sparse temporal construction must be exhaustive, not approximate. Charge the total coincidence edges E_time, indexing, pair grouping, event matching and integer assignment. Pathological event bursts can create dense time-edge graphs. A streaming/external-memory or per-pair alternative is acceptable only with the same complete domain and prospective resource accounting. Fixed depth culling or a shorter recording is not an acceptable optimization. Worst-case dense assignment O(max(U,D)^3) and O(UD) storage are explicit; independent algorithms may have different operation/space counts.

For R_source both banks independently emulate the written/source-pinned primitive semantics, including failure branches, and compare to the separately qualified native source.
