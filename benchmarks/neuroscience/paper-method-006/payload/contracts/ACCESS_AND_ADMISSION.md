# Access, data roles and future admission

The canonical task has matched A/B access and separate R/I objectives. Resource differences are disclosed as experimental conditions, not hidden in a software bundle. Public historical exposure applies to all arms. Nothing in this source design proves provider isolation, unseen data or faithful native execution.

## Typed observations and artifacts

1. **Common primary literature:** the authenticated main article, genuine supplement/reporting summary when recovered, and source-independent written methods/metric contracts. Reading published Methods/results is literature exposure; it is not a new authentic grading run. Whole-paper figures and reported numbers are already public and cannot be treated as secret targets.
2. **Common signal observations:** every admitted complete original recording/view, native clocks/channel geometry, legitimate fixed processed observations and necessary input metadata. Candidates may inspect all of the current I query recording and estimate unsupervised state. They receive no previous query's mutable state or private score feedback.
3. **Original construction observations:** the complete512 drift-source inventory,11 waveform-source inputs,597-waveform/1497-ISI lineage and all constructor configuration. Pre-existing IBL processed drift/spike observations may be a legitimate *paper input boundary* if authenticated as the paper's original inputs. This reproduces the paper's downstream use; it does not claim independent rerunning of upstream IBL sorting or biological acquisition. Raw waveform extraction and the paper's own simulation/injection processing remain required. If upstream pyKilosort regeneration is claimed or needed to recover missing original inputs, its complete graph/costs are additional. This boundary must be frozen before implementation, not selected after convenient results.
4. **Truth and source answers:** injected/simulated spike times, identities, source-unit linkage, outcomes and reference comparisons are role-typed. Positive evaluation targets are all100 injected units per hybrid, the designated600 single units per synthetic condition and the complete original biophysical single-unit roster. Each synthetic condition also retains all600 MUA generators as construction/background support, not positive evaluation targets. Authenticate that class/ID-role join; a source helper's nmax600 does not authorize slicing unverified physical labels. R can receive the input truth required to reconstruct the original analyses in its own workspace. I final truth, reference outputs, intermediate scores, matching decisions, selected examples and failure-conditioned feedback remain in the grader. An innocuous filename, archive-member order, log, precomputed embedding or cached array must not serve as a label channel.
5. **Author code:** only B receives the authenticated output-free source packet, with exact file pins, license and publication-version relation. This includes each selected author-method version needed for the whole paper, not merely the held Kilosort4 snapshot; old Kilosort-family source versions are unresolved gates. A must not receive a selected-author native sorter as a hidden callable oracle, source archive, wrapper, cached executable or completed answer table. Frozen third-party comparator tools unrelated to the selected author-method implementation may be common to both arms only under an explicitly admitted identical tool manifest; otherwise comparator execution stays with the grader. The source-family boundary and old-version literature necessary for A reproduction must be admitted before implementation. The package's source, notebooks, model/template resources and precomputed numerical outputs must be classified separately. Notebook code can be admitted through a source-only extraction; cached outputs and answer arrays are excluded. This phase did not inspect notebook outputs or wTEMP bodies.
6. **Templates/models:** wTEMP.npz and any fitted/template bank used as a legitimate fixed input require separate provenance and role admission. If used, the exact same resource must be available to A and B, or a separately named access condition must be adopted; it cannot ride silently inside B's code advantage. Default templates-from-current-data does not establish or waive the predefined-bank branch's provenance. No model resource was read or authorized here.
7. **New runtime artifacts:** candidate spike outputs, native outputs, metric-bank products, temporary arrays, logs and figure products are keyed by canonical task, arm, objective, profile, query identity and attempt. The R and I namespaces, mounts and processes are distinct. The two banks have distinct writable namespaces and do not exchange numerical artifacts.

## Commitment and query lifecycle

Each access arm commits one I program/configuration/resource manifest before receiving protected evaluation truth or any R workspace outputs. A and B receive equal observation/tool/time policies except the declared code packet. Code generation and method commitment do not count as scientific validation. R can then proceed in independent contexts; no R-generated labeling, fitted state, hints, metrics or selected plots may update the sealed I method. The controller must prevent artifact access and feedback, rather than rely only on a prose promise. Historical model/provider exposure is separately disclosed and remains unverified.

For each I query, a fresh process receives its complete admitted signal, permitted metadata and the sealed method. It can perform full-recording unsupervised fitting. It emits all events/unit IDs and mandatory diagnostics, then terminates. The controller validates coverage, clock/shape, outputs and resource receipts before any private metric worker runs. The method does not receive that score before processing another query. The selected policy permits no cross-query fitted-state transfer, final-truth HPO, online adaptation based on past scores or external network/provider calls. Common immutable libraries/resources may be reused with provenance; candidate state cannot be disguised as a common cache.

One scientific worker at a time is the baseline schedule, with independent complete-recording contexts. Internal threads, child processes and GPU streams are separately pinned and counted. A controller may batch transport without merging query state or changing outputs. Physical worker/process receipts must show the actual schedule. Admission failure, over-budget work and native crashes retain attempted costs and typed partial artifacts; no restart with a smaller dataset is automatically selected.

## Authentic admission checklist as scientific gates

For each original asset, require versioned source identity, full object/member descriptor and integrity, complete scope, native format/dtype/endianness, compression decoder, shape/sample count, channel/neural/sync mapping, clock/origin/transform, units/scaling, and deterministic source-to-query role join. Descriptors can establish expected extents; only later authorized authentic admission can establish payload/native facts. Previously captured small hybrid headers are not reread in this design. Their historical metadata claims are evidence to verify, not new body authentication.

Resolve the three hybrid archive-to-IBL joins, six simulation geometry/configuration joins, normal/twice-speed biophysical transform, original Fig1 locator relation, Fig2 exact files, complete other-probe sessions and immutable DANDI versions. Preserve every source row even where excluded by an original scientific rule. A missing field, unknown session or inaccessible branch is required-unscorable, not silently omitted from an aggregate.

The paper's dataset/comparator definitions and the benchmark I definitions are distinct. Original released traces remain fixed observations. Independently recreating them from raw sources requires a producer/version/seed contract and its full cost. A processed-boundary reproduction claim is narrower than end-to-end upstream regeneration and must say so. No fake constructor may create counts, waveforms, labels or clocks from a figure, precomputed score or convenient filename.

Later engineering controls must demonstrate separate mounts/namespaces, blocked truth/reference access, fresh query state, immutable code commitment, no R-to-I transfer and no score-feedback selection. This design adds zero canonical IDs and zero qualified tasks. The source-only queue of its preceding selection did not install an interface or authorize scientific work. This design package has no queue authority unless root separately selects an exact reviewed union.
