# Predictive and instructive cerebellar encoding of dopamine reward drives motivated behavior

This repository contains the MATLAB analysis code and processed data supporting:

> Benjamin A. Filio, Amma Otchere, Subhiksha Srinivasan, Srijan Thota, Luke Drake, Lizmaylin Ramos, Philipp Maurus, and Mark J. Wagner. “Predictive and instructive cerebellar encoding of dopamine reward drives motivated behavior.” (in press).

The study examined how cerebellar granule cells (GrCs) and climbing fibers (CFs) represent rewarding outcomes that do not require physical consumption. Head-fixed mice learned to push a robotic handle for delayed optogenetic activation of ventral tegmental area dopamine neurons or electrical stimulation of the medial forebrain bundle. Additional experiments examined water reward, altered reward delays, chronic cell registration, passive stimulation, CF-mediated reinforcement, and optogenetic inhibition of GrCs during learning.

The repository includes analysis-ready MATLAB data, scripts that reproduce the data-driven panels and statistical analyses, bundled helper functions, and numerical source-data workbooks. Raw two-photon movies and original behavioral videos are not included.

## Requirements

The code was verified with:

- MATLAB R2025a
- Statistics and Machine Learning Toolbox
- Signal Processing Toolbox

Earlier MATLAB releases may work but were not tested. `MainData.m` loads two large MAT files and requires substantially more memory than the other scripts.

No separate installation is required for the functions in `dependencies/`. Each top-level script locates its own directory and adds the adjacent `dependencies` folder to the MATLAB path automatically. The helper files should otherwise be left in place.

## Quick start

1. Download or clone the complete repository while preserving its directory structure.
2. If the MAT files are not included in your copy, download the processed data from the associated Dryad record.
3. Place the MAT files in `data/`, or select their location when MATLAB prompts you.
4. Open a top-level `.m` script in the MATLAB Editor.
5. Run the complete script.

Each script first looks for a `data` folder beside itself. If that folder is absent, a directory-selection dialog asks for the folder containing the MAT files.

Running an entire script from the beginning is the most reliable way to reproduce its analyses. For section-by-section execution, run the initialization section first, retain the variables created by preceding sections, and keep the script active in the MATLAB Editor so that its location can be resolved correctly.

The scripts create MATLAB figure windows and print statistical results in figure titles or the Command Window. They do not save publication-layout figure files automatically.

## Data

The `data/` directory contains processed, analysis-ready MATLAB files rather than raw acquisition data. These files include trial- and session-level behavior, event-aligned neural activity, chronic cell-registration results, learning curves, stimulation signals, licking measurements, and markerless-pose-estimation outputs.

`mainData1.mat` and `mainData2.mat` are two parts of the same primary dataset and must be used together. They were split only to make the large dataset easier to store and distribute.

Not every session contains every experimental modality. Empty values, absent optional structure fields, and `NaN` values indicate unavailable, missing, or excluded measurements as appropriate. Individual panels apply their own animal-, session-, trial-, cell-, registration-, and tracking-quality criteria. Consequently, sample counts can differ across panels derived from the same top-level MAT file.

The associated paper and its Methods provide the authoritative definitions of experimental groups, preprocessing, inclusion criteria, analysis windows, and statistical tests. The Dryad record provides the detailed data-file and variable descriptions; the repository copy of that documentation is retained in [`README_DRYAD.md`](README_DRYAD.md).

## Numerical source data

Prepared numerical source data are located in `excel/SourceData/`, with one workbook for each main or Extended Data figure. Worksheet names identify the corresponding figure panels.

`excel/MainData.xlsx` is the master workbook used during source-data generation. Each top-level script defines the following parameter near its beginning:

```matlab
exportSrcData = false;
```

Leave this set to `false` for ordinary figure reproduction. Set it to `true` only when regenerating or updating the master workbook through `dependencies/export_nature_master.m`.

Before enabling source-data export:

- close `MainData.xlsx` in Excel;
- confirm that the repository is in a writable location; and
- retain the existing `excel/` directory.

An open workbook or a read-only directory can prevent MATLAB from saving the export.

## Reproducibility notes

- Some analyses use random shuffling or permutation controls. Their Monte Carlo estimates can vary slightly between runs unless a random-number-generator seed is set before the relevant section.
- Figure appearance can vary modestly with MATLAB version, operating system, fonts, and display settings.
- The supplied analyses use the processed and normalized signals stored in the MAT files. Re-running motion correction, neural source extraction, spike detection, or pose estimation requires the original imaging or video data, which are outside this repository.
- Original acquisition-directory strings retained in some structures serve as provenance or session identifiers. Those paths do not need to exist on another computer.
