# Figure 2h held-event accuracy

This executable component adds spontaneous-transition prediction scoring for the registered REM result family. It does not prepare neural features, fit a classifier, recover original random draws, or qualify reproduction or improvement. The existing [Figure 5e evaluator](../../../../shared/neuroscience-components/rem-dmm-figure5e/README.md) remains separate and unchanged. Both original strata are required for the registered task. Reproducing original findings and exceeding them on the same task are separate first-class outcomes. Paired paper+data and paper+data+author-code conditions must retain identical observations, evaluation support and budgets; this scorer does not establish either paired delivery or either scientific outcome.

The evaluator retains the 22-PC by owner-supplied-time-coordinate by 25-repeat accuracy array, confusion counts, means and resampling SEM. An optional frozen comparator is joined to exactly the same held events and produces paired accuracy differences and discordant correctness counts. It reports all six mice in every cell, including null accuracy for mice absent from a draw, and preserves the complete 424-event census with zero-use events. It never substitutes equal-mouse accuracy, Brier loss, significance, a favorable PC/time, or an aggregate scalar for the original pooled-event endpoint.

The [source paper](https://www.nature.com/articles/s41593-026-02314-z), Methods “Classification analysis,” describes 70% of REM events plus the same number of Wake events for training, and remaining REM events plus equally many Wake events for testing. A training/test draw is reused for all time bins, with 25 repetitions. The public source describes six mice, 47 REM and 377 Wake events. Here 1 means NREM-to-REM and 0 means NREM-to-Wake.

There is no default numerical time grid or inferred bin count. The operator must supply the exact numerical coordinates plus their source artifact hash and locator. The scorer enforces finite ordered coordinates in the preceding 150-second window at 10-second spacing and complete predictions over every declared coordinate. Neither a syntactically valid hash nor this grid check establishes that the operator supplied the complete original grid. Recover and independently authenticate that grid before original-paper qualification; a reduced grid cannot establish either reproduction or improvement. The mention of significance through zero does not resolve whether the figure coordinates denote bin edges, centers or another convention. Neural sample support, realized event mapping, rounding, random draws and cross-PC split sharing remain unrecovered. The scorer permits separate draws for each PC, requires one draw across that PC's time bins, and requires the owner to bind 32 or 33 training REM events explicitly. It refuses train/test overlap for either class.

`score.py OWNER.json CANDIDATE.json [--baseline BASELINE.json]` prints a JSON report. All input files are bounded to 32 MiB and parsed without pickle or code execution. The CLI is an operator utility, not an isolated candidate runtime or a hostile-filesystem sandbox. Keep owner labels, raw recordings and full scoring reports outside public Git. The scorer's `public_plan` removes outcome fields but is not by itself a qualified participant packet: joint split membership, public event information and repeated exposure can reveal outcomes, so its use requires a separate exposure review.

The owner schema is `rem-fig2h-owner-v1`: `task_id`, `provenance`, six unique `mice`, 424 `events` (`event_id`, `mouse_id`, `label`), `time_seconds`, `rem_train_count`, and 550 `splits` (`pc`, `repeat`, `train_ids`, `test_ids`). PCs are 1–22 and repeats are 0–24. Provenance requires SHA-256 identities for the retained article, cohort join, preprocessing, split source and time-grid source, plus `time_grid_source_locator`; hash syntax alone does not authenticate any of those sources. The article digest is fixed to the reviewed source copy. Each balanced split uses all 47 REM events and 47 of the original 377 Wake events, retaining all unused Wake events in the census.

The prediction schema is `rem-fig2h-predictions-v1`: `task_id`, `case_plan_sha256` (the canonical hash returned by `public_plan`) and `22 × 25 × len(time_seconds)` cells. Each cell contains `pc`, `repeat`, `time_seconds`, `test_ids` and corresponding integer `predicted_labels`. Explicit IDs allow arbitrary within-cell ordering while detecting substituted training events, duplicates and missing observations. Candidate and comparator use exactly the same schema and plan. No candidate-provided targets or reported accuracy are accepted.

`test_score.py` uses generated data with the source cohort and PC/repeat dimensions, and explicitly generated coordinate grids that are not evidence of the original grid. Tests check analytic confusion/accuracy/SEM and paired differences, absent-mouse handling, complete declared-grid support, ID joins, train/test leakage, both rounding choices, target rejection and malformed JSON. They establish software behavior only. No authentic arrays, original predictions, cached notebook outputs, model fits or new scientific runs were used. Resampling SEM is descriptive across reused events; it is not a six-mouse uncertainty interval. No t-test, Bonferroni family, significance onset, meaningful-effect threshold or improvement decision is invented.
