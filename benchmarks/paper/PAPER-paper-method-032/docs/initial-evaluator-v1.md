# MindEye2 initial evaluator v1

This package implements an independently useful **feature-level retrieval evaluator**, post-model repeat aggregation, two reconstruction metric kernels, and an exposure-ledger audit. It adds source implementation to `PAPER-paper-method-032`; it does not complete or qualify the canonical paper task. No neural data, images, weights, model execution, or authentic scientific results are bundled.

The canonical contract remains byte-identical (SHA-256 `be0baca5eebb4c64fa0d6096fdbd9df12aa16e4abf9342c6d16ab0aa433ac9ff`). Its complete adaptation/reconstruction and same-data comparison requirements remain in force. Native feature production, full reconstruction metrics, protected execution, authentic reference/baseline competence, and rights/exposure qualification are outstanding.

## Source and prospective policy

The [primary paper](https://proceedings.mlr.press/v235/scotti24a.html), [author README](https://github.com/MedARC-AI/MindEyeV2/blob/76a2609243ba1bacb450e47e3dc78de1f78a9c00/README.md), and [evaluation notebook](https://github.com/MedARC-AI/MindEyeV2/blob/76a2609243ba1bacb450e47e3dc78de1f78a9c00/src/final_evaluations.ipynb) define the implementation. Code revision is `76a2609243ba1bacb450e47e3dc78de1f78a9c00`; the historical dataset revision is `26421f100e4c6012a35ecadb272a0ec1d999202d`. Source inspection establishes semantics, not authentic execution. The provenance JSON records precise code locators and outstanding disagreements.

* Image retrieval queries brain embeddings against image embeddings. Brain retrieval reverses queries and candidates, following the author correction.
* Each of 30 draws uses 300 distinct matched images. Features are flattened and L2 normalized. Both directions use the same draw and identity order. The report preserves every draw, its mean, and normal 95% interval using population SD divided by √30. This interval quantifies variation over retrieval subsets; it is not a subject or population confidence interval.
* The operator freezes the actual draw identities before candidate access. `freeze_pools` uses a local NumPy legacy `RandomState(42)` by default. This prospective choice prevents global-state drift and does **not** reproduce the unknown historical notebook RNG state. Retrieval ties are rejected because native GPU argsort tie ordering is not portable. No native numeric-equivalence claim is made.
* Reference admission requires 1,000 unique image identities for each admitted paper subject (1, 2, 5, or 7). It binds an externally verified full-population manifest and feature extraction receipt by SHA-256. A count and a hash do not independently prove their biological contents. All four subjects remain required for paper-level reporting; one subject's component output is not a cohort result.
* `aggregate_repeat_embeddings` sorts integer NSD image indices and averages **post-model outputs**. One observed presentation is repeated three times; two presentations receive the author's 2:1 weighting; three are averaged. Averaging voxels before the nonlinear model is not equivalent. Trial identities, original order and completeness still need native verification.
* `reconstruction_identification` implements the notebook's strict Pearson comparisons for each reconstruction against other real-image features (column-wise); equal similarities lose. Paper appendix prose describes the opposite orientation. That discrepancy stays explicit and unresolved. `paired_pearson` is a kernel for already preprocessed paired arrays. Neither routine runs image models, resizes images, or substitutes for SSIM/all required reconstruction endpoints.

The paper's one-hour setting adapts a model pretrained on seven other subjects using the target's first session. The [training notebook](https://github.com/MedARC-AI/MindEyeV2/blob/76a2609243ba1bacb450e47e3dc78de1f78a9c00/src/Train.ipynb) selects `train/0.tar` for one session. The nominal 750 presentations/resampled examples per epoch do not prove 750 unique eligible training records after exclusions. A shard is an index source, not a replacement for neural and image HDF5. `required_adaptation_assets` enumerates the exact required neural/index/image/checkpoint paths for this adaptation branch. Content hashes and the complete native reconstruction dependency manifest remain unresolved. Released-weight adaptation is never described as a rerun of pretraining or scaling.

## Interfaces

The package needs Python 3.11+ and NumPy already available in the environment. No installation or downloading occurs. Run from the repository root:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s benchmarks/paper/PAPER-paper-method-032/implementations/initial-evaluator-v1/tests -v
python3 benchmarks/paper/PAPER-paper-method-032/implementations/initial-evaluator-v1/evaluator.py required-assets 1
python3 benchmarks/paper/PAPER-paper-method-032/implementations/initial-evaluator-v1/evaluator.py audit-exposure ledger.json
python3 benchmarks/paper/PAPER-paper-method-032/implementations/initial-evaluator-v1/evaluator.py score --reference reference.json --reference-sha256 TRUSTED_RAW_FILE_SHA256 --candidate candidate.json --image-features images.npy --brain-features brain.npy
```

`score` requires separate operator-owned reference JSON and two numeric NPY arrays. It verifies the reference's **raw file** SHA-256 supplied independently by the operator, plus each NPY's exact bytes. Pickle is disabled. Candidate JSON cannot supply or replace reference image features. No authentic reference is distributed here.

Reference fields are `task_id`, `contract_sha256`, `code_revision`, `dataset_revision`, integer `subject`, 1,000 unique string `image_ids`, 30 arrays of 300 string IDs in `retrieval_pools`, `feature_space`, `image_features_sha256`, `population_manifest_sha256`, and `feature_extraction_receipt_sha256`. The fixed feature-space value is `openclip:ViT-bigG-14:laion2b_s39b_b160k:256x1664-tokens`. NPY first dimensions follow declared IDs; remaining dimensions flatten to 256×1664 coordinates. Flattened arrays are permitted. Candidate fields are `reference_manifest_digest`, `image_ids`, integer `subject`, matching `feature_space`, `brain_features_sha256`, `checkpoint_sha256`, and `exposure_ledger_sha256`. The reference-manifest digest uses the module's canonical JSON `digest` function and differs from raw-file SHA-256. Candidate rows may arrive in a different order and are reconciled by exact identities; missing, duplicate or extra rows fail.

`score_aligned_features` is the lower-level numerical engine used by the admitted scorer. It accepts smaller feature widths for independently derived engineering controls and has no admission output. `retrieval_draw`, `reconstruction_identification`, `paired_pearson`, and `aggregate_repeat_embeddings` are Python interfaces. `paired_comparison` requires identical reference/population/pool commitments and returns paired draw deltas; this alone cannot establish equal exposure or scientific improvement.

Exposure JSON fields are integer `target_subject`, `calibration_session_zero_based: 0`, positive integer `protected_sessions_zero_based`, distinct string `calibration_image_ids` and `protected_image_ids`, `training_regime`, `checkpoint_pretraining_subjects`, `checkpoint_pretraining_image_ids` (explicit `null` if unknown), `checkpoint_sha256`, `image_model_resources_sha256`, `calibration_trial_manifest_sha256`, and `protected_trial_manifest_sha256`. Trial-manifest hashes bind repeated-presentation identities; image sets alone cannot establish equal neural inputs. Regime is `released_shared_adaptation` (exactly the seven other subjects in ascending order) or `single_subject_from_scratch` (empty pretraining subject list). Checkpoint hash identifies the evaluated checkpoint in either regime. The audit rejects declared calibration/test image overlap, reports shared-pretraining/test overlap separately, and keeps unknown exposure unknown. Session separation is a prospective protected-evaluation restriction needing authentic feasibility verification. `compare_exposure` compares declared target images/sessions/trial manifests and image-model resources while leaving total neural exposure and causal attribution unverified. These ledgers are declarations, not attestations about checkpoint contents.

## Validation and remaining work

Generated controls exercise asymmetric image/brain retrieval, the full 30×300 numerical path, strict Pearson ties and column orientation, constant/NaN/zero failures, post-model repeat weighting, frozen pool identity, native feature width, cohort membership, reference hash binding, source revision rejection, exposure leakage, and paired-comparison pool equality. They use no authentic data and establish neither baseline competence nor scientific qualification. Production-width feature arrays and authentic NPY scoring were not run; bounded controls use the same numerical core with small feature widths.

Admission booleans remain false. The next scientifically necessary work is to acquire an authorized complete trial/image manifest and protected feature reference, establish native preprocessing/repeat parity, qualify rights and pretrained exposure, freeze all reconstruction endpoints, and execute/review same-budget baselines. This package does not authorize those campaigns.

They are a specific future acquisition set for a complete first-session/test membership and repeated-presentation join. Their sizes do not establish sample counts or whether particular test presentations occurred in session one. No data or weight body was opened for this metadata check. The four neural derivatives total 6,686,768,192 bytes and the four released one-session checkpoints total 35,519,587,656 bytes; those identities do not prove the historical normalization producer, source paper checkpoint usage or training exposure. The nine-file inquiry alone cannot reproduce the endpoint. The full original reconstruction/retrieval panel and separate subject-1 transfer comparison, including their image resources and normalization references, remain unchanged and unqualified.

A future authorized membership check should authenticate every acquired file against the pinned publisher digest, enumerate all shard members and native sample identities, join the behavioral subject/session/global-trial/image/shared-image columns, and report complete first-session and test intersections and presentation order for each original subject.
