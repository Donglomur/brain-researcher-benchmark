# PFC Full99 conditional reconstruction: Science 2.0 source adapter

This draft reuses the accepted complete PFC finite endpoint. It is an additional open-internet, eight-hour access profile, not another benchmark ID. The original offline paper/data versus official-code protocol is unchanged. Both public code and the public oracle are discoverable online, so this profile cannot measure the original code-access treatment effect or claim an unseen test.

No native Harbor trial, Docker build, scientific-array read or model trial was performed while constructing this adapter. The two source Dockerfile templates are rendered only by the task-specific materializer after exact input admission. A rendered package does not establish image content, availability, platform, native operation or scientific compatibility. Real author metadata and an expert time estimate are absent, not fabricated. The package remains a local draft until those requirements and full target checks are satisfied. These omissions mean the current source directory is not submission-ready and does not pass the complete upstream format/build gate.

## Difficulty

The intended work is exact conditional reconstruction across all 99 recordings, twelve families, eight categories and all 69 full/animal-deletion cases. The fitting roster has 19,186 units from 68 animals; the scored PFC population is separately 10,243 units from 65 animals. Difficulty for current models has not been measured. A domain expert must review this AI-authored instruction draft, state a defensible expert-time estimate and assess whether this finite workflow is sufficiently challenging for the main Science set. Do not increase compute, conceal conventions or select thresholds merely to induce model failure.

## Reference solution

solution/solution.py is a byte-identical copy of the independently authored accepted analytic participant program. It reads only the supplied packet and computes hypergeometric conditional moments from full and per-animal sufficient statistics. It neither reads saved answers nor imports the verifier. solution/solve.sh adapts its existing ordinary-output CLI to the declared Harbor artifact path. No map refitting is required.

## Verification

The clean verifier evaluates only submission.jsonl. Harbor also transfers its conventional artifacts directory; the fixed evaluator does not consume it. It imports only evaluator-authored sources, authenticates the released packet, and validates the complete case roster, labels, matrix dimensions, exact integer counts and reduced rational moments before any target-dependent computation. The unchanged endpoint scorer independently computes every reference case and retains all continuous enrichment, geometry, hierarchy and animal-influence diagnostics.

Binary reward is one only when every required count, mean and variance field has zero exact discrepancy in all 69 cases and twelve families. The exact mismatch count and rational maximum, rather than a rounded mean or near-one threshold, determine success. Undefined geometry remains explicit in scientific-metrics.json and is not converted to fabricated zero. The task does not ask participants to estimate geometry independently: complete exact moment agreement implies the inputs to those deterministic diagnostics agree.

Malformed or missing output is reward zero. Runtime, trusted-packet or scorer failures are infrastructure errors and produce no reward. pytest emits CTRF to /logs/verifier/ctrf.json; reward.txt is the only Harbor reward channel. Submitted code is never executed by the verifier.

Reference values are computed by the separately authored conditional kernel, while the participant oracle uses a different sufficient-statistic implementation. Both implement the stated exact conditional estimand. Prior accepted local full-cohort parity and negative evidence are background; this new Harbor transport/runtime still requires its own oracle/no-op and corruption validation.
