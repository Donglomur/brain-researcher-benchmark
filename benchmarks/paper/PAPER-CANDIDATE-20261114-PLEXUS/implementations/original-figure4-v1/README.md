# Original Figure 4 folds and AUROC

This component reconstructs the original author-code observation splits and scores a complete guide/donor/two-fold AUROC vector. It supplements the historical prospective whole-plate evaluator, which has a different endpoint. It does not perform preprocessing, representation training, logistic-regression fitting, or establish an authentic paper comparison.

The source is [Figure4/figure_4.py at revision 69ccecbcc00f8462c8ce2a9d699be09f4c53ed66](https://github.com/pgrosjean/plexus/blob/69ccecbcc00f8462c8ce2a9d699be09f4c53ed66/figure_scripts/Figure4/figure_4.py), SHA-256 `2c685db69e2604f1214e02eb2dec19c161e5732acd34aa51c32ec30039601af7` (18,428 bytes). The original body was recovered from an existing public GitHub API receipt; no new source download was needed. See `sources.json` for provenance and unresolved limits. Source observations and predictions are not distributed.

The critical source detail is asymmetric class balancing. The function draws half the non-targeting locations, then visits sorted guides with NumPy's legacy random stream seeded at zero. It draws half the guide locations and down-samples the larger **first-fold training** class to the smaller class. The first model trains on that balanced subset and scores all first-fold held observations. The reciprocal model trains on the unbalanced held observations and scores the balanced subset. Discarded observations do not reappear in the reciprocal evaluation. These balancing draws consume the same random stream as later guide-location draws; reconstructing only half-well assignments produces a different protocol. The function resets the seed for each of its four family/donor calls.

The function treats non-targeting guides as additional positive classes, excluding their own rows from the negative controls when the guide identifier contains the literal substring `non-targeting`. This behavior and the greater-than-eight first-training-observations-per-class cutoff are retained. Source naming that would duplicate an observation across positive and negative arrays is rejected for reconciliation rather than silently repaired. One-class reciprocal training sets are recorded as skipped because the source classifier cannot fit them. Actual fit failures, convergence, and representation-dependent exclusions cannot be established from metadata.

`prepare` consumes JSON with schema `plexus-figure4-observations/v1`, `source_figure4_sha256`, `data_record: "10.5281/zenodo.15809433"`, `preprocessing_receipt_sha256`, and exactly four `panels`: each combination of `family` (`manual_features` or `plexus`) and `donor` (`WTC11` or `Patient Line`), all with `tau_status: "WT"`. Each panel contains `observations_source_sha256` and an ordered `observations` list. Each observation has `observation_id`, `gene_id`, `guide_id`, and `well_id`, all nonempty strings. Manual observations additionally have `zarr_file`; Plexus observations have `aggregate_by`. These must be source-converted strings, with the original post-preprocessing row order retained.

Manual `loc_id` is the source expression `well_id + '_' + zarr_file`. Plexus `loc_id` is the first two underscore-separated `aggregate_by` tokens joined with `_`, followed by `_` and `well_id`. Plexus observations must already have been aggregated by `aggregate_by`; duplicate aggregation keys are rejected. The package does not invent a cell-to-well reduction. The scoring unit is each row of the original classifier input: manual-feature observations or aggregated Plexus observations. Wells determine folds; they do not receive equal scoring weight.

The preparation output lists ordered training/test observation identities and labels for every guide/fold, identities discarded by balancing, source-reasoned skips, and source/census/preprocessing pins. Hash pins preserve supplied identity, not authenticity or completeness. Preparing a generated or partial census does not recover the original full cohort.

`score` takes the same census, its independently frozen canonical SHA-256, and a submission with schema `plexus-figure4-predictions/v1`, `plan_sha256`, and `scores`. Each score contains `method`, `donor`, `guide_id`, integer `fold` (1 or 2), `observation_id`, and finite guide-positive `probability` in [0,1]. Required methods are `author_manual_features`, `author_plexus`, and `candidate`. The candidate uses the Plexus observation population and must retain its analysis units; its architecture is unrestricted by this scorer. A different observation population requires separate reconciliation, not silent replacement. Every required prediction identity must occur exactly once, including the original control-guide tasks. Training, duplicate, unknown, or missing identities fail.

AUROC uses tie-aware ranks, mathematically equivalent to `sklearn.metrics.roc_curve` followed by `auc`. The output retains the full method/donor/guide/fold vector and descriptive candidate-minus-author-Plexus differences. No complete-screen scalar, interval, improvement threshold, or paper-win decision is invented. Reciprocal folds and common negative controls are dependent. The 0.8 display line is not a baseline.

Python 3.10+ and NumPy are required; the generated controls were designed for the existing NumPy 2.4.6 environment. NumPy's version is included in the plan identity. Author-code parity additionally uses existing pandas and scikit-learn for a minimal observation shim and the author's ROC arithmetic, with the classifier and scaler replaced by non-fitting recording/identity objects.

```sh
python3 figure4.py prepare --census /absolute/census.json --output /absolute/plan.json
python3 figure4.py score --census /absolute/census.json --census-sha256 FROZEN_CANONICAL_PIN \
  --submission /absolute/predictions.json --output /absolute/report.json
python3 -B tests/test_figure4.py
python3 -B tests/author_parity.py /absolute/pinned-author-figure_4.py
```

The canonical hash is SHA-256 of UTF-8 JSON with sorted keys, compact separators, ASCII escaping, and no nonfinite values. `digest()` implements it. Duplicate JSON keys are rejected by the CLI. Evaluation reconstitutes the plan from the pinned census, so a submitted plan cannot alter eligibility or labels.
