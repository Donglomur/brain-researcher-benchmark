# POYO code lineage and the unresolved 2023 result binding

The official POYO repository is linked to **A Unified, Scalable Framework for Neural Population Decoding (NeurIPS 2023)**. Its currently visible code history does not establish the original experiment version. This note records a contemporary code-to-processing dependency join and preserves the missing historical result binding. It adds no readiness claim.

At commit `6b052f148128ec5d8e3fe7077692b3ffbac92039`, the repository has an eight-commit chain ending at a parentless commit dated 12 May 2026. The API returned one branch (`main`), no tags, and no default-branch commits through 31 December 2023. These are observations of current history, not proof that older private, deleted, or separately archived code never existed. Git timestamps alone do not establish first public availability. [Observed history](https://api.github.com/repos/nerdslab/poyo/commits?per_page=100)

The first substantive commit describes copying code from `examples/poyo`. A separate upstream commit documents moving the official code to `nerdslab/poyo` and simplifying the remaining example. The inspected upstream path history also includes a parentless commit that explicitly describes history modification during a repository merger. It is therefore unsafe to choose a current commit by date and call it the 2023 release. The inspected records do not prove exact byte identity of the imported files. Its source declares target scaling and `torchmetrics.R2Score()`, but the inspected files do not freeze all original recording/trial IDs, adaptation budgets, historical metric arithmetic, or the source-result program. The configuration was not executed. A later upstream message records removing Flint; its cause was not inspected and this does not authorize dropping Flint from the paper task.
