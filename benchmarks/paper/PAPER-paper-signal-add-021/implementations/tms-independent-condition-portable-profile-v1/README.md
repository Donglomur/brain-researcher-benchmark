# TMS independent-condition reconstruction profile

This package implements the existing `tms_exact_real_248_method_specified_reconstruction_v1` endpoint: four maps with 62 channels each, using all 1,458,240 selected original neural-response operands. It provides source and an explicit interface for owner-authorized assets. Authentic data, the protected reference, local configuration and the runtime image are not distributed here.

Both material arms receive the same paper, complete input and explicit method. B additionally receives two selected released MATLAB implementation files. The task measures reconstruction of that declared method; it is not unaided paper understanding or full-repository assistance.

The 33 implementation files in `package/` and their `PORTABLE_SOURCE_LOCK.json` are unchanged from the independently reviewed portable profile. The numerical kernel, all-case scoring, candidate instructions and single-attempt lifecycle retain their accepted identities. The frozen contract contains its original source-stage flags; [VALIDATION.md](VALIDATION.md) records the subsequently completed, narrower local validation without rewriting those flags.

## Start with invented controls

From this profile directory:

```sh
python3 -I -S -B package/controls.py
```

This runs 44 stdlib controls with invented files and mocked owner boundaries. It launches no Docker container, reads no authentic dataset or reference, and makes no model call. The proposed CI job first authenticates the complete source lock, then runs this exact control entrypoint once and preserves both streams and exit statuses. CI uses Python 3.11.18 for these invented controls; it does not widen the authentic owner's Python 3.11.6 runtime policy.

## Authentic owner entrypoints

- `package/outer_once.py` is the complete authentic owner launcher. Its internal child is `package/run_once.py`.
- `package/provision.py` imports the two complete files of an already accepted original-input projection, byte for byte.
- `package/source_projection.py:project_original` is the original-source projection API. Its separately admitted native reader/runtime is not included here.
- `OPERATOR_CONFIG_TEMPLATE.json` and `RUN_MANIFEST_TEMPLATE.json` are intentionally non-executable examples. Populate and authenticate them privately using authorized assets.

See [PROVISIONING.md](PROVISIONING.md) for every required role, the original-source route, runtime constraints and literal command forms. Missing owner assets cause refusal; this package does not synthesize a reference or silently substitute a dataset.

## What has been checked

All 44 invented portability controls passed a prior independently reviewed local invocation. Two separately selected same-host authentic compatibility attempts also passed whole independent review: each covered every one of the 248 outputs and 97,216 support records, with six complete historical artifacts matching under the two program assignments. The unchanged comparator and a deliberate final-plus-two negative control each traversed both material-arm interfaces. This is fixed-program compatibility evidence, not an estimate of an LLM's performance or the benefit of code assistance.

The source/workspace roots moved; the original authorized input and reference roots were reused. Cross-host, copied-data, operating-system, runtime-version and architecture equivalence were not demonstrated. No additional benchmark or fully provisioned submission is established. Redistribution permissions and image-content qualification remain separate from this source package.
