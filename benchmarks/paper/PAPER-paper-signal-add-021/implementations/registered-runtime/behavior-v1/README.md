# TMS behavior reconstruction

This is the portable source package for the behavior profile of `PAPER-paper-signal-add-021`: reconstruct **315 participant-condition-outcome cells, 18 contrasts and 270 leave-one-participant-out summaries** from one released CSV. It adds no benchmark ID. The existing fixed-region EEG profile is unchanged.

Arm A receives the paper, complete CSV and the same task/method/schema as arm B. Only B also receives the two exact official source files. The inherited owner freezes both programs, runs isolated sequential arms with matched budgets, commits both closed outputs, and only then reads the protected reference for scoring. Ordinary candidate failure and uncertain infrastructure closure remain different outcomes.

The package includes the complete 16-role owner source, a source-only plan/build/select interface, strict scorer, evaluator reference-generation source and an explicitly fixed construction program. It contains no article, research CSV, official source body, protected reference, candidate result, private receipt or owner-specific host configuration. The reference and construction implementation are evaluator material; the owner does not mount them as task material or give the construction program to a model.

Start with [ACQUISITION.md](ACQUISITION.md) for exact public upstream locators and the conversion recipe, then [portable/README.md](portable/README.md) for provisioning. [RUNTIME.md](RUNTIME.md) identifies the remaining exact-runtime and private-evidence requirements. These requirements are enforced; an available PFC/DMFC image cannot silently replace the selected TMS image.

The accepted local construction used the same fixed audited program in both arms and both scored 1.0. That verifies the complete construction path. It does not measure LLM ability, official-code benefit, scientific improvement or SOTA performance. A smaller p-value or larger effect earns no improvement reward. See [VALIDATION.md](VALIDATION.md) for the evidence and limits.

`TASK.md`, `METHOD.json`, `SUBMISSION_SCHEMA.json` and `scorer.py` preserve the accepted task bytes. Participant means, signed helper formulas and the specified corrected inference remain separate. This is a finite prescribed behavioral analysis, not whole-paper reproduction or the original authors' unknown randomized results. Public data and evaluator source remain a contamination risk.
