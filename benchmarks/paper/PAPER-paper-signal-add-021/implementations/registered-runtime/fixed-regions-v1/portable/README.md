## Concrete commands

1. Copy REQUEST.template.json to an owner-private location. Replace every /OWNER placeholder; use ordinary canonical single-link files. Fill both frozen program pins and all exact inherited-evidence locators. Supply the actual Unix socket identity and canonical CPython executable location only in the private request. 2. Establish the owner-authorized local-use reference and set authorized_local_use=true only under that existing authority. The scientific asset/code commitments are fixed; arbitrary substitute catalogs and subsets are refused.
3. From any directory run:

    python3 -I -S -B /ABSOLUTE/fixed-regions-v1/portable/provision.py plan --request /ABSOLUTE/private-request.json

The default --source-root is the containing fixed-regions-v1 directory. It can be supplied explicitly for an exact copied source tree. CATALOG.json maps each of the16 logical owner dependencies to a literal path inside that tree. TASK.md, METHOD.json, SUBMISSION_SCHEMA.json and scorer.py are reused in place. The other12 dependencies and their template lock are included in owner-template/. There are no private checkout or network source dependencies.

4. The plan emits the exact rendered lock plus source-review, runtime-admission and owner-grant templates, all unaccepted. Have the complete rendered source and actual runtime independently reviewed. Write the approved source/runtime records at their declared private locations and update their exact hashes/lengths in the request. Their descriptors stay outside the16-member runtime lock, avoiding a hash cycle. Run plan again on the final request and retain its final unselected grant template.
5. Run the same command with build in place of plan. It creates fresh private package/operation trees and an unselected manifest. It reads only source and metadata, not the data, article, code, programs or reference bodies. The rendered package authenticates the entire logical graph; no symlink escape, extra source member or shortened data/code subset is permitted.
6. After the owner explicitly selects that one operation, set only owner_selected_execution=true in the final exact grant and record it:

    python3 -I -S -B /ABSOLUTE/fixed-regions-v1/portable/provision.py select --package /ABSOLUTE/private-package --grant /ABSOLUTE/private-owner-grant.json

The command rechecks every source member, exact typed grant and both reviewed records. It writes the immutable grant and selected manifest and returns a JSON argv array. It does not execute that array. Existing selections/attempts are never silently replaced or retried.
7. The separately selected operator launches that exact argv once under an admitted resource window. The inherited owner first retains eight bounded capacity probes, then the full invented numerical-convention compatibility episode. Only afterward can it stage authentic assets and run A then B. Independently review the complete original lifecycle, both frozen outputs, protected scoring, costs and all exact group/container absence.

The records are trusted operator attestations, not credentials or automatic authorization. Source review must cover the rendered bindings, not merely flip a template flag. The owner reads/hashes every actual asset at intake and compares it with the catalog. Provisioning source tests cannot establish an actual asset match or image qualification.
