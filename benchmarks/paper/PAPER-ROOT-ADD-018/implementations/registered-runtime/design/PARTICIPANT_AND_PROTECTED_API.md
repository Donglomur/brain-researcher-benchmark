# Proposed complete participant and protected API — S2

This document specifies interfaces; it implements and installs none. The design is language-neutral. The host must execute the participant's actual source, including arbitrary alternative model architecture, fitting and analysis, rather than accept only an instruction JSON selecting a fixed reference pipeline. Example function names below denote future contracts, not existing functions.

## Canonical contract and roles

The canonical task remains `PAPER-ROOT-ADD-018`. An immutable operator manifest fixes contract version, paper/source pins, role-cohort tables, dependency environment, exposure arm A/B, lane R/I, allowed inputs, split policy, seeds, product obligations, budgets, and protected reference/scorer identities. It contains no hidden answer values. Every dataset member has a public role identifier and operator-verified content identity; private target hashes remain in the private ledger if they could facilitate answer lookup.

One subject can occupy multiple scientific roles; primary keys are `(dataset_version, rat_id, session_id, unit_id_if_applicable, role_id, condition, trial_id, event, bin)` with explicit nullable fields. Never join by a filename substring or assume row order. Source/input identifiers are content-addressed and carry the allowed availability time. A public schema can describe columns without exposing private values. The 287-member archive roster is an acquisition inventory, not a cohort or obligation count.

The participant submits a source tree, dependency lock/build declaration, entrypoint map, self-described method, fixed seed policy, output schema and complete intended obligation list. Shell commands and dependencies execute only in the declared future sandbox; source must not request network access, host secrets or protected reference files. A cannot access B's code, either through shared caches or history. Resource accounting covers build, investigation, fit, prediction, artifacts, failures and retries. No resource budget has been empirically qualified in this source-only phase.

## Operator-to-participant execution

1. `admit_submission(source_bundle, declaration)` authenticates source, records the exact condition and policy, checks that every required obligation is declared, and starts a fresh isolated execution context. Merely supplying known output files is inadmissible as submitted-method evidence.
2. `build(public_schema, pinned_dependencies, resource_contract)` executes the submitted build and captures executable/package hashes, stdout/stderr limits, environment and exit status. B may compile or adapt the pinned author code; A may reimplement it. Both may construct genuinely new methods. The operator neither substitutes a reference executable nor silently repairs the candidate.
3. `fit(train_view, validation_interface, obligations, seed_manifest, work_dir)` executes the participant's actual learner/analysis program. The training view contains only role-authorized data. R includes the full admissible historical reproduction inputs; I excludes all protected future target data and future-dependent cohort decisions. Validation yields only the predeclared finite feedback and counts attempts. The result is a sealed model bundle, preprocessing state, learned parameter/state schema, fit provenance, declared analysis products and complete failure/disposition table. A source-to-build-to-fit-to-model receipt is mandatory; artifact hashes alone do not establish that training occurred.
4. `predict(frozen_model, public_query, stream_state)` runs arbitrary participant prediction code in an isolated target-specific stream. The operator supplies query IDs and permitted observations from the complete target-independent universe in `QUERY_UNIVERSE_AND_CUTOFFS.md`; target values and private scoring masks never enter this process. Behavior requests include every administrative pre-wait trial, while neural/decoder requests use their distinct protected information views. Receipt cutoffs come from the host, not the candidate. The response includes prediction, optional predictive distribution, declared latent outputs, latest-observation watermark and method state. Current observations of allowed peer neurons are permitted; current or past test observations of the target neuron are not. Test state cannot persist across target-neuron contexts. No shared writable cache, global worker memory, query-order side channel or target-feedback channel is allowed.
5. `analyze(reproduction_view, sealed_native_fit, obligation_spec)` executes the submitted analysis to produce complete native numerical tables, model simulations, masks, transformations, diagnostics and report claims. R can reconstruct historical full-data analyses; its outputs cannot enter an ongoing I context. A single method may contain a native reproduction implementation and a separate improved predictor, each distinctly identified.
6. `collect(products, execution_receipts)` is a trusted outside collector. It takes bounded regular files, rejects links/path escapes/duplicate IDs/unknown output schemas, verifies exact obligation and query membership, validates dimensions/types/finite values, records valid undefined cases with reasons, and seals all products and actual-source receipts. It never relies on candidate-provided inclusion counts, scores, test targets or timestamps as authority. Every required omitted/failed item has an explicit disposition; it cannot disappear from the denominator.
7. `grade_sealed_submission(sealed_submission_id, operator_target_ref, qualified_reference_ref, policy_id)` runs separately with private targets. It re-verifies source/build/model/input/query/collector bindings and exact policy versions. It recomputes aggregation, eligibility, loss, native statistic comparisons, controls and uncertainty independently from sealed numerical outputs. Candidate processes cannot invoke it with arbitrary targets or reference directories. It writes final score products and their complete input/reference identities. Separate grading is intentional; `private_grade_called:false` in the candidate producer is not evidence of a missing score join.
8. `assemble_report(condition_id, score_products, obligation_statuses, costs)` is trusted and checks a one-to-one complete join of every obligation, role, expected case, source/model ID and score receipt. It rejects a report composed from different submissions, mismatched target versions, incomplete cohort products or favorable subsets. It exposes appropriate public results only after all relevant arms are sealed.

## Required product schemas

`cohort_roles`: one row for every inventoried source entity and every relevant eligibility role, with included/excluded/unknown status, rule version, rule evidence, reason and parent rat/session/unit. Operator verifies this against source-compatible inputs. Missing scientific provenance remains a gate, not an exclusion that improves score. All required public and protected rosters are frozen before candidate execution; failure never changes membership or weights.

`behavior_trials`: original session/trial order; offered ordinal and physical volume; available-event times; trial violation/catch/reward/opt-out/timeout roles; exposure masks; selected native and prospective masks separately; detrending and normalization parameters with fit-only provenance for I. Public I rows omit future/private fields and future-dependent row selection; absence/order/count can reveal targets as surely as fields. The public query universe and private outcome/mask roster are separately sealed. R output includes every selected/excluded original key, not just condition means.

`behavior_curves_and_fits`: all rat/block/reward cells, six transition series, four original quartiles, pre/post incongruent summaries, raw and 20-µL-only counterparts, counts/means/uncertainty, all requested 50-start sigmoid seeds/objectives/convergence/parameters and best-fit rule. Returns native three behavioral model alternatives and the divisive/inference model products on the correct original input sequences. No missing-data bin can silently convert to a zero.

`muscimol_products`: paired per-rat condition effects and ratios; early/late bins; slopes/offsets; history coefficients and fitted decay; raw/normalized ITIs; session order/washout; histology eligibility; separate acute-unit distance, infusion timing, FR threshold and suppression products. Native acute products retain original distances, source sort permutation, both zero-rate logical masks, exact linear-index distance writes, unchanged rate columns, post-write distances, source edge construction and every bin/fit exclusion. Corrected column-rate handling has a distinct method key. One acute rat cannot supply an animal-level sample size equal to its unit count.

`cell_response_products`: source-unit identity, role-specific event preference, selection window, per-trial aligned observations or auditable sufficient summaries, pre/post keys, native means and native resampling outputs, four event comparisons and brain-area controls. Selection and uncertainty use distinct declared units. Historical pooled-cell p-values remain native outputs, with rat/session-aware sensitivity analyses separately labeled. Active signed nonpref-minus-pref order, physical block transitions, all1,000 replacement/complement draws, strict tail, raw masks and complete three-bin-run masks follow `NATIVE_SEMANTICS.md`; undefined source arithmetic cannot establish significance.

`tca_products`: source tensor geometry and preprocessing, 1–20 rank/10-restart objective table for both expert/naive roles, all fitted factor matrices with scaling/permutation map, final rank-8 model, cluster 0 threshold and all cluster assignments, original neuron/session map, every event/block reconstruction and cluster response. Native tensors carry per-session/event/block whole-average NaN masks, whole-condition assignment results and default-zero-slice masks. They preserve the source whole-slice zero-fill and distinguish it from measured zeros; missing-aware corrected tensors cannot replace native inputs. Compare reconstruction and an explicitly fixed scale/permutation alignment, not raw factor-entry identity across equivalent CP solutions. Preserve the native factor-order map for cluster-specific claims; alignment must not select a favorable subset. Negative normalized inputs versus nonnegative factors and the missing `sortNeuronFact` routine require an authenticated native resolution; neither rectification nor invented cluster ordering may be hidden in the adapter.

`latent_models`: per-session native hLDS A/B/C/D/Q/R and initial-state details where appropriate, exact dimensions, optimization seeds/iterations/objectives/convergence, fit split keys and C-SVD transformation, ordinary-LDS comparator and all learned normalizers. Names Q/R are conceptual noise covariance roles; exact native parameterization is a missing-producer gate. Improved arbitrary architectures return their own executable model and a declared sufficient parameter/state schema; they are not forced to pretend to be linear hLDS.

`latent_queries`: every held-time/held-neuron prediction and observed-watermark receipt; target neuron training-loading provenance; filtering versus smoothing mode; latent trajectories tagged by valid time; original and prospective folds; reward and block decoder predictions/probabilities; MI estimator settings and null estimates; slow-latent history regression design/coefficient/uncertainty. Learned latent labels/signs cannot be estimated using test block labels.

`ati_simulations`: 200 separately keyed original simulation cases, mechanism label and truth held private during I, exact geometry/seed/generator reference, per-case fitted models and ATI trajectories, denominator-zero dispositions and coordinate-map provenance. The trusted grader joins truths and computes recovery metrics; participant labels cannot establish mechanism. Any zero-denominator required bin makes its full-support ATI undefined; no subset average is the official result. All200 cases and both100-case mechanism strata remain in the fixed recovery denominator. The expert/naive real-session ATI table is separately keyed; native bottom/top-40% selectors preserve middle-20% exclusion and ties as explicit rows.

`panel_evidence`: all 50 main panel obligations and all cited supplementary branches, pointing to numerical products, masks, figures, control analyses, native statistics, Methods-conformance dispositions and limitations. Diagrams/anatomy are marked non-statistical and require corresponding provenance. This table cannot manufacture missing source or missing external supplemental panels.

`execution_and_costs`: exact submitted source/build/model/input hashes, seeds, process status, actual invoked entrypoints, resource usage, query receipts, complete errors, attempts and collector seal. A candidate's statement that it fitted a model is not an execution receipt.

## Protected score reports

The final report contains separate `native_source_reproduction`, `methods_conformance`, `prospective_neural_prediction`, `prospective_behavior`, `prospective_reward_decoder`, `simulation_recovery`, `association_and_controls`, `coverage_and_failures`, and `costs`. Native reproduction is a vector of complete obligations and estimator comparisons; a p-value copied from the paper is not a pass. No full-paper label may appear while a mandatory obligation is unresolved or unqualified. Report an explicit missingness denominator for every family. `FAMILY_SCORE_CONTRACTS.json` and `SCORE_AND_DISPOSITION_POLICY.md` define finite types, admissible statuses, exact support/weights, valid restricted-wait censoring, five-class requirements, ATI undefinedness and complete comparator gain admission. A missing/invalid required output has null whole-family score/gains; a missing reference has null paired gain, never a substituted easier comparator.

For improvement, absolute losses and paired same-input baseline differences are primary. Rat-clustered uncertainty avoids treating correlated bins/neurons as independent animals. All model selection and success thresholds are fixed before test execution. Secondary family claims use a prespecified multiplicity policy; alpha allocation and practical-effect thresholds must be frozen during reference qualification before authentic candidate tests, not selected from favorable outcomes. A/B exposure effects use matched cases and resource budgets, independent contexts and method-selection replicates; do not conflate a code-access benefit with a novel scientific method.

## Required future counterexamples

These are planned validations, not executed fixtures or tests. Each must be independently implemented after selection and its expected outcome frozen before authentic evaluation.

- A genuinely alternative submitted learner must execute, produce new fitted state and pass collection; a fixed-reference-only wrapper or artifact-only replay must fail submitted-method admission.
- Changing source after build, model after fit, target/reference version, cohort ID or artifact order must fail receipt/score binding. Source variants that produce identical legitimate predictions can score identically, but must retain distinct honest provenance.
- Omit a difficult animal, failed optimizer, undefined ATI case, simulation, supplement obligation or a required target query: report incomplete coverage/failure, never a higher score through denominator shrinkage.
- Leak future bins, use a centered smoother, orient latent signs on test block labels, refit normalization on all sessions, or share target-test observations across neuron contexts: reject causal improvement qualification while preserving clearly labeled historical native reproduction.
- Supply precomputed ATI/decoder output without fitted producer lineage; swap query IDs or target-neuron IDs; report the source's 287-file roster as eligible sessions: reject.
- Mismatch units (Hz/counts/square-root counts, seconds/minutes, physical/ordinal reward), use median ATI groups instead of 40% tails, or change ratio-of-norms to norm-of-sum: fail the specific scientific contract.
- Feed constant/mean/no-history/simple LDS controls and shuffled-label controls; verify the grader responds to actual prediction quality, correct units and case support. These are future qualification controls, not current results.
- Change R full-data outcomes or B code in shared state while I/A is active: isolation must prevent any influence. Show genuine per-arm source/source-access provenance.
- Exercise transformation-equivalent hLDS coordinates, zero ATI denominator, missing reward classes, singular covariance, absent block support, tied quantiles and NaN model fits. Expected dispositions must be declared, not patched after results.

The independent grader remains outside participant execution. A complete trusted host/collector/grader/assembler chain, not a producer-local call to private grading, is the required protected score boundary.

## S2 API closure

The host seals a public full query universe and a separate private target/mask/reference roster before candidate execution. `collect` requires exactly all public keys, including privately unscored behavior keys, and writes independent candidate-failure records. `grade_sealed_submission` recomputes target/reference scientific dispositions and preserves the original fixed weights. `assemble_report` joins all74 native obligations,20 roles, all200 simulations, every prospective family and every comparator, retaining null-valued failures. All schema records in the S2 catalogue bind actual submitted source/build/fit/model receipts, exact cohort/input/query/target/reference versions, policy and resource receipts; artifact-only or fixed-reference-only execution remains inadmissible. All outputs are design contracts, not implemented methods.
