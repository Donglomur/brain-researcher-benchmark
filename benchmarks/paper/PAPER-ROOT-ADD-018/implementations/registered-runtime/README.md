```sh

python -I -S -B operator_api.py --program PROGRAM.json --review REVIEW.json --output FRESH_DIR --other-reserve-bytes RESERVED_BYTES --condition all
```

The second command requires a complete owner-admitted source manifest, review, condition plans, protected targets, independent reference programmes, current runtime/source identities and explicit resource reservations. It is not an example authorization. The default is all four conditions; a named condition retains its existing scope.
