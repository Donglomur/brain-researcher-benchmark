# Figure 1e prepared-rate family assembly

This operator-side component turns the existing per-neuron arithmetic into the complete **named method/variant family** in `reproduction.v2.json`: eight source method labels across GCaMP8f/m/s, without averaging their neuron vectors. It does not establish the original neuron roster, preprocessing, model provenance or paper result. No canonical task, source condition, improvement rule or readiness status changes.

`assemble_family(manifest, targets, predictions)` accepts an evaluator-owned ordered neuron roster, explicit prepared sample identities, and eligibility/masks fixed separately for every method/neuron. Every method/variant remains represented. Missing/extra prediction identities, duplicate neurons, reordered sample identities and missing values on fixed support are errors. A source exclusion requires an explicit operator reason and source identity; its output row remains present with null metrics. An undefined Pearson correlation also remains present with its reason. A prediction cannot choose its own support or delete a difficult neuron. Different source method masks are retained; the assembler does not silently intersect them.

The declared Figure 1e condition is30Hz, noise8 and50ms target smoothing. These are checked metadata, not proof that any supplied vector was correctly prepared. There is no resampling, smoothing, lag search, clipping, model fitting, cohort selection, target generation, aggregate, statistical test or paper-win rule. Targets and predictions must already be aligned at the source-defined sample grid. Each neuron has one prepared target vector, and each method has an explicit output-unit declaration. The raw-fluorescence comparator can have different units from the target spike rate: **only dimensionless Pearson is computed**, so no cross-unit rate error/bias is emitted. The original per-neuron metric component remains unchanged for actual commensurate rate diagnostics.

The assembler checks and loads the exact bytes of `../author-rate-metrics-v1/metrics.py` (SHA256 in SOURCES.json), reusing its prepared vector/support validation. Pearson uses the same unsmoothed `numpy.corrcoef` definition and explicit empty/constant support handling. NumPy/SciPy versions are recorded. Dependency drift fails closed rather than silently changing the arithmetic.

## Input shape

The generated test fixture documents the complete interface; its six invented neuron IDs and toy values are software controls only. `manifest.neurons` supplies ordered IDs, one of the three original variant labels, and complete unique sample IDs. `manifest.eligibility` contains exactly one record for every named method and neuron. Each record carries `evaluate` plus a boolean mask, or `source_excluded` plus a reason and null mask; both require a source-document identity and an output-unit declaration. `targets` is an exact neuron-ID mapping. `predictions` is an exact eight-method mapping whose inner keys equal that method's frozen eligible neurons. Each vector packet contains the fixed ordered sample IDs and values; JSON null is permitted only outside its fixed support.

The source-manifest, alignment and eligibility hashes identify operator declarations. They are **not authentication signatures or evidence of correct source preparation**. The operator must protect/freeze this manifest outside participant control and independently verify its linkage to original data/model execution. This library neither enforces that custody nor admits submitted analyses. Original method-specific exclusions must be recovered, not filled with guesses. There is deliberately no117/105 default roster or inferred twelve-neuron exclusion: source captions and released-file counts do not determine original ordered biological identities.

## Validation and integration

Run `python -I -B test_family.py` with the existing NumPy/SciPy environment and sibling author-rate-metrics component. During construction, invoke through the project's existing two-slot generated-test pool. Thirteen tests cover complete family/order, mapped identity joins, missing/extra/duplicate support, sample permutations, fixed-mask violations, preserved source exclusions/undefineds, distinct method masks, condition substitution, variant omission, dependency drift, input immutability and the raw-fluorescence unit distinction.

The new test command needs explicit enrollment by the sole integrator in the existing source-component CI mechanism; this private package is **not yet CI-enrolled**. No new dependency installation or shared workflow edit is included.

## Still unresolved

This is not a complete original Figure1 reproduction or improvement evaluator. Original neuron/file/animal/session identities, biological dependence, all source eligibility/conditions, authentic calcium/ephys preparation, historical versus corrected timing, excluded-neuron author models and full comparison criteria remain unresolved. Figure1g's low/high-noise gain definition is not invented or implemented. Historical source-tuned OASIS/MLSpike must retain their disclosed heldout-label exposure; this API does not grant such access to protected improvement candidates. A returned complete *declared* family is not evidence that the declaration covers the original paper. The result explicitly records no source authentication, cohort equivalence or scientific qualification.
