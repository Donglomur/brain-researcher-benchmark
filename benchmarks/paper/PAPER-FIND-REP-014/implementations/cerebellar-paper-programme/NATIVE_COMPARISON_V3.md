# Exact metadata for the selected Figure 6 branches

`native_compare_v3.py` is an additive numerical-calibration successor. It guards the metadata exported by `IOChRmine`, `learningCurves_IOChRmine` and `IOChRmine_imaging`, then delegates the complete native numeric-tree comparison to `native_compare_v2.py`. The historical implementation and execution manifests remain unchanged. This file does not select the successor for a run.

The previous comparison applies a floating-point tolerance to every floating metadata value. Original MATLAB metadata stores collection lengths, array dimensions, cell counts and source mouse/day ordinals as doubles. A fractional change such as `2.0` to `2.0000001` can therefore receive perfect numerical agreement. The successor requires finite nonnegative integral values for these discrete fields and exact equality between the supplied reference and candidate. Source completion/good-movement/reward masks must remain exact booleans. The three reviewed metadata schemas are closed: new fields require an explicit semantic review.

The guard preserves the existing continuous treatment of `dtb` and `normTime`, full original root/leaf/shape/status requirements, source group and directory values, and the separate A/B comparison interfaces. The six other historical branches keep their v2 metadata behavior; this component makes no new exactness claim for them. Invalid or changed selected-branch discrete metadata refuses the comparison rather than receiving an approximately matching score.

The source basis is the previously cached, pinned [author release](https://zenodo.org/records/21645651), plus the separately identified benchmark-authored export wrappers and learning-metadata helper. Those seven local text bodies were freshly authenticated against existing `native/BINDINGS.json` pins. Exact hashes and locators are in `NATIVE_COMPARISON_V3_SOURCES.json`. No author data, source archive or external page was downloaded for this change.

Thirteen generated regression methods passed through the existing shared test pool. They demonstrate the predecessor's false-agreement cases; preserve continuous tolerances; require complete day/root/mask support; reject nonfinite/fractional/boolean counts and unreviewed metadata; and exercise both information conditions through the private grade interface. These generated records contain no empirical observations. Run the focused public test from this directory with `python3 -I -S -B test_native_compare_v3.py`. CI enrollment and independent integration review are still required.

This fixes a comparison defect; it does not authenticate the supplied reference, execute an independent submitted analysis, establish original animal/session/trial identities, or qualify the selected Figure 6 reproduction. Collection counts and source-array ordinals are not automatically biological units. Original cohort/input/clock lineage, final-paper/source parity, competent trusted computation and scientifically justified reproduction criteria remain unresolved. The eleven scalar proposal summaries and complete native trajectories remain distinct from a matched-value fraction. Same-result improvement remains ineligible: stronger biological effects or a new predictive split would not establish superiority on the original finding. No readiness or scientific-result claim changes.
