## Operator entrypoint

An already qualified operator calls:

```python
from critical.native_worker import run_reference_programme

result_bytes = run_reference_programme(
    original_issuer, request, transport, design, cost,
    native_plans, bindings, input_root, output_root, device,
)
```

`original_issuer` is the actual existing live issuer object. Its returned lease
must implement `require`, `native_plan`, `terminal`, and `close`, with real
admission of the selected complete source, scientific bindings, namespace and
runtime. Matching JSON, a status flag, a no-op method, or the generated fixture
in the tests grants no authority. The original host/lease remains in the parent;
child phase requests go back to that exact original lease over its owned socket.

`native_plans`, `bindings`, `design`, `input_root`, `output_root` and `device` are
the existing independently selected complete scientific inputs. No default
scientific plan is available here. The unchanged `NativeContext` checks the full
operation set and scientific-binding joins, and the unchanged programme roster
orders the full reference assembly. Both paper/data access conditions and the
prospective improvement task retain their existing separate design and scorers.

`transport` has exactly these operator-selected fields:

| Field | Meaning |
| --- | --- |
| `author_root` | Absolute ordinary root of the exact externally retained official author source. All author Python members in the existing source catalogue are captured and authenticated before dispatch. Bodies are not included here. |
| `cgroup_parent` | Absolute Linux cgroup-v2 parent delegated to this operator, with actual `cgroup.kill` and populated-event support. |

The deployment must separately qualify a single-threaded/fork-safe parent with

that prevents the child from escaping the owned subtree. This module does not
create a secure deployment from a pathname. No actual runtime is authorized by
this construction package.

## Implemented path and failure behavior

1. The earlier `WorkerFamily` receives and owns every worker before acquisition.
   The complete 26 workers are issued without spawning 26 simultaneous children.
   Each operation creates its own child only during serial dispatch.
2. The parent captures the complete pinned author import closure. The child
   compiles those captured bytes, including transitive author imports, instead
   of rereading a file or accepting cached bytecode after hashing another body.
3. The child waits for the parent to attach it to an owned cgroup before the
   fixed `NativeProducer.execute_in_selected_worker` entrypoint can run. The
   existing `critical.native.original_call` and full original scientific
   consumers remain the invocation path; no callable is accepted in production.
4. Every child phase is checked on the original parent's live lease, with ordered
   sequence/selection joins. The parent drains bounded diagnostic pipes while
   receiving frames. No pickle or transported arbitrary Python object is used.
5. Before fork, a retained `RemoteCostPrefix` owner reserves remaining ordinary
   read/write capacity on the original `Costs`. A valid one-use child prefix
   debits that owner; child outstanding reservations remain outstanding in the
   parent. Missing/malformed prefixes retain unknown reservations. Child I/O
   observations are documentary projections, never parent `IOOperation` objects.
   Physical I/O, native CPU/RSS and transport I/O are not ordinary logical bytes.
6. An exact source-owned `RemoteCapturedOperation` is admitted only after the
   child is reaped and the actual owned cgroup reaches `populated 0` and is
   removed. It is distinct from the original child-local capture object. A copy,
   replay, wrong worker, wrong slot or unclosed result is refused.
7. Failure closes each owned resource once, preserves the original parent error,
   and attempts the full tree retirement independently. An unattached blocked
   child can be killed only while it remains the exact unreaped child. There is
   no signal to a recycled PID or process-group identifier. Remote exceptions
   retain a bounded document; they do not claim original cross-process identity.

Transport observations are attached to the existing reference method lineage.
This software completion does not promote a benchmark to scientifically ready,
establish historical reproduction, or establish a better model result.
