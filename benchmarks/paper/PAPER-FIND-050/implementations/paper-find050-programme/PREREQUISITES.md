The source-only commands require Python 3.11 and POSIX ordinary filesystem
semantics. The actual native programme additionally requires all of the
following, selected and enforced by the original live operator:

- A Linux fork-safe, single-threaded parent before numerical-runtime imports;
  a delegated cgroup-v2 subtree supporting cgroup.kill and populated-state
  observation; child namespace/credentials that prevent subtree escape; actual
  child/descendant retirement and original parent lease identity.
- An admitted exact third-party numerical/device runtime and official author
  import closure. The package does not invent a lockfile from unpinned upstream
  requirements. The current captured importer supports the reviewed bare-alias
  roster; future package/dotted imports need new review. No upstream code body
  or numerical dependency is vendored or installed here.
- The complete 26-operation native-plan and binding dictionaries, historical
  invocation/seed/configuration lineage, all full populations and output
  selectors. `critical.native_context.NativeContext` validates those joins;
  matching `science_review_status` text alone grants no scientific authority.
- All 29 authentic main-session inputs, exact identity/geometry/rights,
  additional cohorts, deconvolution assets and full preprocessing. Provider
  metadata in the package is not custody of local bytes. FX43's repeated source
  label and the declared historical/source discrepancies remain explicit.
- The prospective memory simulator, protected targets, independent baseline,
  seeds/folds, budget, improvement acceptance and two matched exposure arms.
  These remain distinct from reproducing historical paper outputs.
- Immutable ordinary source/input namespaces, no symlink substitution, offline
  exposure/output roots, bounded transport/log channels, source-selected
  read/write allowances and independently measured whole native resources.
  Ordinary logical cost prefixes do not measure physical I/O, native RSS or CPU.

Every explicit scientific/runtime hold remains in `source/contracts/GATES.json`.
The `describe` command prints all 32. This package changes none of their states.
The full reproduction endpoint includes 40 dense spectra of 10,000 modes each;
memory capacity limits must never be handled by lowering those dimensions.
The inherited `legacy_empirical_core` profile remains visibly named in the
contracts and cannot stand in for the complete paper programme.

The original `critical.operator_service` and paired runner remain included.
Their completion slots, protected vaults and four actual arms must be supplied
by the qualified deployment; wire JSON cannot create those objects. Full
comparison uses reproduction and prospective improvement for both paper-data
and paper-data-author, with fixed paired scientific support. The reference API
does not replace the participant's paired programme runner or protected scoring.

exercise transport/control-flow failures. They do not establish numerical

expert endorsement, scientific readiness, SOTA or Terminal-Bench submission
