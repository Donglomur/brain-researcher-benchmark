# Original offline MC_Maze outcome interface

This additive interface permits the original 35-bin held-in observation window for co-smoothing and prediction of ten unseen future bins. Primary improvement takes one complete prediction set. It retains the original 20-ms tensor shapes, ordered panel, protected test fields, scorer and four metrics.

The previous `source-matched-nlb-v1` implementation remains unchanged. Its two author recipes, 192 particles, 32 repeats, filtered outputs, encoder-dependency controls and author-calibration receipts retain their original roles. Its arm-labelled candidate receipts are not accepted by this offline interface. Source-prefix and strict-online comparisons require separately named policies and appropriate comparators.

Reproduction and improvement are independent outcomes. Reproduction still requires all eight source-method findings, justified agreement/uncertainty and trusted execution with granular output verification. Author calibration is not an AI reproduction. This adapter produces offline improvement metrics and declared provenance; neither its metadata nor its aggregate score decides either scientific outcome.

## Source and contract binding

`policy.py` requires the exact independently reviewed additive `improvement.temporal-scope.v1.json` and corrected `reproduction.v1.json`. It verifies the retained scorer/delivery helper hashes before import. The mathematical evaluator is the same separately byte-pinned official `nlb_tools` implementation; no metric is redefined. Updating one of these sources requires a reviewed successor and new pins.

`delivery.py` uses the retained authentic-phase admission and allowlisted material-copy functions. It creates a new atomic pair with distinct offline schemas. Both conditions receive identical observations, paper, current task, outcome contracts and source-recipe protocol; only `paper_data_author_code` adds the official source. No checkpoint, test target, prediction or new raw-archive field is added. The source protocol is labelled `author_baseline_protocol.json`, so it is not mistaken for the candidate's training budget.

Call the delivery CLI with `--prepared-root`, `--author-source`, `--paper`, `--task`, the trusted current `--task-sha256`, a new external `--output` directory, and an explicit `--reserve-bytes`. This revision authorizes no actual export or candidate run. The local construction wave requires a 60-GiB reserve and separate resource accounting for any future authentic export. Material preparation does not enforce execution isolation.

## Operator episode policy

Before candidate results, a trusted operator must freeze the actual delivered materials, behavioral guidance, validation feedback, selection/adaptation policy, equal paired budgets, source qualification and scientific comparison criteria. No policy instance or scientific criterion is supplied by this implementation because these remain unresolved.

The `smc_offline_episode_policy_v1` object has exact fields validated in `policy.validate_episode`: task/scope, current canonical task and primary-contract identities; complete reference-panel hash; paired-delivery and both condition-manifest hashes; materials, selection/adaptation, budget, scientific-comparison and trusted-review receipt hashes; both author-calibration receipt hashes; four source references; and the selected reference ID. Delivered task/contract identities must agree with that policy even when a contradictory manifest has the expected hash. References retain both published and both qualified reproduced co-bps values. Published 20-ms anchors are fixed at 0.3225 and 0.3407. Selection must use a strongest retained value; a lower reproduced result cannot replace a higher published result for a paper-win claim. Tied strongest references are allowed. The operator must authenticate source linkage, information conditions and all referenced reviews before approving this policy.

Hashes and declared qualification roles do not authenticate scientific qualification. The CLI's `--episode-policy-sha256` must come from the trusted pre-candidate review, never a candidate-selected file. A plausible JSON document alone cannot establish that the comparator was selected before a candidate, that the data were used, or that a run occurred. Central outcome admission still requires independently verified execution/output and source-grounded criteria. Missing policies are rejected, not filled with defaults.

Original NLB permits supplied behavior to guide learning. Actual use must be declared separately for fitting and selection. A behavior-assisted score is not automatically matched neural-only superiority. No policy gains additional fields, test behavior, future spikes, held-out test spikes, trial authority or transductive adaptation merely because the original task permits full-window inference.

## Prediction freeze and scoring

`scorer.py freeze` accepts one submission and requires `--panel`, `--episode-policy`, its operator pin, `--delivery-manifest`, condition, method identity, an independently authenticated run-receipt hash, seed, explicit `--behavior-guided-fitting yes|no`, `--behavior-guided-selection yes|no`, and a new output path. The command has no target argument. It validates the original arrays and complete panel, then emits `smc_nlb_offline_prediction_freeze_v1` without a causal/noncausal arm label.

`scorer.py score` requires the same frozen inputs plus the freeze receipt, separately stored original exposed target, its immutable target SHA, the byte-pinned official scorer source, and a new output path. It verifies frozen inputs and takes a stable prediction snapshot before reading the target. It emits all four metrics and declared comparator differences as `smc_nlb_offline_operator_score_v1`. Scientific outcome is always `unknown`; positive differences do not establish superiority, reproduction, strict-online operation or current SOTA. Original January 2026 target exposure remains explicit.

The original evaluator and source array validation are reused. New generated controls exercise single-output offline access, protected identities, published/reproduced comparator selection, missing companions, incorrect source-arm/author receipts, behavior declarations and unknown scientific status. They do not rerun an authentic model, recover a published number or qualify an episode.
