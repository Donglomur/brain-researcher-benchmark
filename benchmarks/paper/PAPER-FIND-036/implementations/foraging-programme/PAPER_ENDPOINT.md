# Figure 6B improvement endpoint integration

`program/paper_endpoint.py` adds an executable paper endpoint check to this existing
programme. It consumes the protected `grade.py` result, its exact collection and
preparation receipts. It derives balanced accuracy independently from each
session's pooled confusion counts, requires every original session and HW row,
and compares candidates A/B separately with the operator BNB equation reconstruction and published
**0.7271**. It never uses probability reconstruction error as improvement success.

This build has **no scientific result and is not improvement-ready**. The official
15,089,711-byte archive could not be acquired through either allowed ordinary
route. No source arrays, labels, historical predictions or candidate models were
read; no fitting or candidate execution occurred. The original 40-session roster,
rat joins and author calibration remain unverified.

## Relationship to the existing programme

This is an additive endpoint checker, not another preparation or execution
scaffold. It reuses `prepare.py`'s archive descriptor and source-member grammar,
`support.validate_prepared`'s exact fold partitions, `support.phases`'s complete
1,320-phase identity chain, equal-session aggregation, and the existing descriptive
rat summaries. It requires the original full programme's nested-control support;
it does not replace that requirement with a smaller cohort.

`controller.py` remains responsible for freezing the four programs before numeric
exposure and separating every fold's fitted state. `prepare.fold_rows` preserves
the original source-order fivefold memberships with seed 622, then privately
permutes training and query order. `controller.stage` gives improvement candidates
opaque UUID views without source session names, indices or target-correlated
class blocks; `stage_model_alias` hides private source paths. `engine.py` supplies
isolated processes and restricted mounts. This new checker launches none of them.

The CLI binds the exact result → collection → preparation digest chain and checks
the source/member/token/session joins, full phase roster, 40-bin unit features,
[-1,+1]-second window, clipping and fold seed. Within each method it checks original
class support and derives balanced accuracy from pooled counts before taking the
equal mean across 40 sessions. It also requires the native operator BNB and the
held-out operator BNB control to agree session by session. Unchanged historical source
manifests continue to identify their original snapshots; they do not include or
qualify this new module.

After an independently admitted full programme execution, the operator can run:

```sh
python3 program/paper_endpoint.py \
  --result /operator/RESULT.json --result-sha256 RESULT_SHA256 \
  --collection /operator/COLLECTION.json --collection-sha256 COLLECTION_SHA256 \
  --prepared /operator/PREPARED.json --prepared-sha256 PREPARED_SHA256 \
  --output /operator/FIGURE6B_ENDPOINT.json
```

An independently authenticated complete biological map can additionally be passed
with `--animal-mapping` and `--animal-mapping-sha256`. All paths in this example
refer to operator-only receipts, not bundled assets. The output contains final
scores and must remain under the episode's final-feedback policy. The checker
reads metadata only; source array paths inside receipts are never followed. Each
receipt has an 8 MiB read cap. Complete native receipt size has not been measured;
an oversized receipt is refused, with no truncation or partial-panel fallback.

## Calibration and interpretation

The frozen rounding interval is **0.7271 ± 0.00005**: half of a hundredth of a
percentage point. It is defensible only after source equivalence is established;
it provides no allowance for undocumented package drift, changed rows or revised
folds. The module reports the numerical interval check separately and never
equates it with source admission. No authentic author calibration is available in this build; the reconstructed
operator score is named separately and `author_replay` stays unset. Do not widen
the interval after seeing a result.

The existing `reference_math.py` implements independent BNB equations and
`operator_program.py` calls those equations. Its native and improvement scores
are not an authentic execution of the authors’ scikit-learn branch. An external
reference-competence admission in the old grader does not turn that comparator
into a pinned author replay.

The permitted 200-fit author operation would be a real-HW **endpoint replay**, not an
unchanged execution of the whole author script. Its independent unseeded shuffled
and permutation-importance branches are distinct outputs. The source recipe is
`BernoulliNB(alpha=1, binarize=0, fit_prior=False)` with five stratified folds,
shuffle enabled, seed 622, original label-3/4 rows and all original features.
The source's whole-session normalization and symmetric smoothing are transductive.
Training-only candidate scaling cannot make the released representation causal.

Candidate differences against the operator reconstruction and paper scalar are
descriptive until an actual author replay is admitted and the
task-justified minimum effect and valid paired rat-aware uncertainty are fixed
before final testing. The module therefore always leaves `paper_win` and the
population interval unset and `improvement_ready=false`. Existing rat means and
leave-one-rat-out summaries are labeled descriptive, with separate equal-animal
weighting; they do not replace the paper's equal-session point estimate or provide
an inferential interval. Forty recording sessions are not forty independent rats.
