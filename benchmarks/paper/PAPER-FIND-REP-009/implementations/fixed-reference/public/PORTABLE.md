# Portable Figure 3C thalamus reconstruction

This package preserves PAPER-FIND-REP-009's complete 17-session, 34-condition probability reconstruction. TASK.md, INPUT_SCHEMA.json, OUTPUT_SCHEMA.json, PUBLIC_SCORING.md and SESSION_MANIFEST.json are unchanged. Their historical source-design/readiness statements describe their original authoring stage; this delivery adds portable files and an artifact grader, without changing canonical readiness or the scientific task.

Use the complete released Figure3C_data.RData and official article-and-supplement.official.pdf. They are bound directly from existing verified files before assembly and copied once into the export. The R workspace contains all released context labels and is already preprocessed; this is fixed-reference reconstruction, not protected-label prediction. No rows, features, sessions or conditions have been reduced or recomputed for packaging.

Authoring condition A receives the five task/schema/session documents, the article/supplement and the workspace. Optional source-assisted condition B adds only optional-author-code/3C_analysis.R. The current historical independent reconstruction was source-assisted; this package does not run either arm or establish a code-access effect. At candidate runtime, mount only the workspace, SESSION_MANIFEST.json and one selected sessions/pairNNN.json under the alias /input/session.json. The other materials are authoring/environment assets. The same frozen program handles all 17 requests, with no private feedback between them.

The standalone artifact interface accepts a directory containing exactly pair001.json through pair017.json, each holding that session's submission.json content. Each file is at most 4,000,000 bytes. The exact per-session schema is OUTPUT_SCHEMA.json. Seventeen fixed public request files are supplied; they contain only public identity and condition order. Selecting or copying a request does not run a coordinator or candidate.

Preserve Laser_OFF then Laser_ON, feature first-appearance order, partition-return training order, increasing test rows, zero fill for absent feature slots and retained observed NA values. Only the neural uuid_ columns are predictors. The last OFF cell has 477 trials and 143 test rows. Structurally valid support differences are scored as complete cell mismatches, not hidden public-schema failures.

The unchanged core gives every cell weight 1/34, including the 143-row cell. Matching supports receive mean absolute Randomised-probability discrepancy; differing support receives the original error 1. Accuracy, fixed-direction and source-auto AUC, signed contrasts and all nominal paired diagnostics remain separate. Source-auto orientation follows the median rule, not max(AUC,1-AUC). Published P=.008 is never a target or threshold. There is no new performance floor, averaging over a reduced cohort or silent numerical clipping.

The runtime recipe preserves the sealed compiled ARM64 R 4.3.1 prefix and its installed packages, including caret 6.0-94, xgboost 1.7.5.1 and pROC 1.18.0. The private paired diagnostics require jsonlite 1.8.4 and digest 0.6.31. The software archive was deterministically compressed without executing it. See environment/ for the public-base build recipe and exact software bindings. This is a declared reconstruction environment, not proof of the historical authors' binaries or original option choices.

Sessions are the analysis units here. The paper's four-animal legend and seven Table S1 Figure 3C names do not reconcile the per-session animal map. Nominal session p-values do not establish independent-animal significance. Upstream spike preprocessing, Figure 3G/TRN, Figure 3F/SHAP, whole-paper reproduction, causal inference and predictive improvement remain outside scope.
