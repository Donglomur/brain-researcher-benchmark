# Complete-support tree and curve scoring

Malformed, oversized, partial or structurally invalid JSON is rejected before the private-reference callback. Public admission requires exactly the 25 declared sessions, supported types/shapes, finite nonnegative tree distances, legal tree topology and bounded support identifiers. It does not require a scientifically correct tree, normalizer or curve. Private reference files are opened only after public admission. A support disagreement discovered against the reference is a scored scientific mismatch, not retroactively a zero-read malformed submission.

The primary metric is a lower-is-better **equal-session, equal-label normalized curve error**. All 25 sessions and three labels contribute, with no outcome-based subset. Within each session/label, compare the union of integer bottom-up heights of the submitted and reference curves. A height present on only one side receives error 1. A comparable finite pair receives `min(abs(candidate-reference), 1)`. Matching undefined entries receive zero; a finite/undefined disagreement receives 1. Average heights, then labels, then sessions. Wrong complete support receives full session error 1. No minimum performance or significance is required for a valid score.

The grader independently reconstructs curves from the submitted tree and the reference's raw-data-derived row labels. The submitted raw and normalized curves and normalization records must agree with that reconstruction within `1e-10 + 1e-8*abs(reconstructed)`, with exact missing-value reasons. An inconsistent label receives primary error 1. This prevents a supplied correct curve from concealing an unrelated tree. Comparison to the private reference uses the reconstructed candidate curve. The report also retains uncapped absolute errors on comparable finite entries, their denominators and every mismatch; it does not silently average only successful sessions.

The companion tree metric is **equal-session cophenetic normalized mean absolute error**: for every unordered pair of leaves, compare the linkage distance at their common ancestor and divide the mean absolute difference by the reference root distance (use scale 1 if that distance is zero). Left/right orientation and internal IDs with equivalent pairwise distances do not change this metric. Sessions with unmatched support have no comparable cophenetic value and report that reason explicitly, alongside full primary penalty. Report comparable-session count; never call a subset mean the full-cohort metric. This companion has no accuracy floor and is not substituted for the primary metric.

Inspect both endpoints: a correct height-curve alone does not certify the Ward distances or raw-rate geometry. If an uncapped error overflows finite floating-point representation, it is null with an explicit reason and the corresponding full-cohort aggregate is unavailable; that session is not silently dropped or treated as zero error.

Undefined normalization records use `status="undefined"` and one of `no_nonroot_curve`, `nonfinite_last_nonroot_denominator`, `zero_last_nonroot_denominator`, or `nonfinite_normalized_curve`. Defined records use `status="defined"`, `reason=null`, and the positive finite last-nonroot denominator. The label order is `Context`, `Direction`, `Position`. A nonfinite or absent denominator is null; an exactly zero denominator is numeric zero. Each undefined normalized row is entirely null. Raw nonfinite entries are permitted only as nulls and are checked against the reconstructed curve.

The reference targets the public source-defined conventions in `TASK.md`. Different tie resolutions can yield different tree and height-curve values; this is reported as a numerical discrepancy with the declared SciPy reference, not proof that the paper's qualitative claim is false. Scores do not establish a learning effect, a p-value, independent-neuron replication, Figure 3F parity or a complete paper reproduction.
