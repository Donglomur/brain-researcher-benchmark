# Reconstruct the source-defined hippocampal hierarchy curves

For all 25 recording sessions in `SESSION_MANIFEST.json`, reconstruct population vectors from the released sorted-spike, position and trial files, fit a Ward tree, and report the three label-variance curves defined below. This task evaluates a specified computational endpoint associated with Chiossi et al., *Learning reshapes the hippocampal representation hierarchy*, PNAS 122(11), e2417025122 (2025), DOI 10.1073/pnas.2417025122.

The common specification deliberately resolves differences between the paper and released implementation. The paper describes root normalization and successive partitions; this task targets the released implementation's **bottom-up node heights, root exclusion and last retained nonroot normalization**. Those are public requirements in both conditions. Condition A receives the main paper, released inputs and this specification. A later condition B may additionally receive official implementation files. A is not an unaided reproduction of Figure 3F. The supplementary Methods are unavailable in the retained packet; local regional selection rules for Figure 3F remain unresolved and are outside this task.

## Raw text serialization

The selected `.lwhl`, `.res` and `.clu` members are one-dimensional text streams, one scalar record per line, without a column-name header. Surrounding spaces/tabs, LF or CRLF line endings, and a final record without a trailing newline are compatible with the retained parser. `.lwhl` contains one floating-point linear position per 50 Hz frame; ordinary decimal/scientific notation and explicit nonfinite floating tokens are handled by the published missing-value rules. `.res` contains plain nonnegative decimal integer ticks, one per spike. `.clu` contains a plain integer cluster-count header as its first record, followed by one plain nonnegative integer cluster label per corresponding `.res` record. Do not remove the first `.res` value or treat the `.lwhl` first value as a header.

`.des` has no header: each nonblank line contains one whitespace-delimited class token. Strip surrounding whitespace, ignore blank lines, and preserve token order. `session_shifts.txt` also has no header and one numeric timestamp per nonblank line. Shift timestamps can be serialized in decimal/scientific notation, but their exact values are nonnegative integers in the 24 kHz clock; reject a genuinely fractional value rather than truncating it before the declared frame conversion.

The behavior files are UTF-8, headered **comma-separated** CSV with the eight named columns `Context,Start,Correct,Type,U,A,B,Other`, in that order. Standard CSV quoting applies; parse the header and preserve original row order. `holesdug` and `error_type`, mentioned by a convenience loader in the official code, are absent from this deposited table and must not be invented or required. The selected endpoint uses the eight supplied fields. Small metadata text can be decoded with UTF-8 BOM handling. Reward-coordinate files have one header record followed by whitespace-separated numeric rows with three columns; they are retained inputs but do not replace the animal-specific bin edges in `ACQUISITION_CONFIG.json`. README is ordinary text.

These statements describe serialization from retained source and closed schema evidence. They do not supply empirical positions, timestamps, class lists, trial outcomes, population vectors or reference answers.

## Join every session without selecting favorable trials or neurons

Use the manifest's exact files. In each `.clu`, the first integer is the cluster header; subsequent labels pair one-for-one with the entire `.res` timestamp stream. Class row zero maps to cluster ID 2, through cluster ID equal to the header. Keep all class rows for the identity join; select every `p1` cluster in ascending ID order, including mapped clusters with no events. Labels 0 and 1 are not mapped pyramidal columns. Do not force the released class-row count to equal the paper's reported 1,725: the existing metadata discrepancy (1,730 class rows versus 1,725 reported putative units) is disclosed, and recording columns are not asserted to be unique neurons across days.

Keep original zero-based CSV row ordinals. `Type`, after stripping whitespace and case folding, identifies `learning`/`visible` training rows and `probe` rows. Preserve all 1,010 training rows and 100 probes in support reporting. The primary tree uses the first 40 training rows per session in original order. The first `jc233/170220` session has ten additional training rows; they remain in `training_row_ids` but do not enter the tree. Probes remain in `probe_row_ids` and do not enter the tree. Do not use correctness, outcome, variance or neural activity to select trials or columns.

Convert `.res` ticks to 50 Hz frame indices by integer floor division by 400 (20 kHz clock). Convert session shifts by floor division by 480 (24 kHz clock). These clocks differ. For `n` training rows, shifts have `n+6` boundaries. Training row `i` occupies the interval between converted shifts `i` and `i+1`. After the second sleep interval between shifts `n` and `n+1`, probe `j` occupies shifts `n+1+j` to `n+2+j`, for `j=0..3`. A converted boundary may equal tracking length; a spike frame must be strictly within it. The missing initial sleep in `jc250/050221` is the documented zero first boundary, not a missing training trial. Do not clip or shift endpoints to force a match.

## Population-vector definition

Use float64 positions and the nine animal-specific bins in `ACQUISITION_CONFIG.json`. Position-bin membership is `(left, right]`. For the motion calculation, initialize intermediate values and output edge samples to zero. At each interior index `i=5..N-6`, the speed increment is `sqrt((position[i]-position[i+1])**2)` if both positions are positive, and -1 otherwise. The unsmoothed direction increment is `position[i+1]-position[i]` under the same positivity condition, and NaN otherwise. For each such `i`, speed is 50 times the mean of nonnegative speed increments in the ten-sample slice `[i-5:i+5)`; if `position[i]` is not positive or there are no selected increments, speed is NaN. Direction is the mean of non-NaN direction increments in the same slice, then mapped to -1/0/+1 by its sign. An empty selected direction slice remains NaN. First and last five output samples remain zero. Speeds above 100 cm/s are retained; no other preprocessing cap applies.

A frame contributes only if it is strictly inside the training interval, lies in its position bin, has speed **greater than** 3 cm/s and direction -1 for `Start=L` or +1 for `Start=R`. Occupancy is the number of contributing frames divided by 50. Count at most one spike event per cluster per 20 ms frame, matching the released intersection operation. Counting every within-frame spike is a distinct multiplicity diagnostic, not the primary target. Divide each cluster's eligible unique-frame count by occupancy seconds to obtain raw Hz. A zero-occupancy trial/bin is excluded from the primary tree and reported in `excluded_primary_row_ids`; it is never imputed as a zero vector. Any other nonfinite admitted rate is an error, not a reason for another exclusion.

Flatten primary vectors in original-trial-major, then bin-major order, keeping all ascending `p1` columns. `leaf_row_ids` records the corresponding `[original_csv_row_ordinal, bin_index]` pairs. Do not normalize columns, standardize, clip, apply PCA or include labels as Ward features. Fit Euclidean Ward linkage with `optimal_ordering=False`. Reference ties follow SciPy 1.15.3 in this fixed input order; historical SciPy 1.11 paper topology is not claimed. Left/right child orientation is irrelevant to scoring. A different tie resolution remains a scored scientific discrepancy, not malformed output.

## Tree and curve definition

For `m` retained vectors, linkage row `i` represents node `m+i` and has `[left_child, right_child, Ward_distance, descendant_count]`. Leaves are `0..m-1`; every child must precede its parent, and the one root must cover every leaf exactly once. Distances are finite nonnegative numbers. Heights are zero at leaves and `1+max(child heights)` at internal nodes. Let root height be `H`.

Labels, in order, are Context (`A=0`, `B=1`), Direction (`Start L=0`, `R=1`), and Position (bin index 0..8 divided by the maximum retained bin index). For each internal node, compute the sample variance (`ddof=1`) of each label over its descendant leaves. At each exact bottom-up height `h=1..H-1`, average those variances with equal weight per node, not per leaf and not across a root-frontier partition. Set height zero to zero. The root at height `H` is excluded: each raw curve has exactly `H` entries.

Normalize each session/label curve by its own last retained nonroot value. If that value is zero, nonfinite, or absent, keep the raw curve and return only null normalized entries with an explicit undefined reason. Never replace this denominator with the root value or an epsilon. If retained position maximum is zero, its internal label variances are undefined; raw entries beyond height zero are null and the normalized curve is undefined. Use the exact status/reason conventions in `OUTPUT_SCHEMA.json` and `PUBLIC_SCORING.md`.

The grader reconstructs candidate-only equal-session pooled descriptive summaries: right-pad individual reconstructed normalized curves with missing entries, compute each height's mean and sample SEM (`ddof=1`, undefined for fewer than two contributors), retain the per-height contributing-session counts, then reverse only the pooled display axis. A session with unmatched reference support keeps an entirely missing slot of its submitted curve length; the report states the unmatched count and marks the pool incomplete. It never presents a support-conditioned mean as a complete-cohort reconstruction. There are five animals and 25 nested recording sessions; neither nodes nor population-vector rows are independent animals. You need not submit pooled arrays.

Linkage child IDs and descendant counts may be integer-valued JSON numbers such as `0.0`, matching ordinary SciPy serialization; support IDs must be literal integers. Boolean values never count as numbers. `OUTPUT_SCHEMA.json` specifies every nested dimension and normalization condition.
