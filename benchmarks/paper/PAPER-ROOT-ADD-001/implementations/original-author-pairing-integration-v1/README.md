# Generated lifecycle integration control

One test connects the existing generated store and real authority/packed files
to the author-pairing lifecycle and lineage checks, then runs unchanged recovery.
Closure, transport, held-qid and query-row mutations must fail. Generated results
must not enter either the original-reference wrapper or the paired-score API.

The 96-bin fixture has one session and three selected jobs. Lifecycle observations
are synthetic test operands. This is no native execution, estimator fit,
original-data reproduction or successful original-reference recovery.

Run the command in `SOURCE.json` from the repository root. NumPy is the only
nonstdlib test dependency. Fixtures are retained in a fresh temporary directory;
set `LANGUAGE_INTEGRATION_OUTPUT_ROOT` to an explicit absent path when auditing
artifacts. The gross fixture cap is 2 MiB, with no automatic retry or deletion.
