# Selected original Figure 3b execution

This component connects the selected original store to private response selection,
frozen request identities, a candidate-provider interface, packed held-out
predictions, the original pooled Pearson scorer, and the continuous paired-effect
report. It uses all 14 sessions/eight people, population responses, zero-based
layer 5 and lag indices 17–19. The schedule contains 42 source jobs and 5,685
software callbacks. Those counts do not require that many API calls or processes.
The full 224-array reproduction remains a separate option.

`prepare.py` accepts the exact externally hashed selected preparation admission.
It authenticates the producer source before opening archives. The producer retains
the original supplied PCA embeddings, population averaging, centered smoothing,
speaker/support exclusions, qid grouping and lag padding. It produces only the
selected store; its current input loader still traverses all 13 original members
per session, and those bytes must be charged. No store is prepared by importing
this component or running its generated controls.

`run.py --protocol PATH --protocol-sha256 SHA256` is an explicit admission seam.
It binds the selected store, schedule, globally frozen candidate, condition,
provider source/configuration/admission, scoring runtime, private output paths and
finite component ceilings. The currently implemented native-provider option is
an explicit fresh-exec baseline. It refuses missing target qualification and
unsupported platforms. This code neither selects that option as a practical
default nor supplies its missing Linux namespace/FD/cgroup/reset qualification.
An alternative clean supervisor or trusted batching provider needs its own
reviewed isolation proof and declared participant-programme condition.

Collection accesses only the permitted response shards for each held qid. The
private cache is never a participant input. Each source feature may be reused
read-only where bytes match; candidate state or response access may not accumulate
across held exclusions. Durable authorities retain exact source context, row maps,
private target identity and frozen public request IDs. Recovery independently
reads the saved packed predictions and the authenticated original target view.
It does not call the candidate again or reconstruct a union of training labels.

The comparator reads the exact previously accepted 485,111-byte author-result
receipt and selects its 42 saved source observations in original row-major order.
It does not recover individual lags from rounded means or reread result arrays.
Its census linkage attributes the original source condition; it does not establish
same-stack baseline prediction parity or resolve the 567-versus-579 identity gap.
The report includes 14 paired session deltas, eight participant contributions and
leave-one-person-out sensitivity while retaining the equal-session estimand.
Undefined Pearson values propagate as null. There is no binary win, meaningful
minimum-effect criterion, new SOTA claim or all-paper-findings improvement claim.

Resource limits are additive. `store_read_limit` is instantiated twice, once for
collection and once for recovery. `wall_seconds` and `receipt_output_bytes` are
also separate allowances for each phase. `phase_cost_bounds()` exposes their sums
and the additional fixed-reference read. Cache reads, frozen bundles, dispatched
bundles, authority streams, packed files and provider lifecycle streams each have
separate cumulative counters. They are not one shared whole-entrypoint meter.
An external finite hard deadline covers imports, indivisible file/numerical work,
and setup/cleanup; the simultaneous component RAM admission is conservative and
is not a measured process-tree RSS claim. Failed runs retain partial streams.

The source loader enforces an ordinary-file size bound before reading, checks a
stable identity and hash, and executes those exact verified bytes. It assumes the
trusted host and operator remain trusted. It does not defend against a privileged
host rewriting runtime state. The original retrospective PCA, centered smoothing
and public data/code exposure remain scientific limitations even after a correct
future fresh-state boundary.

Generated controls exercise an actual tiny selected store through the cache,
pure provider stub, durable authorities, packed predictions and original scorer.
A separately labelled synthetic 42-cell accumulator control checks the complete
report branch; it mocks source authentication and is not an original result.
Other controls cover admission, changed scope/support/runtime, exact source-byte
execution, private-reader cleanup and malformed reference evidence. No candidate
subprocess, authentic source payload, model or scientific run is performed.
