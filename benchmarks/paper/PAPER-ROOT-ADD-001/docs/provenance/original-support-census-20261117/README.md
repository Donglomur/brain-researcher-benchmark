# Original workload census

The complete original C1–D1 schedule contains **6,776,076 held-sentence
prediction requests** across 58,926 field/layer/lag jobs, 14 sessions and eight
people. The downstream scientific result family still contains 224 arrays.
No model was fitted and no result array or scientific score was generated by
this census.

A conservative partition identifies 202,407 distinct held-sentence units.
Requests within each unit share identical permitted response and test support.
This does not authorize combining
feature layers, carrying participant state across different held-label
boundaries, or describing the partition as maximally efficient.

Naively serializing a separate six-array input packet per prediction request
would transfer 5,712,432,092,592 bytes of array payload—about 5.71 TB cumulatively.
That is not peak storage. Float64 predictions alone account for 9,719,745,192
bytes, before headers or provenance. The protected executor therefore needs
shared immutable storage, strictly selected per-request views, fresh participant
state for each held qid in every feature job, and packed private outputs. Those
are subsequent engineering and runtime
qualification steps, not achievements of this receipt.

The admitted census read 56 selected source members: timing/qid CSVs, speaker
column 0 and first-PC missingness from two lexical embedding families. It
traversed and authenticated the complete selected compressed/expanded members,
including lexical bytes outside the selected component. No firing-rate
response member was read. Support artifacts remain operator-private.

The single run completed in 0.425236 seconds with 67,174,400 bytes peak child RSS
and 2,146,732 bytes of private output. Independent review checked all source
joins, saved counts/costs, output hashes/modes and process closure without
reopening the original archives or recomputing the census. One earlier
metadata-only preflight failed because it expected an unabbreviated hash in
the root note; its correction preceded the sole authentic attempt. Earlier
generated guard failures and their fixes also remain in the evidence history.

`RECEIPT.json` binds the source commit, exact execution proposal, saved census,
independent reviews and measured costs. It contains no neural response or
private support array. This is workload preparation, not AI reproduction,
same-task improvement, protected-execution qualification or an additional
benchmark.
