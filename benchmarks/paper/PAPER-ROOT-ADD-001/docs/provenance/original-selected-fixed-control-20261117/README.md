The authenticated Figure 3b input and scoring route completed on all 14 sessions from eight people: 42 jobs and 5,685 held-query predictions. The single attempt took **225.534 seconds**. Independent saved-output checks verified every worker closure and request chain, all 42 full-job prediction hashes, and the 14 session score triplets.

This was a deliberately trivial engineering control. A globally frozen programme saw only time indices and returned `(time % 17 - 8) / 8`. It saw no neural responses, features or qids, and trained no model. Forty-two fresh workers produced full-job outputs; exact held-row slices supplied all original requests. This reuse is specific to that pure time-only programme.

The unchanged original scorer produced an equal-session correlation of **0.0004774344710546234**, with all 14 session means defined. This value is a procedural check, not an AI result, author reproduction, paper comparison or improvement claim.
