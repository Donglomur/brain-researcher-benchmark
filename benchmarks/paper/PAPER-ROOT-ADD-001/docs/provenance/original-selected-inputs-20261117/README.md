# Original selected input preparation

The original Figure 3b input store is prepared for all **14 sessions/eight people**,
**42 fixed jobs** and **5,685 held-out request definitions**. The single admitted
run took **7.556 seconds** and wrote **18,497,064 bytes in 5,913 files**. Independent
review confirmed the saved source lineage, held-group order/counts and file
extents without reopening array payloads.

This closes input preparation, not prediction execution or scientific evaluation.
No model was fitted, no AI/candidate programme ran, and no new predictions or
scientific scores were produced. The fixed original population layer 5 and lag
indices 17–19 remain unchanged. Full 224-array reproduction is separate.

[The receipt](RECEIPT.json) records source/runtime/output identities, costs and
limitations. [Independent publication review](REVIEW.json) binds these public
files. The [selected store implementation](../../../implementations/original-figure3b-store-v1/README.md)
and [execution interface](../../../implementations/original-figure3b-execution-v1/README.md)
remain source components with explicit execution gates.

The 18.5 MB output does not imply a small original-data read: preparation charged
2,118,763,714 source bytes. Its observed regular-file allocation was 41,021,440
bytes; physical IO and directory/inode overhead were not measured. Peak child
RSS was 645,742,592 bytes, not a simultaneous process-tree memory measurement.

Released primary C1/D1 outputs contain correlations, not raw held-out predictions
for this endpoint. The release's separate sentence-swap predictions use another
condition and lag. A future fixed pipeline control therefore cannot be called
author-prediction replay. Protected execution, historical baseline computation,
uncertainty/effect criteria, and the 567-versus-579 representation identity issue
remain unresolved. No new SOTA, paper win or finished benchmark is claimed.
