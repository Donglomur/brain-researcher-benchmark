# Conditional arithmetic for the original CellMincer aligned-trace endpoints

These partial kernels implement source-resolved operations from Figure3 and Methods Par73–74 of DOI10.1038/s44303-024-00055-x. They do not constitute an original-data scorer or claim reproduction, improvement, calibration, runtime or readiness. The existing `initial-evaluator-v1` remains unchanged: it intentionally defines a separate prospective grid, spectral defaults, whole-cell split and no-test-EP calibration.

The concrete missing computation is explicit-bin reduction after prominence optimization. The existing scorer reports seven prospective thresholds without reconstructing the original bins. This module also provides strict matching without the old floating-point exclusion margin, and spectral reduction on explicitly supplied transform/support operands without importing the old Hann/floor/time/frequency defaults. The latter order already agrees with the old scorer; it is not a newly discovered bug in that implementation.

## Supplied operands and source order

`fuzzy_peak_score` requires increasing integer peak ticks and an explicit clock rate. It checks `abs(delta_ticks) * 500 < ticks_per_second`, exactly preserving the displayed strict2ms inequality without a one-picosecond exclusion band. Every peak independently needs some counterpart; no one-to-one assignment is imposed. This performs no clock recovery or time quantization. The supplied identity labels an operand; it does not establish an authentic clock. Empty denominators and zero/zero harmonic F1 refuse because the article supplies no convention. The prospective evaluator's zero conventions are not imported.

`prominence_bin_profile` requires ordered rational-string EP thresholds, an explicit list of optical thresholds and corresponding F1 values for each EP threshold, and every bin's threshold indices and positive weights. All optical thresholds must lie in the exact inclusive `p±0.2mV` interval. It takes the maximum **within each supplied optical-threshold row first**, then averages those maxima using the supplied bin weights. Every supplied EP threshold must appear in at least one bin. Overlapping bins are permitted when explicitly supplied; no bin edge or integration rule is selected implicitly. The returned maximum is only over supplied states: neither complete continuous optimization nor historical grid recovery is certified. A producer must still bind the peak extraction, threshold sets, F1 operands and complete original grid. No optimum threshold is returned.

`peak_prominence_bin_profile` fills the peak-to-profile computation without accepting a caller-computed F1 matrix. It takes complete supplied peak ticks and rational-string prominences, explicit EP thresholds, an explicit `>=` or `>` membership relation, an exact tick clock and the same explicit bins. For each EP threshold it evaluates every distinct optical peak set in the closed `p±0.2mV` interval, then performs the existing maximum-before-bin-mean reduction. It checks each prominence equality and an exact rational midpoint between consecutive boundaries; ties are removed together and near-equal rational values never collapse to one float. This recovers interior optima that an endpoint-only or coarse search can miss. The selected optical threshold is not returned.

Completeness means every threshold state of **the supplied peaks under the declared relation**. It does not establish complete peak detection, historical threshold equality semantics, clock recovery, the original EP grid, bin edges or weights. Every state uses the existing strict2ms existential scorer. If any state has an empty denominator or zero/zero harmonic F1, the whole profile refuses; it neither drops that state nor invents a zero convention. The profile reports state counts, conditional maxima, explicit weighted bins and `historical_recipe_authenticated: false`. Grader-side inputs and outputs remain EP-derived material and must not be used for candidate training or selection; this function does not establish isolation.

`residual_noise_profile` consumes frequency-by-window EP and raw/method residual powers on an explicitly supplied common grid. The caller must supply the EP frequency indices included in total power, exclusion threshold, positive time weights, power reference, an explicit positive floor or `None`, and transform/grid/mask/dB identities. The common eligible mask is calculated once from EP total power `<= threshold`; raw and every method use it. Powers are converted to dB **before** the weighted time mean; subtracting method mean dB from raw mean dB yields the full frequency vector. No above100Hz scalar, across-recording pooling, cell weighting, uncertainty or pass threshold is created. All supplied cells are validated, including excluded windows. A missing eligible support or a retained zero power with no selected floor refuses.

The spectral producer is absent. Its original64-sample window/48-sample overlap, window family, centering, FFT/scaling, residual construction and alignment must still be established. A caller-provided identity or common grid is not evidence that historical masks or transforms have been recovered. The10-log conversion implements the mathematical dB of supplied power relative to the explicitly supplied power reference; historical scaling/reference/floor remain unqualified. Positive weights are explicit conditional operands, not evidence of original averaging weights.

## Scope that remains unresolved

All results are conditional vectors. The module contains no native file loader, peak finder, STFT, calibration, model run, biological grouping, original26/22 cohort selector or matched comparator producer. Original optical-to-EP calibration remains a prerequisite; these kernels cannot be relabeled a no-test-EP evaluation. Unknown numerical bins, detected-peak completeness, historical threshold relation, detector ties, undefined cases, EP mask threshold, transform conventions and whole-study aggregation remain scientific source gates. Original raw/CellMincer/SUPPORT/PMD/N2S outputs and reference vectors remain empirical gates.

No source omission is filled by a convenience default. Missing keyword arguments, incomplete dimensions, nonfinite values and unsupported numeric extents fail. Refusal of mathematically undefined or unrepresentable cases is an unsupported-domain boundary, not a newly selected zero/missing-data policy. An original scorer needs source-grounded handling of those cases before it can use these partial kernels over the complete study.

`SOURCE_BINDINGS.json` records exact published preimages and the independently accepted interpretation. The original bindings record the prior component snapshot. The peak-to-profile extension uses the same equation21–23 interpretation and adds no peak detector or historical policy. No central contract, readiness flag or published endpoint is changed. Focused generated controls, if admitted, establish these arithmetic seams only and are not scientific evidence.

The peak-search generated controls cover an interior optimum missed by a coarse grid, both equality policies, exact near-ties, closed interval boundaries, exhaustive small rational states, explicit weighted bins and refusal of undefined or malformed inputs. They establish arithmetic behavior only. The source equations are in [Methods, equations21–23](https://pmc.ncbi.nlm.nih.gov/articles/PMC11618097/); threshold membership and detector details remain caller-declared rather than source-authenticated.
