# Exact operator support for MindBridge composition

This namespace supplies the existing metadata/code artifact required by the
unchanged `target7-composition-v1` composer. Its11 pinned files are copied byte for
byte into `private/` (132,568 bytes). A separately counted1,296-byte copy of the
same `protocol.py` supplies `public/protocol.py`, satisfying the original alias
check without changing the converter. The12 source postimages total133,864 bytes.

From a repository checkout, pass these explicit locations to the composer:

- `--operator-root benchmarks/paper/PAPER-paper-method-033/implementations/target7-operator-support-v1/private`
- `--implementations-root benchmarks/paper/PAPER-paper-method-033/implementations`

The sibling composer's immutable `dependency_pins.json` authenticates all11 files,
the calibration module and original panel validator. The alias must match the
private protocol exactly. No workstation artifact path is a default or required
input for this composition route. Existing calibration, composition and panel
files remain unchanged.

These files are operator/grader support. Their presence in a repository does not
authorize mounting them in an agent's candidate view. Preserve separate
`paper_data` and `paper_data_author_code` access conditions and the existing
private target/gallery boundaries.

`tests/test_public_location.py` is one focused generated check from the public
layout. It reuses the existing in-memory fixture generator without running any of
its18 methods, loads only local operator/sibling artifacts, and composes a complete
metadata packet. Its `Path.open` observation concerns dependency loading; it is
not OS isolation or a claim about Python/NumPy library I/O. No images, neural
arrays, archives, models or numerical metrics are loaded or evaluated.

The copied `prepare.py` and native operator files preserve their original source
and generation identities. This projection does not make their archive, author
code, checkpoint, caption or other runtime assets available, and does not qualify
their scientific execution. Authentic source/index verification, historical
membership, publication comparability, freeze chronology and model/runtime holds
remain. Public CI adoption and task registry changes belong to the integrator.
