# MindBridge source calibration and reconstruction selection

This component implements two operations recovered from the pinned author code at `2a3943ff5b619db6f85f16a5e7ff1331d25def55`: calibration subset selection and the target-aware best-of-eight reconstruction choice. It preserves the original Table 2 source subjects 1/2/5, target subject 7, and budgets 500/1500/4000. It does not run MindBridge, extract features, score a complete eight-metric panel, or establish a paper improvement.

`calibration_memberships(filenames)` consumes a complete operator-owned inventory of basenames from the extracted **target-7 train directory**. It groups at the first period and sorts sample IDs as strings, then returns the prefixes at all three budgets. This recovers the actual `NSDDataset` procedure; the training loader shuffles only after membership selection. Every recognized sample must contain `jpg`, `nsdgeneral.npy`, and `coco73k.npy`. The author also recognizes `.subj`: it may accompany a complete sample, but a `.subj`-only key is rejected for missing modalities rather than silently omitted from the sorted prefix. Incomplete samples, duplicate basenames, and fewer than 4000 samples are rejected. Unknown extensions do not introduce sample IDs. The helper never opens payloads. A valid inventory is not evidence that the original split or published calibration IDs have been authenticated.

`select_best_of_eight(target_embedding, candidate_embeddings)` consumes one true-stimulus embedding and an iterable of exactly eight frozen candidate embeddings, each with shape `(257, 768)`. It streams candidates, preserves the target's float32/float64 dtype, casts candidate dtype to match, flattens all tokens, normalizes, and calculates cosine similarity with the source's second norm division. The first maximum wins. All embeddings must be finite with nonzero norms. Rejecting invalid values is stricter than upstream `nanargmax`, which can skip a NaN candidate; this prevents a malformed packet from silently becoming a fewer-than-eight comparison.

The selection features are **not the final CLIP features used for the paper's identification metric**. `recon.py` constructs `Clipper('ViT-L/14', hidden_state=True, norm_embs=True)`. `models.py` applies bicubic resize to 224, center crop, CLIP normalization, Hugging Face vision hidden states, post-layer normalization, visual projection, and division by the CLS-token norm. `utils.py` then compares the flattened 257×768 outputs. In contrast, `eval.py` uses OpenAI CLIP `encode_image`, bilinear resize to 224 and CLIP normalization for Pearson two-way identification. Reusing final metric embeddings for selection changes the source protocol.

`apply_selection(selection, candidate_payloads)` applies that **one chosen index to every payload**, including images and operator-extracted metric features. It cannot select a different reconstruction per metric. Use the original eight metrics on the chosen reconstruction, averaging over the complete 982-image target-7 test set separately at each calibration budget. The existing `initial-evaluator-v1` Pearson kernel remains preserved; its fixed-index protocol and prospective curve aggregate are still a separate calibration component. No new metric aggregate is introduced here.

These are operator utilities. All eight images, generation order, code, weights, seeds and exposure receipts must freeze **before** true-target feature access. Never expose the target features or target-derived selected index during fitting, generation or candidate iteration. A Python function and consistency hashes do not enforce isolation or authenticate a prior freeze. An actual protected evaluation service remains to be qualified.

The NumPy cosine calculation implements the source mathematical operation. Float rounding can differ from the source PyTorch/device execution, especially for nearly tied candidates. Bitwise author parity and near-tie behavior on authentic embeddings have not been qualified. Feature extraction versions/weights, the original full image membership, exact published calibration identities, SSIM and all eight native metric transforms, baseline replay, uncertainty and meaningful effect remain unresolved.

The pinned source uses `webdataset_avg_split/train` and `val` separately. Cached author-designated metadata reports 8559 train and 300 validation rows, whereas the paper describes 8859 training images overall. The recovered prefix rule applies to the **train directory only**; merging train and validation would change calibration membership. This source/component finding does not resolve the published-run membership history.

Run the generated controls through the shared approved test pool with Python and the existing NumPy installation. The script is `tests/test_source_protocol.py`. Tests contain no NSD records, stimulus images, model inference, private targets, fitted models or scientific performance estimates. Source receipt hashes and exact implementation/test hashes are recorded in the external handoff. Upstream source content is not redistributed in this component.
