# Original time-decoding query identity component

This operator-only component addresses the explicit missing identity/presentation
interface in the selected `PAPER-FIND-ADD-003` time-decoding contract. It is
**unadmitted source**, not a runnable benchmark, a new task, an authentic-data
result, or a paper reproduction/improvement. The existing scorer and central
task/authority files remain unchanged.

`mapping.py` uses the exact pinned `../original-time-v1/score.py` roster rules.
It retains all 11 animals, 44 sessions, 140 source trial rows, recorded-delay
cue membership, real/shuffled controls and 176 endpoint panels. Each eligible
whole-trial LOO fold has seven query identities. A fresh private 32-byte key
produces domain-separated HMAC identities and a key-dependent presentation
order. It does not consume or reset the author's MATLAB RNG stream.

Only `IdentityPlan.public_fold(fold_id)` may be sent to a participant. Its exact
fields are `schema`, `fold_id`, and seven `queries` containing `query_id` alone.
It contains no animal/day/cue/control, source trial index, actual bin, absolute
timestamp, source-order index, private roster hash or inverse map. The operator
later joins permitted neural vectors to those IDs in that same order; **this
component does not load, join or authenticate any neural vectors**.

`operator_binding()` returns the private source identities and inverse bin map
for the operator's preparation/restoration. `operator_fold_ids()` supplies the
operator's key-dependent dispatch order. Neither is a participant interface.
Private keys and objects must remain outside participant filesystems and logs.

The response format is:

```json
{
  "schema": "h_original_time_opaque_response_v1",
  "fold_id": "f_<opaque hex>",
  "packet_sha256": "<SHA256 of canonical public_fold object>",
  "predictions": [
    {"query_id": "q_<opaque hex>", "predicted_bin": 4}
  ]
}
```

There must be exactly seven distinct predictions, one per query, with integer
classes 1 through 7. Their submitted order is irrelevant. Canonical JSON is
UTF-8 `json.dumps(sort_keys=True, separators=(',', ':'), allow_nan=False)`.

`Collector.submit(operator_fold_id, response)` consumes that fold's first final
attempt even when the response is malformed. Malformed, duplicate, unknown,
cross-fold, incomplete, noninteger and wrong-packet responses cannot be repaired
through a second submission to the same collector. `fail()` records an observed
execution failure. `finish()` restores the unchanged scorer's original trial
positions and actual-bin ordering. Missing folds remain explicitly `unstarted`;
failed folds remain failed, and all panels remain present. It returns no score
feedback. Repeated `finish()` returns copies of the same final document.

## Boundaries that remain open

Opaque identities are not an execution sandbox. In whole-trial LOO, a sample
held out in one fold is a labeled training sample in other folds. A candidate
with shared state or access across those folds can retrieve its answer despite
randomized IDs. A qualified executor must supply fresh isolated fit/query state
for each fold and prevent cross-fold/cross-condition data and feedback access.
This source component neither implements nor proves those guarantees.

A future admitted operator must also authenticate the original processed MAT
input and complete source joins; construct the exact eligible-ROI, ten-frame
means; bind the native source RNG and once-per-helper training-label shuffle;
keep timing-bearing fields and original source files private; freeze candidate
code and matching access/resource budgets; and validate actual signal-to-ID
joins. Training preprocessing, native author replay, protected published
references, vector superiority criteria and mouse-level uncertainty remain
unresolved. A hash check authenticates bytes to a declared pin, not their
scientific origin. Query/neural fingerprints may still reveal source identity.

The key must be generated by the operator with a cryptographic random generator
and must be fresh for each independently frozen run. The API checks its byte
length, not its entropy or custody. The deterministic key in tests is only for
generated controls and must never be used for a study. Restart-safe custody,
durable response storage, process teardown and adversarial isolation are not
implemented here. Seven-bin query grouping preserves the source held-out trial;
whether joint inference is allowed belongs in the future frozen candidate API.

Generated checks: run `python3 -S -B test_mapping.py` through the existing shared
construction-test pool. They cover all 44×140 trial positions with all 176
panels, nontrivial anti-diagonal score restoration, wrong/duplicate/missing IDs,
wrong packet commitments, first-final failure retention, exact recorded-delay
masks, empty source cues and immutable final records. These are software
controls, not neural/AI performance measurements. This new test command still
requires central CI enrollment by the repository integrator.
