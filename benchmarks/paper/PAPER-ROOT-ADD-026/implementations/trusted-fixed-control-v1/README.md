# Temporal adaptation complete fixed control

This package prepares one finite, trusted engineering control for
`PAPER-ROOT-ADD-026`. It is not an AI trial, original-method reproduction,
improvement result, or readiness promotion. The real data have not been opened
by this construction package. Native execution requires root admission of the
exact frozen protocol and its artifact reservation.

`zero_rule.py` predicts integer zero at all 819 samples. Its only argument is
the query count (6 or 72); it receives no observed values, identities, context,
targets, or learned state. Reusing an immutable-in-use zero row saves memory.
The unchanged prediction contract still serializes every required value.

`fixed_control.py` rebuilds the already accepted original prospective seed-0
folds and both source plans from authenticated metadata. Digest disagreement
stops execution. Each branch has all 79 electrodes, two original none/S source
coordinate sets, 12 folds with 66 observed and 6 query conditions, and 158 full
jobs. The two branches remain separate: source-positional CV retains the source
column interpretation, and named-response CV uses all 819 response columns.
Full jobs use named responses in either branch.

The coordinator projects one observation at a time through the original
interface and discards it after committing the fixed output. It writes no
training matrix bank and introduces no cache. It wraps the unchanged original
member reader only to enforce the admitted paths and count logical reads.
Both complete branch panels are sealed before either metric evaluator runs.
Within each branch the original delivery gate freezes all CV predictions before
full-data observations. This is ordering and commitment, not secrecy: the
trusted projector parses complete CSVs and full observations expose all labels.

The existing source metrics retain undefined scores, condition/fold/electrode
rounding and the prospective bootstrap seed 19. The fixed rule must give equal
scores across the 948 none/S CV pairs and 79 electrode pairs within each branch.
Regional bootstrap estimates need not agree because the source RNG advances
between slots. No branch score is silently substituted for the other.

`run_control.py` authenticates the operator protocol and guard before loading
the worker. `guard.py` verifies the exact native admission, one active lease,
output reservation, Python/framework/watchdog pins, source files, and installed
NumPy distribution before numerical imports. Python runs with `-I -S -B`.
The guard applies CPU limits and disables core dumps; its RSS checks are not
an OS hard memory limit. Unknown bootstrap costs retain declared allowances.

The future native attempt has one worker, one watchdog, one thread, a 1 GiB
declared working-memory limit, 840/850 second CPU limits, a 900 second wall limit
and a 10 second kill grace. There is no automatic retry. A failed or interrupted
attempt retains partial artifacts and charged allowances.

Both integer-zero panels require exactly 81,390,224 bytes in 4,114 files.
The complete conservative artifact envelope is 100,621,902 bytes, including two
8 MiB score-report caps and separate final/failure-report caps; the requested
reservation is 128 MiB. These are output bounds, not a runtime guarantee.
Successful completion calls the original input reader 28,440 times, returning
9,387,131,288 cumulative logical bytes from the existing 84-file input bank.
There are no downloads. Source-derived collector rereads are reported as
expected counts rather than instrumented observations. Runtime authentication
reads and unmetered interpreter/import-loader/physical IO are distinguished.

The `paper_data` field is only the existing schema tag for this control; no
paper-assisted participant experiment is claimed. Interactive use still needs
enforced fresh provider/context isolation per coordinate: training responses
from one fold contain another fold's query labels. This trusted control cannot
resolve that requirement. Original category-selection and Figure 4–9 recipes,
author-method reproduction, and scientific improvement remain open.

Generated controls use the shared bounded test pool and invented small payloads.
They validate the source contract and admission behavior; they are not runs on
the original neural data. Protocol, output proof, generated-test receipts,
independent reviews and final handoff are kept in the sibling evidence tree.
