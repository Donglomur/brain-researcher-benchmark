# Complete temporal-adaptation engineering control

One admitted fixed-zero control completed successfully on the original
79-electrode input bank. Both original evaluation branches produced all 2,054
required prediction records and passed independent checks of the saved results.
The [machine-readable receipt](engineering-control-20261117.json) binds the
exact protocol, source components, plans, result and review by SHA-256.

The prediction rule received only the query count, 6 or 72, and returned integer
zero at every sample. It performed no learning, fitting or AI inference. Both
complete panels were committed before either metric evaluator accessed targets.
The original projector, collector, rounding and bootstrap recipe were retained.

Each branch includes 1,896 CV coordinates and 158 full-data coordinates. A CV
coordinate has 66 observed conditions and six query conditions, each with 819
samples. Full-data coordinates expose all 72 responses and are not held-out
evaluations. Coordinate and repeated source-slot counts are not benchmark or
independent-method counts.

All observed CV condition, fold and electrode scores were finite. The 948 paired
CV coordinates and 79 paired electrode summaries agreed across the original
none/S slots within each branch. These slots used the same fixed rule.

These are the saved descriptive bootstrap medians for the none slot; the S slot
has the same reported medians. The source bootstrap resamples electrodes within

separate. The receipt includes the intervals and exact score definitions.

The run took 500.474 seconds and recorded 195,166,208 bytes of peak RSS. It wrote
83,365,830 bytes across 4,124 artifacts. Its 9,387,131,288 bytes of original-input
reads were cumulative logical reads from existing files; there were no downloads.
Memory was checked through observed peak RSS, without an OS hard RAM limit.
Imports, physical IO and external diagnostic streams were not comprehensively
metered.

Independent review checked saved source, score, commitment and terminal joins.
It did not reread neural arrays or prediction bodies, or independently recompute
raw-data R² and bootstrap results. The artifact-size inventory was a separate
orchestrator metadata check. A preserved generated-test fixture failure and all
evidence-helper revisions remain included in their respective accounting.

This establishes successful execution of this engineering control. It does not
establish AI performance, original-method reproduction, scientific improvement,
complete source recipes, a qualified participant runtime, or benchmark readiness.
