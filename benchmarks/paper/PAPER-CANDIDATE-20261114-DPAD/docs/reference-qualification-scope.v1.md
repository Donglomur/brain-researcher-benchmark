# DPAD reference qualification and source-protocol scope

The published seven-session selector is resolved: the complete cited release's list of 30 broadband-available Indy sessions yields the paper's first seven sessions, from `indy_20160622_01` through `indy_20160921_01`. The [source-protocol reference specification](source-protocol-reference.v1.json) records the complete eligibility crosswalk, seven exact MAT catalog entries and the full publication-code search/refit recipe. Catalog identity does not authenticate raw arrays, selected electrodes, preparation or historical execution. Those gaps keep the task blocked.

The [published-source provenance](published-source-provenance.v1.json) already records 490 Figure 6i values. They are owner-side historical results, not fresh predictions or a named pairing to future session-fold outcomes. Earlier numeric-absence wording in retained components records their source-recovery stage; this note neither re-extracts those values nor changes a reproduction tolerance.

The [reproduction](../reproduction.v1.json), [improvement](../improvement.v1.json) and [paired outcomes](../outcomes.v1.json) remain separately binding. A fresh, independently qualified source-method reference is permissible without historical weights, RNG state, original caller bytes or an exact old runtime. It must preserve the original scientific task and use explicitly bound observations, sampling/preparation rules, training-only selection and protected evaluation. A historical-realization claim additionally needs the actual historical electrode/fold support. A source-supported fresh stochastic realization is not an exact historical replay and cannot be paired to anonymous published columns.

The full source recipe preserves all seven model alternatives, eight dimensions, the 90-architecture flexible search and twofold inner selection. It makes three consequential settings explicit: the paper's `0.01` relative-difference frontier floor, `uAK` joint recursion when both A and K are nonlinear (Eqs. 12–13), and `_Cz20` plus both `allow_nonzero_Cz2=False` and `model2_Cz_Full=False` to omit the additional fourth-stage behavior readout for `0 < n1 < nx`. Source-derived calls are not executed or runtime-qualified. Later default changes must not silently replace these settings.

## Existing component restrictions

| Retained component | Actual restriction | Scientific interpretation |
|---|---|---|
| `initial-evaluator-v1` | Requires sample counts divisible by five and constructs equal floor-width blocks. | This is its admitted calibration profile, not evidence that original sample counts divide by five. Removing only the guard would omit a tail. |
| `paired-candidate-v2` | Pins the predecessor SHA, inherits its folds, and requires 77–99 neural channels. | Preserve its recorded profile and metric lineage. The width is the paper's reported historical outcome, not a rule for selecting fresh random draws. |
| `inner-preparation-v1` | Requires 77–99 neural channels and already-prepared outer-training arrays; scaling flags are explicit. | This component does not construct raw observations or authenticate the original electrode sample. |

The current evaluator admits only `reference_kind="generated_engineering_control"` or `reference_kind="owner_supplied_unverified"`. The authoritative task has no runnable or scientifically qualified reference, and no scientifically admitted fresh panel is currently shown to be rejected by these guards. This correction therefore clarifies existing unqualified component limits. If a future qualified panel falls outside them, documentation alone is insufficient: a versioned channel/full-tail interface and its focused controls must be implemented.

No validator is relaxed here. A fresh ceil/tail fold allocation is available in the released source, and a documented fresh electrode realization need not reproduce the historical width. Supporting either in an executable benchmark requires a separately bound profile, complete row/channel identities and complete-tail handling after the observation recipe is qualified. A held-session split, new cohort, changed filter causality or different prediction target remains an extension.

## Requirements that remain

- Preserve the seven selected sessions, random 32-of-96 M1 electrode protocol once its eligibility/sharing rule is established, and exact realized sorted-unit identities. Do not search seeds to reach the reported unit count or paper score.
- Preserve five contiguous temporal outer folds, training-only architecture/dimension selection, four cursor position/velocity channels, and past-neural one-step prediction with no test-behavior input.
- Complete 10-ms binning, 50-ms Gaussian smoothing and 50-ms output alignment, including cursor velocity construction, bin origin/edges, downsampling phase and boundary context. Source helpers do not establish which unrecorded producer choices were used.
- Retain the seven-method joint neural/behavior frontier, all 35 named session-fold outcomes, channelwise correlations, validity masks and source aggregation. The folds are repeated temporal evaluations of one animal, not 35 independent animals. A competent executed reference, dependence-aware uncertainty, reproduction tolerances and meaningful improvement rules remain unqualified.
- Keep the scientific panel and evaluation identical in paper+data and paper+data+author-code. The reference specification contains author-code-derived details and is operator material, not a paper+data participant input. Official-code access is the intended information difference; this documentation implements no delivery or access enforcement.

An original-file schema/timing inspection can resolve actual fields, channel/slot identities, time support and whether velocity is supplied. It cannot recover an unrecorded derivative/filter/resampling choice or random draw from raw observations alone. The minimal remaining artifact is a compact observation-construction recipe, or a separately justified reconstruction that is subsequently qualified on original data. No original acquisition, fitting, parser execution, new input profile, readiness promotion or benchmark-count increase is selected here. Historical artifacts and all unqualified outcomes remain preserved.
