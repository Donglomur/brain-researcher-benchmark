# Cardiac paired executable source

This task-local source connects the existing public Cardiac matched-artifact package to protected program execution. Both programs are committed before either arm receives its input files. The captured output of each executed program is the only output eligible for grading. Private grading waits for both owned controllers and all candidate resources to close.

This is source construction, not current runtime qualification or a scientific result. It adds no benchmark ID and establishes no measured official-code benefit.

The scientific contract is unchanged: all 655 processed Salzburg rows; three raw and three separately standardized Student-t models; all 30 parameters; four chains, 2,000 tuning and 2,000 retained draws per chain; target_accept=0.9; population standardization (ddof=0). The existing equal-model beta-mean error divided by reference posterior SD remains the score. Summary agreement and self-reported diagnostics do not prove data dependence, inference fidelity or convergence.

## Existing components and required operator bindings

The A41/B46 packet specification is reused from components/cardiac-matched-artifacts. B adds exactly five official-source files; neither arm contains model.py or posterior_summary.py. The existing public summary scorer is imported directly, not copied. This public specification is distinct from any locally prepared private receipt; no private receipt is accepted implicitly.

The existing published NEURAL095 transport subtree is reused without copying its framework. Its public Docker executable/config/socket placeholders require explicit operator bindings. The Cardiac-specific producer, profile, holder and strict recovery remain unchanged. Only the exact two used recovery identity functions and their small dependencies are extracted from their previously reviewed source; unrelated task routes are omitted. Ownership-v4 and its trusted-controller validator are reused from authoring/shared-program-ownership-v4.

The exact candidate image remains sha256:385454f413cc6f607bc7e6bfc0246c365fe3a5d6ee8f8a9fdef47196b6141156. The 9aaf image is not a substitute. Candidate limits remain 120 seconds, 1.75 CPUs, 3 GiB memory, 128 pids, two numerical threads, offline/nonroot/read-only isolation and exact individual file mounts. The proposed pair clock is 420 seconds (360 work, 60 cleanup); these engineering ceilings are not measured feasibility or an execution grant.

REQUEST.inert.json is deliberately disabled. An operator must supply both programs; prepared public packet receipt/root; admitted operands and a pinned reference-binding metadata file using the existing public packet schema; exact current runtime, capacity, ownership and closed-cost evidence; and explicit Docker bindings. No authentic input, private target path/hash, original outcome, local receipt or admission authority is exported.

The packet binding contains an operands directory and reference_binding descriptor with path, bytes and sha256. It enters operator-only manifests and is reconstructed in each controller. The actual target is opened only by the unchanged paired scorer after both arms close. It is never mounted into a candidate.

The public owner uses exact existing ownership-v4 methods after checking operator-supplied current route qualification evidence against the complete exact dependency-manifest identity, entrypoint and controller. Historical private adoption records are not shipped or silently treated as current public-route qualification. Admission records are trusted operator evidence joins, not capacity measurements or security authority conferred by booleans. A complete separately selected resource operation and route-specific runtime/interruption qualification remain necessary.

## Execution and reference

After the missing prerequisites are accepted, the interface is:

    python3 -I -S -B authoring/cardiac-paired-execution/pair_run.py --review /operator/frozen-request.json --root-selected-once

The example does not select execution. The outer preserves preflight failures, partial outputs and unknown group closure. No supplied-summary CLI argument exists. A stop failure cannot become a vacuous "all groups absent" result. No automatic retry occurs.

reference_program.py is an unrun developer-derived operator reference outside both packets. It mechanically inlines the existing four helper functions and removes their two imports; it is not an independent model solution or evidence that all six fits finish in120 seconds. Authentic feasibility, current numerical output and route-specific execution qualification remain unestablished.

Fresh independent authoring contexts and equal effective authoring resources are still required for a code-access study. Same-input execution can emit memorized answers; execution attribution alone does not establish data dependence or historical environment reproduction.

## Public relocation validation

Run python3 -I -S -B authoring/cardiac-paired-execution/test_public.py. The five controls move the source into a generated checkout with spaces, authenticate reused dependencies, bind synthetic operator metadata without opening a target, reconstruct child packet/transport manifests and check existing owner validation without launching processes. Subprocess and socket construction are explicitly forbidden. These are relocation checks, not a replay of prior scientific controls or a Docker/model run.

Independent public review found and corrected two metadata-boundary defects before any execution: actual socket control characters now refuse, and current owner admission binds the complete executable dependency manifest. The frozen initial projection and generated counterexamples remain preserved outside the public export.
