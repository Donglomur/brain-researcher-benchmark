## RESTCVR-002

**Proposal Title:** Resting-state cerebrovascular-reactivity (CVR) and hemodynamic-lag mapping — an execution-hard reconstruction task (recipe divergence + coupled-physics assembly + declared robustness with hidden realization)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** Functional MRI / cerebrovascular reactivity

**Source paper:** Liu et al. 2017, *NeuroImage* (resting-state cerebrovascular-reactivity mapping without gas challenges, https://doi.org/10.1016/j.neuroimage.2016.11.054); Tong & Frederick 2014, *NeuroImage* (systemic low-frequency oscillations / hemodynamic lag). Dataset: a **paper-parameterized** resting-state BOLD/PetCO2 cohort, generated deterministically at `synth_build/generate_fixtures.py`; the true physiology is held out for grading under `tests/planted_truth.npz` (the reference run on the noise-free, artefact-free signal, built by `synth_build/build_truth.py`).

**Status: FULL runnable Harbor task (revised per review).** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — the instruction names the deliverable (produce lag, rCVR, and where determinable CVR maps); the difficulty is *execution*, not an un-cued judgement. It follows the shape of the maintainer's `pcasl-cbf-quantifier`: the agent implements the resting-state CVR / hemodynamic-lag pipeline **from scratch** (no fitter bundled), over a **heterogeneous 8-subject cohort where subjects need fundamentally different computations**, with a **publicly-declared robustness** requirement (the corrupted-frame realization hidden), graded voxelwise against the **planted physiology** on **convention-invariant** physical quantities.

### What changed in this revision

1. **Robustness contract made public.** `instruction.md` now states, under *Robustness / data-quality contract*, that a majority of subjects carry a few grossly motion-spiked BOLD frames that must be **censored** before the fit, that a low-SNR cluster is excluded from grading, and that the lag is a continuous sub-frame quantity of either sign — only the *realization* (which subjects/frames) is hidden. A correct fit of the stated method is no longer penalized for failing to guess an undeclared step.
2. **Graded against the true physiology, not one fitter.** The verifier no longer recomputes with a private pipeline on the real data and demands agreement. It compares each submitted map, voxelwise, to the **held-out planted target** = the reference run on the **noise-free, artefact-free** BOLD+PetCO2 signal (`tests/planted_truth.npz`, built by `synth_build/build_truth.py`). That target is the convention-invariant physical truth; **any valid estimator** applied to the real data recovers it within tolerance. The hidden reference modules were removed from `tests/`.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — subjects need *different code paths*, discoverable only from each sidecar. The vasoactive drive is the subject's natural end-tidal-CO2 fluctuation (resting state, no gas challenge), so the whole task turns on timing done right. Regressor fork: for some subjects an external PetCO2 trace was recorded (converted to mmHg — present in mmHg for some and kPa for others, ×7.5 apart — and resampled onto the BOLD frame grid honouring its own sampling and a possibly-negative start offset); for the rest **no trace exists**, so the regressor is built data-driven from the mask-mean BOLD and absolute CVR in %/mmHg is then **not determinable and must be omitted**.
2. **Coupled-physics assembly** — the motion-spike census, the percent-signal conversion, the detrending, the continuous (sub-frame) cross-correlation lag search, and the reactivity slope must **all** chain together; an error in any one compounds. The graded lag is the *continuous* cross-correlation-peak shift of either sign — a gas-challenge-style integer-frame (k·TR) search is too coarse and fails, because the resting delays are a fraction of a TR and TR varies per subject (1.0–2.0 s).
3. **Declared robustness, hidden realization** — a majority of subjects carry a few grossly motion-corrupted frames that bias the lag/mean/slope heavily unless **censored** before the fit. This is now **declared publicly** in `instruction.md`; only the realization (which subjects/frames) is hidden.
4. **Convention-invariant grading** — lag (TR-relative tolerance), rCVR (GM-normalized), and CVR (%BOLD/mmHg) are uniquely determined given the pinned model, so two independent correct implementations compute them identically (proven below).

### Verifier

`tests/test_outputs.py` grades **voxelwise** over the gradeable brain voxels against `tests/planted_truth.npz` (the held-out true maps = the reference run on the noise-free, artefact-free signal; never under `/app/data`), one parametrized test per (subject × map) panel — **24 panels**. The gradeable-voxel set (voxels clearing a peak cross-correlation floor; the planted low-SNR cluster excluded) and the TR are stored in the truth file. A computable map passes when ≥90% of gradeable voxels match the planted value within tolerance — lag atol = 0.50·TR (a strictly sub-frame band that admits the intrinsic scatter of a slow-drive cross-correlation lag estimated from a few hundred *noisy* frames against the *noise-free* target, while still defeating an un-refined integer-frame `k·TR` search — widened from 0.35·TR now that the target is the clean-signal reference rather than the reference on the same real data); rCVR rtol 10%/atol 0.06; CVR rtol 10%/atol 0.02. An unsupported map (absolute CVR for a data-driven subject) passes only when the submission **omits** it. Reward is binary (pytest rc==0 → 1 else 0). **The verifier imports no reference pipeline** — it only loads the planted `.npz`.

**Validity / discrimination evidence (recomputed for this revision, in-repo).** The oracle recovers the planted target on **all 24 panels** — the 20 computable panels comfortably inside tolerance (rCVR/CVR at ≥97.8% voxel agreement; every lag panel ≥93%), the 4 absolute-CVR panels correctly omitted. The plausible-but-wrong pipelines each fail their own axis: **no spike censoring** fails 9 panels (the spiked subjects' lag/rCVR/CVR); **no kPa→mmHg conversion** fails the 2 kPa subjects' absolute-CVR panels; an **integer-frame (no sub-frame refinement) lag** fails ~4 lag panels; **absolute CVR for a data-driven subject** fails its must-omit panel. So a from-scratch correct solver passes and each single-axis shortcut fails, on axes the instruction now *declares*.

### Difficulty — frontier gate

On the *previous* (hidden-contract) version, **gpt-5.6-sol (codex, xhigh) scored 0.0**, solving 15/24 panels — failing the continuous sub-frame lag refinement, the motion-spike censoring, the kPa→mmHg conversion, and the data-driven-subject absolute-CVR omit rule.

### Notes / honesty

- **Reconstruction paradigm.** The difficulty is executional (get the timing, units, and per-subject forks right with no recipe). `instruction.md` names the deliverable, the conventions, *and* the declared robustness contract; only the corrupted-frame realization and the per-subject regressor/omit forks are left to be discovered from the data.
- **Declared robustness (realization hidden).** The instruction states the motion-spike frames exist and must be censored, the low-SNR cluster is excluded, and the lag is sub-frame; only *which* frames/subjects are spiked is hidden.
- **Data.** Paper-parameterized, small, deterministic, and **leakage-clean** (the planted truth lives only in `tests/planted_truth.npz`, never under `/app/data`). Regenerable via `synth_build/generate_fixtures.py` + `synth_build/build_truth.py`.
- **allow_internet=false.** The task is self-contained (dependencies baked in the image; no network at run or verify time).
