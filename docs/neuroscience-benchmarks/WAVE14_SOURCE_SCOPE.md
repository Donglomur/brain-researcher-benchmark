It is an integration of scientific source code, not a runnable or scientifically qualified full-paper release.

The iSTTC baseline retains its exact author source and `baseline/LICENSE.author`, which contains the GNU General Public License version 3 notice. That component notice remains applicable independently of the repository's root license. This audit does not infer a GPL “only” versus “or later” election from the full license text alone. The existing author-attribution file is included. No external dependency bodies were traversed or imported by this publication review.

Private captured preferences, selected actual operator bindings, route baselines, execution/review/accounting receipts and superseded source history remain local. In particular, `next-paper-complete-program/BINDINGS.json` and `isttc-program-registration/BINDING.json` are deliberately absent. Tests are published source only and were not executed in this hygiene review. Native execution, authentic data, historical numerical equivalence, source-specific renderer/runtime qualification and whole-paper completion remain unqualified.
