# Partial neuroscience benchmark source snapshot

This branch publishes selected benchmark source code, declared contracts, construction tools, and a reviewed OFC tensor-input component. It is a source integration snapshot, not a completed release of 200 runnable or scientifically qualified benchmarks.

The snapshot deliberately omits actual recordings, derived arrays, held-out answers, operator predictions, private identity/roster payloads, execution artifacts, acquisition request ledgers, local private records, and personal communications. Existing source contracts can refer to omitted operator inputs or authoring dependencies. Such references describe required future inputs; they do not assert that those inputs are included or available.

The OFC component preserves the reviewed full-cohort input-transform requirements and invented controls. It does not provide full TCA decomposition, authentic-data parity, historical native runtime qualification, or a scored scientific result. The author source notice is retained beside its exact source dependency.

The broader source overlay has been scanned for common credential patterns and contains source code and declared benchmark contracts. This publication review does not establish complete runtime dependencies, licensing for every external dataset, numerical equivalence, actual-data readiness, or scientific qualification. Subsequent integrations must preserve these distinctions and add explicit reviewed fetching/inventory interfaces where needed.

This snapshot must be created from the existing public fork base with only the exact reviewed source allowlists. The unpublished local build history and its artifacts remain local. Commits and changes newer than the frozen source commit need their own review before publication.
