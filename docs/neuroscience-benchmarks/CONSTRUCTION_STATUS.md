## What the two directions test

**Paper research:** reproduce a clearly identified published result, then test a separately specified improvement against independent references. Compare paper + data with the same inputs + authenticated author code. A selected empirical result can be narrower than its paper; improvement on that endpoint does not by itself establish a new scientific finding or state of the art.

**Neural data:** test what can be inferred from neural measurements, and separate signal information, analytical reasoning, scientific reasoning and access to trained tools. Frozen prediction programs and case-by-case investigation are distinct conditions. Behavioral, simulated and structural endpoints remain distinguishable from measured neural signals.

The [100-paper scientific-scope assessment](https://github.com/Donglomur/brain-researcher-benchmark/blob/publish/neuroscience-200/docs/scientific-scope/SCIENTIFIC_SCOPE.md) records these distinctions, publication editions and unresolved evidence. Catalogue membership does not establish paper quality, novelty, complete data coverage or reproducibility.

## What is on GitHub

The public branch contains all 200 task manifests and audited source snapshots. The [source inventory](https://github.com/Donglomur/brain-researcher-benchmark/blob/publish/neuroscience-200/docs/neuroscience-benchmarks/SOURCE_SNAPSHOT.md) describes each published component. This status uses public commit `f1c7c7ff13c4032fed14a7ae9a0cf8dd1ce02774` as its baseline; later updates should be read with their own scope records.

Complete source capture means that every file in a particular declared source list is present. It does not mean complete external dependencies, complete paper reproduction or a successfully executed study. For example, the foraging and OSL snapshots include all 37 and 42 captured members respectively. Other exports are deliberately partial: FIND050 includes 44 of 46 captured members, omitting two derived notebook-code files; NEURAL-026 includes 14 of 15, omitting a personal-path binding. Their original source lists remain unchanged, so those public snapshots cannot satisfy their complete source requirements alone.

Authentic input support, qualified environments, native-method agreement and reference competence remain unresolved where the component scopes say so. Some data preparation has passed local checks, but there is no verified total of fully ready input programs. Source review and invented engineering controls do not establish empirical performance. Model and authentic scientific evaluation remain paused; this construction snapshot reports no new reproduction accuracy or improvement result.

## What completion requires

A benchmark needs an authenticated paper/data/code lineage where applicable, complete declared input support, a fixed leakage-aware protocol, independent competent references, working preparation and execution, and a validated scorer. A scientific qualification additionally needs a complete empirical run with recorded costs, failures and uncertainty appropriate to the biological units. Submission readiness requires the relevant packaging, documentation and independent acceptance checks. Source commits alone satisfy none of those later stages.

The immediate work is to finish and review complete source programs, resolve missing inputs and dependencies, and qualify their execution without shrinking cohorts or replacing the scientific question to obtain an easier result.
