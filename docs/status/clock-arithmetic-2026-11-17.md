# NEURAL-047 clock arithmetic repair

The November 16 audit found inconsistent time boundaries in NEURAL-047 preparation. A rounded absolute cutoff could admit a supplied timestamp outside the existing 4.8-second history limit, or select a landmark before the existing 2.4-second elapsed limit. The earlier proposed normalization was withdrawn because it assumed a timestamp precision that had not been established.

The repair compares exact supplied integer/float values against the existing binary64 interval constants. It converts relative offsets once and refuses preparation when those offsets cannot retain strict ordering. It adds no tolerance, clamping, nominal sampling rate or reconstructed decimal timestamps. For example, the supplied binary64 value `495.2` is excluded from a history ending at `500.0`; it is not relabeled to make the interval pass.

The repaired [implementation and source-selection instructions](../../benchmarks/neural/NEURAL-047/implementations/neural-047/full-conditional-programme-v3/README.md) preserve the canonical task, scientific contract, metrics, admission gates and historical runtime manifest. A separate current manifest identifies all 27 runtime members, with only the history implementation changed. The existing runtime interface can select this manifest, but both external runtime and reference-numerics admissions must independently bind its exact bytes. No admission is created or bypassed by this repair.

All 22 generated regression tests pass locally, including complete packet preparation, exact interval boundaries, mixed numeric types, unrepresentable offsets, current-source authentication and rejection of altered source or manifest bytes. An independent arithmetic oracle also checked 189 generated records. These controls execute no native model or scientific campaign. The [dedicated CI workflow](../../.github/workflows/neural047-clock-arithmetic.yml) checks the current source closure and these 22 tests; hosted CI is separate release evidence.

The source arithmetic defect is repaired. Authentic WT timestamp, frame and animal identities remain unbound to the documented upstream clock conventions, and native clock qualification remains unresolved. This changes no task counts, source ownership counts or scientific qualification status. The [original audit](audit-2026-11-16.md) remains a preserved record of the earlier finding and withdrawn proposal.
