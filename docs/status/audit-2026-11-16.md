## Consequential findings and repair work

| Area | Observed failure | Implemented repair focus |
| --- | --- | --- |
| Complete input support — SBIND | A truncated row source could silently end iteration while reporting the complete declared frame count. | Explicit iteration and complete-row validation; preserve the full required population. |
| Evaluator separation — cerebellar task | A private target operand could alias a candidate-visible source operand during preparation. | Reject conflicting roles before staging or reading protected target contents. |
| Process ownership | Bootstrap help/rejection paths could signal an inherited process group; the Narratives controller could leave descendants after reaping its leader. | Establish ownership before signalling and retain a safe cleanup identity until output streams close. |
| Source authentication | A pinned TMS loader could execute cached bytes different from the source it had checked; nested runtime code was omitted from a freshness fingerprint. | Execute the verified source bytes and include the selected nested runtime source in freshness checks. |
| Numerical metrics | Accepted inputs exposed integer rounding, unsigned subtraction, correlation distortion, overflow or underflow in several scorers. | Validate original numeric domains and use stable arithmetic while retaining the declared metric, population and tolerances. |
| Candidate-input validation | Some malformed public submissions became operator failures or reached private-configuration handling prematurely. | Reject invalid candidate payloads before protected input access, while preserving genuine operator/reference errors. |
| Relocation and instructions | Several wrappers or instance constructors still used retired paths; some displayed instructions described an older interface. | Authenticate exact current source locations and add current operator guides with explicit external-input requirements. |
| CI and repository checks | Maintained test suites and newer guides were omitted from discovery; several jobs had inconsistent action pins, credentials or bounds. | Complete test and navigation discovery, consistent source-only CI settings, and explicit ownership checks. |

The JSON correspondence records the exact finding IDs, public source paths,
reviewed repair evidence and known commits. **The accepted repairs are implemented
and locally reviewed; publication CI is reported by the release PR checks.**
Of the 56 actionable items, 55 have a verified repair commit. NEURAL-047 remains
open. The additional version-scoped optogenetics compatibility update is recorded
with the separate declared limitations and does not inflate that repair count.
Generated controls, source hashes and test counts establish only their stated
software checks. Agreement with authentic neuroscience data and successful paper
reproduction require separate evidence.

## Work still left

- **NEURAL-047 clock precision remains open.** The proposed endpoint correction
  was withdrawn. A valid precision/domain policy must distinguish small
  floating-point cancellation from a materially different temporal window.
  No replacement clock rule or passing CI coverage for that withdrawn patch is
  claimed here.
- **The 70 task definitions without assigned source need implementation work.**
  The other 164 also need their individual gaps resolved; having source does not
  establish complete data preparation, a working protected evaluator or a
  competent reference method.
- **Source preparation is distinct from authentic execution.** NEURAL-058 and
  NEURAL-081 preparation changes have their own repair records. Original-input
  identity, complete population coverage, native fidelity and empirical reference
  agreement still require task-specific evidence.
- **Scientific qualification remains a separate programme of work.** It requires
  the declared paper/data/code access conditions, complete admitted inputs,
  leakage and contamination controls, correct endpoints, competent comparators,
  protected evaluation and independent results. This audit ran no authentic-data
  or model campaign.
