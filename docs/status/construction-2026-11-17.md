# Construction update: eight evaluator components

Eight construction components for existing task records have independent source reviews and committed implementations. This note describes their implemented endpoints and remaining requirements. Combined registry counts and release/merge CI results are reported separately. The separate expansion work is outside this update.

These changes add implementation sources to existing tasks. They add no task IDs or scientific qualifications. Generated controls, model conditions and parameter configurations are not additional benchmarks. The repository-wide number of scientifically qualified benchmarks remains unknown.

| Component | Implemented construction endpoint |
|---|---|
| DoSEI — `clinical-dosei-responsiveness` | Ordinal MAE, per-category recall, classwise calibration tables/ECE, and paired participant summaries for original-arm RPS/MAE under an explicit prospective policy. The original scorer and complete population rules are unchanged. |
| iSTTC — `PAPER-paper-method-add-004` | A duration/trial sensitivity producer covering all 103,950 prescribed fit coordinates, retaining each success or failure, with mandatory diagnostics under both reference policies, two balanced Figure 7C Gaussian REML models, and a separate prospective mouse bootstrap. |
| Cardiac — `PAPER-ROOT-ADD-016` | Exact 655-row input and six separate raw/standardized model preparations, plus independent complete saved-draw summaries. This operator component supplies no fitted or accepted reference and adds no participant holdout. |
| FUS — `NEURAL-SCOPE-20261114-FUS-DIRECTION` | Complete held-record-fold delivery as lossless packets containing eight calibration maps and one query map. All 48 prescribed positive folds remain required for the full assay. Native MAT normalization remains unimplemented. |
| Seizure — `NEURAL-009` | Conditional normalized event scoring over all 686 pinned recordings and 23 biological people, with exact upstream event semantics, sample diagnostics and full-support constant controls. |
| Processed MEG — `PAPER-paper-method-add-010` | Conditional nested participant-held-out selection over 246 supplied scalar connectivity measures, with training-only standardization and separate scoring. The canonical connectivity-versus-nuisance comparison remains incomplete. |
| Calcium/kinematics — `NEURAL-025` | Session-local training-only selection/PCA/ridge decoding, complete five-mouse/ten-session scoring, phase/direction controls, training-trial rotation diagnostics and descriptive paired-mouse uncertainty on admitted normalized inputs. |
| Typing V1 — `PAPER-ROOT-ADD-002` | Complete frozen-panel V1 presented-sentence CER/WER evaluation with ordered-keystroke, physical-trial and grouping checks. This is offline artifact evaluation; it does not execute a decoder. |

The FUS deliverable was revised from a proposed native-normalization bridge to complete-fold packet delivery. Inspected primary consumer code does not establish physical acquisition bounds, original clock synchronization, stored dtype/geometry or the five Run99 constituent lists. The implementation preserves those unresolved requirements. Provider image fidelity, protected execution and matched reference competence also remain unqualified.

The MEG component conditions on a supplied historical 246-measure domain selected using whole-cohort quality control; it does not retrospectively make feature eligibility nested. Authentic label-independent observations, regional-time-series extraction, matched nuisance inputs, biological identity joins and corrected-supplement identity remain unresolved. Its proposed face-versus-object endpoint measures category decodability among consciously seen stimuli, not consciousness detection or scientific improvement.

DoSEI's secondary policy is a prospective construction choice, not an author-reported protocol. Its participant intervals describe fixed predictions and do not establish new-patient confidence coverage or refitting uncertainty. Authentic participant/assessment identities, causal EEG preparation, data rights and competent physiological references remain unresolved.

iSTTC retains every prescribed coordinate and failure over the declared 5,775-unit, 26-mouse, eight-area cohort. The paper/notebook reference and missingness conflicts are resolved only through an explicit prospective policy. Authentic cohort/QC reconciliation, historical windows, native R/lme4 parity and competent references remain unverified. Source p-values/profile intervals, pooled-area Figure 7B, Figure 7D/F curves and full-paper reproduction are outside this component. Mouse-bootstrap summaries are conditional on fixed fits, windows and scaling, with no established coverage.

The seizure evaluator groups `chb21` with `chb01` as one biological person. Its prospective threshold, causal context, record resets and 23 leave-one-person-out folds are explicit. Tolerant processed-event coverage does not establish original clinical event counts or onset timeliness. Native EEG/header/annotation identities, normalization and clocks, competent EEG-derived and timing/montage-only references, patient-paired uncertainty, actual training adherence and protected execution remain required.

The calcium component uses session-local neuron spaces and a prospective policy for retrospective lift-conditioned readout; it does not reproduce the author's preprocessing-before-cross-validation pipeline. Angles and velocities remain separate 24-channel conditions. A locally calibrated new-mouse comparator does not establish cross-animal transfer. Native MAT/trial/clock/ROI alignment, upstream processed-input exposure, source-reference competence and five-mouse uncertainty coverage remain unverified.

Typing implements the pinned V1 presented-sentence neural export endpoint. The online typed-target metric, V2 and final language-model rescoring are different endpoints; the final LM-assisted paper headline is outside this component. Source recording metadata and declared aliases do not establish the authentic selected transcript/keystroke population. Complete input identities, preprocessing, particular-use rights, neural-only prediction provenance, matched references and protected execution remain unresolved.

The cardiac component preserves all 655 exposed development participants and six separate model fits. Saved draws and hashed producer records do not establish fitting, independence, data dependence, tuning or convergence. Authentic input/rights admission, native numerical comparison, reference competence and protected custody still require independent evidence. No accepted-reference binding is emitted.

The eight components preserve their canonical task bodies and historical source packages. Generated controls establish engineering behavior only; no authentic-data or scientific model campaign was performed for these additions. Complete populations, input custody, independent reference evidence, resource feasibility and protected evaluation remain scientific or deployment requirements as applicable.
