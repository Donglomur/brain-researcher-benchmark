# What the historical execution records establish

Three inspected profiles have retained records of actual program execution or
program controls. These support specific historical pipeline claims. Current
public runtime qualification and complete scientific readiness remain open.

This November 16, 2026 audit inspected existing metadata. It performed no new
native, data or model runs and changes no benchmark or readiness count. It
sampled three profiles from the 42 historical finite acceptances; it does not
reconcile the remaining 39.

| Profile | Evidence in retained records | Scope and limits |
| --- | --- | --- |
| [Purkinje / PAPER-FIND-REP-013](../../../../benchmarks/paper/PAPER-FIND-REP-013/implementations/registered-runtime/manifest.json) | A separately implemented developer program completed, committed its output and was scored. Its terminal receipt links source, program, result and outcome-commit hashes. | Source-assisted reconstruction of 10 released trees and 13 components, with 31 numeric table fields and 58 scalar diagnostics. Operational acceptance does not define scientific success. Donor mapping, biological generalization and whole-paper findings remain unresolved. |
| [Across-day velocity / NEURAL-023](../../../../benchmarks/neural/NEURAL-023/implementations/registered-runtime/manifest.json) | Four named program controls exercised the prediction/scoring boundary: reference, negative, malformed-linger and private-probe. | One animal and two exposed recording days, with 96 channels and 20 ms bins. This establishes a controlled development pipeline; the complete multi-session/multi-animal task, ordinary run mode and an agent study remain unqualified. |
| [TMS behavior / PAPER-paper-signal-add-021](../../../../benchmarks/paper/PAPER-paper-signal-add-021/implementations/registered-runtime/manifest.json) | Historical ordinary-program A/B receipts link programs to scored outputs. A later passed registration explicitly records zero new scoring invocations. | Processed behavioral tables for 15 participants, including 135 participant-condition means/counts. The valid-null B control demonstrates interface operation. Raw gaze/EEG, whole-paper inference and the current capacity wrapper remain unqualified. |

The historical endpoints are cell-equal branch-length RMSE for Purkinje,
mean-axis retrospective velocity R-squared for NEURAL-023, and mean absolute
error of participant-condition means for TMS. Each profile also has separate
coverage, comparison or provenance obligations. No new numerical result or
scientific-success threshold is introduced here.

## Evidence projection

[profiles.json](profiles.json) contains 82 selected scalar fields from six
retained records. Each projection gives the original record's byte length and
SHA-256 plus the exact JSON pointer for every selected value. Population and
metric descriptions are labelled interpretation alongside the evidence. The
current public manifest pins supply context; they are not executed-environment
identities.

This is a maintainer-derived projection. The original complete receipts,
program/output payloads and environment records are not included. Opaque hashes
identify retained records and claimed output chains; independent reproduction
still requires the original evidence and a qualified runtime. Local paths,
process/container identities, raw logs, review credentials and target/prediction
payloads are excluded from this publication.

## What remains to qualify

The next evidence should join each historical run to its executed image and
package environment, exact producer/scorer sources, admitted inputs and reviewed
public provisioning. NEURAL-023 also needs per-control output/source joins. These
joins were not resolved by this metadata audit.

The current TMS and Purkinje capacity successors have no new execution evidence
in this sample. Earlier execution cannot be inherited merely because a later
manifest carries a passed flag. Protected evaluation, paper/code comparisons,
genuine agent attempts, difficulty and scientific validity remain separate
requirements. See the [repository quality assessment](../../assessments/REPO_QUALITY_20261116.md).
