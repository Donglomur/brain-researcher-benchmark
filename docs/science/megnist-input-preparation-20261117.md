# MegNIST: authenticated input preparation

This source proposal concerns the [MegNIST preprint, arXiv:2611.21399v1](https://arxiv.org/abs/2611.21399v1), [author code at commit c5c8cd6522a586854a7df16a9adb2e24e9296ae4](https://github.com/neural-processing-lab/megnist-paper/tree/c5c8cd6522a586854a7df16a9adb2e24e9296ae4), and the [released dataset at revision be8353b8c6152a5e3e2fcf44da098605db5f3c19](https://huggingface.co/datasets/pnpl/MegNIST/tree/be8353b8c6152a5e3e2fcf44da098605db5f3c19). The dataset release declares CC BY-NC 4.0. This is a preprint source; no journal-publication claim is made.

The task uses MEG recorded during visually cued covert digits from **one participant across four sessions**. The released split contains 10,000 training, 1,000 validation and 1,000 test cases, with 306 channels and 250 time samples per case. Evaluation is within-person on held-out runs. It does not establish cross-person generalization or unconstrained thought decoding. The author-documented run allocation is preserved; this preparation authenticates the released HDF5 endpoint rather than independently reconstructing raw FIF timing.

All three original objects, totaling **3,672,112,686 bytes**, matched their published whole-file SHA256 values. The actual source schema qualified, and all **12,000 cases** were copied and verified against the originals without normalization, filtering, resampling, reordering or dropped rows. Feature bytes, including signed zeros, and private label/row/ID joins were verified. The originals were reauthenticated after preparation. All 108 planned bounded preparation operations passed without retries or schema relaxation.

The completed `standalone_features_static_axes_v2` packet contains fresh train/validation files with signals, labels and opaque case IDs; the test file contains only signals and opaque IDs. Evaluator-private joins retain test labels and canonical row mappings. A separate clean `axes.h5` exposes training-derived time samples, sensor coordinates, channel names and channel types after exact cross-split identity and source-role checks. Source order, dtype and bit values are preserved. The test and axes exports contain no source attributes, trial metadata, provenance or links to originals.

The publication manifest SHA256 is `ec53db9a60779e01ee05496833418355151781afff7b02f9db20a879029ace02`. It binds the three split files and the separate axes artifact. This is a completed **input-preparation milestone**, not a reproduced classifier result, improvement result or qualified evaluation environment. No model training, inference or scientific score was run. Filesystem, network and conversation isolation for participant execution remains to be implemented and verified; directory separation alone does not provide it.

For later benchmark construction, retain the complete original seven-width by ten-seed reference panel and report reproduction and same-task improvement separately. Candidate methods may change architecture under the same cases, permitted information and declared tuning budget. Optimization seeds are not independent participants. A gain over this paper requires its own controlled evaluation and does not alone establish field-wide SOTA. This source proposal introduces no new task ID or benchmark-ready count.
