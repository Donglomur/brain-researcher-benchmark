## RETINOTOPY-002

**Proposal Title:** Population receptive-field (pRF) mapping of a heterogeneous retinotopy cohort — an execution-hard reconstruction task (recipe divergence + coupled-model assembly + declared robustness with hidden realization)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** Visual neuroscience / retinotopic fMRI (pRF)

**Source paper:** Dumoulin & Wandell 2008, *NeuroImage* (population receptive-field estimates in human visual cortex, https://doi.org/10.1016/j.neuroimage.2007.09.034); Kay et al. 2013, *J. Neurophysiol.* (compressive spatial summation in human visual cortex). Dataset: a **paper-parameterized** retinotopic-mapping fMRI cohort (moving-bar apertures + BOLD + per-subject HRF), generated deterministically at `synth_build/generate_fixtures.py`; the true pRF physiology is held out for grading under `tests/planted_truth.npz` (the planted pRF centres/sizes + determinability classes, built by `synth_build/build_truth.py`).

**Status: FULL runnable Harbor task (revised per review).** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — the instruction names the deliverable (produce per-voxel eccentricity, polar angle, and pRF size) and the difficulty is *execution*, not an un-cued judgement. It follows the shape of the maintainer's `pcasl-cbf-quantifier`: the agent implements the pRF inversion **from scratch** (no fitter bundled), over a **heterogeneous cohort where subjects need fundamentally different computations**, with a **publicly-declared robustness** requirement (the corrupted-timepoint realization hidden), graded voxelwise against the **planted physiology** on **convention-invariant** physical quantities.

### What changed in this revision

1. **Robustness contract made public.** `instruction.md` now states, under *Robustness / data-quality contract*, that a majority of subjects carry a few grossly motion-spiked timepoints that must be **censored** before fitting, that each subject's own HRF must be used, that the compressive exponent applies where declared (report raw σ), and that low-R² voxels must be omitted — only the *realization* (which subjects/timepoints are spiked) is hidden. A correct fit of the stated model is no longer penalized for failing to guess an undeclared step.
2. **Graded against the true physiology, not one fitter.** The verifier no longer recomputes with a private pipeline and demands agreement. It compares each submitted map, voxelwise, to the **held-out planted pRF** (`tests/planted_truth.npz`, built by `synth_build/build_truth.py`) — the true eccentricity/polar/size that generated the signals — over the reliably-driven (planted must-keep) voxels, requiring NaN on the planted must-omit voxels. Determinability comes from the planted voxel class (comfortably either side of the announced R²≥0.30 rule), not from a reference recompute. The hidden reference modules were removed from `tests/`.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — the forward model forks per subject, discoverable only from each sidecar: the visual-field pixel→degree scale, stimulated extent, number of bar-sweep directions, and TR all vary (a hard-coded stimulus geometry mis-locates the pRF); each subject supplies its **own** sampled HRF and a **majority are non-canonical** (convolving with a hard-coded canonical HRF biases the fit); and some subjects are **compressive** (`css_exponent` n<1 given in the sidecar), where a linear fit recovers a biased pRF *size* and the field's σ/√n "effective size" is the wrong quantity — the graded size is the **raw** Gaussian sd. A single fixed recipe cannot fit the cohort.
2. **Coupled-model assembly** — the pRF forward model is heavily coupled: a unit-height 2D-Gaussian's spatial overlap with the moving-bar aperture → an optional compressive nonlinearity (drive = overlap**n) → convolution with the subject's HRF → a per-voxel free gain and baseline. An error in any stage corrupts the least-squares fit for eccentricity, polar angle, and size.
3. **Declared robustness, hidden realization** — a **majority of subjects** carry a few grossly motion-corrupted timepoints (large transients across all voxels) that must be detected and censored before fitting, or the variance-explained collapses and determinable voxels are wrongly omitted. This is now **declared publicly** in `instruction.md`; only the realization (which subjects/timepoints) is hidden. Additionally, only a minority of voxels carry a reliable pRF, so a pipeline that fits every voxel reports spurious pRFs on noise and on voxels outside the stimulated field — all of which must be **omitted** by the announced variance-explained threshold (NaN), with polar angle further NaN within the foveal cutoff.
4. **Convention-invariant grading** — eccentricity (deg), polar angle (rad), and raw-σ pRF size (deg) are convention-invariant once the coordinate convention, HRF convention, and determinability rule are pinned in `protocol.json`; the pRF fit is well-posed, so a from-scratch solver recovers the planted values while wrong pipelines fail — no reporting-convention ambiguity.

### Verifier

`tests/test_outputs.py` grades **voxelwise** against `tests/planted_truth.npz` (the true pRF centres/sizes that generated the signals; never under `/app/data`), one parametrized test per (subject × map) panel — **24 panels** in all. Determinability comes from the planted voxel class: **must-keep** voxels (a reliably-driven pRF; planted R²≈0.72–0.95) require a finite value within a per-map tolerance (eccentricity rtol 0.08/atol 0.22 deg; prf_size rtol 0.12/atol 0.25 deg; polar_angle circular atol 0.15 rad); **must-omit** voxels (pure noise, or a centre far outside the stimulated field; planted R²≈0.08–0.20) require NaN; borderline voxels (≈0.18–0.36, straddling the announced R²≥0.30 rule) are ungraded. These bands sit comfortably either side of R²=0.30, so a correct fit's keep/omit decision matches the planted class. A panel passes when ≥85% of its graded voxels satisfy their condition. Reward is binary (pytest rc==0 → 1 else 0). **The verifier imports no reference pipeline** — it only loads the planted `.npz`.

**Validity / discrimination evidence (recomputed for this revision, in-repo).** The oracle recovers the planted target on **all 24 panels**, every panel at ≥95.5% graded-voxel agreement (most at 98–100%) — comfortably above the 85% bar. The plausible-but-wrong pipelines each fail their own axis: **no motion-spike censoring** fails 12 panels (the spiked subjects); a **hard-coded canonical HRF** fails 7 panels (the shifted-HRF subjects); a linear fit on a compressive subject / reporting σ/√n biases the size panels; keeping every voxel fails the omit rule. So a from-scratch correct solver passes and each single-axis shortcut fails, on axes the instruction now *declares*.

### Notes / honesty

- **Reconstruction paradigm.** This task's difficulty is executional (get many coupled quantitative decisions right with no recipe), unlike the recognition-tier "un-cued judgement" tasks in this repo. `instruction.md` names the deliverable, the model conventions, *and* the declared robustness contract; only the corrupted-timepoint realization and the per-subject forks are left to be discovered from the data.
- **Declared robustness (realization hidden).** The instruction states the motion-spike timepoints exist and must be censored, each subject's own HRF must be used, the compressive exponent applies where declared, and low-R² voxels are omitted; only *which* timepoints/subjects are spiked is hidden.
- **Data.** Paper-parameterized, small, deterministic, and **leakage-clean** (the planted truth lives only in `tests/planted_truth.npz`, never under `/app/data`). Regenerable via `synth_build/generate_fixtures.py` + `synth_build/build_truth.py`.
- **allow_internet=false.** The task is self-contained (dependencies baked in the image; no network at run or verify time).
