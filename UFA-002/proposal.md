## UFA-002

**Proposal Title:** Microscopic anisotropy (uFA) from a heterogeneous b-tensor-encoding cohort — an execution-hard reconstruction task (recipe divergence + coupled-physics assembly + hidden robustness)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** Diffusion MRI / microstructure

**Source paper:** Lasic et al. 2014, *Frontiers in Physics* (microscopic diffusion anisotropy / uFA from variable b-tensor shape, https://doi.org/10.3389/fphy.2014.00011); Westin et al. 2016, *NeuroImage* (q-space trajectory / b-tensor encoding, https://doi.org/10.1016/j.neuroimage.2016.02.039). Dataset: a **paper-parameterized** b-tensor-encoding diffusion cohort (Westin 2016 / Lasic 2014 signal model), generated deterministically at `synth_build/generate_fixtures.py`; the planted convention-invariant ground-truth maps (MD/uFA/Ciso) are held out under `tests/planted_truth.npz` (written by the generator, never shipped under `environment/data`).

**Status: FULL runnable Harbor task.** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — `instruction.md` names the deliverable (produce per-voxel MD/uFA/Ciso maps); the difficulty is *execution*, not an un-cued judgement. The agent implements a microscopic-anisotropy inversion from b-tensor-encoding data **from scratch** (no fitter bundled), over a **heterogeneous cohort where subjects need fundamentally different computations**, with a **declared robustness** requirement (the realization hidden), graded voxelwise against the **planted physiology** on **convention-invariant** quantities.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — subjects need *different code paths*, discoverable only from each sidecar's per-volume list of b-tensor **shapes** (linear LTE b_Δ=+1, planar PTE b_Δ=−1/2, spherical/isotropic STE b_Δ=0). Separating isotropic variance V_iso from anisotropic variance V_aniso — hence uFA — requires **≥2 distinct shapes**: an LTE-only or PTE-only subject confounds them and **uFA and Ciso must be omitted**; an STE-only subject determines V_iso (Ciso) but not V_aniso (uFA must be omitted); only a ≥2-shape subject supports all three maps.
2. **Coupled-physics assembly** — the powder (direction-averaged) signal of each shape follows the second-order cumulant model Sbar_s(b)=S0·exp(−b·MD + ½·b²·C2_s) with C2_s = V_iso + (4/5)·b_Δ(s)²·V_aniso; MD and S0 are **shared** across all shapes (a shared-slope joint fit) and only the curvature depends on shape. The shared-slope log-quadratic powder fit, the per-shape b_Δ variance split with the 4/5 powder factor, and the uFA normalisation must **all** be assembled correctly; an error in any one compounds.
3. **Declared robustness, hidden realization** — a majority of subjects (6 of 8) carry one or two grossly corrupted diffusion volumes (motion dropout / spike) that must be **rejected** before the joint powder fit, or the shared MD and every curvature (and thus every downstream map) are biased. `instruction.md` now **declares** that such corrupted volumes exist and must be rejected robustly; only the *realization* (which subjects / which volumes) is hidden and must be discovered from the data.
4. **Convention-invariant grading** — MD, uFA, and Ciso are uniquely determined given the pinned cumulant model and b_Δ split; any valid estimator recovers the same planted values within tolerance, so a from-scratch solver can pass while wrong pipelines fail — no reporting-convention ambiguity.

### What changed in this revision (addressing the review of the hidden-contract version)

1. **Robustness contract made public.** `instruction.md` now states, under *Robustness / data-quality contract*, that a minority-to-majority of volumes are grossly corrupted and must be detected and rejected robustly before the joint powder fit — only the *realization* (which subjects/volumes) is hidden. A correct pipeline is no longer penalized for failing to guess an undeclared step.
2. **Graded against the true physiology, not one fitter.** The verifier no longer recomputes with a private pipeline on the real data and demands agreement. It compares each submitted map, voxelwise, to the **held-out planted target** = the true MD/uFA/Ciso that generated the powder signals (`tests/planted_truth.npz`, written by `synth_build/generate_fixtures.py`). Because the powder model is exact and the estimators are ordinary least squares, **any valid estimator** applied to the real data recovers the planted values within tolerance. The hidden reference modules were removed from `tests/`.
3. **uFA graded over parenchyma.** uFA `= √(3·V_aniso/(2·V_aniso+V_iso+MD²))` is a √ of a bounded ratio that is ill-conditioned in free water (V_aniso ≈ 0). It is now graded over brain **parenchyma (GM+WM)**, where microscopic anisotropy is defined — matching this repo's precedent of grading such component maps over parenchyma; CSF is not graded for uFA. The oracle recovers uFA at 100 % of parenchyma voxels (vs ~13–50 % of CSF voxels, where the √ amplifies near-zero scatter). MD and Ciso remain graded over the whole brain mask, tolerances unchanged.

### Verifier

`tests/test_outputs.py` grades **voxelwise** against `tests/planted_truth.npz`, one parametrized test per (subject × map) panel — **24 panels** in all; the score is the fraction of panels correct. A determinable map passes when ≥90% of its region's voxels match the planted map within a per-map tolerance (MD rtol 5%/atol 0.02; uFA rtol 8%/atol 0.04; Ciso rtol 15%/atol 0.02). MD and Ciso are graded over the whole brain mask; **uFA** over parenchyma (GM+WM). An undeterminable map (uFA for a single-shape subject, Ciso for an LTE-only or PTE-only subject) passes only when the submission **omits** it.

**Validity / discrimination evidence (recomputed for this revision).** The oracle recovers the planted target on **all 24 panels (19 computable at 100 % / ≥97 % voxel agreement, 5 correctly omitted)** — comfortably inside tolerance. Because the powder model is exact (second-order cumulant) and the estimators are ordinary least squares, a genuinely-correct independent implementation reproduces every determinable panel. A **naive submission that disables the gross-volume rejection** fails **14 panels** through the real verifier — every panel of the six corrupted subjects (sub-02, sub-03, sub-05, sub-06, sub-07, sub-08) — while the two clean subjects (sub-01, sub-04) still pass and the omit forks are unaffected. So a correct robust solver passes and the robustness/omit shortcuts fail, on axes the instruction *declares*.

Oracle **reward 1.0** verified in-container (deterministic). On the *previous* (hidden-contract) version, **gpt-5.6-sol (codex, xhigh) scored 0.0**, solving 11/24 panels — failing the shared-slope joint powder fit, the b-tensor-shape variance split (V_iso/V_aniso), the uFA/Ciso omit rules by encoding set, and the corrupted-volume rejection.

### Notes / honesty

- **Reconstruction paradigm.** This task's difficulty is executional (get the coupled powder physics, variance split, and per-subject forks right with no recipe), unlike the recognition-tier "un-cued judgement" tasks in this repo. `instruction.md` names the deliverable and pins the conventions but never enumerates the pitfalls (the shape-set forks, the corrupted volumes, the variance split) — the agent must discover them.
- **Data.** Paper-parameterized, small, deterministic, and **leakage-clean** (the planted maps live only in `tests/planted_truth.npz`, never under `/app/data`; `fixture_spec.json` is build-provenance only). Regenerable via `synth_build/generate_fixtures.py`.
- **allow_internet=false.** The task is self-contained (dependencies baked in the image; no network at run or verify time).
