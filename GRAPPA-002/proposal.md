## GRAPPA-002

**Proposal Title:** GRAPPA parallel-imaging reconstruction of a heterogeneous multi-coil cohort — an execution-hard reconstruction task (recipe divergence + coupled k-space bookkeeping + hidden robustness)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** MRI image reconstruction / parallel imaging

**Source paper:** Griswold et al. 2002, *Magn. Reson. Med.* (generalized autocalibrating partially parallel acquisitions / GRAPPA, https://doi.org/10.1002/mrm.10171). Dataset: a **paper-parameterized** accelerated multi-coil MRI cohort (Griswold 2002 GRAPPA signal model), generated deterministically at `synth_build/generate_fixtures.py`; the true physiology is held out for grading under `tests/planted_truth.npz` (the fully-sampled true coil-combined magnitude — RSS over the live coils of the clean full k-space; never under `environment/data`).

**Status: FULL runnable Harbor task.** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — the instruction names the deliverable (produce the coil-combined magnitude image per subject); the difficulty is *execution*, not an un-cued judgement. It follows the shape of the maintainer's `pcasl-cbf-quantifier`: the agent implements GRAPPA **from scratch** (no recon library bundled), over a **heterogeneous cohort where subjects need fundamentally different computations**, with a **declared robustness** requirement (realization hidden), graded per-pixel against the **held-out planted physiology** on a **convention-invariant** (median-normalised) magnitude.

### What changed in this revision (addressing the review of the recompute-and-grade design)

1. **Robustness contract made public.** `instruction.md` now states, under *Robustness / data-quality contract*, that (a) every R-1 missing-line offset must be reconstructed, (b) a majority of subjects carry grossly corrupted ACS lines that must be detected and rejected robustly (with the note that they hide below the legitimately-bright centre rows, so a global threshold fails), and (c) some subjects carry a dead noise-only channel that must be excluded from the fit and the RSS — only the *realization* (which subjects/lines/channels) is hidden. A correct implementation of the stated method is no longer penalized for failing to guess an undeclared step.
2. **Graded against the fully-sampled true image, not one fitter.** The verifier no longer recomputes a private GRAPPA reconstruction on the real data and demands agreement. It compares each submitted magnitude, per-pixel (median-normalised, over the object mask), to the **held-out planted target** = the fully-sampled true coil-combined magnitude (`tests/planted_truth.npz`, emitted by `synth_build/generate_fixtures.py`). That fully-sampled image is the convention-invariant physical truth; **any valid GRAPPA reconstruction** of the undersampled data recovers it up to residual aliasing, within tolerance. The hidden reference modules (`grappa_pipeline.py`, `grappa_ref.py`) were removed from `tests/`.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — the acceleration `R` varies (2, 3, 4), so a subject needs `R−1` **separate** shift-invariant kernel fits, one per missing phase-encode offset; a pipeline that assumes a single offset (the R=2 case) leaves six of eight subjects grossly aliased. The calibration kernel geometry is per-subject. A single fixed recipe cannot reconstruct the cohort.
2. **Coupled k-space bookkeeping** — placing the acquired undersampled lines on the full DC-centered grid, assembling the source/target neighbourhoods across all coils, fitting the kernel weights from the ACS by least squares, synthesising every missing line, `ifft2(ifftshift(·))` per coil, and root-sum-of-squares combination must **all** be assembled correctly; an error in any one produces coherent residual aliasing.
3. **Declared robustness, hidden realization (the decisive axis)** — six of eight subjects carry a pair of grossly motion-corrupted ACS lines that must be rejected before the least-squares kernel fit. The corrupt lines are planted in the low-energy transition zone of the ACS block, whose centre-of-k-space rows are legitimately ~9–16× brighter, so a **global** energy/z-score threshold cannot separate them (a loose cut deletes the bright legitimate centre rows → degenerate fit; a tight cut misses the edge spikes → aliased weights) and a single-shot "drop the worst row" leaves the second spike — only a **local-baseline, iterative** robust estimator works. Three subjects additionally have a dead (noise-only) receive channel that must be excluded from both the kernel fit and the RSS combination. The instruction now *declares* all of this; only the *realization* (which subjects/lines/channels) is hidden.
4. **Convention-invariant grading** — each image is normalised by its median over the object, removing the arbitrary receive-gain / DFT-normalisation scale, so the graded quantity is the spatial content (residual aliasing) alone; the fully-sampled true image and any valid GRAPPA reconstruction agree to within tolerance.

### Verifier

`tests/test_outputs.py` grades each subject's reconstruction **against the held-out planted physiology** (`tests/planted_truth.npz`; never under `/app/data`) = the fully-sampled true coil-combined magnitude, per subject and voxelwise over the object mask (**8 panels**, each its own test). Reward is **fractional** — the score is the fraction of subjects reconstructed correctly. A subject passes when ≥90% (`PASS_FRAC`) of object-mask pixels of the median-normalised magnitude agree with the true image within `TOL` = 0.10. The tolerance is unchanged from the original recompute-and-grade verifier; the target changed from a reference GRAPPA reconstruction on the real data to the fully-sampled true image. All reference modules were removed from `tests/`.

**Validity / discrimination evidence (recomputed for this revision).** The oracle recovers the fully-sampled true image on **all 8 subjects** (per-subject object-pixel agreement 0.97–1.00, comfortably above the 0.90 pass threshold; the object mask derived from the reconstruction equals the planted object mask exactly). Wrong pipelines each fail their own axis, graded through identical grading logic: **no ACS-line rejection** → 6 subjects fail (exactly the corrupted subjects, agreement 0.48–0.77); **dead channel kept in the fit + RSS** → 3 subjects fail (exactly the dead-coil subjects, agreement 0.16–0.21). So a from-scratch correct solver passes and each single-axis shortcut fails, on axes the instruction now *declares*.

### Notes / honesty

- **Reconstruction paradigm.** This task's difficulty is executional (assemble a coupled k-space reconstruction with no recipe), unlike the recognition-tier "un-cued judgement" tasks in this repo. `instruction.md` names the deliverable, the k-space/coil conventions, *and* the robustness contract, but never enumerates the *realization* (which subjects have which acceleration, which ACS lines are corrupt, which channels are dead) — the agent must discover it from the data.
- **Data.** Paper-parameterized, small, deterministic, and **leakage-clean** (the planted truth lives only in `tests/planted_truth.npz`, never under `/app/data`; verified by regen leaving `environment/data` byte-identical; `fixture_spec.json` is build-provenance only). Regenerable via `synth_build/generate_fixtures.py`.
- **allow_internet=false.** The task is self-contained (dependencies baked in the image; no network at run or verify time).
