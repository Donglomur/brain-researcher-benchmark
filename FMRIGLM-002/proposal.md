## FMRIGLM-002

**Proposal Title:** First-level fMRI GLM of a heterogeneous single-run cohort — an execution-hard reconstruction task (recipe divergence + coupled-inference assembly + declared robustness with hidden realization)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** Functional MRI analysis

**Source paper:** Friston et al. 1994, *Human Brain Mapping* (statistical parametric mapping / general linear model, https://doi.org/10.1002/hbm.460020402); Woolrich et al. 2001, *NeuroImage* (temporal-autocorrelation prewhitening for the fMRI GLM, https://doi.org/10.1006/nimg.2001.0931). Dataset: a **paper-parameterized** first-level fMRI cohort, generated deterministically at `synth_build/generate_fixtures.py`; the held-out grading target is under `tests/planted_truth.npz` (the pinned public first-level GLM computed on the actual BOLD, built by `synth_build/build_truth.py`).

**Status: FULL runnable Harbor task.** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — `instruction.md` names the deliverable (produce per-voxel task and modulation betas and t-statistics); the difficulty is *execution*, not an un-cued judgement. The agent builds a first-level GLM **from scratch** (no fitter bundled), over a **heterogeneous cohort where subjects need different designs**, with a **publicly-declared robustness** requirement (the realization — which frames/subjects — hidden), graded voxelwise against a **held-out pinned-method target** on **convention-invariant** effect sizes and inference.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — subjects need *different designs*, discoverable only from each events table and motion trace: **half** the subjects' events tables carry a `modulation` column (a parametric-modulation regressor must be added and its contrast reported) and half do **not** (that contrast is undefined and must be **omitted**); the task regressor of a modulation subject is estimated in the *augmented* design, so dropping the modulation column also biases the task beta. TR, run length, and event timing differ per subject, so the regressors must be rebuilt per run.
2. **Coupled-inference assembly** — the fixed-micro-grid (0.1 s) HRF convolution and frame sampling, the mean-centred (not standardised, not orthogonalised) parametric-modulation column, the 6 motion + degree-2 drift nuisance basis, the gross-spike detection, the pooled AR(1) Prais-Winsten prewhitening, and the GLS contrast inference (β and t) must **all** be assembled correctly, and an error in any one compounds.
3. **Declared robustness, hidden realization** — a majority of subjects (6 of 8) carry a few grossly motion-corrupted frames — a large framewise-displacement transient mirrored by a BOLD spike **not** captured by the 6 realignment parameters — that must be detected and modelled out (spike regression or censoring). This requirement is now **declared publicly** in `instruction.md` and `protocol.json`; only the realization (*which* frames/subjects) is hidden, and the betas and t-statistics are biased if they survive.
4. **Convention-invariant grading** — given the supplied HRF and the pinned design/prewhitening/inference conventions, β and t are uniquely determined by the data; two independent correct implementations compute them identically (measured below at 100% voxel agreement), so a from-scratch solver can pass while wrong pipelines fail — no reporting-convention ambiguity.

### What changed in this revision (addressing the review)

1. **Robustness contract made public.** The motion-spike step was previously undeclared — worse, `protocol.json` pinned the nuisance basis as "6 motion + degree-2 drift, no other expansions", which *contradicted* the reference's spike regression. `protocol.json` and `instruction.md` now declare, under *Robustness / data-quality contract*, that a minority of frames in a majority of runs are grossly motion-corrupted and must be detected and modelled out (spike regression or censoring), with only the realization (which frames/subjects) hidden. (This is a documentation change to `protocol.json`; the agent-visible signal arrays — BOLD, motion, events, mask, HRF — are byte-identical.)
2. **Graded against the held-out pinned-method target, not an in-verifier fitter.** The verifier no longer imports/runs a reference pipeline. It loads `tests/planted_truth.npz` — the value the fully-pinned, public first-level GLM produces on the actual BOLD, built once by `synth_build/build_truth.py`. Because a t-statistic is undefined on a noise-free signal and the GLS effect-size estimate carries an irreducible sampling error many times the tolerance, a noise-free "planted physiology" target is not well-posed here; the pinned-method value on the actual data is the well-posed, convention-invariant target (any correct implementation of the public spec recovers it — measured 100% below). The hidden reference modules (`glm_pipeline.py`, `glm_ref.py`) were removed from `tests/` (the oracle's copies remain under `solution/`).

### Verifier

`tests/test_outputs.py` grades **voxelwise** over the brain mask against `tests/planted_truth.npz`, one parametrized test per (subject × quantity) — **32 panels** (8 subjects × {beta_task, tstat_task, beta_mod, tstat_mod}). Reward is **binary**: pytest returns 0 only if all panels pass. A computable quantity passes when ≥90% of brain voxels agree within a per-quantity tolerance (beta rtol 5%/atol 0.6; tstat rtol 8%/atol 0.7); an unsupported quantity (the modulation contrast for a subject with no `modulation` column → key absent in the target) passes only when the submission **omits** it.

**Validity / discrimination evidence (recomputed for this revision).** The oracle recovers the target on **all 32 panels**. A genuinely-correct independent implementation (FFT convolution, an explicit Prais–Winsten whitening matrix, scipy linear algebra) reproduces every panel at **100% voxel agreement**, and an alternative valid robust scheme (frame **censoring** instead of spike regression) reproduces it at **≥95.8%** — confirming the target is convention-invariant across correct methods. The plausible-but-wrong pipelines each fail their own axis, measured through the real verifier: **no motion-spike modelling** fails **18 panels** (the 6 corrupted subjects' beta/tstat; the 2 clean subjects still pass); an **omit-rule violation** (forcing or dropping the modulation contrast) fails those panels; and (per prior measurement) no prewhitening, a re-normalised HRF, or no drift each bias their own axis. So any correct pinned-convention implementation passes and every shortcut fails.

Oracle **reward 1.0**, in-container (deterministic; oracle recovers all 32 target panels).

On the *previous* (hidden-contract) version, **gpt-5.6-sol (codex, xhigh)** scored **0.0** (k=1), solving 14/32 panels — failing the undeclared motion-spike modelling on the 6 corrupted subjects, the AR(1) Prais–Winsten prewhitening, and the parametric-modulation omit rule / augmented design.

### Notes / honesty

- **Reconstruction paradigm.** This task's difficulty is executional (get a hundred coupled design and inference decisions right with no recipe), unlike the recognition-tier "un-cued judgement" tasks in this repo. `instruction.md` names the deliverable and pins the conventions but never enumerates the pitfalls (the modulation fork, the corrupted frames, the per-run design rebuild) — the agent must discover them.
- **Data.** Paper-parameterized, small, deterministic, and **leakage-clean** (the held-out target lives only in `tests/planted_truth.npz`, never under `/app/data`). Regenerable via `synth_build/generate_fixtures.py` + `synth_build/build_truth.py`.
- **allow_internet=false.** The task is self-contained (dependencies baked in the image; no network at run or verify time).
