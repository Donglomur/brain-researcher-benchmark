## FMRILAG-002

**Proposal Title:** Hemodynamic-lag mapping of a resting-state BOLD cohort — an execution-hard reconstruction task (recipe divergence + coupled-physics assembly + declared robustness with hidden realization)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** Functional MRI / hemodynamics

**Source paper:** Tong & Frederick 2010, *NeuroImage* (global low-frequency oscillation lag, https://doi.org/10.1016/j.neuroimage.2010.06.049); Tong et al. 2019, *Front. Neurosci.* (systemic low-frequency hemodynamic "noise" in resting-state BOLD, https://doi.org/10.3389/fnins.2019.00787). Dataset: a **paper-parameterized** resting-state BOLD cohort (8 subjects, one run each, differing TR), generated deterministically at `synth_build/generate_fixtures.py`; the true physiology is held out for grading under `tests/planted_truth.npz` (the reference run on the noise-free, spike-free signal, built by `synth_build/build_truth.py`).

**Status: FULL runnable Harbor task.** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — the instruction names the deliverable (produce the per-voxel hemodynamic lag map, in seconds, NaN where not significant); the difficulty is *execution*, not an un-cued judgement. It follows the shape of the maintainer's `pcasl-cbf-quantifier`: the agent implements the lag estimator **from scratch** (no pipeline bundled), over a **heterogeneous cohort where subjects need fundamentally different computations**, with a **publicly-declared robustness** requirement (the realization hidden), graded voxelwise against the **planted physiology** on a **convention-invariant** quantity.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — the *reference signal* forks, and the fork is **not labelled**: on the clean subjects the whole-brain global mean faithfully tracks the shared low-frequency hemodynamic fluctuation and is the reference, but on the artifact subjects a high-amplitude non-neural fluctuation contaminates a band of non-gray-matter voxels and hijacks the global mean, so the reference must be restricted to gray matter. Neither uniform choice works — the global reference is wrong on the artifact subjects, and a gray-matter reference is systematically offset (deep white-matter / CSF arrive later) on the clean subjects — so the fork must be inferred by comparing the two candidate references.
2. **Coupled-physics assembly** — the reference must be built, the integer-frame lagged Pearson cross-correlation formed over the retained frames, its peak located, and that peak refined to sub-TR precision by **parabolic interpolation**, with the correct sign convention (positive where the voxel follows the reference); an error in any stage biases the map. Integer-only lag (no parabolic refinement) fails the tolerance.
3. **Declared robustness, hidden realization** — gross motion-spike frames (present on a *majority* of subjects) must be **censored** before building the reference *and* before the per-voxel cross-correlation, else the spikes — shared across the brain at zero relative lag — pull every voxel's lag toward zero. This requirement (like the reference fork and the significance-omit of noise-floor voxels) is now **declared publicly** in `instruction.md`; only the realization (*which* frames/subjects) is hidden.
4. **Convention-invariant grading** — the graded quantity (a lag in seconds relative to the pinned reference, and an omit partition) is fixed by the physiology; an ungraded band between the significant and noise-floor populations makes the exact threshold non-load-bearing, so two independent correct implementations agree — no reporting-convention ambiguity.

### What changed in this revision (addressing the review)

1. **Robustness contract made public.** `instruction.md` now states, under *Robustness / data-quality contract*, that a minority of frames in a majority of runs are grossly motion-spiked and must be censored before the cross-correlation (and restates the un-labelled reference fork and the noise-floor omit) — only the *realization* (which frames/subjects) is hidden. (Instruction-only change; the agent-visible data are byte-identical.)
2. **Graded against the true physiology, not one fitter.** The verifier no longer imports/runs a reference pipeline. It compares the submitted lag map to the **held-out planted target** (`tests/planted_truth.npz`, built by `synth_build/build_truth.py`): the **lag values** are the reference run on the **noise-free, spike-free** signal (measured relative to the same pinned reference — the convention-invariant physical truth for a lag-relative-to-reference), and the **gradeable / omit partition** is the planted structure (vascular voxels vs the dropout / artifact-following voxels). The partition cannot be read off a clean signal — a noise-free tiny-amplitude dropout voxel still correlates perfectly with the driver, so the omit status is intrinsically a noise/SNR phenomenon — so it is taken from the planted amplitude/artifact structure, which was measured to coincide exactly with the reference's noisy significance partition (the planted vascular set equals the reference rpeak≥0.55 set on every subject). The hidden reference modules (`fmrilag_pipeline.py`, `fmrilag_ref.py`) were removed from `tests/` (the oracle's copies remain under `solution/`).

### Verifier

`tests/test_outputs.py` grades **voxelwise** against `tests/planted_truth.npz`, one parametrized test per (subject × check) — **16 panels**. A **lag** panel requires the submitted lag to be finite and agree within 0.40 s with the planted lag over the gradeable (significantly-lagged, vascular) voxels; an **omit** panel requires the omit voxels (dropout / artifact-following) to be omitted (NaN) for ≥90% (subjects with < 12 omit voxels are not graded on omit). Reward is fractional over the 16 panels.

**Validity / discrimination evidence (recomputed for this revision).** The oracle recovers the planted target on **all 16 panels** (per-subject lag agreement 97–100% over the gradeable voxels; the fork decision on the clean signal matches the real data on every subject; 100% of the omit voxels correctly omitted). The plausible-but-wrong pipelines each fail their own axis, measured through the real verifier: **always the global reference** fails **8 panels** (the artifact subjects); **no spike censoring** fails **11 panels**; **no significance omit** fails **7 omit panels**; **integer-only lag** (no parabolic refinement) fails **8 lag panels**. So any valid estimator passes and every single-axis shortcut fails, on axes the instruction now declares.

### Notes / honesty

- **Reconstruction paradigm.** The difficulty is executional (infer the reference fork, censor spikes, build the cross-correlation and refine its peak, and omit the insignificant voxels — with no bundled pipeline), unlike the recognition-tier "un-cued judgement" tasks in this repo. `instruction.md` names the deliverable and conventions but never enumerates the pitfalls (the reference fork, the spike census, the significance omit) — the agent must discover them from the data.
- **Data.** Paper-parameterized, small, deterministic, and **leakage-clean** (the held-out planted truth lives only in `tests/planted_truth.npz`, never under `/app/data`). Regenerable via `synth_build/generate_fixtures.py` + `synth_build/build_truth.py`.
- **allow_internet=false.** The task is self-contained (dependencies baked in the image; no network at run or verify time).
