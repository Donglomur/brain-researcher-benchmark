## GLUCOCEST-002

**Proposal Title:** Dynamic glucose-enhanced (DGE) CEST quantification of a heterogeneous cohort — an execution-hard reconstruction task (recipe divergence + coupled-physics assembly + hidden robustness)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** Molecular MRI / chemical-exchange saturation transfer (CEST)

**Source paper:** Walker-Samuel et al. 2013, *Nature Medicine* (glucoCEST, https://doi.org/10.1038/nm.3252); Xu et al. 2015, *Tomography* (dynamic glucose-enhanced / DGE MRI); Kim et al. 2009, *MRM* (WASSR B0 correction of CEST Z-spectra, https://doi.org/10.1002/mrm.21873). Dataset: a **paper-parameterized** dynamic Z-spectrum time-series cohort (Walker-Samuel 2013 / Xu 2015 signal model), generated deterministically at `synth_build/generate_fixtures.py`; the true physiology is held out for grading under `tests/planted_truth.npz` (the reference run on the noise-free / drift-free / motion-free signal, built by `synth_build/build_truth.py`; never under `environment/data`).

**Status: FULL runnable Harbor task.** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — the instruction names the deliverable (produce the dynamic glucoCEST AUC and initial uptake rate maps); the difficulty is *execution*. The agent implements the DGE-CEST quantification **from scratch** (no reconstruction library is bundled), over a **heterogeneous cohort of Z-spectrum time series where subjects need fundamentally different handling**, with a **declared robustness** requirement (realization hidden), graded voxelwise against the **held-out planted physiology** on **convention-invariant** (temporal-difference) quantities.

### What changed in this revision (addressing the review of the recompute-and-grade design)

1. **Robustness contract made public.** `instruction.md` now states, under *Robustness / data-quality contract*, that (a) the scanner frequency drifts across the series and must be tracked and removed per timepoint, (b) a minority of dynamic frames are grossly motion-corrupted and must be detected and rejected robustly, and (c) the pre-infusion baseline TREND (not a constant) must be removed — only the *realization* (which subjects/frames) is hidden. A correct implementation of the stated model is no longer penalized for failing to guess an undeclared step.
2. **Graded against the true physiology, not one fitter.** The verifier no longer recomputes with a private pipeline on the real data and demands agreement. It compares each submitted map, voxelwise, to the **held-out planted target** = the dynamic-glucoCEST reference run on the **noise-free, drift-free, motion-free** signal (`tests/planted_truth.npz`, built by `synth_build/build_truth.py`). That target is the convention-invariant physical truth; **any valid estimator** applied to the real data recovers it within tolerance. The hidden reference modules (`glucocest_pipeline.py`, `glucocest_ref.py`) were removed from `tests/`.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — subjects need *different handling*, discoverable only from the data: the scanner centre frequency **drifts** over the dynamic series on a *majority* of subjects, so the whole Z-spectrum slides along the offset axis with time and must be re-referenced to the water resonance **per timepoint** (a single static B0 correction reads the drift as spurious glucose uptake); some subjects have a **drifting pre-infusion baseline** whose trend must be removed (a constant-mean baseline leaves the drift as false enhancement); a couple of subjects have too few post-infusion dynamics for the initial uptake rate to be determinable, so the rate map must be **omitted** (like a water-reference-absent absolute concentration).
2. **Coupled-physics assembly** — the per-timepoint water referencing, the glucose-band CEST integral on the corrected axis, the gross-frame rejection, the baseline detrend, and the AUC / OLS-slope must **all** be assembled correctly; an error in any one compounds.
3. **Declared robustness, hidden realization** — a minority of subjects carry one or two grossly **motion-corrupted** post-infusion dynamic frames whose glucose-band signal is a gross temporal outlier that must be rejected and repaired (temporal interpolation) *before* the AUC and rate, not integrated. The instruction now *declares* this (and the drift / baseline-trend requirements); only the *realization* (which subjects/frames) is hidden.
4. **Convention-invariant grading** — the graded quantities are **dynamic** (a temporal difference of the glucose-band integral), so the per-voxel static water-dip / interpolation bias cancels and the AUC / rate are convention-invariant; the noise-free planted target and any valid estimator on the real data compute them identically within tolerance.

### Verifier

`tests/test_outputs.py` grades each submitted map **against the held-out planted physiology** (`tests/planted_truth.npz`; never under `/app/data`) — **voxelwise** over the brain mask, one parametrized test per (subject × map) panel, 16 panels in all. A computable map passes when ≥90% (`PASS_FRAC`) of brain voxels match the planted value within a per-map tolerance (auc rtol 12%/atol 0.010 ppm·min; rate rtol 15%/atol 0.0010 ppm/min); an unsupported map (rate for a short post-infusion series) passes only when the submission **omits** it. The gate delivers a binary reward (all panels pass → 1.0). The tolerances are unchanged from the original recompute-and-grade verifier; the target changed from a reference fit on the real data to the reference on the noise-free/drift-free/motion-free signal. All reference modules were removed from `tests/`.

**Validity / discrimination evidence (recomputed for this revision).** The oracle recovers the planted target on **all 16 panels** (14 computable at 100% voxel agreement, median per-voxel relative error 4–7%; 2 correctly omitted rate panels) — comfortably inside tolerance. Wrong pipelines each fail their own axis, graded through identical grading logic: **single static B0 / no per-timepoint drift tracking** → 5 panels fail (exactly the drift subjects); **no motion-frame rejection** → 4 panels fail (exactly the motion subjects); **constant-mean baseline instead of the fitted trend** → 4 panels fail (exactly the baseline-drift subjects); **rate computed everywhere (no omit)** → 2 panels fail (the short-series subjects). So a from-scratch correct solver passes and each single-axis shortcut fails, on axes the instruction now *declares*.

### Notes / honesty

- **Reconstruction paradigm.** The difficulty is executional, unlike the recognition-tier "un-cued judgement" tasks in this repo. `instruction.md` names the deliverable, the physics conventions, *and* the robustness contract, but never enumerates the *realization* (which subjects drift, which frames are corrupted, which subjects have a short series) — the agent must discover it from the data.
- **Data.** Paper-parameterized, small, deterministic, and **leakage-clean** (the planted truth lives only in `tests/planted_truth.npz`, never under `/app/data`; verified by regen leaving `environment/data` byte-identical). Regenerable via `synth_build/generate_fixtures.py` + `synth_build/build_truth.py`.
- **allow_internet=false.** The task is self-contained (dependencies baked in the image; no network at run or verify time).
