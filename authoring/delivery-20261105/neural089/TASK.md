# NEURAL-089: 2025 phoneme decoding from listening MEG

Predict 39-class phoneme probabilities from 0–0.5-second MEG windows after supplied phoneme onsets. This is the original single-person LibriBrain phoneme task, with a strict target-free interface and complete query coverage. It is not the 2026 50-word/top-10 task, continuous unsegmented speech recognition, or an across-person benchmark.

The source is [LibriBrain (2025)](https://arxiv.org/abs/2506.02098), using [pnpl/LibriBrain](https://huggingface.co/datasets/pnpl/LibriBrain) at exact revision `5a7c332b34fc7be329c4df3e527a41f67bfd878f`, PNPL code `33aff3fd70a197a47f73a06cb5d1e6b0e1cbfb9b`, and experiments code `08e4d8feedf458c8b68e14472d4885a9e951c4dc`. The archive/code snapshot was inspected in 2026; task semantics are explicitly the 2025 phoneme edition. No mutable remote constants are fetched at preparation or scoring time. Classes and their exact zero-based order are in classes.json; they are the pinned 39-label PHONEME_LABELS_SORTED constant. Official phoneme_1 corresponds to class index0.

## Biological unit and exact split

There is one source participant, subject0. The frozen manifest has 90 original Sherlock recording runs. Training comprises the 88 keys other than validation `('0','11','Sherlock1','2')` and query/test `('0','12','Sherlock1','2')`. These are the native explicit run keys from the official 2025 configuration. All events from a run stay in one partition; no random phoneme-window split is used. Session identifiers are scoped by task/run. This native split is not asserted to hold out every physical session across all stories, all stimulus chapters, or other people. Repeated story/chapter or session structure can remain; no unseen-stimulus claim is made.

The provided validation partition is development data and has labels. It can be used for method choice before final prediction, but all fitted normalization statistics and estimator fitting must use training data only under this version. Do not refit on validation or use query distribution statistics, query labels, transcripts, original annotations, audio, word timing/duration/context fields or source identity lookup. Fix the method before query access. The supplied baseline uses only training and no validation selection. This package provides files and a static scorer, not a process-isolation attestation.

## Window construction and inputs

Use every event whose kind is phoneme, excluding exact segments sil and oov_S. Strip the suffix at the first underscore and map the base label to the fixed39 classes. Unknown target labels cause preparation failure. Use `start=int(timemeg*250)` and exactly125 samples, all306 channels in the verified channel_schema.json order. Nonfinite/negative onsets, out-of-bounds windows, nonfinite neural values, missing runs and schema mismatches fail preparation; no silent row/run omission, padding, class-based downsampling or truncated query set is allowed. These strict failures strengthen the legacy loader's permissive skip/clamp behavior.

Original continuous files must have data shaped channels×time, times from zero at250Hz within stored-float rounding, and the exact channel names/types. A real pinned training recording has verified this layout and all5996 target windows' bounds; neural values were not decoded for that inspection. Every other recording is checked independently at preparation. Broad/LibriBrain2 reduced-time-origin files are outside this original2025 manifest.

The operator pools population channel means and standard deviations across every continuous sample of the88 training runs, using a streaming stable moment calculation. Those same training statistics transform all partitions. Divide by positive training standard deviations and clip at±10; zero-variance/nonfinite training channels fail. No source file or cached HDF5 attribute is modified. Each output is float32, shaped windows×306×125, in training-channel-standard-deviation units. This preserves train-only normalization policy; source floating-point/storage differences can prevent bitwise author-pipeline parity.

Each opaque run HDF5 exposes only windows and24-character opaque ids. Training/validation also expose integer labels0..38. Query HDF5 has no labels, transcript, events, time coordinates, original run names or source attributes. inputs.json supplies safe relative file pins and partition/group IDs; panel.json lists every query ID. IDs use an operator-private32-byte HMAC key and event row identity, then sort within run; lexical order carries no declared class order. The original labeled events and private provenance never enter candidate inputs. The task provides event-aligned windows, so detection of phoneme onsets itself is not evaluated.

## Submission and score

Submit UTF-8 JSON with exactly schema_version=1, task_id='NEURAL-089' and predictions. Each prediction contains exactly query_id and probabilities:39 finite numeric values in frozen class order, each in[0,1], summing to1 within absolute1e-6. Supply every panel ID once, in any order. No duplicate keys/IDs, unknown/missing IDs, booleans, NaN/Infinity or extra fields. Maximum200,000 queries and256,000,000 bytes; limits fail rather than select a subset. See prediction.schema.json. Raw JSON schema integer semantics are supplemented by strict lexical integer checking in the scorer.

The primary metric is the mean F1 over all39 fixed classes, matching the pinned official2025 diagnostic scorer. Argmax chooses the lowest class index on a tie. For each class, precision/recall denominators of zero produce0; F1 is0 when precision+recall is0. Absent classes therefore remain in the39-class denominator. Accuracy is reported separately, with per-class support/precision/recall/F1 and the full39×39 confusion matrix. There is no combined reward or scientific-success threshold. Weak or confidently wrong valid predictions receive their actual continuous scores. These metrics are compatible with the official diagnostic definitions; the JSON/ID/privacy boundary is this package's stricter interface, not the original CSV frontend or an assertion of online-competition comparability.

## Fixed baseline and limitations

baseline.py implements a prospective streaming comparator, not the published CNN. Average five consecutive25-sample bins per channel, flatten to1530 features, fit StandardScaler only on training batches, then fit SGDClassifier(log_loss,L2,alpha=1e-4,learning_rate=optimal,random_state=89,shuffle=False,average=False) for exactly five passes over all training batches. Each update receives all39 class IDs; batch size128. Parameters are fixed, with no search, validation fitting or query calibration. Prepared channel normalization is also training-only. Generated tests mock the estimator; no actual training or empirical scoring has occurred.

Observations and annotations are historically public, and source preprocessing was already applied upstream. The single participant supplies no across-person replication. Overlapping windows within a run are dependent; do not treat phoneme trials as independent biological units. Data are CC-BY-NC-4.0 and author code BSD-3-Clause. No TIMIT/MOCHA audio, pretrained checkpoint or third-party stimulus is included. Acquisition and full packet preparation remain separate from source construction; only one training recording's structural/timing check has actually been performed.
