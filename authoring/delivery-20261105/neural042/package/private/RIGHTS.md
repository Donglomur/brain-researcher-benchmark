# Attribution and distribution boundary

Official DANDI metadata identifies CC-BY-4.0 for the dataset. Attribute Daume et al.
and the exact DANDI snapshot. This export includes no NWB recordings or stimuli.
The pinned repository root is BSD-3-Clause; included EEGLAB FIR helpers preserve
their embedded GPL-v2-or-later notices. Treat the prospective pac.py filter
implementation as GPL-v2-or-later-compatible derivative source when distributing
it together with those helpers; do not flatten third-party notices into the
repository root license. Official source bytes are retained unchanged.

Original author source and transport pins are provenance, not benchmark answers.
The opaque source archive contains small author example masks; it is retained
outside the export and must not be supplied to a candidate. Future clinical masks,
ID mapping, private gold and exclusion records are operator-only. Actual data
redistribution and consent/attribution obligations must be reviewed before a
public release; local construction is not publication approval.
