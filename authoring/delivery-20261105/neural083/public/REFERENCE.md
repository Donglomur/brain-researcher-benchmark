# Independent unexecuted probability reference

The exact native driver and helper source are preserved under private/source/official, with original byte/Git blob pins. MATLAB source uses100Hz resampling, causal order5 Butterworth8–30Hz,20 fixed channel indices, inclusive1000–3500ms segmentation, pooled class covariance CSP, two end eigenvectors from each side, sample logvariance and BBCI automatic shrinkageLDA. Its output is an uncalibrated signed decision, then accuracy. GPLv3 text belongs to the GigaScience subtree; LoadData README supplies MIT text for that subtree. Other helper/third-party terms must be respected, not relicensed wholesale.

The new reference is a prospective independent implementation, not an exact reproduction. Source preprocessing counterpart uses SciPy rather than MATLAB; channel/onset/class bindings remain unobserved beyond one MAT header. CSP explicitly solves `eigh(C_right, C_left+C_right + 1e-6*trace(C_left+C_right)/20 * I)`, with class pooled sample covariance and four ordered extreme eigenvectors. The scale-relative ridge and explicit eigenvalue ordering are new. Logvariance uses ddof1 along251 samples; zero/nonfinite variances fail. Context uses training-only feature mean/SD (zero SD→1), with no CSP. LDA uses sklearn solverlsqr, shrinkageauto, equal priors. This differs from the native BBCI shrinkage formula; no native-score parity is asserted.

For a nonzero calibration allowance the reference uses exactly the20 or100 supplied target calibration examples; the unused permitted donor data remain available to other candidates. At zero calibration it uses all10600 donor examples. Five-fold out-of-fold scores are formed by original allowed-calibration trialindex modulo5, or original donor-person indexminus1 modulo5 when using donors, preserving whole donor people. These training-only fold labels are supplied in the packet; changing opaque-ID keys cannot change them. Every CSP/LDA fit occurs within its training fold; held query features/labels never tune weights or probability mapping. Fit a logistic map to all out-of-fold scores (C1,lbfgs,max_iter1000,seed83083), then refit the readout on all permitted reference-training examples and apply the fixed map to query scores. No post-query fitting is allowed.

If permitted reference-training labels have one class, or an inner fold is empty/has fewer than2 examples of a class, return the fixed smoothed class prior `(n_right+.5)/(n+1)` for every query. This deterministic fallback does not acquire replacement labels or conceal support failures. Numerical fitting errors abstain. PERMUTED_EEG uses the same procedure and budget with supplied permuted labels; CONTEXT uses the same labeled rows and calibration policy. Unexecuted code is not evidence of competent performance or calibrated probability quality.

Actual environment installation, fit convergence, MATLAB comparison, CPU/memory timings and empirical results remain pending. Generated controls use test doubles, never fit these models.
