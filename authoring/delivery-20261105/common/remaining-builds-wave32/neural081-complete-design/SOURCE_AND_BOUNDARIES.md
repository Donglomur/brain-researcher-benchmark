## Exact event-type policy

Read the full processed marker table operator-side as finite integer triples. Require chronological sample order, finite legal recording extent and original first_samp. No marker channel is copied to candidate EEG. First form the complete trial roster independent of any window validity or feedback outcome; select exactly c*10+4 for each of the twelve declared c. An unknown apparent condition4 code is a full-source error, not an omitted class.

Recognized processed events:

* c*10+d for declared c and d in{1,2,3,4}: physical trial onsets after the author's raw-trigger/label match; d4 provides the target roster.
* 1000: physical audio-onset marker;1111: physical noise-trial onset.
* 2000/2001: self-report feedback labels with **nonphysical pseudo-times** in this importer. Do not use them for crop geometry, validity, target choice, predictor input, trial retention, or response/condition filtering.
* Unmatched1001/1002/1003 raw trial-start codes and any other unknown event type: unresolved annotation support. Refuse complete preparation pending a separately reviewed source correction; do not silently treat them as valid missing-label trials or generic harmless markers.

The author importer uses approximate log timestamps to find class labels, then replaces physical onset-marker labels in a second pass. For feedback keystrokes it explicitly uses the previous log event's time plus one sample, because the key log has no timestamp. Therefore old prepare.py's “any next event before crop end” test is scientifically incorrect. Ignoring feedback for geometry is not dropping an EEG trial or asserting when the participant actually responded.

For each selected physical onset s, require [s+256,s+2304) fully within recorded sample extent. Check **all genuine physical trial/audio/noise onsets** after s and before the exclusive crop end; any such competing onset blocks complete preparation. A physical marker exactly at crop end does not overlap. Multiple incompatible physical events at s are ambiguous and block the complete source. Coincident feedback pseudo-events are recorded privately but are not evidence of a physical collision. A feedback event cannot rescue a bad physical crop.

This type-aware test is necessary but not a proof of actual acoustic absence or exact mental-state timing. An audio onset before s could in principle have a later offset, and the processed table does not by itself supply all physical offsets. The future source/annotation qualification must join the original Block2 timing protocol, version-specific stimulus durations, physical marker history and any available valid original timing evidence. It must state whether the actually executed stimulus program is known. The held presentation script has apparent transcription errors; it is protocol evidence, not an authenticated executable replay. Do not fabricate audio offsets from feedback pseudo-times or from current query EEG. If complete valid imagery-window support cannot be established, keep the task unqualified rather than omitting cases or asserting verified no-concurrent-audio.

The benchmark's unconditional descriptive target is the source-annotated instructed excerpt. Even after qualification, source-protocol absence of concurrent playback is not a causal claim about pure imagined content: named-cue memory and earlier listening remain possible signal sources. No candidate or grader may infer actual introspective compliance from target accuracy.
