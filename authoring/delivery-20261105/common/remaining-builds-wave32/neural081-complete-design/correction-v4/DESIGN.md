# Complete NEURAL-081 scientific design, successor V4

This design concerns the existing OpenMIIR condition-4 task. It is source construction for review. It does not qualify inputs, an environment, references, a candidate, provider access, paid execution or submission readiness. Implementation requires root adoption after sole independent review.

## Scientific question and estimand

Can a model use the complete fixed EEG representation to identify the instructed excerpt in a person absent from its labelled training set? Compare (F) a data-free-authored frozen prediction program and (I) an LLM that investigates each current query using the same training information, frozen trained tools and Python. I's analysis is allowed to depend on that current EEG; ending it before the query would test a different question. Both modes explicitly have single-query transductive access: they may fit temporary statistics/models using the nine-person labelled training set plus exactly one unlabeled current query. The held person is absent from labelled training, but its one waveform may participate in adaptation. This is not a strictly inductive candidate protocol.

The primary measure is equal-person, equal-class balanced accuracy in the EEG view. It is a closed-set 12-class, ten-person benchmark. Repeated trials for a person never cross the outer boundary. All classes occur in training people; this is not unseen-excerpt generalization. The labels are instructed excerpts, not verified mental contents. Lyrics/no-lyrics classes are distinct excerpts, not twelve distinct melodies.

Full support is P01,P04,P05,P06,P07,P09,P11,P12,P13,P14; class column order is1,2,3,4,11,12,13,14,21,22,23,24. Use every processed condition-4 trial in all ten exact released FIFs. Each person must have all twelve classes. Let n_p be its verified count and N=sum n_p. The existing bounds12≤n_p≤10,000 are retained as admission limits, not observations. N=600 remains an explicitly unverified source-comment illustration. A bad event/channel/file/class invalidates complete preparation; it never authorizes deleting an inconvenient observation.

## Frozen measurement

Source rate must be512Hz, not an assumed conversion of unknown headers. From each processed physical trial onset s, read the declared64 EEG channels at relative samples[s+256,s+2304), exactly64×2048 values in volts. For each sample subtract the mean of those64 channels in binary64; average each nonoverlapping four-sample block; cast once to finite float32, yielding64×512 at128Hz. No outside-window padding, class-dependent duration, added ICA, interpolation, adaptive filtering, mastoid referencing or whole-session fitting. Four-point averaging is a specified representation, not ideal antialias filtering or unchanged raw-waveform sampling.

All64 canonical channel names and order come from the exact old PROTOCOL. Retain channels even if flagged bad; do not interpolate or drop them. Record complete bad flags privately and report flag prevalence only after closure. If the release lacks one of these64 EEG channels, supplies active projections, has nonfinite required samples, or cannot be represented in float32, full preparation refuses. The task measures this supplied representation, with whatever authenticated upstream filtering/resampling history is present. An unknown upstream transform remains a lineage gate; it is not silently described as clean raw EEG.

Processed labels differ from raw hardware values. Condition4 is Block-2 imagination after author event matching; raw marker4 means noise. Follow SOURCE_AND_BOUNDARIES.md, including the known untimed-feedback defect. No outcome, self-report, EEG amplitude, prediction quality or elapsed compute selects trials.

## Views, folds and complete repetitions

There are ten outer held-person folds, two views and three author replications r0,r1,r2. EEG uses the full defined waveform. ZERO replaces every training and query waveform value by positive binary32 zero, retaining only the permitted structure/labels. ZERO cannot mount EEG data, fitted models, outputs or transcripts. Neither view exposes song names, timings, event/feedback channels, filenames, source order or query-class counts.

Training includes all nine other people, their labels, and opaque person groups for grouped selection. Queries are delivered individually, never as the full held-person batch to candidates. Operators and frozen references may hold complete batches under separate authority; candidates cannot. Candidate/public records use the exact sanitized projection in CANDIDATE_PROJECTION.md; full source/person/authority/clock records never enter candidate space. Reference numerical training rows use the label-independent opaque order in REFERENCE_MATHEMATICS.md.

The same underlying trial has private canonical identity, with context-specific32-hex aliases to prevent public joins between views/modes/replications. Full exact mapping and support remain operator-side.

Reference families and train-only choices are sealed before any candidate query exposure. F has three data-free source-author episodes total. I has6N fresh author/investigation episodes, one per current trial/view/replication. F has6N separate query executions of its frozen source. Equal input information and numerical operation classes do not imply equal LLM-author timing or equal context counts. EXPOSURE_AND_WORKLOAD.md fixes the exact distinctions.

All nine inner held-training-person splits are used in each outer fold/view. Parameter selection uses only inner training-person predictions. All three selected families are refit; a training-only temperature scan and strongest-family choice are retained. The original fixed bandpower/auto-LDA baseline is separately executed without the new calibration. Uniform and Laplace training-prior comparators are explicit.

These fixed reference definitions remain inductive: their fitted statistics, settings and temperatures use only the permitted training people. Candidates have broader single-query adaptation rights. Beating an inductive reference is an endpoint improvement under that broader access, not a reasoning-only attribution or a matched-inductive-method claim. The matched F/I contrast addresses the timing/form of investigation with separately reported author/provider costs.

This retains3,680 matrix-model fits, but the full design adds20 explicit selection/calibration/analytic-comparator workers and one protected grading worker to the earlier selection-level process estimate. It never conceals these operations inside a zero-cost word “baseline.” For these fixed references, feature extraction is deterministic and trial-local and learned statistics remain inside each training role. Candidate scratch adaptation follows the broader V4 access contract. Reference state reuse across queries/modes is readonly and accounted for, not a new fit per query.

Empirical competence is unestablished. Correct implementation, full support and numerical qualification are requirements independent of whether the methods outperform priors. A poor reference or a candidate below chance remains a reportable negative outcome. Calling a method SOTA or a candidate's improvement scientifically substantive requires external empirical evidence; it cannot follow from source acceptance or a favorable outcome gate.

## Measurement, comparisons and uncertainty

For each person, class recall is correct/n_class; average the twelve recalls, then average ten people. Prediction ties use the first class in the declared order. Secondary log loss averages trials within person then ten people, using max(p_true,1e-12) only inside the logarithm. No row renormalization. Probabilities must be nonboolean finite numbers in[0,1], with math.fsum within1e-6 of1. Any missing/reordered/duplicate case or malformed row invalidates that complete submission; no surviving-fold mean is a full result.

Report all ten people, all twelve class recalls/confusion rows, all three replications, both modes and both views. The headline F and I values are the mean of their three complete replication scalars; retain those scalars rather than presenting only a favorable replicate. The paired mode contrast is mean_r mean_p(BA_I,r,p - BA_F,r,p) in EEG. Report analogous ZERO and within-method EEG-minus-ZERO contrasts and each fixed family/historical/prior result. The strongest reference identity is chosen using the actual calibrated OOF probability BA/NLL on training validation before queries, never from test results. Positive temperature is not claimed to preserve binary64 argmax under rounded ties. Exact metric reductions are in REFERENCE_MATHEMATICS.md.

Biological n is10, not trial count, execution count or3replications. Training sets overlap across LOPO folds. Report the complete finite-cohort per-person distribution and leave-one-person-out *aggregation sensitivity* of already-computed person scores (no retraining), plus the three-author-replication range and sample standard deviation. Do not label these as independent-population confidence intervals. No iid-trial significance test, naive ten-fold standard error, sign-flip p-value or post-hoc winner test is selected. Future population-inference work needs a separately justified design and independent biological evidence; this benchmark's default comparison is descriptive on its fixed cohort.

Record the five-person stimulus-version strata, but they are not randomized groups. A difference between independently selected strongest families across views compares selected procedures, not a pure marginal causal EEG effect. The ZERO view tests signal-access and pipeline information, not removal of ocular activity, movement, cue memory or earlier perception. A named visual instruction precedes imagery; instructional compliance is unverified. Thus successful decoding means predictive information about the instructed class in the supplied EEG under this protocol, not pure auditory imagination, causal neural understanding, unfamiliar-melody recognition, clinical validity or model-unexposed knowledge.
