# Complete support without alternate assessment-label exposure

The V3 label-free custody repair is retained in V4. It supersedes any V1/V2 wording that treated the full support_v1 as ordinary pre-grade operator metadata. Operator-only is not equivalent to target-safe: support_v1 includes private_label for every trial and is itself a protected assessment-label-bearing object. Its body is accessible only to separately admitted trusted G0 preparation and protected G5 grading. No pre-grade campaign controller, outer observer, access validator, projection verifier or generic source/hash helper may open it. The same rule applies to any alias or alternate serialization containing that complete label map.

## Trusted issuer and exact label-free index

G0 reads original label-bearing sources under its explicit upstream preparation authority. It constructs and validates the complete support_v1 and separate assessment_target, verifies exact canonical row/label equality, issues the legitimate isolated training-label views, and constructs support_index_v3. These real trusted annotation reads are logged and charged; the task never claims no label access anywhere.

support_index_v3 has exactly schema, task_id, preparation_generation, protocol_source, source_inventory_descriptors, people, class_ids, canonical_channels, rows, protected_support_descriptor, protected_assessment_descriptor, preparation_closure and support_disposition. schema is neural081_label_free_support_index_v3. Source inventory entries are descriptors only; embedded original events/annotations are forbidden. The public protocol class_ids list is fixed and does not encode each row's class. people/channels follow the original full cohort/protocol; this whole index is still operator-only, not a candidate mount.

Each row has exactly person, canonical_id, source_event_index, source_onset_sample, processed_condition, source_file_descriptor, window_descriptor and physical_boundary_disposition. processed_condition is the selected condition4, never the combined class/condition event code. physical_boundary_disposition is a source-owned status enum and an optional descriptor to protected original evidence, never event-table/feedback/label values embedded as narrative. The rows contain no private_label, class-specific event code, self-report, class-count vector, label-dependent order, per-row class checksum or original annotation body. They are ordered by fixed PEOPLE then canonical_id and contain every selected trial once. Original identifiers/timing remain operator-private and are absent from CANDIDATE_PROJECTION.

support_disposition states whether the complete source-owned preparation/support checks passed; it can assert required class support was validated privately but does not publish per-row labels or class-specific counts. This is trusted preparer evidence with exact source/generation/closure, not independent pre-grade recomputation of hidden labels. All runtime pre-grade code must reject extra/unknown fields instead of recursively accepting arbitrary metadata strings that might contain a copied target. Exact schema checks plus qualified immutable physical role custody are required; a field-name blacklist is not the sole protection.

The protected descriptors contain only canonical protected path, exact bytes and SHA256, plus their role in the enclosing typed schema. They are issued after G0 durably seals the bodies. Pre-grade components authenticate the issuing source/receipt/index and use those descriptor identities without opening/hash-reading the protected operands. No claimed SHA equality check is allowed to secretly read a target body. Physical alias/mount/inode/namespace immutability must be qualified independently; source-only descriptor pins do not establish it.

## Training labels remain legitimate, isolated inputs

G0 creates exact outer-training9-person and inner-training8-person/validation1-person views as required by the mathematical graph. Each role's source-bound receipt joins its identity set to the label-free complete index, records its permitted biological people, and binds the exact EEG/label/group bodies. G0 establishes label correctness against the protected source; native role users validate complete allowed identity/shape/class support and that receipt under their own authority, not by opening the global protected support.

A candidate sees only its nine-person training labels through the sanitized mounted view, plus one unlabeled query. A reference fit sees only its specified training labels; inner selection may read its nine training people's validation labels. A pre-grade controller/observer transports descriptors and validates closed artifacts/role identities without opening numeric label bodies. Access validators inspect source/role metadata and original action/closure evidence, not extra global/other-fold label maps; no statistical-semantic review is selected. The union of differently authorized training roles is not a new candidate or controller grant to all assessment labels. Cross-context writable state/label feedback remains forbidden.

## Global barrier and final protected read

G4 independently validates complete N identities through support_index_v3, all required producer/model/action/source/access closures and all240 final panels before issuing G5 authority. It can check coverage/group/view/shape/lineage without knowing each query class. Missing class support or annotation correctness remains a G0 source gate and is independently confirmed in G5, not inferred from prediction counts.

Only after this full barrier may G5 open support_v1 and assessment_target, join both to the exact protected descriptors/generation and the label-free index, independently verify every row/label equality and full class support, and compute the frozen metrics. No candidate resumes or receives feedback. A mismatch fails the complete study; it does not permit recomputing a subset or quietly replacing the labels. Final whole-controller natural-exit and artifact closure still follow G5 as already specified.

Future source controls must use target sentinels for both protected bodies and alternate-label aliases, prove every pre-grade lineage path consumes only the label-free index/descriptors, test unknown-field/combined-event-code rejection, and retain legitimate role-specific training label access. No such fixture or authentic read occurs in this design correction.
