# Candidate-only projection and private operator joins

This retains the V2/V3 projection schemas under the V4 access boundary for both F and current-query I. Full support/context/model/selection/authority/producer records in INTERFACES_AND_REVIEW_GATES.md are operator-only. Candidate access consists only of the exact projected objects below, permitted numerical bodies, generic source-owned inference tools and its own episode scratch. This is access minimization, not a claim that allowed EEG/model data cannot reveal biological identity statistically.

## Public context

`candidate_context_v4` has exactly schema, task_id, access_policy, mode, replication, view, context_alias, class_ids, representation, query, training, models, tools and remaining. schema is `neural081_candidate_context_v4`; task_id NEURAL-081; access_policy is exactly `single_query_transductive_v4`; mode F or I; replication r0/r1/r2; view EEG or ZERO; alias is the current context-specific32hex token. No global query index, canonical ID, held-person name, total held-person row count, event timestamp, source filename or source-order field is present.

representation is exactly `{dtype:'float32',shape:[64,512],sample_rate_hz:128,units:'V',channels:<the fixed64 canonical names>}`. query is exactly `{path:'/input/query.npy',row_alias:<same context_alias>}` and resolves to that one numerical row. training is exactly `{eeg_path:'/input/train.npy',labels_path:'/input/train_labels.npy',rows_path:'/input/train_rows.json',shape:[n_train,64,512]}`. Training EEG/labels cover all permitted nine people and classes; n_train is allowed training information, not a hidden query-count field. train_rows is an ordered list of exact `{row_alias,group_alias}` records with32hex aliases; labels are exact canonical class IDs in the aligned label array. It has exactly nine group tokens. No original person identifier or source event index is serialized. Array dtypes/shapes and complete bijections are privately validated before mounts.

For each context the issuer derives training row/group aliases through separate truncated-HMAC domains, respectively `NEURAL081-training-row-v2|generation|context_alias|canonical_id` and `NEURAL081-training-group-v2|generation|context_alias|person`. The same fixed private identity mechanism/key is used; delimiter-containing fields and collisions refuse. Sort the row aliases lexicographically and apply that permutation consistently to EEG, labels and public row metadata. Group handles preserve only the legitimate grouping relation. The alias list and its exact canonical private inverse are retained under operator custody. The identity key/body and original names are never mounted. No outcome or waveform value controls the order. Class/channel/feature axes keep their declared canonical order.

models is a four-entry ordered list of model handles BP_LDA, TM_LDA, RBF_KRR, HISTORICAL_BP_LDA, each paired with the generic path `/models/<handle>/model.json`. The strongest-family handle, uniform probabilities and training Laplace prior appear in the public model metadata described below; they are legitimate training-derived information. tools is exactly `{api_version:'neural081_tools_v2',module:'reference_tools',source_path:'/tools/reference_tools.py',source_sha256:<exact approved public source hash>}`. The generic inference module contains no private source/authority paths or raw environment secrets. Its complete immutable dependency closure is joined operator-side, not exported as a file inventory of private locations.

remaining contains exact nonnegative integer native_seconds, native_actions, provider_requests, scratch_write_bytes, managed_read_bytes and source_bytes, plus finite nonnegative normal_seconds_remaining. It is a relative budget snapshot stamped by the trusted adapter, not a clock-control request. The absolute campaign/case origin, deadline, authority location and producer invocation remain operator-only. There is no public override of timers or budget counters. F's native_actions limit is1; I's at most8. F receives no query-time provider capability despite sharing the numerical context.

## Public frozen models

Each `candidate_model_v2` contains exactly schema, handle, family, configuration, class_ids, feature_definition, scaler, parameters, calibration, training_row_tokens_or_null, strongest_family, uniform_probabilities and laplace_probabilities. It has no outer/inner person, source path, training_support path, original environment path, authority, numerical diagnostic transcript or producer closure. feature_definition is the source-owned public mathematical identifier BP or TM; family/configuration fields disclose the actual train-only selected recipe. Calibration contains only its selected finite positive temperature. Prior arrays contain exactly the twelve legitimate training-only values. The strongest handle is fixed by the training selection before queries and repeated consistently across these model records.

scaler and parameters are fixed-schema descriptors `{relative_path,dtype,shape,bytes,sha256}` under that model's generic directory, with the exact array names required by its family (means/scales/class coefficients or kernel training features/B/centering vectors and class means). They contain only non-executable numeric state. No pickle, bytecode, mutable URL or arbitrary filename is accepted. Class/feature axis order is canonical. KRR row-indexed arrays and its public training_row_tokens use the single protected role order fixed before fitting in REFERENCE_MATHEMATICS.md; no per-query model permutation, mutation or refit occurs. Every mode receives identical sealed original model bodies and the same inference source for the corresponding fold/view. Either candidate may copy and adapt these bodies inside its own scratch namespace using the permitted training data and one unlabeled query. Such a copy is candidate state, not a replacement or mutation of the frozen reference. Copies and adaptations never persist to another context. The family-specific shape/source contract is checked privately before exposure; absence of private provenance fields is not absence of provenance checking.

A source-owned `projection_binding_v4` is private: it joins the exact full operator context/models/source/clock, complete label-free support_index_v3 and protected support descriptors, the identical private/public single_query_transductive_v4 policy, public JSON/array/source bodies, generic mount map, opaque alias inverse and all role/shape constraints. Its pre-grade verifier never opens the full label-bearing support_v1 or assessment body; G0 authenticates their issuing lineage and G5 verifies their bodies after the complete barrier. It establishes the supplied projection completeness/identity under qualified issuance and custody; it does not prove a complete internal statistical trace. No such trace is a scoring eligibility requirement when all single-query adaptation is allowed. The execution/access joins are in EXECUTION_ADMISSION.md. Public and private schemas must reject one another rather than treating extra fields as harmless. The numerical image/launcher must hide host paths in process environment, cwd, sys.path, tracebacks and file metadata visible to the sandbox; this is a qualified deployment requirement, not implied by a JSON filter.

## Public tool result and private trace

The provider receives an exact `candidate_tool_result_v2` with fields action_index, status, stdout, stderr, files and remaining. status is one of completed, closed_analytical_error or closed_encoding_error; uncertain native closure aborts the episode and is not presented as a recoverable action. stdout/stderr each contain exactly text, projection_truncated, original_bytes and original_sha256. Their UTF8/prefix rules and caps are in RESOURCE_CONTRACT.md. The retained original raw stream is private; its hash is an integrity identifier, not a path to read it. Runtime-origin error messages contain only source-owned generic categories and sandbox paths. If a private host/authority/source path reaches the native stream or an unexpected runtime error cannot be safely represented by the reviewed category schema, withhold provider delivery and fail the exposure boundary; do not silently redact an admitted successful trace.

files lists only admitted candidate-created ordinary files under `/workspace`, with relative_path, bytes and sha256; no operator/model/input inventory is attached. Provider-visible text can report numerical evidence from its allowed data, but no other context/target data exist in that namespace. The private trace retains original provider request/response bodies, code, raw tool streams, exact runtime errors/closures, original clocks, source/authority/projection joins and all costs. This trace is not a candidate mount. No automatic full private trace or raw operator receipt is appended to the next request.

## Fairness and remaining limits

F and I receive the same information categories and frozen models within each matched query/view; context-specific aliases may differ but add no class information. Matching concerns complete biological support and numerical access, not equality of private token strings. Full query batches, test labels/feedback, other folds' models/traces and cross-query writable state remain absent. Candidate-recognizable public dataset provenance and inferable biological signatures are not magically removed by opaque aliases. Report that limitation, while enforcing the explicit absence of administrative identity/source-order fields.
