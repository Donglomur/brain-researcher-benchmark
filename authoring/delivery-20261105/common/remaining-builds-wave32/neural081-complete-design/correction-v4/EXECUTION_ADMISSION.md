# V4 execution/access admission without statistical-semantic review

V4 permits single-query transductive candidate computation. The permitted authentic information is the complete nine-person labelled training view, exactly one current unlabeled query, sanitized metadata and readonly original tools. F and I may fit temporary statistics/models on those observations, produce inferred pseudo-labels or adapt private copies of tools. They may not obtain another held query, the current target, feedback, another context's state or additional services. Ground-truth labels of the held person never enter labelled training. No algorithm-quality or training-only-statistics judgment is needed to decide eligibility.

## Remove the earlier review service

V1–V3 METHOD_ADMISSION and method_decision_v2 are historical, not operative. There is no F_SOURCE/I_ACTION/QUERY_FINAL statistical review, no3+60N human/LLM decisions, no1800+4320N review-second term and no reviewer identity, completion or interpretive verdict in runtime eligibility. A renamed reviewer, provider adjudication, implicit transcript judge or automatic training-only-fit classifier cannot be inserted as an equivalent gate. Independent code/security/numerical/scientific review before deployment still matters, but is not a per-candidate statistical-semantic service.

Candidate source identity and qualified physical capability remain distinct requirements. A source hash cannot prove no escape or universal internal observability. The complete source must actually implement sandbox issuance, provider/native transport, resource enforcement and independent original-terminal/artifact observation. Qualification records are exact external selections for those mechanisms; a boolean without evidence cannot substitute for their implementation or demonstrated behavior.

## Concrete source-owned admission sequence

1. **Before any authentic/key/candidate operand:** capture the full trusted programme source/dependency graph; authenticate actual interpreter/argv/cwd, selected operation, exact qualified environment/native/provider mechanisms, original clock and finite reservation. Missing qualification refuses before operands. No assessment body is needed for this check.
2. **Before a candidate context:** issue its complete role view from the V3 label-free support index and protected G0 receipts. Verify exact nine-person training membership, one query, view/generation, sanitized schemas, complete frozen tool/model identities and generic readonly mount paths. Retain the private canonical inverse. Do not read either global label-bearing support or assessment object. Qualified physical custody must exclude aliases, extra data, shared writable state, engine sockets and host credentials.
3. **F author/source seal:** schema-validate and capture the exact bounded data-free source bundle/dependencies before any authentic exposure; bind its identity to the replication and original author closure. Source files remain readonly throughout query execution. There is no statistical-semantic approval. Each query launches the same sealed algorithm once, with no provider capability. Its scratch coefficients, derived representations and data-dependent branches may vary with the current permitted query.
4. **I action admission:** validate the exact action schema/index, capture its submitted UTF8 source and bind it to the current context, prior closed action prefix, selected physical capability, remaining native/request/byte limits and original endpoint. This deterministic gate does not classify whether a function is a fit or which allowed observation contributed to it. Reserve the action before launch and retain its full debit on failure. No review service or extra provider call occurs between validation and execution.
5. **During execution:** the source-owned adapter actually enforces the one-context namespace, network/process restriction, exact engine object custody, deadline/resource caps and stream/artifact limits. Native code has no provider access; only the host's selected I conversation transport may contact the selected endpoint. Any ambiguous isolation/stop/custody outcome aborts and retains uncertainty. Ordinary fully closed analytical errors may consume a subsequent I action under the unchanged budget rules; no automatic retry of unknown work occurs.
6. **After an action/case:** retain original wait/stream/resource observations, exact top-level submitted/sealed source, outputs and artifact identities, then validate the one probability row and complete action prefix. At case closure no candidate-visible mutable state survives into another context. Private operator evidence may be retained for audit under a physically separate namespace. No correctness or target feedback returns to the candidate.
7. **Before G5:** the independent observer verifies all12N case/source/access/resource/terminal joins and all240 complete panels, including the full fixed reference graph. It never requires a method_decision_v2 or another semantic approval. Only then may the protected grader read both sealed global label-bearing bodies and produce provisional metrics; the final original controller exit and external artifact/source check remain separate acceptance conditions.

These steps belong to the existing host/controller/observer and native action graph. Source/metadata/body operations and failure preservation remain charged. They are not additional reviewer contexts, new reference fits or hidden processes.

## Dynamic code, scratch fitting and observability

The sealed F programme may compute Python expressions, synthesize code strings or construct data-dependent algorithms at query time if they execute entirely within the same selected Python capability. This is execution of its pre-authored algorithm, not an opportunity for an external actor or provider to replace its source. I may generate source through its existing bounded action protocol. Generated code cannot enlarge mounts, fetch/install dependencies, contact services, launch unselected children, gain privileges or mutate the shared readonly tools/source. No per-generated-fragment human/statistical approval is selected.

The qualification must describe supported dynamic-code/standard-library/numerical-library behavior and enforce the physical boundary despite that behavior. Missing enforcement prevents runtime qualification. There is no claim that every internal function call, fit, generated statement or memory operation is semantically reconstructed. Record exact externally submitted source, native actions, resources and retained artifacts. Any optional candidate report of internal fits or explanations is labelled as reported, not independently counted and not a new score or eligibility gate. Total physical I/O cannot be certified by Python helper counters alone; RESOURCE_CONTRACT retains that limitation and its qualification requirement.

Original frozen models remain immutable inputs. Scratch copies may be fitted jointly with the current unlabeled query and training data, but are never published as updated shared references. Adaptation is reset for every query/view/replication. ZERO still receives only zero waveform values and its own zero-trained original tools; transduction does not grant EEG access. Provider pretraining or inference from legitimate numerical signatures is not assumed absent merely because administrative identity fields are removed.

## Interpretation and future source checks

Candidate improvement over fixed inductive references has broader candidate access and flexible per-query computation as possible explanations. The primary F/I comparison matches this access while differing in pre-authored versus current-query provider synthesis; report their distinct author/reasoning costs. It does not isolate a causal reasoning mechanism. All biological and fixed-cohort limitations remain.

A later implementation grant should exercise allowed joint training/query adaptation through both mode routes, exact F-source immutability and absence of query-time provider access, actual single-query/target/other-context refusals, readonly original models with writable private copies, complete closure without any semantic-review token, original budgets and failure handling. These would be boundary controls, not proof of complete semantic observability or scientific competence. No implementation, fixture or authentic operation is performed by this design document.
