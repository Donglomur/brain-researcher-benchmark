# Prospective resources and complete accounting

All figures are selected upper bounds or algebra, not measured wall time/RSS, actual API spending or qualified feasibility. The original120s/2CPU/4GiB per-person partial recipe is explicitly superseded for the complete current-query study. No scientific/API action is authorized by this document. Before a real run, the verified complete N/n_p census, exact hardware/provider, aggregate storage/CPU/token reservation and spending cap must all be selected. An unaffordable complete source remains an unexecuted task; do not reduce support.

## Per-operation bounds

Units GiB=2^30, MiB=2^20. Source capture/bootstrap/imports, hashing, validation, all attempted actions and failed publications are inside the applicable envelopes, not free preprocessing. Exactly one numerical CPU is selected per native worker; BLAS/OpenMP/etc threads are1. Candidate child processes are disabled. No GPU, external checkpoint or unselected remote numerical service is included.

* Preparation: at most3,600s normal wall/CPU per person,16GiB resident memory, one person at a time. Full input stream is authenticated before scientific use; rereads are charged. A preparation failure has a separately selected120s diagnostic closeout, never extra valid scientific time.
* Reference fit: at most7,200s normal wall/CPU per fit. Let n be exact training rows and d the feature width. LDA memory reservation is ceil_GiB(512MiB+64nd+256d²) bytes. RBF fit memory is ceil_GiB(512MiB+48n²+64nd+256d²). These are admitted reservations, not proof the implementation fits them. Source/native allocation accounting must reject before any unbounded allocation and empirical qualification must measure the true peak; no approximate kernel or discarded rows may be substituted.
* Reference inference: at most900s normal wall/CPU and memory ceil_GiB(512MiB+32nd+64qd+32qC) for n model training rows/q query rows, with streaming query blocks of at most256. Do not materialize a whole q×n kernel if it exceeds the admitted bound; row/block evaluation is exactly the same kernel, not subsampling. Model/core/source and block IO remain charged.
* Selection/calibration worker: at most300s/4GiB, complete180OOF artifacts, exact labels/metrics/grid/temperatures and analytic outputs. Protected final grader: at most3,600s/8GiB, streaming full source/artifact/label admission and complete reductions. Raw outputs can be private on disk; a streaming implementation must retain exact counted support rather than process a sample.
* Candidate F or I query:8GiB resident memory,480s cumulative native CPU and480s cumulative native normal-wall reservation,16GiB private scratch writes/retention cap and one fresh current-query namespace. I has≤8native invocations; each action requests a positive wall reservation not exceeding the remaining480s. With1CPU quota, reserve that same number of CPU-seconds prospectively before launch and retain the full reservation even if the process ends early. F has one480s maximum worker under the same quota. No silent refund after failure or using a later cgroup measurement to exceed the original prospective envelope.
* Candidate complete episode: original normal deadline2,400s after first permitted input exposure; native child deadlines are bounded by both their reserved intervals and that original endpoint. I provider requests have≤120s each,≤9requests, each≤2MiB raw response,≤32,768 admitted input tokens and≤4,096 output tokens. Actual token counting requires a selected tokenizer/provider contract; unsupported usage measurement is unqualified. Original request error consumes its slot and reserved budget. Provider I/O may not stall a watchdog beyond the native deadline.
* F source-author episode: original normal endpoint2,400s after the first author prompt/source exposure, with all source capture/schema validation/sealing completed inside it; no authentic data/models,≤9provider requests at the same token/HTTP caps and≤8optional data-free source/toy-analysis Python workers, each60s/4GiB and a combined480s/256MiB scratch envelope. These ≤24native authoring workers are explicitly **additional non-scientific-source-authoring processes** outside7,391+54N. No such toy execution occurs in the current zero-fixture design phase.
* Any uncertain native/provider stop has a fixed120s failure-closeout interval relative to its already-selected original endpoint. It cannot earn a valid prediction. A final campaign readback interval is selected below; no nested origin reset is allowed.

Maximum provider-request count is54N+27. Maximum input/output token reservations are that count times32,768/4,096 respectively, without claiming actual use or a current price. Both model sampling config and the monetary spending cap must be explicitly selected later. Provider keys are read only by the admitted host adapter after metadata/source qualification and are absent from native environments/receipts. Current grant authorizes no paid/provider execution.

## Logical bytes, native I/O and persistence

Let E=131072N be canonicalfloat32EEG payload; per person E_p=131072n_p. Original release is6,995,284,395B. Base fixed feature payload per view is F=10752N (320+1024 binary64 features); ZERO may be generated, but its logical operations are still counted. A naive ten-fold copy costs10E; one-at-a-time staging avoids resident tenfold duplication while preserving all ten folds. No single full-cohort memory claim follows from the7GB source size.

A candidate query receives the full training support E_train=131072(N-n_p), one query131072B and readonly model/source bodies whose exact byte sum is M. Admit **R_case=8*(E_train+M+16MiB)** logical input bytes and **W_case=16GiB** output bytes for each mode. This same bound applies to the managed logical native reads across F or I activity for that query; it is not an excuse to hide source/import/model rereads. It is NOT a universally enforced total-physical-I/O cap for arbitrary Python. mmap, library internals, page cache, metadata and unsupported syscalls need a separately qualified observation/enforcement model with a prospectively selected aggregate reservation. If that cannot be established, report native physical I/O unknown and withhold the corresponding runtime qualification; no finite Python helper count can silently stand in for it. An actual complete fit can exceed this bound and fail; do not lower training support. The host separately reserves staging/copy/integrity/source/receipt bytes with exact actual descriptors before each operation. Candidate arbitrary native I/O must be constrained by the selected filesystem/engine enforcement and measured or conservatively bounded separately; a Python helper counter alone cannot certify arbitrary code's physical I/O.

For every reference operation, precompute the exact admitted input/source/model descriptors and output-shape caps. Reserve their complete native read/write demand plus a fixed32MiB bootstrap/completion allowance before launch. Numerical source IO must charge each array/source read, hash reread, EOF probe, completion artifact and durable publication; host copy/hash counters do not replace these worker costs. Exact model output caps follow their persisted array schemas, not an arbitrary generous scalar. A failure retains full prospective reservations. If the execution engine cannot enforce/observe the declared native I/O model, runtime qualification is absent; host byte tallies are reported honestly as host-managed logical IO only.

All retained private raw/prepared/reference/model/candidate/provider artifacts need a preflight storage reservation. Do not infer “dataset size” from cumulative copies. At least the full original release, E, both feature views, onefoldstaging, complete reference outputs/models,12Ncase outputs/traces and assembled240panels must fit the selected retention policy. Candidate transient scratch can be removed only after exact successful external closure and retained output admission, never blindly after unknown failure. Failed namespaces/containers remain isolated for inspection and count against the campaign's failure allowance; their existence may require stopping rather than launching more work.

The scalar probability payload in final240panels is2,304N bytes; inner-validation probability payload is34,560N bytes. Raw class scores add an equal-sized scalar array for the corresponding reference artifacts, plus JSON/IDs/lineage. Individual12Ncandidate artifacts and assembled panels duplicate their probability content when both retained; charge both. Per-case transcript cap is16MiB including provider envelopes/tool source/results and source/model identity receipts; overcap fails before more materialization. Every native worker, including reference/preparation/F/I/source-author workers, has separate original stdout and stderr byte caps262,144 each. Raw arrays/models use the admitted artifact paths, not the stream budget. Original streams are retained independently before summaries. Reaching a cap without verified EOF is an overflow/uncertain failure, never a complete prefix relabeled as the original stream.

For closed candidate/source-author actions, decode captured streams with strict UTF8. Invalid UTF8 is a recorded closed tool error; do not replace invalid bytes and claim an exact decoded transcript. Provider-visible output is the first8,192 Unicode codepoints of valid stdout and first2,048 of valid stderr, each with explicit projection-truncated boolean, original byte count and SHA256; that bounded projection does not truncate the retained raw observation. The tool result carries a generic candidate-visible error category, never an operator traceback/path/authority descriptor. Candidate-created text within its sanitized namespace can be visible. The source-owned runtime error projection is reviewed before deployment and enforced automatically; no per-action human/LLM review of generated text is selected. Unsupported/private-path-bearing runtime errors refuse provider delivery under the fixed schema.

Before each request, the selected exact tokenizer must count the full ordered conversation: original prompt/actions and these projected tool results, plus the prospective transport framing required by the provider. Maximum admitted input is32,768 tokens; overflow refuses before transmission with context_budget_exceeded. No implicit summarization, transcript deletion, provider-side truncation or automatic retry is selected. Output is at most4,096 tokens and2MiB original response bytes; unsupported token/framing measurement prevents qualification. Original request/response bodies remain protected and count toward the16MiB trace cap. The provider receives only the candidate projection, not that operator trace. F-author source responses and I code/predictions obey the same policy. Source-owned validation/readback must be streaming and may not recreate every transcript in RAM simultaneously.

Reference feature input work from the original complete grid is12,261,376N payload bytes across bothviews, excluding new selection/calibration rereads, source/import/model/output hashing and candidate work. The selection/calibration workers add explicit reads of all3,600OOF predictions/rawscores and their permitted training labels; shapes/bytes are exact after preparation. The fixed historical baseline may recompute features; actual extra raw reads must appear in its ledger. The prior illustrative261,095,424,000B naive raw-reference traffic at N600 is cumulative logical work, not resident data or a measured spend.

Even one raw training pass in every candidate query has payload131072*12*sum_p[n_p*(N-n_p)] bytes. At illustrative equal60/person that is509,607,936,000B. Repeated I actions can add more; immutable trained tools/cache can avoid passes only if equally provided and source-bound. Queries are not independent biological observations just because they have separate tool contexts.

## Whole-study bound and original clock

Use one original campaign origin before source/input/authority capture. Root chooses a preflighted serial schedule (no uncontrolled parallel actors). Scientific native maximum normal time is:

`10*3600 + 3680*7200 + 3680*900 + 20*300 + 12N*480 + 3600 seconds`.

The term3680*7200 counts all matrix fits;3680*900 counts their inference. Provider normal bound is120*(54N+27) seconds. Optional F data-free source workers add24*60seconds. V4 removes the former1800+4320N-second statistical-semantic review term entirely. It does not transfer that allowance to native CPU/wall, provider calls/tokens, scratch or another reviewer. Keep the original2,400s author/query endpoint. I and a maximum F author each have at most1080s provider+480s native=1560s; F query has at most480s native. Existing host/source/projection/readback work must fit the remaining time and its separately bounded I/O; there is no permission to use it for unselected candidate work. No human/LLM statistical review service is part of this graph. These are deliberately conservative serial maxima, not useful elapsed-time predictions. Source/capture/readback/durable-host processing receives an additional original-clock allowance **H=86400 + 60*(7391+54N+24) seconds**; its coarse size does not bypass operation-specific byte or child deadlines. Select the final campaign normal endpoint as origin plus the sum of these frozen bounds. Unused allowance is not transferable into a child's normal scientific deadline. A campaign this large may be impractical; require explicit aggregate selection before any actual run.

Each complete producer is independently closed before the next selected dependent stage. Final readback and grading must complete within that original normal endpoint and their own selected intervals. A separately bounded final120s failure closeout remains failed. Every actual observed call/process/provider/body counter, completed/failed/entered-incomplete/unentered identity and lower/upper usage statement is retained. The original environment/clock/provider process may not be restarted under a new origin to disguise exhausted budget.

At the current N ceiling, a dense RBF kernel alone can exceed50GB and the complete query campaign can have600,000I episodes. The design intentionally exposes this uncertainty instead of assuming600trials or4GiB. Actual complete trial census, solver memory, versioned provider limits, storage and monetary authority are mandatory later preflight gates. None is currently qualified.
