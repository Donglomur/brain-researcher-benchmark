## Program, native and observer boundaries

`controller.py` authenticates source, root-selected configuration and all four
programs before data. Each full view is streamed through exact declared length,
SHA256 and descriptor/path identity, then reauthenticated before native handoff
and after all exact native/CLI closures. No pickle is loaded by host staging.
`engine/native.py` and `engine/holder.py` are a reviewed adaptation of the MICrONS
transport: isolated non-root network-disabled containers; strict11-field CLI
closure and6-field natural producer state; exclusive PID1 ready marker in a
holder-private4KiB tmpfs with explicit init=false; finite capture; owned resource
identities; no Docker log collection or candidate-produced execution claims.

Original baseline warnings/prints are preserved in estimator source. The daemon
log driver is disabled as an operational sink; silence is not a method assertion.
The baseline runs in `/work/reference` under128MiB scratch, then copies its exact
CSV and methods to the empty output volume. Natural exit and complete capture
must occur before typed output admission. Candidate exit success alone is not
an admitted artifact, and a file's existence never proves successful execution.

`observe.py` owns the complete controller child, records its original monotonic
origin before source capture, and checks all5 original phase receipts and full
output supports before publishing OBSERVED.json. Startup failure independently
attempts cancellation and every captured signal-handler restoration. The child
uses the same original origin; there is no reset per phase. The standalone
entry checks the original outer deadline again after successful timer/handler
cleanup before returning zero. The prior d4c6 source could return zero after
delayed cleanup; its source and review remain historical. Normal completion
requires all original host/native closures plus the outer natural exit. Forced
stops can interrupt independent CLI process groups or daemon resources; their
state remains unknown. The outer group is not a claim of transitive custody.
No automatic retries, private grades or runtime/scientific qualifications occur.

## Private grading remains separate

candidate panel, the distinct baseline CSV/methods, original native evidence and

that policy independently, retain successful external OBSERVED.json custody,

Candidate BASE estimates cannot replace the independently run comparator.

remain unchanged; different coverage does not establish superiority. No new
failure penalty, score, acceptance threshold or SOTA assertion is introduced.
