# Fold-isolated access and future execution contract

This is a complete source-design contract. It does not implement or qualify a runner, preparation, provider, container, trained decoder or grader. Future source construction must supply concrete producers, immutable artifacts, independent observations and original-clock custody, rather than callbacks accepting finished predictions.

## Source preparation and physical role separation

Original NWBs contain private behavioral quantities beside neural recordings. They are operator inputs only and may never be mounted into candidate, provider, author, tool-analysis or inference contexts. Source preparation must authenticate the whole 55-object descriptor roster and each admitted original schema/time/target bridge before producing minimized artifacts. The retained source census covers every original row, channel, person and day, including empty/invalid dispositions. Source bytes, target tables, event pairing, original identifiers and derived private statistics remain protected.

The safe public packet consists only of source-bound neural windows/masks, permitted relative alignment and axes, a positive context projection and opaque public row IDs. Separate fold-specific training-label artifacts contain only the training days' admitted target columns. A query packet never contains held labels, source target-row indices, stop/duration, pose, speech, bimanual fields, behavioral R² or a route to the original source. Duplicate IDs, unbounded JSON fields, path aliases, extra files, unqualified source tables and mismatched masks/axes refuse before effects. A hash or chmod alone is not proof of physical isolation or immutability; actual mount, namespace, hardlink/symlink and alias custody require independent qualification.

No whole-study actor training artifact is created as a convenience. An independent protected operator may hold the full census and target bank; it emits physically minimized fold views with separate labels and logs the exact source/row/role membership. The reference operator is also separate from the candidate. It does not publish inner/outer validation scores, selected states or predicted held labels into global authorship.

## Positive input projection

All case views carry only opaque row identity, relative sample alignment, sample rate, deterministic within-person channel identity/anatomy where qualified, and the exact technical availability masks. Opaque IDs are join keys, not admissible arbitrary numeric predictors. C additionally permits anonymized time of day, recording-day ordinal and static acquisition context. N additionally permits the full admitted neural values. NC permits both. Fixed reference encodings are defined in the reference contract; candidates may construct other permitted features.

The allowed temporal context must be actually supported by source metadata: anonymized absolute dates do not authorize reconstructing real dates, patient identity or a guessed hospital schedule. Event onset is an explicit oracle cue, not a learned event detector. Relative alignment and masks expose technical support; they do not certify source quality. No target-derived channel flags or original held-day noise summaries enter the positive projection. A missing optional context field has an explicit missing indicator under a predeclared schema; an unknown required time/target schema blocks the complete profile.

Each case receives the complete held-day label-free query batch at once. F and I have identical access to that batch and may perform the same predeclared numerical transformations, transduction and query-dependent fitting that do not use its labels. This does not authorize another person's data, another outer fold's learned state, or labels of the held day inferred from a previous fold. Case-local memories, prompts, plots, files, embeddings, model state, tool traces and provider caches must be destroyed/retired or made inaccessible before the next case. Actual physical isolation is an admission gate, not inferred from directory names.

## Global authorship and method sealing

The global source-only setup may read the same paper, task specification, permitted documentation, code and environment inventory for F and I. It cannot read any authentic study values or labels, since their union would include every held day. Separately authorized engineering fixtures cannot mimic protected original rows or become an unaccounted authoring data source. This design phase creates none.

F may write a general Python/programming-language method implementing feature extraction, supervised fitting, training-only selection, neural/context fusion, batch transduction and prediction. Its source, dependencies, data-independent configuration, legal provider grammar and method-admission review are sealed before study data exposure. Model weights and query-adaptation state may be fitted later by that frozen program within each isolated case. F is full method construction, not merely choosing from a fixed list of reference models.

I uses the same source-only setup policy and then starts a fresh case-local investigator for each held-day fold. It can inspect the same permitted training/query inputs, write and execute case-local analyses, alter its method and then seal all executable/fitted state before final output publication. It may receive training-only inner-validation feedback it computes within the case; no outer-target feedback is supplied. The investigator context is the complete held-day case, not one conversation per event or sample. Chunked transport is permitted only when it preserves access to the entire ordered batch and all costs; it does not shrink support.

After case exposure, F provider returns must be typed finite numerical values/features or bounded choices among predeclared audited operations. No generated executable code, new dependency, unrestricted plan/prompt/tool-call DSL, or generated method reinterpretation may cross that interface. Such behavior is I even when a static wrapper requests it. Source filters alone cannot prove arbitrary semantics; independent method admission remains unqualified until performed. The same numerical library/tool operations must remain available to both modes, and a valid F program can itself implement numerical test-time adaptation.

One source-only policy realization per selected cell is the default R=1. Record model/provider version, decoding settings, declared seeds and any nondeterminism. No undeclared prompt search across held scores is allowed. Source setup costs are reported separately and allocated per cell; per-case resource ceilings are identical for matched F/I cells. Equal ceilings do not require wasting resources to equalize realized consumption. An author-variance extension needs separate predeclared independent realizations and full cost/output coverage.

## Supplied decoder T1

The generic numerical environment (T0) provides no fitted neural decoder or held-query predictions. It can contain source libraries and documentation required to author models; this is not an unaided LLM condition.

T1 is the exact selected strongest NC reference R1 state for the case and endpoint, trained/selected exclusively on outer training days under the full nested graph. It is offered identically to F and I only after their global source-only setup, through a case-local typed inference interface. No R2/private reference evidence, training search scores, target store or other fold model is mounted. The interface can compute full-batch outputs on the exact permitted training/query views and explicitly marked training outputs; in-sample predictions must never be represented as held-out validation. Every inference, retained prediction bank and source read is charged even when no new fit is required.

T1 may return predictions and declared finite intermediate features only if their exact lineage and shapes are predeclared before implementation and shared with both modes; the selected minimal interface here returns the three endpoint predictions plus supported/failed status. It cannot answer arbitrary target queries or supply feature importance based on held labels. Tool-alone is the identical inference output on every held row. F/I may calibrate using their permitted training data, with honest in-sample versus inner-held-day separation. If exact qualified core reference states are unavailable, the complete original training graph must be separately admitted and budgeted; a supplied checkpoint or completed-output callback cannot stand in.

The conditional tool panel is NC only. Decoder outputs carry neural information. Holding those outputs fixed while removing raw samples would test additional raw information conditional on the decoder, not total neural contribution; that extra contrast is not silently included here. The separate NC_D module receives neither original T1 outputs nor original trained states.

## Full-workflow assignment control

The operator creates the deterministic NC_D whole-bundle donor map before any fit or query exposure. Every source-derived neural bundle, technical mask and relative alignment is transformed consistently in training, inner validation and held query phases. Recipient context/targets stay associated with their recipient event. New C-style mask summaries are computed from the moved bundle. All candidate/references start fresh and use only this transformed view; no original-neural derived feature, fitted state, prompt, analysis or cache crosses the boundary. For each mode, the identical frozen source-only original-NC F program or I policy, provider configuration and paired declared seed contract MUST be used for D; no independently authored D global policy or D-specific prompt is allowed. Reusing this source identity does not reuse a running context or any study-derived state. Fresh D case-context instantiation and every analysis/fit/query operation remain charged.

The actor-facing data schema is NC and exposes no explicit original/D flag, private operator condition name, revealing path or method toggle. Independent source/view/mount review must bind that projection. The operator's private source/state/artifact identities still distinguish arms exactly. Disrupted input statistics may make the condition inferable; this is not proof of universal blinding. A provider unable to support a qualified paired seed contract retains unknown stochastic variation in the comparison, which must be disclosed rather than attributed entirely to assignment. No original query-derived provider cache may be reused to simulate paired randomness.

Within each day, the donor map is a nonzero cyclic shift of the full event list. A source-only deterministic seed and exact canonical event ordering must be fixed before implementation; arbitrary reordered IDs may not silently change the intervention. Absolute donor provenance is private. No row is dropped to obtain an exact mask match. A nonempty singleton day leaves the full diagnostic unsupported, not replaced by identity or a smaller cohort. The resulting contrast is sensitivity to within-day neural-and-support assignment, with no causal/exchangeability guarantee.

## Concrete execution obligations for the later source implementation

The later implementation must include source-owned preparation, fold materialization, native numerical reference workers, candidate author/fit/infer workers, bounded provider HTTP/tool transport, full scheduler, original-stream observer, lineage admission and protected scoring. It must bind exact source/environment/input/role/configuration descriptors, all expected output IDs/shapes, original origin and phase deadlines, and prospective CPU/GPU/memory/disk/read/write/provider limits before effects. Unknown resource feasibility cannot be represented by an unlimited default. Nested native actions consume the enclosing case/whole allowance; resetting a child clock or silently granting another minimum allowance is forbidden.

Success requires independent actual completion evidence, complete stdout/stderr capture and source/artifact rechecks, not a child-produced success boolean or exit alone. Retain attempted states, nonzero exits, partial streams, output/preimage custody and costs even when failure publication itself fails. Stopping or retrying ambiguous live resources requires a separately qualified owned-identity mechanism; numeric PID/PGID identity is not enough. No automatic retry after unknown publication/native/provider state. No callback may assert a finished fit, native prediction, full-support closure or scientific score in place of the concrete computation and its observation.

Protected grading first admits every selected candidate/reference/tool panel's complete public source, row, state, view, configuration, output-shape/finiteness and original-completion edges. All admission reads exclude the canonical private target roots and their physically qualified aliases. Only after complete public admission may the evaluator open target bodies, establish source-key pairing and compute the selected scores. Neither source path normalization nor a final function-call position alone proves target-last custody. Actual filesystems/mounts, source identity and physical role disjointness remain independent qualification requirements.

Source-only construction cannot establish authentic cohort feasibility, trained-model competence, provider semantics, numerical reference agreement or scientific results. Each remains separately gated and reported.
