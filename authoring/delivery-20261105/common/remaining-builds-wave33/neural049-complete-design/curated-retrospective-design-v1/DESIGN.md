# NEURAL-049: complete curated, event-cued retrospective decoding

This is the explicitly selected successor **design direction** within NEURAL-049. The original continuous confidence-qualified signed wrist forecast remains required-unscorable history. No registry/default has changed. This profile asks whether source-curated movement parameters can be decoded from a retrospective neural window around a known event, across all original within-person held-day folds. It does not detect events, forecast a continuous trajectory, simulate chronological deployment, establish causal motor coding, or demonstrate unaided LLM understanding of neural samples.

## Complete source population and target census

Retain the full frozen DANDI000055/0.220127.0436 release:12 people,55 daily NWBs,845,869,698,341 advertised bytes. The exact prior descriptor roster remains authoritative for source membership. Every released `intervals/reaches` row is required; no additional fastest-event selection, convenience day/person subset or post-outcome valid-only aggregate is allowed. Let E_sd be the authenticated count for person s and day d; E_s=sum_d E_sd and E=sum_s E_s. E_sd is symbolic now. No paper count or upper200/day description substitutes for the released-table census.

The operator must retain a disposition for every source object, channel, day and reach row, including empty days, duplicate/malformed/unmatched rows, absent data and unsupported people. A row with a known masked neural observation can still receive a prediction; an unknown or contradictory source clock/channel/target identity is not an ordinary missing value. An unresolved required row leaves the complete primary result undefined. A valid empty day contributes no event, and remains reported; a required person with no scoreable target rows makes the12-person primary undefined. Neither failure causes a reduced replacement cohort.

Source `ReachEvents` and `intervals/reaches` originate from separate CSV products in the converter. This profile selects the onset in each required `intervals/reaches.start_time` row as its oracle event cue, with that same row's targets; it does not substitute the separate `ReachEvents` list. Preparation must authenticate the interval table's original CSV/row/clock provenance and its ECoG time map. No positional, equal-length or invented tolerance join between the products is accepted. The separate list's relation is retained as an unresolved source fact unless independently documented; it is not silently asserted bijective or made the target census. If a later constructor proposes to use it, exact source-supported mapping is a new admission requirement. Duplicate/ambiguous interval rows or an unbound selected cue-to-signal clock block the complete primary; a legitimately distinct event product does not by itself remove curated rows or invent missing targets.

The primary target is the **released folded vertical reach angle** in `Reach_angle_degrees`, measured in degrees. The Methods describe folding horizontal direction so that upward and downward movement lie near +90 and−90; it is not a circular full heading. Use the authenticated released target field exactly, not a newly computed velocity or a reconstructed angle guessed from coordinates. Range/units/transform provenance must be independently admitted; unexpected values are a source-schema failure, never clipped. `Reach_magnitude_px` and `Onset_speed_px_per_sec` are complete secondary targets on the same row census, retaining pixel and pixel/second units. Source camera movements and pose-model error limit their physical interpretation. Approximate pixels-per-centimetre remarks are not calibration.

The target table's stop time/duration, all three target fields, speech and bimanual outcomes, target-derived electrode R² and target pairing keys remain private to preparation/fitting/scoring roles. The future actor receives training labels for its permitted training days, and no held-day target or score feedback.

## Exact retrospective observation window

For each curated event with admitted onset e seconds in its own daily source, request the complete10-second half-open interval[e−5,e+5). This adopts the original event-analysis window length while explicitly allowing post-onset measurements. The known event onset is a behavioural oracle cue shared by every candidate/reference/view; performance is conditional on the released selection procedure.

Require a qualified uniform500Hz source time map t_k=s0+k/500 and exact source length. Set k0=ceil(500*(e−5−s0)); retain5000 consecutive source-grid positions k0,…,k0+4999. Record their exact first/last times and the fractional alignment offset; check the actual half-open interval predicate, finite arithmetic and the justified source timestamp tolerance before body reads. Do not silently round to a pose frame or interpolate neural samples to an assumed event grid. If source timestamps are not this admitted schema, report that source mismatch rather than resample under an undocumented rule.

Positions outside the same day/physical source extent are represented by an explicit availability mask and a neutral missing value. No adjacent day is borrowed, preventing source-window overlap with another training or held fold. Source-native nonfinite or declared absent channel values are likewise masked; finite zero is a valid numerical value, not an inferred acquisition gap. The original per-sample maskedness and alignment facts remain retained. Masking represents available released observations; it does not certify an independently measured physical gap or signal quality. Unknown time alignment, undefined source membership or an unbound electrode table cannot be repaired by masking.

Retain all admitted source electrode identities in a deterministic within-person channel roster. That roster may use label-free anatomical/acquisition metadata across that person's days, including the held day, because this retrospective batch exposure is explicitly shared. Every model state records it. A channel absent on one day has a mask; it is not dropped from the census. Query-day whole-file standard deviation, kurtosis, median deviation, `good` flags and behaviour-derived R² columns cannot fit scaling, select electrodes or enter the query. Their original use in producing the released signal remains a documented upstream exposure, not something this profile can undo.

All learned scaling, clipping, imputation constants and feature selection are fitted only on the current training-day partition. Known missing cells are represented after that transform by zero plus the explicit mask. Fully masked neural rows remain required predictions using the view's available context/intercept and a no-observed-neural flag. They do not count as independent evidence of a neural signal contribution. No signal-amplitude threshold removes a target row after outcomes.

## Scientific input views

All views receive the same admissible structure: opaque case/event IDs, channel-axis description, source sample rate, relative epoch alignment and the exact declared observation masks. These common masks carry source-derived technical information. Consequently, C→NC measures the added recording values conditional on that common technical support, not total information in every neural-derived artifact.

C adds positively specified timing/acquisition context: event onset within the anonymized24-hour day, recording-day ordinal, qualified static channel/group/anatomical descriptors, and deterministic mask summaries. N supplies the neural values and common structure but no additional day/time predictor block. NC supplies both. Nonlinear derivations of permitted inputs are allowed equally to F and I. The detailed reference feature API will freeze representations, but actor freedom is not restricted to those reference features.

There are no query pose coordinates, reach stop/duration, speech/bimanual quantities, retrospective coarse activity labels or behavioural electrode R² in C, N or NC. Day ordinal and time of day are legitimate declared context, not random private identities. Raw source filenames/paths and private target-row mapping are never a side channel. Public-development memorization cannot be ruled out solely by opaque IDs; no fresh-data novelty claim is made.

## Complete split and fit scope

Use every day once as the held day for its person:55 outer folds. Each outer training set contains all other released days of that same person. Within each outer fold, leave each remaining training day out once for reference selection; the complete census gives202 inner folds across the55 outer cases. Empty days remain folds/dispositions with zero-row prediction records and zero SSE, not silently dropped folds. Zero training support or zero total inner validation support makes the required fit/selection unsupported; an individual empty validation day alone does not. No cross-person source or fitted state is introduced to rescue a sparse fold.

All training preprocessing is refitted within each inner split. Candidate F/I have the same outer training days, held-day label-free batch, allowed tools and resource ceilings; their own training-only selection must be accounted. There is no held-person population panel or causal pre-event panel in this selected design. Symmetric held-day use includes both earlier and later days as training and therefore is not future-day deployment.

## Mode definition and matched case access

Both modes receive a source-only global setup context and the same permitted fold data at execution. F can author arbitrary analysis/prediction code and a fitting/batch-adaptation recipe before any study values are exposed. Its source and admissible post-exposure provider action grammar are then sealed. It may learn parameters and perform label-free full-query-batch transformations, normalization or transduction under that fixed recipe. F is not artificially restricted to row-by-row inference or frozen numerical parameters.

I begins each held-day case in a fresh isolated investigator context with the same training labels, label-free query batch, source/tool material and resource ceilings. It may author/edit executable analyses and select its method using that permitted case information, then seal the method/fitted state before final recorded predictions. Training-only validation is permitted; held-target scores, feedback and target-derived artifacts are not.

A fixed outer wrapper calling a provider to generate arbitrary query-specific executable code or unrestricted tool/plan DSL is I, not F. F provider calls after case exposure are limited to a predeclared typed numerical/finite-choice interface over audited operations; they do not rewrite the method. Numerical batch operations available to I must also be expressible within the F programming/tool environment. This is a difference in when methods are chosen, not a ban on F batch adaptation. Independent semantic method admission remains required; source checks alone cannot establish that arbitrary code obeys the mode boundary.

No global author may see the union of outer-fold training data: every day is held somewhere. Global F and I setup therefore use paper/specification/source and synthetic examples only when separately authorized; none are generated in this zero-fixture design phase. All actual fold labels, values, derived statistics, tool outputs, analyses and predictions stay fold-isolated and never return to global setup or another fold. This restriction makes F/I a compound authoring-versus-case-investigation contrast, not a pure measure of intrinsic reasoning.

Use one prespecified author-policy realization per mode/view/tool setting for the core design. The two D cells reuse the respective NC source-only policy identity, not independently authored global realizations; each D case still instantiates a fresh isolated context. Report that results are conditional on those realized policies; event/person resampling does not estimate author/provider variation. Three or more independent author realizations may be separately predeclared for an author-variance study, but are not a hidden mandatory multiplier. Reference optimizer seeds are separately fixed and are not author replications.
