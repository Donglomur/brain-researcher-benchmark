## Fixed identities and context

Person identifiers are the two-digit source strings01..12. A day identifier is the positive integer session ordinal from the frozen source path, such as3or7. The timing feature uses that original ordinal, retaining gaps; it is not recompressed to a within-person rank. Source paths/identifiers remain operator-private; actors receive a separately minted opaque join identity and the declared ordinal/time predictor block. Static channel descriptors cannot be enriched from an unselected external patient source.

The selected oracle cue and labels are from the same intervals/reaches row. Let the canonical original row index be its0-based position in the authenticated original table, retaining the original order; validation must refuse duplicate/ambiguous row identities rather than silently sorting/relabeling by a target. For the D assignment only, event_roster_pin is the lowercase SHA-256 hexdigest of canonical JSON of an ordered array of triples[source_relative_path,"intervals/reaches",original_row_index], one per required row in that day. Canonical JSON is UTF-8, ensure_ascii=True, separators comma/colon without spaces, no nonfinite numbers. These triples include no target/amplitude/context values, whole-payload hash, clock-derived outcome or secret key. The separate source/input descriptors still bind actual authentic bytes for custody. The full32-byte D offset digest is interpreted unsigned big-endian. This fixes the identity types and target-independent seed input meant by the owner/helper formulas; source-body changes still invalidate admission even if the label-free roster pin is unchanged.

The per-case reference fit cache binds all complete training input and label descriptors, exact view, transform, configuration, implementation/source/environment and stochastic contracts. Its fit seed excludes ordered outer/inner consumer roles and held data; target/body hashes bind state identity but do not introduce validation/outcome-dependent random seeds. All actual intentional training resampling, shuffling, initialization and dropout must match the qualified written seed contract. A different stochastic realization cannot reuse a nominally identical training-set state. No actor cache or cross-implementation cache is admitted by this rule.

## View and endpoint semantics

C/N/NC reference blocks are exactly those in the helper's SPEC: six timing columns,117C_s spectral/history neural columns and48C_s common mask columns for the spectral/tree families. The all-channel temporal network separately consumes full waveforms/masks. This positive definition overrides any casual use of “context” suggesting extra query behavioral values. Candidates may derive richer functions of the same permitted raw inputs but cannot add new source fields. Training labels of all three selected endpoints are available to candidates; the references fit each scalar endpoint separately and never use another endpoint's held label. These are complete competent reference designs, not a claim that separate scalar models exhaust every possible multitask strategy.

R1=A is fixed as the numerical scoring and supplied-tool anchor. R2=B is a mandatory independent full check, not a better-score fallback. Every prediction's raw value and fixed target-blind projected value are retained. All comparisons and inner selection use the common projected values; nonfinite raw values fail before projection. Target range/units are independently admitted and never repaired by projection.

Source-relative sample membership uses actual r_j and the fractional alignment; no recentering to an ideal event grid is allowed. Known absent/nonfinite/day-edge samples have explicit masks and finite neutral transformed values. A zero-source value is not an absence indicator. Full source channels and rows remain, including fully masked query rows. Empty validation days carry zero-row/zero-SSE artifacts; absent training support and zero total inner support are different failures.

The reference spectral operator's prospective fixed windows and finite dimensional summaries do not restrict candidate model freedom. The reference numerical choices are not author-code replicas, causal filters, estimates of continuous physical confidence/gaps or native biological truth.
