## Open gate register

1. **Exact original payload/source membership:** all55 metadata identities and actual source bodies must join through an authorized later admission. Current advertised hashes are not a fresh data validation.
2. **Full released event census:** authenticate every intervals/reaches row, duplicates and empty dispositions; E_sd remains unknown now.
3. **Selected cue and target provenance:** bind the same row's original CSV onset/targets/units/folded-angle definition. Separate ReachEvents mapping is unresolved and unused, not guessed.
4. **Neural/event clock:** independently establish selected source time base,500Hz uniform grid, fractional alignment, source extents and exact epoch membership/tolerance. Unsupported source variants refuse.
5. **Channel identity:** establish every ElectricalSeries electrode DynamicTableRegion/table/axis correspondence, union across days and absence reasons; integer indices alone do not prove table identity.
6. **Availability/mask semantics:** qualify native finite/absent/day-edge construction and all-masked behavior. Physical continuous confidence/gap truth remains unavailable and is not claimed by this mask.
7. **Upstream exposure:** retain actual whole-day filtering/reference/noise processing and pose-model all-day training/capture lineage. This is retrospective selected-event decoding, not newly causal preprocessing.
8. **Licensing/access and privacy:** source metadata/licensing is available but actual authorized access, redistribution/model/service terms and physical role custody require explicit admission before use. No payload download is selected here.
9. **Mathematical implementation:** source-owned exact three-family fit/feature/selection and preprocessing operators, numerical versions and finite error behavior must implement the written contract.
10. **Independent reference agreement:** separately authored complete R1/R2 sources and qualified pre-outcome tolerances/selection identity; no better-test-result choice.
11. **Reference competence:** actual training stability and strong full-support performance opportunity cannot be proven from equations or a passing import. A weak/failed family does not become a valid strong baseline by label.
12. **Complete resource feasibility:** full symbolic census-to-profile derivation, finite matched case caps and native/provider/storage/read/write/retention costs, including failures and actual deterministic runtime.
13. **F/I semantics and parity:** independent method admission, equal label-free batch/operator access and honest timing-of-authorship differences; provider nondeterminism/realized-policy limits retained.
14. **Physical fold/query/private isolation:** no authentic label/value/tool/trace/cache flow across actor folds or into global authorship; safe projected data only.
15. **Concrete runtime and external completion:** actual producer/source/artifact observations, original clocks, retained original streams, bounded effects, exact cleanup/unknown-state reporting and no arbitrary result callbacks.
16. **Target-last admission and exact scoring:** all selected public rows/shapes/finiteness/lineage before private target access, physical alias protection, independent complete denominators and paired statistics.
17. **Optional tool custody:** exact R1 NC state reuse, all in-sample versus held outputs distinguished, case-local access and complete inference/exposure costs.
18. **Optional D feasibility:** every nonempty day supports a nontrivial full donor map, exact source-only seed/order, identical original-NC global F program/I policy and provider/paired-seed contract, fresh whole-workflow contexts and independently fitted states; no original derived data crossing and no explicit actor-visible arm cue. Input-inferred identity and unknown provider randomness remain limits.
19. **Reference cache custody:** only identical training-set/configuration/preprocessing/RNG/implementation state reused, all202 consumers retained; no automatic fallback if unqualified.
20. **Root stage selection:** this scientific design needs sole-peer and root acceptance; implementation, authentic admission/execution, installed routing and publication remain separate selections. None is implied by file creation or source review.
