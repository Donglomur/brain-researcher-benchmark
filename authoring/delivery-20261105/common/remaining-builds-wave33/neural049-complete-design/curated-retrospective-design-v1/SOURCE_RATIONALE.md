# Source evidence and explicit scope change

The current design uses held source and the already selected source-first retrievals only. SOURCE_BINDINGS.json records exact body identities; SOURCE_CENSUS.json derives only metadata arithmetic. No authentic header, neural array, pose, video, target table, key, model or checkpoint has been opened here. No new network request, fixture, source import or scientific computation was performed in this design phase.

## What the primary sources establish

The AJILE12 article, DOI10.1038/s41597-022-01280-y, PMC9023453, provides the original Methods and describes12participants/55released daily recordings and processed500Hz ECoG. The exact DANDI000055/0.220127.0436 metadata roster identifies55assets and advertises845,869,698,341bytes. Those facts establish the intended complete source support, not actual readable shapes, all row counts or verified current payload bytes. The held release/code/Methods identities are bounded source evidence, not blanket data acquisition authority.

The upstream article, DOI10.1523/ENEURO.0007-21.2021, PMC8225404, describes curated reach extraction and a retrospective10-second neural segment around onset. It reports baseline[-1.5,-1]seconds, initial[0,.5]seconds and low/high bands8–32/76–100Hz in an analysis predicting neural power from behavioral/environmental features. Its native random90/10event regressions, repeated200times, are a different direction/split from the proposed held-day neural-to-behavior decoder. The proposed ridge, nonlinear and temporal references are prospective strong benchmarks, not a replication of that native model or verified improvement over reported paper percentages.

The original selection procedure uses pose confidence above0.4 together with rest/movement/duration/trajectory conditions, capped fast-event selection and visual curation. This supports a curated selected-event interpretation. It does not establish a continuous independent pose-confidence series or exact acquisition-gap mask for the original continuous forecast. Likewise, coarse break annotations and the validation notebook's30-minute nonnumeric exclusions do not supply that missing provenance. The old continuous profile remains required-unscorable, with its original failures and evidence intact.

The converter at exact official revision f44ca6f6c51251b62b6f47492bba400472d4a7ba writes separate source products: ReachEvents timestamps from one CSV and an intervals/reaches table from another. The latter directly maps its own `Time of day (sec)` to start_time and its own movement parameters to Reach_angle_degrees, Reach_magnitude_px and Onset_speed_px_per_sec. This explicit design selects that row's own start_time as the event cue and that same row's targets. It does not assume a positional or tolerance-based join to the separate ReachEvents list. Actual interval-CSV provenance, timestamp epoch/rounding and ECoG time alignment remain independent source gates.

The exact source also includes duration/stop time, speech/bimanual quantities, channel noise statistics/good flags and behavior-derived electrode R². They are not harmless public features. The positive actor projection excludes query target/proxy fields and whole-held-day amplitude-derived selectors. No unknown bimanual unit convention is silently used; those fields are excluded entirely from prediction. Target names alone do not verify authentic units or semantic pairing; those are later admission obligations.

## Upstream exposures that remain

Pose models were trained per person using annotated frames drawn across days. The released event targets are therefore not generated by a wholly held-day-independent pose estimator. Whole-recording/day neural preprocessing, artifact handling, rereferencing and noise measures also precede this split. Train-only downstream feature scaling cannot undo that upstream exposure. The selected result is retrospective transfer over the released processed/curated data, conditional on that lineage. It is not a causal neural forecast, prospective future-day deployment, event detector, general population transfer or proof that a model understands raw neural signals without tools.

The source can zero artifact intervals; finite zeros therefore remain values and are not used to infer an exact physical gap mask. This new profile's finite/declared-absence/day-edge mask describes available released observations only. It is explicitly shared technical information in C/N/NC. Unknown required source clocks or identities cannot be repaired by replacing values with zeros. Fully masked known observations remain in the target/prediction census and must not inflate a neural-information claim.

## Why the design choices answer the selected question

The event-cued retrospective window removes the unsupported continuous-confidence requirement by an explicit root-selected question change, not by pretending the original requirement is satisfied. Full within-person held-day transfer addresses day variability without adding an unselected held-person population task or borrowing a convenient smaller cohort. Equal event weights within each person and equal person macro weighting preserve the selected endpoint and prevent large-event participants from silently dominating the final number.

C/N/NC plus competent families separate context/technical-support information from the incremental availability of recording values. Family-matched increments retain a stable model class, while strongest-family comparisons also allow train-only family choice and are labeled accordingly. Fresh NC_D workflow contexts test assignment sensitivity including moved mask information; a frozen original-query state replay would instead measure only late-input sensitivity and is not substituted here. T1 asks a distinct conditional tool question and retains complete trained-state lineage and exposure costs.

F is allowed arbitrary source-only method construction and the same label-free query-batch numerical operations as I. The difference is that I can change executable methods using the current case, while F applies its previously sealed program and typed provider interface. This avoids an artificial row-by-row handicap or thousands of unrelated per-event conversations. It also makes the contrast conditional on the realized policies and method-admission boundaries; there is no unrestricted discovery/novelty claim.

## Source and licensing limits

The held primary articles expose CC BY4.0 source text; the held converter repository license and DANDI release metadata are pinned for later terms/access review. This does not authorize downloading all advertised data, reconstructing patient identities, redistributing arbitrary derivatives, using a provider under unexamined terms, or acquiring model weights. No new source/model dependency is silently fetched. The upstream code and Figshare leads recorded by the source-first study remain unvisited source leads unless separately selected.

The four raw retrieval responses have exact .response.txt transport aliases with the original byte/hash identities and an explicit external-path mapping. This design binds those alias bodies as evidence. Historical original-path names are not asserted to exist in a clean checkout; any replay requiring them needs a separately selected restoration/alias-aware procedure. Source packaging changes do not change scientific content or source-gate status.

All current documents are scientific source-design artifacts. Complete actual implementation, authentic support, numerical agreement, reference competence, resource feasibility, provider/physical isolation and observed study completion remain unqualified.
