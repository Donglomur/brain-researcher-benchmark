# Independent outside completion

These are admission schemas, not passing evidence templates. The central implementation never emits either external-completion proof.

After observing the original collect invocation's natural return and all stream closure, an independently selected operator may issue a sealed `neural049_external_central_completion_v1` object. Required fields are realm=`actual_original_tool_capture`, issuer equal to the original parent operator_identity, exact central_source and parent_source pins, authority pin, collection `{path,pin}` of the existing central RESULT, review pin from that result, actual argv/cwd matching its retained INTENT, ordinary integer exit_code=0, natural_exit=true, streams_complete=true, observed_after_central_return=true, provisional=false, finite completed_at no earlier than the central result's observed_end, and capture_artifacts. Every capture artifact is an existing ordinary sealed `{path,pin}` under the selected operator root; there must be 1–32. It must contain the actual original tool/command/stream evidence, not reconstructed successful output.

The independent parent external-outer-completion proof remains a distinct object under its unchanged source schema and original origin. Its original fields include the exact observation, source, operator issuer, natural ordinary zero exit and streams_closed/capture_completed=true/provisional=false, with retained actual evidence. For this nested central route it additionally binds central_collection, central_external_completion and nested_caller, the latter being the pin of the original central-retained CALLER.json for the parent observe process. This links existing parent and outside central observations in chronological order. It does not reuse one process's immediate wait to certify another process's future return.

Only after these existing objects are sealed may the independent operator select the parent's late-grading declaration and a central grade review. The same original authority and original readback deadline remain operative. If external closeout consumed the original grading window, grading refuses. A later central audit deadline does not extend that window.

The grade RESULT likewise does not certify its own exit. An independent outside original capture must close the grade invocation before it is described as operationally complete. No source artifact here supplies that later evidence, and no PID/PGID probe alone establishes child identity or complete termination.
