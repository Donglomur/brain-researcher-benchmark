# Author and case interface

A frozen F author receives the written task, mathematical/cue/unit/exposure contracts and source-only tools before any study values. It may write arbitrary Python analyses and a general executable prediction method. It is not restricted to choosing a reference or orchestration template. Its final source implements fit(batch, context) -> (safe_state, features) and predict(state, batch, typed_provider_values, context) -> a finite float64 array of shape [all held-day rows, 3]. A protected independent semantic review must bind the exact source, recipe, claim, setting and source closure before use.

An I global author instead seals an instruction policy before values. Each case then starts a fresh provider context, with all permitted training data and the entire label-free held-day batch available through actual isolated analysis workers. It may author/edit query-local executable analyses and its final method. No case outputs, traces, fitted state or held labels return to a global author or another case. One case is one full held-day batch, not one LLM conversation per sample.

F and I receive identical permitted training/query batches, numerical TTA capabilities and case resource envelopes. The complete held batch may participate in a predeclared F numerical adaptation rule. F's later provider outputs are only finite typed matrices for predeclared slots: each has fixed source prompt, input/output width and training/query/one axis. They cannot be interpreted as executable code, dependencies or a new unrestricted plan/DSL. This post-query restriction does not restrict initial F method construction. Actual semantic admission remains necessary; arbitrary Python cannot be universally certified by these structural checks.

Public parts contain ordered opaque row IDs, the complete person channel union, mask [n,C,5000], fractional offsets [n], float64 x [n,C,5000] unless C, and six context values unless N. Training parts alone contain all three labels. Actor context carries the complete training/query ID lists and a passed seed, with no original person/day map, D flag or private fitted-reference capability. The same fit/predict seed is passed, Python random and NumPy legacy RNG are initialized; arbitrary library RNGs must use the passed seed and independent qualified method/environment contract. Provider nondeterminism remains distinct.

Targets are folded vertical angle in degrees, magnitude in pixels, onset speed in pixels/s. Raw predictions must be finite before a shared projection clips angle to [-90,90] and other outputs below at zero. All raw and projected outputs are retained. No row may disappear because every neural sample is masked.

T1 exposes only three complete R1 selected-NC output columns per role, derived from the exact case's training-only selection/final fit. Training outputs are explicitly in-sample, never held-out validation. All training and query prediction work is scheduled and charged, without extra hidden fits. Model states, private selection files, reference source and operator bank metadata are absent from actor mounts. T0 has no tool bank.

D binds the identical source-only NC F program or I policy, provider configuration and paired declared seed contract. Every D case context, analysis, fit, feature/projection state and selection remains fresh. The complete within-day neural/mask/offset bundle is cyclically reassigned by the separately qualified preparation mapping; recipient C and targets remain unchanged. No original-query-derived artifact, tool output or fitted cache crosses arms. There is no explicit actor arm cue, but inferred perturbation and provider randomness remain possible. This is assignment sensitivity for one realized policy, not a causal/exchangeability or author-variance estimate.

Source-controlled tool feedback and submitted claims are candidate-influenced evidence. They do not independently prove tool use, correctness or scientific understanding. HTTP messages and original responses are retained privately with exact source/method/operation links; credentials are neither hashed nor logged.

The V3 source-owned actor_context supplies the complete positive cue/epoch/mask/context-column/target/score contract and selected software inventory before values. Global source setup explicitly names C/N/NC and T0/T1; F/I are matched and D reuses original NC without an arm cue. This context pin enters exact method admission and independent provider-message reconstruction. No study values or private reference capabilities enter it.
