## Family R: regularized spectral/history regression

Use12fixed windows: the ten consecutive1s blocks across[-5,+5), plus[-1.5,-1) and[0,.5). Select each window by actual r_j half-open interval membership, including the retained fractional cue-to-grid offset. Assert exactly500 source-grid positions per1s window and250 per.5s window under the qualified arithmetic, before applying availability masks; day-edge padding does not remove a position. Do not silently recenter a DFT window or accept499/501/249/251 positions. At each channel/window, w[n]=.5−.5cos(2πn/(L−1)) (symmetric Hann); v=M*w. Subtract the v-weighted mean of X' and form z=v*(X'−weighted_mean). If sum(v²)=0, mark no weighted support and set the corresponding neural features to zero. Otherwise use the one-sided DFT periodogram |DFT(z)|²/(500*sum(v²)), doubling positive non-Nyquist frequencies; integrate a band by summing bins whose physical frequency falls in it and multiplying by500/L. There is no filter fit, zero-as-gap inference, interpolation, FFT padding or ROI averaging. Finite-mask padding changes the spectral observation operator and is reported; this is not a claim of unbiased spectral reconstruction under gaps.

The nine disjoint bands in Hz are[1,4),[4,8),[8,32),[32,55),[65,76),[76,100),[100,115),[125,175),[185,200] (the last includes200). These retain the source nominal low/high band limits with an explicit prospective DFT endpoint convention and avoid60Hz harmonics. They do not assert author Morlet/filter numerical parity. The fixed feature is log(power+1e−12) in standardized-signal units. Append one early-minus-baseline log-power contrast per band/channel, zero only if either window lacks weighted support. All12window powers and nine contrasts yield117*C_s neural features; no validation-selected band or lag search.

Common S has four mask features for each of the12windows/channel: observed fraction, longest missing run divided by L, any observed sample, and positive Hann-weight support. Thus dim(S)=48*C_s; the full R/tree design dimension P_s=6+165*C_s is retained for C/N/NC, with unavailable blocks fixed to zero. The mask features reveal partial support consistently. The original neural values and full binary masks remain in the model input contract even though R chooses this finite summary.

Fit standardized target by ridge with an unpenalized intercept:
(1/n)||y'−b−Z beta||² + lambda||beta||².
Training feature centring makes b=0 in standardized coordinates; retain the explicit intercept in the state. The nine lambdas are10^k for k=−6,…,2, ascending. Use exact full feature coordinates; no PCA, screening or query covariance. A numerically qualified primal or dual solve is allowed, never an unreported rank truncation. Family R has9configurations.

## Family B: nonlinear spectral/history model

Use exactly R's full features/mask/timing opportunity, with the same train-only transforms. Fit deterministic squared-error gradient boosting, starting at the training standardized target mean. Learning rate=.05; no row or column subsampling. Configurations are the Cartesian product maximum leaves{4,16}, leaf L2{1,10}, and tree count{100,300}:8configurations.

Inside each fitting scope, freeze up to63feature thresholds from64quantile bins. For sorted n training feature values, threshold j uses the value at index ceil(j*n/64)−1 for j=1,…,63; retain unique values strictly below the maximum. Left branch is <=threshold. Constant columns have no splits. Minimum leaf size=max(2,ceil(.05*n)); the unsplit root is allowed when no split satisfies that floor. For residual r, leaf value=sum(r)/(leaf_count+leaf_L2). Split gain is the sum of child sum(r)^2/(count+L2) minus the parent term; require strictly positive gain. Grow best-first to the selected leaf cap, tie-breaking by ascending feature index, threshold rank, then leaf-path bitstring. Same gain and reduction-order contract is implemented independently below. Finite masks remain predictors through S; there is no separate learned missingness branch.

## Family T: learned regularized temporal/waveform network

This family learns temporal filters from the complete5000-sample waveform; it is not a fixed-feature ridge substitute. Input is[2*C_s,5000], concatenating X' (zeros for C) and binary M. Do not infer a quality mask from waveform amplitude. The same schema and convolutional capacity apply in C/N/NC.

Layer sequence: Conv1D(2*C_s→W,kernel25,stride1,padding12,bias), exact GELU(x)=.5*x*(1+erf(x/sqrt2)), then AvgPool1D(kernel5,stride5) to1000positions. Follow three residual blocks with dilations1,4,16; each block is Conv1D(W→W,kernel9,same zero padding4*d,bias), GELU, training-only dropout.1, Conv1D(W→W,kernel9,same padding,bias), then GELU((input+branch)/sqrt2). No batch normalization, instance normalization, query-batch fit or channel selection.

The temporal path retains the exact5000 input positions,500-position source-index bins, length5pooling to1000 positions, and ten100-position latent-index bins. These are ordered source-grid shapes, not interpolated onset-centred samples; their actual relative support remains r_j.
