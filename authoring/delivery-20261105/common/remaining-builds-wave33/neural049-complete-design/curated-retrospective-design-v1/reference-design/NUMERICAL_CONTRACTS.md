# Two independent numerical reference contracts and API

These are written specifications for two later separately authored implementations, A and B. No implementation, module import, fixture, numerical computation, framework execution or source acquisition is selected by this document. The same scientific method/grid is implemented twice for independent numerical/custody evidence; these are not six new scientific families or additional benchmark IDs. Shared permitted artifacts are this contract, primitive event/mask schemas, source pins and ordinary low-level numerical libraries. Neither author imports the other's scientific feature/fit/predict code, fitted state, selected configuration, predictions or finished-output callbacks. Their complete results are independently produced before comparison. A=R1 is the normative scoring and supplied-tool anchor; B=R2 is a mandatory independent check. Neither better performance nor A failure authorizes substituting B as the anchor.

## Frozen metadata/API surface

Each FitScope identifies task/version, implementation, endpoint, family/configuration, person, logical outer/inner role in the consumer record, canonical unordered excluded-day set or final training-set identity in the fit record, exact ordered training day/event roster, source-generation/clock/channel-axis/mask-constructor pins, input view C/N/NC/NC_D and random-stream contract. All events include opaque row identity, released target field/units where training is permitted, actual relative5000-position source grid r_j=s0+(ceil(500*(e−5−s0))+j)/500−e, j=0,…,4999, retaining fractional offset, complete channel axis, source/structural support and six timing fields only when permitted. Query views contain no endpoint/proxy labels. Separate masks are exact primitive booleans; source reasons/absolute identity joins remain protected operator metadata.

`fit(scope, training_events)` returns a sealed state and complete work disposition. State includes all input/source/interface pins, full event/day support, channel means/scales/inactive flags, scalar feature/target means/scales, every feature/column identity, full configuration and seed algorithm, numerical environment/dtype, complete coefficients/trees/network tensors, declared training steps and source-level execution lineage. Zero/empty/constant dispositions are explicit. The trained object cannot consult a new query or an external result callback while being sealed.

`predict(state, assigned_event_batch)` returns one finite RAW scalar in original target units per assigned original event and its separately named common-rule projected scalar, plus original opaque IDs, exact state/source/view pins and support flags. It is stateless: no updated parameters, cross-query fitted normalizer, new learned channel-quality mask, target-dependent threshold or mutable prior-output channel. Full source-supported input shapes/rows are required, including entirely masked events. Its stateless per-event normalization, convolution/periodogram and fixed physical-domain projection are those in REFERENCE_SPEC. Numeric-only T1 access uses this same interface and exact state; operator metadata must be projected out of actor tool outputs.

`select(outer_scope, full_inner_results)` requires every prescribed configuration/inner-fold result and training/validation identity. It computes complete pooled inner SSE/counts, selects within family, refits every family and seals the train-only strongest-family alias. It cannot read outer targets. The source-owned selection report records all configurations, complete inner prediction artifacts and original-unit sums; failed configurations do not silently disappear. A selected outer state is never an unbound caller-supplied object.

## Independent feature/mask/transformation paths

A: explicit two-pass float64 training channel/feature/target statistics; direct window arrays; source-owned symmetric-Hann construction and one-sided FFT periodograms; explicit masks, contrasts and stable feature-column order.

B: independently written streaming accumulators/centred reductions with the same population-statistic definitions; independently assembled window/mask support and frequency bins; an independently invoked FFT/DFT primitive, not A's feature bank. It can stream complete channels/events but may not approximate frequencies, drop axes, reduce precision or select a smaller cohort. Both use the same prospective feature formula, not unknown author Morlet defaults. Both must distinguish observed zero from absent/nonfinite input, preserve every column and report zero/all-masked/constant cases. Basic schema checks may be shared; scientific feature bodies are not.

All intermediates used for comparison are indexed by full event/channel/window/band identities. Feature parity is checked before model parity in later selected qualification. Window membership uses actual r_j, asserting500/250 positions for1s/.5s windows under qualified arithmetic; no temporal recentering/interpolation is allowed. No current tolerance or source success is a claim of authentic native parity. Exactly matching integer membership, masks, full support, configuration enumeration and metadata is mandatory; floating differences must be assessed under a separately selected, pre-outcome numerical error/tolerance contract, never an outcome-selected loosened tolerance.

## A/B ridge implementations

A implements a centred full-coordinate primal Cholesky solve when P<=n, and the exact dual Cholesky identity otherwise: beta=(Z'Z+n*lambda*I)^−1 Z'y' or beta=Z'(ZZ'+n*lambda*I)^−1 y'. Predictions use the full beta, training feature transforms and unpenalized target mean. No singular-value cutoff, covariance shrinkage beyond the selected lambda, pooled neural ROI or feature-rank truncation.

B independently implements ridge through a full SVD/augmented-QR formulation, including the same n*lambda and all nonzero/zero singular directions. The specification is beta=V diag(sigma/(sigma²+n*lambda)) U'y', with exact zero coefficients for zero singular directions; no approximate/partial SVD or data-selected truncation. Dense coefficient storage, equivalent factor storage and blockwise multiplication must produce the same full prediction function. Its own statistics/features are used; A's fit factors are unavailable. Comparison checks objective residuals, coefficients/predictions and shape/custody on complete selected support in later qualification.

## A/B boosted-tree implementations

A independently scans each frozen training threshold and admissible leaf partition in deterministic row order, computing leaf values/gains from complete residuals and growing best-first under the exact tie rule.

B independently builds training-bin sufficient statistics (counts and residual sums), forms exact prefix statistics and derives the same permitted split candidates and gains, then reconstructs the complete trees. The same threshold identities/<=rule, leaf floor, regularization, learning rate, initial mean, tree count and fixed tie order are mandatory. It must not call A's split routine or import a fitted tree, and may not replace this specified method by a library's superficially similar defaults. Compare complete tree membership/thresholds/leaf values and all predictions, not just final aggregate loss. Integer counts/rosters must match exactly. Near floating split/selection ties are a numerical qualification issue, not permission to pick whichever implementation scores better.

## A/B learned temporal network implementations

A uses a concrete independently authored tensor/autodiff implementation of the exact conv/pool/residual/GELU/readout graph in REFERENCE_SPEC, with its own optimizer loop and full fixed training schedule.

B uses a separately authored mathematical graph with the same tensor axes and parameters, preferably an independently implemented convolution lowering (explicit indexed patches/matrix multiplication) and a distinct qualified autodiff/backend path. It cannot call A's module or use A's gradient/update/checkpoint. Low-level tensor libraries may be common only if independence of the complete scientific graph and optimizer source is documented. Replacing the model by fixed random features, a shallower network, another loss or a population-pretrained decoder is not an acceptable B implementation.

Canonical tensor axes are channel/time for inputs, output/input/kernel-index for Conv weights, output/input for Dense, and event-major batches. Convolution is cross-correlation (no kernel reversal), zero padding is symmetric, all pooled positions are retained. The exact5000 source-index positions retain their actual fractional alignment. The first length25convolution precedes nonlinear activation and length5average pooling to1000 positions; the ten100-position latent bins correspond to ordered500-position source bins without resampling. Residual dilations1,4,16 and the ten ordered100-position readout bins are literal. Global means/maxima are not substituted for the ten bins. Max ties backpropagate through the first temporal index; dropout is inverted Bernoulli keep=.9, applied only at the two specified kinds of training site; inference disables it. There is no batch-dependent normalization.

For each fit, a pure counter stream is derived from SHA-256 of a canonical UTF-8 JSON array containing version, family T, endpoint, person, exact ordered training-day IDs and training-event IDs, public source-generation identifier, architecture width and stream kind. The ordered outer/inner consumer role is absent. Training targets, amplitudes, validation/query values and selection outcomes do not determine the seed. It deliberately excludes C/N/NC/D, implementation A/B, weight decay and epoch budget, so matched views/configurations do not become a seed search. For weights, add full tensor name and element index. Use the first8digest bytes as unsigned big-endian64-bit integer u64, set u53=u64>>11, and map to u=u53*2^−53 exactly in float64 on[0,1); Xavier uniform has half-width sqrt(6/(fan_in+fan_out)), biases zero. Conv fan sizes include kernel length. Epoch order is increasing hash(seed,'shuffle',epoch,event_id), with event_id as deterministic final tie-breaker. Dropout adds epoch, batch-position-independent event_id, layer, feature and time indices. No framework-global RNG or data-dependent draw count can change the stream. Canonical encoding is UTF-8 JSON, ensure_ascii=True, no whitespace, ordered arrays, finite integer/string identifiers only; there are no unordered dictionaries or floating values in the seed tuple. Tensor indices are zero-based integers. No framework-global or outcome-dependent random source is permitted. Exact training-array/label/source/transform pins additionally enter the fit-cache key even though they are not outcome-valued RNG inputs. Same training support across the two ordered consumers therefore has the same initialization and update order.

For step t with mean batch squared-error gradient g, first clip its full parameter L2 norm at1 (zero norm remains zero). m=.9*m+.1*g and v=.999*v+.001*g²; use standard bias corrections at t. Update theta=theta*(1−lr*decay)−lr*m_hat/(sqrt(v_hat)+1e−8), with decay0for biases and the selected decay for weights. No AMSGrad, optimizer-state reuse between folds, gradient accumulation across omitted samples, validation stopping or best-state checkpoint. A smaller last batch contributes its mean loss and one update. Both implementations record actual batch roster, optimizer-step counts, initial/final state pins and all independently qualified stopping/cleanup facts.

The design fixes the numerical equations and no-autotuning policy; actual source, native framework/version/device precision, deterministic kernels, environment and error tolerances remain admission gates. A/B disagreement must remain visible; it cannot be 'resolved' by selecting the implementation with better outer R2. Complete authentic model competence and full resource feasibility remain unqualified until later authorized empirical validation. The current task author has performed no such computation.

## Degeneracy, identity and comparison outputs

All endpoint/input/family/outer-fold comparisons retain full original membership and units. All-zero channels/features, missing windows, no weighted Hann support, constant training labels and explicit empty days have named dispositions. An empty inner validation consumer contributes0rows/0SSE; absent training support or zero total inner validation support blocks selection, not a single empty validation day. The cue and target are from the same required intervals/reaches row; the unused separate ReachEvents product is not a manufactured prerequisite or positional join. A and B must agree on those metadata cases and exact requested work. Admitted released nonfinite samples follow the explicit mask policy. Unadmitted nonfinite-source handling, nonfinite predictions, ambiguous clocks, unsupported targets or missing models/outputs are retained failures, not fallbacks to an easier estimator.

Later qualification should include independently authored mathematical tests for masked spectrum normalization, ridge primal/dual/SVD equivalence, tree gain/tie/leaf constraints, temporal parameter/gradient/update correctness, event/day exclusions, D whole-bundle ancestry, target-last grading and supplied-tool state identity. These are a proposed future test plan only: no fixtures or numerical tests were created or run here. A third independent expected-answer calculation may be needed where two implementations share a basic primitive; two agreeing outputs alone are not proof of truth.
