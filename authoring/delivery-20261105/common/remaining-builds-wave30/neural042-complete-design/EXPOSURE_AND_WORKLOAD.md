No clinical metadata/mask bodies, exact source-to-opaque map, raw signal, patient-derived examples, fitted models, intermediate PAC, original result scalars as targets, earlier task runs or actor transcript bank. Reading public papers beforehand is disclosed exposure; it is not counted as unseen knowledge.

No other person's authentic observations. ## Disruption construction and target meanings

D uses a qualified private pre-study control seed (not an identity key) with committed seed provenance. Its value and donor map stay operator-only; a public seed plus public IDs would make the mapping trivially reversible. No seed is generated/read in this design. For each channel separately and each (row//35,probe) stratum, take all retained eligible trials, sort by opaque recipient ID, and choose a uniform nonzero cyclic shift where size≥2. Reassign the complete (waveform, same-window rate) bundle under recipient identity while keeping original recipient load/correctness/probe/order labels. For size1 use identity and record it. Strata and support are never reduced to make disruption convenient. Operator qualification proves a bijection, exact bytes/shapes, moved-rate pairing and no donor-label or map exposure. Fixed control draws are independent of effect size and common across F/I T0 cells.

This removes part of waveform-to-condition correspondence; it retains within-trial PAC, event-relative structure and each bundle's internal neural content. It can alter cross-channel alignment, conditional power balance and matching support. It is therefore a correspondence diagnostic, not a clean total neural-ablation or causal surrogate. A stronger multichannel or phase-randomized null would be a new separately reviewed condition, not an implementation shortcut.

The **primary target is always the qualified original O report**. O/T0 andO/T1 are canonical full-report reconstruction. D/A test recovery of that same report from changed/absent evidence. D is additionally scored against its own qualified D report as a distinctly named self-consistency diagnostic. This prevents interpreting a correct computation on D as an inability to compute PAC. Both O-target andD-target report schemas, support outcomes and targets are separately named and private.

Canonical support mismatch/invalid output does not have a numerical MAE. Compare strict complete-report success/eligibility and per-endpoint status across all36 people before discussing conditional numerical errors. Never replace invalid/null values with zero, compare only favorable complete cases as if they represented the whole cohort, or invent a scalar “neural gain” from undefined errors. A/D may fail to reconstruct original support itself. If both compared reports are valid and their canonical scores are defined, report paired errors on the original fixed reference-supported people; otherwise report the exact structural/support failure and leave that numerical contrast unqualified. D self-consistency uses D's full support and does not silently replace the O-target metric.

Original-query-derived code/constants, embeddings, summaries, method state, logs, tool outputs, predictions and provider prompts cannot cross into D/A. The immutable F source and I base policy are the only common method artifacts; they precede all query exposure. No adaptation on O followed by replay can qualify the full-workflow controls. Any such optional later replay must be separately named late-input sensitivity.
