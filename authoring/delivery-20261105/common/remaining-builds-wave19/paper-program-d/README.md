# PAPER-FIND-050: empirical-core reproduction and retrospective prediction

This source package turns the selected empirical core of *A critical initialization for biological neural networks* (Nature, 2026; DOI `10.1038/s41586-026-10528-1`) into a paired paper benchmark. It implements all 29 selected sessions: 26 calcium recordings and three electrophysiology recordings. It adds no canonical task IDs.

The reproduction endpoint retains the selected original Figure 2/3 estimands: all 500 covariance/SVCA ranks, the original PC correlation outputs and all source-defined DMD modes. It preserves the source's branch-specific preparation, rank support, signed values and temporal block conventions. This is the complete **selected empirical core**, not the complete figures or whole paper. Shuffle, neuron/time subsampling, running-state, simulation and other supplementary sweeps remain excluded. Source-derived reference composition is not evidence of numerical parity with a historical published run.

The separately named `chronological_five_frame_processed_signal_v1` asks whether a method can predict the full neural population five frames ahead on the final fifth of each processed recording. All 29 sessions and all admitted neurons remain. The model fits on the first four fifths; every query prediction is sealed before the next input frame is exposed. The evaluator computes complete candidate and independent DMD, persistence and diagonal AR outputs. It reports session MSE, equal source-label-group MSE, reference-minus-candidate differences, and separate modality/region summaries. It does not combine forecasting and reproduction scores.

Both endpoints compare paper + data with paper + data + relevant author source. Four independent authoring contexts produce the two native and two forecasting programs; all four freeze before numerical exposure. B receives 11 authenticated files totaling 142,426 bytes: nine original files and two explicitly identified notebook-code extractions. The original five-file condition is preserved as history. This is not a complete GitHub checkout: original notebooks with outputs and `simulations.py` are unavailable in this closure. No candidate receives the operator runtime or reference artifacts.

## Concrete implementation

- `program/prepare.py` prepares the complete original roster under a separately selected authority. It authenticates source and original inputs, preserves source population support, and computes development-only normalization. Actual preparation has not been run here.
- `program/observe.py` captures the selected source and launches `controller.py` with the original clock. The controller stages exact per-role inputs, freezes programs, and composes all **261 producer phases**: 87 native, 87 fit and 87 stream phases. Host preparation, staging, observation and protected grading are additional work.
- `program/engine.py`, `docker_cli.py`, `holder.py` and `stream_io.py` implement future owned-container lifecycle, capped capture, sealed model transfer, and chronological duplex inference. Native Linux Docker, immutable images, package versions and full-workload feasibility need separate qualification.
- `program/reference_math.py` implements the three prospective comparators. The native helper closure is retained under `program/native-source/`; original and extracted B source is under `program/author-source/`.
- `program/grade.py` authenticates an independently selected complete source manifest against the collected run, requires external natural-close admission, and checks all 261 phases and all outputs before opening protected targets. Its result is not a claim of scientific qualification.
- `program/adapter.py` keeps central dispatch disabled until root explicitly selects and qualifies an operation. `REGISTRATION_PROPOSAL.json` identifies the concrete source paths for root's serial integration; this worker has not edited central registries.

The CLI authorities must pin the source manifest, exact files, environment, resource limits and original origin. Preparation and grading additionally require `root_source` to be the executing source directory and use the same complete manifest as collection. The initial authority read is bounded to 1 MiB before materialization and charged into the original-clock ledger. Docker and duplex output reads, including overflow bytes, are charged when materialized. Outbound duplex bytes are separately recorded; this accounting is not total OS physical I/O, subprocess-internal work or measured RSS.

## Evidence and limitations

`DESIGN.md`, `EVIDENCE.json`, `DESIGN_EXPOSURE_ADDENDUM.md` and `AUTHOR_EXPOSURE_INVENTORY.json` preserve the reviewed source-grounded design. `forecast-math/` retains the author's math derivation and engineering controls. `peer-review/` contains the sole independent review. `history/runtime-v1/` and `history/runtime-v2/` preserve the earlier implementation freezes and their executed control sources. The final runtime changes only `prepare.py` relative to v2, adding a separate conservative read charge for the second NPZ decoding pass. `checks/V3_SOURCE_DELTA.json` preserves that exact distinction; v2 test observations are not relabeled as a new full v3 run.

The original ephys eligibility mask uses full-session firing rate, so population support is transductive. Calcium inputs are already processed/deconvolved, and upstream temporal causality is unqualified. The prospective endpoint therefore concerns retrospective prediction in the released processed signals; it does not establish online prediction, causal dynamics or generalization to new animals. The repeated FX43 label is conservatively grouped, yielding 28 source-label groups whose biological independence remains unresolved.

Twelve author RAM/mock control groups passed for the second runtime freeze. They cover complete-roster closure, chronological exchange, source binding, bounded authority reads, transport accounting and resource ownership. They did not invoke native processes or scientific analyses. The first control run undercounted repeated metadata copies: the corrected 700 KB retained / 2.1 MB cumulative bound exceeded its former allocation. `checks/ACCOUNTING_CORRECTION.json` preserves that overrun and the later prospective extension; later passing controls do not make the earlier accounting compliant.

Independent v2 controls passed eight numerical/metadata/stream groups and six mocked boundary groups, with an additional explicit source-order inspection. The failed environment attempt remains in the peer records. Independent v3 authentication checks all 46 source members and the single changed preparation member; it does not substitute source review for scientific execution.

Authentic full-input/shape admission, original numerical parity, environment and process qualification, reference competence, actual resource feasibility, method/exposure review and scientific evaluation remain open. **This is reviewed source construction, not a ready benchmark, a reproduced scientific result or an improvement claim.**
