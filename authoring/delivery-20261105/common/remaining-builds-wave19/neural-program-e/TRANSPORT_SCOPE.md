# Native transport and cost scope

The source derives from the exact reviewed NEURAL014 transport listed in TRANSPORT_INITIAL_REUSE.json. Changes bind the NEURAL089 namespace and only fit/infer phases; six separately sealed models support the complete two-role roster. Root must choose an exact already cached numerical image, explicit producer intervals, actual input plan and qualified resource envelope before execution. The 8 GiB free-space floor is a conservative policy, not a measured task requirement. No shared Docker service or installed image was changed by source construction.

The host authenticates every complete projected source file before exposing a numerical view. A later pointwise query read must match that original file stamp. Training views stream-copy complete pinned sources; query views contain exactly one complete window. No original query labels or label-bearing provenance are opened by runtime staging. All candidate mounts are read-only apart from the bounded isolated output; one selected phase runs per fresh native container.

Model capture at seal/final/independent outer admission hashes full bytes. Individual inference phases mount the same read-only sealed model and compare its original file stamp before/after; they do not host-copy or host-hash the model per query. Consequently host managed I/O and native model exposure are distinct. The separate `(6Q+2) * model_cap` value bounds declared mounted model bytes over inference invocations. The observer also sums actual mounted model sizes from authenticated seals. Neither is measured physical I/O. The independent reference source declares one pickle load each inference; arbitrary candidate payload rereads, OS caching, filesystem overhead and native library I/O remain unmeasured. Fixed reference passes are source declarations; arbitrary optimizer update counts remain unknown.

A source hash and a read-only artifact cannot certify that a method never adapts to its single supplied query window. The explicit independent method/exposure admission remains required. Input, native isolation/runtime, image/numerical equivalence, actual complete-panel cost and scientific/reference competence remain unqualified. This build does not execute a container, decode original data, fit a model or call a scientific scorer.
