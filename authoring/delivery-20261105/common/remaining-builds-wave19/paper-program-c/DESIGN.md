# Proposed OSL paper program

This design proposes **PAPER-paper-signal-add-004**, *osl-dynamics, a toolbox for modeling fast dynamic brain activity*, Version of Record DOI **10.7554/eLife.91949.3**. It is unregistered in the inspected 80-runtime / 31-paper snapshot. It adds no task, condition-derived benchmark or scientific qualification. Selection is provisional until the parent and designated peer assess this boundary; implementation has not begun.

The chosen task has original paper-era computation, complete named empirical cohorts and concrete independent predictive controls. These are the selection reasons. Small storage is not a reason. `DESIGN_EVIDENCE.json` pins the exact held TASK, source contract, native recipe and registry snapshot. NoMAD was considered first but its selected decoder condition changes normalization, lagging and evaluation; that prospective exercise does not establish the missing original end-to-end paper reproduction. MEG's historical table endpoint is real, but its complete feature-producer/configuration selection is unresolved. Neither gap is hidden by choosing a convenient route.

## Original reproduction boundary

The native route is the paper-cited Software Heritage revision `cded3b2ea95efef7b6c089c5e111fd565b716922`, declared version 1.2.dev12. The retained six author scripts are authenticated original method implementations. Their outputs reconstruct the original empirical analyses, rather than a replacement predictive exercise. Later PyPI 1.2.11 is not substituted. Existing observation-only capture derivatives preserve the non-capture AST, and their exact source/capture delta must remain visible.

Native reproduction covers every original selected empirical branch:

| Branch | Complete cohort / data | Source method and outputs |
| --- | --- | --- |
| ctf_bursts | 65 people, left motor signal, 100 Hz | 3-state TDE21 HMM; all burst summaries, state spectra/covariances and envelope relationships |
| elekta_ae | 19 people × 6 runs, 38 Giles parcels, 250 Hz | 8-state envelope HMM; spatial states and complete task-event state responses |
| elekta_tde | Same 114 complete runs | 8-state TDE15/PCA80 HMM; full spectra/networks and event responses |
| ctf_tde | All 65 people, 38 parcels, 250 Hz | 8-state TDE15/PCA80 HMM; temporal/network structure and age relationships |
| ctf_dynemo | Same 65 people | 7 continuous modes; regression spectra, coactivation and age relationships |
| ctf_static | Same 65 people | Four-band Welch power/coherence and amplitude-envelope correlation |

Each of five stochastic branches retains three sets of ten full attempts, selecting minimum training free energy within each set; every failed attempt stays in the ledger. Static analysis runs once. No arm may select people, runs, time crops, states, modes or frequencies for convenience. Native numerical age boundaries, 114-run Elekta inference and the original evidence-log defect remain documentary source behavior. Already declared corrected age/event sensitivities are separate outputs. Original seeds are unrecovered: new explicit seed schedules will be identified as prospective reproducibility choices, never historical checkpoint recovery.

The reproduction report must distinguish (a) independently executed original-method estimates and the original scientific quantities, (b) stochastic agreement with a separately executed operator reference, and (c) the existing same-fit numerical audit. A same-fit audit is never promoted to independent reproduction. No rounded paper figure values become reference truth. Reference fitting, numerical tolerances and empirical stochastic variation remain unqualified until actual authorized runs.

The full paper also contains methodological/simulation illustrations (Figures 7–12). Their source coverage is an explicit whole-paper obligation, separate from the six empirical branches. If complete illustration entrypoints cannot be bound from held source, the implementation must preserve a named incomplete branch and must not describe the entire paper as reproduced or complete. It must still implement the complete empirical program rather than replacing it with that hold.

## Separate improvement and references

The existing prospective condition retains all 65 CTF people and all 19 Elekta people × six runs. SHA256-ranked people are assigned round-robin to five folds using the frozen task salt. All runs from one person stay together. The four branches are bursts (21 dimensions / 3 states), AE (38 / 8), CTF TDE (80 / 8), Elekta TDE (80 / 8). No DyNeMo likelihood is substituted for this Gaussian-HMM endpoint or pooled with it.

Standardization/PCA uses training people only, with the existing fixed rank condition; all retained query samples use the frozen state. The candidate receives the training represented runs and the declared program/resources, not private query observations or labels. Native-family reference HMMs are fitted separately on exactly those training people and selected solely by training free energy under the same three-set/ten-attempt policy. The static Gaussian uses the existing `1e-6 × mean training variance` ridge. Neither reference can be weakened or replaced by the candidate.

Common-phase and independent-phase surrogate-trained controls are required, with fixed seeds and the same fit budget, then assessment on the identical real query recordings. The exact ordering of phase randomization and fixed representation must be resolved and recorded from the existing contract before implementing; the design does not silently pick a new estimand. Controls do not add benchmark IDs.

For a run `x[1:T]`, score the exact Gaussian HMM density with normalizing constants:
`alpha_1(j)=log(pi_j)+log N(x_1;mu_j,Sigma_j)` and
`alpha_t(j)=log N(x_t;mu_j,Sigma_j)+logsumexp_i(alpha_(t-1)(i)+log A_ij)`.
Reset the initial distribution at every run and retain structural zeros. For each person sum run log likelihoods, divide by the total represented samples, then average people equally. Report absolute candidate likelihood, independent HMM/reference likelihoods and signed gains separately for every branch/fold/set/control. No density across incompatible represented spaces is averaged into one reward. Negative gains are valid. Non-SPD covariance, invalid simplex, missing runs or undefined arithmetic is explicit; no scoring-time regularization or favorable support deletion.

The native audit retains its source-defined normalized absolute error and undefined-pattern rules. Independent-fit correspondence/variation is a separate report, with no arbitrary pass tolerance or automatic biological-success flag.
