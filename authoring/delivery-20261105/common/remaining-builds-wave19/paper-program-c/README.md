The program covers the original CTF burst, CTF TDE-HMM, CTF DyNeMo, CTF static, Elekta AE-HMM and Elekta TDE-HMM routes. CTF retains all65 people. Both Elekta routes retain all19 people and all6 runs per person. No branch, run, spectral component, state, condition or failed attempt is removed to obtain a score. Native source has3 burst states,8 HMM states and7 DyNeMo modes. Literal original static/dynamic age splits and run-level Elekta inference are preserved.

Native and prospective representations are different profiles. The four held-person objectives remain separate embedded-space likelihoods, not a pooled signal-density claim or a DyNeMo replacement.

The engineering flow is concrete source:

1. `core.py` fixes original people/runs, person folds, all attempts and new prospective seeds. `prepare.build` transforms complete operator-bound raw regional runs, fits only real training people, freezes the representation, then makes original-run phase controls and private real query arrays. It writes its completion record only after every run/control. `prepare.training_view` exposes one training control without queries.
2. `access.admit` checks a separately trusted complete image/source/mount audit. A excludes installed, mounted, cached and reachable author OSL implementations, including known renamed copies and reviewed derivatives. B and the independent operator use the exact historical source in distinct images. Full inventories and actual provider isolation are required; a different PYTHONPATH is insufficient.
3. `native.capture.build` creates reviewed AST-instrumented derivatives only in a future fresh location. The AST proof preserves all original statements after capture calls/imports are removed. `native_run.run` invokes those exact B/operator scripts with a source-bound sink. Primitive captured arrays retain all spectra, both NNMF components, events, original inference, fitted coordinates and typed auxiliary model/configuration state. No pickle or candidate executable is admitted into the operator.
4. `reference.fit` supplies a concrete independently executed historical-family HMM comparator for every full training branch/fold/control/set/attempt. `reference.static` fits the same real-training representation Gaussian. Neither takes query observations or candidate state. Native operator references independently execute every original branch. Actual execution remains paused.

No provider callback implementation is missing, and no actual provider environment is qualified.
