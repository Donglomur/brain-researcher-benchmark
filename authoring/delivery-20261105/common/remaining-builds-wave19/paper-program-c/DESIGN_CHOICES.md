# Concrete source choices for review before implementation

This supplements DESIGN.md. Root accepted the six original empirical branches as the source-build objective, with historical seeds and whole-paper acceptance separate. These resolutions are proposed for paper_c's check before dependent implementation.

## Access correction

The OSL implementation is the subject paper's author code. Arm A must have neither historical nor current `osl_dynamics` installed, mounted, cached or reachable. An environment that differs only in PYTHONPATH is insufficient. A receives the same paper, complete allowed observations, contract and permitted general dependencies (for example NumPy, SciPy and TensorFlow); B alone additionally receives the exact pinned historical OSL source and its approved dependencies. The independently executed operator reference uses a separate private OSL environment. Freeze complete image/source/module inventories and isolation-policy identity. No trusted reference, fitted/native state, other-fold inputs or operator package is mounted into either candidate arm. Actual environment isolation is not qualified by this source build.

## Prospective phase-control order

The source helper `preprocessing.phase_randomize` accepts a time-by-channel real run and preserves its periodograms; common-phase preserves that supplied signal's cross-spectrum. The selected four-HMM endpoint requires the same representation for candidates and controls. The previous contract did not uniquely fix ordering. The following is an explicit prospective resolution of that gap, not recovery of historical surrogate experiments:

1. Fit all representation parameters using only the complete, unrandomized training-person runs for the branch/fold. Freeze them once; no query run is used.
2. For `real`, apply that frozen representation to the original training runs. For `common_phase` and `independent_phase`, first randomize each original training run independently at its original supplied channel/sampling grid, with a fixed run-specific seed, then apply the identical representation. Do not concatenate real runs before randomization or embedding.
3. AE preprocessing on each such original or surrogate run is exactly absolute Hilbert transform followed by the five-sample valid moving average, then the fixed training moments. The Hilbert operation uses the whole run and is retrospective. TDE uses the existing prospective channel-major, oldest-to-newest lag order, then fixed training moments/PCA. Bursts preserve the existing full 21-dimensional prospective representation. No per-query moments or PCA are fitted.
4. Every control/model is evaluated on the same real held-person runs transformed using that same frozen state. The static Gaussian is fitted on the real represented training pool and remains the common comparator. Report its relationship to each separately trained HMM control without changing the query data.

Raw-spectrum preservation describes the original input to `phase_randomize`, not the nonlinear AE or cropped delay-vector spectrum. This is the reason to put phase randomization before AE/TDE. It is not evidence of physiological causality or a surrogate-null p-value. Any original annotation gaps, physical row maps and exact retained-run inputs must remain bound by preparation; no new interpolation or discarded run is authorized.

## Native representation and state correspondence

Native and prospective representations are different profiles. Historical `Data.tde_pca` first standardizes each original run, then uses a covariance sum/SVD to derive float32 PCs, applies time embedding/PCA, and the scripts standardize the projected runs again. The prospective helper instead fits pooled training embedded-feature moments/PCA. Never match emissions across these two profiles or assert native equivalence.

For native independent-fit comparison, first require an authenticated identical representation binding: complete input/sample/run order, source/native profile, parcel/lag/PCA/component order and all fitted transformations; captured prepared-run shape/dtype/body identities provide a sufficient exact coordinate check. The reference and candidate have separate model fits. Identical representation does not mean identical model parameters or fitted state. If the coordinate binding differs or cannot be authenticated, state correspondence is explicitly unavailable. No guessed sign flip, PCA rotation, query-based matching or outcome-maximizing scale repair is permitted. Raw literal outputs, complete attempt failures and state-invariant scientific observations remain reported, but this must not yield a complete native comparison score.

When the exact native representation agrees, use the held author's `inference.modes.match_covariances` default RV-coefficient objective on independently fitted emission covariances. Its implementation forms `G=C C^T`, then `RV(C,D)=tr(G_C^T G_D)/sqrt(tr(G_C^T G_C) tr(G_D^T G_D))`; a one-to-one assignment maximizes total RV. All states/modes stay in the assignment. Covariance identity comes from complete trusted model capture, never candidate-named labels or query predictions. Preserve the original SciPy `linear_sum_assignment` operation and bind its eventual environment version, including tie behavior; retain the full cost matrix, winning order and ambiguity flag. Undefined similarity yields unavailable correspondence, not an arbitrary assignment. This matching is an assessment convention sourced from the held library, not a claim that the paper used this exact comparison. RV correspondence alone neither establishes AE mean equivalence nor identifies biological states or unique DyNeMo components.

Preserve literal original state/mode order in every stored native artifact. Apply one separately recorded permutation consistently to every state-indexed comparison array, including means, initial probabilities, both transition axes and both axes of DyNeMo coactivation. Do not independently rematch each observable. No permutation may alter people, runs, frequencies, source support or fit selection. Held-person Gaussian-HMM marginal likelihood is permutation invariant and requires no matching at all.

NNMF is separate. Held source already orders components by ascending peak frequency. Retain both components and that literal order in raw outputs; do not replace it with a better query/reference match. Record peak ties and stochastic fit differences. No historical equality or calibrated tolerance is asserted.

## Full outputs and stochastic accounting

The assembler must include all original state spectra, complete frequency axes, both NNMF components, covariance/mean axes, all person/run summaries, full Elekta event arrays and inference fields, and DyNeMo `alp_corr` (65×7×7, with its source-zeroed diagonal). DyNeMo PSD has coefficient/intercept support; coherence does not acquire an invented coefficient/intercept axis. Native Elekta event responses use `argmax_time_courses` before epoching, not averaged posterior-alpha curves.

The source spectral wrappers do not request `return_weights=True`. Absence of `w.npy` means the source's equal-average group behavior; do not silently inject sample weights. Record native trimmed sample counts separately. Undefined numerical support remains explicit and complete.

The static branch is one no-fit analysis, not a deterministic pipeline: it includes two 1,000-permutation group comparisons. Account for all native permutation inference, NNMF and other stochastic calls as well as model initialization/training. Historical random streams are unavailable. A new frozen process/run seed controls future reproducibility only; its equivalence to old paper runs is unknown.

Native role roster: each candidate arm and the independent operator reference requires all 150 model attempts (five stochastic branches × three sets × ten) plus one static analysis. Candidate A/B runs and reference are independent, for 453 scheduled branch attempts including three statics. No candidate result substitutes for the reference or for another arm.

Prospective role roster: four HMM branches × five held-person folds × three training controls (`real`, `common_phase`, `independent_phase`) × three fit sets × ten attempts = 1,800 model attempts for each candidate arm and for the independent reference, 5,400 total if all three roles are executed. Each set selects training free energy only and retains all ten dispositions. The same real training representation/static Gaussian is shared within a branch/fold only as fixed operator preparation, not as shared candidate state. For each role this yields 180 selected HMMs if all sets succeed. Candidate search beyond the fixed fit budget must be declared and cannot be silently free.

No failed attempt may trigger deletion of a person/run/branch. A set with no usable fit remains incomplete; no model or score is fabricated. The proposed source will report native and prospective budgets separately, count actual observed costs, require external natural exit/closure, and keep partial outputs unaccepted. It will not start any scientific execution.
