# Exact proposed detector mathematics — V2, pending independent/root acceptance

This is a prespecified reference design, not an empirical result or a claim that an existing package implements it. Equations below define the source implementation to be independently reviewed. No mathematical evaluation on authentic arrays or invented fixtures occurred in this design phase. ## A. Observations, labels, groups and weights

A recording r has D_r integral seconds, C_r genuine EEG channels, and calibrated values x[r,t,n,c] in microvolts for t=0..D_r-1 and n=0..255. Its exact original digital values, per-channel scale/offset and256Hz sampling are preserved. For learning only, y[r,t]=1 iff integer second [t,t+1) lies in one of that record's admitted integral-second ictal intervals. All other observed seconds are0; unobserved inter-file time supplies no observations. Original integral endpoints make partial-positive-second ambiguity impossible in this selected protocol; nonintegral input refuses rather than rounds labels.

For a training support of m biological people, let n_{p,0},n_{p,1} be their respective full observed class counts. Require both positive for every training person. Each observation of person p and class y has weight w=1/(2m n_{p,y}); therefore sumw=1 and every person/class has equal mass1/(2m). Labels only set legitimate training weights. Neither held validation nor outer-query labels contribute to weights/scalers. Validation event metrics use full continuous duration without class balancing.

Rows are ordered by sorted opaque person ID, recording ID and second. Opaque identifier values and target label bits never enter model features. Trusted grouping code may use these IDs to construct support and seed provenance. Caches may share only exact immutable target-free features/metadata under the qualified custody policy; no fitted scaler, model, threshold, fold history or validation result is reused between contexts in this initial schedule.

## B. Fixed per-second EEG features

No learned filter, ICA, rereferencing, per-person centering or test-distribution normalization is performed. Each feature uses only its one complete recorded second, across all admitted channels. This is retrospective one-second classification, not a prospective latency claim. It neither borrows adjoining seconds nor bridges a gap. Inputs must be finite; a nonfinite channel/second invalidates the full panel. Flat signals remain legitimate observations, not exclusions.

For each channel, let mean m=fsum_n(x_n)/256 and z_n=x_n-m. Define four amplitude features:

1. log1p(fsum_{n=1..255}|x_n-x_{n-1}|/255), mean absolute first difference in microvolts.
2. log1p(sqrt(fsum z_n²/256)), population SD in microvolts.
3. log1p(max x-min x), peak-to-peak microvolts.
4. log1p(sqrt(fsum x_n²/256)), uncentered RMS microvolts.

For the spectral features, use the periodic Hann window h_n=(1-cos(2πn/256))/2 and v_n=h_n z_n. Let X_k=sum_{n=0..255}v_n exp(-2π i k n/256). For k=1..127, the one-sided power assigned to that1Hz bin is P_k=2|X_k|²/(256 sum_n h_n²); it has microvolt² units. DC/Nyquist are not used in the selected bands. The five bands are exact integer-bin sets {1,2,3}, {4..7}, {8..12}, {13..29}, {30..45}. Their features are log1p(sum P_k) in that order. There is no tuning of bands to outcomes or adding sub-Hz information absent from a one-second DFT.

Feature10 is spectral entropy across bins1..45: if S=sum P_k=0 set0; otherwise q_k=P_k/S and H=-sum_{q_k>0}q_k log(q_k)/log45. Feature11 is the zero-crossing fraction sum_{n=1..255}1[z_n*z_{n-1}<0]/255; exact zeros do not count as a crossing. Signed products must be evaluated safely in the admitted finite range; overflow refuses rather than discarding an observation.

For each of these11 channel features retain three across-channel summaries, in feature-major order: median, q0.9 and maximum. Quantiles use the sorted values a_0..a_{C-1}, index u=(C-1)q, lower=flooru, upper=ceilu, and a_lower+(u-lower)(a_upper-a_lower). For C=1 all three equal the channel feature. These33 columns use all genuine derivations, including duplicate labels. Statistical summaries are the selected method, not a hidden channel subset; full waveforms remain in the full analyst view.

## C. Matched acquisition features and preprocessing

Every training support constructs its own lexicographically sorted vocabulary of exact montage signatures, from permitted training header/channel metadata only. Add one one-hot column per training montage, one explicit unknown-montage column, and log1p(C_r). An unseen query montage maps solely to unknown=1; no query vocabulary fitting. Each record's metadata vector is constant over its duration. No recording position, duration, day, age/sex, filename or ID value is a predictor. The full feature width is d=33+M_train+2. Since M_train<=686, d<=721. Exact support determines M_train; this is a bound, not observed dimensionality.

The joint condition includes all33 EEG features. `matched_no_eeg` has the same indexed columns but the33 EEG coordinates are defined zeros and absent from its read/fit authority. No EEG means/variances, caches or learned state are opened, hashed or fitted. Both conditions receive the same complete metadata, training labels, per-person/class weights and unknown-montage policy. Their metadata scalers must agree byte-for-byte under the same arithmetic implementation.

For each available column j, fit training population mean μ_j=sum w_i x_ij and variance v_j=sum w_i(x_ij-μ_j)². Transform with (x_j-μ_j)/sqrt(v_j) if v_j>0; if v_j=0 emit0 and record a constant column. A negative/nonfinite computed variance refuses rather than clamps. Withheld EEG columns have a declared zero transform and no learned statistics. Scalers are fit anew inside every inner support and final outer support, then sealed before validation/query feature reads. This matters: global or outer-support scaling before inner validation would leak validation data into model selection.

## D. Three logistic settings

For standardized rows u_i and weights summing to1, minimize

L(b,β)=sum_i w_i[softplus(b+u_i·β)-y_i(b+u_i·β)] +(λ/2)||β||².

The intercept b is unpenalized. λ is exactly one of (0.0001,0.01,1.0), in ascending order. There is no hidden multiplication by sample count or reuse of a package's differently scaled C parameter. With both classes present and λ>0, the intended objective has an identified finite optimum; numerical failure still remains possible.

Initialize b=0 and β=0. Use full-support Newton steps from the weighted gradient/Hessian, no stochastic minibatches, row subsampling, warm starts from other folds or validation-based early stopping. Solve Hδ=g using binary64 Cholesky; require positive finite pivots. Define vector infinity norm as max absolute coordinate and matrix infinity norm as maximum row sum of absolute entries (row sums use the frozen fsum rule). Compute a=||Hδ-g||∞ and b=||H||∞||δ||∞+||g||∞ from the same captured H,g,δ. Require every H, g and δ component finite; signed entries may be negative. Require the norms, a, b and their norm products finite and nonnegative. The selected normwise backward error is a/b when b>0; if b=0 it is0 only when a=0, otherwise the fit refuses. Require this error<=1e-10. Overflow or nonfinite norm arithmetic refuses; it never becomes an implicit successful zero residual. No diagonal jitter, pseudo-inverse, dropped features or alternate optimizer fallback. Backtracking chooses the first α in (1,1/2,...,2^-59) satisfying finite L(θ-αδ)<=L(θ)-1e-4 α g·δ, with g·δ>0. If no step passes, fail the fit. Stop before a new step only if ||g||∞<=1e-7; allow at most200 accepted Newton steps. After accepted step200, recompute the complete objective and gradient at that final iterate and admit it only if the objective/coefficients/gradient are finite and ||g||∞<=1e-7. The linear-solve backward-error test is not the final convergence test and cannot substitute for it. Failure to meet final gradient convergence is retained and invalidates complete model admission; do not quietly use a partial iterate.

The scalar sigmoid/softplus implementation uses sign-stable formulas; every coefficient, objective, gradient, Hessian and probability must be finite. Probabilities must lie in[0,1]. Stable accumulation is required; implementation must use one reviewed deterministic binary64 reduction law and preserve its source/runtime identity. It must not claim correctly rounded transcendental or BLAS-independent output. Tiny later analytic controls will check objective scaling, intercept, weights, constants and solver residuals; authentic convergence/throughput remains a gate.

## E. Six randomized-tree settings

The nonlinear family is a fully specified extremely randomized ensemble, independently implemented or reproduced by an exactly qualified backend. It is not automatically equivalent to an arbitrary sklearn ExtraTrees version/default. Every tree uses all observations and training weights, with no bootstrap or sampled-row approximation. There are256 trees, with grid depth D in(16,32) crossed with minimum child raw-row count L in(32,128,512), ordered by increasing depth then increasing L. Root depth is0. Weighted labels may be class-balanced; the minimum-child rule counts original rows and does not invent weighted pseudo-observations.

At node A, W_A=sum_{i∈A}w_i, q_A=sumw_i y_i/W_A and G(A)=2q_A(1-q_A). A leaf predicts q_A. Stop if depth>=D, node labels are pure, rowcount<2L, or no admissible split exists. Inspect **every nonconstant permitted feature**, not a randomly selected subset. For each feature j with finite node extrema a_j<b_j, draw one threshold τ_j=a_j+U_j(b_j-a_j). Require a_j<τ_j<b_j under binary64; a rounded endpoint supplies no candidate split for that feature and is recorded. Split left on u_j<=τ_j, right otherwise; both children must have at leastL original rows and positive weight. The gain is G(A)-(W_left G(left)+W_right G(right))/W_A. Select the strictly positive finite maximum gain, breaking equal binary64 gains by fixed feature index. If no strictly positive admissible gain exists, stop with an honest leaf. A constant/pure leaf is an ordinary specified result, not a failure fallback after an exception.

Recurse left then right, with node path a string ofL/R. Ensemble probability is the arithmetic mean of its256 tree probabilities in tree-index order. Each model records its full structure and training/source/scaler/grid identity. A memory/resource refusal, invalid numeric result or interrupted tree invalidates the whole required fit; it cannot reduce tree count/depth after seeing validation performance.

Randomness is counter-based and training-support-bound. Canonical seed material is UTF-8 JSON with sorted keys, ensure_ascii=True and separators(',',':'), with exactly these fields: task='NEURAL-010', design='neural010-full-design-v1', support_sha256 (the exact sorted training recording/second membership and input-source descriptor hash, containing no held labels), feature_schema='neural010-feature-v1', grid_index (0..8), tree_index (0..255), node_path (empty root or L/R string), feature_index (0..d-1), and purpose='split_threshold'. SHA256 hashes that byte string. Interpret the first8 digest bytes as unsigned big-endian q and set k=floor(q/2^11). The selected binary64 uniform law is U=float((k+0.5)/2^53), rounding the arithmetic to binary64; if rounding yields1, use the greatest binary64 number below1. Require 0<U<1. This explicit endpoint mapping is independent of data and validation outcomes. No global generator state, arm label, outer held-person ID or query labels enters the seed. All input source/provenance hashes are separately recorded; the support hash does not authorize reading labels outside its training support.

The nested `support_sha256` has a separate exact schema, not an implementation-chosen string. Its value is SHA256 of UTF-8 `json.dumps(document, sort_keys=True, ensure_ascii=True, separators=(',',':'), allow_nan=False)` with no trailing newline. The document has exactly `schema:"neural010-training-support-v1"`, `dataset:"CHB-MIT"`, `dataset_version:"1.0.0"`, and `records`. `records` is the complete permitted training-record list sorted by `(patient_id,recording_id)`. Every record has exactly `patient_id` (24 lowercase hex characters), `recording_id` (24 lowercase hex), `duration_seconds` (strict positive integer), `source_edf` and `target_free_projection`. Each descriptor has exactly `bytes` (strict positive integer) and `sha256` (64 lowercase hex). Records imply all integer seconds0..duration-1 in order; there is no explicit sampled-row list. Repeated record IDs, bool/float extents, noncanonical IDs or incomplete declared training support refuse. Source paths, URLs, dates, output directories, runtime IDs, condition/arm/view/replication, outer or query identities, query geometry, validation outcomes, fitted statistics, annotations/label values and random generator state are excluded. Annotation and role-access identities remain independently mandatory custody/provenance joins, not part of this randomness token.

The separately admitted preparer computes this **training-only public provenance document** using already authenticated operator descriptors, then supplies identical immutable bytes and digest to both matched conditions. The no-EEG process may hash this metadata document and verify its admitted training membership but may never open/hash the EDF or projection bodies or fit EEG statistics to recompute descriptor values. Those values are attestations from the independently qualified original-preparation channel, not permissions to open data. The condition-independent token is used only for trusted randomness/provenance; the hashes/IDs are not learned predictor columns. Identical21-person support therefore has identical token bytes irrespective of which remaining person is outer versus inner held, although the initial schedule still performs separate fits with no reuse. Final22-person supports follow the same rule. The matched metadata vocabulary/feature-index schema is deterministic from each identical training support, so shared metadata feature draws have exact paired identities.

Joint and no-EEG conditions use the same draw for a shared nonconstant metadata feature at the same node path, support and configuration. After different splits their node contents differ; matching random seeds does not imply identical fitted trees. No-EEG withdrawn columns are never candidates. Seeds are fixed before outcomes, with no seed search or multiple-run best selection. Three analyst replications do not retrain these detector references.

## F. Exact nested selection

For each outer held person p, for each of the two strong conditions, for each of nine grid settings, and for each inner held training person q≠p: fit scaler/model on the other21 people, seal it, and infer every second of q. No p input or label is available during this selection. All22 inner people are required. The initial schedule deliberately performs each logical fit independently; no symmetric-fold fit reuse is presumed.

Use the shared fixed threshold grid Θ=(.01,.03,.1,.2,.3,.4,.5,.6,.7,.8,.9,.95,.99). For every setting/threshold, turn raw probabilities into binary0/1 scores using p>=θ and apply the unchanged original event protocol. Compute each of22 validation persons' full eventF1 and FAR over their complete recordings. Select the pair with maximum mean-person F1; then minimum mean-person FAR; then higher threshold; then earlier nine-setting index (logistic3 first, then tree6). Comparisons use exact computed binary64 values, no tolerance-based tie clustering or query-dependent threshold changes. Require all22 F1 values defined; stop if source assumptions fail. Classifier settings are not selected by per-second accuracy or held outer outcomes.

Refit the chosen scaler/model from scratch on all22 outer training people using the same support-bound random law and selected configuration. Freeze the selected threshold, source and full state before any outer query feature read. Infer each full held recording; record raw probabilities and binary ABI scores; recompute canonical events independently from the scores. Every second must be present. A record-level partition or streamed block may change storage, never the algorithm, support, fit weights or time boundaries.
