# NEURAL-010 complete scientific design — V2, pending independent/root acceptance

This is one analytical investigation: can a tool-using analyst accurately assess a frozen detector comparison across complete continuous monitoring, biological-person separation and acquisition/montage controls? Its numerical primary is reconstruction of evidence. Detector performance is a separate empirical outcome. Neither numerical reconstruction nor a positive detector contrast is a score for waveform understanding, artifact causality or clinical utility.

The selected scope is all 686 CHB-MIT 1.0.0 recordings, 24 source folders and 23 biological people, grouping chb01 with chb21. There is no balanced epoch subset, selected seizure subset, reduced person count or shortened recording. Every observed second and genuine selected EEG derivation remains available in the full input. Gaps between recordings are unobserved, not background. All source records, including negative outcomes and unsupported montage strata, must remain.

This document, REFERENCE_MATH.md, ACCESS_AND_BARRIER.md, COUNTS_AND_RESOURCES.md and PACKETS_AND_REPORTS.md jointly define the proposed design. Original source is unchanged. No implementation, authentic input/header/annotation/key access, reference fit, provider/model call, scientific score, acquisition or Git operation is authorized by this design phase. Root and the named independent scientific reviewer must accept an exact coherent freeze before dependent implementation.

## 2. Four complete detector streams, one fixed corpus

Every outer fold holds out one complete biological person and trains on the other 22. chb01/chb21 always move together. Every outer fold emits complete predictions for every recording and every second belonging to its held person. Each of the following four streams has all 23 fold outputs and all 686 records:

1. `candidate`: a prespecified independently built joint EEG-plus-montage detector, selecting the strongest setting of the exact linear/nonlinear family using only inner training-person validation. This is the proposed detector in the original historical report, not an LLM-generated detector or a claimed improvement.
2. `signal_reference`: the unchanged historical median-channel log-line-length reference and training-person-balanced 0.995 background quantile threshold.
3. `montage_only`: the unchanged historical person-balanced montage prevalence control with nested training-person threshold selection and training-global fallback for unseen montages.
4. `matched_no_eeg`: the exact candidate learning/selection procedure, matched metadata, training support, grid, random law, event policy and resource ceilings, but with all EEG feature coordinates withheld and replaced by defined zeros. It must never open signal sample bodies or fit EEG-derived statistics.

The first three retain the historical report and exact numerical primary. The fourth is a compulsory named diagnostic with complete person/montage tables and false-alarm localization. It is not substituted for the historical montage control. Strong-family equations and finite-precision/failure rules are in REFERENCE_MATH.md. No constant or weak surviving setting may replace a failed required fit. If a required fit, threshold comparison or stream fails, the complete study is incomplete and all costs/failures remain recorded.

The joint and no-EEG learning procedures select independently within the same frozen grid. Their selected model families or thresholds may differ. Their contrast estimates the value of allowing EEG features to this learning procedure under this protocol. It is not a same-parameter intervention or pure causal EEG effect. All selected families, configurations and thresholds are disclosed. The historical line-length control is deliberately transparent, not treated as a qualified strong neural comparator. Actual competence of the new family remains a later empirical gate; equations and a large fit count do not establish competence.

## 3. Supervised labels and the global assessment barrier

Root explicitly clarified the label distinction. A separately admitted upstream preparer must read legitimate source annotations to issue each exact training-only view. Its real label reads and lineage are recorded. It is impossible to claim that no annotations are read anywhere before a supervised leave-one-person-out study: each person's labels are necessarily training labels in other folds.

Within each detector context, the held person's labels, other-fold label views/state, global assessment-target body and stage-2 information remain inaccessible. All preprocessing, model selection, probability thresholding and model state are completed on the permitted training people. Query prediction is a fixed rowwise per-second transformation of a sealed model and allowed inputs; it cannot fit a query-person scaler, tune on the full query distribution or use hidden labels.

The stage-1 controller's separate **complete assessment-target operand** must remain unopened—not hashed, read into memory or parsed—until all four full streams, fit/selection states, original source lineage, output support and independently observed closures have passed the all-stream seal. Existing `prepare_analysis.main` reads target bytes before `make_packet` validates every prediction; the implementation successor must repair this real read-before-parse gap. A seal hash is an artifact identity, not evidence of execution isolation.

All detector/reference work, including inner selection and matched controls, precedes this release. The protected controller publishes a durable full seal, obtains independent admission of genuine closure and only then authorizes a separate assessment operation. No detector process, provider context, mutable model or tuning interface survives into stage 2. Failed/unknown cleanup or partial stream admission blocks release. Every analyst context consumes the same immutable released corpus. No second detector attempt is permitted after release without a new separately selected experiment and explicit contamination history.

## 4. Twelve complete analytical execution contexts

Two modes × three replications × two views give **12 complete analyst executions**, each covering all 23 people, 686 records and four detector streams. Folds, views and repetitions are not additional benchmark IDs or independent cohorts.

Modes:

- `frozen_program`: three independent data-free authoring episodes freeze one complete program per replication before any corpus is exposed. Each exact program is then executed in fresh isolated workers on both views. It may branch on the declared view/missing-input flag; it may not call the author model after seeing data, retrieve private scorer code or use another context's output. The same frozen program across views makes the access diagnostic interpretable without changing its authored source. There are three shared fixed-author episodes and six distinct fixed-program executions, with shared preparation costs reported once and explicitly allocated to both contexts.
- `case_adaptive_equal_inputs_tools_compute`: six independent author/investigator episodes, one per replication/view, inspect only that complete current-case packet and permitted tools. Each returns its own complete final report/executable evidence. Neither context nor filesystem memory crosses views or replications. Requested provider seeds are paired across views; unsupported determinism is reported as unknown. A shared seed is not a guarantee of identical model draws.

Views:

- `full_waveform`: the complete released event/annotation/montage corpus, all 686 target-free EEG projections and exact calibration/channel metadata. Every waveform remains available, with complete permitted tools under the declared resource budget.
- `waveform_withheld`: the identical full event/annotation/montage corpus, original waveform descriptors and explicit unavailable-waveform flag, but no signal samples, waveform feature caches, fitted detector models or tool route to recover them. Source/method descriptions and detector-event outputs remain identical. This intentionally retains signal-derived predictions: it tests whether direct waveform access is needed for the **analytical reconstruction** endpoint, not whether the whole corpus contains no neural information.

The waveform-withheld view is compulsory. The report can be calculated from the common metadata; success without waveform access is expected to show the endpoint's capability boundary, not a failure of the benchmark or proof that EEG is irrelevant to detector performance. Waveform-based explanations can be retained for expert examination but receive no automatic correctness claim because independent artifact-class labels are absent.

At analytical execution time, both modes receive the same public question, mathematical report definition, event-policy source, source provenance, realized sealed detector method/configuration descriptions and the same allowed data for the selected view. The earlier data-free fixed-author episode receives only the data-independent question, full support contract, protocol/family/grid/math, public algorithm source and future input/report/view schemas. It receives no authentic corpus rows, opaque identifiers, realized montage vocabulary/counts, selected model configurations/thresholds, fitted statistics/states, detector outputs, metrics or report. The realized sealed descriptions become available only when the frozen program executes, matching adaptive investigation access. Fixed authors never inspect them and then revise their source. Neither receives `analysis_core.reconstruct`, a ready-made answer table, private grader APIs or feedback. Generic Python/numerical/plotting/file tools are allowed. The authored code can independently implement the disclosed mathematics. Reference fitting is not rerun inside an analyst context.

A model-family/provider configuration, exact prompt/context assets and budgets must be source-bound before later runs. Each fixed author and adaptive episode has the same selected maximum provider-token/request budget and the same generic code tool capabilities; the temporal location of access is the defined intervention. Each complete execution has the same native CPU/memory/I/O/wall ceilings. Fixed-source reuse reduces actual author calls, so both actual costs and the corresponding per-context budget opportunities are reported. This is not a pure causal comparison of identical stochastic trajectories.

## 5. Numerical report and separate detector outcomes

PACKETS_AND_REPORTS.md fixes the deterministic projection from the complete four-stream seal to the unchanged three-arm historical packet and a separate matched diagnostic. The original three-arm `prepare_analysis.py` cannot be passed a four-arm packet and is not claimed compatible; the successor supplies a new release/projection adapter. The historical report remains exactly the original three-arm report from `analysis_core.py`: all per-person counts/F1/sensitivity/precision/false alarms per24 observed hours; candidate-minus-signal and candidate-minus-montage differences; every montage's full person membership and undefined metrics; every false-alarm interval in deterministic recording/arm order. The numerical primary is its maximum scaled reconstruction error, lower better, with 1e-8 solely a software arithmetic tolerance. Keep exact fields, support, nulls, booleans, IDs and interval order. Negative or null detector conclusions earn identical reconstruction credit.

A mandatory sibling diagnostic report adds matched-no-EEG counts/metrics, candidate-minus-matched differences at person and montage levels and one localization row per record for that arm. It uses identical equations and a separately reported maximum reconstruction error; it does not silently change the historical primary or mix performance into reconstruction. Complete-study admission requires both reports from all 12 contexts. A malformed/partial report is an admission failure, not an omitted good-looking cell.

Let R be canonical reference-event count, TP detected reference events, FP false-alarm events and T observed seconds. F1=2TP/(R+TP+FP), sensitivity=TP/R, precision=TP/(TP+FP), FAR=86400FP/T. Undefined denominators stay JSON null. Pool counts within each person across their recordings before computing metrics. Do the same within each person×montage stratum. Do not pool people as independent seconds. Complete people must retain their positive annotated support; if authentic selected source contradicts that premise, stop and review the protocol rather than silently discarding the person.

For each endpoint and comparator, paired differences are candidate minus comparator, including FAR (where a negative difference favors candidate). Use all people for whom both values are defined, once each. For n>0, mean=fsum(d)/n. For n>1, descriptive SE=sqrt(fsum((d-mean)^2)/(n(n-1))); otherwise SE=null. Report n and exact positive/negative/zero counts. Preserve montage strata with no positive events, undefined F1/precision, one person or adverse effects. Overlapping training folds and confounded montage membership make this descriptive uncertainty, not calibrated causal significance.

The independent protected grader validates all complete analyst artifacts, source/context and view joins before reconstructing expected numerical reports. It must not provide feedback during an open context or use favored text/signs as reward. Report individual errors, exact admission failures and context pass counts; do not average away a failed context. The same sealed detector metrics are reported once as empirical evidence, not twelve independent replications of detector training.

## 6. Frozen event conventions

Preserve the exact pinned `event_protocol.py`, including edge semantics, rather than replacing it with a conventional one-to-one seizure detector metric. Each final output has one finite score in[0,1] for every integral second and threshold0.5. Strong models store raw model probability and selected threshold privately for admission, then emit binary0/1 decisions in this original score ABI; these are thresholded decisions, not calibrated posterior probabilities.

Intervals are half-open. Canonicalization rounds endpoints to the 10 Hz grid, merges when gap is strictly less than90s, then splits when duration is greater than300s. Canonicalization occurs separately per recording, never across file gaps. Original annotation endpoints are integral seconds. The detection window extends each canonical reference by30s before/60s after, clipped to the file. Detection requires occupied fraction strictly greater than1e-6. A predicted interval is a false alarm only if it has no positive overlap with any detected extended reference window. Multiple references may be detected by one prediction; there is no one-to-one assignment. False-alarm localization must reconcile exactly to the count. These retrospective tolerances do not establish online detection latency or clinical alarms.

## 7. Scientific conclusions this design can and cannot support

A small reconstruction error supports analytical correctness on this frozen corpus. A joint-versus-no-EEG detector contrast supports a method/protocol-specific predictive comparison after competent qualification. Neither establishes causal independence from montage/patient context, raw EEG understanding in language-model weights, clinical effectiveness, an artifact diagnosis, calibration of posterior risks, unseen external data or a SOTA result. A negative neural contrast is valid and must not prompt selection of an easier subset. A failed transfer can reflect learning/model/context limits rather than an absence of neural information.

The public CHB-MIT source is development data with unresolved pretraining contamination and limited clinical/population generalization. Identical montage signatures can reflect acquisition and patient identity; different signatures can occur within one person. No permutation p-value or randomization-based causal claim is selected. Adding artifact-class or causal interpretation scores would require separately sourced labels and a new accepted design.
