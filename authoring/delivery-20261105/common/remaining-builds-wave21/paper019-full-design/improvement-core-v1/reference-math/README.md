# ACh prospective reference numeric core

This pure-standard-library component implements the accepted held-animal improvement mathematics, not the original MATLAB method. It reads no files or secrets, runs no tools, and performs no scientific work on import. It is source pending the independent review by banc_review and root; it does not qualify inputs, runtime, empirical reference strength or full-study feasibility.

`API.json` defines exact signatures. `core.py` supplies animal/session/row weights, population target moments, observed-only training continuous transforms, literal indicators, fixed-clock trapezoidal epochs, exact G/T feature ablations, weighted ridge and full weighted RBF with an unpenalized intercept, complete 20-setting selection, and equal-session validation loss. `fit_head` accepts original strictly positive seconds and returns a model with `target.mean`, `target.variance`, and `target.scale` in log-time units. `predict_head` restores original log-time units; the caller must not normalize targets a second time or exponentiate for the primary score.

The caller passes the complete admitted eligible animal/session roster and unique row IDs separately from data. Missing required groups, zero target variance, malformed observed values, missing portfolio cells or any required numeric failure cause `NumericFailure`. Its `as_record()` records undefined status without permitting retry or weak-survivor selection. No row, setting, head, variant or failed fit is silently omitted. The helper cannot independently establish that a supplied roster is the authentic full cohort.

Feature construction keeps exact common blocks G=[b,c_D*b,c_A*b,c_D*c_A*b] and T=[o_D,o_A,c_D,c_A]. B/D/ACh/F append only their admitted retained value blocks before T. A withdrawn channel argument is rejected before its contents are inspected. Natural masks stay unchanged, and withholding flags are audit metadata rather than estimator features. The caller must fit/read standardizers only for retained neural channels, provide the same fitted behavior transform and natural masks to each variant, and independently prove required modality support. This generic standardizer cannot distinguish a legitimate unobserved history column from an unadmitted entirely absent required modality. Unobserved continuous inputs must be None; no hidden numeric payload accompanies an absence flag. Missingness reason vocabulary, categorical one-hot construction and allowed history come from the independent admitted schema, not from this component.

Continuous transforms use only observed training weights. Observed constants and entirely unobserved columns map to zero even for later observed query values; undefined means/variances stay None. Indicators remain literal0/1. Epochs use the authentic supplied strictly increasing seconds, fixed 50 ms bins and the whole integral, with linear interpolation only between genuine bracketing samples. Every supplied value is checked finite, including samples outside the integration interval. There is no extra baseline or extrapolation.

The ridge objective is sum(w*(z-b-X beta)^2)+lambda*||beta||^2. Weighted feature and target centering removes the unpenalized intercept. The RBF implementation considers every i<j pair, retains every repeated positive distance, uses the exact unweighted median, and forms every dense kernel entry. It solves K+lambda*diag(1/w), uses two solves to determine the unpenalized intercept and a third solve for alpha, then checks the zero-sum alpha residual. No inverse, jitter, pseudoinverse, landmark, random-feature approximation, pair sampling or replacement width is used. All declared 20 settings are required during selection; finite equal scores tie by larger lambda, larger multiplier (ridge comparison-only0), then ridge before RBF. One-ULP lower scores win without an isclose band.

The declared arithmetic is Python binary64 using deterministic row/column loops and math.fsum. Positive-pivot Cholesky solves must pass a scaled infinity-norm backward residual <=1e-10; the alpha constraint uses the same fixed tolerance relative to max(1,sum(abs(alpha))). This is not a forward-error or correct-rounding guarantee. The weight-sum acceptance tolerance is 64 machine epsilons and never renormalizes supplied weights. Nonfinite arithmetic, nonzero product/quotient underflow to zero, exponential kernel underflow, invalid pivots or residual failure refuse. Strict underflow refusal can make a difficult authentic complete portfolio undefined; no easier surviving model is substituted. Runtime floating-point behavior, conditioning and adequate numerical accuracy remain separate qualification obligations.

Every fit requires explicit `limits` ceilings for rows, features, all-pair distances, largest dense matrix elements and a conservative declared live floating-scalar-slot provision. `resource_plan` refuses before internal pair or matrix construction when a complete extent does not fit. It does not count Python object overhead, physical RSS, caller-owned inputs, graph/data transport, outputs, external tool usage or the complete study. The parent reserves and charges every attempt before calling and retains the ledger after failure. The component does not resize/subsample a task to fit a limit. Prediction and other already-constructed array operands remain bounded by the parent's complete execution contract.
