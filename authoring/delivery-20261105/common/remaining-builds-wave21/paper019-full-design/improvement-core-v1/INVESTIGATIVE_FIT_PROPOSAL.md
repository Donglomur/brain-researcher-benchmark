# Proposed investigative fitting contract — source review only

This additive proposal clarifies candidate expressiveness; it does not alter the accepted original endpoint, four global programmes, candidate fit granularity, independent reference mathematics or held-query protection. V1 and V2 remain unchanged. Root and the same independent peer must accept this proposal before a concrete investigative controller is implemented or represented as supported. No provider or scientific execution is selected.

## Current measurement and missing implementation

The present package implements the independent scientific core and validates candidate method/search/source-state evidence descriptors. It neither implements a research-agent controller nor proves that an LLM can investigate this dataset. Its candidate contract leaves the estimator and training search algorithm open; the independent reference alone has the fixed ridge/RBF menu. If connected only to deterministic prewritten candidate pipelines, the resulting measurement is pipeline reproduction and held-animal predictive improvement under matched access conditions. That would be narrower than a general research-agent benchmark and must be reported that way.

## What is immutable

Before any numerical author exposure, seal the same four global native/improvement programmes under A-clarified/B-author-code. For an investigative programme, the sealed source is the complete investigation policy: model/version and inference configuration, system/task/tool prompts, code-generation and execution machinery, allowed tool/source set, context separation, randomization/replay policy, all original train/validation/query boundaries, selection rules, budgets and durable logging policy. No outer outcome, native result, other bundle's investigation, human hint or later conversation may revise that global policy. Source-known paper content and the accepted A/B author-code difference retain their original declared status.

A stochastic investigator is possible only with a predeclared randomization and retry policy plus exact realized logs; no hidden best-of-run selection or numerical retry budget is free. An immutable policy is not the same as one predetermined estimator.

## What each fitting invocation may investigate and revise

Run one fresh investigator for each original access × cohort × outer animal × feature variant × selected realization bundle. All four event heads belong to that one bundle; this does not create more global authors or benchmark IDs. Provide only the full allowed training animals, their admitted group aliases and permitted features/labels, the fixed scientific question/specification, and the access arm's allowed source. Withdrawn-channel values and their statistics are absent even during exploratory analysis. Native full-label contexts remain physically separate from improvement contexts.

Inside that fitting workspace, the LLM may inspect distributions and missingness, formulate training-supported hypotheses, write and revise analysis/model code, fit alternative methods, debug genuine training failures, run grouped inner validation, compare ablations and select its final method under the predeclared policy and complete resource envelope. Candidate search need not mimic the reference's20 settings. Generated method code is an auditable fitting output, not a modification of the global policy. Training-only code changes, attempted fits, diagnostic plots, inner scores, failures, source revisions and selection decisions are all retained with exact identities and costs. No failed attempt disappears from the ledger.

After training-only selection, seal the final executable method source plus fitted state as the original four-head bundle. The protected final model record binds this complete bundle, the selected method/source and its selection evidence. Outer queries cannot reopen search or revise that bundle. One-query inference follows the already accepted target-owned history/tie barrier and receives only its minimized permitted view; held-animal labels, future queries, another variant's output and global context history are unavailable. Released prior outcomes remain query inputs under the accepted schedule, never material for refitting on the held animal.

## Minimal concrete extension and evidence

Implement an investigation adapter inside the per-bundle fitting phase, with actual model/tool execution and a captured append-only action/source/fit/selection ledger. Its inputs are admitted training views and the frozen global policy; its outputs are the sealed four-head method bundle, exact training-only selection record and full attempted-work ledger. It must not accept a callback that fabricates a completed fit, predictions, score or success receipt. The existing candidate `method_conformance_evidence`, `fit_search_ledger_pin` and `source_state_lineage_pin` fields must refer to independently observed concrete artifacts, not self-certified declarations.

A subsequent controller must independently enforce source/view/realm/clock custody, bind generated code and method state to actual processes, and deny training-to-outer or native-to-improvement feedback. Derive the complete original workload and provider/tool/serialization/failure-retention cost envelope before execution, including every160 conditional observed candidate bundle, additional selected nulls and unchanged independent reference/native work. Existing source grants and model-run pauses are not a provider budget or empirical authorization.

## Supported scientific interpretation

With that extension actually qualified and run, the benchmark can measure constrained training-only scientific investigation: whether an LLM uses the admitted neural data, analytical tools and training evidence to reproduce declared quantities and develop methods that generalize to protected animals, and how audited author-code access changes that outcome. Numerical reproduction and improvement remain separate outcomes. Logs can support analysis of hypothesis formation, method revision and selection behavior if those analyses are specified and scored explicitly.

This still does not establish unrestricted research autonomy, causal neural understanding, publication-level novelty or meaningful frontier advancement merely because a score improves. Those claims require their own scientific evaluation. All original full-support, native/ED, contamination, competence and physical execution qualifications remain unchanged; no endpoint is reduced to make this extension easier.
