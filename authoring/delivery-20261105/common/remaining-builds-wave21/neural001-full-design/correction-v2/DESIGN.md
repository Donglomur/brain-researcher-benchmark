## Frozen-program and adaptive-case modes

A study replicate has a predeclared model/version, prompt/context, seed, tool environment and identical full participant resource profile for both modes. One replicate is the basic design; extra seeds are declared before outcomes and costed as additional replicates, never additional benchmarks. The modes are reported separately. This primary mode contrast is the combined treatment of training-stage investigation plus current-case investigation: the adaptive LLM can inspect numeric training data while the frozen-authoring LLM cannot. It is not an isolated estimate of query-time reasoning. Isolating those stages would require separately designed additional conditions, which are not silently included here.

Frozen-program: the LLM produces and seals its global training/prediction program before any study numeric values are revealed. The sealed program fits separately on each person's permitted audiobook training; supervised fitting, learned preprocessing and training-validation parameter selection are grouped by original run and end before any query. The final fitted state is read-only. Then 120 independent query processes apply the fixed program with this state, one current query at a time. No LLM receives numeric query or training values after authoring. The fixed program may automatically perform the same classes of one-case diagnostics, computations, tool calls and prediction synthesis available in the adaptive mode; a simple fixed router is not imposed. Its program is fixed, not its numeric output. It may not refit learned state or retain case state.

Adaptive-case: the global instructions and training-investigation procedure are sealed before numeric exposure. A participant training workspace may investigate that person's labeled audiobook data and produce tools/models using only whole-run training folds. All supervised fitting, learned preprocessing, and training-validation parameter selection finish before queries, and the full trained state and normalizers are sealed. For each of 120 queries, a fresh LLM context receives that frozen state/documentation, allowed person training views and only the current unlabeled query. It can inspect the current waveform, call frozen tools, write/execute diagnostic code and synthesize a new single-query prediction. It may choose a tool, combine tool outputs, calculate query-conditioned combination coefficients, use allowed training examples directly, or create a current-case prediction program. The result may differ from every frozen tool output. This is a case-investigation/programming treatment, not selection from a finite bank. Operational algorithm choices in the current case are part of the intended treatment.

The concrete boundary is between ephemeral one-case prediction computation and a new training/update step. Allowed examples include measuring current-query quality, using that measurement to weight two frozen predictions, applying a current-case numerical calculation to frozen outputs, directly comparing this query with allowed training examples, and choosing a new prediction-synthesis algorithm without optimizing learned model parameters against training labels. Such combination weights or temporary variables exist only in this case; they are not written back to a trained tool, reused on another case, or claimed to be an independently trained model. Iterative numerical solution for this case under a frozen tool/objective is inference, provided it does not change learned tool parameters or use unauthorized targets.

Prohibited examples include fitting a new supervised decoder after query exposure, choosing learned decoder/ensemble coefficients by minimizing a labeled training-validation loss during the query phase, gradient updates to a trained model, recomputing and replacing its learned normalizer/PCA/RFF map, changing tool/model parameter assets, fitting a task model on query-derived pseudo-labels, using another query or batch statistics, receiving hidden targets or score feedback, or retaining state between cases. A scalar calculated from current-query quality for an ephemeral combination is allowed; a scalar fitted against labeled training examples as a new model parameter after query exposure is prohibited. Pretrained/tool normalizers and official input preprocessing remain frozen. Current-case diagnostic and output calculations do not redefine the official source clocks, support, target, sensor roster or learned preprocessing assets.

This replaces the V1 blanket phrase “no query-based hyperparameter search,” whose meaning conflicted with genuine case adaptation. The protocol does not pretend that every arbitrary program can be mechanically classified as inference versus training. Runtime isolation can enforce one-query/one-person access, immutable approved tool states, no network, no target feedback and fresh processes. Method review must additionally inspect all authored code, tool calls and provenance for prohibited new training; equivalent computations can be expressed in ways that are hard to classify. Therefore source/process checks provide bounded evidence of compliance, not universal semantic certification. An unresolved method-conformance finding prevents an unqualified comparison claim; it must be disclosed or resolved before scientific qualification. This limitation does not silently replace the intended case-programming treatment with finite-bank routing.

Each authored global program or current-case program retains the existing 65,536-byte source limit. All dependency/tool identities are pinned; fitted numeric state is not an unmetered executable-code channel. All diagnostic code, generated predictors, tool calls, temporary computations, failed attempts and output synthesis consume the full declared budget. A fresh process and read-only shared training/model mount are required; copying training arrays 120 times is unnecessary. Provider session/caching and filesystem isolation must be qualified, not assumed from reset wording. Every current-query operation is logged under protected provenance without exposing targets.

The same 120 fresh contexts/person apply to each adaptive control arm; the frozen program also processes only one query at a time. Neither mode may communicate between people or queries. There are 2,880 adaptive case contexts per arm per replicate, not 2,880 independent benchmark tasks. Differences from other tasks using training-fold investigations or summary-only representations are reported as differences in experimental treatment, not pooled into one indistinguishable score.

## Matched controls and what they mean

Three candidate arms are mandatory in each mode: actual neural input; no-neural prior; and within-query shifted neural input. Each preserves all 24 people and all 120 exact target supports. Arm-specific access is identical between modes. Controls do not introduce IDs.

The no-neural arm exposes the same permitted training envelope, training interval/run structure, query length/fs and opaque context, but no training or query MEG or neural-model output. It may learn a training-only acoustic prior. This isolates what can be predicted from the nonneural context available under this protocol. It does not grant sentence identity or public audio lookup. A constant training-envelope mean is a declared zero-correlation floor, not a competent neural decoder. The candidate's stronger prior and its development costs are retained, even if unsuccessful.

The shifted arm reuses exactly the neural arm's frozen person-trained tools with no refit. For each query of length L, roll all 306 channels together by floor(L/2) samples within that same query. Leave its target, ID, sensor order, length, scoring support and any support mask unchanged. The offset depends only on allowed length, never on target correlation or a favorable lag. Do not concatenate separated OLSA intervals into an artificial continuous run. Do not fetch extra source-run samples or expose extra queries to construct this control. All original samples remain once; the circular wrap creates an artificial boundary and short filtered sentences may retain substantial autocorrelation. Report L and shift in samples/seconds per case and interpret the contrast as sensitivity to this specific alignment intervention, not proof that all neural information was destroyed.

Fixed references apply the same frozen predictor to actual and shifted views. Adaptive actual/shifted arms instead use independently reset, matched-seed LLM workflows receiving only their respective current waveform and the same frozen training state. The adaptive policy can make different current-case choices. Thus the paired contrast estimates complete-workflow alignment dependence, not the effect on an identical post-adaptation program. It cannot cache an unshifted waveform/output across arms. Within-query shifting is deliberately chosen over a full source-run shift because the existing released query view lacks intervening raw run support; no false continuity is asserted.

No score threshold for “understanding” is introduced. Evidence is the full primary estimate, independent reference comparison, the no-neural and shift contrasts, and exposure/robustness limitations together. Failure of a control to reduce score is reported, not explained away or retuned after seeing targets.

## Independent reference panel

References are separately implemented, frozen and executed by the operator; candidate outputs cannot train/select them. Their complete person-level results are independent from candidate predictions. Both candidate modes can use the same qualified person-trained tools, but that access does not replace the standalone reference panel. Reference competence and native numerical compatibility remain future empirical gates.

R1 is mTRF 2.7 backward lagged ridge anchored to official tag commit `d4fa6e2ebfbad75619e01011cf2a5042f9236ea3`. The reviewed code converts direction=-1, tmin=0, tmax=250 ms and fs=64 to lags -16:0 inclusive: 17 lags and 306*17+1=5,203 design columns including bias. Negative mTRF lag means using later MEG samples to predict the current envelope; this is consistent with retrospective backward decoding. Each epoch/query is a separate cell. Missing lag support is zero in the design matrix, distinct from adding artificial zero-valued target observations. Preserve every target sample.

For each held-out whole training run, compute mean/std separately pooled over magnetometer and gradiometer training values, plus training-envelope mean/std; apply those estimates unchanged to held-out training runs. Use population standard deviation (ddof=0), declared as a prospective convention rather than native MATLAB sample-std parity. Zero variance in a required training quantity is an invalid input/reference qualification, not a silent omission. The seven lambdas are 10^(-6,-4,-2,0,2,4,6). For each lambda, score every validation epoch by signed Spearman, Fisher transform with the canonical endpoint rule, average epochs within run and runs equally. Select maximum mean; ties choose the larger lambda. Refit chosen lambda on all available person training using freshly training-only normalizers.

Native mTRF covariance is the sum of per-epoch X'X and X'y, without sample-count averaging. Its ridge matrix has zero bias penalty; delta=1/64 and M=lambda/delta*diag(0,1,...,1). Native weights are solved and divided by delta, then prediction applies delta. An effective-weight port can solve (X'X+64*lambda*D) beta=X'y and predict X beta, provided independently checked against native source. Do not accidentally use mean-loss ridge or penalize the intercept. Captured sources include train, predict, crossval, lagGen, regmat, olscovmat, formatcells, truncate and the BSD license; these are source evidence, not an installed or fully qualified environment.

R2 is a separately frozen prospective nonlinear comparator, not a claimed paper method: training-only channel standardization, spatial PCA of rank 32 or 64, unit-variance scaling of retained PCA scores, 17 within-epoch lags, 512 Gaussian random Fourier features and ridge with unpenalized bias. The effective PCA transform includes component whitening. Saying that a library PCA call has whitening disabled would not describe the complete transform and is not the mathematical specification.

For each training fold (and again for the all-training refit), let X be its N-by-306 retained training MEG rows. Compute channel means mu and standard deviations s using denominator N (ddof=0), Z=(X-mu)/s, and training zbar=mean(Z). From Zc=Z-zbar, obtain the first k orthonormal right singular vectors V_k in descending singular-value order. Fix each vector's sign by making its largest-absolute loading positive, breaking equal-absolute loading ties by original channel order. Numerical decomposition/eigenspace-tie behavior is part of the exact environment/native qualification; no cross-platform bitwise guarantee is assumed. Define q_j=sqrt(sum_i((Zc V_k)[i,j])^2/N). The final spatial transform for any allowed row x is T(x)=(((x-mu)/s)-zbar) V_k diag(1/q). This centers using training estimates and gives unit population variance to each retained training PCA score. It is not raw unscaled PCA projection. Held-run/query rows never estimate mu, s, zbar, V or q. Nonfinite or zero s, q or target standard deviation invalidates the required configuration and fails reference qualification; it must not silently remove a component/configuration/person or reduce k.

R2 uses training-only target mean/std (ddof=0) and restores that target scale for predictions. R1 likewise restores its training target scale. Lag features are ordered by lags -16,-15,...,0 and then component index within each lag; out-of-interval lag support is zero after the trained spatial transform. There is no cross-epoch bridging or appended zero-valued observation. For rank k, d=17*k. Fix base seed B=20261107. Construct a fresh NumPy 2.2.6 Generator(PCG64(B+k)) independently for each rank. First draw exactly d*512 standard-normal float64 values as standard_normal(size=(d,512), dtype=float64) in C order to form G_k. Then draw exactly 512 float64 uniform[0,1) values using random(size=512, dtype=float64) from that same rank generator, and set b_k=2*pi*u. No draws occur before G_k or between G_k and u. For scale h in {0.5,1,2}, W_(k,h)=G_k/(h*sqrt(d)), and phi(x)=sqrt(2/512)*cos(x_lag W_(k,h)+b_k).

For each rank, the identical base G_k and b_k are reused across every participant, fold, final refit, mode/arm and alpha. Scales change W only through the stated deterministic division; they do not consume new random draws. Alpha never affects the random map. Rank 32 and rank 64 use their distinct B+k streams; no shared generator is advanced by traversal order. A cache must be equivalent to reconstructing that rank's fresh generator and exact ordered draws; cache keys include rank, seed rule, NumPy/RNG identity, dtype and generation layout. Neither source code nor this document generates or reads any actual random-feature array during design. A later runtime must bind generated-map identity and resource cost, including all unused/failed configurations, without choosing a favorable seed from outcomes.

Ridge alpha is one of 0.001, 0.1, 10, 1000 applied to mean squared loss, with an unpenalized intercept. The 2 ranks * 3 scales * 4 alphas yield 24 configurations. Whole-run validation, epoch/run score aggregation, final all-training refit and prohibition on post-query fitted-model updates match R1. Ties choose larger alpha, then larger scale h, then smaller rank. All deterministic engine/platform/source choices are frozen and qualified before numeric execution; their current absence remains a gate. R2 is proposed to avoid treating one linear baseline as the full attainable frontier; superiority is not assumed.

R0 is the no-neural training-envelope mean, separately reported as the valid constant-prediction floor. It is not used as evidence of reference competence. R1 and R2 each run actual and shifted query arms with identical fitted state. R0 runs no-neural only. Candidate and reference panels are joined only at protected scoring. Source-only formulae imply 94 leave-one-run-out folds plus 24 final refits: R1 has 7*94+24=682 ridge fits; R2 has 24*94+24=2,280 ridge fits and up to 2*(94+24)=236 distinct PCA fits if safely reused. R0 has 24 means. These are planned logical counts, not measurements or authority to execute.

## Outputs, primary estimand and uncertainty

Each query emits only a finite float64 vector of the exact supplied length. Trusted assembly creates each person's canonical NPZ with exactly prediction[total_samples] as little-endian float64, interval_ids[120] as Unicode32 and offsets[121] as int64, C order, ordinary NPY1 members inside stored/deflated NPZ, at most 1,048,576 bytes. Preserve canonical boundaries/IDs after private inverse permutation; no candidate sees that map. All 24 canonical files validate before any protected target body is loaded. Duplicate/missing IDs, altered support, extra arrays, links, nonfinite values or incomplete cohorts fail admission; no partial-coverage score is emitted. The existing 250,000 training and 61,440 query row caps are provisional construction limits, not a license to crop data: if authentic complete support exceeds a cap, fail and review a successor.

For person p and trial j, rho[p,j] is signed Spearman on every paired retained sample, using average ranks for ties. z[p,j]=atanh(clip(rho[p,j],-nextafter(1,0),+nextafter(1,0))). Primary Z=(1/24)*sum_p((1/120)*sum_j z[p,j]). Raw signed Spearman and Pearson, all interval values, each person's Z and mean raw correlations, constant-prediction flags and endpoint clipping flags remain in the protected report. tanh(Z) is labeled back-transformed macro Fisher estimate, not an arithmetic mean correlation. Constant predictions score zero; constant targets invalidate the operator packet. The current scorer is preserved exactly. The 70 unique sentence identities do NOT replace the 120 equal trial weights.

Primary report gives Z separately for each mode's actual-neural arm. Prespecified comparisons are adaptive minus frozen, each candidate minus each independent neural reference, actual minus no-neural and actual minus shifted, all paired on the full person/trial support. None implies SOTA without qualified comparisons. Shared sentence identities/repetitions, within-person autocorrelation and reused training invalidate a naive 2,880-independent-case confidence interval. Report participant-cluster bootstrap intervals conditional on this fixed 70-sentence set, and a separately labeled crossed participant/sentence-identity sensitivity analysis preserving all repetitions of an identity with its multiplicity. The latter resamples identity clusters, not a silently identity-reweighted primary. Use NumPy 2.2.6 PCG64 seed 20261108 and 10,000 shared paired bootstrap draws. For the conditional interval, sample 24 participant IDs with replacement and recompute their original 120-trial macro means. For the crossed sensitivity analysis, additionally draw 70 sentence-identity IDs with replacement once per draw, shared across participants, weight each original trial by its identity draw count, divide each resampled person's weighted trial sum by that person's sum of trial weights, and then average the 24 sampled person values. Original repetitions therefore retain their multiplicity. Use the same draw for every paired comparison; report percentile 2.5/97.5 bounds with an explicit percentile interpolation convention fixed in the implementation review. Report the assumptions and missing-group mapping as a gate. Replicate seeds are repeated measurements of the same people, not extra participants.
