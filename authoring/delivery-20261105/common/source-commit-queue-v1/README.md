# Scoped source commit queue

This package implements the local agent-commit/root-integration workflow in `tools/neurobench_source_queue.py`. The operational commands and publication rules are in `docs/neuroscience-benchmarks/GIT_WORKFLOW.md`.

The source utility accepts an externally reviewed and exactly pinned JSON member list. It supports common proposal keys (`files`, `members`, `author_files`, `owned_files`, `review_members`, `exact_files`, `paths`, `proposal_files`, `proposed_members`, `include`, `path_allowlist`); ambiguous proposals require `--member-key`. Members need a repository-relative `path` (or `source`), integer `bytes`, SHA-256 `sha256`, and optionally regular-file `git_mode` 100644 or 100755. Dictionary members map paths to pin records. Deletions, symbolic links, submodules and source outside explicit prefixes are unsupported.

Known non-source suffixes and credential paths are rejected before member bodies are opened. The manifest itself is bounded to 2 MiB; defaults are 2,048 members, 1 MiB per member and 16 MiB total. All path/type/prefix/extent records are checked before any member body. Exact captures use ordinary single-link stable files. UTF-8 and private-key-marker checks are secondary content checks; they do not replace root's publication audit. Merge source bases are bounded to 1 MiB per selected path. Git child output, time and owned-process cleanup are bounded per invocation, not a measured whole-process RSS or whole-command runtime guarantee.

`commit` creates only objects and a new `refs/heads/agents/neuro/...` ref through a unique temporary index. `integrate` is serialized and root-acknowledged; it never edits worktree bytes. It authenticates agent diffs and blobs, checks ancestor/clean-index conditions, applies a three-way patch privately, and creates a two-parent merge. Prepared Git ref locks and an index lock protect cooperating Git actors. An explicit journal supports interruption recovery; it does not imply cross-file atomicity, filesystem-adversary security or support for bypassing Git locks by manual writes. Manual intervention is required for incomplete journals or unknown ref/index state.

Only disposable toy repositories were used for tests. No real repository HEAD/index updates, remote operations, data arrays, model runs, scorer runs, new benchmark counts or runtime qualification are part of this source package. The root agent will install this reviewed package with the existing committer before using the queue for real batches.
