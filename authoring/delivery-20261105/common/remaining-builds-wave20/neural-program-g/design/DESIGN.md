The case-adaptive investigator receives the same permitted training/current-person information via actual tools and may change analysis/inference code after observing that person. ## Independent reference panel

The held MNE tutorial literally uses five relative EEG band features and RF100 in a toy two-person task with a true-label sleep crop. That is lineage, not the new full-cohort method. Reuse the separately held adapted per-channel feature source: Welch Hann400samples/overlap200/nfft400 at100 Hz, mean periodograms, constant detrending, density scaling; normalize PSD over0.5..30 Hz inclusive; average relative bins in[0.5,4.5),[4.5,8.5),[8.5,11.5),[11.5,15.5),[15.5,30); add log(max(population variance,1e-24)). Each available channel gives six features; add three clocks. No fitted transform uses test labels, and no true sleep crop is retained. The candidate may choose other representations within the raw contract.

R0 is a training-only prior/clock reference: empirical five-class prior plus a two-dimensional48-bin wall-clock × integer elapsed-hour histogram, with each cell probability `(class_count+alpha*global_prior)/(cell_total+alpha)`. Elapsed-hour bins above the maximum training elapsed hour map to the final training bin; unseen wall/elapsed cells fall back to the global prior. Select alpha in1,10,100 on the13 validation people by equal-person macroF1, lexical-grid tie-break, then refit65. This is a declared nuisance baseline, not optimal timing prediction.

R1 is fixed epoch-local RF100 on each ofC/EC/OC/EOC with the complete explicit adapted-donor parameter map in REFERENCES.json (including seed241, min_samples_leaf5, max_features1.0 and class_weight=balanced); no hyperparameter selection or floating sklearn defaults. This is the adapted reference, not exact MNE historical reproduction. It fits all eligible65-person training epochs and predicts every query epoch.

R2 is a stronger predeclared contextual/sequence reference in each view. Append within-night centered±5-epoch feature means and population standard deviations (truncate the window at recording boundaries, never cross nights) to the original feature vector. Fit RF300 with seed241, `max_features=sqrt`, `class_weight=None`, `max_leaf_nodes=4096`, and min_samples_leaf1 or5. Estimate five-class priors and adjacent-stage transition counts only from contiguous eligible training epochs, add1 pseudocount to every transition, and normalize rows. Unknown/movement labels break training adjacency; do not bridge their gaps. Initial state prior is the training-global stage prior. At inference, divide RF posterior by the floored training prior, floor at1e-12, raise the transition matrix elementwise to lambda0,0.5,1 and row-normalize, then compute normalized whole-night forward/backward posterior. Lambda0 gives independent uniform transitions, preserving the stated emission/prior convention. Choose min-leaf/lambda jointly by equal-person validation macroF1 across the six grid pairs, with ordered-grid tie-break; refit65 at that choice. Predictions still cover every query epoch with no query mask.

All literal math, probability clipping/normalization, edge handling, seed and sklearn serialization/version requirements will become source tests before scientific use. A source implementation and these stronger models do not certify empirical competence or SOTA. Preserve every weak/adverse reference result. No YASA cache/model is supplied; a future pretrained tool condition requires a separately admitted checkpoint/exposure contract.

Apply the identical-state EEG inference shift to R1/R2 EC and EOC. Add a separate training-label association diagnostic for R2 C andEC: reuse the original selected hyperparameters, rotate each training night's full label/mask sequence by its fixed one-third-night offset, refit on the65 training people, and infer original queries. No validation reselection or query outcome enters this control. It disrupts both clock-label and EEG-label association and can alter transition boundary behavior; its effect is not EEG-specific evidence or a permutation p-value. Do not compare it as if it were the identical fitted-state shift.

Reference preprocessing can be reused without scientific scope reduction. Compute deterministic epoch/context features once per original night, source/version and available channel, with all clock/edge definitions pinned; store separate readonly per-channel feature files so a C/EC/OC fit cannot read extra channels. These153 operator-owned cache producers compute no fitted state and never receive labels. Compute each fold/training-role prior/transition sufficient statistic from only that role's labels; no global all-person fitted statistics enter a fold. Training-label-control statistics remain separately keyed to the transformed label history. Cache artifacts and their producer clocks/costs are independently bound and stay in reference realms, never candidate/provider realms. Candidate outputs, scores, reference predictions and other-fold learned state are never cache inputs. For shifted R2 inference, rotate EEG epoch-local base features first (equivalently transform raw epochs then recompute those base features), then recompute the truncated centered±5-epoch means/std on that shifted sequence. Each reference is fitted independently from candidate/provider contexts and sealed before comparisons. Reference artefacts, validation outcomes and private query labels never enter candidate tools.
