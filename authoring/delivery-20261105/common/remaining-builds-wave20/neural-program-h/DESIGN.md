## Question and selected scope

Can an LLM-directed analysis predict the absolute wheel-speed trajectory across the complete BrainWideBench evaluation cohort, and what predictive sensitivity remains when simultaneous neural counts are added to the declared nuisance information? Compare a globally frozen generated program with an agent investigating the permitted current session. Prediction, input dependence, and scientific interpretation are separate outcomes; none establishes native numerical comprehension, causality, or a new neuroscience finding.

Keep all 29 official evaluation sessions, 13 mice and 7 laboratories from `ibl_brain_wide_bench_2026/all_units/eval`, source revision `6fbd666fe8170a2165f5198c1f490911424a654d`. `SOURCE_BINDINGS.json` binds the held roster, primary code and design donors. The exact source object set, not just its cardinality, determines membership. Every native unit remains in its session's neural input. Unit axes differ between sessions and have no cross-animal neuron correspondence. No quality, response, score or convenience filtering may remove sessions or units.

Use each session's official TS1 train/validation/test domains. A selected movement's entire `[onset-1,onset+1)` context must lie in exactly one official domain and in both wheel and spike support. Retain one explicit disposition for every original movement, including unsupported windows. Require nonempty train, validation and test sets in every session. A malformed source or missing required split stops preparation; it never licenses a replacement session or smaller cohort. Full eligible case counts and unit counts are not yet known.

The endpoint is the 50 actual 50 Hz absolute wheel-speed samples in `[onset,onset+1)`, with original offsets and no new interpolation. Counts include all native units in the same 50 left-closed/right-open 20 ms bins. This is simultaneous, retrospective, movement-aligned decoding. It is not prediction of future movement. Choice is excluded from this benchmark's endpoint.

The nuisance view is exactly 213 scalars: 50 pre-onset processed speeds; 50 pre-onset positions translated by their last position; 50 history offsets; 50 target offsets; nine signed-contrast indicators; three block-prior indicators; and stimulus-to-movement latency. Current stimulus must precede movement. Movement timing and block prior are privileged experimental context. The held publisher pipeline interpolates wheel measurements and applies FIR decimation; source timestamps alone do not establish past-only preprocessing. No causal or online interpretation is allowed and no guessed temporal gap is introduced.

The two-second windows may overlap within a split, and nearby movements/processed wheel samples are correlated. Whole-context split containment prevents direct window crossing between official splits, but does not prove absence of preprocessing influence across a boundary. Preparation records overlap counts and split-boundary distances as operator metadata without changing eligibility. Do not treat windows as independent biological replicates. The evaluation is within-session calibration with multi-lab summaries, not held-animal or held-laboratory generalization. Public source availability, related NEURAL-058/059 development exposure and unknown model pretraining exposure remain disclosed.

## Information arms and state lineage

There are three scientific arms per workflow/replicate, each covering the identical complete test support:

1. `nuisance`: the declared context only.
2. `joint`: the same context and original neural counts.
3. `joint_test_shift10`: the same joint source, selected recipe, fitted state, preprocessing state and RNG state, replayed with only TEST counts rolled +10 along their 50-bin axis. Nuisance values, identities, offsets, target ordering and targets remain unchanged.

Fit and select both nuisance and joint methods using original train/validation inputs and labels. Only the joint test neural stream changes at replay. Training/validation counts are never rolled in this condition. A shifted refit is not part of this design. Any later shifted-refit condition must be separately named and cannot establish the same alignment claim.

Root clarified that "10/50 bins" meant 10 bins within a 50-bin window, not two shifts. A roll by 50 would be the identity, not a one-second intervention. An optional invented engineering check may test that identity; it is not an additional scientific arm or root-selected experiment.

Seal all method state before either original or shifted final replay. In adaptive mode, the investigator may see the original permitted test inputs before that seal, but never a shifted test view. After sealing, the agent/provider terminates and its tools, scratch and transcripts are unavailable to inference. Original and shifted replay run as independent fresh processes from the same initial state and RNG snapshot, at identical internal paths, without an arm flag, previous prediction, transcript, training-label mount, wall-clock seed or shared writable state. Schedule/order is operator-only. No adaptation episode occurs on shifted inputs.

Readonly hashes establish artifact identity, not that arbitrary Python performs no in-memory refitting or identifies a shift. Source/method review must admit a declared prediction-only inference procedure and reject test-indexed lookup tables, target reconstruction, hidden refitting, shift-undoing code and embedded provisional predictions. Generic unrestricted inference cannot provide a universal semantic guarantee. Replay provenance may become verified after actual execution, while scientific method compliance and contribution qualification remain separate gates. Deterministic inference is required for the primary paired replay; stochastic methods must use a frozen randomness policy that produces the same random stream from the same sealed seed, with no entropy/time/network source. Unsupported nondeterministic implementations remain unqualified rather than receiving an arbitrary tolerance.

The 200 ms cyclic roll preserves each unit's total count but changes alignment and introduces a wrap boundary. It is an out-of-distribution perturbation, not conditional randomization or a causal intervention. Sensitivity can support dependence on alignment under this protocol. Insensitivity may reflect temporal invariance, weak prediction, nuisance dominance or adaptation violations; it does not establish absent neural information.

## Two complete workflow modes

Keep the exact canonical names `frozen_program` and `case_adaptive_equal_inputs_tools_compute`. Each mode has three independent authoring replications, with every replication retaining all 29 sessions and all three arms. A partial implementation of one mode is explicitly incomplete. Candidate construction agents exposed to private operator source or other arms are ineligible as blind candidate authors.

In `frozen_program`, one fresh global authoring context per information role and replicate receives the public task, schemas, generic offline tools and no dataset numerical bodies. It produces a source and recipe that are sealed before any test release or numerical fitting. That same source is used for all 29 independent session fits. The fitting process may use that session's original train/validation observations and labels, select its method/hyperparameters, and refit on train+validation. No fitted state transfers across sessions. Final inference receives the current complete test batch and its sealed model only. Algorithmic test-batch fitting is prohibited in the primary replay; declared deterministic transforms must be fixed by final fitted state.

In `case_adaptive_equal_inputs_tools_compute`, each session/role/replicate has a fresh agent context. Nuisance investigators receive only nuisance train/validation values, labels and original unlabeled nuisance test inputs. Joint investigators receive the same plus original train/validation/test counts. They can run Python analyses, inspect their own numerical diagnostics, revise methods, and choose named model families/hyperparameters within the fixed episode allowance. They receive no other session, other role, other replication, shifted inputs, operator reference outputs, evaluator, raw HDF5 behavior group or private score. There is no hidden score feedback. This is declared batch-transductive method investigation, not an untouched test-sample claim.

Adaptive source and a typed selected recipe seal after investigation. Provisional fitted coefficients, learned normalizers, embeddings, prediction tables and numeric caches cannot be carried into final execution through source, comments, recipe or model files. Named family/hyperparameter choices and a public scientific rationale may persist; derived fitted quantities must be recomputed in a fresh final fit using original train+validation. The final fit has no test mount. Test-informed method selection is intentionally allowed in this mode, but test-derived fitted statistics are not. This narrower boundary makes the required seal executable and allows the exact same final state to serve both replays. It must be stated to candidates and reviewed; a general claim that every imaginable form of transduction is permitted would be false.

The final fitter's policy is supervised original-data fitting: hyperparameter comparison fits preprocessing and the estimator on training only, evaluates validation labels, then refits the selected pipeline on train+validation. Its source may implement a new algorithm or preprocessing family, but every data-estimated parameter is recomputed from that admitted final-fit view. The admitted recipe names the algorithm family, typed hyperparameters, declared finite selection/search policy, seed policy and numerical-library dependencies. Method-admission approval enumerates the permitted field names, ranges and scientific role for that exact recipe; a generic arbitrary nested JSON payload is forbidden. Permitted carry includes, for example, a selected regularization strength, a declared transform family, temporal context length or a model architecture. Fitted offsets/scales, tree thresholds, model weights, per-unit rankings, centers, embeddings, case-indexed constants, encoded arrays and test-derived computational summaries are prohibited carry. A hyperparameter cannot be a disguised vector of fitted coefficients. Comments/strings cannot be hidden state stores. Data-informed source structure and declared hyperparameter choices are intentionally part of adaptive investigation. Independent semantic method admission must examine their derivation and cannot be replaced by a hash, static word filter or an assertion of cleanliness. That qualification is currently absent.

Nuisance and joint contexts never share transcripts, tools, fitted state, source revisions or outputs. They receive the same task description, primary agent version and generic tool environment. Their scientific contrasts are descriptive unless an independently reviewed matched-method policy also establishes comparable methodology. The trusted reference comparison below provides an independently specified paired methodology. A candidate may not improve its primary ranking by deliberately degrading nuisance predictions.
