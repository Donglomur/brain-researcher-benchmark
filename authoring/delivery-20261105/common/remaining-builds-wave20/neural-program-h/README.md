# NEURAL-060: full neural contribution programme

This source implements the approved 29-session, 13-mouse, seven-laboratory BrainWideBench wheel-prediction study. It replaces the selected finite-task approach with two complete agent workflows: a globally frozen program and isolated case-adaptive investigations with matched input, tool and compute budgets. Both have three author replications and nuisance, joint, and paired test-neural-shift conditions. They remain one canonical assignment.

The primary endpoint is joint wheel MSE with equal mouse weighting. The diagnostic compares original and 10-bin cyclic-shifted TEST counts within each 50-bin window while keeping nuisance variables, target, fitted state, submitted method and paired RNG fixed. Training and validation remain original. The shifted arm cannot author, adapt or refit again. This is an alignment diagnostic, not a causal effect or proof of native neural understanding.

Three independent reference families supply linear, ExtraTrees and Fourier/history comparisons. Each session and information role uses the complete frozen 13-setting train/validation search and three winner refits. Selected-family contrasts and within-family paired contrasts are retained separately. Empirical competence and resource feasibility remain unknown until authorized full-data qualification.

The concrete execution path includes original-data preparation, a label-free operator projection, typed candidate views, actual HTTPS action transport, offline Docker tool workers, protected semantic method admission, supervised final fitting, fresh prediction-only replay, independent process/journal/daemon observation and protected target-last grading. It is executable source, not a callback returning an imagined investigation. Every external service and authentic input remains disabled and unqualified.

The complete schedule contains 180 author contexts, 870 candidate fit/inference processes and 145 independent reference processes. The references contain 928 constituent fits and 261 family inferences. Candidate outputs form 18 panels; references form nine family panels plus three selected-procedure summaries. These are conditions and outputs, not extra benchmarks.

`DESIGN.md` is the accepted scientific contract. `program/README.md` explains the implementation, isolation, resource policy and limitations. `program/SOURCE_MANIFEST.json` and `program/RUNTIME_SLICE_V3.json` identify the current source. `ROOT_HANDOFF.md` records the review/queue and future-qualification requirements. Both authority templates remain inactive. Historical design, preparation, runtime and failed-control versions are retained explicitly; their historical receipts do not qualify the current version automatically.

Preparation and reference source were independently reviewed before runtime integration. Runtime V1 review identified CPU-stop, event-chain, artifact-lineage, failure-reporting and target-alias defects. V2 repaired those defects; V3 adds canonical path rejection, pending-start uncertainty and exact failure identity lists. Metadata and inert-transport controls exercise the complete fixed workload and malformed cases. They are not authentic preparation, estimator fits, model trials, scientific scores or proof of an operating provider/native environment.

Original full input support, exact prepared query/unit counts and byte identities, environment/provider compatibility, host resource feasibility, reference competence, method-review service and actual scientific results are still open. `qualified_neural_contribution` is null.
