**Purge means adjacent trials, not adjacent chunks.** With zero-based U={0,...,139}, B_k={20k,...,20k+19}, define N(B_k)={20k-1,20k+20} intersect U. Outer query is B_k; outer training is T_k=U minus(B_k union N(B_k)). For each other chunk l, validation V_kl=T_k intersect B_l and training S_kl=T_k minus(B_l union N(B_l)). The six V sets partition all eligible outer training trials. All five windows stay with their trial. The one-trial rule is prospective and cannot undo upstream preprocessing or certify raw overlap removal.

**The shuffle is matched and cannot move excluded labels into inner fits.** Partition each outer training set into atoms with the same acquisition chunk and identical membership bits in every S_kl and V_kl. Permute target labels only within each atom, once per outer case with a predeclared source/case-derived seed. Every enforced inner support is a union of atoms, so every restricted permutation stays within that support. The candidate gets only the resulting outer-null labels. The reference fits and validates against restrictions of that same null vector; it never tunes against original inner-validation labels. Outer-query labels remain private.

Record sizes, permutations and unchanged counts, and never reseed to obtain a desired result. It does not purport to remove every task prior. Native MATLAB shuffles remain literal and separate.
