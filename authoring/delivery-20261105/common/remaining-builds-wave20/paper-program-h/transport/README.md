# H concrete transport

This source adapts the reviewed seven-file OSL transport and its independent host supervisor. The exact donor identities are in `../host/DONOR_BINDINGS.json`. No runtime qualification transfers. This lane has made no provider, Docker, socket, native, model or scientific call. The caller must separately authorize and qualify the actual operation, Linux host, local images, source exposure, original data and full resource policy.

`Provider(control_root, quarantine_root, docker_binary, docker_socket, engine_source_pin, trusted_exposures, source_read_limit, host_write_limit)` implements the actual local Docker launch, stopped-producer capture, retirement and recovery. The two roots must already exist as disjoint operator-private ordinary directories. Source, executable and socket paths must be absolute and have no symlink ancestors. `engine_source_pin` pins `SOURCE_MANIFEST.json`; `trusted_exposures` maps exact approved exposure SHA256 values to private approval paths. All images must already be installed by exact `sha256:` identity. Pulling and network are disabled.

`execute_phase(request, mounts, original_deadline, journal)` returns a pinned closure receipt, captured output inventory, final transport counters and observation time. `observe(phase_id, request_sha256, receipt_pin, original_deadline)` independently rereads that private receipt. `recover(phase_id, request_pin, ownership_pin, original_deadline, journal, limits, controller_closed_proof)` permits only bounded recovery of the three exactly declared owned resources after independent controller and CLI closure. The parent implements the durable journal; it is an evidence sink, not a missing execution provider.

Every request has exactly `schema, phase_id, action, role, image, command, workdir, source, exposure, clock, resources, output`. The schema is `h_owned_phase_request_v1`; workdir is `/work`. The eight actions are `prepare_originals`, `prepare_fold`, `native_attempt`, `train_model`, `analytic_prior`, `evaluate_model`, `grade`, `report`. The native, trained-model and analytic-prior actions permit roles A, B or reference. Other actions are private operator phases. Native-role phases contain the full 11-call reconstruction and emit all selected typed dispositions, rather than changing the phase roster into 33 partial-native output producers.

All phases use `{"kind":"generic","manifest":"OUTPUTS.json"}`. The envelope is exactly `{"schema":"h_transport_output_manifest_v1","phase_id":...,"request_sha256":...,"files":{...}}`, including a pinned `RESULT.json` and every other output member. The envelope excludes its own self-referential pin. The actual output directory must equal those files plus `OUTPUTS.json`. Complete-file cardinality, directory cardinality, extents, hashes, member names and unchanged final inventory are admitted. Scientific array, graph, native-disposition and cohort validation belong to the concrete parent implementation.

`clock` binds the original origin and phase deadline. `original_deadline` is the same global cutoff. All setup, producer, capture and cleanup allowances must fit before launch; recovery cannot refresh it. `resources` has exactly the integer-positive fields in `contract.RESOURCE_KEYS`: all four time allowances, memory, CPU, PIDs, scratch, file/directory/output limits, CLI limits, source reads and host writes. No operational sizes or host feasibility are selected in source. The full 9,240-model retained-set reservation is an additional parent requirement; a transport output cap alone does not satisfy it.

Each mount names an exact read-only file or closed directory inventory with `{path, kind, purpose, files}`. There are no caller writable host binds or overlapping mount trees. A permits paper, contract, input and program purposes; historical author source is permitted only for B/reference/operator, and private reference source only for reference/operator. `h_transport_exposure_v1` binds role, complete image, source, command, exact mount membership, the independently approved image inventory and boundary audit. Actual semantic image/source exclusion is a separately reviewed prerequisite, not inferred from a checksum or a different Python path. Each producer receives fresh `/work` scratch and `/output` volume, isolated UID/GID65534, read-only root filesystem, network none, no capabilities, no implicit volumes, no healthcheck, no restart and bounded resources. The holder has its own read-only capture mount and reported auxiliary ceilings.

The fixed source holder inventories only after independently observed natural producer exit, no OOM and producer removal. Artifacts stream through the bounded local Unix-socket Docker archive endpoint, never CLI/base64 numeric output. Strict tar/HTTP framing, regular-file-only membership, exact extents and hashes, checked writes/fsync/close, no symlinks and a final unchanged inventory gate admission. Every CLI starts behind a one-byte bootstrap gate after a durable Linux birth-identity record. Cleanup signals only a captured pidfd; numeric groups receive absence probes, never a kill based on a reusable PID. Unknown descendants, ambiguous creation acknowledgments, incomplete history, publication failure and cleanup errors remain unknown. Namespace absence alone cannot erase uncertain custody.
