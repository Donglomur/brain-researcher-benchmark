## What the inventory fields establish

Ninety-nine manifests have a nonempty `input_assets.exact_asset_records` field; one, NEDS (`PAPER-paper-method-replacement-005`), does not. This is a field-presence count. Relative to the prior consistent-field census, the count rose from 88 to 99, with eleven formerly empty fields populated. The name `exact_asset_records` does not establish complete selected-program inputs, payload integrity, usable schemas, correct identity joins or readiness.

The metadata review distinguishes five groups across the same 100 projects:

- Ten contain explicit assertions of complete selected input-file membership: ROOT-ADD-002, 006, 007, 010, 014 and 026; method-018, 034 and 047; and method-add-004. This authenticates recorded assertions and membership metadata, not all original derivations, whole selected-program closure, whole-paper coverage, runtime or science.
- MINT, method-011, now names all four original primary behavioral dataset routes. Cohort, annotation, native-loader and protocol joins remain open; three routes lack an immutable payload version/checksum. Larger-paper requirements remain separate.
- REVE, EEGPT and CBraMod, method-003, 023 and 024, have complete inventoried PhysioNet components but incomplete selected multi-dataset program inventories. This component metadata does not cover their full programs.
- NEDS retains all 84 source session memberships and 7,346 candidate original objects, but its exact dependency-resolved loader selection remains unresolved. Candidate bytes are not a selected storage requirement, and a public provider snapshot is not a global immutable release.
- Eighty-five contain descriptors without an adjudicated complete selected-membership assertion in the reviewed fields. Unknown coverage is neither a finding of incompleteness nor evidence of completion.

The canonical specification admission fields still report zero runnable, zero research-qualified and zero full-contract-complete paper projects. This narrow field census does not recount or negate separately registered runtime interfaces, historical finite validations, selected input preparation or installed program routes. Those overlap and require their own evidence. No scientific or model runs, new numerical results or SOTA claims arise from this metadata update.

## Interpretation and remaining dependencies

Inventory rows describe public file names, source dataset/session identifiers, provider object IDs, declared extents, hashes and source locators. They contain no neural payload arrays or protected answers. Public coded subject and recording filenames are source metadata, not a private identity-key mapping. A file named as a measured response, target or prediction is a descriptor; its body is not supplied by this update. The ten Allen session integers are public session identifiers, not outcome data.

Some relative provenance paths refer to local records or to files not included in the public export. They are descriptors with recorded hashes, not an assurance that a reader can retrieve the record here. Do not infer that the corresponding receipts, private material, packet members or scientific dependencies are published. Checksums copied from a publisher, historical local payload digests, Git object IDs and opaque ETags keep their distinct meanings. None is silently treated as a newly verified payload hash.

Historical prose is retained where clearly marked. MINT's legacy single-dataset prose is superseded by its explicit four-route followup; this does not close its larger scope. The iSTTC followup describes the selected released Hawkes simulation scope; biological Allen recordings and whole-paper claims remain separate. ROOT-ADD-010 records a Version of Record and retains superseded reviewed-preprint metadata only as provenance; its source-contract/endpoint reconciliation remains open. Spike-sorting method-add-008 likewise records a Version of Record. The connectivity paper method-add-010 records a correction notice and unresolved held-supplement version/hash join. Publication metadata alone does not establish source parity, input readiness or scientific validity.
