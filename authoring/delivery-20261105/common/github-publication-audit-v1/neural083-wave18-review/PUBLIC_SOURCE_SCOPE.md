# NEURAL-083 public source snapshot

This snapshot contains implementation source for the existing OpenBMI motor-imagery assignment. It is not an executed, scientifically qualified or submission-ready benchmark, and adds no new task, dataset or cohort. The fixed-program condition retains all54 people, both sessions, four calibration settings and three information arms. Each independent candidate/reference panel requires1,296 complete condition results and129,600 probabilities. Both panels together require2,592 results,259,200 probabilities and5,184 fit/infer phases. The same10,800 unique online trials recur across conditions; repetitions are not independent observations or additional benchmarks.

The primary remains EEG/target20 balanced accuracy, averaging sessions within person and then all54 people equally. Other calibration, context and training-label-permutation contrasts remain descriptive. A separately named candidate-minus-independent-reference difference does not replace the primary. Both complete panels must be admitted before protected target access; any missing condition or abstention leaves the complete comparison unscored.

Each condition stages the original globally opaque-sorted monolithic training input. A fresh fit process produces a bounded model; the operator captures and seals that model after natural process closure, retires the training mount, then stages the complete100-row query input for a fresh inference process. Permitted labeled training examples may be retained inside the model. Candidate-visible donor-session fragments are excluded because they would reveal extra source partition information. No cross-condition model/cache reuse is permitted, since target labels occur in other conditions' donor pools.

The query interface is batch inference. A read-only model, source hash or separated fit process does not universally prevent arbitrary submitted code from fitting to query features. The original no-query-adaptation rule therefore requires separate method/exposure admission tied to the exact source, inputs, image, resource limits and execution configuration. This is not mechanically isolated pointwise inference or the interactive-investigation condition. Publication establishes neither that method admission nor actual isolation.

The independent reference is the original benchmark's prospective regularized CSP/sample-logvariance/shrinkage-LDA and training-only out-of-fold Platt probability recipe. With target calibration it uses that permitted calibration alone; zero-calibration transfer uses all10,600 donor trials. Other candidates may use the full allowed donor pool. The prior fallback, five training-only folds and final refit remain declared source behavior. The fit/infer split adds serializable source-defined state and changes some bookkeeping representation; it is not empirical numerical parity with the old combined interface. It is also not the native MATLAB/BBCI reference, a demonstrated competent comparator or a SOTA result. The included historical REFERENCE.md explains the prospective mathematical and preprocessing departures.

The frozen reference uses Python pickle only for its own independently captured and sealed fit artifact. This is not a safe format for untrusted model files: candidate artifacts must never be deserialized by that reference loader. No pickle body, fitted state, weights or prediction output is included in this source publication. NumPy2.2.6, SciPy1.15.3, scikit-learn1.6.1 and Python3.12 are declared future dependencies, not installed or qualified environments.

Resource quantities have different meanings. The108 prepared arrays' numeric payload is433,728,000 bytes. The straightforward full two-panel composition would copy369,199,555,200 training numeric bytes and3,471,552,000 query numeric bytes cumulatively. That repeated copying is not resident dataset size or measured expenditure. The512MiB per-model interface ceiling yields a1,391,569,403,904-byte cumulative worst-case model-capture allowance across all conditions, not a simultaneous retained-model footprint. Input/readback, metadata, native responses, retained allocation, other reservations and time limits need separate explicit admission. These are source-derived components and ceilings, not measured physical I/O, RAM, wall time or local feasibility. No369GB or1.39TB workload was executed by this publication audit.

All18 entries in program/SOURCE_MANIFEST.json are copied unchanged, along with the manifest and selected explanatory/registration/provenance source. This closes only that captured source list. The program's BINDING still points to original protected scorer/protocol definitions, input preparation and historical scientific sources. Actual original recordings, authenticated prepared arrays/index, source-channel/onset/class identities, identity secrets, query targets, operator reviews/authority, exact image/dependencies and resource/runtime qualification are separate prerequisites. Some source documents name rejected designs, controls and history intentionally omitted from this public snapshot. It is not a dependency-complete runnable evaluator release; named historical files are not implicitly present. The supplied adapter remains unselected and refuses normal execution before opening candidate or input operands.

The original experimental class cue persists during imagery, and recorded online visual feedback came from a100-trial-calibrated classifier. Limiting the new program to20 labels does not change historical feedback or prior participant training. The endpoint is retrospective protocol-class decoding, not cue-independent intention decoding,20-trial closed-loop performance, calibration-time reduction or causal motor physiology. Other-session transfer is retrospective and bidirectional. All54 people and complete selected support remain required; no convenient subset is substituted. Full input, method, numerical environment, native runtime, reference competence and scientific qualifications remain absent for this source condition.
