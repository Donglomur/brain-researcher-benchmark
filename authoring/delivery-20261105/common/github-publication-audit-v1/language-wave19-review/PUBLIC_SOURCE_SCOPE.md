# Language paper program: public source snapshot

This snapshot publishes implementation source for the existing **PAPER-ROOT-ADD-001** assignment, based on Cai et al., *Mapping the neuronal building blocks of human language with language models* ([paper DOI](https://doi.org/10.1038/s41586-026-10691-5); [declared release](https://zenodo.org/records/20128462)). It adds no task, empirical result or qualified benchmark. These source identifiers are inherited from the reviewed local provenance; this publication audit did not revisit the websites or open the paper or data.

The selected program retains **14 recording sessions from eight people, 567 session-local units and 33 language-model layers**. It compares reconstruction of the specified neuronal predictivity analyses with separately authored prediction programs. The selected scope excludes the paper's other selectivity, decoding, LFP, anatomical and causal branches. It is not whole-paper reproduction. Session-local units are not independent participants or authenticated cross-session neuron identities.

## Paired access and scientific endpoints

Four programs are frozen independently before numerical input exposure: reproduction A and B, and prediction A and B. A receives the specified paper, task/method specifications and general runtime utilities; B additionally receives the 18 designated released author source files. The timing/text archive is withheld during authoring and enters both runtime views after commitment. Numerical inputs arrive during execution. This is the fixed-program condition, not interactive investigation of each case while authoring a solution.

The two reproduction programs must return all 16 prescribed fields for each session, including the full unit-by-40-lag-by-33-layer context surface. The primary remains equal-person, within-person equal-session mean absolute error against a separately executed benchmark reference. Availability masks must match. Undefined primary support makes the complete primary unavailable rather than permitting favorable unit selection or a replacement threshold.

Prediction retains all five purged sentence folds per session, **70 episodes** overall. Each candidate is compared with independently produced context, lexical, random-token and clock baselines. The fixed baselines select features and regularization within the training packet using the original nested purged rule. The metric pools the five folds within a session before per-unit Pearson and the specified person/session aggregation. Four candidate-minus-baseline gains remain separate from reproduction error; there is no combined reward or arbitrary binary success criterion. Candidate-reported baseline scores are not accepted.

The complete composition has **213 producer phases and 71 trusted preparation/staging children**: three full native producers, 140 candidate prediction producers and 70 operator prediction producers; one full preparation and 70 episode stages. Both candidate arms and every required operator result must close before collection and separately authorized grading. Source controls exercised the complete graph and late-failure barriers using invented metadata and mocked effects. They did not execute these scientific phases.

The operator implementations under `vendor/operator` are benchmark reference and grading code, not candidate materials. A public checkout is not an A or B evaluation view: giving it to a candidate would expose the operator implementation and invalidate the intended comparison. Actual source/image/mount isolation, separate authoring contexts, no feedback between programs and prior-exposure reporting still require independent admission. Public source release cannot establish that a later model has never encountered the implementation or the published results.

## Interpretation and execution limits

The released global PCA/embedding preprocessing can be transductive. Centered smoothing, supplied word/speaker timing and the within-session folds are retrospective. This endpoint does not establish causal future prediction, held-person generalization, interpretation of arbitrary raw neural signals, a novel physiological mechanism or a SOTA improvement. The benchmark reference is grounded in author source but is not claimed to be numerically identical to an authenticated historical native run. Copying the earlier benchmark reference source does not supply that missing validation.

The source contains a concrete controller, staging, Docker transport, independent reference entry points, custody checks and separate grading command. Normal publication runs none of them. Future execution requires authentic input and environment authority, a qualified immutable image and interpreter/native libraries, complete exposure and resource bindings, and independent natural closure of the observer command. A marker file or an authority boolean alone is not proof of those facts. Forced termination can leave independent host groups or Docker resources; unresolved custody does not authorize a retry or release of reservations.

**All 168 original neural/embedding payloads remain missing in the reviewed source state.** The headers, shapes, file identities and archive routes in `BINDINGS.json` and `ACQUISITION.json` are metadata, not downloaded arrays or verified numerical support. Public cohort labels and declared dimensions are source metadata, not newly collected identities. No query targets, waveform samples, neural observations, transcripts, model weights, candidate outputs, private identity keys or communications are included.
