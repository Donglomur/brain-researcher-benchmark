# NEURAL-014 public source snapshot

This is source for an existing neuroscience benchmark assignment, not an executed or submission-ready benchmark. It adds no canonical task, participant, dataset or scientific result. The released implementation is the fixed-program condition: a candidate and an independently frozen reference each produce the complete seven-arm panel. Exploratory, case-adaptive agent orchestration is outside this source condition.

The selected scientific protocol uses all 45 declared T15 sessions from one person: 27 training, nine development and nine later sessions, with 86 publicly labeled HDF5 source members. Each panel requires all 63 session/arm answers. Every suffix query must remain after the defined chronology and global exact-sentence exclusion rules; missing support refuses the complete endpoint. For Q retained suffix trials, the two panels require 56+12Q phases and 38 sealed models. These are construction requirements, not observed authentic-data counts or completed runs.

The primary is mean full-adapt phoneme error rate over the nine later sessions, without clipping. All seven absolute results and the original descriptive contrasts remain. A separately named reference-minus-candidate full-adapt PER contrasts the two independent programs. Within-candidate contrasts cannot establish improvement over an independent comparator. The source provides preparation, a frozen program interface, per-query isolation and model-lineage logic, complete output checks and a protected scoring composition. Scoring code is public; target data, transcripts, identity secrets, authentic arrays, prediction files, model artifacts and operator attestations are not included.

The baseline is an original compact benchmark GRU/CTC reference, not the paper's deployed decoder, author weights, or a demonstrated competent comparator. Its 512-to-128 input affine layer, two 128-unit unidirectional GRU layers, 41-class output, ten training epochs and 100 affine-only calibration updates are source rules. NumPy 2.2.6, Torch 2.6.0 and Python 3.12 are declared dependencies; no compatible image, library installation, runtime feasibility or reference accuracy is established by publication. Full, shuffled and zeroed neural queries share the same sealed adapted model within a panel. Feature loss removes fixed feature columns, not verified physical electrodes. Duration and other retained cues limit ablation interpretation.

The explicit neural014-fixed-program-cost-v2 policy supersedes the original collector's universal trusted optimizer-update requirement for this source condition. It is incompatible with that historical collector. Future qualified observations may establish wall time, selected resources, phase counts, permitted label exposure and model lineage. Arbitrary candidate optimizer steps remain null/not observable unless independently attested for that method. Reference 100-update logic is declared source behavior, not an observed execution count. The old collector and history are not rewritten or published with this snapshot.

The 25 members of SOURCE_MANIFEST.json are all included unchanged, together with that manifest and selected explanatory/launch source. This closes that local runtime-source list only. Referenced historical source pins, original preparation/source-selection metadata, operator review receipts, central registries, actual data, gold, secrets, selected compute/image, independent runtime qualification and execution authority are separate dependencies. The public fork is not a dependency-complete runnable release. The optional captured-entry recipe only constructs a command; it does not authorize a launch. The proposed central adapter refuses before candidate, output or review operands. Some documentation names local review/test/history artifacts that are intentionally omitted; it does not imply those artifacts are present here.

The complete 11,051,034,483-byte archive has not been admitted for this task. Source totals of 10,948 versus 11,162 trials, actual post-exclusion support, feature anatomy, preprocessing exposure, resource feasibility and source preparation remain unresolved. Public retrospective observations from one person do not establish population, clinical, isolated biological drift, official hidden-test, paper word-error-rate, whole-paper reproduction or SOTA claims. No authentic model fitting, inference, evaluation or benchmark score is published. Runtime, scientific and submission qualifications remain false.
