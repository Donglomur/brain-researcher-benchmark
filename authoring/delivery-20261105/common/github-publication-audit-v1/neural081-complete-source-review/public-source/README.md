## F, I and references

Both may temporarily adapt on the same nine-person labelled training set plus exactly one unlabeled current query. Neither receives held labels, another query, cross-query state or target feedback. This is explicitly single-query transduction, not an inductive candidate protocol.

EEG and ZERO views preserve the same biological support. ZERO replaces all training/query waveforms with positive binary32 zero and cannot access EEG artifacts. Three replications and both views give 6N I contexts and 6N F query executions.
