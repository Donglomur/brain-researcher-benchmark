# Explicit reconstruction and relocation limits

All scientific Python source and the selected written equations can be reconstructed exactly from the original-path bodies in `PUBLIC_SOURCE_MANIFEST.json`. The public metadata derivatives preserve the operator schemas and all nonprivate, non-stream values. They make the source structure inspectable without a private user's home path. They do **not** reproduce the original installed byte identities or create a qualified deployment.

Each derivative is an envelope with `original_identity`, `rewrites` and `payload`. Its own public bytes/hash are different from the original descriptor. Each private-root rewrite identifies the exact JSON pointer, SHA256 of the original full locator and symbolic public value. Every non-rewritten value is retained. Original merge-stream replacements identify their UTF-8 byte count/hash without supplying their bytes. The accepted private source hash is never changed to mean a public template.

The symbolic `${NEURAL081_SOURCE_ROOT}` represents a newly chosen absolute repository root. It is not the original private root and must never be expanded by blindly evaluating a shell. A future operator may materialize a new metadata instance by reading the derivative `payload` as JSON, substituting that exact token at only the listed pointers, and writing distinct newly identified files. The source layout below the root stays as listed; the genuine entry-path and captured-source requirements in the code remain in force.

Materialization alone is insufficient. All resulting changed metadata must receive new byte/hash identities, and every dependent descriptor, source manifest, qualification map, proposal, registry and authority must be consistently regenerated and independently reviewed as a **new instance**. Old author/peer/adoption receipts cannot be relabelled as accepting those bytes. Historical provenance artifacts, private operator authorities and protected operational source files are not recreated by a template. The existing runtime's exact private source/adoption joins will refuse a casually substituted public derivative.

The public dataset, source-annotation support and environment obligations are also unchanged. Acquire no data or package merely because this document exists. Actual execution requires separately selected authentic-input access, source/environment/resource/provider/custody qualification and fresh operator records. Preserve target-last grading and per-query F/I isolation. Bind and retain actual process/stream completion; metadata declarations cannot substitute for it.

Thus this snapshot is complete for inspecting and rebuilding the scientific source and explicit metadata schemas. It is not the original complete private operational closure and is not independently runnable under the original authorities. This audit supplies no relocation executable, automatic pin-rebinding procedure or replacement qualification receipt.
