# Source provenance and rights

The public repository's existing MIT license, copyright 2026 Brain Researcher, remains unchanged. The selected benchmark implementation, independently authored numerical references, contracts and shared campaign helpers are project source. Original notices and bytes are retained. This audit adds no project-wide relicensing rule.

The scientific source contracts identify OpenMIIR repository revision `f3418202d8ae9311e9d69238fba694dc437232f8` and Deepthought revision `ec7f12f0be7b0a19f728c612fb8f9e5a42cb9d7e`. They also identify exact historical scikit-learn/SciPy source captures used to specify equations. Those referenced upstream code bodies, recordings, stimuli/workbooks and package distributions are not selected outgoing bodies here. Their licenses and dataset permissions remain their own; no redistribution right for an external recording or library follows from the repository license. This is a source/provenance audit, not an independent legal opinion on external materials.

The scientific code supplies protocol taxonomies, participant codes, channel names, class order, event-code conventions and formulas. These are not an authentic per-trial answer table. Previously invented source-control metadata is explicitly labelled as such. No actual EEG/header, protected identity key, authentic assessment table, fitted state, candidate transcript, provider credential, original installation/verifier stream or raw scientific output is supplied.

Three fixed operator-instance bodies are deliberately not supplied verbatim: the parent manifest, central bindings and source-merge-204 original stream record. Public derivatives preserve their original byte/hash identities and all nonprivate, non-stream fields, with exact changed-field maps. The host-specific installed registry is treated the same way. Private host-root strings are replaced by a symbolic root only in these separately named derivatives. Stream replacements carry identity-only descriptors. Scientific source is not redacted. The original acceptance identities remain distinct from the derivative identities.

The source denial literals `/Users/`, `/home/`, `file://` and `Bearer ` are privacy guards, not disclosed personal locators or credential values. Two project-agent role names in original construction prose are provenance labels. These exact source contexts are documented by the audit; they do not authorize a general privacy-scan bypass.

The exact public outgoing map is the publication boundary. Private audit reports, source-construction history, operational proofs and private Git commit ancestry are not selected by that map. A future publisher must construct clean public history, preserve the existing license and recheck the exact intended bodies. This source package itself selects no publication or scientific operation.
