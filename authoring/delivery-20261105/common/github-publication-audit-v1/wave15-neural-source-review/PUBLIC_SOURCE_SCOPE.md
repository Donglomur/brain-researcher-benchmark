# NEURAL-084 public source scope

This snapshot publishes the frozen v1 interface and source construction for OpenBMI overt-gaze flicker-target decoding. A sequential v2 is in development and is not part of these frozen files. The snapshot adds no empirical results, benchmark qualification, or claim that the exported controller is ready to run.

The task includes all 54 designated people, both sessions and both acquisition phases, with 54 leave-one-person-out contexts. Each context has 21,200 labeled training epochs from the other 53 people and 400 unlabeled queries. The intended complete candidate output has 21,600 predictions. Each context has a fresh candidate process and separate CCA, constant-score and frequency-column-permutation diagnostic processes. These are four declared modes per context, not four newly created benchmark IDs.

The public task contract is in `authoring/delivery-20261105/neural084/public/TASK.md`; packet and submission schemas, the Python CCA reference, and its environment recipe are beside it. The v1 candidate ABI is in `authoring/delivery-20261105/common/remaining-builds-wave15/next-neural-program/program/PROGRAM_ABI.md`. The task's acquisition-status paragraph records its original construction snapshot. It is not a current download inventory or evidence that a real full-cohort packet has subsequently been admitted.

The representation is prospective: ten posterior channels, 400 half-open block-mean samples at 100 Hz over [0,4) seconds. It is not a numerical reproduction of the author's continuous filtering/resampling and inclusive-endpoint MATLAB pipeline. Frequencies and class ordering are public protocol constants; the roster is a designated numeric cohort, not participant names or private query identities. No trial labels, hidden query order, original EEG, trained models, private gold, empirical predictions or results are included. This is overt-gaze target decoding, without claims about covert attention, causal mechanisms, clinical effectiveness or MATLAB parity.

## Dependencies deliberately outside this snapshot

The unchanged `adapter.py` and `program/*.py` are operator infrastructure and reference source. Their original runtime requires `SOURCE_MANIFEST.json`, `BINDINGS.json`, `program/SOURCE_MANIFEST.json`, `program/BINDING.json`, operator selection and review records, authenticated preparation and staging dependencies, a compatible cached container image, and complete prepared public packets. The original bindings also authenticate preparation/scoring sources that are not exported. Those local bindings, templates, captured preferences, receipt histories and private-scoring files are deliberately absent. The code therefore cannot be treated as a self-contained runnable benchmark or as a way to reconstruct the missing operator authority. A future executable public package needs a separately reviewed binding and preparation design.

`test_program.py` and `test_adapter_boundary.py` are invented source-control fixtures. They are included for inspection; this publication audit did not execute them. The adapter controls and embedded-reference comparison require the omitted source manifests/bindings or original preparation sources. Their presence does not imply that the complete test suite runs from the public checkout. The public `Dockerfile` and pinned Python requirements are a source recipe, not proof of a built image or compatibility with the controller's separately fixed image identity. No automatic download, build, execution or installation accompanies publication.

Candidate training transformations and model selection must use training people only. The public single-call v1 ABI makes the current training and query packet accessible together; filesystem mounts alone do not prove training-before-query chronology or absence of query-batch fitting. Independent method and input-preparation review remain required. The separate case-adaptive tools condition is not implemented by this frozen-program route. Complete native execution, empirical reference behavior, private scoring, and scientific validity remain unqualified.
