## Scientific scope

The source study is Daume et al., *Control of working memory by phase–amplitude coupling of human hippocampal neurons*, [Nature, 2024](https://doi.org/10.1038/s41586-024-07309-z). The retained author code is [SBCAT-release-NWB](https://github.com/rutishauserlab/SBCAT-release-NWB) at `a25e8cc3f61630a428f190381745257d4506f148`. The public dataset metadata locks [DANDI 000673, version 0.240118.2135](https://doi.org/10.48324/dandi.000673/0.240118.2135): 44 sessions from 36 people, declaring 23,447,043,476 bytes of original recordings. These are metadata sizes, not downloaded or locally validated data.

This benchmark asks an agent to reconstruct a declared retrospective patient-level PAC analysis, with load and accuracy contrasts, nuisance matching, surrogate diagnostics and equal-person aggregation. It does not reproduce the full source paper, predict prospective behaviour, establish a mechanism or measure unaided native waveform understanding. Correctness and load are permitted grouping variables. Original filtering and within-epoch analysis can be noncausal.

Each report retains all 144 person/design/contrast rows and four group rows. Both within-load accuracy comparisons require at least ten matched pairs; missing support stays null. If accuracy support is absent, the canonical primary score remains null. The source does not lower that floor, replace an endpoint or drop a person to obtain a score. Numerical reconstruction, support status, reasoning and biological claims remain distinct.

The complete comparison contains eight mode/world/tool cells: frozen-program F and case-investigation I, each with O/T0, O/T1, D/T0 and A/T0. O is original input; D changes trial correspondence while retaining within-trial PAC; A withholds measured signals while retaining declared structure. T0 still uses general Python/numerical tools. T1 adds only the restricted local PAC primitives. Four data-free authoring contexts and 288 person phases produce eight candidate reports. Two independently authored numerical references each compute complete O and D reports. There are 448 declared top-level phases, including authoring, and at least 444 native numerical jobs before additional investigation/feature work. These are workload units, not benchmark counts.

Original O is the primary reference target for every cell; D also has a separate self-consistency diagnostic. Failed or unsupported reports are not numerical zeroes and do not yield a fabricated neural-gain scalar. No original-full-study run, native parity, qualified reference comparison, model result, SOTA result or submission-ready claim accompanies this source.

## Exact-byte source encoding

The original `NWB_SBCAT_analysis_main.m` is 12,606 bytes with SHA-256 `7e0c356df1cf7215d67036c90e144cc2f34b57fc8a228da4828a6958ac55cd36`. It contains a Windows-1252 apostrophe and is not valid UTF-8. Its full decoded source was reviewed, including its ordinary upstream Windows locators. No byte was transcoded or removed. The local audited source transport uses an ASCII hexadecimal envelope with exact original length, SHA-256 and Git blob identity.

That envelope is a transport artifact, not the original-path MATLAB file. Complete public delivery of the manifest requires a separately reviewed bounded restoration/materialization path, strict envelope admission, post-decode original pins and exact original-path Git blob verification. Until that occurs and is independently verified, the content audit alone does not establish complete original-path public presence. The other source bodies use identity UTF-8 transport. This exception grants no permission to decode unrelated binary payloads or relax secret checks.
