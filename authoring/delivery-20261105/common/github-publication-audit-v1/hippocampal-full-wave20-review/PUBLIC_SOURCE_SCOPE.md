# Hippocampal benchmark source: public scope

This package exposes the complete, unchanged 40-member executable source capture for the existing `PAPER-FIND-ADD-003`, plus sixteen selected interface, design and provenance documents. It adds no task, result, selected operation or scientific qualification. The source comes from commit `c404dca542a9e2d79629890717c0184bf3c2f3d0`. The executable manifest remains byte-for-byte unchanged; this publication is not a runnable scientific release.

The motivating paper is Dorian et al., *Hippocampal sequences represent working memory and implicit timing*, Cell Reports (2025), DOI `10.1016/j.celrep.2025.116383`. The source defines two distinct evaluations: reconstruction of selected original analyses, and a prospective comparison of representations available within a short neural-data window. Neither condition establishes reproduction of the entire paper, a new biological finding, native LLM understanding of neural signals or frontier performance.

## Complete selected scientific scope

The native condition retains all 23 behavior animals and all 11 imaging animals, the last two standard and first two reversal days, 44 imaging sessions per preprocessing variant, and both source preprocessing and no-smoothing/no-flooring inputs. Its eight original output families contain 56,868 positions across the two variants. Every position retains its original units and a finite, source-undefined, failed or unstarted disposition. Undefined scientific support is not a successful process failure, an omitted animal or an invented target.

The prospective condition predicts first-odor identity from each of five fixed 15-frame windows covering source frames 95–169. It keeps the full 140-trial session, seven contiguous outer folds and exact adjacent-trial purge, with six inner reference folds on permitted training trials. Neural, nuisance/clock, combined, clock-prior and conditionally shuffled-combined families are mandatory. The primary comparison is candidate minus independently selected reference balanced accuracy in the unsmoothed/unfloored variant; source preprocessing is a separate required sensitivity. All families, supports, variants and paired animal values remain reported. This is within-selected-session evaluation, not evidence of generalization to new animals.

The independently specified prospective comparator searches twenty fixed linear/RBF SVM configurations, with 120 inner attempts and one selected refit per trained reference model. Native defaults, graph/native agreement and empirical comparator competence still require qualification. The candidate graph is a finite pure computation with a restricted current-window interface; it is not an arbitrary program with unrestricted query access. The inherited upstream deconvolution, session normalization and preprocessing prevent a claim of raw-signal or online causal decoding.

The complete planned graph has 19,102 outer phases, 9,240 model slots, 924,000 prediction records and 298,144 prospective reference fit attempts. The independent native reference has eleven specified calls. Three native role programs cover the same recipe, but candidate internal call and search counts remain unknown until observed. These are source-derived workloads, not completed runs, measured costs or additional benchmark IDs. A smaller cohort or favorable surviving subset does not qualify the full condition.
