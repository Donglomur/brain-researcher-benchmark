This snapshot publishes implementation source for the existing **NEURAL-089** phoneme task and its `full90_native_split_pointwise_controls_v1` condition. It adds no benchmark ID, empirical result or qualified evaluation. The frozen source identifies [LibriBrain](https://huggingface.co/datasets/pnpl/LibriBrain) edition 2025, dataset revision `5a7c332b34fc7be329c4df3e527a41f67bfd878f` and pnpl revision `33aff3fd70a197a47f73a06cb5d1e6b0e1cbfb9b`. ## Complete scientific condition

The selected scope keeps **all 90 recording runs from one participant: 88 training, one development and one query run**. It preserves every eligible phoneme event, all **306 MEG channels**, each complete **125-sample window** at 250 Hz and the fixed **39-class** order. Eligibility uses the source phoneme event type, excludes only the specified silence/out-of-vocabulary markers and strips the specified label suffix. Invalid clocks, unknown labels, absent runs and short windows fail the complete preparation rather than being silently skipped or padded. The actual query count **Q** must come from authentic full preparation; source refusal caps do not supply Q.

The primary is unchanged fixed-39-class macro-F1 over the complete query recording: absent classes remain zero in the denominator and probability ties choose the lowest class index. Accuracy, class supports and the confusion matrix remain separate. There is no composite reward, arbitrary success threshold, population confidence interval or SOTA claim.

A candidate program and an independently frozen reference program each complete four arms on exactly the same full query panel:

- **MEG:** fit with all permitted training data; development labels may select the candidate method but cannot fit final estimators or normalizers. Seal the artifact, retire the fit view and predict one complete query window per fresh process.
- **ZERO_MEG:** use that role's exact same MEG artifact with a same-shape zero query. This is a training-mean input contrast, not a natural neural observation.
- **PERMUTED_LABELS:** fit a separate artifact with within-run permuted training and development labels. Both roles use the same operator-frozen permutations. Complete rows and class counts remain intact; query labels do not enter permutation construction.
- **PRIOR:** fit a separate artifact using only aggregate training-label counts. It sees no neural values, development labels, run/query identities or timing. A query-independent vector is broadcast by the trusted assembler.

The two roles produce **six sealed fitted artifacts and 6Q + 8 native phases**: three fits and 3Q + 1 inference phases per role. Only the deliberate within-role MEG/ZERO sharing is permitted. Both programs must be committed before numerical exposure. All arms and both roles must close before private target access; failed or incomplete execution does not turn a successful subset into a score.

## What the comparison can establish

This is event-aligned classification in one participant, using privileged supplied phoneme onsets and 0–0.5-second post-onset windows. Adjacent windows overlap and can contain other speech events. Native partitions can share physical sessions, chapters and repeated narrative material. The condition does not establish onset detection, continuous speech recognition, unseen-story transfer, across-person generalization or independent phoneme-trial replication. Historical public labels and retrospective source preprocessing remain exposure limitations.

Fresh pointwise processes restrict cross-query process state and batch statistics; they do not prove arbitrary code cannot adapt to its single window, recover public labels or use prior knowledge. Actual method/exposure review must bind exact programs, input views, numerical image and resource configuration. A hash alone is not proof of authoring chronology. Publishing operator and reference source does not make the repository union an authorized candidate view. Source exposure histories and actual isolation remain to be assessed.

The independent reference follows the earlier benchmark's prospective streaming logistic recipe: five 25-sample means per channel, training-only StandardScaler, then five complete fixed-order SGD logistic passes with the specified regularization, seed and 39 classes. It ignores development data. It is **not the authors' CNN**, a demonstrated competent baseline or an authenticated historical numerical reproduction. Fit/infer serialization parity and empirical competence remain unverified. Its own trusted sealed artifact may use pickle; candidate artifacts do not enter the reference or scorer deserializer.
