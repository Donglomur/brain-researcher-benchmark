# Source rights and disclosure boundary

Selected benchmark orchestration, mathematical reference code, preparation adapters, evaluator algorithms and original protocol are project-authored source. The public repository's existing MIT license and copyright notice remain unchanged. This snapshot creates no new license. External CHB-MIT data/annotations, publisher prose, conversion/scoring projects, numerical libraries, containers and provider models retain their own terms; their raw bodies are not redistributed here.

Two original preparation source bodies are omitted because they contain authentic case-specific annotation information. They are identified only by path, size and hash in the public manifest/inventory. No redacted code is represented as the exact original, and private runtime pins remain unchanged. The supplied evaluator code contains algorithms rather than assessment targets. The original protocol retains authentic aggregate annotation-support counts and public cohort grouping; it would be incorrect to describe this snapshot as containing no annotation-related information.

No raw neural/EDF-header/annotation file, private assessment-target body, identity key, model weights, predictions, credential or communication is supplied. Source variable names, private operand schemas and environment-variable selectors are not secret values. No referenced scientific/key/model/graph body was opened for this audit. Case-specific information was found inside the selected source itself, which is why those original modules are excluded.

The earlier NEURAL009 vendor/protected copies are project-authored benchmark components with exact provenance, not the external epilepsy2bids or SzCORE implementation. Dataset identities and source hashes do not confer rights to external data/software. This scoped content and provenance review is not legal certification or universal privacy assurance. The snapshot is incomplete and does not qualify a deployment or scientific result.
