# NEURAL-026 public source: specified analysis versus reference-code control

This snapshot publishes source for existing **NEURAL-026**, a controlled reconstruction task using paired mouse M1/S1 calcium imaging and reaching kinematics. It adds no benchmark ID, dataset, empirical result or scientific qualification. The upstream identifiers and method lineage come from the frozen local source notes; this audit did not visit websites or open recordings, private identity keys, targets or model outputs.

The question is whether a program can reproduce a completely prescribed analysis from its mathematical specification, and how that compares with access to its executable reference implementation. This is **analytical implementation/reconstruction**, not evidence that an LLM natively understands neural signals, discovers new biology, improves an arbitrary method or reproduces historical Figure 5 values.

## Scope and matched access

The original support remains **five mice, ten M1/S1 sessions, five folds per session and 24 native joint angles**. All **50 cases** are required. The source-defined 128-ROI selection, 51 samples from −100 through +400 ms relative to lift, complete nuisance features and all original eligible matched trials remain. The 10-ms grid is interpolated/event-aligned support, not independent 100-Hz imaging; deconvolved fluorescence is not measured spikes. ROI and trial selection must follow the fixed source rules, without outcome-based or resource-driven reductions.

The two candidate conditions share the complete mathematical specification, schemas, identical admitted case inputs, generic numerical environment and declared resource maxima:

- `specification_only_reconstruction_v2` receives no answer-producing implementation or equivalent task-specific helper.
- `reference_code_control_v2` additionally receives the exact original benchmark `protocol.py` and `reference_program.py`. Their availability deliberately permits direct use of the prescribed estimator. This is an explicit code-access control, not independent scientific reconstruction.

Two global candidate programs and distinct authoring contexts must freeze before any case input. A separately frozen reference program runs independently. The original TASK.md is retained here as provenance but is **not mounted in either successor condition**: its blanket reference-source availability describes an older interface. `ACCESS_REVISION_V2.json`, the current ABI and `specification/RECONSTRUCTION.md` govern the current views. The earlier two-panel/100-producer figures in resource addenda and method-audit notes are historical and do not replace the current three-panel schedule.

A public checkout includes the executable oracle, operator/scoring code and implementation notes. It is not a specification-only candidate view. Future authoring and execution must independently exclude task-specific reference implementations from images, imported modules, caches, helper APIs, earlier conversations and cross-condition feedback. Source hashes and flags are not proof of that chronology or isolation. Technical restrictions cannot rule out pretraining or other prior exposure. No score or reference output may flow back into the specification-only authoring context.

Each producer receives exactly one case, with fresh state. Other folds' training packets contain that case's held-out labels, so mounting the full catalogue or aligned sessions would leak answers. Source-defined matched counts across different-day M1/S1 sessions do not pair individual reaches. The cohort overlaps NEURAL-025; it is not new data or 50 independent biological observations.

## Numerical target and score

The fixed recipe uses a 141-feature nuisance basis and training-only mean-loss ridge with alpha 1, unpenalized intercepts and the specified exact-zero scale rule. A shared nuisance-to-angle fit provides the nuisance prediction and training angle residuals. Each neural arm separately fits nuisance-to-neural regression, residual standardization, reduced SVD, the smallest basis reaching 90% squared-singular-value energy and a residual-angle decoder. The shifted arm rolls whole training neural trials within target strata and refits its neural pipeline; query inputs, nuisance covariates and angle labels are not shifted. It is not a shifted output trajectory.

Exactly zero residual energy returns the nuisance prediction and skips that arm's decoder. A completed reference case therefore uses **three to five ridge fits and two SVDs**; the complete reference uses 150–250 ridge fits and 100 SVDs. These are prospective method counts, not observed computation or counts of arbitrary candidate optimizer calls. A numerical failure is not permission to change the estimator, clipping rule, regularization, cohort or rank selection.

Each output has exact query IDs and nuisance, neural and shifted predictions shaped query trials ×51×24. The original scorer pools held-out moments and errors across the five folds exactly once per mouse/area. For each joint, DeltaEV is the nuisance-minus-neural squared-error reduction divided by pooled target SST. Positive finite SST and complete original support are required. The primary is **mean absolute reconstruction error over all 5×2×24 = 240 DeltaEV contrasts** against the same independently executed reference, lower being better. Negative and null effects are valid. A larger positive biological effect is not the reward.

Secondary prediction errors, shifted-arm contrasts, paired S1−M1 summaries, descriptive five-mouse t intervals, sign-pattern calculations and the fixed jointwise multiplicity correction retain their original definitions. They do not establish causal cortical necessity, population coverage, exchangeability, historical numerical parity or a binary success threshold. Reference predictions remain comparator outputs, not private target truth. The new prospective nuisance/matching/folding choices differ from the original paper analyses, and portable MATLAB-alignment parity remains unmeasured.
