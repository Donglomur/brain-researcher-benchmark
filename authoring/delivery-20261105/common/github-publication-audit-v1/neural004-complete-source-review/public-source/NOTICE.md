This is a scoped content review, not universal privacy assurance or legal certification.

Some original source paths contain the directory name private. Only the exact listed algorithm/protocol/license bodies are proposed for export. Their neighbors and private build ancestry are excluded. Every source body remains byte-identical to the reviewed local pin. Four new explanatory public documents are clearly separate from original executable source and runtime manifests.

The package remains operationally incomplete and scientifically unqualified. External scientific data, publisher materials, dependencies, models and services retain their own terms and require separate authorized acquisition/admission.
