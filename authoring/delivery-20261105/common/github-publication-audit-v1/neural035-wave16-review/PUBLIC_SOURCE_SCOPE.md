# NEURAL-035 fixed-block program public source scope

This is source for the complete selected NEURAL-035 fixed 30-second endpoint: predict later within-session astrocytic fluorescence peak order from earlier public blocks. The source retains all 14 sessions, seven paired mice, 1,012 session-local cells and 28 query blocks. It does not reproduce the original paper's event-specific statistic or whole paper. It adds no task ID, new-animal generalization, causal-memory result, empirical performance result or benchmark qualification.

## Baseline and transparent metrics

The candidate and fixed analytic operator run in two isolated, networkless phases over the same complete read-only public view. Both programs are frozen before that view is prepared. The operator takes first exact maxima and exact constant-cell status independently in each of the five public blocks, computes normalized midranks within each block, and averages those ranks. Flat/degenerate public blocks contribute 0.5. This is not rank-of-mean-peak-time and is not a fitted task-specific model. No operator prediction was generated by this publication audit.

Transparent scalar grading source is included without target payloads. Query-flat cells remain required outputs but are excluded from that query's target-active ranking; candidate and target values are reranked on the same active subset. Mean absolute normalized-rank error is averaged through blocks, sessions, paired contexts and seven mice. An undefined block propagates to the complete primary rather than renormalizing a convenient subset. The fixed reference and all 99 circular-shift diagnostics retain their original meaning. The descriptive surrogate difference is not a p-value, scientific-success threshold or causal conclusion.

`deferred_grade.py` accepts protected data only through a future trusted callback after both complete reports are admitted. It is not invoked by the collection route or enabled by this export. A function signature accepting private data is not a private answer payload; authentic peaks, masks, surrogate values, mouse/context mapping and reports are absent.
