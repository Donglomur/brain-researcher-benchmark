# NEURAL-053: object-category decoding from MEG

Predict the object concept from a fixed MEG summary for a person and image exemplars excluded from supervised fitting. This is a new 1,854-way closed-set task, not the source paper's within-person pairwise category-decoding analysis. The classes are learned concepts; the held-out examples are new images and people, **not unseen concept labels**.

The intended source is all four THINGS-MEG participants, each with 12 sessions and ten runs/session, from OpenNeuro ds004212 version2.0.1, immutable commit `5405e3ef6478cd55da62d14c9340b4f95f620b03`. Author code is pinned to `5e0eccac51eac78b57045f5b90b4f53814f56c32`. Authentic metadata for all108,192 recorded trials has been joined. Each participant has22,248 experimental images (1,854 concepts ×12 exemplars),2,400 repeated-test presentations and2,400 catch trials. This endpoint uses all experimental images in the split policy below; repeated-test and catch trials are excluded by their source role, not by neural responses.

**Current status: partial.** Source labels, timestamps, complete acquisition identities and numerical/interface code exist. The full66,179,063,749B MEG/ocular derivative panel, actual feature packets, qualified reference runs and runtime validation do not. No biological prediction or baseline score has been computed.

## Fixed views and split

For each class, sort its12 experimental `things_image_nr` values by the raw SHA256 digest of UTF-8 `neural053-v1:<integer image ID>`, breaking a hash tie by numerical image ID. The first two are the global query-image set; the other ten are training images. This split is formed from authenticated stimulus identities only, before neural access. Every image identity has one class and the same experimental image/class roster in all four participants.

There are four leave-one-person-out folds. For a fold, all sessions from the held-out person are unavailable for training. Training uses the other three people's ten training images/class:55,620 rows. Query uses the held-out person's two query images/class:3,708 rows, with every one of the1,854 classes represented. The query image identities are excluded from training for **every person**, including across the other folds. This prevents repeated images from supplying the answer through a different recording. It does not test zero-shot concept learning.

All training transforms, feature choices, learned normalization, calibration and hyperparameter selection must use training data only. If selection is added, group entire training participants and globally repeated image identities; no trial-wise split of another person's copy of an image into both sides. The provided fixed reference has no hyperparameter search. No query-batch fitting or transduction is allowed. Each arm and fold must run in a fresh isolated view; the union of folds would expose training data from the nominally held-out person.

Query IDs are HMAC-derived, sorted opaque identifiers using a private operator key. Query views contain no source image/category IDs, original epoch ordering, image paths, corrected trigger/sample numbers, trial outcomes, response keys, source session/run names or eye/stimulus marker channels. Opaque order prevents alignment to the openly published event list by row number. The source itself is public and development-exposed; offline isolation cannot establish absence from model pretraining.

## Source-derived summaries and timing limits

The official MEG preprocessing uses optical-corrected event samples,0.1–40Hz whole-run filtering, per-epoch prestimulus z-scoring,−100..1300ms epochs and200Hz downsampling. It explicitly drops malfunctioning sensor MRO11-1609. The470 available channel sidecars all list272 physical MEG sensor names, including that sensor, but mislabel their types as `OTHER`; BIGMEG4 session02 lacks all ten channel/MEG sidecars. Therefore the preparer requires the exact remaining **271 names and actual magnetometer kinds from the processed FIF headers**, not a guess based on BIDS type or the acquisition-count wording. The missing sidecars do not justify dropping that session. Full headers and processed metadata remain unverified until the payloads are supplied.

For each experimental epoch and each of271 sensors, the neural feature is the mean of the40 source samples at **100 ≤ t < 300ms**. The input retains finite-sample fractions separately; an entirely missing feature is stored as zero with fraction zero, not as an observed zero. The neural arm contains271 means followed by271 fractions (542 columns). This is a fixed temporal summary of author-processed signals, not arbitrary access to native waveforms.

The ocular arm uses official eye derivatives from channels UADC009-2104, UADC010-2104 and UADC013-2104 (horizontal gaze, vertical gaze, pupil). These are eye-tracker analog channels, not EOG substitutes. Source prose has a suffix discrepancy for the vertical channel; pinned code and actual CSV header support2104. Eye data were processed across the run, including invalid-sample removal and detrending; no new interpolation is performed here. The preparer checks the full1,681-sample,1200Hz epoch order. Rounded millisecond CSV timestamps are validation metadata only: native sample ordinals240..479 select the exact100–300ms interval. Three finite means and three finite fractions give six features. Every eye row joins the same experimental image, class, person, session and run as MEG. The joint arm concatenates neural and ocular features (548 columns).

All three arms retain exactly the same queries. No eye-quality, response-accuracy, category-significance or held-out neural filtering may silently remove observations. Missing values remain explicit through fractions. Fraction patterns can carry acquisition/artifact information; a score does not by itself prove that oscillatory or representational content rather than missingness was used. Dedicated missingness-only and raw-processing controls are required before such stronger claims.

Zero-phase filtering and run-wide ocular processing can use data outside the selected100–300ms interval. This task is retrospective decoding from released derivatives. The fixed summary does not establish a causal latency boundary, online availability, cortical source localization or eye-artifact removal. Source clocks and original sensor identities are retained privately for qualification.

## Program input and fixed reference

A single allowed arm/fold directory contains `training.npz`, `queries.npz` and `contract.json`. Arrays are float32 `features`; training also contains int32 `labels` in1..1854. Contract training/query IDs define exact array order, along with class order. Only the specified feature arm is available to the solver. No private roster, original event tables, target arrays or other folds may be mounted.

`reference_program.py` is a new, unrun baseline: fit feature mean/standard deviation on training rows, replace zero scales by one, form one standardized mean per class, and softmax negative squared Euclidean distance divided by twice the feature count, with equal priors and fixed temperature. It fits no statistic on queries. This simple comparator is not an established SOTA decoder or the paper's CoSMoMVPA LDA. Stronger training-only programs may be submitted under the same eventual resource envelope. No execution/time/CPU/GPU qualification is implied by source availability.

## Submission and metrics

Submit `submission.json` plus four NPZs, named BIGMEG1.npz through BIGMEG4.npz, according to `submission.schema.json`. Each NPZ has exactly `query_ids` (`<U32`, shape3708), integer `classes` (shape1854, values1..1854), and `neural`, `ocular`, `joint` float32 or float64 probability matrices, each shape3708×1854. Arrays use C order. Each archive and its combined decompressed NPY members must be ≤192MiB. JSON is strict UTF-8, ≤262,144 bytes; no duplicate keys, pickle/object arrays, extra members, symlinks/FIFOs, path traversal or nonfinite probabilities.

Probabilities must lie in[0,1] and row sums must differ from one by ≤1e-6. They are not normalized or clipped by the grader. Class and query orders must match exactly. All four folds and all three arms validate before any private numerical targets are loaded.

Primary score: mean over the four people of **class-balanced Top-1 accuracy for the neural arm**. Within a person, average accuracy within each of the1,854 classes, then equally across classes. Also report class-balanced Top-5 accuracy and natural-log loss for every arm. Exact argmax/top-k ties favor smaller class IDs. A true-class probability of zero produces positive-infinite loss, encoded with a JSON-safe state; there is no artificial probability floor. Missing reference class support makes the primary unscorable instead of silently removing that class/person.

Fixed uniform and training-frequency priors use identical cases/classes and are scored separately. Report neural-minus-ocular, joint-minus-ocular, neural-minus-uniform and neural-minus-training-prior differences in balanced accuracy. The uncertainty diagnostic enumerates all4^4 resamples of the four paired person differences, using linear2.5/97.5 percentiles. Four people provide limited population evidence; intervals are not proof of general human robustness. Unlike metrics are never collapsed into one reward. No pass threshold, paper reproduction, SOTA result or native LLM-understanding claim is attached.
