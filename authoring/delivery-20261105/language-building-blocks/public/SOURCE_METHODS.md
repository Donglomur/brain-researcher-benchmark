# Source mapping and reproducibility limits

Primary version: Zenodo record 20128462; the exact six archive/README/environment MD5s and selected ZIP member CRC/offsets are in private ACQUISITION.json. AUTHOR_CODE_PINS binds the 18 unchanged selected Python files. Individual code bytes were obtained by exact HTTP ranges and checked against ZIP CRCs; the entire analysis archive MD5 was not recomputed. Header census decoded only NPY headers and verified declared numeric extents; it did not verify complete member CRCs or open neural/embedding values. Future provisioning authenticates whole archives before selecting all members.

The operative C1 population and D1 unit scripts, rather than filename prose, fix the full-context panel. `function_code.get_predictivity_neurons` uses source speaker[:,0]. For lag d<0 it pads -d zero response rows and drops the last -d, using original features/qids/speaker. For d>0 it pads d zero feature/qid rows and drops the last d, using the original response-time speaker mask. The padded qid is zero and may pass qid<99990; this unusual behavior is preserved only in native reconstruction. `get_explained_r` fits Ridge(alpha=.01) per left-out qid and correlates concatenated predictions with targets. The adapter uses a vectorized multi-target ridge for units; numerical parity with the serial source is untested.

C1 time-shuffle permutes the complete already-smoothed population series (seed20), not words or neuronal columns. C1 random-token, C1 sentence-swap and C2 context-length scripts use only prior_dt10. C3 semantic/combined and word2vec explicitly reshape word×30 arrays to word×30×1 and exclude NaN first-component rows; C3 onehot uses the supplied syn PCA array and does not remove word rows. All C3 curves use prior3/post0. All 16 named native arrays per session are required. Native curve interpretation is conditional on publisher-global PCA, background word means and source masking; the stricter prediction interface is separately named.

The paper describes populations across cortical regions, but the released anonymized p1..p8 mapping has not been authenticated to region/hemisphere here. No anatomical subgroup endpoint is fabricated. Sessions are repeated measurements nested in people; units are not cross-session matched. Primary benchmark aggregation is prospectively equal-person then equal-session; this differs from some paper displays weighted by neurons. No exact historical figure-number metric, reported significance or author-result file is used as hidden gold. Rebuilding the numerical reference remains future scientific work.

The released code/environment is Python3.11.3, NumPy1.24.3, SciPy1.10.1, pandas2.0.1, scikit-learn1.2.2. A minimal pinned recipe is supplied, but no image digest, dependency installation, numerical backend parity or runtime capacity is certified. No model checkpoints or raw language strings are needed for the selected PCA-conditional task.
