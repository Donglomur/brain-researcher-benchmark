## IDIF-002

**Proposal Title:** Image-derived input function and kinetic outcome for a heterogeneous dynamic-PET cohort — reference-region ratio + blood-calibrated macro-parameter — an execution-hard reconstruction task (recipe divergence + coupled-physics assembly + hidden robustness)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** PET kinetic modeling

**Source paper:** Logan et al. 1990, *JCBFM* (graphical analysis of reversible binding, https://doi.org/10.1038/jcbfm.1990.127); Patlak et al. 1983, *JCBFM* (graphical evaluation of blood-to-brain transfer constants, https://doi.org/10.1038/jcbfm.1983.1); Zanotti-Fregonara et al. 2011, *JCBFM* (image-derived input function, https://doi.org/10.1038/jcbfm.2011.107). Dataset: a **paper-parameterized** dynamic-PET IDIF cohort (Logan 1990 / Patlak 1983 graphical analysis; Zanotti-Fregonara 2011 IDIF), generated deterministically at `synth_build/generate_fixtures.py`; the true physiology is held out for grading under `tests/planted_truth.npz` (the reference run on the clean, artifact-free TACs, built by `synth_build/build_truth.py`; never under `environment/data`).

**Status: FULL runnable Harbor task.** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — the instruction names the deliverable (extract the IDIF and write the per-region ratio map always, and the absolute kinetic macro-parameter where blood samples exist); the difficulty is *execution*, not an un-cued judgement. The agent implements the IDIF-and-kinetic pipeline **from scratch** (no tool bundled), over a **heterogeneous 8-subject cohort where subjects need fundamentally different computations**, with a **declared robustness** requirement (realization hidden), graded per-region against the **held-out planted physiology** on **convention-invariant** quantities.

### What changed in this revision (addressing the review of the recompute-and-grade design)

1. **Robustness contract made public.** `instruction.md` now states, under *Robustness / data-quality contract*, that contaminated carotid voxels must be excluded before averaging, that a majority of subjects carry grossly motion-corrupted carotid tail frames that must be rejected before integrating the input function, and that the graphical model is fixed by the tracer class — only the *realization* (which voxels/frames/subjects) is hidden. A correct implementation of the stated method is no longer penalized for failing to guess an undeclared step.
2. **Graded against the true physiology, not one fitter.** The verifier no longer recomputes with a private pipeline on the real data and demands agreement. It compares each submitted outcome, region-by-region, to the **held-out planted target** = the IDIF + graphical-analysis reference run on the **clean, artifact-free** TACs (only good carotid voxels, no motion frames, no count noise; `tests/planted_truth.npz`, built by `synth_build/build_truth.py`). That target is the convention-invariant graphical macro-parameter; **any valid estimator** applied to the real data recovers it within tolerance. The hidden reference modules (`idif_pipeline.py`, `idif_ref.py`) were removed from `tests/`.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — two forks are latent in the data. The **tracer class** forks the graphical model: a reversible tracer needs the **Logan** distribution-volume slope, an irreversible tracer the **Patlak** net-influx slope — the wrong one is grossly biased and fails **both** maps. The **calibration state** forks whether the absolute map exists at all: `kinetic.npy` (VT or Ki) is written **only** where arterial blood samples exist and must be **omitted** otherwise (the recovery scale is undetermined) — writing it for a no-blood subject violates the omit rule. `ratio.npy` (DVR for reversible, Krel for irreversible) is always written.
2. **Coupled-physics assembly** — the carotid ROI blood curve must be assembled from candidate voxels, spillover-corrected with the given tissue fraction (`U = A − SP·Ctis`), recovery-calibrated by a closed-form blood-sample match, and fed through the trapezoidal cumulative integrals and the OLS graphical slope at the pinned `t_star` — an error in any one compounds.
3. **Declared robustness, hidden realization** — two un-cued-realization axes span the cohort: (a) the carotid candidate voxels of the calibrated subjects include **partial-volume/tissue-contaminated voxels** whose attenuated bolus must be excluded before averaging (biases the absolute map); (b) on a **majority** — the five irreversible-tracer exams — one or two carotid **tail frames are grossly motion-corrupted** and must be rejected before the input function is integrated. A tail-frame corruption is smoothed away by a Logan cumulative-integral slope but grossly biases a Patlak slope, so the motion axis punishes a pipeline that skips frame QC on **both** its kinetic and its ratio map. The instruction now *declares* both axes; only the *realization* (which voxels/frames/subjects) is hidden.
4. **Convention-invariant grading** — the graphical slopes are unique given the pinned `t_star` and integration convention; the noise-free planted target and any valid estimator on the real data (different carotid voxel selection, different corrupted-frame detection, `numpy.polyfit` OLS, framewise or trapezoidal integration) recover the same macro-parameter within tolerance — no reporting-convention ambiguity.

### Verifier

`tests/test_outputs.py` grades both maps **against the held-out planted physiology** (`tests/planted_truth.npz`; never under `/app/data`) — **per region** over the target regions, one parametrized test per (subject × map) panel. Reward is **fractional** over the **16 panels**. A supported panel passes when ≥90% (`PASS_FRAC`) of regions match the planted value within tolerance (ratio rtol 10%/atol 0.05; kinetic rtol 10% with atol 0.2 for VT / 0.002 for Ki, keyed off the tracer class stored in the planted truth); the kinetic panel of an uncalibrated subject passes only when the submission **omits** the file. The tolerances are unchanged from the original recompute-and-grade verifier; the target changed from a reference fit on the real data to the reference on the clean, artifact-free TACs. All reference modules were removed from `tests/`.

**Validity / discrimination evidence (recomputed for this revision).** The oracle recovers the planted target on **all 16 panels** (region agreement 0.95–1.00, comfortably above the 0.90 pass threshold; median per-region relative error 1–9%; the 3 uncalibrated kinetic panels correctly omitted). Wrong pipelines each fail their own axis, graded through identical grading logic: **skip frame QC** → 8 panels fail (the five irreversible subjects, both maps for the calibrated three + ratio for the uncalibrated two); **skip voxel QC** → 6 panels fail (the contaminated subjects). So a from-scratch correct solver passes and each single-axis shortcut fails, on axes the instruction now *declares*.

### Notes / honesty

- **Reconstruction paradigm.** This task's difficulty is executional (build the IDIF, the right graphical model, the calibration and the QC per subject, no recipe), unlike the recognition-tier "un-cued judgement" tasks in this repo. `instruction.md` names the deliverable, the model conventions, *and* the robustness contract, but never enumerates the *realization* (which subjects are which tracer/calibration state, which voxels are contaminated, which frames are corrupted) — the agent must discover it from the data.
- **Data.** Paper-parameterized, small, deterministic, and **leakage-clean** (the planted truth lives only in `tests/planted_truth.npz`, never under `/app/data`; verified by regen leaving `environment/data` byte-identical). Regenerable via `synth_build/generate_fixtures.py` + `synth_build/build_truth.py`.
- **allow_internet=false.** The task is self-contained (dependencies baked in the image; no network at run or verify time).
