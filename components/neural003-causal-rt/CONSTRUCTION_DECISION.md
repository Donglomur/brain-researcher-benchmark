# Construction decision

NEURAL-003 remains the response-independent EEG reaction-time task. The exact earlier offline cleaned-epoch condition is retained as retrospective evidence only. Its RT > 0.1 and <= 3 second selection is a conditional endpoint; it is neither the current causal programme nor evidence that a crop removes future preprocessing influence.

The recovered original writer uses a noncausal lowpass, record-wide selected-epoch ICA and manual retrospective inspection. Saved metadata have no original block/session mapping. The experiment records block/trial/condition, but the release's original raw-to-anonymized permutation, behavioral-to-EEG clock join and complete raw roster are not established. The paper specifies 1024 Hz acquisition; saved epochs are decimated to 512 Hz. The suggested 100 Hz laptop setting changes the recipe. No authentic recordings, headers or keys have been opened.

This candidate therefore contains new, independently determined downstream source components and a precise incomplete raw-input contract. It does not claim a complete producer chain, runnable programme or source acceptance. No N004 operative code is reused. N004's accepted conditional-contrast HMP programme cannot fill the causal input gap.

The prospective filter is explicitly new: a forward-only one-pole smoother with fixed alpha 1/8 at native 1024 Hz, after instantaneous common-average referencing. It is not the original 40 Hz filter or an approximation claimed to reproduce it. No ICA, interpolation, query-fitted standardization, resampling, acausal padding or post-deadline artifact rejection is permitted. Continuous state starts at the original session's acquisition start; the startup requirement is outcome-independent. All source samples contributing to a feature precede the fixed 100 ms deadline. The actual raw acquisition transfer function and timing must still be supplied and independently qualified.

All 26 people are held out in turn. Inner validation holds out each of the other 25 people, keeping each person's complete sessions, original blocks, instructions and trials together. Original blocks must be supplied through a verified source join; ordinal division or condition-run inference cannot manufacture them. The primary comparator uses contrast and instruction only. Expected-side covariates belong to a separate diagnostic, not the primary comparator.

Early responses observed by the 100 ms deadline are counted privately and excluded from the at-risk query set; their windows are never shortened. For later missing, interrupted or censored responses, the canonical total-RT estimand cannot be silently completed by assigning 3 seconds. The downstream scorer requires a separately sealed complete finite first-response target roster. Resolving that roster and the nonresponse estimand is a scientific prerequisite, not a schema acceptance. This package does not freeze a replacement capped-RT or survival endpoint.

The code below implements deterministic partitions, forward sample dependence, training-only transforms/references, strict complete-output admission and participant-macro MAE. It deliberately has no MAIN/native acquisition, event-to-behavior join, isolation attestation producer or runtime launcher. Those concrete missing producers are enumerated in MISSING_INPUT_CONTRACT.json. No dummy refusal adapter is presented as a finished programme.
