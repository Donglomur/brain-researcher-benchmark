# Operator canonical reference format

References are private evaluation operands. Supply them independently of the candidate, with accepted provenance and a separately pinned COMMIT.json. This package does not generate, download or qualify an authentic reference projection. The inherited scientific targets were produced by existing admitted reference readers and adapters; a new JSON projection must be independently checked against those accepted records before real use.

Both candidate and reference trees contain exactly the 1,020 roster filenames and COMMIT.json. Files have no write bits and are ordinary, single-link files; directories are sealed and static under a trusted operator after the producer is stopped. No symlink parent paths. These checks are not a sandbox or proof of immutable custody against a concurrent adversary.

Candidate COMMIT.json keeps the existing schema `cerebellar-committed-numerical-artifacts-v1`. Reference COMMIT.json uses `cerebellar-canonical-private-references-v1`. Both have exactly `schema`, `candidate_id` (`PAPER-FIND-REP-015`), `files` (every filename mapped to exact positive integer `bytes` and lowercase `sha256`) and `total_bytes`. Pin the entire manifest's bytes and SHA256 independently. Candidate records are bounded at 2,000,000 bytes and total 1,500,000,000; references at 8,000,000 bytes and total 4,000,000,000. COMMIT.json is at most 250,000 bytes. These are admission ceilings, not measured authentic projection sizes or guaranteed completion costs.

Each reference record contains exactly `target` and `trial_count_steps`. `target` has precisely the public candidate record structure and exact roster identity. `trial_count_steps` is one nonempty list per original trial, in trial order. Each list contains strictly increasing five-integer rows `[start_index1, Detection, FalseAlarm, Hit, Boundary]`, starts at threshold index 1, and covers through the figure's last threshold. Every row satisfies the same count conservation as the candidate. Later starts cannot exceed 150001 for F2 or 30001 for F3. The target's selected counts must equal the steps evaluated at its selected index.

This is the exact logical representation emitted by the existing accepted `adapters.f2` and `adapters.f3`; no new biological observations or refit are implied. The portable validator explicitly refuses missing trial series, duplicate/noninteger starts, absent first-threshold coverage and invalid counts. The unchanged numerical helper alone assumes these private invariants and is not a reference provenance validator.

All 1,020 candidate records are validated before any reference manifest or record is opened. Candidates are rechecked during scoring. Reference errors produce `operator_error`; malformed or unrepresentable candidate losses produce `invalid_submission`. Failure retains no partial score. Every successful grade includes all per-record diagnostics in roster-order column tables, the keyed-row digest and separate equal-mouse F2/F3 summaries. Reference/read counters count successfully decoded record bodies, including bodies rejected later by operator structural validation; they exclude manifest reads and are not kernel I/O counters.
