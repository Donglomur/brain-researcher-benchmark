## MULTIECHOFMRI-002

**Proposal Title:** Multi-echo fMRI — per-voxel T2* mapping and the temporal SNR of the optimal echo combination across a heterogeneous cohort — an execution-hard reconstruction task (recipe divergence + coupled-physics assembly + declared robustness with hidden realization)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** Multi-echo functional MRI

**Source paper:** Posse et al. 1999, *MRM* (multi-echo BOLD optimal combination, https://doi.org/10.1002/(SICI)1522-2594(199907)42:1<87::AID-MRM13>3.0.CO;2-O); Kundu et al. 2012, *NeuroImage* (multi-echo EPI / tedana, https://doi.org/10.1016/j.neuroimage.2011.12.028). Dataset: a **paper-parameterized** multi-echo fMRI cohort (Posse 1999 / tedana model), generated deterministically at `synth_build/generate_fixtures.py`; the true physiology is held out for grading under `tests/planted_truth.npz` (the reference run on the artifact-free signal, built by `synth_build/build_truth.py`).

**Status: FULL runnable Harbor task.** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — the instruction names the deliverable (estimate per-voxel T2*, and the tSNR of the T2*-weighted optimal echo combination, per subject); the difficulty is *execution*, not an un-cued judgement. The agent implements the tedana-style pipeline **from scratch** (no fitter bundled), over a **heterogeneous 8-subject cohort where subjects need fundamentally different computations**, with a **publicly-declared robustness** requirement (the corrupted-frame realization hidden), graded voxelwise against the **planted physiology** on **convention-invariant** quantities.

### What changed in this revision (addressing the review of the hidden-reference contract)

1. **Robustness contract made public.** `instruction.md` now states, under *Robustness / data-quality contract*, that a majority of subjects carry grossly motion-corrupted frames that must be detected and censored before the temporal mean and the tSNR — only the *realization* (which subjects/frames) is hidden. A correct pipeline is no longer penalized for failing to guess an undeclared step.
2. **Graded against the true physiology, not one fitter.** The verifier no longer recomputes with a private pipeline on the real data and demands agreement. It compares each submitted map, voxelwise, to a **held-out planted target** (`tests/planted_truth.npz`, built by `synth_build/build_truth.py`): T2\*/S0_norm are the reference fit of the **noise-free, motion-free** signal (the apparent physical values, dropout included), and tSNR — a noise-defined quantity — is the reference run on the **real signal with the ground-truth-corrupted frames removed** (the tSNR obtained by perfectly censoring the known-bad frames). Any valid estimator recovers these within tolerance. The hidden reference modules were removed from `tests/`.
3. **tSNR identifiability handled honestly.** Because tSNR needs the real noise (a noise-free signal has zero temporal variance), its target is anchored to the ground-truth censoring rather than to a noise-free signal; the oracle recovers it at 100% voxel agreement, and a non-censoring pipeline fails it. Per-map tolerances are unchanged from the prior revision.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — a 3+-echo train supports a validated per-voxel mono-exponential T2*/S0 map, while a 2-echo train does **not** (the fit is exactly determined and un-validatable, like a water-reference-absent absolute concentration) so the T2*/S0 maps must be **omitted** — yet those same 2-echo subjects still need the exact 2-point T2* *internally* to weight the optimal echo combination whose tSNR is graded for **every** subject. A single fixed recipe cannot fit the cohort.
2. **Coupled-physics assembly** — the log-linear T2*/S0 fit, the Poser optimal-combination weights `w = TE·exp(−TE/T2*)`, and the temporal-SNR of the combined series must **all** be assembled correctly; an error in any one compounds across the (subject × map) panels.
3. **Declared robustness, hidden realization** — a **majority** (5 of 8) of subjects carry a few grossly motion-corrupted time frames that must be censored **before** the temporal mean (which feeds T2*/S0) *and* before the tSNR, or both are biased on those subjects; a minority carry a susceptibility-dropout region of shorter-apparent-T2* late echoes. `instruction.md` now *declares* the corrupted-frame requirement; the *realization* (which subjects/frames) stays hidden.
4. **Convention-invariant grading** — T2* (ms), S0_norm, and tSNR are uniquely determined given the pinned model; a from-scratch implementation (a different motion detector via a robust MAD z-score, a non-linear magnitude-domain T2* fit) recovers the same planted physical values within tolerance (verified below), so a correct solver can pass while wrong pipelines fail — no reporting-convention ambiguity.

### Verifier

`tests/test_outputs.py` grades **voxelwise** over the brain mask against `tests/planted_truth.npz`, one parametrized test per (subject × map) panel — **24 panels** (8 × {T2star, S0_norm, tSNR}); the binary Harbor reward requires all to pass. The planted target is the reference run on the artifact-free signal (built by `synth_build/build_truth.py`), so the grader accepts **any scientifically valid estimator** and never requires the output of one particular fitter. A computable map passes when ≥90% of brain voxels agree within a per-map tolerance (T2star rtol 8%/atol 2 ms; S0_norm rtol 6%/atol 0.03; tSNR rtol 8%/atol 3); an unsupported map (T2star/S0_norm for a 2-echo subject) passes only when the submission **omits** it (the key is absent from the planted truth). The hidden reference pipeline was removed from `tests/`.

**Validity / discrimination evidence (recomputed for this revision).** The oracle recovers the planted target on **all 24 panels** — T2*/S0_norm at ≥98.6% voxel agreement (worst is the dropout subject's S0_norm) and every tSNR panel at 100% — comfortably inside tolerance. A **naive pipeline that skips the motion censoring fails 8 panels** through the real verifier, exactly on the 5 motion subjects (T2* and tSNR biased by the uncensored frames), while the 3 motion-free subjects still pass. So a from-scratch correct solver passes and the single-axis shortcut fails, on the axis the instruction *declares*.

### Notes / honesty

- **Reconstruction paradigm.** This task's difficulty is executional (get the per-subject echo-count fork, the optimal-combination weights, and the motion robustness right with no recipe), unlike the recognition-tier "un-cued judgement" tasks in this repo. `instruction.md` names the deliverable, the physics conventions, and (now) the declared motion-censoring requirement — but the corrupted-frame *realization* (which subjects/frames) stays hidden and must be discovered from the data.
- **Data.** Paper-parameterized, small, deterministic, and **leakage-clean** (the planted truth lives only in `tests/planted_truth.npz`, never under `/app/data`). Regenerable via `synth_build/generate_fixtures.py` + `synth_build/build_truth.py`.
- **allow_internet=false.** The task is self-contained (dependencies baked in the image; no network at run or verify time).
