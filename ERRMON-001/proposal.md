## ERRMON-001

**Proposal Title:** Error-related frontocentral negativity in the ERP CORE Flankers task — an un-cued time-locking trap (the error negativity is generated at the response, ~400 ms after the stimulus)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** cognitive EEG / event-related potentials

**Source finding / dataset:** The **error-related negativity (ERN)** — the frontocentral (FCz) negativity that follows an erroneous button press — quantified as the **mean error-minus-correct amplitude at FCz in the 0-100 ms window** for the **ERP CORE** Flankers task (subject 001). **Dataset:** fetched at runtime with `mne.datasets.erp_core.data_path()` (no credentials; the MNE ERP CORE bundle is the Flankers task, subject 001). Genre: **reproduction**.

### The un-cued lever (PRIVATE — reviewers only)

The deliverable ("the mean error-minus-correct amplitude at FCz in a 0-100 ms window") never says **which event the epochs are time-locked to**. The recording marks both the flanker arrays (`stimulus/...`) and the button presses (`response/left|right`). The error-related frontocentral negativity is generated by the performance-monitoring/motor system at the moment of the **erroneous response**, and the button presses occur a variable ~400 ms (206-1438 ms here) after the array. Averaging epochs time-locked to the **response** reveals the full negativity (~-5.9 µV at FCz); time-locking to the **stimulus** (the naive choice — the stimulus markers are the salient "trials" and stimulus-locked ERPs are the default) smears it across the reaction-time jitter and all but cancels it (~-0.6 µV in the same window). The instruction gives the annotation codes (needed to pair each array with its response and label errors) but never states that the negativity is response-locked, never mentions epoching to the button press, and never says the stimulus is the wrong anchor.

Everything else is pinned so only the time-locking choice moves the number: subject 001; an **error** = pressed hand ≠ target arrow direction; **FCz**; **average reference** over the 30 scalp electrodes; **0.1-30 Hz** band-pass; a **pre-event baseline** (200 ms); the **mean amplitude in the 0-100 ms** window; error-average minus correct-average. Because the graded quantity is a within-electrode **error-minus-correct difference**, it is robust to the baseline window and to the low-pass edge; the reference is pinned (it materially changes the value) so it is not a free axis.

### Step-0 (validated, real data — MNE 1.12.1)

Pinned pipeline; mean error-minus-correct amplitude at FCz, 0-100 ms window (subject 001, 400 trials paired, 54 errors / 346 correct):

| time-locking | reported ERN amplitude |
|---|---|
| **aligned to the RESPONSE (correct)** | **-5.9 µV** |
| aligned to the STIMULUS (naive), same 0-100 ms window | **-0.6 µV** |

The correct value is robust: **-5.5 to -6.2 µV** across low-pass 15/20/30/40 Hz and across pre-event baseline windows (-400..-200 and -100..0), average reference. Median reaction time 404 ms (range 206-1438 ms). Every **stimulus-locked** window stays small in magnitude: 0-100 ms → -0.6, 0-150 ms → -0.1, 200-400 ms → -2.1, 300-500 ms → -3.9, 400-600 ms → -2.3 µV — none reaches the response-locked value.

### Why this quantity is well-posed (reviewers)

The ERN is, by definition and physiology, a **response-locked** component: the "error-related" frontocentral negativity is time-locked to the erroneous response, so its correct value is the response-aligned one (~-5.9 µV). The stimulus-aligned value (~-0.6 µV) is not a competing convention — it is simply the wrong anchor for this signal. The graded quantity is an **error-minus-correct difference** at a single pinned electrode with a pinned reference, so it is convention-robust (baseline and low-pass edge cancel in the difference); this is the same amplitude genre already used by AUDN1-001. The reference is a real amplitude axis (average → -5.9 µV, linked-mastoid → -11 µV), so it is **pinned** in the instruction rather than left free, exactly so the reference is not the lever — the only un-cued analytic choice is the time-locking.
