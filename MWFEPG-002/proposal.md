## MWFEPG-002

**Proposal Title:** Myelin water fraction from an EPG-corrected multi-echo-T2 cohort — an execution-hard reconstruction task (recipe divergence + coupled-physics assembly + declared robustness with hidden realization)

**Scientific Domain:** Life Sciences · **Field:** Neuroscience · **Subfield:** Quantitative MRI / relaxometry

**Source paper:** Prasloski et al. 2012, *MRM* (stimulated-echo (EPG) correction for multicomponent T2 / myelin-water analysis, https://doi.org/10.1002/mrm.23157); MacKay et al. 1994, *MRM* (in-vivo myelin-water imaging, https://doi.org/10.1002/mrm.1910310614). Dataset: a **paper-parameterized** multi-echo spin-echo (CPMG) cohort (Prasloski 2012 EPG model), generated deterministically at `synth_build/generate_fixtures.py`; the true physiology is held out for grading under `tests/planted_truth.npz` (the pinned reference run on the noise-/artifact-free signal, built by `synth_build/build_truth.py`).

**Status: FULL runnable Harbor task.** This is a **reconstruction** task, *not* a recognition / "spot-the-confound" task — `instruction.md` names the deliverable (produce per-voxel MWF and, where supported, gmT2); the difficulty is *execution*, not an un-cued judgement. The agent implements an EPG-corrected myelin-water inversion **from scratch** (no fitter bundled), over a **heterogeneous cohort where subjects need fundamentally different computations**, with a **publicly-declared robustness** requirement (the corrupted-echo realization hidden), graded voxelwise against the **planted physiology** on **convention-fixed apparent** quantities.

### What changed in this revision (addressing the review of the hidden-reference contract)

1. **Robustness contract made public.** `instruction.md` now states, under *Robustness / data-quality contract*, that a majority of subjects carry grossly corrupted echoes that must be detected and rejected before the inversion — only the *realization* (which subjects/echoes) is hidden. A correct fit of the pinned model is no longer penalized for failing to guess an undeclared step.
2. **Graded against the true physiology, not one fitter.** The verifier no longer recomputes with a private pipeline on the real data and demands agreement. It compares each submitted map, voxelwise, to the **held-out planted target** = the pinned reference run on the **noise-/artifact-free** signal (`tests/planted_truth.npz`, built by `synth_build/build_truth.py`). Because the spectrum inversion is ill-posed, this is the *apparent* value of the pinned, convention-fixed inversion (grid, μ, cutoff, window all pinned); any valid estimator implementing the pinned physics recovers it within tolerance. The hidden reference modules were removed from `tests/`.
3. **Identifiability made honest in the tolerance.** The many-echo spectrum MWF is well-conditioned (atol 0.03), but the **few-echo pinned-3-pool MWF is only constrained by 8 echoes** and carries a genuine Rician-driven scatter in the fast-decaying myelin pool, so its atol is 0.07 (measured; still far below the >0.4 error a non-robust fit incurs on a corrupted subject). gmT2 tolerance unchanged.

### Why this is hard (the four difficulty drivers)

1. **Recipe divergence** — subjects need *different code paths*, discoverable only from each sidecar: **many-echo** subjects (32 echoes) support the full regularized T2 spectrum and report **MWF + gmT2**; **few-echo** subjects (8 echoes) cannot resolve a spectrum and must instead be fit with the pinned **3-pool model**, reporting **MWF and omitting** the spectrum-derived gmT2. A uniform recipe is wrong on one fork.
2. **Coupled-physics assembly** — the CPMG echo train is **non-mono-exponential** because the refocusing flip departs from 180° (nominal <180° for most subjects, times a per-voxel B1 transmit map), so the per-T2 basis must be the **extended-phase-graph (EPG) stimulated-echo amplitude** at the true flip α = B1·nominal (a plain exp(−TE/T2) basis biases MWF on every non-180° subject); the ill-posed spectrum is recovered by a pinned **first-derivative-regularized non-negative least squares** (fixed μ=1.5) on a pinned log-spaced grid; MWF is the short-T2 (≤40 ms) fraction and gmT2 the amplitude-weighted geometric-mean T2 over the intra/extra-cellular window. Errors compound.
3. **Declared robustness, hidden realization** — a majority of subjects carry one or two grossly motion-corrupted echo volumes that must be **detected and rejected** before the fit, or the whole spectrum (and thus MWF and gmT2) is wrong. `instruction.md` now *declares* this requirement; the *realization* (which subjects/echoes) stays hidden.
4. **Convention-fixed grading** — the regularized fit is strictly convex and the flip is supplied, so the pinned inversion determines a unique apparent MWF and gmT2; any correct implementation of the pinned physics recovers the same planted values within tolerance (verified below), so a from-scratch solver can pass while wrong pipelines fail — no reporting-convention ambiguity.

### Verifier

`tests/test_outputs.py` grades **voxelwise** over the brain mask against `tests/planted_truth.npz`, one parametrized test per (subject × map) panel — **16 panels** (8 × {MWF, gmT2}); reward is **fractional** (each panel its own test). The planted target is the pinned reference run on the noise-/artifact-free signal (built by `synth_build/build_truth.py`), so the grader accepts **any scientifically valid estimator** of the pinned physics and never requires the output of one particular fitter. A computable map passes when ≥90% of brain voxels agree within a per-map tolerance (gmT2 rtol 6%/atol 4 ms; MWF rtol 8% with atol 0.03 for the well-conditioned many-echo spectrum and 0.07 for the 8-echo pinned-3-pool fit); an unsupported map (gmT2 for a few-echo subject) passes only when the submission **omits** it (the gmT2 key is absent from the planted truth). The hidden reference pipeline was removed from `tests/`.

**Validity / discrimination evidence (recomputed for this revision).** The oracle recovers the planted target on **all 16 panels** — many-echo MWF and every gmT2 at ≥0.99 voxel agreement, the noisier few-echo 3-pool MWF at ≥0.95 — comfortably inside tolerance. A **naive fit that skips the gross-echo rejection fails 8 panels** through the real verifier, exactly on the corrupted subjects (MWF and, where present, gmT2), while the uncorrupted subjects still pass every panel. So a from-scratch correct solver passes and the single-axis shortcut fails, on the axis the instruction *declares*.
